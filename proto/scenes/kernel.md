# 闭环：线性变换的核

阶段：大学（线性代数，第一次系统学习线性变换）
学习者已学过（前置，假定已闭环）：向量空间、子空间的定义与判定、线性变换的定义、矩阵乘法、齐次线性方程组的解法。
学习者尚未学过（有限视角：不得用来解释）：像空间与秩–零化度定理、特征值、对偶空间、商空间。

## 验收范围（主张 + 证据）

类型：【教学】= 本闭环要教会的；【确认】= 前置或可能已会的，有行为证据即可，不要求口头讲解。

1. 【结构】【教学】能解释为什么核被定义为“映射到零向量的全体向量”——这个定义在回答什么问题。
   证据：无提示下用自己的话讲清动机；并能回答“如果 T 不是线性的，这个集合还有这些好性质吗”。
2. 【复现以上】【教学】能独立证明：核是定义域的子空间。
   证据：独立写出完整证明，零向量、加法封闭、数乘封闭三步不缺，每步说明用到了线性的哪一条。
3. 【结构】【教学】能说明核与“线性变换是否单射”的关系。
   证据：无提示下给出“核只含零向量 ⇔ 单射”的论证（至少一个方向完整）。
4. 【近迁移】【教学】题目中不出现“核”字时，能认出问题本质是在求核。
   证据：变式题（例如“求所有满足 f(p)=0 的多项式 p，f 为求导”），无提示下识别并求出。
