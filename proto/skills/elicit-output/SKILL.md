# 让学习者输出：为了决定下一步

## 为什么要学习者输出

你看不到学习者脑子里有什么，只能看到学习者说出来、写出来的东西。你下一步怎么做——往前走、回头补哪一步、能不能收尾——取决于学习者实际掌握了什么，所以需要学习者输出。

同一次输出对学习者自己也是学习：自己组织一遍，理解才真正完成；只看懂、跟着点头，停在“感觉懂了”。所以训练不是讲完以后附加的检查，而是闭环的一半。

## 什么时候要

只在你下一步的做法取决于你还不知道的东西时要。问自己：学习者这次说什么，会改变我接下来做的事吗？

- 会——不知道上一步站没站稳；不知道学习者离开原来的情境还能不能用；看到学习者错了，但不知道错在哪一环。这时要。
- 不会——对话里已经看清的（学习者自己推出过、自己讲清过），不再要，往前走。反复要已经看到的东西，学习者会觉得在被考；早期原型就是这样失败的：按一张预先定好的清单要证据，和下一步做什么无关。

“我懂了”“明白”不算看清；学习者自己做出来、讲出来才算。

## 要什么

面对面对话里信息最多的，是让学习者自己组织：讲为什么、推一段、在一个情境里用。选刚好能回答你那个疑问的一种，不追求越难越好。

| 你想知道 | 让学习者做 |
| --- | --- |
| 这一步站没站稳 | 用自己的话说为什么这样做，或把关键一步自己推一遍 |
| 能不能用、能不能和旧知识接上 | 给一个新情境，让学习者用刚走完的这一段去处理 |

新情境最好同时用到学习者已经站稳的知识点。考试题值得借的就是这一点：一道题把几个知识点组合起来，新的一段能不能和旧的接上，一次就看得出来。组合的材料：

- `m09/`：学习者已经走通的链；
- `m08.md`：和本段相连的知识点（前置、推导、混淆关系）；
- `m07/chNN/prob-N.md`：教材习题，部分有书末答案 `ans-N.md`。可以直接用或改编，但放进对话里一起做，不当作业布置。

例：学习者刚自己推出变质量方程，并说“后面的我不清楚怎么推了”。这正是给新情境的时候，比如一个同时要用到这个方程和学习者已会的系统选取、受力分析的情境，而不是宣布这一段结束。

## 看学习者的输出

- 看思路，不只看结果：从哪一步开始偏，偏在道理上还是计算上。
- 道理上的缺口：回到那一步讲清楚，再让学习者用一次。训练暴露缺口、讲解补上、再用——这个来回就是闭环里的“理解 ↔ 训练”。
- 计算失误：指出即可，不回头重讲。
- 想了但没做出来：这次尝试本身有价值。先看学习者卡在哪，给能让学习者继续的最小提示，不急着给整套解法。
- 在新情境里做对了、讲清了：这就是“新情境下能用”，收口时直接用这段对话，不另外再考。
