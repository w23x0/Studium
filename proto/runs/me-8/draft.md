# 讲解稿：质点系动量定理——为什么只对成员固定的系统成立，系统边界怎样选

## 2. 能从各质点的第二定律出发推导 dP/dt = F_ext，并讲清这个结论的动机、成立前提，以及成员改变时它为什么不能直接用。

对于单质点第二定律有 $dp/dt=F+\sum f$ 对于选定的一个系统内 dP/dt = $\sum dp/dt$ =F_ext 因为f由于牛三内部都抵消了 成立前提是系统选取之后内部成员不变 成员改变则前后成员动量和不一致 结果不符合

## 3. 能讲清系统边界怎样选：内力与外力由边界决定，选定后必须前后一致，不同选法通过第三定律给出一致的结果。

因为系统区分了内力和外力 将内力给化简了 所以得看具体场景 需要求什么里就怎么选取系统即可

## 4. 能综合运用"按边界划分内外力 + 质点系动量定理"处理有外力的多体问题，并用两种系统选法和极限情形检验结果。

系统的作用是将作用力分成两种 内力和外力 对于内力来说我们可以做到一个忽视的作用 即去掉内力影响计算外力数值 通过对对象的组合多种系统达到计算特定的对象的作用力的作用
