符号：
- 参考系：惯性系（地面）。
- 质点 1、2：系统的两个成员，名单固定。
- p₁、p₂：两质点各自的动量（矢量）。P = p₁ + p₂ 为系统总动量，逐分量相加。
- F₁ᵉˣᵗ、F₂ᵉˣᵗ：系统以外的物体对质点 1、质点 2 的合力（外力）。
- f₁₂：质点 2 对质点 1 的力；f₂₁：质点 1 对质点 2 的力（内力）。
- N 质点推广：pᵢ 为第 i 个质点的动量，Fᵢᵉˣᵗ 为它受的外力，fᵢⱼ 为 j 对 i 的力；P = Σpᵢ，F_ext = ΣFᵢᵉˣᵗ。
- 虚线框例：光滑水平桌面上画一个固定的虚线框，虚线不是物体。小球质量 m，以恒定速度 v 从框外进入框内，所受重力与支持力平衡。"系统"定义为"此刻在框里的东西"。
- 拖车例：水平直路上，卡车（质量 M）用轻绳拖小车（质量 m），两者同以加速度 a 前进，正方向取前进方向。地面对卡车的水平推动力为 F，小车阻力忽略。T 为绳对小车的拉力（向前），绳对卡车的拉力为 −T（向后）。
- 木板物块例：光滑冰面上有木板 B（4 kg），B 上放物块 A（1 kg），A、B 间有摩擦且相对滑动。水平恒力 10 N 向右拉 B。此刻 A 的加速度为 1 m/s²，向右。正方向取向右。
- 弹簧连接体例：光滑水平面上，木块 A（m₁）与 B（m₂）由轻弹簧相连，水平恒力 F 向右作用在 A 上，正方向取向右。此刻 A 的加速度为 a₁，B 的加速度为 a₂。弹簧对 B 的力记为 T_B。

已推出：
- 单质点 F = dp/dt 按分量使用，质量恒定时与 F = ma 一致。F = ma 是矢量等式，三个分量方程同时成立（L11 学习者；L35 学习者，轻微提示后）。
- P = (3, 2, 0) kg·m/s，矢量逐分量相加；p(t) = (t², 2t, 0) 在 t = 2 s 时 dp/dt = (4, 2, 0) kg·m/s²（L49，学习者，独立）。
- 两质点相加，由 f₁₂ = −f₂₁ 得 dP/dt = F₁ᵉˣᵗ + F₂ᵉˣᵗ（L65，学习者，分步提示下；抵消一步由系统补写）。
- N 质点：dP/dt = F_ext（L70–72，系统讲）。
- 小球在所选系统之外时，它与系统之间的力不是内力（L82，学习者，独立）。
- 虚线框例中名单改变，P 的变化来自名单变化，不来自外力。dP/dt = Σdpᵢ/dt 要求求和的始终是同一批质点（L94 学习者，轻微提示后；L103–107 系统讲）。
- 前提：每个质点的第二定律都在惯性系中成立，内力都满足第三定律。若内力不成对抵消，dP/dt = F_ext + Σ（内力残差）（L117–123，系统讲）。
- 内力只在求总和时抵消，单个成员的 dpᵢ/dt 仍含内力（L129，系统讲）。
- dP/dt = F_ext 不是新定律，由单质点 F = dp/dt 与第三定律直接推出，对任何一批质点都成立，不限于刚体（L127，系统讲）。
- 内力或外力由所选边界决定，不是力本身的属性（L137 系统讲；L189 学习者，短答）。
- 拖车例：取卡车 + 小车为系统，F = (M + m)a；只取小车，T = ma；只取卡车，F − T = Ma。后两式相加即得第一式，衔接靠绳对两车的力等大反向（L148–155，系统讲）。
- 木板物块例：只框 A，摩擦力 1 N 向右；只框 B，10 − 1 = 4a_B，a_B = 9/4 m/s²；框 A + B，10 = 1·1 + 4a_B，结果相同（L201，学习者，独立）。两式一致，是因为 A、B 间的一对摩擦力等大反向（第三定律），整体式等于两个部分式之和（L208，系统讲）。
- 弹簧连接体例：框 A + B，F = m₁a₁ + m₂a₂，a₂ = (F − m₁a₁)/m₂；框 B，T_B = m₂a₂ = F − m₁a₁（L221，学习者，独立）。
- 若 a₁ = F/(m₁ + m₂)，则 a₂ = a₁（L221，学习者，独立）；T_B = m₂F/(m₁ + m₂)（L226，系统纠正；L233 学习者认可）。这一时刻只能说明没有相对加速度（L227，系统讲）。
- 只框 A 时，弹簧对 A 的力是外力（L233，学习者，短答）。
