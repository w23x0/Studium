## 验收范围（主张 + 证据）

类型：【教学】= 本闭环要教会的；【确认】= 前置或可能已会的，有行为证据即可，不要求口头讲解。

1. 【P3】【复现】【确认】能用分量表示矢量，会逐分量做矢量加法和对时间求导，知道不同方向的分量不能相加成一个数。
   证据：独立、过程可见地做对一道题。题目：两个质点的动量分别为 p₁ = (2, −1, 0) kg·m/s 和 p₂ = (1, 3, 0) kg·m/s。
   - 求总动量 P = p₁ + p₂（逐分量相加，得 (3, 2, 0) kg·m/s）；
   - 若某质点的动量为 p(t) = (t², 2t, 0) kg·m/s，求 t = 2 s 时的 dp/dt（逐分量求导，得 (4, 2, 0)）。
   常见误解：
   - 把同一矢量的不同分量当作标量相加。
   - 把各矢量的模直接相加，当作合矢量的模。

2. 【K1】【复现】【确认】能对单个质点使用矢量形式的 F = dp/dt，并知道质量恒定时它与 F = ma 一致。
   证据：独立、过程可见地做对一道题。题目：质量 2 kg 的质点动量为 p(t) = (3t², 4t, 0) kg·m/s。
   - 求 t = 1 s 时它所受的合力（按分量对 t 求导，得 (6, 4, 0) N）；
   - 写出此刻的加速度，并验证 F = ma 成立。

3. 【K3】【结构】【确认】能从各质点的第二定律出发推导 dP/dt = F_ext，并讲清这个结论的动机、成立前提，以及成员改变时它为什么不能直接用。
   证据：独立、过程可见地做对一道题，不要求口头讲解。题目：两质点系统不受外力。假设它们之间的相互作用力不满足第三定律，例如 f₁₂ = −2f₂₁（假想情形）。
   - 求 dP/dt。合格答案：dP/dt = f₁₂ + f₂₁ = −f₂₁，一般不为零；
   - 用一句话指出 dP/dt = F_ext 依赖哪两条（单质点 F = dp/dt 和第三定律），以及它为什么让人不必知道内力也能研究整体。
   常见误解：
   - 把 dP/dt = F_ext 当成另立的定律，或以为只对刚体成立。
   - 以为内力相互抵消，所以内力也不影响系统各部分的运动。
   - 以为某个"系统"只要不受外力，动量就一定不变，而不检查成员是否固定。
   - 把进出质点带走的动量当成一种"外力"。

4. 【K2】【结构】【确认】能讲清系统边界怎样选：内力与外力由边界决定，选定后必须前后一致，不同选法通过第三定律给出一致的结果。
   证据：独立做对一道题，不要求口头讲解。题目：沿用主张 5 的弹簧双木块情境。某同学在 t₁ 取"A + B"计算总动量，在 t₂ 只计算 B 的动量，再把两者之差除以时间间隔，当作外力 F。指出错误。合格答案：考察过程中途换了系统，前后不是同一批成员，这个差值没有意义。
   常见误解：
   - 在考察过程中途更换系统，例如前一时刻取整体、后一时刻只算一部分。
   - 把边界外物体施加的力当作内力略去，或把边界内的相互作用当作外力。
   - 认为分部分分析"不合法"或"不如整体分析正确"。

5. 【K3】【近迁移】【确认】能综合运用"按边界划分内外力 + 质点系动量定理"处理有外力的多体问题，并用两种系统选法和极限情形检验结果。
   证据：独立、过程可见地做对下题中能说明问题的一问即可（(a) 或 (d)），不要求逐问取证。
   题目：光滑水平面上，木块 A（质量 m₁）与 B（质量 m₂）由轻弹簧相连。水平恒力 F 作用在 A 上，某时刻测得 A 的加速度为 a₁。
   (a) 求此刻 B 的加速度 a₂ 和弹簧对 B 的弹力。
   (b) 分别取"A + B（含弹簧）"和"只取 B"为系统，各写一次方程，说明两者怎样一致，以及为什么不需要知道劲度系数和形变量。
   (c) 某同学取 A 为系统，写出 F = m₁a₁，理由是"弹簧是内部的"。指出错在哪里。
   (d) 若 a₁ 恰好等于 F/(m₁ + m₂)，a₂ 和弹力各为多少？说明这对应什么运动情形。
   合格表现：
   - 写明所选的系统，并据此判断弹簧力是内力还是外力；
   - (a) 得到 a₂ = (F − m₁a₁)/m₂，弹力为 F − m₁a₁；或 (d) 得到 a₂ = a₁，弹力为 m₂F/(m₁ + m₂)，并指出两木块一起运动，没有相对加速度。

停靠点：
① 主张 1 之后：矢量的分量加法与求导已会。
② 主张 2 之后：单质点 F = dp/dt 已确认。
③ 主张 3 之后：已能推导 dP/dt = F_ext，并说清"同一批质点"这个前提。
④ 主张 4 之后：已能说清内外力由边界决定、两种选法的衔接。主张 5 为确认，取到一问即可结束本闭环。
