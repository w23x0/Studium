# 闭环：牛顿第二定律

阶段：高中物理（第一次系统学习牛顿第二定律）
学习者已学过（前置，假定已闭环）：力的概念与常见力（重力、弹力、摩擦力）、力的合成与分解、牛顿第一定律、匀变速直线运动公式。
学习者尚未学过（有限视角：不得用来解释）：动量与冲量、功与能、圆周运动与向心力、非惯性系。

## 验收范围（主张 + 证据）

类型：【教学】= 本闭环要教会的；【确认】= 前置或可能已会的，有行为证据即可，不要求口头讲解。

1. 【结构】【教学】能说明 F=ma 回答的是“力怎样改变运动”：F 是合外力，a 与合外力同向，力是改变运动状态的原因而不是维持运动的原因。
   证据：无提示下用自己的话讲清；并能正确回答“物体的运动方向一定与合外力方向相同吗”，给出理由或反例。
2. 【复现以上】【教学】能对单个物体做受力分析并用牛顿第二定律求加速度。
   证据：独立完成一道有摩擦的斜面题：受力图完整、按合适方向分解、列式并求出 a，每一步说明依据。
3. 【结构】【教学】理解加速度与合外力的瞬时对应。
   证据：无提示下判断“剪断细绳 / 撤去某力的瞬间”物体的加速度，并说明为什么弹簧弹力不能突变而绳的拉力可以。
4. 【近迁移】【教学】能处理连接体问题。
   证据：变式题（两物块由轻绳相连在水平面上被拉动），无提示下自行选择整体法或隔离法，求出加速度与绳的张力。
