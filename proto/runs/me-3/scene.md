# 闭环：用微分形式的牛顿第二定律求解一维速度相关阻力问题

阶段：大学基础物理（力学），据自述判断（高中物理已学完、学过微积分）。
学习者已学过（前置）：
- 高中形式的牛顿第二定律 F = ma、受力分析、匀变速直线运动公式（自述）
- 导数与积分的基本运算，包括带初值的不定积分和定积分（自述）
- 分离变量法求解形如 dy/dt = f(y) 的一阶常微分方程（假定）
- 指数与对数函数的运算（假定）

学习者尚未学过（有限视角：不得用来解释）：
- 动量形式 F = dp/dt 在变质量系统（如火箭）中的使用
- 非惯性参考系与惯性力
- 线性常微分方程的一般解法（积分因子、特征方程）
- 二维、三维中矢量方程耦合的运动（如带空气阻力的抛体）
- 拉格朗日力学等分析力学表述

## 验收范围（主张 + 证据）

类型：【教学】= 本闭环要教会的；【确认】= 前置或可能已会的，有行为证据即可，不要求口头讲解。

1. 【复现】【确认】能用分离变量法求解一阶常微分方程，并代入初值。
   证据：给出 dy/dt = −c·y、y(0) = y₀（c > 0），学习者独立、无提示地写出分离变量和两边积分的过程，得到 y(t) = y₀·e^(−ct)，过程可见。

2. 【结构】【教学】能从 F = m·dv/dt 出发，为受线性阻力 F = −kv 的物体列出运动方程并求出 v(t)，同时说明为什么匀变速公式在此不适用。
   证据：题目为“质量 m 的物体以初速 v₀ 在光滑水平面上运动，只受阻力 −kv，求 v(t)”。学习者需独立、无提示地完成以下几步，过程可见：
   - 写出 m·dv/dt = −kv；
   - 分离变量并积分，得到 v(t) = v₀·e^(−kt/m)；
   - 在解答中自行写出一句理由：加速度随 v 变化、不是常量，所以 v = v₀ + at 等匀变速公式不能用。

3. 【近迁移】【教学】能把同样的方法用于受力组合不同的变式：重力加线性阻力的竖直下落，求终端速度和 v(t)。
   证据：题目为“质量 m 的物体从静止下落，受重力 mg 与阻力 −kv，求终端速度和 v(t)”。学习者需独立完成，过程可见：
   - 列出 m·dv/dt = mg − kv；
   - 由 dv/dt = 0 得到 v_T = mg/k；
   - 分离变量求得 v(t) = (mg/k)(1 − e^(−kt/m))；
   - 检查 t → ∞ 时 v → v_T。
