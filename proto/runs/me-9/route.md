## 闭环设计
- 学习目标：我想深入学习牛顿第二定律。
- 场景：scene.md
- 设计说明：学习目标是深入第二定律。me-6 暴露的核心误区是"F = d(mv)/dt 是牛二的原始形式"，正对应 M08 中的 K1–K21 混淆关系。me-8 已显示学习者掌握 K3/K2，路线偏差记录也建议抬高起点、直接进入 K20、K21，所以从 K3 出发，经 K20 走到 K21。P15（相对速度）在 me-7 中不牢，但本段推导全部用对地速度，不依赖它。因此把 (v − u) 作为相对速度的解释和参考系检验留到下一段，不在这里补前置。
- 下一闭环候选：
- P15 → K21（参考系检验）：先用一道题确认伽利略速度变换，再说明 (v − u) 是相对速度，所以方程在各惯性系中形式相同，而 d(Mv)/dt 依赖参考系（承接 me-6 原主张 2 ③、原主张 3 (b)(c)）。
- K21 → K23 → K25：火箭运动方程（也可由 K5 质心匀速推出），自由空间中 v_f = −u ln(M₀/M_f)，末速度与燃烧快慢无关；需要 P12，开头宜确认分离变量积分（me-5 的缺口）。
- K23 → K26、K27：重力场中燃烧越快越好，以及推力与比冲。
- K13 → K14 → K15：动量的分量守恒，以及相对速度须取分离瞬间的发射器速度（me-7 遗留，依赖 P15）。
- K17 → K28 → K29 → K30：粒子流对表面的平均力、动量输运速率 ρv²A，以及 F = Ṗ_in − Ṗ_out。
- K3 → K4 → K5 → K6：质心的定义、质心运动定理及其只描述平动的边界。
