## 验收范围（主张 + 证据）

类型：【教学】= 本闭环要教会的；【确认】= 前置或可能已会的，有行为证据即可，不要求口头讲解。

1. 【复现】【确认】能用分离变量法解一阶常微分方程，并用初始条件定出积分常数。
   证据：独立、过程可见地做对一道题：解 dy/dx = 2x(1 + y)，y(0) = 0，得 y = e^{x²} − 1。须写出三步：分离变量、两边积分并带常数、由初始条件定常数。

2. 【结构】【教学】能讲清"牛顿第二定律是关于 x(t) 的微分方程"这条逻辑链：力的函数形式决定怎样求解，初始条件确定唯一的运动。
   证据：无提示讲清以下要点（口头叙述，或推导加说明）：
   ① 动机。m·d²x/dt² = F(t, x, v) 是关于位置函数 x(t) 的二阶微分方程。力的函数形式是物理给出的输入，"求运动"就是解这个方程。F 为常数时积分两次，得到的就是高中匀变速公式。
   ② 唯一性的条件。确定具体运动需要两样东西：力的函数形式，以及 x(0)、v(0) 两个初始条件。需要两个初始条件，是因为方程是二阶的，每积分一次引入一个常数。少一个初始条件，只能得到一族运动；力相同而初态不同，运动也不同。
   ③ 按力依赖的变量选解法。
      - F 只含 t：直接对 t 积分。
      - F 只含 v：不能写 v = ∫F dt / m，因为 F(v(t)) 在 v(t) 求出之前是未知的时间函数。必须分离变量，写成 m·dv/F(v) = dt。
   ④ 边界：力的方向与符号。速度相关力的方向由速度决定，要看它的表达式能否自动随 v 变号。
      - −kv 在 v 取负时自动变号。
      - 大小为 kv² 的阻力必须写成 −k·v|v|，否则方程只在一个运动方向上成立。
   常见误解：
   - 力随速度变化时仍套用匀变速公式，把 a 当常数。
   - F 依赖 v 时直接写 ∫F dt 求速度（me-5 中学习者曾说"t v 直接积分没问题"）。
   - 只列初速度、初位置，漏掉"力的函数形式"这一必要输入。
   - 把 ma 当作一个额外的力画进受力图。

3. 【结构】【教学】能讲清 a = v·dv/dx 的来源、用途、适用条件，以及它与高中公式的关系。
   证据：无提示讲清以下要点（口头叙述，或推导加说明）：
   ① 来源：沿轨迹把 v 看成 x 的函数，由链式法则得 dv/dt = (dv/dx)(dx/dt) = v·dv/dx。这是等式变形，不是"配出来"的技巧。
   ② 用途：代入后方程变成 m·v·dv/dx = F，积分变量从 t 换成 x，时间被消去，直接得到速度与位移的关系。问题问的是距离或位置而不问时间时，或 F 只含 x 时，用这种方法。
   ③ 边界：v 必须能写成 x 的单值函数，即所考察的区间内运动单向、v 不经过 0。遇到折返点（如上抛的最高点），要在折返点处分段积分，不能一次积过去。
   ④ 依赖：a 为常数时，v·dv/dx = a 对 x 积分即得 v² − v₀² = 2aΔx。高中那个"不含时间的公式"正是它的特例。
   常见误解：
   - 认为 v·dv/dx 只是数学上凑出来的写法，说不出链式法则这一来源。
   - 以为它对往返运动也能一次积分到底。
   - 只说"把未知量变成了 v 和 x"，讲不出"换成对 x 积分、消去 t"。

4. 【近迁移】【教学】能对线性阻力建立带符号的运动方程，按所求量自选对 t 或对 x 积分，并用常力情形对照、定性论证来检验结果。
   证据：一道综合题，要求独立、无提示、过程可见。
   题目：质量为 m 的小船关闭动力后以初速 v₀ 在静水中滑行，水的阻力大小为 kv、方向与速度相反，其他水平力忽略。
   (a) 求速度降到 v₀/2 所用的时间 t₁。
   (b) 求这段时间内滑行的距离 s₁。
   (c) 另一条船质量同为 m、初速同为 v₀，受大小恒为 kv₀ 的阻力（等于第一条船的初始阻力）。用高中公式求它停下的时间和距离，并与 (a)(b) 比较。说明两船中哪一条在相同速度区间内滑得更远，并从两船受力大小的比较给出理由。
   (d) 第一条船要用无穷长时间才停下，滑行总距离却有限。说明这两者为什么不矛盾，再说明 k → 0 时 t₁、s₁ 的趋向与"无阻力匀速运动"是否一致。
   合格表现须同时满足：
   - 取定正方向，写出 m·dv/dt = −kv。
   - (a) 分离变量对 t 积分，写出上下限 v₀ → v₀/2，得 t₁ = (m/k)·ln 2。
   - (b) 主动改用 m·v·dv/dx = −kv 对 x 积分，而不是先解 x(t)。写出上下限，得 s₁ = mv₀/(2k)。
   - (c) 求出常力船停下的时间 m/k、距离 mv₀/(2k)，并指出：常力船在减速全程受的力都不小于第一条船，所以在相同速度区间内滑得更近或相等。数值上，常力船从 v₀ 减到 0 的距离，恰好等于第一条船从 v₀ 减到 v₀/2 的距离。
   - (d) 用"v 越小阻力越小、减速越慢，但 dx/dv = −m/k 为常数"一类的论证解释两者不矛盾；并指出 k → 0 时 t₁、s₁ 都趋于无穷，与匀速运动一致。
   - 全题不需要拆项积分，也不需要高阶展开求极限。
