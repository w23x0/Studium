你这个从公理出发的推导是对的：从标量层面的 0+0=0，配合数乘对标量加法的分配律，得到 0·w = 0·w+0·w，两边加上 0·w 的负向量，就推出 0 = 0·w。

有一处你直接跳过去了：从"0·w + 0·w + (-(0·w))"化简到剩下"0·w"这一步，其实还用了两条公理——把三项重新结合的方式（结合律），以及某个向量加上零向量还是它本身（零向量公理）。这两条你在过程里用到了，只是没点名，不是大问题，记下就行。
