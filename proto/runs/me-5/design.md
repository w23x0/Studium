【场景】
# 闭环：把牛顿第二定律当作微分方程来求解运动（以速度相关力为例）

阶段：大学物理·力学（大一水平，假定。学习者高中物理基础好、学过微积分，"深入学习"取大学力学的起点）
学习者已学过（前置）：
- 牛顿三定律、受力分析、力的正交分解（自述）
- 匀变速直线运动公式（自述）
- 一元微积分：导数、链式法则、不定积分与定积分、ln 与 e 指数的积分（自述）
- 用分离变量法解一阶常微分方程，并用初始条件定积分常数（假定）

学习者尚未学过（有限视角：不得用来解释）：
- 常微分方程的一般理论（解的存在唯一性定理、线性方程通解结构、二阶常系数方程的特征根法）
- 变质量系统与火箭方程
- 非惯性系与惯性力
- 拉格朗日力学、哈密顿力学
- 狭义相对论动量

## 验收范围（主张 + 证据）

类型：【教学】= 本闭环要教会的；【确认】= 前置或可能已会的，有行为证据即可，不要求口头讲解。

1. 【复现】【确认】能用分离变量法解一阶常微分方程，并用初始条件定出积分常数。
   证据：独立、过程可见地做对一道题：解 dy/dx = x·y²，y(0) = 1，得 y = 2/(2 − x²)。须写出分离变量、两边积分、由初始条件定常数这三步。

2. 【结构】【教学】能讲清"牛顿第二定律是关于 x(t) 的微分方程"这条逻辑链：由力的形式决定怎样求解，由初始条件确定唯一的运动。
   证据：无提示讲清以下要点（口头叙述，或推导加说明）：
   ① F = ma 写成 m·d²x/dt² = F(t, x, dx/dt)，是关于位置函数 x(t) 的二阶微分方程。高中的匀变速公式只是 F 为常数时把这个方程积分两次的特例。
   ② 求出具体运动需要两样东西：力的函数形式，以及两个初始条件 x(0)、v(0)。力相同而初态不同，运动也不同。积分常数正是由初始条件确定的。
   ③ 按力依赖的变量选解法：
      - F 只含 t：直接对 t 积分两次。
      - F 只含 v：写成 m·dv/dt = F(v)，分离变量得到 v(t)。
      - 需要 v 与 x 的关系，或 F 只含 x：改用 a = v·dv/dx，对 x 积分。
   ④ a = v·dv/dx 来自链式法则 dv/dt = (dv/dx)(dx/dt)。用它换成对 x 积分，即可消去时间，得到速度与位移的关系。
   常见误解：
   - 力随速度变化时仍套用匀变速公式，把 a 当常数。
   - 把 ma 当作一个额外的力画进受力图。
   - 以为 F 依赖 v 时也能直接写 ∫F dt 求出速度。
   - 省略积分常数，或忽略初始条件的作用。
   - 速度相关力的方向不随速度方向取号，导致方程符号出错。

3. 【近迁移】【教学】能对速度相关的阻力建立并求解运动方程，求出时间与位移两类量，并用极限检验结果。
   证据：一道综合题，要求独立、无提示、过程可见：
   质量为 m 的小球以初速 v₀ 竖直上抛，空气阻力大小为 kv、方向与速度相反。求：
   (a) 上升到最高点所用时间 t₁；
   (b) 最大高度 H；
   (c) 说明 k → 0 时两结果分别趋于什么，并与高中结论对照。
   合格表现须同时满足：
   - 正确写出带符号的方程 m·dv/dt = −mg − kv；
   - (a) 用分离变量对 t 求解；
   - (b) 主动改用 v·dv/dx 对 x 求解，而不是先解出 x(t) 再求极值；
   - (c) 用 ln(1+u) 的展开取极限，得到 v₀/g 与 v₀²/(2g)。
   参考答案：t₁ = (m/k)·ln(1 + kv₀/(mg))，H = mv₀/k − (m²g/k²)·ln(1 + kv₀/(mg))。

【设计说明】
学习者是冷启动，目标"深入学习牛顿第二定律"范围笼统。本闭环因此只取最先该学、最能用上其微积分基础的一块：把第二定律当作微分方程求解，并以速度相关力作载体。深度按"基础好、学过微积分"的自述定在大学力学。"会分离变量法解一阶常微分方程"是假定的前置，且本闭环离不开它，所以设为第 1 条【确认】。

【下一闭环候选】
1. 位置相关力 F(x)：由 v·dv/dx 导出功–动能定理与势能，并求解一维弹簧振动（简谐运动微分方程）。
2. 二次阻力 kv² 与终端速度，上抛运动中上升与下落时间的比较。
3. 二维情形：矢量形式的第二定律，带阻力的抛体运动与各分量方程的耦合。
4. F = dp/dt 与 F = ma 的区别：变质量系统与火箭方程。
5. 第二定律的适用范围：惯性系与非惯性系（惯性力），以及与第一定律的逻辑关系。
