**背景**：竖直上抛、阻力 kv 的题，你已经算出了
- t₁ = (m/k)·ln(1 + kv₀/(mg))
- H = mv₀/k − (m²g/k²)·ln(1 + kv₀/(mg))（补上了系数 m。单位检查：mv₀/k 是 kg·(m/s)/(kg/s) = m，对得上）

现在要做 (c)：k → 0 时两者各趋于什么，是否回到高中结论。

**用 u 替换**

令 u = kv₀/(mg)，也就是 k = mgu/v₀。代进去后各项分别是：
- m/k = v₀/(g·u)
- mv₀/k = v₀²/(g·u)
- m²g/k² = v₀²/(g·u²)

于是

  t₁ = (v₀/g) · [ ln(1+u) / u ]

  H = (v₀²/g) · [ (u − ln(1+u)) / u² ]

k → 0 就是 u → 0，两个方括号都是 0/0 型。

**轮到你（简短回复即可，不用抄上面的式子）：**
用洛必达（或泰勒展开）分别求：
- ln(1+u)/u 当 u → 0 时的极限
- (u − ln(1+u))/u² 当 u → 0 时的极限

每个写出结果，再加一句怎么得到的，比如"洛必达一次，得到……"。然后说一句：乘上前面的 v₀/g 和 v₀²/g 以后，是否分别对上了高中的 v₀/g 和 v₀²/(2g)。
