两个方向都完整、正确，依据也标清楚了：

- **⇐ 方向**：你先证 ker T ⊆ {0}（由 T(x) = T(0) 和单射得到 x = 0），又用"0 ∈ ker T"补上另一边的包含。证明集合相等要两边都写，你没有漏掉后一半。
- **⇒ 方向**：从单射的定义"设 T(u) = T(v)，推出 u = v"出发，用 T(u) = T(v) ⇒ T(u−v) = 0 把问题转到 ker T 上，再用 ker T = {0} 得到结论。这里用的是那个等价关系中从左到右的方向。

把前面证过的结论当作引理，直接组织成新的证明，这样写是可以的。
