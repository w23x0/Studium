你对第 1 步的疑问是对的，**T(0) = 0 需要证明**。原因是线性变换的定义里只有两条：

- T(u + v) = T(u) + T(v)
- T(cu) = cT(u)

定义里并没有直接写"T(0) = 0"。它是从这两条推出来的结论，所以在证明里不能当作已知直接用。

可以对比一下非线性的函数 g(x) = x + 1，它的 g(0) = 1 ≠ 0。所以"零映到零"不是所有函数都有的性质，而是线性带来的。

还有一个细节：T(0) = 0 左边的 0 是 V 里的零向量，右边的 0 是 W 里的零向量，两者不一定是同一个东西。
