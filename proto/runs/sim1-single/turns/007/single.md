三问都对，反例也给得具体：(1,0) 和 (0,1) 都在 Z 里，它们的和 (1,1) 不在 Z 里。你把问题定位到了"加法封闭"这一步，也说清了它对应 ker T 证明里用加法保持的那一步。

有一处可以写得更严格。第 2 问检查数乘时，你只验证了 (1,0) 这一个点，而封闭性要对 Z 里**任意**一点成立。一般的写法是：若 xy = 0，则 f(cx, cy) = (cx)(cy) = c²·xy = 0。所以 f 虽然不满足数乘保持（它多出来的是 c²，不是 c），零点集在数乘这一步却碰巧封闭。这说明 f 不是线性的，并不意味着三步都会失败。要看的是具体哪一步用到的性质缺了。

**下一步，请你独立写一个证明：**

设 T: V → W 是线性变换。证明：

> ker T = {0} ⇔ T 是单射。

两个方向都尽量写。如果只能完整写出一个方向，就先把那个方向写完整。每一步注明依据。

写到哪一步就发到哪一步。

【练习条件】
任务：独立证明"ker T = {0} ⇔ T 单射"。
完成条件：至少一个方向论证完整，最好两个方向都有。
- (⇐) 方向：设 T 单射。由 T(0) = 0 可知 0 ∈ ker T；若 T(x) = 0 = T(0)，由单射得 x = 0。
- (⇒) 方向：设 ker T = {0}。若 T(u) = T(v)，则 T(u−v) = T(u) − T(v) = 0，所以 u − v ∈ ker T，u − v = 0，u = v。
- 依据要标出，包括 T(0) = 0 和 T(u−v) = T(u) − T(v) 的来源。

独立程度：完全独立，本轮不给提示。卡住时先问学习者卡在哪个方向、哪一步，再考虑提示"单射的定义是 T(u)=T(v) ⇒ u=v"。
验证意图：对应主张 3。要求无提示给出"核只含零 ⇔ 单射"的论证，检验学习者能否把前面分步得到的结论（T(u)=T(v) ⇔ T(u−v)=0，以及 T(0)=0）自己组织成一个完整证明，而不是在引导下逐问作答。
