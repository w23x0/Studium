三问都答对了，而且第 3 问找得很准：

- 你从两边核对了问题。一边是结论不成立：f(2) = f(−2)，但 f(4) = 16 ≠ 0。另一边是原因：推导中“拆开”那一步用的是 f(u + w) = f(u) + f(w)，而 f(2 + (−2)) = 0，f(2) + f(−2) = 8，这条性质对 f 不成立。
- 所以你刚才用到的“换个问法”（两个不同输入是否给出同一输出 ⇔ 零点集里是否有非零向量）**不是对任何函数都成立**。它依赖“两个输出之差 = 两个输入之差的输出”，而这一点正是由线性保证的。

到这里，我们已经知道 ker T 能回答什么问题。接下来看它本身是什么样的集合。

**请你证明：若 T: V → W 是线性变换，则 ker T = {x ∈ V : T(x) = 0} 是 V 的子空间。**

按子空间的判定，分三步写：
1. 零向量在 ker T 里；
2. ker T 对加法封闭；
3. ker T 对数乘封闭。

每一步都注明用到了线性定义里的哪一条。如果某一步看起来“显然”，也请把理由写出来。

写到哪一步就发到哪一步。

【练习条件】
任务：独立证明 ker T 是定义域 V 的子空间，要写出三步：零向量属于 ker T、加法封闭、数乘封闭。
完成条件：三步都有。第 1 步要推出 T(0) = 0，不能直接当作已知；可以用数乘保持，例如 T(0) = T(0·v) = 0·T(v) = 0，或用加法保持得到 T(0) = T(0+0) = T(0)+T(0)。第 2 步用加法保持得到 T(u+v) = 0 + 0 = 0。第 3 步用数乘保持得到 T(cu) = c·0 = 0。每一步都要标明用了哪条性质。
独立程度：完全独立，不给提示。学习者如果在第 1 步直接写“T(0) = 0”，只追问一句“这一步为什么成立？用了哪条性质？”；如果仍然卡住，再提示“0 可以写成 0·v”。
验证意图：对应主张 2（独立复现核是子空间的证明，三步不缺，每步对应到线性性质）。之后可以用非线性的例子，比如 f(x, y) = xy，它的零点集不是子空间，来补足主张 1 中“不是线性时，这个集合还有没有这些好性质”在子空间这一面的检验。
