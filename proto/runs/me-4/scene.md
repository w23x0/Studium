## 验收范围（主张 + 证据）

类型：【教学】= 本闭环要教会的；【确认】= 前置或可能已会的，有行为证据即可，不要求口头讲解。

1. 【复现】【确认】会求解一阶可分离变量微分方程，并能用初始条件确定常数。
   证据：独立、过程可见地做对一道题：已知 dv/dt = −(k/m)v，v(0) = v₀，求 v(t)。分离变量、积分、代入初始条件的步骤都要写出，结果为 v = v₀e^(−kt/m)。

2. 【结构】【教学】能讲清牛顿第二定律作为运动微分方程的逻辑结构，以及按力的类型选择求解形式。
   证据：无提示讲清以下要点：
   ① m·d²x/dt² = F 是关于位置 x(t) 的二阶微分方程。F 是该时刻的合力，只对应该时刻的加速度，可以依赖 t、x、v。
   ② 只知道力还不能确定运动，必须再给初始位置和初始速度，两者合起来才唯一确定 x(t)。
   ③ 恒力是特例：直接对方程积分两次，就能得到高中的 v = v₀ + at 和 x = x₀ + v₀t + ½at²。因此这些公式只在合力恒定时成立。
   ④ 按力依赖的变量选写法：
   - F(t)：直接对 t 积分；
   - F(v) 且要求 v–t 关系：写成 m·dv/dt = F(v)，再分离变量；
   - F(x)，或需要 v–x 关系：用 a = v·dv/dx（由链式法则得来）化成对 x 的方程。
   
   讲解可以是口述，也可以是推导加说明。
   常见误解：
   - 变力情况下仍套用匀变速公式；
   - 认为速度方向总与合力方向相同；
   - 写 a = v·dv/dx 时说不出它来自链式法则 dv/dt = (dv/dx)(dx/dt)，或误写成 a = dv/dx；
   - 认为只要知道受力就能确定运动，忽略初始条件。

3. 【近迁移】【教学】能对速度相关的变力，由受力写出运动方程，选择合适的形式求解，并用极限检验结果。
   证据：独立、过程可见地完成一道综合题。
   
   题目：质量为 m 的小球以初速 v₀ 竖直上抛，所受空气阻力 f = kv，方向与速度相反。
   - (a) 求上升到最高点所用的时间 T；
   - (b) 求最大高度 H；
   - (c) 验证 k → 0 时结果退回无阻力情形。
   
   判定条件：
   - 上升阶段阻力方向写对（与重力同向）；
   - (a) 用 dv/dt 形式；
   - (b) 用 v·dv/dx 形式，或对 v(t) 再积分；
   - (c) 过程可见，展开对数后得到 v₀/g 与 v₀²/(2g)。
   
   参考答案：
   - T = (m/k)·ln(1 + kv₀/(mg))
   - H = (m/k)·v₀ − (m²g/k²)·ln(1 + kv₀/(mg))
