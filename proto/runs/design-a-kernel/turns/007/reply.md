你问的这个问题很好，答案是：**不是碰巧，它们在矩阵情形下就是同一个集合。**

"零空间"通常是对**矩阵**说的：矩阵 A 的零空间就是 Ax=0 的全部解，也就是 { x | Ax = 0 }。
"核"是对**线性变换**说的：ker T = { v ∈ V | T(v) = 0_W }。

当 T(x) = Ax 时，把核的定义展开：
ker T = { x | T(x) = 0 } = { x | Ax = 0 } = A 的零空间。

所以你今天第二部分"求 ker T 就是解 Ax=0"，套路一模一样是理所当然的，因为它们根本就是同一个东西。两个名字的区别只在于说的对象不同。核的定义只要求 T 是线性变换，不要求 T 写成矩阵乘法的形式。你今天的证明就是在这种一般情形下做的，只用到可加性和齐次性。顺带一提：放到矩阵上，那个证明说的就是"Ax=0 的全部解构成一个子空间"。
