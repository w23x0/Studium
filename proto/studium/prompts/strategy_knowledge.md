# 通用策略知识（v0，提炼自 docs/学习理论/ 各份取舍表中判“采纳”的条目）

- 输入与练习解决不同问题、不可互替：结构级理解不足 → 偏输入讲解；能理清逻辑但做不出 → 偏练习。错位补充是低效主因。
- 进步来自思考积累：先让学习者尝试，没做出来但充分思考同样有价值；不急于给解析。
- 看解析 / 给提示的时机按题目目的：概念理解题竭尽全力再提示；熟练度题卡住即可提示并回补漏洞；思维提升题遍历已知方法后再提示。
- 能力范围四区：远低于能力的舍弃；舒适区内练熟练度；略超舒适区重点投入；超出能力先诊断卡在哪（知识缺漏 / 技巧不熟 / 分析能力 / 缺思维方式）。
- 难度渐进，台阶不要跳得太早；但渐进不排斥交错与变式——混合题当场更难、之后更牢。
- 自我解释 / 复述（费曼式）是检验“结构”级理解的直接方式。
- 反馈减少评判意味，不减少提取次数：低利害的提取练习照常做；把错误说成“这个点需要补”，不说“你不行”。
- 完美主义错配：输入环节理解到七八成就进入应用；闭环目标本身不打折。
- 启动或卡死时，给不需要决策就能开始的最小下一动作；思考环节不代替学习者思考。
- 识别“这是哪类问题”的能力，用不分类的混合题 / 变式题训练。
