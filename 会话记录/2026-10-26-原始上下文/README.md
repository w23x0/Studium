## 谈定的方向（未定稿，定稿时要改的设计在右列）

| # | 方向 | 定稿时要改 |
| --- | --- | --- |
| 1 | 身份只分两类：学习者（说的话 + 在页面上真动手的操作）；主模型派出的子代理交回的结果。开场就是起点。不要统一的“程序事实”标记 | `学习对话.md` 收件箱行、§11 动作行；原型 `prompts/loop.md` |
| 2 | 按时间线：每条带时间，按发生顺序接在后面，后者压过前者。离开多久不设门槛；可提示模型大致估学习者要花多久、掌控节奏，不另做分析、统计、记录 | `01-流程.md` 暂停行；`学习对话.md` 暂停行 |
| 3 | 只记观测得到的：真操作、打字、说话；去掉“看得到哪几块、停留多久” | `学习对话.md` §11 动作行（10-26 定稿） |
| 4 | 页面不出现选择题、“我懂了”这类低信息量按钮 | `学习对话.md` §11 动作行的例子 |
| 5 | 页面上的文字（含分析）由主模型写；子代理管位置、样子、交互；子代理做的（函数图、代码等）交回时说一句做了什么，主模型要细节自己调工具查 | `会话/页面编辑员.md` 分工；§11“主对话只看目录” |
| 6 | 主模型上下文里不出现块编号、版本号；过没过时由程序核对 | `学习对话.md` §11 版本行；`页面编辑员.md` |
| 7 | 页面编辑员改为 Agent SDK 自带的子代理，叫“子代理”；我们只做外围（能写哪些文件、交时检查、浏览器试跑） | `页面编辑员.md`；`01-流程.md` 会话表 |
| 8 | 退回保留但简化：页面回到那一版，时间线上接一条学习者的动作与原因；不截上下文、不让主模型写教训 | `学习对话.md` 上下文行、§11 退回行（10-26 定稿） |

## 原型与设计的差距（改原型时照做）

| # | 差距 | 在哪 |
| --- | --- | --- |

| 2 | 页面编辑员是自开的另一个会话，结果由程序转述 | `page/editor.ts` |
