产品负责人 2026-09-28（me-8 失败后）：“最小实验的问题就在于无论怎么实验都是错误的，不如直接去把最小基础给做好”；“你没有把握就别继续修修改改了”；提示词里限制模型的规则“少写还不够”。

**Why:** v0 原型把每次试用的问题都补成提示词规则（确认先考、非复述取证、话要短、先自查……），合起来让单次教学不如通用对话模型、也不如教材；根子是模型手里没有教材、没法按需查。

**How to apply:** 遇到教学质量问题，先查地基（模型能不能读到原文 / 结构 / 历史），再考虑规则；提示词只写闭环定义、底线、输出格式；拿不准的改动先别做，先和产品负责人对齐方向。检验标准：单次不明显差于“通用模型 + 同一教材”，跨闭环明显更好。相关：[[feedback-own-judgment-and-validation]]、[[feedback-experiments-only-when-needed]]
