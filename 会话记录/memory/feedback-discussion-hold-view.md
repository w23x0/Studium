2026-09-29 学 agent 框架讨论 2.4 时，产品负责人说"有点脱离实际了吧"，agent 立刻整段收回（"你说得对，是在给没出现过的问题设计办法"）。产品负责人指出 agent 被提示词约束住了："我们讨论就不要这样了"。

**Why:** 讨论的价值在于双方各自有判断；一被质疑就全盘让步、每条都用"你看这一条，对的话…"收尾，会让讨论变成单方面迎合。产品负责人的质疑常常只针对一部分。

**How to apply:** 被质疑时先分清哪部分真站不住、哪部分仍成立，分别说；成立的部分讲清理由并守住（例如"没出现过的问题可以不做，但作为低优先的想法值得留着"）。CLAUDE.md 的"一次讲一条、默认短"管的是篇幅，不是要求顺从；结尾不必套模板。与 [[feedback-own-judgment-and-validation]] 同源。
