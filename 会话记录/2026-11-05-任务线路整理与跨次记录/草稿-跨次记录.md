# 草稿：跨次记录（#83）

> 状态：**草稿，未定稿**（2026-11-05 agent 写）。依据：本会话谈定的三条（事实由学习对话当场记、判断不存用时读原文；普通文件 + 短索引、不用专有记忆工具；不做界面、改由主对话代改）+ `docs/调研/跨会话记忆格式-发现.md`。逐节和产品负责人过，过完的才进 `docs/设计/`。名字“跨次记录”是 agent 临时起的，可改。

## 1 一句话

学习对话（及主对话）在学的当场记下的几样**事实**，一行一条、带日期、带指回原文的行号；每个对话开场由程序放进上下文。判断（会了什么、连上了什么、下一段走哪）不记，读的一方按指针读原文现场下。

## 2 记什么

| 类 | 例子 | 只留最新还是追加 | 对应外部做法 |
| --- | --- | --- | --- |
| 学到哪 | “STM32 定时器：讲完预分频与自动重装值，144 拍在哪段时间里数刚接上，计数模式没讲” | 追加；读的一方看最新一条（不另造“当前视图”，`00` §4） | Claude auto memory 的 project 类；Codex 任务历史 |
| 没学完的 | “中断优先级开了个头，学习者说下次再说” | 追加；接上了另记一条“已接上”，指向原条 | 同上 |
| 纠正与确认有效的做法 | “不手写代码，能看懂就行”（学习者原话）；“先给定义、不用比喻”被学习者确认有用 | 追加；改主意时新条标明替换哪条 | Claude feedback 类；Fable 5 “Record corrections and confirmed approaches alike” |

不记：知识本身（`00`：知识交给模型）；对学习者的判断（会了 / 没学牢 / 水平）；原文里已有、又不是上面三类的内容。

## 3 一条长什么样

| 字段 | 内容 |
| --- | --- |
| 日期 | 写入时刻（程序填） |
| 类 | 学到哪 / 没学完 / 纠正与做法 |
| 一句话 | 学到哪、没学完：写这次的边界与停在哪；纠正与做法：**照学习者原话**，后加当时在说什么（防 Codex 警告的过度推广：一道题里的话不写成长期偏好） |
| 指针 | 原文行号（`00` §4「证据引用按行号」，程序核对） |
| 替换 | 可空；填被替换那条的编号 |
| 范围 | 项目 / 学习者（见 §4） |

## 4 放在哪

| 层 | 放什么 | 谁读 |
| --- | --- | --- |
| 项目一层 | 默认都放这里 | 这个项目的所有对话 |
| 学习者一层 | 只有学习者明说“以后都这样 / 不管学什么”的纠正与做法 | 所有项目的所有对话 |

存成普通文件，模型用普通读写工具（调研 §0 第 2 条：两家收敛到索引 + 普通文件）。

## 5 谁写、什么时候

| 谁 | 写什么 | 何时 |
| --- | --- | --- |
| 学习对话 | 三类都写 | **空着，等 STM32 学完读原文再填**（候选：接上一块时、学习者说出长期的话时、学习者离开前、收尾时）；“模型不一定记”的风险靠程序在固定时机提醒，不靠提示词一句话（调研 §3.1） |
| 主对话 | 纠正与做法（学习者在主对话里说的） | 同上 |
| 谈方向 | 不写：谈定的存成方向（`记录/方向目标.md`） | — |

与收尾那一句：学完时学习对话写的“学到哪”就是收尾那一句，不另出一份（`00` §4“不出第二份说法”）。

## 6 谁读、怎么读

| 项 | 内容 |
| --- | --- |
| 开场 | 程序把本项目 + 学习者一层的条目按日期放进开场上下文，不靠模型自己去翻（调研 §3.1：不读是最多人反映的问题） |
| 要判断时 | 按指针读原文（`00` §4 读法） |
| 冲突 | 新条替换旧条；与学习者当场说的冲突时，以当场说的为准（同项目说明） |

## 7 改与删

不做界面。学习者在主对话说“那条不对 / 忘掉”，主对话写一条替换或删除；写后在对话里说一句改了什么。

## 8 上限

现在不设计（几个月到不了）。只定一条：**不让模型自己压缩索引**（调研 §3.1 #91188：压缩会删掉要紧内容）。触发：开场放进去的条目超过约 1 万 token 时再谈，记任务线路。

## 9 和现有设计的冲突（要产品负责人当场明确）

| 现有 | 来历 | 冲突 |
| --- | --- | --- |
| `记录/项目说明.md`「不做」：模型自己写的自由记忆 | 定稿 10-23 | 理由是“走到哪了已存成几种确定的记录（方向目标、学过的记录、单子与路线、状态记录），再加一份会打架”；单子与路线、状态记录已随 W12 撤（试验中），理由的前提没了。跨次记录也不是“随手记”：限三类、带指针 |
