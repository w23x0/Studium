## 只读区现在的样子

物理目录 `<数据>/sandbox/<学习 id>/只读/` 的摆法 = 模型看到的 `只读/…`；工作区里放一个 `只读` 链接指向它（当前目录下 `ls 只读/` 就能用）。

| 位置                                             | 内容                                                                                                                                             |
| ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| `说明.md`                                        | 每一项是什么 + 对话原文格式一句（每条 `L行号 谁（年-月-日 时:分）：` 开头，续行缩进 6 格，`grep '学习者（'` 只看原话）；和开场附的沙盒说明同一份 |
| `本次对话.md`                                    | 本次原文                                                                                                                                         |
| `学过的记录/<项目名>/<学习 id>-<标题>.md`        | 一次学习一个文件：头（项目、状态、开始、最后活动、结束、收尾那一句、组件在哪；旧数据另有单子、路线决定、判定）+ 整份原文                         |
| `学过的记录/<项目名>/<学习 id>-组件/<名字>.html` | 那次每个组件的最新一版（来源 `component_version` 的清单 → `screens/<学习 id>/块/`）                                                              |
| `学过的记录/索引.md`                             | 按项目分组，本项目在最后；组内按开始时间、旧的在上；每行：文件、状态、开始、最后活动（距今几分钟 / 小时 / 天），下一行收尾那一句                 |
| `学过的记录/外部导入.md` `外部导入/`             | 同前，说明压成一段                                                                                                                               |
| `主对话.md`                                      | 本项目主对话原文（主对话的话写作“主对话”）                                                                                                       |
| `谈方向/<会话 id>-<标题>.md`                     | 本项目每次谈方向一个文件（头 + 原文）                                                                                                            |
| `跨次记录.md` `项目说明.md` `方向.md`            | 同前                                                                                                                                             |
| `资料/目录.md`、`资料/<资料 id>`                 | 目录 + 指向正文目录的链接（原来目录在 `只读/资料目录.md`、正文在别处，说明却写 `只读/资料/目录.md`）                                             |
| `附图/` `教学工具/`                              | 同前                                                                                                                                             |

## 真用时看什么

1. 模型第一条命令还会不会因为路径失败；`ls 只读/` 后是不是一眼明白。
2. 要上次的图时有没有去 `<id>-组件/` 拿，而不是重画。
3. 有没有用 `grep '学习者（'` 一类自己筛；开场读进去多少 token。
4. 链接在 Linux 沙盒（bubblewrap）里能不能顺着读到资料正文：正文目录已在放开读的名单里，按理能读；读不到就报给 agent。
