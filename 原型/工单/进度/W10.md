## 4.2 说给框架的口 + 框架小模型

| 改           | 做法                                                                                                                                                                                                                                                                                                                        |
| ------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 主模型的工具 | `arrange_screen`（`studium.ts`）：`parts`（每块开头几个字 + 一句指向，可拆，§9 第 3 条）· `about`（不拆时）· `bring_back`（极简短描述）· `layout`（平常话说放哪）；回一句“记下了”，不显示给学习者                                                                                                                           |
| 摆屏         | `hub.ts` 的 `KindConfig.afterTurn`：每轮（含模型自己起的一轮）输出完、下一轮开始前调；新 `core/page/screens.ts`：把这轮的话按 `parts` 切块、这轮派出的子代理记成占位，候选旧块 = 主模型写过的块、学习者的话、子代理交回、组件（最新版）、还在做的活（§9 第 10 条），只给“时间 + 一句话”（§9 第 11 条）；存清单、记 `screen` |
| 不调小模型   | 这轮没点名、没说放法时，新块照顺序一块一行，不调小模型（`screen` 不带 `ms`）                                                                                                                                                                                                                                                |
| 对不上       | 小模型给 null、回答读不出、出错：不猜，记 `screen_note`，下一轮按时间接在线后面（`preface`）                                                                                                                                                                                                                                |
| 小模型       | 新 `prompts/arrange.md`；`app.ts` 的 `frameworkCall`：不给工具、`ephemeral`（不留会话文件）、按 `profiles.framework`（默认 `claude-haiku-5-5`）；`port.ts` 加 `ConversationSpec.profile` `ephemeral`                                                                                                                        |
| 新旧学习     | 新开的学习 `session_opened.screens: true`；旧的（没有这一项）学习者再说话、申请收口、确认都回“这次学习是旧版开的，只能看；要接着学，请回项目另开一次”（§9 第 1 条），“搁着”照旧可点                                                                                                                                         |
| 回在某块下   | `user_message.replyTo` 经 `POST …/messages` 的 `replyTo` 传进来；交给主模型时写“（回在「那块的一句话」下面）”                                                                                                                                                                                                               |

看一眼（真模型，一次学习 4 轮：开场 + 学习者 3 句，第 3 句要“把一开始那个问题再放出来”）：

- 每轮都调了 `arrange_screen`；第 4 轮点名“开场那道 2cm 与 4cm 周期预测题”“上一轮讲两效应相抵与整体放大 2 倍的那段”，**两条都对上了**，小模型 5.6 秒。
- **发现问题**：这一版提示词让主模型“写完再调”。结果第 1 轮的那道预测题没到正本——工具调用之前写的话被放进了思考块，没交回（正是实现选型「实现时要守的」那条）；屏幕上只剩调用后补的一句“这一轮先停在这道预测题上”。之后几轮，调完工具它又补写一段转述，屏幕上重复。→ 改成“每轮先调 `arrange_screen`（读文件、派子代理也先做），最后一口气写给学习者的话”（工具说明在本步，`loop.md` 在 4.3）。
- 多等了多久：只有调小模型的那轮多 5.6 秒；其余轮不调。

对得准不准（工单要先看 10 轮左右）：两次看一眼合计 5 次点名，5 次都对到了对的块；没碰到对不上的。轮数不到 10，**没量够**，留给产品负责人真用时看（每次耗时随 `screen.ms` 记着）。
