## 4.4 子代理只做组件

| 改             | 做法                                                                                                                                                                                                                                                                                                     |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 对象           | `core/page/agent.ts` 重写成 `Components`：子代理名 `component`；每个组件一个文件夹 `工作区/组件/<c1…>/`（每块一个 `.html` + `目录.md`），`组件/目录.md` 列全部组件（文件夹 \| 一句话）；新做的就新建文件夹，交上后框架发编号（c1、c2…，块 b1、b2…）并照新版重摊                                          |

| 学习者动了组件 | 4.0 第一件做不到，按 §9 第 4 条退路：`onAction` 另开一次子代理（`profile: subagent`、不留会话文件、工作区就是 `组件/`、不给命令），带组件当前版、当初的交代（`subagent_started.brief`）、这次的操作；它自己改就交，往上报调 `report_to_main`；它的沙盒动作照记进正本（`task = maker-…`）。用在 4.5       |
