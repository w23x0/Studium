## 判断（agent 自定，可直接改）

| 项                           | 说明                                                                                                                         |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| 名字不改，仍叫学习对话       | 方向本来就是学习里的事（“这件事本来在任何会话里都能谈”）；改名会牵动种类名、界面、只读区目录、旧数据，眼下用不上             |
| 「方向」放在「学习者的话」后 | 放「开始之前」后面容易被读成开场的一步；工单说不是开场固定动作                                                               |
| 主对话不主动引导             | 工单写主对话“自己能简单聊，要搜就开讨论串”；主动引导写在学习对话里                                                           |
| 不加“谈方向时不讲课”         | `talk.md` 有“这里不讲新知识、不出题”；学习对话里谈方向和学是一回事，加这句是为一个没发生的现象加规则；工单列在“真用时看什么” |
| 旧谈方向在派生索引算已结束   | 只读的对话显示“进行中 / 等你”会误导；旧的谈方向重开过（`thread_reopened`）也不再变回进行中                                   |
| 只读改成“只有学习对话能发话” | `threadOf(live)` 原来只挡旧版学习对话，旧的找资料也能被发话（提示词已删，会空跑）；一并挡掉                                  |
| 长期的话例子                 | “我不想选 因为我现在什么都不知道”是 L91 原话的前半；“学完想自己做一块电源板”是编的示例（电源设计那次的原话云端读不到）       |
| 外部导入渠道“畅谈”留着       | 旧的 `imports.jsonl` 里有，界面与只读区照旧显示；不再写新的                                                                  |

## 没做

检索机制（#89）；方向文档的替代品；到点提醒；项目开场固定引导（工单「不做」）。`ticket`、`resumeOf` 这类没人传的 `createSession` 参数、`find` 在外发披露名单里，属 W19 的“没人调用的一并删”，没动。

## 真用时看什么

1. 长期的话还漏不漏（像 L91 那种抱怨、想拿它做什么），有没有凑数乱记、text 里带不带模型的引申。
2. 学习对话会不会主动谈方向，时机合不合适（STM32 那样一上来脚踏实地学的，它会不会硬插）。
3. 一聊方向会不会变成讲课。
4. 搜到的质量。
5. 有没有因为没有方向文档而跑偏（三个旧项目照旧能读到旧方向；新项目只靠跨次记录和原文）。
6. 学习者在项目对话里说“带我了解了解”时，主对话是自己聊还是开学习对话，开出去的学习对话是谈方向还是直接开讲。
