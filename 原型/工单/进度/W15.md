## 做了什么

| 项                       | 改动                                                                                                                                                                                                                                                   |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `loop.md`「一次学习」    | 定义补回 `00` §2 的出发点与新点：从已会的几个点出发，沿出发点接到新点的那条路把新点接上；出发点不同，学到的理解不同                                                                                                                                    |
| `loop.md`「开始之前」    | 按工单草稿写：附了什么；以前的对话没有替你定下一步；学习者每个时刻会的不一样；第一步先读记录、再判断这一次（组合不出来，缺的那块就是这一次），由此定边界；他说了从他说的出发，没说就定下来直接开始、不列选项，判断不说给他                             |
| `loop.md`「收尾」        | 没动：读完清单就提收尾的根因是没有自己定新点、只照“逐行读完”走，「开始之前」改了这一层；不加针对单个现象的规则                                                                                                                                         |
| `project.md`「分工」     | 主对话：传需求、读过收尾知道大概能学什么、判断不了组合，所以不定这一次；学习对话：这一次学什么——说了从他说的出发，没说自己读记录判断；原“下一次学什么由学习者提；方向谈定之前谁都不替他定”拆成“什么时候开始学由学习者决定；长期往哪走不替他定，和他谈” |
| `project.md`「跨次记录」 | 学到哪去掉“留下没讲的”，改成“从哪出发、学了什么、停在哪，学习者说下次再说的”（理由见下）                                                                                                                                                               |
| `main.md`                | 学习者说了话：加“要开始学、没说学什么：照样开学习对话，交代里不替它想怎么开场”“问接下来能学什么：按各次收尾说个大概，具体组合由学习对话判断”；讨论串的动静里“下一次学什么由学习者来提”改成“什么时候开始下一次由学习者定”                               |
| 模型                     | `src/core/model/profiles.ts`：`loop: { model: 'opus', effort: 'high' }`（`STUDIUM_PROFILES` 里配 `{"loop":{"effort":"max"}}` 仍叠加在这上面，模型照旧 Opus）                                                                                           |
| 跟着改                   | `../../提示词记录.md`、`../../更新记录.md`、`../README.md`                                                                                                                                                                                             |

## 真用时看什么

1. 学习者只说“开始今天的学习”时，学习对话有没有先读记录、直接开始一块（不列选项）；开的这块是不是从稳的点组合出来的。
2. 学习者说了想学什么时，有没有从他说的出发。
3. 第一步读了多少（上下文起步多大，输入框下方的数）。
