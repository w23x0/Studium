## 和工单不同的地方

| 不同                                                                                       | 理由                                                                      |
| ------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------- |
| 从别的项目拿：`origin` 照抄原来的，来源项目与资料 id 记在新字段 `copiedFrom`               | `origin` 是重试时重新处理用的真来源；改成“来源项目”会让重试失效           |
| 多一种记录 `find_candidates`（程序核过的候选清单）                                         | 界面要从正本读出一份核过的清单来勾；`candidates_picked.forLine` 指它      |
| W8 的网页抓取：返回的是 PDF 时存原件、照新 PDF 走 MinerU；抓不到时报一句人话               | 找资料交回的讲义多是 PDF 网址，按网页转会是乱码。没改存法与别的转换       |
| W8 的 Materials 加了 `retry` `copy` 两个方法                                               | §4.4 重试、§4.1 从别的项目拿要用；存法不变                                |
| 扩展名定得了的（pdf、字幕、代码、转不了的）`upload_routed.by` 记 `model`，理由写“按扩展名” | 记录类型照工单只有 `model` / `learner` 两种；理由里写清是程序按扩展名定的 |
| `notes.ts` 只留读旧笔记（列表、图片）；书库里旧笔记照旧能浏览                              | 旧数据里已导入的笔记还会被引用，删了读不到                                |
| 旧的 `{ note }` 外部导入指针不再列出（数据没删）                                           | 工单要删旧形状；读到时跳过                                                |
| “我导入的学过的”只列本项目导入的（`Import.project`）；学过的记录本身仍按人不按项目         | 项目页只摊本项目的；导航、学习对话照旧读全部                              |

## 拿不准的

- 分流的模型调用借用主对话的模型配置（低强度）；没单独占一个会话种类。
- 浏览器拖文件夹靠 `webkitGetAsEntry`，Chrome / Edge / Safari 都有；“添加 → 文件夹”用 `webkitdirectory`。
- 云端环境网络白名单不放行 wikipedia、大学网站，网页 / 联网查来的资料在这里抓不到（状态如实标“失败”）；本机应正常。
