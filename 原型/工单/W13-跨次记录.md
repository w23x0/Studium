## 1 记什么

| 类 | 谁记 | 内容 | 例 |
| --- | --- | --- | --- |
| 学到哪 `progress` | 学习对话 | 这次的边界、停在哪、留下没讲的、学习者说下次再说的 | “讲完预分频与自动重装值，144 拍在哪段时间里数刚接上；计数模式没讲” |
| 学习者说过的长期的话 `learner` | 主对话、学习对话、谈方向 | `quote` 照抄原话（程序核对）+ `text` 当时在说什么；怎么讲他听得懂、学到什么程度、他的条件 | quote“我不手写代码，能看懂就行”，text“讲 HAL 初始化时说的” |
| 撤回 `withdraw` | 同上 | 学习者说某条不对、要忘掉：`replaces` 指那条，`text` 写他怎么说的 | — |
| 程序列的（不存） | 程序从正本现算 | 本项目每次学习：标题、状态、开始 / 结束 / 最后活动时间；合上的收尾那一句；没合上的结束原话 | — |

不记：知识本身（`00`：知识交给模型）；对学习者的判断；原文里已有、又不属于上面几类的。学习者明确说“记住……”在主对话里照旧写项目说明（`remember`），不改。

## 2 记录形状（`src/shared/records.ts`，加类型，不升数据版本）

```ts
interface CrossNote {
  type: 'cross_note';
  at: string;
  kind: 'progress' | 'learner' | 'withdraw';
  text: string;            // ≤ 200 字
  quote?: string;          // learner 必填，≤ 300 字；须出现在 lines 里学习者那句话中（去掉空白后比，学习者改过的那句也认）
  lines: number[];         // 出处：本会话正本里的行号（学习者 / 模型 / 别的会话发来的话）
  scope: 'project' | 'learner'; // progress 恒为 project；withdraw 跟被撤回的那条；learner 只在学习者明说以后都这样时用
  replaces?: string;       // 被替换 / 撤回的那条：`会话 id:L行号`；须是本项目现在看得到的一条
}
```

记在写它的那个会话的正本里；编号 = `会话 id:L行号`。派生索引不改表，只加按类型找会话的查询（`sessionsWith`）。
