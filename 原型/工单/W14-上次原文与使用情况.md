## 1 开场附上次原文

### 1.1 附什么

| 项 | 做法 |
| --- | --- |
| 什么时候 | 只在 `start_thread` 开学习对话时（`src/core/studium.ts`，现在拼 `facts` 那段）；重开不附，那边的上下文还在。谈方向、主对话不附 |
| 选哪次 | 本项目、不含本次、没删的学习，按最后活动时间取最新一次，状态不限（合上、没学完、还开着都算）；一次都没有就不附 |
| 附什么 | 与 `只读/学过的记录/<id>-对话.md` 同一份文字（`sandbox.ts` 的 `transcriptText`，整份、带行号），不截、不摘要 |
| 放哪 | 跨次记录后面，前面一行标题写明这是哪次（id、标题）、行号与只读区那份相同 |
| 上限 | 不设。超过约 5 万 token 再按 #84 处理，现在不设计（现有的单次原文最大约 30 KB） |

### 1.2 程序附的内容不能进这次的原文（否则一层套一层）

现在程序附的话和主对话的交代拼在 `thread_message.text` 里，所以 `（程序附）…` 会出现在 `renderTranscript` 的结果里（`-对话.md`、`本次对话.md`、`read_thread`）。如果直接把上次原文拼进去，第 N 次的原文就含第 N−1 次的全文，再含第 N−2 次，越滚越大，别的对话读到的也全是重复内容。

| 改哪 | 怎么改 |
| --- | --- |
| `src/shared/records.ts` `ThreadMessage` | 加可选字段 `attached?: string`：程序附给模型、不算对话原文的内容 |
| `src/core/hub.ts` `PeerMessage`、`message()` | 同名可选字段；写进记录；发给模型的 `input.text` 接在 `m.text` 和 `cited` 后面 |
| `src/core/studium.ts` `start_thread` | 沙盒说明、项目说明、跨次记录、上次原文都放 `attached`，`text` 只留主对话的交代 |
| `src/core/transcript.ts` | 不渲染 `attached`。旧记录 `text` 里已有的小段“（程序附）”不动 |
| 其他读 `thread_message` 的地方 | 施工时 grep 一遍。从正本重新拼模型输入的地方要带上 `attached`，给人和别的对话看的地方不带 |

### 1.3 提示词（记 `../提示词记录.md`）

`loop.md`「开始之前」补一句：第一条消息末尾还附了本项目最近一次学习的整份原文，更早的按跨次记录的出处读。不加“不要重问”这类规则：要解决的是看不到，不是不听话。

## 2 上下文显示

| 项 | 做法 |
| --- | --- |
| 显示什么 | 这个对话现在的上下文大小，灰色小字，如 `上下文约 75k` |
| 来源 | 该会话最新一条 `context_used.tokens`（已有记录，界面还没用过）；回完一轮更新；还没回过话就不显示 |
| 放哪 | 主对话、谈方向、学习对话的输入框下方靠右（`src/ui/components/input/composer.tsx` 一带，施工时按实际位置定） |

| 不做 | 不显示上限与百分比：上限要活着的进程问 `getContextUsage`，产品负责人的尺度是 20～30 万内（#75），数字本身够用 |

## 3 额度显示

| 项 | 做法 |
| --- | --- |
| 显示什么 | 订阅额度各窗口的已用百分比与重置时间：5 小时、7 天，以及接口有返回的按模型窗口（如 7 天 Opus）；没返回的不显示 |
| 放哪 | 左下账号菜单一行（`src/ui/components/sidebar/account-menu.tsx`）+ 使用情况面板最上面 |
| 来源一 | Agent SDK `query.usage_EXPERIMENTAL_MAY_CHANGE_DO_NOT_RELY_ON_THIS_API_YET({ skipBehaviors: true })`，读 `rate_limits`；打开菜单或面板时问一次 |
| 来源二 | 流里的 `rate_limit_event`（`rate_limit_info`：`rateLimitType` `utilization` `resetsAt`），适配器 `src/core/model/claude-agent-sdk.ts` 现在没接，接上后更新同一份 |
| 存放 | 只放核心内存，不写正本 |
| 没有活进程时 | 显示最后一次拿到的值和时间；一次都没有就写“暂时拿不到” |
| 风险 | 来源一是 SDK 标明的实验接口，可能改名或撤掉，要包好错误，失败不影响别的功能；SDK 升级时 `npm run check` 会报出改名。`utilization` 的取值范围以真实返回为准：来源一注释写 0–100，来源二没写，两边可能不同，要核对类型注释或按值判断 |
| 模型接口 | `src/core/model/port.ts` 加一个可选方法，只有 Claude 实现；别家没有时界面不显示这一行 |

### 4.2 口径（已用截图的数核对过前两行）

| 量 | 算法 |
| --- | --- |
| Token | 输入 + 输出 + 缓存写入 + 缓存读取（截图 1B ≈ 996.5M + 3.9M + 25.1M + 5M + 4.5M） |
| 缓存命中 | 缓存读取 ÷（缓存读取 + 缓存写入 + 输入），不算输出（截图 97%） |
| 占比 | 这个讨论串的 Token ÷ 本项目 Token |
| 输入、缓存写入、缓存读取 | 从该会话 `model_raw` 里助手消息的 `usage` 现算。同一条消息会有多行（一个内容块一行），按消息 `id` 去重；模型取 `payload.model`。旧数据也有 `model_raw`，不用补记录 |
| 输出 | `model_raw` 里的 `output_tokens` 只是流式开头的数，不准；取 `context_used.output` 按轮加总，算给那一轮的模型 |
| 算哪些会话 | 归属本项目的（用 `cross-notes.ts` 那套归属判断），含主对话和只读的旧种类；已删的不列不计；不属于任何项目的不算 |
| 什么时候算 | 打开面板时现算；慢了再说，现在不做缓存 |
