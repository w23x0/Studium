## 1 目标

照 Claude 项目（Library、项目说明）与 NotebookLM（添加来源、发现来源）把“东西怎么进项目”做出来：**拖进来 / 点添加**（文件、文件夹、链接、仓库地址）、**从本机书库选**、**从别的项目拿**、**找资料对话**（联网列候选、勾了才存）；进来先**分流**成资料或学过的（笔记、别处 AI 对话记录进外部导入）；每份显示**处理状态**；项目页改成**三个页签**（学习 / 资料 / 记着什么）；加**项目说明**（学习者写、主对话代写、各对话开场带上）。

## 4 加 / 改什么

### 4.1 入口（界面 + 核心）

| 入口 | 界面 | 核心 |
| --- | --- | --- |
| 拖进来 / 点“添加” | 「资料」页签整页可拖放；“添加”菜单：文件 · 文件夹 · 链接 · 代码仓库。主对话输入框拖入**非图片**文件时不进输入，改走同一上传（图片照旧转写） | 上传：`POST /api/projects/<id>/uploads`（multipart，多文件；文件夹按相对路径上传）→ 存到 `<数据>/projects/<id>/上传/<上传 id>/` → 分流（§4.2）→ 资料走 W8 `POST …/materials`（`origin` = 上传路径），学过的走 §4.3 |
| 链接 / 仓库 | 输入框：网址或 Git 地址（仓库可填提交号） | 直接调 W8 `POST …/materials`（`kind: 'web'` / `'repo'`），不分流（链接与仓库一律当资料） |
| 从本机书库选 | 保留现有按学科挑书（`Picker`），挪进“添加”菜单 | 调 W8 “从书库加进项目”那条 |
| 从别的项目拿 | “添加”菜单列出其他项目及其资料，勾选 | `POST /api/projects/<id>/materials/copy` `{ fromProject, material }` → 在本项目区复制一份（`source.json` 新 id、`origin` 记来源项目与资料 id） |

限额（参照 Claude：单次 100 个文件；单文件上限实现定）：超了在界面上直接说，不静默截断。

### 4.2 分流

| 项 | 做法 |
| --- | --- |
| 谁判 | 程序先按扩展名粗分：`.pdf` `.html` `.srt` `.vtt` `.docx` 等 → 资料；`.md` `.txt` `.json`（对话导出）→ 交模型判一次（一个短调用，只回 `资料` / `学过的` + 一句理由；不分析内容）|
| 显示 | 上传后每份一行：文件名 · 判成什么（可点改）· 理由；学习者改了以学习者为准，改判时程序把它从一边移到另一边 |
| 记录 | 每次判、改判在主对话正本追加 `upload_routed`：`{ type, at, upload, file, routedTo: '资料' \| '学过的', by: 'model' \| 'learner', reason? }` |

### 4.3 学过的：笔记与别处 AI 对话记录（外部导入）

| 改 | 做法 |
| --- | --- |
| 存放处 | `<数据>/learned/imports/<导入 id>/`：原件 + 转 md（`.md` 原样；对话导出 JSON 转成“学习者：… / AI：…”逐条 md）；不进资料、不进沙盒的 `只读/资料/` |
| 渠道 | `Import['channel']` 加 `'对话记录'`；`ref` 加 `{ file: string }` 指 md；W2 的笔记导入改成走这里（`ref: { file }`），旧 `{ note }` 形状删 |
| 沙盒 | `只读/学过的记录/外部导入.md` 照旧列条目，并把每份 md 放 `只读/学过的记录/外部导入/<导入 id>.md` |
| 对话记录怎么读 | 渲染头部写一句：“这是学习者在别处跟 AI 学的对话；只有学习者说的、做的算证据，AI 讲的不算学习者会” |
| 删 | `notes.ts` 的“切小节进书库”流程与 `NoteImport` 手填路径界面 |

### 4.4 处理状态

「资料」页签每份资料一行：标题 · 种类 · 角色（模型判的，W8）· 状态（`处理中` 转圈 / `可用` / `部分可用` 带问题数 / `失败` 带原因）· 操作（重试、删除）。状态由 W8 的列表接口给，处理中每隔几秒重拉或走 SSE（已有事件通道优先）。删除：`project_material` `op: 'remove'`；已有引用在依据面板标“资料已删”。

### 4.5 找资料对话（新会话种类 `find`）

| 项 | 做法 |
| --- | --- |
| 种类 | `CONVERSATION_KINDS` 加 `'find'`；提示词 `prompts/find.md`；`webSearch: true`；`STUDIUM_PROFILES` 可配 |
| 谁开 | 主对话新工具 `find_materials` `{ request: string }`（学习者原话）→ 程序开 `find` 会话 |
| 开场给 | 学习者那句话、方向说明、项目说明（§4.6）、本项目资料目录（标题 + 种类 + 网址） |
| 交回工具 | `submit_candidates` `{ candidates: { title: string; url: string; why: string; alreadyIn?: string }[] }`（≤ 10；程序核 `url` 是 http(s)、去重、标出已在本项目的） |
| 界面 | 找资料对话里出候选清单（复选框，“全选”，“存所选”）；存 = 对每个勾中的调 W8 `POST …/materials` `{ kind: 'search', origin: url, title }`；正本记 `candidates_picked` `{ type, at, picked: number[] }` |
| 主对话 | 收到存完的事实后说一句存了几份 |
| 不做 | 不自动存；模型写的调研说明不存成资料 |

### 4.6 项目说明

| 项 | 做法 |
| --- | --- |
| 记录 | 主对话正本追加 `project_instructions`：`{ type, at, text: string, by: 'learner' \| 'main', forLine?: number }`（`forLine` = 主对话代写时学习者那句话的行）；当前值 = 最后一条；历史 = 全部 |
| 接口 | `GET /api/projects/<id>/instructions` → `{ text, history: { at, by, text }[] }`；`PUT` 同路径 `{ text }`（学习者改，`by: 'learner'`） |
| 主对话代写 | 新工具 `remember` `{ text: string }`：模型给出改后的全文；程序存一条 `by: 'main'`，并在对话里由主对话说一句改了什么（提示词层） |
| 谁读 | 主对话每轮附上的事实（`turn_context`）加项目说明；畅谈、导航、找资料、学习对话开场给；学习对话放沙盒 `只读/项目说明.md`；**守卫、状态整理、教法记录整理不给** |
| 长度 | 上限 16000 字（参照 Claude），超了接口拒、界面提示 |

### 4.7 项目页三页签

| 页签 | 内容（从现有组件挪，不重写） |

| 设置（齿轮） | 名字、期限（`DeadlineLine` 挪过来）；模型配置不在这里（开发者面板） |
