## 4 加 / 改什么

### 4.1 资料存放处（新，`src/core/knowledge/materials.ts`，取代 `library.ts` 的书库扫描）

每个项目一个区：`<数据>/projects/<主对话 id>/资料/<资料 id>/`，跨项目同一份各存一份（实现可共用转换产物，本单不做共用）。

```
<资料 id>/
  source.json      // 见下
  原件/            // 原样保留（PDF、网页快照 HTML 等）；仓库不复制原件，见 kind=repo
  正文/            // md；仓库 = 固定提交的工作树（代码原样）
```

```ts
interface MaterialSource {
  id: string;
  title: string;
  kind: 'pdf' | 'web' | 'subtitle' | 'repo' | 'search' | 'md';   // search = 联网查来的新内容
  origin: string;          // 原路径 / URL / 仓库地址
  version: string;         // pdf: 文件哈希；web/search: 抓取时间；repo: 提交号
  fetchedAt: string;
  converter?: string;      // 'mineru' | 'readability' | 'srt' | 'none' …
  status: '处理中' | '可用' | '部分可用' | '失败';
  problems?: string[];     // 失败或有问题的块，不伪装成可用（资料.md「入库」）
  role?: { value: '主资料' | '参考资料'; by: 'model'; at: string; sessionId: string }; // 模型判断后写；界面可见
}
```

| 种类 | 处理（本单只要做到能用，不追求转换质量） | 定位串 |
| --- | --- | --- |
| `pdf` | 已有书库的切分结果直接挂进来当 `正文/`（`m07/` 下的 md）；新 PDF 走 `书库处理/` 的 MinerU 流程，产物放 `正文/` | `资料id/文件:行号`（同现行） |
| `repo` | `git clone` 到 `正文/` 并 `checkout` 到指定提交（不给提交 = 当时的 HEAD，记下提交号）；不转 md | `资料id/路径/文件:行号` |
| `web` / `search` | 存 HTML 快照到 `原件/`，转 md 到 `正文/`（能用的现成库即可，如 Readability + turndown；本地已有依赖优先） | `资料id/文件:行号` |
| `subtitle` | `.srt` / `.vtt` 转 md，每段前保留时间点 | `资料id/文件:行号` |
| `md` | 原样放 `正文/` | `资料id/文件:行号` |

资料更新 = 新加一份（新 `version`）；旧引用仍指旧那份，不改指。

### 4.2 项目与范围

| 改 | 做法 |
| --- | --- |
| `project_material` 记录 | 改为 `{ type, at, op: 'add' \| 'remove', material: string }`；`add` 时资料已在本项目区里 |
| `scopeOf` | 只返回本项目的资料；**删掉“没选 = 全库”**；跨项目不读资料 |
| 旧书库 | 书库根（`STUDIUM_LIBRARY`）只作“从书库挑一本加进项目”的来源：加进来 = 在项目区里建一份 `kind: 'pdf'`、`正文/` 指向（或拷贝）它的切分目录 |
| HTTP | 加资料：`POST /api/projects/<id>/materials` `{ kind, origin, title?, commit? }` → 后台处理，`status` 随处理更新；列表接口带 `kind` `version` `status` `role` |

### 4.3 沙盒

| 改 | 做法 |
| --- | --- |
| 只读区 | `只读/资料/<资料 id>/` → 该资料的 `正文/`；每份旁边放一个程序渲染的 `只读/资料/目录.md`：每份一行（标题、种类、版本、日期、状态、角色） |
| 说明文字 | `sandbox.ts` 里“教材原文”改为按种类说；没有资料时仍写“缺资料依据” |
| 仓库能跑 | 学习对话要跑仓库代码时，由模型把需要的部分拷进学习者代码目录再跑（只读区不可写）；不另加命令 |
| 角色 | 导航第一次读某份资料后，可经已有的交回单子 / 路线决定附带 `roles: { material, value }[]`，程序写进 `source.json` 的 `role`；不另开工具 |
