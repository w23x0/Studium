## 2 学习对话：自己读、自己定边界

| 项 | 做法 |
| --- | --- |
| 怎么开 | 主对话直接开学习对话（取代 `plan_next`）。开场 = 主对话写的交代 + 学习者原话原样附上（按行号引，程序照抄）。交代里只写学习对话需要、自己读不到的项目背景，学习者的话有两种读法时写一句它的理解；**不替学习对话定学什么、不加学习者没要求的要求**（照 Claude 主对话系统提示「Communicating with threads」） |
| 第一步 | 学习对话自己读记录（以前的学习原文、主对话原文、资料、项目说明、方向目标），自己定这次的边界：从哪出发、学到哪、哪些不碰。不交回主对话、不另存、不定格式、不定路线；就留在它自己的上下文里 |
| 提示词 | `loop.md` 改写：一次学习的定义改成不依赖单子；第一步要做的事写成事实（学习者每个时刻会的不一样：并行学、在应用外学、会忘；以前的记录带日期）；删单子、出发点、导航、状态记录、转写相关的句子 |
| 能联网 | 学习对话放开 `WebSearch` / `WebFetch`（去掉“沙盒与联网不同时有”的限制，只对学习对话；`claude-agent-sdk.ts` 注释同步） |
| 能重开 | 学习对话结束后能重开（学习者在界面上、或主对话替他），和别的讨论串一样；重开后再收尾就再写一句新的收尾，接在后面（取代 10-28“学习对话不能重开”） |
| 中途要先学别的 | `request_branch` 改成：学习对话给主对话发话请开一条新讨论串（照 Claude 讨论串的 `message_coordinator`），附学习者原话；这次学习照样开着 |
| 收尾 | `request_close` / 学习者确认学完照旧 |

## 3 协调：照 Claude 项目的主对话与讨论串

### 3.1 发话（取代现在的 `message_thread` 等回话 + SDK 中途插话）

| 项 | 做法 |
| --- | --- |
| 一个口子 | 任何会话给另一个会话发一句话，**发出去马上返回**；对方空着就当场跑一轮，对方正忙就排进 hub 的队列，等它这一轮跑完再给它。对方回的话按同样方式作为一条消息送回发话方（发话方空着就叫醒它） |
| 不用 SDK 中途插话 | 去掉 `interject` 的使用（`hub.ts` `send` 里 `live.running && interject` 那条路、适配器的 `interject` / `pending` 插话计数）。学习者在模型说话中途发的话同样排队到这一轮结束（产品负责人：中途不需要打断，能停就行）。根因记录：11-02 23:57 主对话转话给找资料，SDK 把插话并进当前一轮，适配器 `pending` 仍在等它另一轮，找资料一直“在跑”、主对话等了 1800 秒 |
| 来历标注 | 送进模型的每条输入写明：谁说的（学习者本人 / 主对话 / 某讨论串 / 程序）、时间、**距学习者上次说话多久**；别的会话转来的学习者原话标成学习者的原话（照 Claude 的 wake 与 `<cited author="user">`） |

### 3.2 主对话的工具

| 工具 | 说明 |
| --- | --- |
| 开讨论串 | 学习对话、谈方向、找资料（导入会话由程序开，见 §6）；**不先问学习者**：意思有两种读法时按最可能的开，并在交代里和回给学习者的一句里说出它的理解 |
| `message_thread` | 按 §3.1 发话，附学习者原话行号；不加学习者没要求的要求 |
| `read_thread` / `list_threads` | 读讨论串原文（不是摘要）、列讨论串（标题、状态、最后活动）；删掉的不列不读 |
| 改名、结束 / 重开 | 所有讨论串（含学习对话） |
| 改自己上一条 | 发现理解错了，直接改它上一条说的话（照 Claude `edit_message`），不追加更正；界面显示改后的 |
| 不回话 | 可只回一个表情或不回（照 Claude `react` / `no_reply_needed`） |
| 撤掉 | 本机只读沙盒与命令行（推翻 11-02，取代 W11 §5）：主对话只读项目里的东西；学习者给本机路径时，`import_local` 照旧由程序拷进项目、开导入会话处理（模型不读本机） |
| 每轮附上的事实 | `turn_context` 只留时间类事实（§3.1）；方向目标、讨论串清单、学过的记录不再每轮附，要用自己读（照 Claude：串清单与历史不自动带） |
| 提示词 | `main.md` 照 Claude 主对话系统提示的结构改写；写明“学习者只看到一个助手，不提内部机制（会话、id、删不掉之类）”；回话按时间的规矩以后专门谈，这次不加 |

### 3.3 讨论串的工具（学习对话、谈方向、找资料都有）

| 工具 | 说明 |
| --- | --- |
| 读主对话 / 读别的讨论串 / 列讨论串 | 直接读，不经主对话问 |
| 给主对话发话 | 请开新讨论串时用（§2 中途要先学别的） |
| 给别的讨论串发话 | 只在两边的活互相依赖时 |
| 改名、结束 | 自己的 |

## 4 界面

| # | 改什么 | 做法 |
| --- | --- | --- |
| 4.1 | 讨论串卡片 | 一条讨论串在主对话里只有一张卡片（再转话不新放卡片）；卡片标题跟着讨论串现在的标题；卡片带状态（与右栏同一来源：等你 / 进行中 / 停着 / 已结束） |
| 4.2 | 时间 | 鼠标移到某条消息上，左下角显示那条的时间（所有对话） |
| 4.3 | 删除 | 讨论串每行一个菜单，里面有删除，删前确认一次；只在界面上手动删（主对话不带删除工具）。删 = 在主对话正本追加一条删除记录（新类型，只加）+ 主对话上下文后面接一句“学习者删了「…」”；之后界面（卡片、右栏、搜索）不显示、别的会话读不到、学过的记录与沙盒里不再包含；正在跑的先停；找资料存下的资料、谈方向定下的方向不跟着删；不做撤销 |
| 4.4 | 停止与编辑 | 生成中途能点停止（适配器中断当前一轮；其他模型同样断开输出即可）；停下后能改自己刚发的那句并重新生成。上下文里接“学习者停止了生成”“学习者把上一句改成：……”，界面只显示改后的 |
| 4.5 | 正在做什么 | 去掉光秃的“在想…”；按当前工具调用显示一行（正在读文件 / 正在搜索 / 正在跑命令 / 正在写组件 / 正在把话转给「…」），不显示内容；所有对话统一；由程序从工具调用得出，不让模型另写 |
| 4.6 | 中途碎话 | 模型在工具调用之间说的话（如“Numbers look reasonable. Submitting the component.”）不上学习页、不进主对话的消息流，只作 4.5 那一行的依据；只有一轮最后写给学习者的话上页面 |
| 4.7 | 改动标记常驻 | 组件换新版、文字被改过：块旁一直标“第 N 版 / 改过”，点开能看之前的版本（照 Claude artifact 的版本切换与 Claude Docs 的改动署名）；取代现在“只标到学习者下次说话”的 `freshMark` |
| 4.8 | 找资料 | 去掉勾选：找资料对话自己定存哪些、直接存；学习者说不要再删（§4.3 的增量删法用到资料上：追加删除标记） |

## 5 学习页（竖流，现在唯一的学习页）

| # | 改什么 | 做法 |
| --- | --- | --- |
| 5.1 | 组件嵌进文字 | 模型能在自己写的话里标“组件放这儿”（格式施工时定，写进提示词的输出格式），组件嵌在那一段的位置；不再只能“先交组件、挂在这一轮文字上面” |
| 5.2 | 提示词删 | `loop-stream.md` 删“每一轮写的话要完整、尽量能单独看懂”与“改、挪、拿掉这些先做，最后一口气写给学习者的话”里规定先后的部分 |
| 5.3 | 提示词加（都写成定义 / 事实） | ① 页面的目的：控制学习者眼前信息的边界和速度，知识边界随对话往前移 ② 组件 = 补文字说不清的部分（过程、变化、空间关系），放在它配合的那段文字处 ③ 你对学习者的了解只来自他的输出，你问什么决定他能告诉你多少：只要一个数、一个是非、一个选项的问题，答对答错都看不出他怎么想 ④ 学习者说的话也是关于他的证据：可能是真的需要，也可能是想绕开难的那一步，他自己未必意识到；照着做之前先判断是哪种 |
| 5.4 | 点击跳转 | 不做（2.5 搁置：嵌入改完多半用不着；真用还要来回翻再说） |
| 5.5 | “盖住、点开才看” | 不做（先看 5.1–5.3 改完模型会不会主动控制页面） |
| 5.6 | 图片 | 学习者附的图原样放进消息送给模型（`TurnInput` 加图片，适配器按 SDK 的 image 块送；图片文件同时在沙盒只读区，看不了图的模型自己用工具打开） |
