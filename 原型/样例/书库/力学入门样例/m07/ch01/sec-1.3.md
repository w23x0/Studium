# §1.3 加速度（p.6）

速度本身也会变。速度变化得多快，用**加速度**描述。照速度的定义方式，平均加速度是速度变化量除以时间：

$$\bar a = \frac{\Delta v}{\Delta t}$$

取极限得到瞬时加速度：

$$a(t) = \frac{dv}{dt} = \frac{d^2x}{dt^2}$$

加速度的正负表示速度变化的方向，不表示“加快”或“减慢”。速度为正、加速度为负时，物体在减速；速度为负、加速度也为负时，物体反而越跑越快。判断加快还是减慢，要看速度与加速度是否同号。

**例 1.2** 一个小球竖直上抛，取向上为正，它的加速度一直是 $-9.8$ 米/秒²。在最高点，速度为零，加速度是多少？

解：仍然是 $-9.8$ 米/秒²。速度为零不等于加速度为零：在最高点速度正在由正变负，变化率不为零。
