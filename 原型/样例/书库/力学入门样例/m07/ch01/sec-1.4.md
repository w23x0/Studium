# §1.4 匀加速直线运动（p.9）

加速度保持不变的直线运动叫匀加速直线运动。设 $t=0$ 时位置 $x_0$、速度 $v_0$，加速度为常数 $a$。由 $a = dv/dt$ 积分得

$$v(t) = v_0 + a t$$

再由 $v = dx/dt$ 积分得

$$x(t) = x_0 + v_0 t + \tfrac{1}{2} a t^2$$

两式消去 $t$，得到不含时间的关系：

$$v^2 - v_0^2 = 2a(x - x_0)$$

这三个式子只在加速度恒定时成立。加速度随时间变化时，要回到定义 $a = dv/dt$、$v = dx/dt$ 逐步积分。

**例 1.3** 汽车以 20 米/秒行驶，刹车后加速度为 $-5$ 米/秒²。刹车距离多长？

解：末速度为 0，由 $v^2 - v_0^2 = 2a\Delta x$ 得 $\Delta x = \dfrac{0 - 400}{2 \times (-5)} = 40$ 米。
