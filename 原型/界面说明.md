# 界面说明

> 状态：待定（agent 写，实现层，不新增产品结论；产品结论以 `../docs/设计/` 为准）。
> 依据：10-24 界面体检（静态走查 + 真模型走一遍：建项目 → 畅谈 → 导航 → 学习三轮 → 收口 → 回项目）。
> 10-29 起没有项目页（项目 = 项目对话 + 右边讨论串），本页已按此改。
> 用法：改界面前先看本页对应一节；本页只管“怎么摆”，功能有无以设计为准，设计里有的不删。

## 0 总原则

| 原则               | 做法                                                                                                                                                           |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 一页一件事         | 每页先回答“来这里做什么”，第一屏只放做这件事要的东西；其余收起或挪到别处                                                                                       |
| 同一信息只出现一处 | 别处只放一行摘要 + 链接                                                                                                                                        |
| 对话为主           | 学习者的事在对话里做；页面是看和改记录的地方，不和对话抢主动作                                                                                                 |
| 参照               | Claude 桌面版：左栏（新建 · 搜索 · 项目 · 置顶 · 最近）、项目对话右边的讨论串（等你 / 进行中 / 已结束）、对话页（顶部“项目 / 对话”面包屑）、右侧 artifact 面板 |

## 1 全局

### 1.1 导航与“我在哪”

| 项         | 规则                                                                                                                 |
| ---------- | -------------------------------------------------------------------------------------------------------------------- |
| 顶栏       | 每页左上一条面包屑：`项目名 / 当前页`；项目名**永远**回项目对话（没有项目页，10-29），主对话用“项目对话”这个词明写   |
| 返回按钮   | 文字说去哪：“回项目对话”，不只写项目名                                                                               |
| 左栏高亮   | 只高亮当前一行；列表按最近活动排序，但当前打开的这行不在点击瞬间跳位（下次进页面再排）                               |
| 地址       | 当前项目、页面、对话写进地址（`#/p/<id>/c/<id>`）：刷新、浏览器后退回到原处；旧书签 `#/p/<id>`（原项目页）进项目对话 |
| 新开的对话 | 程序开出任务对话后，主对话里给一张卡（已有）；进去后顶部写明它从哪来、做完回哪                                       |

### 1.2 等待与进度反馈

| 场景                                 | 现在                                   | 改成                                                                                                                             |
| ------------------------------------ | -------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| 模型在答，还没出字                   | 一个或两个跳动黑点，旁边已有“复制”按钮 | 一行灰字“在想…”，出字后消失；回答下面不放复制按钮（悬停出现会挤动文字，不打磨的半成品不做）                                      |
| 模型在用工具（读记录、开对话、联网） | 看不到                                 | 不显示工具行，调工具前的短旁白也不显示（10-29，学习者不用知道模型怎么做的）；等待提示只有“在想…”与收口那句（`wording-tools.ts`） |
| 导航（约 30 秒）                     | 主对话里一张卡 + 黑点                  | 不显示导航卡片与“看过程”（10-29）；定完出“开始学：<标题> →”卡片                                                                  |
| 等收尾那一句（10-31 起不开守卫）     | 按钮字变成“在收尾…”                    | 学习页下方一行“在收尾…”（转圈）；学习对话写下收尾那一句就换成那一句，它觉得还差、直接回话就去掉这一行                            |
| 发消息后                             | 不自动滚动，新回复在视口外             | 自己发消息后滚到底；看历史时才停住并显示“回到底部”                                                                               |

### 1.3 空状态

| 规则                                           | 例                                                           |
| ---------------------------------------------- | ------------------------------------------------------------ |
| 一块空着只写一句“下一步怎么做”，不写“还没有”   | 讨论串空：“还没开过。谈方向、学习、找资料都会在这里列一条。” |
| 同一屏最多一处空状态说明；其余空分组整块不显示 | 等你 / 进行中 / 已结束 三组全空时合成上面一句                |
| 空的说明不和标题下的解释重复                   | 解释写在空状态里，有内容后不再显示解释                       |

### 1.4 文案

| 规则                              | 现在的反例 → 改法                                                                                                                             |
| --------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| 对学习者说“你”，不说“学习者 / 他” | 方向卡“学习者只想弄明白…”、判断理由里的“他” → 记录原文可保留，界面渲染时不直接贴模型写给程序的原文；要贴就标“记录原文”                        |
| 不出现内部编号、工具名、英文      | `st-590816b8`、`open_goal_talk`、“依据里的行号写成了 L11” → 不显示                                                                            |
| 时间一律本地时间                  | 状态记录里 05:29 与别处 13:29 是同一刻                                                                                                        |
| 出处标记要短且可分辨              | 一段里十个“（那句原话）” → 用小号上标序号 ①②，悬停显示原话                                                                                    |
| 一件事一个词                      | “先放一放”（暂停，仍在学）/“先到这里”与“先放下的（没学完）”（结束，算搁着）→ 暂停叫“先停一下”，结束没学完叫“搁着”（设计用词），两词不共用“放” |
| 按钮写动作，说明不超过一行        | 每块标题下的解释最多一行，较长的放进 `?` 悬停                                                                                                 |

### 1.5 视觉统一

| 项                   | 规则                                                                                                                                                                                                                                                                             |
| -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 字体                 | `--font-sans` 先列 `'PingFang SC','Noto Sans CJK SC'` 等中文字体，再列 `system-ui`（别的机器上起作用）。使用者本机的 fontconfig 是有意设成全部用 Maple Mono 的，界面照系统设定走：不打包网页字体、不盖掉系统设定                                                                 |

| 间距                 | 区块之间 `gap-8`，区块内 `gap-3`；卡片内边距统一 `p-4`                                                                                                                                                                                                                           |
| 按钮层级             | 一屏最多一个实心陶土色主按钮（这一页最该做的事）；次要 `outline`；其余 `ghost` 或文字链接。图标按钮必须有悬停文字，不放无字图标当唯一入口（“学完了”卡片右边的盾牌）                                                                                                              |
| 卡片                 | 只给可点的整块或成组内容加边框卡片；单行文字不套卡片                                                                                                                                                                                                                             |
| 配色（10-29）        | 左下账号菜单“外观”：跟系统 / 浅色 / 深色（`src/ui/theme.ts`，存浏览器 localStorage，`<html>` 标 `data-theme` 与 `.dark`）；学习页组件小窗（iframe）按实际深浅给底色与颜色变量 `--studium-bg/fg/muted/border/accent`（`page-frame.ts`），子代理提示词写了这些变量，组件不写死颜色 |
| 窄屏（< 768px）      | 左栏变抽屉（顶栏左上按钮打开）；右侧面板与讨论串变全屏覆盖层，左上“返回”                                                                                                                                                                                                         |

## 3 已定的取舍

| 问题                                                | 定法                                                                                                                                                   |
| --------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 学习对话两个出口（“先放一放”暂停 / “先到这里”搁着） | 只留“搁着，以后再学”（收进“…”）；暂停不设按钮：设计里暂停不算事件，学习者走开、回来接着说即可（`../docs/设计/01-流程.md` 事件表“暂停”行）              |
| 新建项目                                            | 点“新建项目”填项目名（必填，学习者自己起）和想学什么（可不填，填了作为主对话第一句发出）；第一次打开不自动建“项目 1”，没有项目时显示全部项目页的空状态 |
