# 界面说明

> 状态：待定（agent 写，实现层，不新增产品结论；产品结论以 `../docs/设计/` 为准）。
> 依据：10-24 界面体检（静态走查 + 真模型走一遍：建项目 → 畅谈 → 导航 → 学习三轮 → 收口 → 回项目）。
> 用法：改界面前先看本页对应一节；本页只管“怎么摆”，功能有无以设计为准，设计里有的不删。

## 0 总原则

| 原则               | 做法                                                                                                                                                                                                                                  |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 一页一件事         | 每页先回答“来这里做什么”，第一屏只放做这件事要的东西；其余收起或挪到别处                                                                                                                                                              |
| 同一信息只出现一处 | 别处只放一行摘要 + 链接（例：方向全文只在“记着什么”，项目页头只放一行）                                                                                                                                                               |
| 对话为主           | 学习者的事在对话里做；页面是看和改记录的地方，不和对话抢主动作                                                                                                                                                                        |
| 参照               | Claude 桌面版：左栏（新建 · 搜索 · 项目 · 置顶 · 最近）、项目对话右边的讨论串（等你 / 进行中 / 已结束）、项目页（标题 + 说明 · 右侧知识与指令）、对话页（顶部“项目 / 对话”面包屑）、右侧 artifact 面板、“正在思考 / 用了工具”可展开行 |

## 1 全局

### 1.1 导航与“我在哪”

| 项         | 规则                                                                                        |
| ---------- | ------------------------------------------------------------------------------------------- |
| 顶栏       | 每页左上一条面包屑：`项目名 / 当前页`；项目名**永远**去项目页，主对话用“项目对话”这个词明写 |
| 返回按钮   | 文字说去哪：“回项目对话”“回项目页”，不只写项目名（现在同一个项目名两处去向不同）            |
| 左栏高亮   | 只高亮当前一行；列表按最近活动排序，但当前打开的这行不在点击瞬间跳位（下次进页面再排）      |
| 地址       | 当前项目、页面、对话写进地址（`#/p/<id>/chat/<id>`）：刷新、浏览器后退回到原处              |
| 新开的对话 | 程序开出任务对话后，主对话里给一张卡（已有）；进去后顶部写明它从哪来、做完回哪              |

### 1.2 等待与进度反馈

| 场景                                 | 现在                                   | 改成                                                                                                      |
| ------------------------------------ | -------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| 模型在答，还没出字                   | 一个或两个跳动黑点，旁边已有“复制”按钮 | 一行灰字“在想…”，出字后消失；回答下面不放复制按钮（悬停出现会挤动文字，不打磨的半成品不做）               |
| 模型在用工具（读记录、开对话、联网） | 看不到                                 | 灰色一行“读了学过的记录”“开了谈方向的对话”，可展开看细节（同 Claude 的工具行）；数据来自 `tool_call` 记录 |
| 导航（约 30 秒）                     | 主对话里一张卡 + 黑点                  | 卡片上写“正在定下一次学什么 · 看过程”，定完卡片变成“开始学：<标题> →”                                     |
| 守卫（约 30 秒）                     | 只有按钮字变成“正在整理…”              | 对话里插一行“正在整理这次学到了什么，约半分钟”，完成后换成“这次学到了什么已整理好”（不说学没学会）        |
| 发消息后                             | 不自动滚动，新回复在视口外             | 自己发消息后滚到底；看历史时才停住并显示“回到底部”                                                        |

### 1.3 空状态

| 规则                                           | 例                                                                     |
| ---------------------------------------------- | ---------------------------------------------------------------------- |
| 一块空着只写一句“下一步怎么做”，不写“还没有”   | 学习页签空：“还没开始学。在项目对话里说想学什么，或点‘下一步学什么’。” |
| 同一屏最多一处空状态说明；其余空分组整块不显示 | 进行中 / 学完了 / 搁着 三组全空时合成上面一句                          |
| 空的说明不和标题下的解释重复                   | 解释写在空状态里，有内容后不再显示解释                                 |

### 1.4 文案

| 规则                              | 现在的反例 → 改法                                                                                                                             |
| --------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| 对学习者说“你”，不说“学习者 / 他” | 方向卡“学习者只想弄明白…”、判断理由里的“他” → 记录原文可保留，界面渲染时不直接贴模型写给程序的原文；要贴就标“记录原文”                        |
| 不出现内部编号、工具名、英文      | `st-590816b8`、`open_goal_talk`、“依据里的行号写成了 L11” → 不显示                                                                            |
| 时间一律本地时间                  | 状态记录里 05:29 与别处 13:29 是同一刻                                                                                                        |
| 出处标记要短且可分辨              | 一段里十个“（那句原话）” → 用小号上标序号 ①②，悬停显示原话                                                                                    |
| 一件事一个词                      | “先放一放”（暂停，仍在学）/“先到这里”与“先放下的（没学完）”（结束，算搁着）→ 暂停叫“先停一下”，结束没学完叫“搁着”（设计用词），两词不共用“放” |
| 按钮写动作，说明不超过一行        | 每块标题下的解释最多一行，较长的放进 `?` 悬停                                                                                                 |

### 1.5 视觉统一

| 项                   | 规则                                                                                                                                                                                                             |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 字体                 | `--font-sans` 先列 `'PingFang SC','Noto Sans CJK SC'` 等中文字体，再列 `system-ui`（别的机器上起作用）。使用者本机的 fontconfig 是有意设成全部用 Maple Mono 的，界面照系统设定走：不打包网页字体、不盖掉系统设定 |
| 字号层级（只用四级） | 页面标题 `text-2xl` 衬线 · 区块标题 `text-base font-medium` · 正文 `text-sm`（对话正文保持 `1.05rem` 衬线）· 说明 `text-xs` 灰                                                                                   |
| 间距                 | 区块之间 `gap-8`，区块内 `gap-3`；卡片内边距统一 `p-4`                                                                                                                                                           |
| 按钮层级             | 一屏最多一个实心陶土色主按钮（这一页最该做的事）；次要 `outline`；其余 `ghost` 或文字链接。图标按钮必须有悬停文字，不放无字图标当唯一入口（“学完了”卡片右边的盾牌）                                              |
| 卡片                 | 只给可点的整块或成组内容加边框卡片；单行文字不套卡片                                                                                                                                                             |
| 窄屏（< 768px）      | 左栏变抽屉（顶栏左上按钮打开）；右侧面板变全屏覆盖层，左上“返回”；现在 390 宽时左栏不收、对话区被挤成一列字                                                                                                      |

### 2.6 学习对话

| 项           | 内容                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 来这里做什么 | 学这一个点                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |

| 底栏         | 主按钮“我觉得懂了”；“…”里放“先停一下”（暂停）与“搁着，以后再学”（没学完结束），各带一行说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| 收口时       | 屏幕下方一行“正在整理这次学到了什么…”→ 换成“这次学到了什么已整理好 · 看整理的内容”（点开去面板；守卫不把关，不说学没学会）；底栏一句“这次学到了什么已整理好。还想补一句就接着说；不补就点‘学完了’”，只剩“学完了”与“再补一句”（聚焦输入框）两个按钮；旧版的学习在对话流里也是一行“这次学到了什么已整理好”，链接“看整理的内容”                                                                                                                                                                                                                                                                                       |
| 结束后       | 底栏一条“这部分学完了 · 回项目对话”；对话里不再重复同一句                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| 屏幕         | 不分对话和页面两块：中间一屏是主模型这一轮定的（它新写的话 + 它点名拿回的旧块，框架摆好），一屏换下一屏、回到顶上；主模型的文字直接显示（公式、表格），组件放各自小窗，还没做好的组件先占一块“正在做…”；主模型点名拿回开场时显示一块“开场时的单子”（这次学 · 学完应该能 · 从哪出发 · 先假定你会的 · 这次怎么走，不显示只给模型的沙盒路径等），拿回收尾记录时显示一块“这次学到了什么（整理的内容）”（同“看整理的内容”点开那份的理由与学到的）；两块紧密相关时并排，窄屏叠成一列；主模型在写时屏幕下方先显示正在写的那段；一轮没跑成时屏幕下方一行“这一轮没跑成（<服务交回的那句，如额度几点恢复>），可以再说一次。” |
| 回话         | 底部一个总的回话处；每块下面有“在这里回”，回的话记成和那块有关（输入框上方写“回在「…」下面”，可取消）；学习者刚发的话显示在屏幕下方，到主模型下一轮出屏为止                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| 以前的屏幕   | 有两屏以上时屏幕右上“以前的屏幕 ▾”列各屏（第 N 屏 · 时间）；点开只看，横条“回到现在”；不做退回                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| 旧版的学习   | W10 之前开的学习对话照旧按消息流显示，只看；底栏“这次学习是旧版开的，只能看；要接着学，请回项目另开一次”与“搁着，以后再学”；旧页面不显示                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| 参照         | Claude.ai 对话页；单子像项目里的“说明”折叠条                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
