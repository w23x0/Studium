## 批 2a 接口（原文与出处；类型在 `src/shared/protocol.ts`，均要带口令；书名、文件都用查询参数，URL 编码）

| 方法 路径                                                                 | 返回 / 做什么                                                                                                                                     |
| ------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| GET `/api/library/books`                                                  | `{books:[{id, title, sections, hasOriginal}]}`                                                                                                    |
| GET `/api/library/toc?book=`                                              | `{book, title, entries:[{num, kind, title, pages?, file?, chapter, level?, pdfPages?, note?, examples?}]}`；`file` 空 = 没有独立正文的章          |
| GET `/api/library/section?book=&file=[&from=&to=]`                        | `{bookTitle, entry?, totalLines, from, to, lines:[{n, text}], prev?, next?}`；行号 = `read_source` 印的行号；`prev / next` 是目录顺序里的邻近小节 |
| GET `/api/library/search?q=[&book=&limit=]`                               | `{query, hits:[{book, bookTitle, file, num, title, line, snippet, pdfPage?}], total}`；词用空白隔开，须同时出现在同一段                           |
| GET `/api/library/page?book=&page=`                                       | `{available, canRender, imageUrl?, blocks:[{type, bbox, text?}], anchors:[{pointId, pointName, quote, bbox?}], note?}`；page = 原 PDF 页（1 起）  |
| GET `/api/library/page/image?book=&page=[&bbox=x0,y0,x1,y1]`              | 原件页面 PNG（pdftoppm 渲染，缓存在数据目录）；`bbox` 只取那一块；带 `?token=` 可直接做 `<img src>`；没有原件 404、本机没有 pdftoppm 501          |
| GET `/api/library/locate?book=&file=&from=[&to=]`                         | `{locations:[{line, page, bbox}]}`：小节里的行在原件上的位置（按文字比对 content_list 块，比不出的行不返回）                                      |
| POST `/api/library/citations` `{text}`                                    | `{citations:[{raw, start, end, book, file, from, to, resolved, problem?, bookTitle?, section?, pages?, pdfPages?, lines?, location?}]}`           |
| POST `/api/library/reports` `{book, file, from, to?, kind?, text, page?}` | 201 `{report}`；kind = 转录错 / 公式错 / 定位错 / 其他（默认其他）；带报错当时的原文快照                                                          |
| GET `/api/library/reports[?book=&file=]`                                  | `{reports}`                                                                                                                                       |

位置框 `bbox` = `[x0, y0, x1, y1]`，各 0–1000，占整页宽 / 高的千分比，原点在页面左上角（MinerU content_list 坐标，M08 锚点同）；界面按图的实际宽高乘 / 1000 即像素位置。

教材出处标记：`【教材|书名|小节文件|L起行-止行】`（单行 `L12`；`｜` 与 `|` 都认），格式定义与解析在 `src/shared/citation.ts`（`parseCitations` / `formatCitation`）；界面拿回复文字 POST `/api/library/citations` 得到结构化数据。选择卡出处里“书名/文件:行号”回查后在 `SourceView` 里 `resolved:true` 并带 `book / from / to / lines`。模型工具：`search_textbook`（闭环 / M05 / 守卫 / 畅谈），`read_source` 结果末尾附现成的出处标记。
