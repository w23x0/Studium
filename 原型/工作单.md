## 批 1a 接口（界面读写用；类型都在 `src/shared/protocol.ts`，均要带口令）

| 方法 路径                               | 返回 / 做什么                                                                                                   |
| --------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| GET `/api/loops/:id/evidence`           | `{loop}`：状态、开场单子、守卫每次判定（理由、引用行 + 原文、模型、触发的收口申请、挂着的异议）、诊断、全部异议 |
| GET `/api/cards/:cardId`                | `{card}`：每个选项的单子 + 出处（回查到点 / 子句 / M09 记录 / 闭环原文行；书里的只给定位，批 2 才读原文）       |
| GET `/api/projects/:mainId/overview`    | `{overview}`：`groups` = inProgress · awaitingChoice（带完整选项）· closed · unclosed                           |
| GET `/api/m09/records[?loop=<闭环 id>]` | `{records}`：形成记录 + 依据行原话 + 模型 + 异议                                                                |
| GET `/api/m10/records[?loop=<闭环 id>]` | `{records}`：教法记录，同上                                                                                     |
| GET `/api/m15/state`                    | `{current?, records}`：当前状态页 + 底层记录（来源、范围、依据行原话、模型、异议）                              |
| GET `/api/m08/points[?q=关键词]`        | `{points, empty}`：全部 / 搜到的点（标书给的 / 模型补的 / 未审，锚点带页与位置框）                              |
| GET `/api/m08/points/:id`               | `{point, into, from}`：点 + 进入它 / 从它出发的子句                                                             |
| GET `/api/m08/clauses/:id`              | `{clause}`                                                                                                      |
| POST `/api/sessions/:loopId/objections` | 对守卫判定提异议 `{line, text}` → 201 `{objection}`；闭环开着 = 原话进闭环（`inLoop`），之后可再 close-request  |
| POST `/api/objections`                  | 对 M09 / M10 / M15 记录提异议 `{kind, recordId, text}` → 201 `{objection}`                                      |
| GET `/api/objections[?kind=&record=]`   | 异议存放处里的异议                                                                                              |
| GET `/api/sessions/:id/model`           | `{model:{name, known, note?}}`：实际执行的模型，取不到时 `known:false` + 兜底说明                               |
| GET `/api/disclosure`                   | 内容送往哪个服务、通道、会送出的内容、各类会话的模型与强度                                                      |
