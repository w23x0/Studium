# 原型 · 写代码的地图

> 在 `原型/` 里写代码时读这页。产品结论与技术设计不在这里：设计以 `../docs/设计/` 为准（会话怎么跑看 `会话/`，
> 存什么看 `记录/`），选型以 `../docs/设计/实现选型.md` 为准。
> 进度看 `工单/README.md` 与 `工单/进度/`。

## 规矩（每次都适用）

- 改完跑 `npm run check`（类型 · lint · 格式）；不过不算完。Stop hook 也会跑它。
- 不写自动测试、不用假模型（10-23 产品负责人定：假模型只证明程序按剧本走，证明不了真模型能用）；做完不专门验证，不截图、不另起服务、不跑真模型，出了问题产品负责人用到时会说（11-04）。
- 模型 SDK 只能在 `src/core/model/` 的适配器里引用；界面与核心只经 `src/shared/` 相通。
- 正本 JSONL 只追加、永不改写：不写任何改旧行、删行、重排的代码；格式升级只产出新文件或派生层。
- 不写空 catch、不吞异常；确实要忽略的写明理由。

## 正本记录

每个会话一个 `var/sessions/<会话 id>.jsonl`，一行一条，行号 = 引用地址。类型见 `src/shared/records.ts`：
`session_opened`（旧数据里含单子 `ticket`）· `user_message`（异议带 `objection`，附图带 `images`）· `assistant_message` ·
`model_raw`（适配层吐出的原始消息，含思考块）· `model_session`（续接凭据）· `model_used` · `turn_failed`（服务交回的报错句记在 `notice`，不记成 `assistant_message`）·
`program_fact` · `tool_call` · `sandbox_action`（沙盒里的读 / 写 / 跑命令；`tag` 由程序按路径打：`教学工具:<文件名>`）·
`close_requested`（10-31 起模型申请时带收尾那一句 `summary`：这次做了什么、停在哪；学习者点“我觉得懂了”那条没有；11-05 起学习页没有这个按钮，学习者点的那种只在旧数据里）· 旧数据 `guard_verdict`（含 `understanding` 与实际执行的 `model`，10-31 起不再产生，照旧能读、能显示、能提异议）· `loop_ended` `after_loop_step`
（恢复 `loop_resumed`；旧数据：搁置 `loop_shelved`，11-04 起界面与模型都不再触发）·
`project_goal` `project_title`（项目名随方向变，开头那行不改）· `turn_context`（这一轮输入前附上的事，有才记：学习者停止了生成 / 删了讨论串、主对话新接上时的“现在几点 + 最近的消息”、学习对话攒着的组件操作；`forLine` 指那轮输入的行）·
`task_opened` `talk_ended`（畅谈）· 讨论串（`thread_closed` `thread_reopened` 结束与重开，`thread_title` 自起标题）· `project_material` `project_deadline`（项目资料与期限）· 旧数据：`branch_requested`（学习对话请开分叉，W12 换成 `message_coordinator`）`conversation_pointer`（只读）·
`upload_routed`（上传的一份分到资料还是学过的、归谁，改判再记一条）· `material_owner`（资料改归属，W11）· `project_asked`（别的会话来问这个项目的主对话，记问答，不进它的上下文，W11 试验）· `project_instructions`（项目说明，每改一次一条，当前 = 最后一条）·
学习页（`component_version` · `component_action`（学习者）· `component_error`；旧数据，只读：`layout`（10-29 区域图的布局版本、小模型耗时、打回次数）`screen` 第几屏与清单指纹 · `component_report`（框架另开的子代理交回的）· `screen_note`（框架回主模型的一句）；`session_opened.screens` 标按屏幕跑，`user_message.replyTo` 回在某块下；竖流学习页（10-29 #74 试验）：`session_opened.page = 'stream'`、`user_message.quotes` 选中页面上几处再说（11-05 #92 起可多处，带前后几个字 `before` `after`；旧行是单个 `quote`，读时用 `quotesOf`）、`component_action.state` 组件“现在的状态”（只留最后一次），页面改动就是成功的页面工具 `tool_call`）·
`context_used`（每轮跑完时主模型上下文多大、这一轮输出多少，所有会话，10-29 起；W14 起输入框下方显示最新一条，使用情况面板用它的 output）·
W17（试验中）：`message_tidied`（学习对话对学习者一行话的整理，`line` 指那句，同一行以后写的为准；原话不动，渲染成 `整理（` 开头的一条）·

## 真模型

走产品负责人本机的 Claude 订阅：本机先用 `claude` 登录一次，再 `npm start`。Agent SDK 不读 CLAUDE.md 与设置
（`settingSources: []`）、系统提示用我们自己的；思考概要（`display: 'summarized'`）存进 `model_raw`，导出上下文时看，界面不显示。学习对话开六个内置工具（通用读写、搜索、命令）并套沙盒，另放开 WebSearch / WebFetch（W12 §2；沙盒里的命令照旧不联网）；导入会话同样带沙盒（只读原件、可写正文、不联网）；谈方向放开 WebSearch / WebFetch；主对话不读本机、不给内置工具（W12 §3.2）。会话之间发话走 `hub.message`：马上返回，对方这一轮跑完回的话送回发话方；不再用 SDK 中途插话，学习者生成中途说的话排到这一轮之后；停止走 SDK 的 `interrupt`。我们自己的密钥（`MINERU_TOKEN` 等）不进模型那边的环境。它自己的会话文件存在
`~/.claude/projects/` 下以数据目录命名的文件夹里，只作续接用；我们的正本是 `var/sessions/*.jsonl`。

## 本机试用

1. `cd 原型 && npm ci`；本机 `claude` 登录过一次；Linux 还要装 `bubblewrap` 与 `socat`（`sudo apt install bubblewrap socat`），没装时学习对话与导入会话一开就失败（沙盒起不来），macOS 不用装。
2. `npm start`，打开终端打印的地址。
3. 主对话里说想学什么 → 它开谈方向的讨论串（卡片在对话里），谈定后回项目对话说“下一步学什么” → 它开学习对话（学习对话先自己读以前的记录再开口；模型的工作区在 `var/sandbox/<学习 id>/工作区/`，是它自己的草稿）→ “我觉得懂了”（学习对话觉得可以收就写收尾那一句，觉得还差就直接说；它也可自己提出收尾）→ 学习者确认“学完了” → 主对话说一句结果；学完的学习再说话就重开。
4. 资料把文件 / 文件夹拖进项目对话的输入框上传（10-29 起没有项目页，网页链接、代码仓库的手动加入口也没了）；PDF 要先配 `MINERU_TOKEN`，本机装 `pdfinfo`（poppler-utils）；学习者给本机路径时主对话用 `import_local` 让程序拷进来。

## 正式使用与更新（10-23 起）

产品负责人开始拿原型真学，数据不能再“删掉重来”。规矩如下，不加发版流程：

| 规矩           | 做法                                                                                                                                                                                                                                                                 |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 数据不丢       | 改了记录形状（`src/shared/records.ts`、各存放处的行格式、目录结构）就把 `DATA_VERSION` 加一，并在 `src/core/log/data-dir.ts` 的 `MIGRATIONS` 写这一步迁移；启动时程序先整份备份到 `<数据>-备份/` 再升级。只加可选字段、读侧兼容旧行的，不算改形状                    |
| 改了什么有处查 | 合进 `main` 的改动只要使用者能感觉到（新功能、行为变了、要重新登录 / 装东西、数据升级），在 `更新记录.md` 最上面加一行；纯重构、文档不记                                                                                                                             |
| 更新怎么做     | 本机：`git pull` → `npm ci`（依赖变了才需要）→ `systemctl --user restart studium`；想保险先 `npm run backup`                                                                                                                                                         |
| 核心怎么跑着   | 10-28 起由用户级 systemd 托管（`~/.config/systemd/user/studium.service`，跑 `npm start`，开机自起、崩了重启；额外环境变量放 `~/.config/studium.env`）；日志与带口令的地址看 `journalctl --user -u studium`；别再在终端另起 `npm start`（数据目录锁会挡住后起的那个） |
| 手机上用       | 手机开 Tailscale，打开 `https://w23x.taild165aa.ts.net/?token=<var/token 里的口令>`（`tailscale serve` 把 443 转到本机 4317，设置重启后还在）；不上公网                                                                                                              |
