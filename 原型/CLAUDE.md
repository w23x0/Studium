# 原型 · 写代码的地图

> 在 `原型/` 里写代码时读这页。产品结论与技术设计不在这里：设计以 `../docs/设计/` 为准（会话怎么跑看 `会话/`，
> 存什么看 `记录/`），选型以 `../docs/设计/实现选型.md` 为准。
> 进度看 `工单/README.md` 与 `工单/进度/`。

## 规矩（每次都适用）

- 改完跑 `npm run check`（类型 · lint · 格式）；不过不算完。Stop hook 也会跑它。
- 不写自动测试、不用假模型（10-23 产品负责人定：假模型只证明程序按剧本走，证明不了真模型能用）；做完不专门验证，不截图、不另起服务、不跑真模型，出了问题产品负责人用到时会说（11-04）。
- 模型 SDK 只能在 `src/core/model/` 的适配器里引用；界面与核心只经 `src/shared/` 相通。
- 正本 JSONL 只追加、永不改写：不写任何改旧行、删行、重排的代码；格式升级只产出新文件或派生层。
- 不写空 catch、不吞异常；确实要忽略的写明理由。

## 会话种类

| 种类     | 日常叫法 | 提示词                                      | 何时开                                                                                                                                                                                                                                   |
| -------- | -------- | ------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `main`   | 主对话   | `main.md`                                   | 一个项目一条，学习者在这里说话；开讨论串、给讨论串发话（W12 §3，照 Claude 项目的协调者）；不读本机、不在沙盒里跑                                                                                                                         |
| `loop`   | 学习对话 | `loop.md`（`{{页面}}` 接 `loop-stream.md`） | 主对话 `start_thread` 开（W20 起只开这一种）；自己读记录，开场只定从哪接（#104 试验）；方向（学这个能做什么）由它判断何时主动谈；在沙盒里跑、能联网；结束照讨论串（`close_thread`，学习者也能在讨论串栏点），结束后能重开（W12 §2、W19） |
| `import` | 导入处理 | `import.md`                                 | 导入的原件里有不是纯文字的文件、学过的要写总结、上传归哪边拿不准时程序在后台开（W11 试验；W12 §1.6 起它判归哪边、归谁）；界面不显示                                                                                                      |

种类名单在 `src/shared/records.ts` 的 `CONVERSATION_KINDS`（提示词装载从它取；`STUDIUM_PROFILES` 的可用键就是它，见 `src/core/model/profiles.ts`）。

磁盘上还有旧种类（`talk` `guard` `nav` `state` `pedagogy` `retrieve` `output` `find` `editor`）的正本：文件不动，派生索引跳过，界面不列。其中只有旧谈方向（`talk`）模型还读：里面有学习者的长期想法（`src/core/goal.ts`）。

## 正本记录

每个会话一个 `var/sessions/<会话 id>.jsonl`，一行一条，行号 = 文件行号 = 引用地址（`cited`、`cross_note` 的出处都靠它，这些文件只追加，不改写、不挪动）。类型见 `src/shared/records.ts`：
`session_opened`（`page = 'stream'` = 竖流学习页；没有 = 更早的学习，只读）· `user_message`（`quotes` = 选中页面上几处再说的，带前后几个字）· `assistant_message` ·
`model_raw`（适配层吐出的原始消息，含思考块）· `model_session`（续接凭据）· `model_used` · `context_opened`（当时实际给的系统提示词与工具）· `turn_failed`（服务交回的报错句记在 `notice`，不记成 `assistant_message`）·
`program_fact` · `tool_call` · `sandbox_action`（沙盒里的读 / 写 / 跑命令）·
`turn_context`（这一轮输入前附上的事，有才记：学习者停止了生成 / 删了讨论串、主对话新接上时的“现在几点 + 最近的消息”、学习对话攒着的组件操作；`forLine` 指那轮输入的行）·
`project_title`（开头那行不改）· `task_opened` · 讨论串（`thread_closed` `thread_reopened` 结束与重开；`thread_closed.by` 有 `learner` = 学习者在讨论串栏点的；`thread_title` 自起标题）· `project_material`（项目资料）·
`upload_routed`（上传的一份分到资料还是学过的、归谁，改判再记一条）· `material_owner`（资料改归属，W11）· `project_asked`（别的会话来问这个项目的主对话，记问答，不进它的上下文，W11 试验）· `project_instructions`（项目说明，每改一次一条，当前 = 最后一条）·
学习页（`component_version` · `component_action`（学习者；`state` = 组件“现在的状态”，只留最后一次）· `component_error`；页面改动就是成功的页面工具 `tool_call`）·
`context_used`（每轮跑完时主模型上下文多大、这一轮输出多少，所有会话，10-29 起；W14 起输入框下方显示最新一条，使用情况面板用它的 output）·
W17（试验中）：`message_tidied`（学习对话对学习者一行话的整理，`line` 指那句，同一行以后写的为准；原话不动，渲染成 `整理（` 开头的一条）·
W13（试验中）：`cross_note`（跨次记录的一条：学到哪 / 学习者说过的长期的话 / 撤回，记在写它的会话里，编号 = `会话 id:L行号`，改主意、撤回都是新记一条用 `replaces` 指旧的）·
W12：`thread_message`（别的会话发来的话，带附上的学习者原话 `cited`，`reply` = 回话；W14 起 `attached` = 程序附给模型、不算对话原文的内容（开场的沙盒说明、项目说明、跨次记录、上次学习的整份原文），发给模型时排在学习者这次的话前面（按时间，#104 试验），`renderTranscript` 与给人、别的对话看的地方都不带）`thread_deleted`（学习者删了讨论串，记在主对话）`turn_stopped`（学习者点了停止）`message_edited`（学习者改最后一句 / 主对话改自己上一条）`message_reaction`（主对话回的表情）。
加类型只能加，不改旧字段的意思。

旧数据：磁盘上还有早就不再产生的类型（`screen` `close_requested` `guard_verdict` `choice_card` …），程序不认，读到就跳过（不能抛异常），文件不动。程序还读的只有这几样：`loop_ended`（算已结束）、`subagent_result` 与 `user_message.replyTo`（旧学习的对话原文里有）、`project_goal`（方向目标，`src/core/goal.ts`）、没有 `attached` 的 `thread_message` 旧行（程序附的内容拼在 text 末尾，渲染时去掉）。

## 命令

| 命令                                                                  | 做什么                                                                                                                                                                                                               |
| --------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

## 真模型

Codex / GPT 的配置、续接、执行环境与验证边界见 [`Codex接入.md`](Codex接入.md)；设置中选择内核，首次启动默认仍是下面的 Claude；对话输入区选择模型 / 强度并查看上下文。登录入口与配置优先级同见该文档。

走产品负责人本机的 Claude 订阅：本机先用 `claude` 登录一次，再 `npm start`。Agent SDK 不读 CLAUDE.md 与设置
（`settingSources: []`）、系统提示用我们自己的；思考概要（`display: 'summarized'`）存进 `model_raw`，导出上下文时看，学习页的过程记录也显示（11-06 试验，`src/ui/process-model.ts`）。学习对话开六个内置工具（通用读写、搜索、命令）并套沙盒，另放开 WebSearch / WebFetch（W12 §2；沙盒里的命令照旧不联网）；导入会话同样带沙盒（只读原件、可写正文、不联网）；主对话不读本机、不给内置工具（W12 §3.2）。会话之间发话走 `hub.message`：马上返回，对方这一轮跑完回的话送回发话方；不再用 SDK 中途插话，学习者生成中途说的话排到这一轮之后；停止走 SDK 的 `interrupt`。我们自己的密钥（`MINERU_TOKEN` 等）不进模型那边的环境。它自己的会话文件存在
`~/.claude/projects/` 下以数据目录命名的文件夹里，只作续接用；我们的正本是 `var/sessions/*.jsonl`。

## 本机试用

1. `cd 原型 && npm ci`；本机 `claude` 登录过一次；Linux 还要装 `bubblewrap` 与 `socat`（`sudo apt install bubblewrap socat`），没装时学习对话与导入会话一开就失败（沙盒起不来），macOS 不用装。
2. `npm start`，打开终端打印的地址。
3. 主对话里说想学什么 → 它开学习对话的讨论串（卡片在对话里；学这个能做什么、往哪走也在这里谈；学习对话先自己读以前的记录再开口；模型的工作区在 `var/sandbox/<学习 id>/工作区/`，是它自己的草稿）→ 学习对话觉得差不多了在话里说，学习者说可以或说不学了它才结束（也可在讨论串栏“⋯”里点结束）→ 主对话收到一声“结束了”；结束的学习再说话就重开。
4. 资料把文件 / 文件夹拖进项目对话的输入框上传（10-29 起没有项目页，网页链接、代码仓库的手动加入口也没了）；PDF 要先配 `MINERU_TOKEN`，本机装 `pdfinfo`（poppler-utils）；学习者给本机路径时主对话用 `import_local` 让程序拷进来。
