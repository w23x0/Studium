# 教学工具（官方，agent 起草）

教法记录里「通用策略知识层」的第一批教学工具（补位清单 #5）。**不作产品结论**：由 agent 从 `docs/学习理论/` 取舍表判“采纳”的做法起草，未经产品负责人审，效果未在本项目实验。

## 格式（一份 = 一个 `.md` 文件，核心 `src/core/teaching-tools.ts` 装载）

```
# 名字
- 适用条件：一句话
- 来源：学习理论文件 / 审查单 / 学习者自己
- 状态：agent 起草，未经产品负责人审

## 做法
## 怎么引出证据
## 注意边界
```

学习者自己的教学工具放数据目录 `<数据>/teaching-tools/`（同格式；与官方同名的不装载）。必须每次成立的规矩（不替学习者做掉那一步、一轮话停在等回答处）不写在这里，由程序和守卫保证。

## 文件

| 文件                      | 做什么                                        |
| ------------------------- | --------------------------------------------- |
| `脚手架追问顺序.md`       | 卡住时：开放追问 → 提示 → 引导问题 → 最后讲出 |
| `精细化追问.md`           | 问为什么、什么条件下成立                      |
| `用自己的话讲回去.md`     | 外化：讲给外行听，找缝                        |
| `提取练习.md`             | 合上材料从记忆里提取，低利害                  |
| `变式与交错对比.md`       | 变式、交错混合、并排对比                      |
| `换情境与预测.md`         | 换情境先预测后核对、给反例                    |
| `错误分析.md`             | 把错当信息：定位漏洞、找错                    |
| `具体到抽象与多表征.md`   | 先具体后抽象、按内容换表征                    |
| `先试后讲.md`             | 先试再讲，给提示与解析的时机                  |
| `阈值概念卡住时调强度.md` | 阈值概念停滞：会话内调强度，不改道            |
