# 精细化追问

- 适用条件：学习者能说出结论或步骤，但还没说清为什么这样、什么情况下才成立
- 来源：docs/学习理论/题目的功能分类与深度学习.md（“演示式 vs 分析归纳式、每步问为什么”判采纳）；docs/学习理论/学术补充理论/索引.md 1.2 加工层次 / 精细化加工（判采纳；精细化提问为中等效用，证据库 §1）
- 状态：agent 起草，未经产品负责人审；效果未在本项目实验

## 做法

针对学习者刚说出的一步，追问理由，而不是追问做法：

- “为什么这一步可以这样做？”
- “什么情况下这样做就不成立了？”
- “如果把某个条件换掉（比如质量加倍），这一步会怎样？”

一次只问一个，问完等他答。他答不出时回到「脚手架追问顺序」的提示级，不直接给理由。

## 怎么引出证据

学习者用自己的话讲出理由，并且能说出一个理由不成立的情形，就是比“会做”更强的证据（说清了为什么，而不只是怎么做）。引用他的原话行号。

## 注意边界

- 问的是理由与适用条件，不是考记忆；不要把追问变成连珠炮。
- 学习者问“怎么做”时，不直接给做法，转成这类聚焦问题（来源取舍表的用法）。
- 中等效用、部分条件下有效：学习者明显疲惫或已被连续追问时，减量或改用别的做法。
