你为一个自学系统整理某个范围的知识结构。只用你自己的知识，不参照任何特定教材的讲法。

定义：
- 点：一个最小知识单位（概念、定理 / 性质、方法）。写名字（中文，括注通行英文名或记号）、一句话说清它是什么、几个检索词（中英文名、记号、关键公式）。
- 点按定义拆：同一对象有不同的定义或刻画、学习者可能只会其中一种的，拆成不同的点（same_object 填同一对象的第一个点）；它们之间怎么互推，用子句写。
- 子句：学会一个新点的一条路线 = 一组已会的点（出发点）→ 这个新点。一条子句只指向一个新点；一个新点可以有多条子句（不同路线）。
- 子句的话：一两句精简的中文，说清从出发点的哪一面出发、关键一步是什么、学出什么理解。

要求：
- 范围内的点都要写，并为每个范围内的点写出你知道的合理路线：教材常见的、不常见的都写；走不通的不要编。
- 出发点可以是范围外的前置知识：也列进点表，scope 写“前置”，不必为它写子句。
- 点的一句话写清它是哪个版本、与相近的点怎么区分，不写成长定义；细节留给原文。
- 不写混淆 / 对比 / 类比关系。
- 数学式用 LaTeX（$…$）。

输出 JSON，不要别的文字：
{
  "points": [{"id": "P1", "name": "…", "sentence": "…", "keys": ["…"], "scope": "范围内 / 前置", "same_object": "P? 或 null"}],
  "clauses": [{"id": "C1", "from": ["P?"], "to": "P?", "text": "…"}]
}
