你对照一本教材某一节的原文，审核一份知识结构清单（点 + 子句），并回扫补上书里有、清单里没有的点与路线。清单起初由模型凭自身知识生成，前面各节审核时补进来的条目也在里面（标了来源）。原文每行开头是行号和制表符。

定义：
- 点：最小知识单位（名字 + 一句话）。同一对象有不同的定义或刻画、学习者可能只会其一的，是不同的点。
- 子句：学会一个新点的一条路线 = 一组出发点 → 一个新点，加一两句话：从出发点的哪一面出发、关键一步、学出什么理解。

只看本节原文，做五件事：

1. 点落位（points）：清单里的点，本节在讲它（引入、定义、陈述或证明它）的，给摘录，判“一致”或“书的定义不同”。书按另一种定义或刻画引入它的，判“书的定义不同”，并把书的那个点写进 new_points（split_of 填清单里那个点）。本节没讲、只顺带提到的不列。

2. 子句判定（clauses）：只列本节原文与之相关的子句，判两种：
   - 书给的：书在本节从这组出发点、经这一面走到这个新点。与清单那条只差一点时按这把尺：差别那一步需要的东西在不在这条子句自己声明的出发点与面里——在，算同一条，差别写进 note；不在，就不是同一条，清单那条不判书给的，书自己那条写进 book_clauses。
   - 零件：书只露出这条路线的零件（提到结论、用到其中一步），没有走完整条路线。挂上摘录，note 写缺了什么。
   方向相反（书从另一头推）、出发点不同、用到的面不同，都不是同一条：书自己那条写进 book_clauses。

3. 回扫（new_points、book_clauses）：本节讲到的学习路线，凡清单里没有同一条的，都写进 book_clauses：出发点、新点（用清单 id，或 new_points 的临时 id N1、N2…）、一两句话（同子句的话）、摘录。本节在讲、清单里没有的点写进 new_points（名字、一句话、检索词、摘录）。出发点若清单与 new_points 都没有，也作为 new_points 写出（摘录可空，note 写“本节当作已知”）。

4. 别混淆（cautions）：书里明写的“别混淆 / 注意区别 / 不要以为”，挂在相关的点上，写一句话 + 摘录。不写成子句。

5. 疑似转录错误（transcription_issues）：原文是 PDF 自动转录的，可能有符号错。读到你认为是转录错误的地方，列出行号、原样文字、应是什么、理由。不要在摘录里悄悄改正。

摘录规则：照原文抄，不改写、不压缩；公式的空格与写法可以规整，符号不能改（转录错误也照抄）。行号是摘录所在行。每条不超过 40 个词。每个落位的点、每条书给的子句至少一条摘录。拿不准就写进 note。
