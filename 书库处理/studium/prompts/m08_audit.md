你对照一本教材某一节的原文，审核一份知识结构清单（点 + 子句），并回扫补上书里有、清单里没有的点与路线。清单起初由模型凭自身知识生成，前面各节审核时补进来的条目也在里面（标了来历）。原文每行开头是行号和制表符。

定义：
- 点：最小知识单位（名字 + 一句话）。同一对象有不同的定义或刻画、学习者可能只会其一的，是不同的点。
- 子句：学会一个新点的一条路线 = 一组出发点 → 一个新点，加一两句话：从出发点的哪一面出发、关键一步、学出什么理解。

做法：从书出发，按原文顺序通读本节，逐段问“书在这里讲了哪个点、走了哪条路线”，再拿去对清单。

1. 书讲的点（book_points）：本节引入、定义、陈述或证明的每个点，按原文顺序都列出：
   - 清单里有同一个点（同一定义 / 刻画）：id 填清单的点，match 填“一致”。
   - 书按另一种定义或刻画讲清单里的某个对象：id 填 null，写出书的这个点（名字、一句话、检索词），split_of 填清单里那个点，match 填“书的定义不同”。
   - 清单里没有：id 填 null，写出这个点，split_of 填 null，match 填“清单没有”。
   只顺带提到、本节没有讲的点不列。

2. 书走的路线（book_routes）：本节讲到的每条学习路线（书怎样从已会的点学到一个点），按原文顺序都列出：出发点、新点（清单 id，或第 1 项里新写的点用 tmp 编号 N1、N2…）、一两句话、摘录；same_as 填清单里与它是同一条的子句 id，没有就填 null。
   判“同一条”用这把尺：差别那一步需要的东西在不在清单那条子句自己声明的出发点与面里——在，是同一条，差别写进 note；不在，就不是同一条。方向相反、出发点不同、用到的面不同，都不是同一条。
   出发点若清单与第 1 项都没有，在第 1 项补写（摘录可空，note 写“本节当作已知”）。

3. 零件（parts）：清单里另一些子句，书在本节只露出它的零件（提到结论、用到其中一步），没有走完整条路线：列出子句 id、摘录、缺了什么。与本节无关的不列。

4. 别混淆（cautions）：书里明写的“别混淆 / 注意区别 / 不要以为”，挂在相关的点上（清单 id 或 N?），一句话 + 摘录。不写成子句。

5. 疑似转录错误（transcription_issues）：原文是 PDF 自动转录的，可能有符号错、字母粘连、漏字。列出行号、原样文字、应是什么、理由。不要在摘录里悄悄改正。

摘录规则：照原文抄，不改写、不压缩；公式的空格与写法可以规整，符号不能改（转录错误也照抄）。行号是摘录所在行。每条不超过 40 个词。每个书讲的点、每条书走的路线至少一条摘录。拿不准就写进 note。

点的一句话与路线的话都写精简的中文，数学式用 LaTeX（$…$）。

输出 JSON，不要别的文字：
{
  "book_points": [{"id": "P? 或 null", "tmp": "N? 或 null", "name": "…", "sentence": "…", "keys": ["…"], "match": "一致 / 书的定义不同 / 清单没有", "split_of": "P? 或 null", "quotes": [{"line": 0, "text": "…"}], "note": "…"}],
  "book_routes": [{"from": ["P? 或 N?"], "to": "P? 或 N?", "text": "…", "same_as": "C? 或 null", "quotes": [{"line": 0, "text": "…"}], "note": "…"}],
  "parts": [{"id": "C?", "quotes": [{"line": 0, "text": "…"}], "note": "缺了什么"}],
  "cautions": [{"point": "P? 或 N?", "text": "…", "quotes": [{"line": 0, "text": "…"}]}],
  "transcription_issues": [{"line": 0, "text": "原样", "should_be": "…", "reason": "…"}]
}
（book_points 里 id 为清单点时，name / sentence / keys 可省略。）
