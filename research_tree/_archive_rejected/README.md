# _archive_rejected — 已归档 / 已否决调研产出

> 2026-08-15 建立。**不是删除**，是产品裁决后从现行依据中移出，git 历史与文件均在，仅不再作为 Studium 设计依据。

## 为什么归档（产品裁决 2026-08-15）

用户确认三点：
1. **老旧范式不要**：agent 记忆层 / RAG 问答 / 知识库检索 / 上下文工程——这些是临床、办公、客服场景的产物，与「个人多教材理科学习」项目不匹配，没人做过我们这个方向。
2. **不可信研究者不要**：Context Codec（arXiv 2605.17304，作者 Trukhina/Vashkelis）资历不透明、实证薄弱（作者自述小规模诊断研究）、影响力小，不作为证据支柱。
3. **偏题不要**：K2 数学/科学表示单开专题偏题（本项目就是学理科的，数学表示即知识表示主体）。
