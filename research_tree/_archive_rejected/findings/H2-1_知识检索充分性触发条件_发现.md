# 叶子 H2-1 知识检索充分性与触发条件 调研发现
> ⚠ **已归档（2026-08-15 产品裁决）**：本卡属老旧范式（agent 记忆/RAG/知识库/上下文工程，临床办公场景），与「个人多教材理科学习」项目不匹配，已移入 _archive_rejected/，仅作历史参考，不再作为 Studium 设计依据。

> 任务 H2-1 / A=原文到手 B=二手转引 C=推断
> 调研主题：LLM 时代的知识检索——「何时该触发检索（active/adaptive RAG）」+「检索是否充分的判据」；接 V6 的 CS-RAG 反转尾巴
> 时间锚定：外部文献全部 2024-01 后（V6 种子 2506.05690/2606.25656 为已抓 A 级）

## 0. 一句话结论
**2024–2026 的 RAG 检索已从「总是检索、固定 k」成熟到「按效用/不确定性/查询难度自适应决定是否检索与检索多少」，但出现两条关键的反直觉实证：（i）「何时触发」用简单信号（不确定性分数 / 初始检索的 score 分布）常常匹敌甚至胜过学到的复杂 utility router；（ii）在固定本地模型预算下，简单固定选择（固定混合检索 + 两轮短循环）常匹敌或胜过自适应路由 + 多轮深循环——增益主要来自「跑短检索循环」而非「自适应」。** 更根本的判据出现：把 active retrieval 重述为 **utility estimation**（检索只在边际正确性变化超过 no-retrieval 答案时才有价值），并区分 **knowledge insufficiency vs ambiguity/conflict**（前者触发 RAG，后者加推理而非检索）；检索充分性不能用 recall/lexical overlap 度量（Bio-GRACE 证明），且 **temporal misgrounding**（静态 RAG 自信引用当前在用但不适用的版本，0% 命中日期适用版本）是 Studium 时序锚定红线的直接对应风险。

## 1. 父会话问题逐条回答

**Q1. 何时该触发检索？触发信号是什么？**
- 结论：2024-26 的主流是把触发建立在**模型自身的不确定性/检索效用**上，且有清晰分解。
  - **When Should Active RAG Retrieve（2607.24010）**：把 active retrieval 重述为 **utility estimation**——检索只在边际正确性变化超过 no-retrieval 答案时才有价值；分离三个单点评估混淆的问题（trigger score 排序能力 / 阈值跨期迁移 / trigger 端计算改变部署成本）。给出 budget-aware 评估工具：exact top-k utility frontier、deployable threshold frontier、conservative budget frontier、**harm audit**、cost decomposition。**关键实证：retrieval harm 非可忽略，简单不确定性或检索分数 baseline 常匹敌学到的 utility router**。
  - **Interpretable Uncertainty for Adaptive Retrieval（2607.07380）**：从 LLM 内部 hidden state 单次 forward pass 估计**两类不确定性**——**knowledge insufficiency**（知识不足，触发 RAG）vs **knowledge ambiguity/conflict**（歧义/冲突，加推理而非检索）。透明可解释，替代 opaque policy 或昂贵多步 prompting。
  - **SAGE（2608.08237）**：生产级 SLO-aware，用**初始检索自身的轻量特征**（score 分布、rank gap、lexical 信号）模仿学习决定每查询的 passage 数 k；NQ 上 P95 5s SLO 下 95% 合规 vs 静态 k=20 的 30%，跨数据集/模型泛化。
  - **GRASP（2607.10463）**：RL 训练 agent 自适应协调互补检索工具（语义搜索/关键词搜索/段落阅读），奖励联合考虑准确/grounded reading/互补搜索/turn 效率；学到可解释 skim/scan。
- 依据：2607.24010、2607.07380、2608.08237、2607.10463
- 等级：A

**Q2. 检索是否充分？充分性用什么度量？**
- 结论：**不能用 recall / lexical overlap 度量充分性**，且有反直觉证据。
  - **When Retrieval Helps and Distracts（2608.01409）**：生物医学事实核查引入 **Bio-GRACE**（金标准归一化诊断，测检索证据是否恢复参考证据的**决策收益**）；揭示**检索效用是源依赖**——PubMed 检索对 PubMed-aligned 源有帮助但对广公共卫生 claim **分散**模型；**检索 recall 与 lexical evidence overlap 对事实核查不够**。充分性 = 检索是否恢复了「没有它就做不出的决策收益」。
  - **Temporal Misgrounding in Legal RAG（2608.09393）**：**系统性检索并引用当前在用版本而适用版本是更早/更晚版本**——这是充分性的时序维度。静态当前版本 RAG：参数知识 3.0% 严格准确，RAG 2.7%，**静态 RAG 0% 命中日期适用版本却自信引用真实但不适用版本**。多版本索引端到端检索器达 98.3%。答案用**原子 ground-truth "nuggets"（regex + numeric tolerance）确定性评分，绝不用 LLM-as-judge（LLM judge 会继承它要评分的时序偏差）**。
  - **When Should Active RAG Retrieve 的 harm audit**：充分性必须显式审计「检索造成的伤害」，而非只看准确率上升。
- 依据：2608.01409、2608.09393、2607.24010（harm audit）
- 等级：A

**Q3. 自适应是否总是优于固定？检索 vs 参数化内化的边界？**
- 结论（实证）：**自适应不总是优于固定**，且**检索不是唯一/最优知识载体**。
  - **Dissecting Agentic RAG（2606.21553）**：本地 7B 上 5000 问消融，三个反直觉发现——（1）**固定混合检索（reciprocal rank fusion）一致优于规则式自适应路由（+1.8 EM）**，因为路由启发式在几乎所有 multi-hop 子问题都有的命名实体上误触发 BM25；（2）**两轮检索捕获五轮 95% 的增益，深循环无益**；（3）查询分解与 cross-encoder reranking 有统计显著但更小的增益。**结论：固定本地模型预算下，简单固定选择常匹敌或胜过自适应版本，增益主要来自跑短检索循环**。
  - **Data Quality over Capacity（2607.21861）**：文档直接 bake 进 LoRA 权重做 closed-book；**训练数据质量是 closed-book 准确率主导杠杆**（单次 curation 把准确率从 57.7% 提到 85.7%，大于任何架构改动）；15 文档上内化 adapter（84.2% recall）胜过 BM25-RAG（58.9%）甚至 gold-chunk oracle（65.6%）、延迟更低。**检索 vs 参数化内化：小语料高质量场景，内化可能胜过检索**。
- 依据：2606.21553、2607.21861
- 等级：A

## 2. 关键发现

**F1. 【When Should Active RAG Retrieve：active retrieval = utility estimation，harm audit + 边际增益判据】**
- 论断：active retrieval 重述为 utility estimation——检索只在边际正确性变化超过 no-retrieval 答案时有价值；分离 trigger score 排序 / 阈值跨期迁移 / trigger 计算改部署成本三问题；工具：exact top-k utility frontier、deployable threshold frontier、conservative budget frontier、harm audit、cost decomposition；实证：retrieval harm 非可忽略，router 排序随数据集/预算变，名义阈值会错失目标 usage，**简单不确定性或检索分数 baseline 常匹敌学到的 utility router**；评估应报 frontier + realized usage + threshold-transfer error + harm rate + cost decomposition。
- 来源：arXiv 2607.24010，abs 页 arxiv_abs_2607.24010.html；published 2026-07-27
- 原文摘录：「retrieval is valuable only through its marginal correctness change over a no-retrieval answer」；「simple uncertainty or retrieval-score baselines often rival learned utility routers」；「Budget-aware Active RAG evaluations should therefore report frontiers, realized usage, threshold-transfer error, harm rates, and cost decompositions alongside accuracy」
- 等级：A

**F2. 【Interpretable Uncertainty：区分 knowledge insufficiency vs ambiguity/conflict，单次 forward 估计触发信号】**
- 论断：从 LLM hidden state 单次 forward pass 估计两类不确定性——insufficiency（知识不足）触发 RAG，ambiguity/conflict（歧义/冲突）加推理而非检索；透明可解释，替代 opaque policy 或昂贵多步 prompting；支持可解释用户工具设计。
- 来源：arXiv 2607.07380，abs 页 arxiv_abs_2607.07380.html；published 2026-07-08
- 原文摘录：「We distinguish between knowledge insufficiency and knowledge ambiguity or conflict, and efficiently estimate these from hidden states in a single forward pass」；「RAG is triggered when knowledge is insufficient, while additional reasoning is applied when ambiguity or conflict is high」
- 等级：A

**F3. 【SAGE：SLO-aware 自适应检索，用初始检索自身 score 分布决定 k，跨域泛化】**
- 论断：生产 RAG 在严格 tail latency/成本 SLO 下；标准固定 k 忽略查询难度（易查询过检索、难查询欠服务）；SAGE 用初始检索的轻量特征（score 分布、rank gap、lexical 信号）模仿学习选每查询 k；推理期不加 LLM 调用、开销极小；NQ 上 P95 5s SLO 下 95% 合规 vs 静态 k=20 的 30%、P95 延迟降 36%、检索成本降 51%、仅失 2pp EM；单一 NQ 训练策略跨 HotpotQA/UnSeenTimeQA/四 LLM 族泛化（+45-52 点 SLO 改进）。
- 来源：arXiv 2608.08237，abs 页 arxiv_abs_2608.08237.html；published 2026-08-08
- 原文摘录：「lightweight features derived from initial retrieval (e.g., score distributions, rank gaps, lexical signals)」；「adds no LLM calls and minimal overhead」
- 等级：A

**F4. 【GRASP：粒度感知 RL 搜索策略，协调语义/关键词/段落阅读三动作】**
- 论断：agentic RAG 难在决定何时检索、词法还是语义、控制粒度防无关 token 干扰；GRASP 是 RL 框架训练 agent 自适应协调互补检索工具（语义搜索/关键词搜索/段落阅读），检索句级证据、仅在需要时扩上下文；奖励联合考虑答案准确/grounded reading/互补搜索/turn 效率；学到可解释 skim/scan（语义搜索广探索、段落阅读局部验证、关键词搜实体证据）。
- 来源：arXiv 2607.10463，abs 页 arxiv_abs_2607.10463.html；published 2026-07-11
- 原文摘录：「a reward that jointly accounts for answer accuracy, grounded reading, complementary search, and turn efficiency」；「the learned policy develops interpretable skimming and scanning behavior」
- 等级：A

**F5. 【Dissecting Agentic RAG：固定混合检索胜规则路由，两轮捕获五轮 95%，简单固定常胜自适应（反直觉）】**
- 论断：本地 7B（Qwen2.5-7B-Instruct）上 5000 问 HotpotQA 消融；全管线 EM=53.2%/F1=61.6% vs 单遍 dense 基线 EM=43.1%；三反直觉发现——（1）固定混合检索（reciprocal rank fusion）一致胜规则式自适应路由（+1.8 EM/+1.9 F1），因路由在几乎所有 multi-hop 子问题都有的命名实体上误触发 BM25；（2）两轮检索捕获五轮 95% 增益，深循环无益；（3）查询分解与 cross-encoder reranking 有统计显著但更小增益；**结论：固定本地预算下简单固定常匹敌或胜自适应版本，增益主要来自跑短检索循环而非自适应路由或多轮**。
- 来源：arXiv 2606.21553，abs 页 arxiv_abs_2606.21553.html；published 2026-06-19
- 原文摘录：「fixed hybrid retrieval via reciprocal rank fusion consistently outperforms rule-based adaptive routing」；「two retrieval iterations over the decomposed sub-questions capture 95% of the gains of five」；「most of the gain comes from running a short retrieval loop, not from adaptive routing or from many iterations」
- 等级：A

**F6. 【When Retrieval Helps and Distracts：Bio-GRACE 诊断，检索效用源依赖，recall/overlap 不够度量充分性】**
- 论断：生物医学事实核查 evidence-generation；fine-tuned LLM 是最强证据生成系统，生物医学分类器最强于纯判定；**PubMed 检索效用源依赖**——对 PubMed-aligned 源（PubMedQA/SciFact）有帮助但对广公共卫生 claim 分散模型；引入 **Bio-GRACE**（金标准归一化诊断，测检索证据是否恢复参考证据的**决策收益**）；揭示检索 recall 与 lexical evidence overlap 对事实核查不够，支撑 selective retrieval。
- 来源：arXiv 2608.01409，abs 页 arxiv_abs_2608.01409.html；published 2026-08-02
- 原文摘录：「Bio-GRACE shows that retrieval utility is source-dependent, motivates selective retrieval, and exposes why retrieval recall and lexical evidence overlap are insufficient for biomedical fact-checking」
- 等级：A

**F7. 【Temporal Misgrounding in Legal RAG：静态 RAG 0% 命中日期适用版本，须时序索引 + 原子 nugget 确定性评分（不用 LLM-as-judge）】**
- 论断：定义并量化 **temporal misgrounding**——系统性检索并引用当前在用版本而适用版本是更早/更晚版本；标准法律 RAG 把 corpus 当静态，法律问答实为时序索引检索问题；FiscalQA Pro：32,436 文章版本（93 年 1938-2031）+ 209 专家评审题（33 CGI 文章）；**静态当前版本 RAG 参数知识 3.0% 严格准确、RAG 2.7%、静态 RAG 0% 检索日期适用版本却自信引用真实但不适用版本**；多版本索引端到端检索器 98.3%、oracle-article ablation 99.1%（残差在首段 recall 非版本选择）；**答案用原子 ground-truth nuggets（regex + numeric tolerance）确定性评分，绝不用 LLM-as-judge（会继承它要评分的时序偏差）**；另发版本感知判例数据集（69,208 引用链接）。
- 来源：arXiv 2608.09393，abs 页 arxiv_abs_2608.09393.html；published 2026-08-10
- 原文摘录：「the systematic retrieval and citation of the currently in-force version of a legal article when the applicable version is an earlier or future one」；「Static RAG retrieves the date-applicable version 0% of the time, confidently citing a real but inapplicable version」；「an LLM judge would inherit the temporal bias it is meant to score」
- 等级：A

**F8. 【Data Quality over Capacity：小语料高质量，文档内化进 LoRA closed-book 胜过 RAG（检索 vs 参数化边界）】**
- 论断：文档直接 bake 进 4-bit Gemma LoRA 权重做 closed-book（无检索无上下文预算）；约 100 次训练运行（单文档到 99 文档语料）；**适配器容量充足后训练数据质量是 closed-book 准确率主导杠杆**（胜过 LoRA rank/学习率/两替代架构之和）；容量本身是硬门槛（其下任何数据干预无效）；单次 curation（缩短金答案到规范 1-6 词、删 trivia）把 15 文档准确率从 57.7% 提到 85.7%（大于任何架构改动）；15 文档上内化 adapter（84.2% recall）胜 BM25-RAG（58.9%）甚至 gold-chunk oracle（65.6%）、延迟更低；容量趋势（rank 须随语料增）与 rank-学习率耦合（初误诊）。
- 来源：arXiv 2607.21861，abs 页 arxiv_abs_2607.21861.html；published 2026-07-23
- 原文摘录：「training-data quality is the dominant lever on closed-book accuracy, outweighing LoRA rank, learning rate, and two alternative architectures combined」；「the internalized adapter (84.2% recall) beats a BM25-RAG pipeline with a base reader (58.9%) and even a realistic gold-chunk oracle (65.6%) at lower latency」
- 等级：A

## 3. 对决策点的输入
- 可移植模式 = **「检索触发 = utility/不确定性驱动，但要先做 harm audit 与成本分解；充分性 = 决策收益恢复度（非 recall/overlap）；自适应须证明胜过简单固定 + 短循环基线；时序语料必须版本索引」**。
- **与 Studium 时序锚定红线的直接交叉点（F7 temporal misgrounding）**：Studium「机械信号只定向不结案」「锚点=原文对应」红线在 RAG 时代对应「temporal misgrounding」风险——静态 RAG 会自信引用真实但不适用版本，**LLM-as-judge 会继承它要评分的时序偏差**，所以充分性判定须用原子 nugget 确定性评分（regex + numeric tolerance）而非 LLM 判官。这正是 Studium 既有「向量只定向不结案」「证据边不数值化」红线在检索语境的强化。
- **与 H3-3（承诺级可验证压缩）共振**：F7 的「原子 nugget」+ F6 的「Bio-GRACE 决策收益」都是把检索充分性落到「可机械验证的原子」而非连贯摘要——与 Context Codec 的 round-trip recoverability 同源。
- **接 V6 尾巴**：V6 已挖到 CS-RAG 反转（检索在某些场景反而降质）、LightRAG 混合形态、知识新颖度判据；H2-1 把「何时检索 / 检索是否够」坐实为 utility estimation + harm audit + 源依赖效用，补全 V6 的触发条件侧。

## 4. 与范围/红线的冲突张力
- 无红线冲突。切分边界：聚焦「检索触发 + 充分性判据」，不展开向量索引内部（BM25 vs dense 的召回工程细节留给检索实现）、不展开 LoRA 训练工程（F8 只取「内化 vs 检索」边界结论）。
- F5（简单固定胜自适应）与「自适应是先进」直觉张力——已如实标 A 实证，非冲突而是对盲目自适应的警示。

## 5. 未决与风险
- F5 的「简单固定胜自适应」是在**固定本地 7B 预算 + multi-hop QA** 的特定设置；大模型/其他任务是否反转未确认 → 标 C 悬置。
- F2 的 hidden-state 不确定性估计依赖模型内部访问，闭源 API 不可用 → Studium 若用闭源模型，触发信号须退到检索分数/外部启发式（F3 SAGE 路径）。
- F7 是法律单一领域；temporal misgrounding 在科研文献（arXiv 版本演进）的普适性未确认 → 标 OPEN（但机制普适：凡有时序版本的语料都适用）。

## 6. 建议的下一步
- H2-2 继续挖检索失败模式（毒化/对抗/过时/幻觉接地），F6/F7 已给种子（源依赖效用、temporal misgrounding）。
- 把 F7 的「原子 nugget 确定性评分 + 不用 LLM-as-judge」写进 Studium 锚点校验的形式化注脚（与既有 [[anchor-verification-blind-spot]] memory 交叉——LLM 判官会继承偏差，呼应 grep 逐字校验的必要性）。
