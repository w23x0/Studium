## 0. 一句话结论
2024–2026 数学/科学知识表示的主范式已从「静态载体选型」（形式化库/本体/KG）迁移为「表示即流程」：**形式化目标（Lean 语句/证明）成为机器可校验的权威表示，autoformalization（自动形式化）是把非形式知识转换成这种表示的流水线，LLM agent 在其中扮演重建理论、发现依赖、判定命题的角色**；同时，内部表示研究（format-agnostic reasoning subspace、fluid reasoning representations）证明数学知识在 LLM 隐藏层里以跨格式的概念子空间而非符号串存在，这为 Studium 提供了「载体可机器校验 + 关系图必须可构造/可发现 + 公式锚点要维度/公理接地」三个可移植模式，并对 V2（MMK 成对理论图）与 V3（MaRDI 成对本体）形成实证修正——成对图约束不足以表示涌现性科学知识，2026 年出现了超图/高阶知识表示的直接证据。

## 1. 父会话问题逐条回答

### Q1. 2024–2026 数学/科学知识如何在 LLM 时代被表示与组织？哪些超越老形式化库/老本体的新范式？
**结论**：出现四类超越老静态载体的新范式（全部 A 级，均有 arXiv 摘要原文到手）：
1. **形式化目标即权威表示（Formal-target-as-truth）**：知识不再「存在库里等检索」，而是被组织成 Lean 4 可编译的语句/证明目标，并配自动形式化流水线。实证：FormalMATH（2505.02735，5,560 道已机械验证的 Lean4 题，含 human-in-the-loop autoformalization + 多 LLM 语义校验 + 否定式反证过滤，保留率 72.09%）；Formal Conjectures（2605.13171，2,615 条研究级形式化命题，含 **1,029 条开放猜想**，作为「零污染的 evolving benchmark」）；CAM-Bench（2605.17255，1,000 道计算/应用数学 Lean 目标，配 **dependency-recovery pipeline** 从教材上下文重建局部定义/引理）。
2. **理论重建工作流（Theory-reconstruction workflow）**：大尺度形式化不是翻译单条语句，而是从异构文献「重建一个连贯理论」——显式处理四类困难：隐式依赖发现、源缺陷修正、语义保真、跨源错位调和。实证：FormaTheoria（2608.10894，AI 协调的端到端工作流，扩展到有限单群分类的 Bender–Suzuki/Feit–Thompson 等大段互依赖群论，Lean 机器校验，保留 provenance 与审查门控）。
3. **结构化/可执行/高阶知识图（Structured, executable, higher-order knowledge representations）**：老 KG/本体是成对三元组，被证明对涌现性科学行为表达不足。实证：Higher-Order Knowledge Representations（2601.04878，**超图**知识表示，1,100 篇生物复合材料文献建成 161,172 节点/320,201 超边、幂律指数≈1.23，节点交集遍历让 agent 跨语义远距概念搭桥——cement 的典型例句「cerium oxide→PCL 支架经 chitosan 中间体」）；Executable Knowledge Graphs xKG（2510.17795，以论文为中心的「可执行」知识库，内嵌代码片段+技术洞见，多粒度检索，接入三套 agent 框架在 PaperBench 上 +10.9%）；SciAgents（2409.05556，大规模本体论 KG + LLM 多 agent + 原位学习用于材料发现）。
4. **语料涌现式共识表示（Corpus-emergent consensus representation）**：用 LLM 从大规模文献抽取结构化知识，而非手工维护本体。实证：2606.07570 用 ~18,000 篇高被引高温超导论文构造连接竞争机制/材料族/证据模态/引文关系的 KG，LLM 抽取的表示「recover coherent and physically interpretable structures」，且对 prompting/decoding/模型扰动稳健；SCALE（2608.07254）用 LLM+嵌入+社区发现给 OpenAlex 分类法加「科学概念」层——概念作为稳定组织单元。

**依据与等级**：上述 8 条发现全部为 A 级（curl 抓到 arXiv 官方 abs 页并核对标题/日期/摘要）。日期均在 2024-09 至 2026-08。

### Q2. 数学推理/证明的表示：仍形式化类型论，还是转向 NL+检索、神经符号、向量/图表示、Lean/Coq 的 LLM 辅助新形态？2024-26 实证？
**结论**：形式化类型论仍是**校验侧的地面真值**，但已不是唯一表示层；2024-26 的实证走向是「**双轨融合 + 隐藏表示**」：
1. **形式化类型论（Lean）仍是终审裁判，但消费方式变成 RL/agent 流水线**：DeepSeek-Prover-V2（2504.21801，Lean4，MiniF2F 88.9%、PutnamBench 49/658）；Seed-Prover 1.5（2512.17260，88% PutnamBench、80% FATE-H、33% FATE-X，**9 小时内解出 2025 Putnam 12 题中的 11 题**，agentic RL + 测试时缩放）；AlphaGeometry2（2502.03544，神经+符号混合，专用表示语言扩展到线性方程/运动/非构造问题，IMO 2000–2024 几何覆盖率 66%→88%，整体解出率 84%，并随 AlphaProof 达 IMO 2024 银牌）。
2. **非形式与形式显式互操作（hybrid informal↔formal），而非二选一**：HERMES（2511.18760，首个显式「非形式推理↔Lean 形式证明」交替的工具化 agent，中间形式检查防推理漂移 + 跨步证明连续性内存，AIME/HARDMath2 上 accuracy +40% 且推理 FLOP 减 80%）；DeepSeek-Prover-V2 同一模型内整合非形式+形式推理（「informal 与 formal 的差距在显著收窄」，AIME 2024-25 中 DeepSeek-V3 多数投票 8/15 vs 其形式化 6/15）；Symbolic Informalization（2606.16893，Dedukti 作为 Agda/Lean/Rocq 之间的 hub + GF 语法框架，把形式数学可靠地「非形式化」回自然语言——反向表示通道）。
3. **研究级/开放猜想的验证闭环（verified discovery）**：2606.29687 用 LLM（Claude Fable 5）+ Lean 4 端到端机器验证了悬置十余年的 FGG（QAOA 近似比）猜想——「模型发现隐藏动力学对称性并借邻域工具」；2604.03789（Rethlas 非形式推理 agent + Archon 形式验证 agent，LeanSearch 检索，解决交换代数开放问题并 Lean 验证）；2607.07779 立场论文系统论证从「solver」转向「research agent」，并把 **relational structure、数学探索、工具生态、人机协作**列为核心限制；2510.11986 指出 autoformalization 之前还缺「**conjecturing**（先猜想结论/界）」，建 ConjectureBench。
4. **证明步骤的「过程性」表示**：ToMap（2607.11307）把整篇证明的 autoformalization 结构化为 Decomposer-Formalizer-Prover 流水线，原子化自洽证明单元是成败瓶颈，用形式验证进度 + 语义 rubric 定义 Pareto 前沿引导分解演化（ProofFlowBench 上比此前最佳 +19.0%）；2606.09449 提出**无金标 reference-free 的 proxy-judge 理论**：用「按轴属性检查向量」替代精确匹配判定 autoformalization 对错，并证明有界判官噪声下期望内在差距几何收敛——即「判定命题是否成立」本身变成可计算的表示部件。
5. **向量/隐藏层表示（interpretability）**：2605.09496 发现 LLM 中层存在 **Format-Agnostic Reasoning Subspace（FARS）**——10 维概念子空间同时承载英文散文/数学记号/Python 三种表层形式，替换这 10 维可保留 90–96% 输出；且存在「**declarative vs procedural**」不对称（数学表示与散文更兼容、与代码差异最大）。2602.04843 发现 extended thinking 使动作/谓词概念的隐藏表示在推理轨迹中收敛到非混淆概念方向（Fluid Reasoning Representations）。→ 数学知识确实以向量/子空间形态存在，而不仅是符号串。

**依据与等级**：全部 A 级。2605.09496/2602.04843 用 1.6B–8B 开源模型，对前沿闭源模型的普适性仍是推断（C 级边界）；AlphaProof 博客为厂商一手声明（A 级但非同行评审）。

### Q3. 对 Studium 理科知识载体（M08 概念关系、公式/定理锚点）的可移植模式？V1/V2/V3/V7 哪些被推翻或修正？
**结论**（可移植模式，均带 A 级来源）：
- **P1 锚点校验可部分机械化，但要用「语义校验」而非逐字比对**：FormalMATH 的「多 LLM 语义校验 + 否定式反证过滤」把人工审校前保留率提到 72.09%（2505.02735）；proxy-judge 把「判断命题是否匹配」做成按轴属性向量并证明其收敛性（2606.09449）。→ 对 Studium M08 公式/定理锚点：锚点本身无法全部机器证明，但「锚点↔自然语言命题」的对应可以用语义代理校验 + 反例过滤半自动化。
- **P2 依赖图必须是「发现/重建」的产物，不是预设的**：FormaTheoria 把「隐式依赖发现」列为大尺度形式化四难之首（2608.10894）；CAM-Bench 用 dependency-recovery pipeline 从教材上下文重建局部引理（2605.17255）。→ V1（形式化库依赖图）**部分修正而非推翻**：依赖图仍核心，但 2026 年实证说明它是 LLM agent 要「从文献重建」的构造性工件，需 provenance 与审查门控，不能照搬老库静态依赖。
- **P3 成对图/成对本体不足以表示科学概念关系，需高阶表示**：2601.04878 明确「traditional KGs pairwise constraints fail to capture the irreducible higher-order interactions」并给超图方案与规模证据。→ **V2（MMK 理论图）与 V3（MaRDI 本体）被实证修正**：成对三元组丢语义；M08 概念关系应至少支持超边/多元关系，且保留共现上下文。
- **P4 公式锚点要「维度/公理接地」**：MMFormalizer（2601.03017）把物理公式锚到量纲或公理接地，递归从感知基元构造形式命题（首个覆盖哈密顿经典力学/相对论/量子力学/热力学的多模态 autoformalization）。→ Studium 公式锚点可从「符号级」升级为「量纲/公理级」语义接地。
- **P5 未证命题（猜想）与已证定理要分轨**：Conjecturing（2510.11986）证明「猜想」是 autoformalization 之前的独立步骤；Formal Conjectures 把 1,029 条开放猜想与 836 条已解题目分开组织（2605.13171）。→ M08 中「开放/争议」命题需要独立表示态。
- **P6 知识载体从「库」变成「活的、可执行的、可增长的」**：Formal Conjectures 的 evolving benchmark 提供「数学家/机器共同维护」的接口（2605.13171）；xKG 证明「可执行」载体让 agent 复制科研能力 +10.9%（2510.17795）。
- **V7（五家族表示）被范式性修正**：2024-26 的主轴不是再选一个家族，而是「**表示=流水线**」——autoformalization→语义校验→形式验证→agent 维护（2412.16075 立场、2606.08728 综合综述、2607.07779）。老家族（mathlib/MML/Metamath/MaRDI/OntoMath）全部降格为**基线/backbone**（如 MiniF2F、mathlib4、PhysLean），不再是被选型的新载体。内部向量子空间（FARS）提示还应新增一族「隐藏表示」（2605.09496）。

**依据与等级**：A 级来源为主；「把某范式移植到 Studium」属研究建议，标 C；2606.08728 综述把四轴（非形式/形式/发现/训练技巧）当作统一图景，是支持「V7 被范式性修正」最强的 A 级综述证据。

## 3. 对决策点的输入
- **决策点「知识载体选型」**：2024-26 的主流不是再选一个老库/老本体，而是「**形式化目标（Lean 语句/证明）+ autoformalization 流水线 + agent 维护的活资源**」三元组。若 Studium 要跟进，性价比最高的是：锚点出 Lean 目标 + 语义校验，而非整体引入某形式化库（对齐 V1 修正项 P2）。
- **决策点「概念关系图」**：成对三元组图（V2/V3 式）被 2026 超图证据修正；至少应预留超边/多元关系能力，并保留共现上下文（P3）。
- **决策点「公式/定理锚点」**：升级为量纲/公理接地 + 开放/已证分轨（P4/P5）；「锚点↔命题」对应用语义代理校验而非逐字 grep（P1，呼应记忆库「锚点校验盲区」——proxy-judge 提供了可机械化的新思路）。
- **决策点「LLM 时代载体评估」**：需新增一族「隐藏/向量表示」（FARS 等），LLM 自身内部已存在跨格式数学概念子空间——这提示载体设计可同时服务「人读」与「模型读」。

## 4. 与范围/红线的冲突张力（无则明说无）
- **张力 1（Lean 为中心 vs 不评估 Lean/Coq 作运行时证明器）**：2024-26 该领域绝大多数论文以 Lean 为校验后端。本调查的处理是**只取其「知识表示形态」**（语句作锚点、依赖图重建、证明分解单元、proxy 判定），不评估 Lean 运行时性能，符合红线字面。已在 Q1/Q2 中显式以表示视角转述。
- **张力 2（老库作基线）**：mathlib/MiniF2F/PhysLean 等只作为基准被提及（如 DeepSeek-Prover-V2 的 MiniF2F 88.9%、PhysProver 的 PhysLean），不构成关键发现。无越界。

## 5. 未决与风险
1. **年份判定风险**：arXiv ID 前缀 YYMM 已交叉核对 citation_online_date，全部落在 2024-09~2026-08；但 26xx（2026）稿件多为近期 preprint，尚未同行评审，结论可能被后续版本修订。
2. **export API 被限流**：首个关键词组原计划走 export API，全部命中「Rate exceeded」；改用 arxiv.org/search + abs 页后检索质量未受影响，但搜索面（尤其 formula/KG 专项）略窄——两个专项查询（math KG survey、formula semantic retrieval）返回 0 结果，对应角度由 autoformalization/CAM-Bench/MMFormalizer 间接覆盖。**未核**：老「公式语义检索（Formula2Vec 类）」在 2024-26 是否仍有新作，未查到 2024+ 的直接替代实证。
3. **内部表示论文的模型规模限制**：FARS/FRR 用 1.6B–8B 开源模型，对前沿闭源模型（如 Studium 实际部署）的成立性属 C 级推断。
4. **从论文到 Studium 的可移植性**：P1–P6 是研究建议（C 级），尚未在 Studium 语料（中文理科教材 + 既有 M08 载体）上验证；尤其中文教材的 autoformalization 成本未评估。
5. **「表示即流程」对个人知识库的可承受性**：FormaTheoria/Formal Conjectures 的工作量（长期 agent 流程、审查门控）面向研究级团体；个人/小团队载体是否值得引入，需成本分档。
