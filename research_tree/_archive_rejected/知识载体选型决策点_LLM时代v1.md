## 0 总判断（一句话）

**LLM/agent 时代对 Studium 知识载体选型的净结论：既有的「L0 JSONL 锚点可 grep + L1 RDF 语义层 + L2 FHIR 式版本化 + 机械信号只定向不结案 + 向量只定向不结案 + 图索引等触发」全部成立且被 2024–2026 文献独立强化，但需要在四个机制上补强——①检索/记忆的「充分性判据」（什么时候已经够了、何时触发），②证据冲突的「来源归因」（演化/操纵/未决三分，而非简单选边），③语料的「时序/版本索引」（静态 RAG 会自信引用不适用版本），④harness 自演化的「准入护栏」（污染不可逆，回滚不能替代把关）。** 最反直觉的一条：对精确、证据接地的问题，给 agent 对**未修改原始记录**的可控搜索（ReFind）或治理化的双时态状态机（GPM）**常常胜过**精巧的语义结构——这与 Studium「锚点=原文对应、机械信号只定向不结案」红线在 LLM 时代被独立印证。

### D2 知识载体·检索（H2-1 + 接 V6 尾巴）

| 维度 | 代表证据 | 等级 | 结论 | 对 Studium 进入方式 |
|---|---|---|---|---|
| **触发信号** | When Should Active RAG Retrieve 2607.24010（utility estimation + harm audit + 成本分解） | A | active retrieval = **utility estimation**：检索只在边际正确性变化超过 no-retrieval 时有价值 | 检索触发先做 harm audit 与成本分解，**简单不确定性/检索分数 baseline 常匹敌学到的路由** |
| **不确定性分解** | Interpretable Uncertainty 2607.07380（单次 forward 区分 insufficiency vs ambiguity/conflict） | A | **insufficiency 触发检索、ambiguity/conflict 加推理而非检索** | 区分「知识不足」与「证据冲突」，后者不盲目再检索 |
| **充分性度量** | Bio-GRACE 2608.01409（金标准归一化诊断）；SAGE 2608.08237（SLO-aware 自适应 k） | A | **充分性≠recall/overlap**；=检索是否恢复「没有它就做不出的决策收益」 | 用决策收益恢复度而非召回率判检索充分性 |
| **自适应 vs 固定（反直觉）** | Dissecting Agentic RAG 2606.21553（**固定混合胜规则路由 +1.8 EM，两轮捕获五轮 95%**）；Data Quality 2607.21861（小语料内化进 LoRA 胜 RAG） | A | **固定本地预算下简单固定常匹敌/胜过自适应**；增益来自「跑短检索循环」非路由 | 不盲目上自适应路由；先固定混合+两轮短循环基线 |
| **时序充分性** | Temporal Misgrounding 2608.09393（**静态 RAG 0% 命中日期适用版本却自信引用不适用版本**） | A | **时序语料必须版本索引**；答案用原子 nugget（regex+numeric tolerance）确定性评分，**绝不用 LLM-as-judge** | 直映 Studium 时序锚定红线：检索器须版本感知，评分须机械确定性 |

**总判断（C+A）**：检索的 LLM 时代判据 = **「utility 触发 + harm audit + 决策收益充分性 + 时序版本索引 + 原子 nugget 评分」**。两条反直觉实证（简单基线胜学习路由、固定胜自适应）警示 Studium 不要追逐复杂检索编排；时序版本索引与原子评分直接强化「锚点=原文对应、机械信号只定向不结案」红线。

### D3 知识载体·可信与引用（H2-2 + 接 V6 CS-RAG）

| 维度 | 代表证据 | 等级 | 结论 | 对 Studium 进入方式 |
|---|---|---|---|---|
| **假置信（攻防）** | When Context Bites/D-SCAN 2608.06947（蓄意攻击使中毒输出困惑度**更低**，不确定性检测失效；attention collapse 签名能抓**未改变答案**的攻击） | A | **不确定性信号在对抗语境被专门击败** | 单靠机械信号（困惑度/向量分）不能结案——红线在对抗语境被强化 |
| **冲突归因** | EvoTrustRAG 2608.07933（同一冲突可能源自**合法演化/恶意操纵/未决**；归因而非选边，协调攻击错误率 31.2%→16.0%） | A | **冲突须归因来源，而非简单选「更可信」方** | 审计晋升状态机可借鉴：对冲突证据判「演化/操纵/未决」再决定保留/隔离/暴露 |
| **反事实充分性** | RAGuard 2607.26339（ZKIP 黑盒 leave-one-out 过滤，ASR→0.000；关键词保留毒化让 BM25 基本不受影响） | A | **反事实 leave-one-out 是无标签黑盒充分性判据**；检索器类型决定攻击面 | 补锚点校验：移除某证据的边际效应度量（与 H2-1 Bio-GRACE 同源） |
| **拜占庭来源验证** | SecureCollaRAG 2608.04366（动态 GNN 可信度评分，非 IID 对抗鲁棒） | A | 多代理协作下须拜占庭容错来源验证 | 多代理知识协作时来源验证不可省 |
| **风险不可单刻画** | DenialRAG 2608.02678（显式命名正确答案再否认；防御各留残余 ASR） | A | **RAG 中毒风险不能用单一攻击族/单一目标模型完全刻画** | 防御须多层异质（无完美防御）；防「防御」直觉 |
| **接地幻觉定位** | Latent Critic 2608.10430（agent 执行幻觉动作而非表达不确定性；潜在空间局部化，0.966 AUROC） | A | 接地失败须局部化检测并拦截（执行前护栏） | agent 执行幻觉动作是风险；检测依赖模型内部（闭源受限） |

**总判断（C+A）**：可信与引用的 LLM 时代判据 = **「异质多层防御 + 冲突来源归因 + 反事实 leave-one-out 充分性 + 版本感知时序」**。核心强化：**「机械信号只定向不结案」在对抗语境下必须成立**——攻击者正瞄准机械信号（假置信）；冲突处理从「选边」升级到「归因」；无完美防御须多层异质。

### D5 支线·长程状态/记忆（H4-1，并入 D1）

- 五维并进：**段级固化**（LycheeMemory，粒度判据）+ **事件中心联想回忆**（RippleMem，证据覆盖）+ **治理化状态机**（GPM，可信）+ **受控干扰**（CMI，演化非单调）+ **充分性早停**（Router-Mem，单 token 决策降延迟 27.3%）。
- **GPM 是 Studium 架构的 LLM 时代独立印证**（见 §3）：双时态状态机 + 来源绑定准入 + 冲突隔离 + 撤回不复活 + 单已验证 head 精确 claim 闭合，与 Studium 审计晋升状态机 + L0/L1/L2 几乎逐项对应——**可信记忆须状态机化、来源绑定、冲突隔离、撤回不复活**。
- 记忆充分性可早停（Router-Mem）与检索充分性（H2-1）直接共振——「充分性可判定且可早停」是检索与记忆共享的判据。

### D6 支线·harness 机制（H1-1/H1-2，并入 D1/D3）

- **自演化**（H1-1）：harness 六维度可自改进（AutoDesign +12.4%、MemoHarness）；**但污染结构不可逆**（Backfires：过临界池规模后新技能反降性能、post-hoc 回滚只恢复小部分）→ **准入 pre-commit 必要**（VaG 三层批评：结构/行为/语义）。
- **可逆副作用**（H1-2）：DSH revertible effects（每副作用带显式 inverse，accumulator 累积，卸载按 inverse 回滚）+ reactive coeffects（依赖声明为 specification，notify 三分类）+ unified context（$\Gamma_\infty$，observational equivalence 商掉物理不可恢复部分）。
- **关键张力精确化**：Backfires「污染不可逆」vs DSH「副作用可逆」——H1-2 用 observational equivalence 把边界精确化：**可逆 = 副作用未扩散进任何组件的 coeffect 投影（未被声明为依赖）；一旦被后代继承为依赖，超出局部回滚边界**。这把 H1-1 的 pre-commit gating 与 H3-1/H1-2 的回滚统一起来：**回滚保证到「观测等价」，准入护栏阻止「不可逆扩散」**。

### D7 支线·上下文工程（H3，结论并入；详见 `上下文工程决策点_v1.md`）

四根可移植支柱：①上下文组件可版本化可回滚（ChronoMem 整库快照）；②压缩形态选符号化原子（⚠Context Codec round-trip recoverability【不可信来源，降级 C 线索】，直接服务 L0 可 grep 红线）；③缓存策略按负载形态裁决（稳定长前缀会话 41-80% 降本，前缀多变 6% 适用）；④工具编排用主动发现（intention-tool graph，不全量 schema 注入）。——并入本文 §4 清单第 6-10 条。

## 2 跨方向横向对照（三个收敛点）

四个方向十叶在**三个点上收敛**，提示它们在同一底层问题（知识载体的 LLM 时代可信性）的不同切面：

1. **「原文/原始记录锚点优先」被 LLM 时代文献独立印证**——ReFind（原文可控搜索胜结构化记忆）、GPM（来源绑定准入+fail-closed）、Temporal Misgrounding（静态 RAG 0% 命中适用版本，须原子 nugget 确定性评分）、RAGuard（反事实 leave-one-out 无标签充分性）、H2-1 F8（LLM-as-judge 继承时序偏差）——**五条独立证据链都指向：可信判定必须锚定可机械验证的原始对应物（原文/原子/反事实），而非间接结构或 LLM 自评**。这正是 Studium「锚点=原文对应、机械信号只定向不结案」红线在 2024–2026 被多方向独立重证。
2. **「演化非单调 + 干扰/污染结构性」横跨 harness/检索/记忆三方向**——H1-1 Backfires（技能污染不可逆）、H2-2 来源腐败/假置信、H4-1 CMI（记忆干扰急剧抑制更新可塑性）——**知识/技能/记忆的累积不保证单调增益，干扰与污染是可靠性的核心变量**。对应到 Studium：写入前的准入把关 + 冲突归因 + 干扰感知，三者缺一不可。
3. **「充分性可判定且可早停」横跨检索与记忆**——H2-1（utility estimation、简单基线胜路由）、H4-1 Router-Mem（单 token 充分性早停）、H3-2（缓存连续性判据）——**不要在「是否足够」上做无界投入；用轻量可判定的充分性信号早停**。这为 Studium 的检索/记忆调度提供成本边界判据。

## 3 与 Studium 既有红线/结论的逐条协调

| Studium 既有项 | LLM 主线证据 | 协调结论 |
|---|---|---|
| **L0 JSONL 锚点可 grep** | ReFind（词法索引胜结构）；⚠Context Codec（round-trip recoverability）【不可信来源，降级 C】；Temporal Misgrounding（原子 nugget 确定性评分） | **强化成立**：原文可检索时结构化不必要；压缩/评分须锚定可机械验证的原子 |
| **L1 RDF 语义层 + 锚点接地** | PolicyKG（谓词接地 Corpus Adapter + FOL 边界标注）；GPM（来源绑定） | **同向**：需要结构化时用「LLM 自动构造 + 谓词接地本体 + 显式边界」，不把单语料审计当普适证明 |
| **L2 FHIR 式版本化（v1.3）** | GPM（双时态状态机）；Temporal Misgrounding（时序版本索引）；EvoTrustRAG（冲突来源归因含演化） | **同向且强化**：双时态/版本化是防 temporal misgrounding 的根本机制，GPM 独立印证 |
| **机械信号只定向不结案** | D-SCAN 假置信（不确定性被专门击败）；Latent Critic（接地幻觉）；DenialRAG（无完美防御） | **对抗语境下必须成立**：攻击者正瞄准机械信号；须异质多层防御 |
| **向量只定向不结案（P6/P9 未解锁 §9）** | 2608.12812（纯向量选型成熟）；ReFind（结构化非必要）；AkasicDB（统一执行为终局方向） | **不推翻**：维持只定向；形态演进方向（统一执行）与选型场景（何时解锁）分设 |
| **图索引等触发（S2/v1.3）** | RippleMem（事件图联想回忆）；AkasicDB（统一执行）；Dissecting（固定混合够用） | **不推翻**：522 节点仍稀疏端；事件图联想回忆是「图真有触发场景」时的形态候选 |
| **审计晋升状态机（V/S 系列）** | GPM（双时态+来源绑定+fail-closed）；EvoTrustRAG（冲突归因）；Backfires（准入 pre-commit） | **逐项同构、独立印证**：可信记忆/技能/证据均须状态机化 + 来源绑定 + 冲突归因 + 准入把关 |
| **锚点校验盲区（[[anchor-verification-blind-spot]]）** | RAGuard（leave-one-out 反事实）；Temporal Misgrounding（不用 LLM-as-judge） | **强化**：LLM 判官会继承它要评分的偏差；单信号/单判官不够，须反事实 + 原子确定性评分 |

## 4 给 Studium 的可移植模式清单（推荐草案，C）

**方向2/4（检索与记忆，直接服务知识载体）**
1. **检索触发做 utility + harm audit**：检索只在边际正确性变化超过 no-retrieval 时有价值；先报 harm rate 与成本分解，再谈准确率；简单不确定性/检索分数 baseline 先测，不盲目上学习路由。
2. **充分性用决策收益恢复度**：检索/记忆是否恢复了「没有它就做不出的决策收益」（Bio-GRACE 思路），而非 recall/overlap；记忆充分性可早停（Router-Mem 单 token 决策思路）。
3. **时序语料必须版本索引**：任何有版本演进的语料（法规/文献/教材版本）检索器须版本感知；评分用原子 nugget（regex+numeric tolerance）确定性评分，**不用 LLM-as-judge**。
4. **冲突来源归因**：证据冲突先判「合法演化/恶意操纵/未决」三类（EvoTrustRAG 思路），再决定保留/隔离/暴露——审计员对冲突做归因而非简单选边。
5. **反事实 leave-one-out 补锚点校验**：移除某证据的边际效应度量（RAGuard ZKIP 思路）作无标签黑盒充分性判据，补充 grep 逐字校验。
6. **结构化只在被证明需要时叠加**：先用原文可控搜索基线（ReFind 思路）；需要结构化时用「LLM 自动构造 + 谓词接地 + 显式 FOL 边界」（PolicyKG 思路）。

**方向1/3（harness 与上下文，承载知识载体）**
7. **harness 自演化须准入护栏**：技能/规则写入前 pre-commit gating（结构/行为/语义三层批评，VaG 思路），因为污染一旦扩散到后代就不可逆（Backfires）——回滚不能替代准入把关。
8. **上下文组件可版本化可回滚**：组件级走 effect inverse（轻、精确，DSH 思路）、跨会话走整库快照（重、观测等价，ChronoMem 思路）两层；回滚保证到「观测等价」而非比特一致（DSH observational equivalence）。
9. **压缩/记忆选符号化原子**：可 grep/可锚点的压缩形态（⚠Context Codec round-trip recoverability【不可信来源，降级 C 线索】+ Telegraph 符号重表达），时序事实显式保 temporal 原子。
10. **上下文管理内建为 harness 职责**：把 context 列为 harness 运行时职责（六职责），不当作每轮让模型自选的提示技巧；工具编排用主动发现（intention-tool graph）不全量注入。

### 7.1 一句话收口（用户确认的核心洞察）

**最好的记忆系统也是有损的——任何派生结构（摘要/embedding/KG/固化）从构造上就是原始记录的有损投影；只有「未修改的原始上下文 + 对其可控搜索」这一层无损（ReFind 实证，58.2 胜 HippoRAG 2）。** 对 Studium 的含义：**L0 原文层 = 唯一无损层，任何派生结构都是它的有损投影，永远不能取代 L0；「回滚无损」只到观测等价（DSH），不到比特级；无损有物理上限（上下文窗口装不下无限原文），所以长程无界处仍需分层压缩/切分（上下文工程支柱）。**
