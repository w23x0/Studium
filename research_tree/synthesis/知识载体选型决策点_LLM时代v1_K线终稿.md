## 0 总判断（一句话）

**LLM/agent 时代对 Studium 理科知识载体的净结论：核心红线全部成立且被 2024–2026 文献独立强化——「锚点=原文对应、机械信号只定向不结案」在 LLM 时代不仅没被推翻，反而因 LLM 自身信号（引用/归因/校验器）被证不可靠而**加严**；但旧结论有四条被修正或需升级：①L1 RDF 作「唯一结构层」过约束（知识以「带身份与证据的原子承诺 + 混合拓扑」组织，而非单一本体）；②L0 JSONL 缺原子身份与版本化（无版本化/事务边界则长期可信性不成立）；③数学/科学表示主流已从「静态形式化库/本体选型」迁移为「**表示即流程**」（形式化目标+autoformalization+agent 维护的活资源）；④检索触发清单需从 V6 两条升级为三条（补「时间/版本判别」轴，「训练外」修正为可操作的「共轭判别器」）。**最反直觉的一条：对精确、证据接地的问题，给 agent 对未修改原文的可控搜索（grep/JSONL）胜过精巧的语义结构——结构化（向量/图/KG）只在被证明需要时叠加。**

## 2 跨方向横向对照（K 线三个收敛点）

K1–K4 在三个点上收敛，提示它们在同一底层问题（知识载体的 LLM 时代可信性）的不同切面：

1. **「原文/原子锚点优先」被多方向独立重证**——K1（⚠Context Codec 原子承诺+round-trip recoverability【不可信，降级线索】、MOSS 可审计关系检索）、K2（FormalMATH 语义校验+proxy-judge 按轴判定、公式量纲接地）、K3（pinpoint 页面级最弱、引用机制不接地、带界抓漏）、K4（GroundedKG-RAG 节点边锚定原文）——**四条独立证据链都指向：可信判定必须锚定可机械验证的原始对应物（原文/原子/形式化目标），而非间接结构或 LLM 自评**。这正是 Studium「锚点=原文对应、机械信号只定向不结案」红线在 2024–2026 被多方向独立重证。
2. **「成对结构（RDF/KG/三元组）表达力不足」横跨组织/表示两方向**——K1（组织放宽为混合拓扑，Mandol/DocTrace）、K2（超图/高阶表示实证修正 V2/V3 成对图）——**对 Studium：M08 概念关系须预留超边/多元关系能力，不再以单一成对本体为唯一结构层**。
3. **「充分性可判定且可早停」横跨检索与表示**——K4（停止条件、多检索有害）、K2（proxy-judge 判定命题可计算化、CAM-Bench dependency-recovery）——**不要在「是否足够」上做无界投入；用轻量可判定信号早停**。

## 4 给 Studium 的可移植模式清单（推荐草案，C）

**组织/存储（D1）**
1. **承诺集作审计单位**：把现有「引文块」升级为带 canonical identity/conflict/confidence/evidence span 的原子承诺（⚠Context Codec 思路【不可信来源，本模式降为 C 级内部设计参考，不引外部证据】）——直接补 B 型盲区半机械化的根因（缺 canonical identity）。
2. **分层+文件系统组织**：HORMA 的「summarized entity→raw trajectory」映射 L1↔L0 双向链接，但每层可追溯回滚（补版本缺失）。
3. **bitemporal 时间语义并入时间锚定**：Graph-Native 的 valid/transaction time 是「时间锚定偏误」（[[research-tree-time-anchor-bias]]）的结构性解药。
4. **事务边界做写入审计**：MemTxn 的 Ordered PatchTest（写前验证是否被源支撑）作审计阶段机器可执行层（对应「机器下界=锚点+无存在量词引理」）。

**数学/科学表示（D2）**
5. **锚点校验半机械化但用语义校验**：FormalMATH 的「多 LLM 语义校验+否定式反证过滤」（保留率→72.09%）+ proxy-judge 按轴属性判定——锚点↔命题对应半自动，非逐字 grep。
6. **依赖图必须是「发现/重建」产物**：FormaTheoria 的隐式依赖发现+provenance+审查门控（V1 修正落地）。
7. **概念关系预留超边/多元关系**：2601.04878 超图方案+保留共现上下文（V2/V3 修正落地）；M08 schema 从成对边升级为可表达多元关系的模型。
8. **公式锚点量纲/公理接地 + 猜想分轨**：MMFormalizer 思路 + Formal Conjectures 的「开放/争议命题独立表示态」。

**可信/引用（D3）**
9. **机械信号域扩到 LLM 信号**：红线表述升级为「一切非原文信号（含 LLM 生成的引用/归因/entailment/校验器结论）只定向不结案」。
10. **机器校验报告改「带界抓漏」**：split-conformal 界/VCE——报告「抓不到什么、多少抓不到」，不报「通过率 y%」。
11. **新定向信号只进候选池**：实体归因校验（97%）、CiteCheck 式元数据判等、sufficiency check——收窄候选审计集，不结案。
12. **引文质量三维框架作审计清单原型**：CITETRACE 的意图/适配/保真三问。

**检索（D4）**
13. **检索=代价感知决策**：JSONL+grep 低代价高精度层，升级（向量/LLM/图）须过「证据增益>成本」闸门。
14. **参数知识优先**：通用教科书内容检索增量小；Studium 自有审查产出（novel/私有）才是检索增强正域。
15. **版本感知索引是上检索的硬前提**：若引入 RAG 而语料有时序版本，静态检索会自信误引不适用版本；最省合规形态=JSONL 层版本标签+时间索引。
16. **图只定向不结案（若建图）**：节点/边锚定源句（GroundedKG-RAG 2026 外部对应物），优先事件/版本粒度。
