## 1 决策点地图（候选方案 / 证据 / 兼容性 / 方向 / 待实测）

### D1 底层序列化格式（JSONL 现状的替代）
| 候选 | 证据（实测） | 兼容性要点 | 方向 |
|---|---|---|---|
| JSONL（现状） | 522 节点/1433 边/921 锚点实测运行 | **锚点 grep -F 直接成立**；append-only 天然 | 保留为 L0 原文层候选 |
| N-Triples/N-Quads（B1b） | W3C 标准；行式可追加 | **grep -F 不直接成立**：锚点以转义形式存在，须先按 ECHAR/UCHAR 还原（B1b，A 级文法支撑） | 若走 RDF 系，需配套"转义还原 grep"工具 |
| Turtle/TriG（B1a） | RDF 1.2；TriG 多图=四图分开+对齐边跨图 | 非逐行，适合语义层不适合原文 grep 层 | 语义层候选 |
| JSON-LD（B1a/B7a） | RDF 1.2 序列化；锚点字符串字面量保留 | 可无损转 RDF；YAML-LD（WD 2026-07-28）Basic profile 语义无损往返、python-yaml-ld 实测可跑通（B7a） | 语义层候选；YAML-LD 双真相风险（冲突32） |
| IPLD dag-json（B4b） | CID 内容寻址默认不可变（A） | CID 不可读、无迁移先例（C）；"Nothing is overwritten" 与 M09 同构 | 版本层可选，不适用原文层 |

**方向（推断 C）**：不选"单一格式替代"，选**分层载体**——L0 原文可 grep 层（JSONL 或 canonical N-Quads+还原工具）+ L1 语义层（RDF 系或属性图系）+ 版本/审计层（见 D3/D5）。"JSONL 直接满足 grep -F"是本树唯一无转义成本的选项（B1b 实测）。

### D2 表达语言/语义模型（图模型 + 词表封闭 9+other）
| 候选 | 证据（实测） | 9+other 表达 | 状态机/迁移约束 | 方向 |
|---|---|---|---|---|
| RDF 1.2 + triple term/reifier（B1a） | A：Primer 官方示例（兴趣边+类型+起源日期） | 词表封闭走 SHACL/ShEx（见下） | 需 SHACL-SPARQL 或应用层 | 语义层强候选 |
| ShEx（B5b） | A：valueSet 显式值+"~"通配并置 | **语法直接表达 9 固定+other**；CLOSED/EXTRA 谓词封闭 | 无内建时序原语 | 词表封闭首选 |
| SHACL（B5b） | A：W3C REC 2017；sh:in 封闭列表、sh:closed | "other 任意值"无内建，需 sh:or 或 SHACL-SPARQL | 同左 | 备选 |
| SHACL-SPARQL（B5a） | A：REC §5 查询返回违例 | 可表达 any 兜底 | **前状态须显式建模**（auditedBy/auditedAt）才可声明式；SHACL-AF 规则多轮迭代留待未来 | 迁移约束层辅助 |
| PG-Schema（B2b） | A：提案非 ISO 标准（arXiv:2211.10962/PACMMOD 2023） | **无官方原语**：STRICT+9 封闭 或 9+OPEN（other 任意不受控，C）；ENUM 仅是 §5.3 扩展 | 转换规则无标准语义，须应用层（C） | 观望（等 GQL v2/LEX） |
| GQL/SQL:PGQ（B2a） | A：ISO 39075:2024、9075-16:2023 已发布 | GQL v1 无完整 schema 语言（graph types 非约束型 schema） | 同 PG-Schema | 观望 |
| Datalog 增量（B3a） | A：DDlog/DBSP/RDFox；EDB 可删/IDB 不可显式删 | 谓词即词表，封闭性靠规则集约定 | **单调事实层+非单调视图**分层可表达状态推进 | 逻辑层候选 |
| DatalogMTL（B3b） | A：时间区间派生结论，官方论文牙医预约动机即"复检导致旧派生撤回" | 同 Datalog | **直接表达"复检/遗忘/重新掌握=新版本区间"**；组合 EXPSPACE、有限可物化片段可行 | M09 逻辑层强候选 |

**方向（推断 C）**：词表封闭 9+other 的最短语法路径是 **ShEx valueSet "~"**（B5b 实测 A）；若走 RDF 系，L1 语义层=RDF 1.2（TriG 多图）+ ShEx/SHACL 校验 + 必要时 SHACL-SPARQL 表达迁移约束（前提：前状态显式建模）。

### D3 版本化机制（M09 动态模型）
| 候选 | 证据（实测） | 与 M09 对应 | 方向 |
|---|---|---|---|
| FHIR _history（B6d） | A：versionId 随内容变更更换+_history 只追加不可改写+Provenance/AuditEvent+verificationStatus（confirmed/refuted/entered-in-error） | **完整可移植先例**：旧版本永久保留仅审计、状态机表达复检/误录 | 强候选（M09 状态机） |
| 时态属性图 assert/retract/correct（B2c） | A：TGMS write-ahead log；TPGM+ 双区间；快照算子（T-PGQL AS OF、T-GQL SNAPSHOT） | 复检=correct（旧版本永久可查）、遗忘=retract、重新掌握=assert；属性级位时防存储爆炸 | 强候选（双轴审计） |
| nanopub 撤回（B4a） | A：trusty URI（SHA-256）+ supersede；发布后不可删 | 不可变+撤回语义 | 候选（需 server 网络，个人规模过重 C） |
| IPLD（B4b） | A：CID 默认不可变、git 同构、ipfs-log/OrbitDB append-only | 与 M09"旧版本不覆盖"同构 | 候选（工具链自备，C） |
| 命名图快照（B1c） | A：SPARQL 1.2 **无任何版本/时态原语**（标准原文检索 0 命中）；IC/CB/TB/HB 档案策略（SWJ 2019）；PROV-O wasRevisionOf | 每个版本一个命名图=应用层约定；保留/剪枝须应用层负责 | 有条件候选（RDF 系内） |
| xAPI voiding（B6c） | A：IEEE 9274.1.1 statement 不可修改、voiding 作废不销毁；物理存储是否 append-only 规范不指定 | 撤回语义先例 | 语义参考 |
| Anki revlog（B6b） | A：revlog 追加（复习历史）与 cards 覆盖（当前状态）**分离存储**；revlog 可重算 FSRS 派生量 | **工程简化模式**：历史流与当前状态分离 | 设计参考（M09 规模友好） |
| 哈希链（B6e） | A：Crosby&Wallach、Schneier&Kelsey、RFC 6962/9162；个人最小=本地哈希链+周期签名 checkpoint | 防篡改审计层 | L3 审计层候选 |
| 数学库删除（B6a） | A：mathlib 6 个月后可删、MML 修订可删 | **允许最终删除→与"不物理删除"红线冲突（冲突27）** | **排除**（仅借鉴 git 快照/替换表机制） |

**方向（推断 C）**：M09 版本层首选 **FHIR _history 式（versionId+不可改写历史+verificationStatus 状态机）** 与 **时态属性图双区间** 二选一；工程上可叠加 **Anki revlog 式"历史流/当前状态分离"** 简化；防篡改叠加 **本地哈希链+周期签名**（B6e，个人规模最小可行，CT/gossip 属过度设计 C）。

## 4 推荐草案（推断 C，非结论；与实测严格分开）
**总判断**：无单一"完美载体"替代 JSONL；全树证据指向**分层双轨**（与 B8c 迁移模式、B1b canonical 指纹互证）：
1. **L0 原文层（红线锚点判等）**：保留行式可 grep 载体。JSONL 现状零成本满足 grep -F；若迁 RDF 系，则 N-Quads 逐行 + 转义还原工具（B1b 实测证明可行性）。**本层不变更存储语言，只做追加**。
2. **L1 语义层（M08 知识图谱）**：推荐 **RDF 1.2 + TriG 命名图**（四图不合并红线直接支持、对齐边跨图表达，B1a）+ **ShEx valueSet "~" 表达 9+other**（唯一语法直接原语，B5b）+ SHACL-SPARQL 补迁移约束（前状态显式建模后声明式，B5a）。备选：属性图 + PG-Schema（须等 GQL v2/LEX，且 9+other/ENUM/转换规则三缺口未解，B2b）。
3. **L2 版本层（M09 动态模型）**：推荐 **FHIR _history 式**（versionId+不可改写历史+verificationStatus 状态机，B6d）或 **时态属性图双区间**（TGMS assert/retract/correct，B2c），二选一后叠加 **Anki revlog 式历史流/当前状态分离**（B6b）降规模成本；不依赖 SPARQL 版本原语（B1c：标准无此能力）。
4. **L3 审计层**：本地逐行哈希链 + 周期签名 checkpoint（B6e）；个人规模不引入 CT/透明日志 gossip 模型（过度设计，C）。
5. **迁移路径**：expand-migrate-contract + 双写/影子读（B8c），RML/YARRRML 做 JSONL→RDF 半自动映射（B8b，注意非正式标准地位）；迁移期输出 canonical 指纹对照（B1b/B8a）。
