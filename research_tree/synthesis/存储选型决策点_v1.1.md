## 1 决策点地图（D1-D6 更新后）

> 沿用 v1.0 六决策点结构；每点只列**本版变化**与更新后的结论行，未变化的旧结论不重复展开（可回查 v1.0）。

### D1 底层序列化格式（JSONL 现状的替代）

| 候选 | v1.1 更新 | 更新后方向 |
|---|---|---|
| JSONL（现状） | 无变化；仍是唯一无转义成本的 grep -F 载体 | L0 原文层首选（保留） |
| N-Triples/N-Quads（B1b） | **P1 实测补入**：921 真实锚点逐字还原 100%，但仅锻炼 `\\`(971) 与 `\"`(38) 两类平凡转义；350/921 含转义锚点对「解码 quote 直接 grep -F」在两条路径共同不可见（需转义感知解析器逐字比较） | 若走 RDF 系，须配转义感知解析工具；「grep -F 直接命中」仅对无转义锚点成立 |
| Turtle/TriG（B1a） | 无变化 | 语义层候选 |
| JSON-LD / YAML-LD（B1a/B7a） | 无变化；YAML-LD 全链路迁移原型仍待实测 | 语义层候选 |
| canonical N-Quads（B1b） | **P1 证伪 rdflib 7.6.0 实现**：`canonicalize=True` 被 `**kwargs` 静默吞掉，输出与普通序列化逐字节相同（120426 字节）且随插入顺序漂移——不实现 RDFC-1.0 | 指纹方案**换实现**：rdf-canonize（npm，w3c-ccg）或自管「按行字典序排序」 |

**本版结论（C 级方向，A 级事实支撑）**：L0 原文层维持 JSONL；「canonical N-Quads 可逆还原」为真（P1 实测），但「rdflib 7.6.0 提供 canonical N-Quads」为假，任何依赖 canonical 指纹的迁移校验须换库/自管排序。

### D2 表达语言/语义模型（图模型 + 词表封闭 9+other）

**本版核心修正（P3）**：

| 候选 | v1.0 判定 | v1.1 判定（更新依据） |
|---|---|---|
| ShEx（B5b） | 「valueSet '~' 语法直接表达 9 固定+other；词表封闭首选」（判 A） | **证伪降级**：`[v1..v9 ~]` 解析为 8 显式 IRI + 1 个 `IriStem(v9~)`（前缀匹配），第 9 个值通过只是「前缀命中自身」的假象；other/任意值被拒。正确写法=闭合 10 列表 `[v1..v9 rel:other]`（132 字符，实测通过） |
| SHACL（B5b） | 备选 | **升为对等路径**：`sh:in` 闭合 10 列表（138 字符）与 ShEx 闭合 10（132）几乎持平；ShEx 无实质最短优势 |
| ShEx '9 + 任意 other' | （隐含可表达） | **不可表达**：裸通配 `[~]`/`[ . ]` 语法 PARSE ERROR；`[ . - excl]` 是补集；「任意 other」本身已蕴含 9 个固定值，两语言最短表达都是「任意 IRI」 |

**实测补充的谓词封闭语义（P3，16/16 与规范一致）**：
- ShEx `EXTRA` **不放行外来谓词**（CLOSED 下外来谓词必拒 ClosedShapeViolation）；EXTRA 只豁免表达式内谓词的超基数副本。旧 B5b 第 39 行「other 放 EXTRA 即可允许额外谓词」的理解**不成立**。
- 若用「9 固定谓词 + 允许外来谓词」：ShEx 侧须去掉 CLOSED（开放 shape）或显式声明 `rdf:type`；SHACL 侧用 `sh:closed + sh:ignoredProperties` 白名单。两侧都要显式处理 rdf:type。

| 候选 | v1.1 更新 | 更新后方向 |
|---|---|---|
| RDF 1.2 + triple term/reifier（B1a） | 无变化 | 语义层强候选 |
| PG-Schema（B2b） | **S3 维持**：无标准校验器、无正式采纳（无新论文、2606.06127 NP-complete 无更新）；GQL v2 Constraints and Keys（BCN-047）+ LEX-096 键约束是「路径已清、成品未出」的中间态，非可依赖结论 | 观望维持（等 GQL v2/LEX，目标 2027） |
| GQL/SQL:PGQ（B2a） | 无变化 | 观望维持 |
| Datalog / DatalogMTL（B3a/B3b） | 无变化 | M09 逻辑层候选 |

**本版结论（A 级实测 + C 级方向）**：L1 词表封闭（9 固定 + other 具体兜底值）的语法路径改为 **「闭合 valueSet 列表 或 SHACL sh:in」二选一**，两者语法成本对等（132 vs 138 字符），不再存在「最短路径」的单边推荐；B5b 的「'~' 直接表达」A 级假设正式标注为**已被 P3 实测证伪**。

## 2 已实测条目（P1/P2/P3 数字）

### P1 N-Quads 转义还原 grep 等价性（B1b 待实测 → 已实测）

环境：rdflib 7.6.0；数据：第 15 章 nodes 921 锚点（顶层 648 + inherited 273，522 节点）。

| 测量 | 数值 | 结论 |
|---|---|---|
| 逐字还原通过率 | **100.0000%（921/921）**，非法转义 0 | 手写解析器与 rdflib NQuadsParser oracle 完全一致（921/921） |
| 与 JSONL 基线 grep 等价 | both 571 / lost 0 / gained 0 / neither 350 | **0 丢 0 变，等价精确成立** |
| neither 350 的构成 | 341 反斜杠 + 12 双引号（3 两者兼有）；含双引号锚点永远不可命中（裸 `"` 在两种序列化里都不出现） | 是 grep -F 用「解码 quote」的**共同盲区**，非 N-Quads 额外损失 |
| 数据实际转义种类 | 仅 `\\`(971) 与 `\"`(38)；`\t\b\f\n\r`、`\uXXXX`、中文、全角空格、换行**零出现** | 100% 通过率**不能外推**到换行/中文/全角空格场景 |
| rdflib `canonicalize=True` | `canonical_identical_to_regular: True`；`canonical_ordered == canonical_shuffled: False`；源码 `**kwargs` 静默吞参 | **未实现 RDFC-1.0**（三重证据：源码 / 字节相等 / 插入顺序漂移） |
| 非 ASCII（U+2013 破折号 3 处） | 两路径都原样写 UTF-8 | 行为一致 |
| 性能 | serialize 0.0042s / roundtrip 0.0097s / 峰值 16.1 MiB | 毫秒级 |
| lone surrogate（合成探针） | rdflib 静默写成 `?`（encode "replace"）→ 往返失真 | 真实可达的数据破坏路径（当前 921 数据无） |

**对本版决策的输入**：N-Quads 路径在真实 921 锚点上「还原后逐字判等」成立；「canonical 指纹」方案须换实现；含转义锚点的 grep 检索须转义感知解析，不能用解码 quote 直 grep。

| 测量 | 数值 | 结论 |
|---|---|---|
| RDF 规模 | 522 节点 / 921 锚点 / 1433 边 / 931 evidence / 6402 三元组（Turtle 600,457 B） | 计数与任务卡完全一致 |
| RDF 构建耗时 | 0.0525 s | 秒级以下 |
| 全量 validate | **8.4812 s**；conforms=False；**205 违规**（全 SPARQLConstraintComponent，封闭词表/边端点 0 违规） | 与手工核验逐字节吻合（205 src 节点 / 362 条未匹配 evidence quote） |
| 内存 | 进程工作集 57,724→83,404 KB（增量 ≈25 MB，峰值 ≈81 MB）；tracemalloc 堆峰值 21.5 MB | 数十 MB 级 |

| 负对照 | 注入 1 个词表外谓词 → 205→206，ClosedConstraintComponent:1 | sh:closed 有牙齿 |

**对本版决策的输入**：pyshacl 接入须以库方式调 `validate()` 取 `(conforms, report_graph, report_text)`，加「shapes 非空且可解析」守卫；`sh:result` 用 `report.objects()` 枚举；不依赖 CLI 退出码做门禁。先裁决「锚点引用存在性」语义（evidence ∈ 节点锚点 vs ∈ 源文本）再定 shapes 承担范围，否则真实数据带 205 条待裁决违规。

### P3 ShEx valueSet '~' 表达 9+other（B5b 待实测 → 已实测且证伪）

环境：node v25.6.1 + @shexjs/parser 1.0.0-alpha.28 / validator 1.0.0-alpha.29；词表：9 固定 rel + other（35 条边）。

| 写法 | 解析结果 | 9 固定 | other | 任意 IRI | 字面量 |
|---|---|---|---|---|---|
| T1 `[9 ~]`（B5b 原文） | **8 显式 + 1 个 `IriStem(requires~)`**（末尾 ~ 粘前值） | 9/9 ACCEPT（假象：第 9 个因前缀自命中） | REJECT | REJECT | REJECT |
| T2 `[9]`（闭合 9） | 9 显式 | ACCEPT | REJECT | REJECT | REJECT |
| T3 `[9 rel:other]`（闭合 10） | 10 显式 | ACCEPT | **ACCEPT** | REJECT | REJECT |
| T4 `[ . - 9 ]`（通配排除 9） | IriStemRange(Wildcard) | 0/9 | ACCEPT | ACCEPT | REJECT（shex.js 偏离：字面量不匹配） |

- 语法探针：`[~]`、`[ . ]`、`[~ - rel:x]` → PARSE ERROR；`[ . - rel:x]` → PARSE OK。裸通配不可作 valueSetValue。
- Q2 谓词封闭：16/16 与规范 §5.5.2 一致——CLOSED 正确；**EXTRA 不放行外来谓词**（只豁免表达式内谓词的未消费三元组）。
- 语法长度：ShEx 闭合 10 = **132** / SHACL sh:in = **138** / ShEx `[9 ~]` = 124（不可用）/ SHACL sh:or(9+任意 IRI) = **165**。
- 性能：shex.js 127.4ms（48 校验：30 ACCEPT/18 REJECT）；pySHACL 对照 S1 1.8ms / S2 2.2ms（毫秒级，非基准）。

**对本版决策的输入**：B5b 的「`[ ex:t1 ... ex:t9 ~ ]` 语法直接表达 9+other」A 级判定**错误，已实测证伪**；「9 固定 + other（具体兜底值）」的正确写法=闭合 10 列表 `[v1..v9 rel:other]`（132），与 SHACL sh:in（138）语法成本对等。

## 3 候选方向判定（S1/S2/S3）

### S1 NebulaGraph 作为 M08/M09 存储候选 → **不采用**

| 项目红线 | 对照结论 | 依据要点（全 A 级） |
|---|---|---|
| R1 锚点逐字 grep -F | **不满足** | 数据以二进制编码 KV 存 RocksDB（自定义 KVStore）；原生索引非子串型，全文检索须外部 Elasticsearch 7.x；社区版**无导出工具**（官方确认），无法导出文本做 grep |
| R2 不物理删除 | **不满足** | DELETE VERTEX/EDGE 为查询层物理删除语义；文档无 soft-delete/tombstone；删除非原子；默认删点留悬挂边 |
| R3 开放字段稳定查询审查 | **需自建** | 强 Schema：ALTER 受限（索引属性不能改、异步 20s、类型变更面极窄）；「开放字段」与强 Schema 直接冲突 |
| R4 候选池+审计晋升状态机 | **需自建** | 引擎仅 RBAC，无候选池/晋升状态机/审计工作流 |

支撑要点：nGQL 是私有方言（原生 nGQL + 部分 openCypher DQL，不兼容 RDF/SPARQL/Gremlin；原生 GQL 仅企业版）；生产环境 48 核/256GB/2×1.6TB NVMe、默认 9 容器、Raft 静态分片；设计目标百亿顶点/万亿边——对 522 节点/1433 边是 8-9 个数量级错配。相对 L0 JSONL + L1 RDF 双轨，无胜出场景（优势仅出现在「多用户并发 + 10^7+ 边 + 需索引化图遍历」的企业级形态改造时）。

**判定**：不采用；不为 NebulaGraph 预留适配位。

### S2 图数据库查询层组合方案 → **等触发（现在不上）**

触发四条清单（沿 T1 操作化，本次复核无变化）：
1. 等价 SNB 复杂读（从给定节点可变长 ≥3 跳模式匹配）的真实产品查询；
2. 该查询在用户直接等待路径且 P95 超阈值；
3. 常规反复执行功能、非一次性后台脚本；
4. JSONL+脚本在 1–2 跳/按 id/全表校验之外已实测不可忍。

**四条当前均不成立**：M07 检索=文档级检索（1 跳标签匹配）；M08 导航=1–2 跳邻域（「图只是查看方式」）；学习过程图上游走=批量后台决策，不在用户直接等待路径；现有需求全是 SNB「短读/简单读」形态。

**若触发后的查询层形态**（按运维成本递增）：档 1 Postgres + `WITH RECURSIVE` / Apache AGE（同库同事务）；档 2 DuckDB + DuckPGQ（分析型只读）；档 3 独立图服务器（Neo4j Community 只读库 + APOC 只读过程，注意 GPL v3 分发影响）。**不建议**：Kuzu（2025-10-10 归档、org 24 仓库全 archive、无后继）；Aura Virtual Graph（云 + Public Preview，借理念不借实现）。

**同步手段（硬约束）**：一律「从源重建的只读派生索引」（PostgreSQL 物化视图 / Fowler CQRS / Event Sourcing complete rebuild 先例），**禁双写/outbox 保索引新鲜**（B8c 原子性不可保证 + Two Generals 理论界限）。

**能力边界**：查询层只买「多跳遍历 + 交互延迟」；审计晋升状态机、时间版本回溯、开放字段稳定审查仍应用层自建、以 L0/L1 + 脚本为真相。

**红线保全四条（写进设计约束）**：引擎 (a) 严格只读、永不进写路径；(b) 索引可丢弃、从 L0 重建；(c) 只喂知识关系图（四图之三）；(d) 节点身份/锚点判等由 L0 决定。任一破坏 → 红线受威胁。

## 6 对 M08/M09 选型的最终建议（推断 C 与实测 A/B 严格分开）

### 6.1 实测确立的事实（A/B，可直接引用）

1. **L0 保持 JSONL + 转义感知工具**（P1）：921 真实锚点 N-Quads 逐字还原 100%，与 JSONL 基线 grep 等价 0 丢 0 变；但 350/921 含转义锚点对「解码 quote 直接 grep」在任何一条路径都不可见——**凡以 grep 命中为存在性判据的验证管线，须对含反斜杠/双引号的锚点改走转义感知解析 + 逐字比较**。
2. **canonical 指纹依赖项更换**（P1）：rdflib 7.6.0 `canonicalize=True` 是静默 no-op，不实现 RDFC-1.0；需真 RDFC-1.0 时用 rdf-canonize（npm）或自管按行字典序排序。
3. **标准层 SHACL 校验在该量级可行但秒级**（P2）：522 节点 8.48s / 81MB / 近线性 ~17ms 节点；JSONL+脚本 0.079s 快 ≈108.6 倍。一次性审计可接受，不构成日常门禁；接入须库调用 `validate()` + shapes 非空/可解析守卫，不用 CLI 退出码做门禁。
4. **ShEx '~' 不能表达 9+other**（P3）：B5b 的 A 级判定已被证伪；L1 词表封闭正确写法=闭合 10 列表 `[v1..v9 rel:other]`（132）或 SHACL `sh:in`（138），二选一、语法成本对等。
5. **NebulaGraph 不采用**（S1）：四条红线 R1/R2 不满足、R3/R4 需自建，个人规模过度设计，无胜出场景。
6. **图查询层等触发**（S2）：触发四条清单当前均不成立；若触发走「从 L0 重建的只读派生索引」，禁双写，Kuzu 归档不上。
7. **属性图系观望维持**（S3）：GQL v2 已进 CD（目标 2027）是可见管线，但「无标准校验器」现状不变；2026 内定案不押 v2。

### 6.2 建议方向（推断 C，供决策层采纳）

1. **L0 原文层**：维持 append-only JSONL；锚点校验升级为「无转义锚点走 grep -F + 含转义锚点走转义感知解析逐字比较」的双路径（P1 已给出可行性）。
2. **L1 语义层**：RDF 1.2 + TriG 命名图；词表封闭用「闭合 valueSet 列表或 SHACL sh:in」（P3），SHACL 校验作为一次性审计层而非日常门禁（P2）；属性图 + PG-Schema 备选维持观望，等 GQL v2/LEX 到 2027 再评估（S3）。
3. **M09 版本层**：FHIR _history 式或时态属性图双区间二选一（旧 v1.0 结论不变），叠加 Anki revlog 式「历史流/当前状态分离」；不依赖 SPARQL 版本原语。
4. **L3 审计层**：本地逐行哈希链 + 周期签名；canonical 指纹若用于迁移校验，换 rdf-canonize/自管排序实现（P1）。
5. **迁移路径**：expand-migrate-contract + 影子读验收（Scientist 式）；**图查询层永不用双写**（S2）。
6. **触发监控**：把「3 跳计时 + 合成图拐点」实验列入待实测，一旦 M07/M08 出现 ≥3 跳邻域类查询即用实验数据判定，避免触发条件停留在纸面（S2）。

### 6.3 一句话总结

两轮新增调研没有推翻「分层双轨」的旧总判断，但**收紧了三条实现细节**：9+other 的语法路径（P3 证伪 '~'，改闭合列表）、canonical 指纹的依赖（P1 换实现）、标准层校验的成本定位（P2 秒级+接入防护）；并把三个候选方向钉死为 **NebulaGraph 不采用 / 图查询层等触发 / 属性图系观望维持**（S1/S2/S3）。
