# 叶子 H2-2 检索失败模式 调研发现

> 任务 H2-2 / A=原文到手 B=二手转引 C=推断
> 调研主题：LLM 检索的失败模式——毒化（poisoning）/对抗检索/冲突接地/接地幻觉/版本演化腐败；接 H2-1 的 temporal misgrounding + salience 攻击种子
> 时间锚定：外部文献全部 2024-01 后（多为 2026-07/08，主题热门）

## 0. 一句话结论
**2024–2026 的 RAG 检索失败模式已被系统刻画并出现攻防两端的反直觉实证。失败模式分四类且各有专门对策：（i）语料毒化——蓄意攻击诱导「假置信」（中毒输出困惑度反而比良性输出更低，使基于不确定性的检测失效），须用 attention collapse 签名（D-SCAN）或反事实 leave-one-out 过滤（RAGuard ZKIP）检测；（ii）证据冲突——同一冲突可能源自合法知识演化/恶意操纵/未解决不确定性，须做「冲突来源归因」（EvoTrustRAG）而非简单选「更可信」的一方；（iii）来源腐败——多代理协作下拜占庭容错（SecureCollaRAG 动态 GNN 可信度评分）；（iv）接地幻觉——agent 执行幻觉动作而非表达不确定性，须潜在空间局部化检测（Latent Critic）。** 关键总判：**RAG 中毒风险不能用单一攻击族或单一目标模型完全刻画**（DenialRAG），防御非均匀且各留残余——检索失败模式是结构性的，须多层异质防御 + 显式归因，呼应 Studium「机械信号只定向不结案」红线。

## 1. 父会话问题逐条回答

**Q1. RAG 检索有哪些失败模式？各自如何检测？**
- 结论：四类失败模式 + 各自检测机制。
  - **语料毒化检测**：When Context Bites（2608.06947）发现蓄意攻击诱导**假置信**——中毒输出困惑度甚至比良性输出更低，基于不确定性的检测（含 H2-1 的不确定性触发路径）被专门击败；发现 **Attention Collapse** 签名（被攻击生成 attention 熵下降集中在中毒文档），D-SCAN 轻量监控注意力动态，**能检测即使攻击未改变最终答案的情况**。RAGuard（2607.26339）给黑盒反事实过滤 ZKIP——leave-one-out decode 按移除引发的语义偏移+输出熵变化打分，无需毒标签/ground-truth/模型内部。
  - **证据冲突归因**：EvoTrustRAG（2608.07933）——**同一冲突可能源自合法知识演化/恶意操纵/未解决不确定性**，把「冲突来源归因」形式化为新问题（识别冲突证据的哪种解释被可观测上下文支持），而非简单选「更可信」方；span-grounded 事实建模成冲突证据图，用时序关系评估；协调攻击下错误率 31.2%→16.0%。
  - **来源腐败**：SecureCollaRAG（2608.04366）——多代理系统知识腐败，动态 GNN 可信度评分做文档来源验证，非 IID 下对抗鲁棒。
  - **接地幻觉**：Latent Critic（2608.10430）——agent **user specification-grounding failure**（执行幻觉动作而非表达不确定性）；轻量 LoRA 与冻结基模型并发，主动重构 residual stream 放大接地信号，单序列内局部化反馈；0.966 AUROC、>80% 局部化准确（如 ungrounded: date）。
- 依据：2608.06947、2607.26339、2608.07933、2608.04366、2608.10430
- 等级：A

**Q2. 攻击者如何利用检索？防御的边界在哪？**
- 结论：攻击者主要走「语料注入 + 冲突内嵌」两条路，且防御有结构性边界。
  - **DenialRAG（2608.02678）**：单文档毒化新设计——**显式命名正确答案、否认它、给攻击者控制的解释**，把正确答案与中毒答案放同一检索段落，把冲突直接嵌入生成器所见上下文；攻击强模型依赖（Mistral-7B 全数据集最高 ASR）；**防御非均匀保护，每个防御在某些设置留残余 ASR**。
  - **RAGuard 的威胁模型边界**：关键词保留的毒化让 BM25 类 lexical retriever 基本不受影响——检索器类型决定攻击面。
  - **总判（DenialRAG）**：**RAG 中毒风险不能用单一攻击族或单一目标模型完全刻画**——这是失败模式的结构性复杂度，意味着防御须覆盖多攻击族 × 多模型 × 多检索器。
- 依据：2608.02678、2607.26339
- 等级：A

**Q3. 对 Studium 锚点/可信红线的可移植模式？**
- 结论（C）：四点。（i）**不确定性信号在对抗语境下被专门击败**（假置信）——Studium 不能单靠「机械信号」（向量/检索分数/不确定性）做结案，这与「机械信号只定向不结案」红线在对抗语境下被强化：攻击者正瞄准机械信号。（ii）**冲突来源归因优于简单选边**（EvoTrustRAG）——Studium 既有审计晋升状态机（V/S 系列审计员）可借鉴「归因」思路：对冲突证据不只判「哪个可信」，而判「这个冲突是演化/操纵/未决中的哪一类」，再决定保留/隔离/暴露。（iii）**反事实 leave-one-out 是无标签黑盒充分性判据**（RAGuard ZKIP）——与 H2-1 F6 Bio-GRACE（决策收益恢复度）同源，都是「移除/加入某证据的边际效应」度量，可作 Studium 锚点校验的补充判据。（iv）**Attention Collapse / Latent Critic 的「内部信号」依赖模型内部访问**——闭源 API 不可用，Studium 若用闭源须退到反事实/外部启发式（ZKIP 路径）。
- 依据：2608.06947、2608.07933、2607.26339、2608.10430
- 等级：C（迁移模式推断）

## 2. 关键发现

**F1. 【When Context Bites / D-SCAN：蓄意攻击诱导「假置信」，attention collapse 签名检测，能抓未改变答案的攻击】**
- 论断：RAG 易受毒化攻击；先前方法靠输出侧信号（困惑度/一致性检查）检测；分析揭示**蓄意攻击常诱导假置信——中毒输出困惑度甚至比良性输出更低，使基于不确定性的检测失效**；探索生成器内部动态，识别 **Attention Collapse** 签名（良性生成注意力分散，被攻击生成熵下降集中在中毒文档）；D-SCAN（Document-level Signal Collapse Analysis）轻量监控注意力动态；多攻击基准有效；**能检测即使攻击未改变最终答案的情况**。
- 来源：arXiv 2608.06947，abs 页 arxiv_abs_2608.06947.html；published 2026-08-07；代码 github.com/yingtaoren/D-Scan.git
- 原文摘录：「deliberate attacks often induce false confidence, where poisoned outputs exhibit even lower perplexity than benign ones, rendering uncertainty-based detection ineffective」；「attacked generations exhibit a decrease in entropy as attention concentrates on poisoned documents」；「D-SCAN can detect attacks even when they fail to alter the final answer」
- 等级：A

**F2. 【EvoTrustRAG：冲突来源归因（演化/操纵/未决），非简单选边，协调攻击错误率 31.2%→16.0%】**
- 论断：RAG 改善幻觉但引入知识腐败漏洞；检索证据冲突是动态/对抗环境根本挑战；现有方法把冲突当静态不一致选更可靠方，忽略**同一冲突可能源自合法知识演化/恶意操纵/未解决不确定性**；把**冲突来源归因**形式化为新问题（识别冲突证据的哪种解释被可观测上下文支持，而非哪个事实该信）；EvoTrustRAG training-free，span-grounded 事实建模成冲突证据图，用时序关系/支持结构/辅助一致性评估 grounded evolution 与 directional intervention 假设，投影到全局一致解释；归因决定早/晚态保为时序知识/干预候选隔离开/未决冲突暴露给生成器；与事后 provenance 方法不同，推理期判定；benchmark-native 冲突 81.4%、attribution macro-F1 72.2%→79.1%、协调攻击错误率 31.2%→16.0%。
- 来源：arXiv 2608.07933，abs 页 arxiv_abs_2608.07933.html；published 2026-08-08
- 原文摘录：「the same conflict may arise from legitimate knowledge evolution, malicious manipulation, or unresolved uncertainty」；「identifying which explanation of conflicting evidence is supported by observable context rather than simply which fact should be trusted」；「reduces the error rate under the strongest coordinated attack from 31.2% to 16.0%」
- 等级：A

**F3. 【SecureCollaRAG：拜占庭容错协作 RAG，动态 GNN 可信度评分做来源验证】**
- 论断：RAG 部分解决幻觉但引入知识腐败攻击漏洞；敌手毒化 RAG 提供的文档操纵 LLM 输出；SecureCollaRAG 拜占庭容错协作 RAG 框架，用多源知识验证机制；agent 系统通过动态 GNN 可信度评分安全验证文档来源，防隐蔽知识腐败同时保领域知识完整性；形式分析 + 评估示非 IID 数据下对攻击者鲁棒。
- 来源：arXiv 2608.04366，abs 页 arxiv_abs_2608.04366.html；published 2026-08-05
- 原文摘录：「a Byzantine-tolerant collaborative RAG framework leveraging Multi-source Knowledge Validation Mechanism」；「dynamically verify document provenance through GNN-based credibility scoring」
- 等级：A

**F4. 【DenialRAG：单文档毒化显式否认正确答案，攻击强模型依赖，风险不可单族/单模型刻画】**
- 论断：RAG 易受语料毒化——攻击者插 crafted 文档操纵 LLM 走向攻击者选定的错答案；先前单文档攻击避免在毒段落内显式命名并反驳正确答案；DenialRAG 互补设计——**显式命名正确答案、否认它、给攻击者控制的解释**，把正确答案与中毒答案放同一检索段落，把冲突直接嵌入生成器所见上下文；4 已发表单文档攻击 ×3 开放域 QA 数据集 ×8 目标 LLM（4 厂商）×5 推理期防御评估；攻击强模型依赖（Mistral-7B 全数据集最高 ASR、其他 LLM 多数有效、某模型区间其他攻击占优）；防御有实质 ASR 降低但非均匀保护（每防御某设置留残余 ASR）；组件级与跨模型分析示 embedded denial 是最具影响力的被测组件；不同毒化机制在不同模型组以不同速率失效力；**RAG 中毒风险不能用单一攻击族或单一目标模型完全刻画**。
- 来源：arXiv 2608.02678，abs 页 arxiv_abs_2608.02678.html；published 2026-08-02
- 原文摘录：「explicitly names the correct answer, denies it, and presents an attacker-controlled explanation」；「each defense leaving residual ASR in some settings」；「RAG poisoning risk cannot be fully characterized by a single attack family or a single target model」
- 等级：A

**F5. 【RAGuard：分层防御，ZKIP 黑盒反事实 leave-one-out 过滤，ASR→0.000，关键词保留毒化让 BM25 基本不受影响】**
- 论断：RAG 接外部语料但暴露于语料毒化（恶意注入段落操纵检索证据）；RAGuard 分层防事实型语料毒化——第一层对抗微调 dense retriever（合成毒文档：捏造事实/矛盾/推理陷阱）教它下推恶意段落；第二层 **ZKIP（Zero-Knowledge Inference Patch）**无标签黑盒过滤：每检索文档做 leave-one-out decode，按移除引发的语义偏移+输出熵变化打分；**无需毒标签/ground-truth/模型内部访问**，对比模型在反事实上下文下的自身答案；中毒 NQ 5-30% 比例下对抗检索器训练单独降但不除 ASR，ZKIP 把测得 ASR 驱到 0.000、Recall@5 在基线 0.03 内；监督分析示反事实信号带可学毒结构；代价 k+1 次生成/查询（k=5 时 6×）；**关键词保留的毒化让 BM25 类 lexical retriever 基本不受影响**（划定威胁模型边界）。
- 来源：arXiv 2607.26339，abs 页 arxiv_abs_2607.26339.html；published 2026-07-28
- 原文摘录：「a leave-one-out decode and scores the document by the semantic shift and output-entropy change that its removal induces」；「ZKIP drives the measured attack success rate to 0.000 in every defended configuration」；「keyword-preserving poisons leave lexical retrievers such as BM25 essentially unaffected」
- 等级：A

**F6. 【Latent Critic：agent user-specification-grounding 失败检测，潜在空间局部化，0.966 AUROC】**
- 论断：作 AI agent 的 LLM 频繁表现 user specification-grounding 失败——执行幻觉的不期望动作强行解决而非表达不确定性；现有检测无法提供可操作实时纠正（不局部化幻觉或推理延迟过高）；Latent Critic 轻量低秩 LoRA 与冻结基模型生成并发运行，主动重构 transformer residual stream——放大潜在接地信号、单序列内翻译成局部自然语言反馈；精炼基模型原生不确定性信号，无二次推理循环开销；机制分析（activation patching + layer-wise probing）示 rank-invariant 行为把既有不确定性几何重构成线性可分表示；工具调用作为细粒度幻觉实例化，跨 Qwen/Llama 验证；实时效优于等规模微调外部检测器/语义熵基线/被动内部探针；0.966 AUROC、>80% 局部化准确（如 ungrounded: date）；ReAct 闭环作可忽略延迟护栏，执行前拦截幻觉防不期望动作并赋能 agent 自纠正。
- 来源：arXiv 2608.10430，abs 页 arxiv_abs_2608.10430.html；published 2026-08-11
- 原文摘录：「executing hallucinated, undesired actions to force a resolution rather than expressing uncertainty」；「amplifying latent grounding signals and translating them into localized, natural language feedback within a single sequence」；「0.966 AUROC and >80% accuracy in localization (e.g. ungrounded: date)」
- 等级：A

## 3. 对决策点的输入
- 可移植模式 = **「检索失败模式须多层异质防御 + 显式冲突归因：不确定性信号在对抗语境被击败（假置信）→ 用 attention collapse / 反事实 leave-one-out；冲突须归因来源（演化/操纵/未决）而非选边；多代理须拜占庭容错来源验证；接地幻觉须潜在空间局部化检测」**。
- **与 H2-1 的攻防闭环**：H2-1 把触发信号建在「不确定性」（F2 insufficiency/ambiguity）上；H2-2 F1 揭示**蓄意攻击专门制造假置信击败不确定性信号**——所以 H2-1 的不确定性触发须叠加 H2-2 的 attention collapse / 反事实检测才抗对抗。二者构成「何时检索（H2-1）+ 检索坏了怎么办（H2-2）」闭环。
- **与 Studium 红线的强化交叉点**：（i）「机械信号只定向不结案」在对抗语境被强化——假置信击败困惑度信号，须异质信号（attention + 反事实 + 来源验证）；（ii）[[anchor-verification-blind-spot]] memory（grep 逐字校验必要性）与 RAGuard ZKIP（反事实 leave-one-out）+ H2-1 F7（原子 nugget 不用 LLM 判官）共振——都是「不用单一信号/单一判官结案」；（iii）时序锚定：EvoTrustRAG 的「冲突来源归因（演化/操纵/未决）」把 H2-1 的 temporal misgrounding 从「检测」推进到「归因」。

## 4. 与范围/红线的冲突张力
- 无红线冲突。切分边界：聚焦「检索失败模式（毒化/冲突/腐败/幻觉）」，不展开完整对抗机器学习训练（对抗微调 retriever 只取防御思路）、不展开 GNN 可信度训练工程（SecureCollaRAG 只取机制）。
- F4「防御非均匀且各留残余 ASR」与「有完美防御」直觉张力——如实标 A 实证，是结构性警示非冲突。

## 5. 未决与风险
- F1/F6 的 attention collapse / latent critic 依赖模型内部访问（注意力权重/residual stream），闭源 API 不可用 → Studium 闭源须退到 F5 ZKIP 反事实路径（黑盒）。
- F4 的攻击强模型依赖（Mistral-7B 最高 ASR）——大模型是否更鲁棒未确认 → 标 OPEN。
- EvoTrustRAG（F2）的「冲突来源归因」training-free 但依赖时序元数据；语料无版本时间戳时退化为静态冲突 → Studium 须保时序元数据才能用满。

## 6. 建议的下一步
- 方向2 收口：H2-1（触发+充分性）+ H2-2（失败模式）合成「LLM 时代知识检索决策点」——何时检索、检索是否够、检索坏了怎么办三问合一。
- 把 F2「冲突来源归因」与 Studium 审计晋升状态机对照（可能同构：审计员对冲突证据做归因而非选边）。
