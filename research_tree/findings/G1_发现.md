## 0. 一句话结论

OntoMath（KESW2014 四类 object property + 2.0 reified relationship 模式）与 Math-KG 六关系**可逐条降级映射到 M08 9+other**，但**无一域词汇可替换封闭词表**——强匹配走 9 核（requires/equivalent/contrasts/alias-of/part-of/applies-to），弱匹配与 2.0  reification 一律 **`other`+`rel_note`**，并附 `externalRel` 记录来源 IRI/名称（C 级字段建议）。Math-KG 因 85% ERC F1 **只作 M05 前驱候选输入**，不自动写 M08 正式边。Apostol Ch10 spot-check 证实现有图已在用 `other`+label 承载域外语义，与对照策略一致。

## 1. 父会话问题逐条回答

### Q1. 能否逐条映射到 9+other？

**能。** 对照表如下（C 级规程，A 级来源挂各行）：

#### Math-KG 六关系 → M08

| Math-KG rel | 语义（A） | 建议 M08 rel | rel_note 模板 | 等级 |
|---|---|---|---|---|
| dependencies | 学习顺序依赖 | **requires** | `ext:MathKG/dependencies` | A→C |
| equivalence | 同名异写/同义 | **equivalent** | `ext:MathKG/equivalence` | A→C |
| synonyms | 近义 | **alias-of** | `ext:MathKG/synonyms` | A→C |
| opposite | 概念对立 | **contrasts** | `ext:MathKG/opposite` | A→C |
| affiliation | 包含/被包含 | **part-of** 或 **is-a**（须人工判层级） | `ext:MathKG/affiliation; sense=containment` | A→C |
| has properties | 另一概念的属性 | **other** | `ext:MathKG/has_properties; prefer=node_field` | A→C |

**裁决（C）**：`has properties` 优先改**节点字段**（06-M08 §3：属性不当边）；若必须连边 → other。**affiliation** 不能自动判 part-of vs is-a（层级歧义）→ 候选池 + 人工审计。

#### OntoMath KESW2014 四类 property → M08

| OntoMath property | 语义（A） | 建议 M08 rel | rel_note | 等级 |
|---|---|---|---|---|
| P1 defines / P2 is defined by | 定义依赖（定义文显式引用） | **requires** 或 **implies** | `ext:OntoMath/defined_by` | A→C |
| P3 belongs to / P4 contains | 对象↔数学领域 | **other**（非 pedagogical 边） | `ext:OntoMath/field; dst=discipline` | A→C |
| P5 see also | 弱关联，≈ rdfs:seeAlso | **alias-of** 或 **other** | `ext:OntoMath/see_also` | A→C |
| P6 solves / P7 is solved by | 方法↔任务 | **applies-to** 或 **other** | `ext:OntoMath/solves` | A→C |

#### OntoMathPRO 2.0 reified relationship → M08

| 2.0 模式 | 语义（A） | M08 承载 | 等级 |
|---|---|---|---|
| Relationship-as-concept（如 Divisibility） | 数学事实=reified 关系实例 | **不进 9+other 边**；可选 **statement 节点** + 参与者 role 字段，或仅 `externalRef` | A→C |
| hasArgument 链 | n 元关系参与者 | 节点字段 `arguments[]` / members 模式 | A→C |

**2.0 与 1.0 关系**：1.0 的 flat property 在 2.0 被 reified 取代（A，2303.13542）；对照表对 1.0 property 仍有效作**降级参考**，生产图不 import OWL 属性为 M08 rel。

### Q2. 无法一一映射如何处理？

1. **禁止**新增第 10 个 rel token（9+other 红线）。
2. **other 必填 rel_note**：格式建议 `ext:{Source}/{relName}[; key=val]`（C）。
3. **externalRel**（开放节点字段，C）：`{system, rel, src, dst, confidence}` 保留域本体原名，供统计与候选同义表。
4. **Math-KG / OntoMath 输出只进候选池**（V3 Q3、85% F1）→ M05 定向或 M08 审计晋升，不自动写正式边。
5. **field/discipline 类**（P3 belongs to）→ 节点 metadata `disciplineRef`，非边（C，与 V3「开放节点字段」一致）。
