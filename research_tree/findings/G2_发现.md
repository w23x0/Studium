# 叶子 G2 M08 节点 schema 形态/语义字段分界 调研发现

> 任务 G2 / 日期 2026-08-14 / A B C 同 V7 约定

> 基线：V7 Q3、06-M08 §3/§8、存储 v1.3

## 0. 一句话结论

M08 节点 schema 应拆为 **形态层（进 L1 RDF + SHACL + FHIR 式 versionId）** 与 **语义层（外部计算或只读注释）**：形态层承载 id、kind、statement、结构字段（hypotheses/conclusion/members/boundary/abstraction_gain）、封闭 rel+rel_note、锚点引用、externalRef/QUDT/DLMF IRI、派生 embedding 字面量；语义层承载可推导性、do-干预、程序采样、向量身份、FSRS 间隔数值——**永不写入 M09 证据边数值**。触发 versionId 变更的是**内容承载字段**（statement/结构字段/rel/evidence 锚点绑定），纯派生 embedding 与外部检索分数不触发（C）。

## 1. 父会话问题逐条回答

### Q1. 形态层字段（L1 RDF + SHACL）

| 字段组 | 字段 | 说明 | 等级 |
|---|---|---|---|
| 身份 | `id`, `kind`/`node_type` | IRI 稳定身份；kind 封闭枚举 | A local |
| 陈述 | `statement`, `name`, `aliases[]` | 可 grep 正文对齐 | A local |
| 定理结构 | `hypotheses[]`, `conclusion` | §8 证明对象形态 | A local |
| 抽象候选 | `members[]`, `boundary`, `abstraction_gain` | L2 抽象审计三必需 | A local |
| 边（独立三元组） | `rel`（9+other）, `rel_note` | SHACL sh:in 封闭 | A local + P3 |
| 证据 | `evidence[].anchor{file,quote}` | 锚点绑在 L0 正文 | A local |
| 外部对齐 | `externalRef[]`, `skos:exactMatch` | OntoMath/QUDT/DLMF/Wikidata | A V3 + C |
| 量纲试点 | `qudt:quantityKind`, `qudt:unit`, `qudt:dimensionVector` | notation/physics 节点 | A QUDT + C |
| 派生注释 | `embedding[]`（字面量） | 向量只定向，可丢弃重建 | A V7 |

**SHACL**：校验形态层形状；不校验语义层真值（V3/V7）。

### Q2. 语义层（RDF 外或只读挂靠）

| 语义 | 存放 | 禁止 |
|---|---|---|
| 形式证明可导 | 外部 proof checker / Lean 会话 | 不作为 M08 写入闸门 |
| 因果 do(·) | 外部 SCM 引擎或注释 URI | 不用 PROV 冒充干预 |
| 概率程序执行 | 外部采样器 | 不把 posterior 写进 evidence |
| 向量身份/相似度 | 候选池分数、M08 检索日志 | 不结案、不赋 evidence 边权 |
| FSRS S/D/R | M05 调度域 | 不进 M09 数值（V5） |
| OWL RL 推理闭包 | 可选候选扩展 | 只定向（V3） |

等级：A（V7 OWL2/PROV/Pearl + V5 FSRS + local §8）。

### Q3. L2 versionId 触发对齐（C 草案）

**触发新版本（content change）**：
- statement / hypotheses / conclusion / members / boundary / abstraction_gain 任一变更
- rel 或 rel_note 变更；evidence 锚点集合变更
- verificationStatus 等效状态变更（M09 资源，见 G3）

**不触发版本（derived / index）**：
- embedding 向量重算
- 外部 IRI 解析缓存
- 候选池分数、检索排名

**落 RDF**：每版本一个命名图（v1.3 L2）；形态层三元组进版本图，默认图放 versionId 元数据。
