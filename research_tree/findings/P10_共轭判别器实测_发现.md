## 0. 一句话结论

在 Studium 自有语料（Apostol 微积分卷1）上，**「共轭判别器涉险」不能按维度一刀切**（K4 触发清单 (b)「时间/版本/数值/规则/跨源身份」过粗）：12 个代表性查询 → **satisfied 6 / confound 3 / at-risk 3**。规则维的 ≥0 vs >0 严格性在 L0/L1 字符串层**可 grep 区分**（不涉险）；数值维 3/4 涉险但 N2「Warning」独特串满意；**真正的涉险点两类**：①决定性串被共享（"the test is inconclusive" 同命中 root/ratio → confound）；②答案需跨实体关系（级数↔瑕积分身份、10.23-10.25 版本对应、调和级数作反例 → at-risk）。可操作代理 = **决定性串 grep 唯一性检查**。

## 2. 对 K4 结论的裁决（C）

1. **触发清单 (b)「共轭判别器涉险」需细分**：数值/规则维并非天然涉险——R1/R2 的严格性差异（≥ vs >）是字符串层可 grep 区分的独特串；N2 的 "Warning" 标记独特可 grep。**涉险与否取决于「决定性串是否独特可 grep」而非维度标签**。
2. **真正涉险点（两型）**：
   - **confound 型（决定性串被共享）**：N1（\|x\|<1 跨 4 概念）、N3/N4（"inconclusive" 同命中 ratio/root）——同串多义，grep 需要上下文消歧。
   - **at-risk 型（答案需跨实体关系）**：I1（身份类比需边 e-G4-019）、V1（版本对应需边 e-G4-018/019）、C1（反例连接需边 e-G2-005）——决定性事实在**边**承载，单节点文本 grep 不满意。
3. **M1 反直觉修正**：「多跳」维不必然涉险——ratio/root 的定义文本**直接含**"special case of the comparison test"，源定理在单节点内可答（K4 (a)「复杂多跳」对"源自/派生"型查询需收紧）。
4. **对 M07/M08 可移植判据**（C）：检索触发前跑「决定性串 grep 唯一性检查」——唯一命中 gt → 简单检索满意、不升级；被共享 / 需跨边 → 触发重估。此为 K4 §5 风险 1 的「简单检索能否满意」代理的**可操作化**。

## 3. proxy 边界（C）

- 查询集为人工构造的代表性样本（12 题，非穷尽）；维度覆盖 simple/numeric/rule/identity/version/multi-hop。
- 决定性串选择含人工判断（选「决定答案的最短独特串」）；换串可能改变 confound/satisfied 边界。
- 语料单书单版本；V 维在此语料退化（用 10.23-25 级数↔瑕积分「对应版本」近似），真实多版本语料需另测。
- 未覆盖：混合型查询（同题多维）、时间敏感事实（教材静态无时效）。
