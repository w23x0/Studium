## 0. 一句话结论

MaRDI/OntoMath/QUDT/DLMF/MathGloss 等 C 族本体与知识图谱，**适合作为 M08 节点字段、外部参考 IRI 与量纲/公式对象粒度的先例库**，**不能替代 M08 封闭 9+other 边关系词表**——它们要么关系词汇开放/稀疏（MaRDI Wikibase、OntoMathPRO 自述关系贫乏），要么根本不是 pedagogical 边（QUDT 量纲、DLMF 特殊函数）。与 v1.3 L1 的整合形态是：**M08 实例三元组 + SHACL 封闭校验为主真源；域本体 IRIs 作 skos:exactMatch / 节点 `externalRef` 降级映射，不整库 OWL-import 当 M08 边词表**。OWL/RL 推理在开放世界下**_sound 但可能 incomplete_**，与「机械信号只定向不结案」同向——**推理=候选/索引/审查提示，结案仍靠锚点+人工审计，SHACL 仍只做只读审计层**。

## 1. 父会话问题逐条回答

### Q1. MaRDI/OntoMath/QUDT/DLMF 等对 M08 概念/关系词表的参考（结合 9+other 红线）？

**结论：可参考对象/字段/外部权威 IRIs；不可参考为边关系词表扩展。**

| 来源 | 粒度与词汇 | 对 M08 9+other 的参考方式 | 等级 |
|---|---|---|---|
| **MaRDI** | Wikibase KG：数据集/软件/论文/**公式/假设**等多模态对象；>1 亿三元组；社区可扩展属性 | 公式/假设/研究对象类型 → **节点类型与开放字段**先例；边关系随 Wikidata 属性开放，**非封闭 9 词** | A |
| **OntoMathPRO 2.0** | 三层（foundation/domain/linguistic）；对象层次 + **reified relationships**；OWL DL | 数学陈述 LOD 表示 → **概念对象字段**（陈述/对象/关系 reification）；1.0 仅 **5 类关系**且作者称关系集「相当贫乏」——**不够也不应替换 9+other** | A |
| **OntoMath 生态** | Mocassin（文档逻辑结构）+ OntoMathPRO（数学知识） | 文档结构 vs 知识对象分离 → 与 M06/M07 vs M08 边界同向；**不提供 M08 边词表** | A |
| **QUDT** | quantity kind / unit / dimension / datatype 的 RDF 词表 | **notation/physics 量纲节点元数据**；零 pedagogical 边 | A |
| **DLMF** | 特殊函数权威数字库；机器可读标注 | **notation/method 节点的外部权威引用**；非通用概念图词表 | A（站点权威；正文页 2026-08-14 抓取超时，见 §5） |
| **Math-KG** | 2 实体类型 + **6 关系**（dependencies/affiliation/equivalence/opposite/synonyms/has properties）；NLP 抽取 F1≈85% | 与 9+other **部分同义映射**（dependencies≈requires, equivalence≈equivalent…）可作**对照表**，不能当权威词表（抽取噪声） | A |
| **MathGloss** | 本科术语 ↔ Wikidata Q-id；多源术语对齐 | **alias-of / equivalent 外部对齐**先例；显式承认 Wikidata **链接稀疏**、需人工 | A |

**对 9+other 红线的裁决（C）**：域本体的关系枚举（OntoMath 5 类、Math-KG 6 类）只能进 **`other`+`rel_note` 统计与候选同义表**，不能扩成开放边词表——与 §3 实测「放开词表掩盖字段建模错误」一致。开放的是**节点字段**（量纲、公式、外部 QUDT unit IRI 等），不是 rel 谓词。

### Q2. OWL/RDF 本体层与 L1 RDF 语义层（v1.3）整合——直接承载还是降级映射？

**结论：降级映射 + 并存参考图；M08 实例不整库 OWL-import 为边词汇。**

- v1.3 已定 L1 = **RDF 1.2 + TriG 命名图**，M08 关系词表 = **闭合 valueSet 或 SHACL sh:in**（P3 实测），SHACL = **只读审计层、非日常门禁**（A，本地 v1.3 + P3）。
- OntoMathPRO **用 OWL DL 表达**（A，2303.13542）——技术上可进同一 RDF 存储，但：
  1. **M08 节点/边实例**须服从 SHACL 形状与 9+other 封闭；
  2. **域本体类/属性 IRIs**（QUDT unit、Wikidata Q、DLMF entry）作为节点上的 **`externalRef` / skos:exactMatch / owl:sameAs（仅当人工审计确认）** 降级引用；
  3. **不**把 OntoMath/MaRDI 的开放 Wikidata 属性直接映射为 M08 生产边——否则破坏统计、`other` 体温计与审查。
- MaRDI 选 Wikibase 的理由包括「完成后可并入 Wikidata」（A）——与 Studium「个人/通用知识分离、四图不合并」一致的做法是：**只借 IRIs，不合并图**。

等级：A（OntoMath/MaRDI/QUDT 原文 + v1.3 本地）+ C（映射规程）。

### Q3. 本体推理在「开放字段稳定查询审查 + 机械信号只定向不结案」中的定位？

**结论：推理 = 定向（候选/索引/不一致提示）；结案 = 锚点 + 闭环审计 + SHACL 只读复核。**

- W3C OWL 2 Overview：**OWL 2 RL 在任意 RDF 图上 reasoning sound，但 may not be complete**——「不能保证所有正确查询答案都被算出」（A，w3c_owl2_reasoning 快照）。开放世界下缺少三元组 ≠ 否定。
- 因此 OWL 分类/继承推理 **不能**当「掌握/未掌握」「关系成立」的结案机制——只能提示「可能子类/可能等价/可能冲突」→ **机械信号只定向**。
- v1.3 已把 **SHACL 定位为秒级只读审计**（P2 实测 522 节点 ~8s）——与 OWL 推理互补：**SHACL = 形状违规报告（审查）**；**OWL RL = 可选候选扩展（定向）**，二者都不是写入闸门。
- Math-KG 关系抽取 85% F1（A）与 MathGloss「wikimapper 消歧 imperfect」（A）共同说明：**NLP/本体对齐输出只能进候选池**，与 M08 候选池+审计晋升同构。

等级：A（W3C + Math-KG/MathGloss 局限）+ C（与 Studium 红线映射）。

## 3. 对决策点的输入

1. **六族取舍（C 族）**：C 族**进入 Studium 的方式 = 参考 IRIs + 节点字段先例**，不进入方式 = **替换 M08 边词表或 OWL-import 开放边**。MaRDI/OntoMath 支持公式/陈述对象；QUDT/DLMF 支持理科 notation/量纲；MathGloss/Math-KG 支持术语对齐与部分关系同义对照。
2. **与 v1.3 整合**：L1 承载 M08 三元组 + 可选命名图存外部本体片段；**降级映射**（externalRef/skos）而非本体直驱生产写入。
3. **服务 M08 检索**：Wikidata Q、QUDT unit IRI、DLMF entry 作 **定向检索线索**（同 V6 向量/图「只定向」）。
4. **服务 M05/M04**：Math-KG `dependencies` 仅作 **前驱候选**（85% F1，不结案）；OntoMath 关系贫乏 → 不能自动补全 M05 路线。
5. **§8 基线验证**：C 族印证「瓶颈在验证不在表达力」——OWL 推理 incomplete、NLP 本体抽取有噪声，与 V7 五家族结论一致。

## 4. 与范围/红线的冲突张力

- **9+other 封闭**：无冲突；域本体开放关系 **不得**扩边词表（张力：OntoMath 5 类、Math-KG 6 类看似「更少」，但语义不同且来源噪声 —— 只能进 rel_note/对照，不能替换 9+other）。
- **机械信号只定向**：无冲突；OWL RL incomplete + Math-KG 85% F1 强化。
- **四图不合并**：MaRDI→Wikidata 合并愿景与 Studium 通用/个人分离 —— 只借 IRI，不合并图（C）。
- **无红线被推翻**。
