## 0. 一句话结论

**2024–2026 的 LLM 检索把「是否检索」从静态工程决策演进为「推理步骤级/自触发的生成内决策」：触发收敛为三条件（查询复杂度、知识不足/不确定性、效用-成本边界），放弃=参数知识足够或停止条件达成——检索是决策不是管道（2403.14403 / 2404.19705 / 2604.26649 / 2604.11407 / 2606.02245 / 2607.24791）。图检索的 2024-26 新证据不推翻 V6「维持等触发」，但修正了 V6 的触发清单：V6 只列了「复杂多跳 + 决定性事实在训练外」，2025-26 新增了 V6 未覆盖的**时间/版本判别**轴——静态向量与普通图会把「同一事实的不同版本」混为一条（2510.13590 / 2506.05939 / 2501.13956），而这恰恰是 Studium 版本化语料的形态；故 V6 的「训练外」判据应改为可操作的「共轭判别器」（时间/版本/数值/规则/跨源身份），M07/M08 引入检索的可移植模式=代价感知升级阶梯 + 参数知识优先 + 停止条件 + 版本感知索引（若上检索则必做，否则静态 RAG 会自信误引不适用的版本）。**

## 1. 父会话问题逐条回答（每问：结论+依据+等级）

### Q1 2024–2026 LLM 检索主流形态与触发条件？何时检索、用参数知识、还是放弃？

**结论：形态从「复杂度路由」（2024）演进到「推理步骤级不确定性触发」（2025-26）与「检索作为生成内决策（自触发 control token）」（2026），触发条件收敛为三条，放弃条件有明确判据。**

- **形态演进（A）**：
  - 2024 锚点=**复杂度路由**（2403.14403 Adaptive-RAG）：小分类器预测查询复杂度，在「不检索/单步/迭代」间动态选择——「dynamically select the most suitable strategy for (retrieval-augmented) LLMs from the simplest to the most sophisticated ones based on the query complexity」；以及**参数记忆优先**（2404.19705 When to Retrieve）：教 LLM 在不知道时生成 `<RET>` 特殊 token——「the optimal strategy for question answering does not always entail external information retrieval; rather, it often involves leveraging the parametric memory of the LLM itself」（PopQA：最热问题参数记忆即可，冷门才需 IR）。DRAGIN（2403.10081）用 LLM 内部不确定性动态触发、从全上下文构造查询。
  - 2025=**推理模型内 agentic 检索**（2501.05366 Search-o1：LRM 推理中遇到不确定知识点动态检索）；**多轮自我怀疑**（2505.02811 SIM-RAG：学何时停止继续搜索——「may continue searching even when enough information has already been retrieved, or…provide incorrect answers without having sufficient information」）。
  - 2026=**步骤级触发**（2604.26649 ReaLM-Retrieve：step-level uncertainty detector 在推理步骤粒度识别知识缺口；比 IRCoT 固定间隔少 47% 检索调用，MuSiQue 71.2% F1 仅 1.8 次检索/问）；**检索=生成内决策**（2604.11407 GRIP：模型经 control token 发射在单条自回归轨迹里决定何时检索、如何改写查询、何时终止）；**代价感知**（2606.02245 Cost-Aware RAG：检索不免费，付费/受限语料下「static selection is brittle: no fixed selector uniformly dominates, and larger budgets do not reliably improve answer quality」；2607.24791 PEA-CAE：企业生产管线「begin with low-cost, high-precision retrieval and escalate to full-document reads only when the expected evidence gain justifies latency and cost」）。
- **触发条件收敛（C 综合，各点 A）**：①查询复杂度/难度（2403.14403）；②知识不足/不确定性（2403.10081、2501.05366、2604.26649、2404.19705 的 `<RET>`）；③效用-成本边界（2606.02245、2607.24791；检索只在边际收益超过不检索答案与代价时触发——与并发会话 H2-1 的 utility-estimation 2607.24010 同向，本卡给出其 2024-25 锚点与 2026 自触发/步骤级实现）。
- **何时用参数知识/放弃**：参数记忆优先于检索（2404.19705；2401.08406 RAG vs Fine-tuning 给出 RAG/微调/混合的权衡，参数内化在高质量小语料上可胜过检索——与 H2-1 F8 同向）；放弃=检索充分时停止（2505.02811 停止条件）或检索伤害（2511.05302「more retrieval can hurt: using only the top-1 retrieved example works best」——多检索反而降质）。
- **等级：A（各论文摘要原文 curl 到手）+ C（综合）**。

### Q2 图检索（GraphRAG/KG-grounded）何时真有用？2024-26 新证据支持还是推翻 V6「维持等触发」？

**结论：核心负面结论全部被 2024-26 新证据支持（V6 不被推翻），但 2025-26 新增了 V6 未覆盖的「时间/版本判别」正向轴；对 Studium 而言该轴比 V6 原触发轴更可能点燃，故 V6 触发清单需补一条而非维持原样。**

- **支持 V6 的证据（A）**：2501.13958（2025 年 GraphRAG 综述）确认图的价值域=专业域多跳关系推理与结构感知知识整合；V6 已挖的 2606.25656「retrieval-generation gap where expanded retrieval does not proportionally improve generation quality」与 2506.05690「Basic RAG is comparable to or outperforms GraphRAG in simple fact retrieval」仍是当前主流负面结论。2511.05302 的「多检索有害」在非图设置同样成立——检索过量是普遍问题。
- **修正/新增——逻辑结构与时间结构（A）**：
  - KAG（2409.13731，蚂蚁/专业域）指出向量 RAG 的两类失效：向量相似度与知识推理相关性之间的鸿沟 + 「insensitivity to knowledge logic, such as numerical values, temporal relations, expert rules」——图/逻辑结构在**数值、时间、专家规则类知识**上补向量之不足。这是 V6「多跳」之外的第二个正向判据：**知识携带向量相似度无法区分的结构判别**。
  - TG-RAG（2510.13590）：「Same facts of different time are difficult to distinguish with vector embeddings or conventional knowledge graphs」——**普通图也会把不同时间的同一事实混为一条**；双层时间图把「同一事实不同时间」建为显式不同边以消歧；配 ECT-QA 数据集测增量更新。
  - E²RAG（2506.05939）：「KG-RAG frameworks collapse every mention of an entity into a single node, erasing the evolving context that drives many queries」——**KG-RAG 的实体折叠是时序查询的失败模式**；实体-事件双图（bipartite）保留时序-因果刻面，在 ChronoQA 上胜过无结构与普通 KG-RAG 基线。
  - Zep/Graphiti（2501.13956）：agent memory 用时间感知知识图维护历史关系；「existing RAG frameworks for LLM-based agents are limited to static document retrieval」——图在**动态知识 + 历史关系**上有正收益。
- **对 V6「维持等触发」的判定（C 综合）**：现判**维持**（简单事实/文档检索上建图仍是负资产，V6 的 M07/M08 现状映射不变），但 V6 的触发清单**需修订为三条**：(a) 复杂多跳/全局关系型查询；(b) 决定性事实非简单检索/参数已知可答；(c) **时间/版本敏感事实，适用版本是决定性判别器**（2025-26 新证据，V6 未列）。对 Studium（版本化语料）而言 (c) 比 (a)(b) 更可能点燃——若未来 M07/M08 引入检索，**版本感知索引是必要条件**（静态 RAG 会自信引用真实但不适用的版本，见 H2-1 F7 0% 命中日期适用版本）。
- **等级：A（各论文摘要）+ C（对 V6 判定修订）**。

### Q3 对 Studium M07/M08 检索的可移植模式？V6「触发=复杂多跳且决定性事实在训练外」是否仍成立？

**结论：V6 结论「半保持、需修正」；可移植模式=代价感知升级阶梯 + 参数优先 + 停止条件 + 版本感知索引 + 图只作锚点定向。**

- **V6 触发是否成立（C 综合）**：「复杂多跳」部分**成立**（2501.13958 综述、2506.05690 一致）；「决定性事实在训练外」部分**不可操作且被修正**——「训练外」无法提前判定，2025-26 给出更好代理：**决定性判别器是向量相似度无法区分的关系**（时间/版本/数值/规则/跨源身份，KAG 2409.13731 + TG-RAG 2510.13590 + E²RAG 2506.05939）。该修正与 Studium 红线同构（锚点判等=跨源/跨写法身份判别），比「训练外」可直接检查。
- **可移植模式（C 应用）**：
  1. **检索是代价感知决策**：从低代价高精度开始、证据增益足够才升级（PEA-CAE 2607.24791；2606.02245）。Studium 的 JSONL+grep 就是低代价层，升级到向量/图/LLM 前先证明增益。
  2. **参数知识优先**：通用教科书类内容模型已知→检索增量小（V6 K8；2404.19705；2401.08406）。Studium 自有审查产出（novel/私有）才是检索增强的正域。
  3. **充分性=停止条件**：不是 recall 最大化（2505.02811；2511.05302「多检索有害」；H2-1 F6 决策收益判据）。
  4. **版本感知索引若上检索则必做**：版本化语料用静态检索会时序误引（TG-RAG 2510.13590；H2-1 F7）。最省的合规形态=JSONL 层的版本标签+时间索引；时间图是一种更贵的实现，不必现在建。
  5. **若未来建图：节点/边锚定原文**（2604.04359 GroundedKG-RAG：每个节点边 grounded 在源句，可审计可读），图只定向、结论由锚点判等——与 V6 红线一致，且 2026 有了外部对应物。
- **等级：A（各依据）+ C（应用综合）**。

**F12. 【KAG：图的补向量域=数值/时间/专家规则的逻辑结构（非仅多跳）】**
- URL: https://arxiv.org/abs/2409.13731 | 标题: KAG: Boosting LLMs in Professional Domains via Knowledge Augmented Generation | 机构: 蚂蚁集团等 | 日期: 2024-09-10

**F13. 【时间图：同一事实不同时间，向量与普通图都难区分】**
- URL: https://arxiv.org/abs/2510.13590 | 标题: RAG Meets Temporal Graphs: Time-Sensitive Modeling and Retrieval for Evolving Knowledge (TG-RAG) | 日期: 2025-10-15
- 摘录: 「Same facts of different time are difficult to distinguish with vector embeddings or conventional knowledge graphs」；时间图「explicitly represents identical facts at different times as distinct edges to avoid ambiguity」；配 ECT-QA（时间敏感 QA，测增量更新）。
- 等级: A
- 意义: **普通图同样把不同时间的同一事实折叠**——这是 V6 触发清单的空白；时间/版本判别是图的第三正向域。

**F14. 【KG-RAG 实体折叠=时序查询失败模式；实体-事件双图修复】**
- URL: https://arxiv.org/abs/2506.05939 | 标题: Respecting Temporal-Causal Consistency: Entity-Event Knowledge Graphs for Retrieval (E²RAG) | 日期: 2025-06-06
- 摘录: 「KG-RAG frameworks collapse every mention of an entity into a single node, erasing the evolving context that drives many queries」；实体-事件双图保留时序-因果刻面，ChronoQA 上胜过无结构 RAG 与普通 KG-RAG 基线。
- 等级: A
- 意义: 对 Studium（版本化语料）最重要的一条：**普通 KG-RAG 会因实体折叠而抹掉演化上下文**；需事件/版本粒度才可用。

**F15. 【时间感知图作 agent 记忆：动态知识+历史关系的正收益】**
- URL: https://arxiv.org/abs/2501.13956 | 标题: Zep: A Temporal Knowledge Graph Architecture for Agent Memory | 机构: Zep 公司 | 日期: 2025-01-20
