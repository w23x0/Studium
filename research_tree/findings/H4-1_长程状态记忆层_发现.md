# 叶子 H4-1 长程状态与记忆层 调研发现

> 任务 H4-1 / A=原文到手 B=二手转引 C=推断
> 调研主题：LLM agent 的长程状态/记忆系统——记忆如何组织、固化、检索、治理、演化；接 H3-1 ChronoMem + H3-3 记忆窗口种子
> 时间锚定：外部文献全部 2024-01 后（本叶 6 篇均为 2026-08，主题热门）

## 0. 一句话结论
**2024–2026 的 agent 长程记忆已从「select–store–retrieve」范式成熟到「按语义段固化 + 事件中心联想回忆 + 治理化双时态状态机 + 受控干扰 + 充分性早停」五维并进，且出现三个直接对接 Studium 架构的机制：（i）Governed Persistent Memory（GPM）把记忆做成可审计双时态状态转移模型 + 来源绑定准入 + fail-closed 释放——与 Studium 审计晋升状态机 + 版本化锚点高度同构；（ii）LycheeMemory 的「语义段级固化」给出记忆准确-成本权衡的判据=不只保留什么、还以什么粒度固化；（iii）CMI 的「受控记忆干扰」实证记忆演化非单调（新经验可强化/修订/干扰既有态），与 H1-1 Backfires 污染不可逆跨方向共振。** 记忆瓶颈已被重述为「在相关信息分布多交互时恢复正确证据集」（RippleMem/Router-Mem），且记忆充分性可早停判定（Router-Mem 单 token 决策），呼应 H2-1 检索充分性。

## 1. 父会话问题逐条回答

**Q1. 长程记忆如何组织与固化以平衡准确与成本？**
- 结论：固化粒度是关键变量，语义段级优于 turn 级。
  - **LycheeMemory V2（2608.12990）**：替代 turn-level consolidation 用 **semantic segment-level consolidation**——按语义边界批多交互成段，编码成 context-independent typed memory record；segment 级批处理降 LLM 编码频率、语义边界保事件级+时序证据；LoCoMo 89.22%/LongMemEval-S 92.20%；比 A-Mem 降构造 token 86.0%/75.9% 不增查询 token。**判据：记忆准确-成本权衡不只取决于保留什么信息，还取决于以什么粒度固化**。
  - **RippleMem（2608.13334）**：把交互历史存为 cue-rich episodic memory unit，组织成 event-centric memory graph，从 isolated retrieval 升到 associative recollection（先召回 anchor 再沿语义+结构联想扩展恢复缺失证据）；图构造成本降约 30×。
- 依据：2608.12990、2608.13334
- 等级：A

**Q2. 记忆如何治理以保可信（冲突/撤回/过期/来源）？**
- 结论：用双时态状态机 + 来源绑定准入 + fail-closed 释放，与 Studium 审计状态机同构。
  - **Governed Persistent Memory / GPM（2608.12476）**：把长期 agent 记忆做成**可审计双时态状态转移模型 + 来源绑定准入 + 派生生命周期状态 + 当前公共屏障 + fail-closed 结构化释放**；五可执行条款覆盖账本完整性/来源绑定/冲突隔离/撤回或删除后不复活/在单已验证 head 对新鲜视图的精确 claim 闭合；3600 案例 GPM-ReleaseBench 匹配全部完整结果；治理车道 2400/2400 正确 vs 未治理 600/2400，修全部 1800 基线失败无回归；331,776 语义态 + 1,990,656 查询态无全契约反例、10 万迹三引擎差分零不符。**核心：记忆不只是 select-store-retrieve，检索不决定矛盾/取代/撤回/删除/过时记录是否支持外发 claim**——须治理。
  - **PGMem（2608.01708）**：persona 存为脱离事件扁 profile 导致 memory-persona validity gap；异质 persona-memory graph 经 typed provenance + evidence 边连事件与 persona，每 persona signal 可追溯到支持/修订它的事件，按 evidential validity 排序，随上下文增长性能提升。
- 依据：2608.12476、2608.01708
- 等级：A

**Q3. 记忆演化有什么失败模式？何时记忆已足够？**
- 结论：记忆演化非单调（干扰），且充分性可早停判定。
  - **Controlled Memory Interference / CMI（2608.07622）**：**记忆演化不是简单存更多信息**——新经验可强化/修订/干扰既有记忆态；多条记忆可能同时相关但状态/时序有效性/权威不同；关系特定干扰急剧抑制更新可塑性（阻断目标记忆暴露或破坏下游使用）；lexical 与 dense 检索有不同干扰路径；毒化对更新权威线索比新近性更敏感；**记忆干扰是可靠持续 agent 记忆的重要因素**。
  - **Router-Mem / Stop When Memory Suffices（2608.01285）**：记忆瓶颈不是存更多而是在相关信息分布多交互时恢复正确证据集；证据条件渐进执行——低成本共享检索前缀 + 轻量充分性路由器预测上下文是否支持早终止（单 token 决策），证据不足时复用检索命中扩 memory block 深分析；降推理时 27.3%/25.5%。**与 H2-1 检索充分性直接共振——记忆也有充分性早停**。
- 依据：2608.07622、2608.01285
- 等级：A

## 2. 关键发现

**F1. 【Governed Persistent Memory：双时态状态机 + 来源绑定准入 + fail-closed 释放，与 Studium 审计状态机同构】**
- 论断：长期 agent 记忆通常当 select-store-retrieve，但检索不决定矛盾/取代/撤回/删除/过时记录是否支持外发 claim；GPM 引入**可审计双时态状态转移模型 + 来源绑定准入 + 派生生命周期状态 + 当前公共屏障 + fail-closed 结构化释放**；五可执行条款覆盖账本完整性、来源绑定、冲突隔离、撤回或删除后不复活、在单已验证 head 对新鲜视图的精确 claim 闭合；3600 案例 GPM-ReleaseBench 全完整结果匹配；治理车道 2400/2400 正确 vs 未治理 600/2400、修全部 1800 基线失败无回归（单侧 95% 下界 99.875%/99.834%）；V5 中文/英文命令臂重封仍 2400/2400；生产代码无关有限模型探 331,776 语义态 + 1,990,656 查询态无全契约反例、10 万迹三引擎差分零不符。
- 来源：arXiv 2608.12476，abs 页 arxiv_abs_2608.12476.html；published 2026-08-12
- 原文摘录：「an auditable bitemporal state-transition model with source-bound admission, derived lifecycle state, current public barriers, and fail-closed structured release」；「Five executable clauses cover ledger integrity, source binding, conflict isolation, non-revival after retraction or deletion, and exact claim closure over a fresh view at one verified head」
- 等级：A

**F2. 【LycheeMemory V2：语义段级固化，判据=固化粒度非保留内容，降构造 token 86%】**
- 论断：现有记忆系统靠 eager consolidation（每交互后调 LLM 提取/摘要/更新），随对话增长成本递增；粗摘要降成本但风险丢细粒度上下文证据，大检索上下文或多跳推理把开销转查询时；LycheeMemory V2 用 semantic segment-level consolidation 替 turn-level——批多交互成段、语义边界检测保事件级+时序证据（优于固定窗口批处理）、编码成 context-independent typed memory record、轻量结构索引做 query-planned 证据检索；GPT-4.1-Mini 上 LoCoMo 89.22%/LongMemEval-S 92.20%；比 A-Mem 降构造 token 86.0%(LoCoMo)/75.9%(LongMemEval-S) 不增查询 token；**判据：长期 agent 记忆的准确-成本权衡不只取决于保留什么信息，还取决于以什么粒度固化**。
- 来源：arXiv 2608.12990，abs 页 arxiv_abs_2608.12990.html；published 2026-08-13
- 原文摘录：「replaces turn-level consolidation with semantic segment-level consolidation」；「the accuracy--cost trade-off of long-term agent memory depends not only on what information is retained, but also on the granularity at which it is consolidated」
- 等级：A

**F3. 【RippleMem：从孤立检索到联想回忆，event-centric memory graph，图成本降 30×】**
- 论断：记忆瓶颈不是存更多而是在相关信息分布多交互时恢复正确证据集；full-context 须噪声长上下文搜索、flat retrieval 常返回孤立不完整记录、graph-based 构造贵且压缩富事件上下文；RippleMem 把一次性检索替换为自适应联想回忆（受 cue-dependent episodic retrieval + associative completion 启发）——存交互历史为 cue-rich episodic memory unit 组织成 event-centric memory graph，查询先经混合 cue 召回 memory anchor 再沿语义+结构联想扩展恢复缺失证据；初始召回记忆既作答案上下文也作补全所需证据的 cue；LoCoMo/LongMemEval-S 总体最佳，LLM-as-Judge +3.95%(LoCoMo)/+11.87%(LongMemEval-S)，图构造成本降约 30×。
- 来源：arXiv 2608.13334，abs 页 arxiv_abs_2608.13334.html；published 2026-08-13
- 原文摘录：「replaces one-shot retrieval with adaptive associative recollection」；「initially recalled memories serve not only as answer context, but also as cues for completing the evidence needed to answer」；「reducing graph construction cost by about 30x」
- 等级：A

**F4. 【Controlled Memory Interference：记忆演化非单调，关系特定干扰急剧抑制更新可塑性】**
- 论断：长期记忆让 agent 跨会话保连续/个性化/经积累经验演化；但记忆演化非简单存更多——新经验可强化/修订/干扰既有记忆态；现有系统重记忆构造与相关性检索，但多条记忆可能同时相关而状态/时序有效性/权威不同；CMI 受控诊断与数据生成框架研究 agent 记忆在不同记忆关系下如何演化；控制记忆演化中良性累积效应有限，而**关系特定干扰急剧抑制更新可塑性且稳定性增益甚微**（阻断目标记忆暴露或破坏下游使用）；lexical 与 dense 检索有不同干扰路径；毒化对更新权威线索比新近性更敏感；CMI 提供干扰感知记忆学习的定向示例，改进有效更新与干扰诱导记忆的区分同时保原记忆任务性能；**记忆干扰是可靠持续 agent 记忆的重要因素**。
- 来源：arXiv 2608.07622，abs 页 arxiv_abs_2608.07622.html；published 2026-08-07
- 原文摘录：「new experiences may reinforce, revise, or interfere with existing memory states」；「relationship-specific interference sharply suppresses update plasticity with little stability gain」；「memory interference emerges as an important factor for reliable continual agent memory systems」
- 等级：A

**F5. 【Router-Mem / Stop When Memory Suffices：证据条件渐进执行，充分性早停单 token 决策】**
- 论断：LLM 持久自适应智能需跨交互保留复用信息的长程记忆；现有系统要么压缩结构化历史以高效访问（降在线成本但可能遗漏时序/因果/跨步依赖），要么在更广轨迹上深研究（提证据覆盖但延迟推理成本高）；能否强答案质量同时低在线延迟？Router-Mem 证据条件渐进执行框架——先共享低成本检索前缀获取证据，轻量充分性路由器预测上下文是否支持早终止（推理期单 token 决策），证据不足时复用检索命中扩 memory block 深分析聚合；证据级监督 + 理由条件表征蒸馏训练；AMA-Bench/BEAM 55.17%/38.77% 降平均推理时 27.3%/25.5% 比全记忆执行。
- 来源：arXiv 2608.01285，abs 页 arxiv_abs_2608.01285.html；published 2026-08-02
- 原文摘录：「a lightweight sufficiency router then predicts whether the context supports early termination, which enable a single-token decision at inference time」；「reducing average inference time by 27.3% and 25.5% compared with full memory execution」
- 等级：A

**F6. 【PGMem：persona-memory 异质图，typed provenance + evidence 边，随上下文增长性能提升】**
- 论断：长期个性化对话 agent 须随 persona 演化追踪用户偏好；现有记忆组织过去事件好但 persona 存为脱离事件的扁 profile，松耦合致 memory-persona validity gap + persona-aware retrieval gap；PGMem 异质 persona-memory graph 经 typed provenance + evidence 边连事件与 persona 节点，保每 persona signal 可追溯到支持/修订它的事件；检索时从 query 相关种子扩展按 evidential validity 排序信号；三基准小语言模型骨干上一致胜摘要/感知 persona/图结构/agentic 记忆基线，且随上下文增长性能提升。
- 来源：arXiv 2608.01708，abs 页 arxiv_abs_2608.01708.html；published 2026-08-03；代码 github.com/wonjunchoi23/pgmem/
- 原文摘录：「connects event and persona nodes through typed provenance and evidence edges, keeping each persona signal traceable to the events that support or revise it」；「improves performance as the context grows」
- 等级：A

## 3. 对决策点的输入
- 可移植模式 = **「记忆 = 可治理的双时态状态对象：语义段级固化降成本（LycheeMemory）+ 事件中心联想回忆提证据覆盖（RippleMem）+ 来源绑定准入与 fail-closed 释放保可信（GPM）+ 干扰感知演化防污染（CMI）+ 充分性早停降延迟（Router-Mem）」**——五维并进，且都把记忆当「有语义身份、可版本化、可治理、可溯证」的对象（非任意字符流），与 H3-1/H3-3 收敛点同源。
- **与 Studium 架构的直接同构（F1 GPM）**：GPM 的「双时态状态转移 + 来源绑定准入 + 派生生命周期状态 + 当前公共屏障 + fail-closed 释放 + 五可执行条款（账本/来源/冲突隔离/不复活/精确 claim 闭合）」与 Studium 既有「审计晋升状态机（V/S 系列）+ L0 JSONL 锚点 + L1 RDF 语义层 + L2 FHIR 式版本化」几乎逐项对应。GPM 是 Studium 架构在 LLM 时代的独立印证（不同团队、同一结论）：**可信记忆须状态机化、来源绑定、冲突隔离、撤回不复活、单已验证 head 上精确 claim 闭合**。
- **跨方向共振**：（i）F4 CMI 记忆干扰 ↔ H1-1 Backfires 污染不可逆 ↔ H2-2 来源腐败——「记忆/知识演化非单调、干扰/污染是可靠性的核心变量」是横跨 harness/检索/记忆三方向的共识；（ii）F5 Router-Mem 充分性早停 ↔ H2-1 检索充分性 + H3-2 缓存连续性——「充分性可判定且可早停」是检索与记忆共享的判据；（iii）F1 GPM 双时态 ↔ H2-1 F7 temporal misgrounding + H2-2 EvoTrustRAG 冲突归因——「双时态/版本化」是防 temporal misgrounding 的根本机制。

## 4. 与范围/红线的冲突张力
- 无红线冲突。切分边界：聚焦「长程记忆的组织/固化/治理/演化/充分性」，不展开 multimodal 记忆（V-Mem/PMMC 只提及不展开）、不展开记忆的神经网络架构训练（CMI 的干扰感知学习只取机制结论）。
- F4「记忆演化非单调、干扰急剧抑制可塑性」与「记忆越多越好」直觉张力——如实标 A 实证，是警示非冲突。

## 5. 未决与风险
- F1 GPM 是单一团队的 ReleaseBench + 自建服务评估；其双时态状态机对 Studium 的适配须对照 Studium 既有审计状态机做差异分析 → 标 OPEN（synthesis 时做）。
- F5 Router-Mem 的「充分性路由器」需训练（证据级监督 + 表征蒸馏），非推理期零成本；Studium 若用闭源须退到启发式充分性判据。
- F4 CMI 的干扰路径区分依赖检索器类型（lexical vs dense）；Studium 的检索栈决定其干扰面。

## 6. 建议的下一步
- H4-2 继续挖向量库/知识库在 LLM 时代的形态（接 V6 的 LightRAG 混合 + H4-1 的 event-centric graph）。
- **把 F1 GPM 作为方向4 synthesis 的核心锚点**：GPM 是 Studium 架构的 LLM 时代独立印证，须逐项对照 Studium L0/L1/L2 做差异分析与可移植清单。
