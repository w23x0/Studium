# 任务卡 B6 — 先例领域存储格式
角色：深度调研树分支调研员（B6）。
分支名：数学库/间隔重复/学习记录/健康档案/审计日志五先例领域的存储实证。

## 问题清单
1. 数学知识库：mathlib（Lean 4）如何存储定理、定义、依赖关系（.lean 源文件 + .olean 编译产物）？MML（Mizar Mathematical Library）的存储格式与演化历史？它们的"知识单元身份"如何定义（与"节点身份=锚点集合"可比吗）？
2. 间隔重复：Anki 的 SQLite schema（cards/notes/revlog 表结构）如何记录复习历史？FSRS 的参数与复习记录存在哪、格式是什么？revlog 是 append-only 吗、支持"重新掌握成新版本"吗？
3. 学习记录：xAPI（Experience API）statement 的 JSON 结构、不可变性要求、LRS 的存储与查询语义？IEEE 1484 / SCORM / Caliper Analytics 的对照？xAPI 的 actor-verb-object 模型能否映射 M09 的"个人学习记录"？
4. 健康档案：FHIR R4/R5 的资源版本机制（versionId、meta）、Provenance 资源、AuditEvent 资源？FHIR 如何处理"不覆盖旧结论"（每次更新生成新 versionId）？其 JSON 序列化与 REST 语义对单文件/文件库模式是否可剥离？
5. 审计日志先例：以上各领域 + 通用审计日志中，"不可变、可追加、可机械校验"的最小实现有哪些（逐行哈希、日志结构文件、WORM）？
