# Spacing Effect — Wikipedia

Fetched: 2026-08-13
Grade: A (原文到手)

## 核心内容

- 定义："The spacing effect demonstrates that learning is more effective when study sessions are spaced out." 与集中突击（cramming/massed）对比。
- 元分析："participants who used spaced practice on memory tasks outperformed those using massed practice in 259 out of 271 cases" (Cepeda et al., 2006)。
- Ebbinghaus (1885)《Memory: A Contribution to Experimental Psychology》最早识别该现象。
- Shaughnessy (1977)：两次呈现+24 小时延迟后效应不稳健；四次/六次出现——"no single explanatory mechanism can be used to account for the various manifestations."
- 延迟效应（lag effect）："recall after long lags between learning is better versus short lags" (Kahana, 2005)。Kornell & Bjork (2008)：归纳学习 spaced > massed。
- 教育应用：Rohrer (2006/2007) 一周后测试 spaced 显著优于 mass；Bahrick et al. (1993) 外语词汇 56 天间隔最优，56 天×13 次 ≈ 14 天×26 次。
- 广告：Fennis & Stroebe (2010) spaced ads remembered better；Appleton-Knapp, Bjork & Wickens (2005) spaced 依赖 study-phase retrieval 而非 encoding variability。
- 结论：尽管证据强，课程结构很少融入间隔安排。
