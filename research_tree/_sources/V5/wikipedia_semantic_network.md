## 核心内容

- Definition: "knowledge base that represents semantic relations between concepts in a network." "a directed or undirected graph consisting of vertices, which represent concepts, and edges, which represent semantic relations between concepts."
- May be graph databases or concept maps; "typical standardized semantic networks are expressed as semantic triples."
- Nodes/arcs "can be organized into a taxonomic hierarchy."
- Collins & Quillian (1969): "retrieval time from semantic memory"; (1970): whether category size affects categorization time. Hierarchical model e.g. canary -> bird -> vertebrate, properties inherited along hierarchy.
- Collins & Loftus (1975): "a spreading-activation theory of semantic processing." Activation propagates between related nodes.
- Richens (1956, Cambridge Language Research Unit): semantic nets as "an 'interlingua' for machine translation." Simmons (1963) and Klein: implemented with first order predicate calculus.
- Sowa (1987): existential graphs of Peirce / conceptual graphs "have expressive power equal to or exceeding standard first-order predicate logic."
- WordNet: "groups English words into sets of synonyms called synsets"; relations: meronymy, hyponymy, hypernymy, synonymy, antonymy.
- Helbig (2006): MultiNet. Late 1980s Groningen/Twente: "Knowledge Graphs, which are semantic networks but with the added constraint that edges are restricted to be from a limited set of possible relations."
- Google 2012 Knowledge Graph: "actually an application of semantic network in search engine."
- TransE (Bordes et al., NIPS 2013): embedding-based approach.
