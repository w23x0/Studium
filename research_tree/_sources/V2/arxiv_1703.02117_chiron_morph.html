Abstract

cttqe\mbox{\sc ctt}_{\rm qe} is a version of Church’s type theory with global quotation and evaluation operators that is engineered to reason about the interplay of syntax and semantics and to formalize syntax-based mathematical algorithms. cttuqe\mbox{\sc ctt}_{\rm uqe} is a variant of cttqe\mbox{\sc ctt}_{\rm qe} that admits undefined expressions, partial functions, and multiple base types of individuals. It is better suited than cttqe\mbox{\sc ctt}_{\rm qe} as a logic for building networks of theories connected by theory morphisms. This paper presents the syntax and semantics of cttuqe\mbox{\sc ctt}_{\rm uqe}, defines a notion of a theory morphism from one cttuqe\mbox{\sc ctt}_{\rm uqe} theory to another, and gives two simple examples involving monoids that illustrate the use of theory morphisms in cttuqe\mbox{\sc ctt}_{\rm uqe}.

1 Introduction

A syntax-based mathematical algorithm (SBMA), such as a symbolic differentiation algorithm, manipulates mathematical expressions in a mathematically meaningful way. Reasoning about SBMAs requires reasoning about the relationship between how the expressions are manipulated and what the manipulations mean mathematically. We argue in [8] that a logic with quotation and evaluation would provide a global infrastructure for formalizing SBMAs and reasoning about the interplay of syntax and semantics that is embodied in them.

Quotation is a mechanism for referring to a syntactic value (e.g., a syntax tree) that represents the syntactic structure of an expression, while evaluation is a mechanism for referring to the value of the expression that a syntactic value represents. Incorporating quotation and evaluation into a traditional logic like first-order logic or simple type theory is tricky; there are several challenging problems that the logic engineer must overcome [8, 9]. cttqe\mbox{\sc ctt}_{\rm qe} [9, 10] is a version of Church’s type theory with global quotation and evaluation operators inspired by the quote and eval operators in the Lisp programming language. We show in [9] that formula schemas and meaning formulas for SBMAs can be expressed in cttqe\mbox{\sc ctt}_{\rm qe} using quotation and evaluation and that such schemas and meaning formulas can be instantiated and proved within the proof system for cttqe\mbox{\sc ctt}_{\rm qe}.

The little theories method [11] is an approach for understanding and organizing mathematical knowledge as a theory graph [14] consisting of axiomatic theories as nodes and theory morphisms11 1 Theory morphisms are also known as immersions, realizations, theory interpretations, translations, and views. as directed edges. A theory consists of a language of expressions that denote mathematical values and a set of axioms that express in the language assumptions about the values. A theory morphism is a meaning-preserving mapping from the formulas of one theory to the formulas of another theory. Theory morphisms serve as information conduits that enable definitions and theorems to be passed from an abstract theory to many other more concrete theories [2].

A biform theory [3, 6] is a combination of an axiomatic theory and an algorithmic theory (a collection of algorithms that perform symbolic computations). It consists of a language LL generated from a set of symbols, a set of transformers, and a set of axioms. The expressions of LL denote mathematical values that include syntactic values representing the expressions of LL. The transformers are SBMAs and other algorithms that implement functions on the expressions of LL and are represented by symbols of LL. The axioms are formulas of LL that express properties about the symbols and transformers of the biform theory. Unlike traditional logics, cttqe\mbox{\sc ctt}_{\rm qe} is well suited for formalizing biform theories. Can the little theories method be applied to biform theories formalized in cttqe\mbox{\sc ctt}_{\rm qe}? This would require a definition of a theory morphism for cttqe\mbox{\sc ctt}_{\rm qe} theories.

Defining a notion of a theory morphism in a logic with quotation is not as straightforward as in a logic without quotation due to the following problem:

  • Constant Interpretation Problem. Let T1T_{1} and T2T_{2} be theories in a logic with a quotation operator ⌜⋅⌝\ulcorner\cdot\urcorner. If a theory morphism Φ\Phi from T1T_{1} to T2T_{2} interprets two distinct constants cc and c′c^{\prime} in T1T_{1} by a single constant dd in T2T_{2}, then Φ\Phi would map the true formula ⌜​c​⌝≠⌜​c′​⌝\ulcorner c\urcorner\not=\ulcorner c^{\prime}\urcorner of T1T_{1} to the false formula ⌜​d​⌝≠⌜​d​⌝\ulcorner d\urcorner\not=\ulcorner d\urcorner of T2T_{2}, and hence Φ\Phi would not be meaning preserving. Similarly, if Φ\Phi interprets cc as an expression ee in T2T_{2} that is not a constant, then Φ\Phi would map a true formula like is-constant​(⌜​c​⌝)\mbox{\sf is-constant}(\ulcorner c\urcorner) to the false formula is-constant​(⌜​e​⌝)\mbox{\sf is-constant}(\ulcorner e\urcorner).

This paper defines a notion of a theory morphism that overcomes this problem in cttuqe\mbox{\sc ctt}_{\rm uqe}, a variant of cttqe\mbox{\sc ctt}_{\rm qe} that admits undefined expressions, partial functions, and multiple base types of individuals. cttuqe\mbox{\sc ctt}_{\rm uqe} merges the machinery for quotation and evaluation found in cttqe\mbox{\sc ctt}_{\rm qe} [9] with the machinery for undefinedness found in 𝒬0u{\cal Q}^{\rm u}_{0} [7]. Like cttqe\mbox{\sc ctt}_{\rm qe} and 𝒬0u{\cal Q}^{\rm u}_{0}, cttuqe\mbox{\sc ctt}_{\rm uqe} is based on 𝒬0{\cal Q}_{0} [1], Peter Andrews’ elegant version of Church’s type theory. See [9] for references related to cttuqe\mbox{\sc ctt}_{\rm uqe}.

cttuqe\mbox{\sc ctt}_{\rm uqe} is better suited than cttqe\mbox{\sc ctt}_{\rm qe} as a logic for the little theories method for two reasons. First, it is often convenient for a theory morphism from T1T_{1} to T2T_{2} to interpret different kinds of values by values of different types. Since cttqe\mbox{\sc ctt}_{\rm qe} contains only one base type of individuals, ι\iota, all individuals in a theory T1T_{1} must be interpreted by values of the same type in T2T_{2}. Allowing multiple base types of individuals in cttuqe\mbox{\sc ctt}_{\rm uqe} eliminates this restriction. Second, it is often useful to interpret a type α\alpha in T1T_{1} by a subset of the denotation of a type β\beta in T2T_{2}. As shown in [4], this naturally leads to partial functions on the type β\beta. cttuqe\mbox{\sc ctt}_{\rm uqe} has built-in support for partial functions and undefinedness based on the traditional approach to undefinedness [5]; cttqe\mbox{\sc ctt}_{\rm qe} has no such built-in support.22 2 A logic without support for partial functions and undefinedness — such as cttqe\mbox{\sc ctt}_{\rm qe} or the logic of HOL [12] — can interpret α\alpha by a type β′\beta^{\prime} that is isomorphic to a subset of β\beta. However, this approach is more complicated and farther from standard mathematics practice than interpreting α\alpha directly by a subset of β\beta.

2 Syntax

The syntax of cttuqe\mbox{\sc ctt}_{\rm uqe} is the same as the syntax of cttqe\mbox{\sc ctt}_{\rm qe} [9] except that (1) the types include denumerably many base types of individuals instead of just the single ι\iota type, (2) the expressions include conditional expressions, and (3) the logical constants include constants for definite description and exclude is-exprϵ→o\mbox{\sf is-expr}_{\epsilon\rightarrow o} — which we will see is not needed since all constructions are “proper” in cttuqe\mbox{\sc ctt}_{\rm uqe}.

3 Semantics

The semantics of cttuqe\mbox{\sc ctt}_{\rm uqe} is the same as the semantics of cttqe\mbox{\sc ctt}_{\rm qe} except that the former admits undefined expressions in accordance with the traditional approach to undefinedness [5]. Two principal changes are made to the cttqe\mbox{\sc ctt}_{\rm qe} semantics: (1) The notion of a general model is redefined to include partial functions as well as total functions. (2) The valuation function for expressions is made into a partial function that assigns a value to an expression iff the expression is defined according to the traditional approach.

4 Theory Morphisms

6 Conclusion

cttqe\mbox{\sc ctt}_{\rm qe} is a version of Church’s type theory with quotation and evaluation described in great detail in [9]. In this paper we have (1) presented cttuqe\mbox{\sc ctt}_{\rm uqe}, a variant of cttqe\mbox{\sc ctt}_{\rm qe} that admits undefined expressions, partial functions, and multiple base types of individuals, (2) defined a notion of a theory morphism in cttuqe\mbox{\sc ctt}_{\rm uqe}, and (3) given two simple examples that illustrate the use of theory morphisms in cttuqe\mbox{\sc ctt}_{\rm uqe}. The theory morphisms of cttuqe\mbox{\sc ctt}_{\rm uqe} overcome the Constant Interpretation Problem discussed in section 1 by requiring constants to be injectively mapped to constants. Since cttuqe\mbox{\sc ctt}_{\rm uqe} admits partial functions, cttuqe\mbox{\sc ctt}_{\rm uqe} theory morphisms are able to map base types to sets of values of the same type — which enables many additional natural meaning-preserving mappings between theories to be directly defined as cttuqe\mbox{\sc ctt}_{\rm uqe} theory morphisms. Thus the paper demonstrates how theory morphisms can be defined in a traditional logic with quotation and evaluation and how support for partial functions in a traditional logic can be leveraged to obtain a wider class of theory morphisms.

The two examples presented in section 5 show that constructing a translation in cttuqe\mbox{\sc ctt}_{\rm uqe} from a theory T1T_{1} to a theory T2T_{2} will often require defining new dummy constants in T2T_{2}. This is certainly a significant inconvenience. However, it is an inconvenience that can be greatly ameliorated in an implementation of cttuqe\mbox{\sc ctt}_{\rm uqe} by allowing a user to define a “pre-translation” that is automatically transformed into a bona fide translation. A pre-translation from T1T_{1} and T2T_{2} would be a pair (μ,ν)(\mu,\nu) where μ\mu maps base types to either types or semantically closed predicates, ν\nu maps constants to expressions that need not be constants, and ν\nu is not required to be injective. From the pre-translation, the system would automatically extend T2T_{2} to a theory T2′T^{\prime}_{2} and then construct a translation from T1T_{1} to T2′T^{\prime}_{2}.

Our long-range goal is to implement a system for developing biform theory graphs utilizing logics equipped with quotation and evaluation. The next step in this direction is to implement cttqe\mbox{\sc ctt}_{\rm qe} by extending HOL Light [13], a simple implementation of HOL [12].
