# Microsoft GraphRAG 原始论文 — From Local to Global: A Graph RAG Approach to Query-Focused Summarization 来源：https://arxiv.org/abs/2404.16130 （摘要页）+ https://arxiv.org/html/2404.16130v2 （HTML 全文） 作者：Darren Edge, Ha Trinh, Newman Cheng, Joshua Bradley, Alex Chao, Apurva Mody, Steven Truitt, Jonathan Larson 机构：Microsoft Research 日期：2024-04-24 提交；v2 2024-06-13 抓取日期：2026-08-13（WebFetch，A 级原文） ## 方法 "our approach uses an LLM to build a graph index in two stages: first, to derive an entity knowledge graph from the source documents, then to pregenerate community summaries for all groups of closely related entities." "Given a question, each community summary is used to generate a partial response, before all partial responses are again summarized in a final response to the user." ## 图何时有用的动机（原文） - "RAG fails on global questions directed at an entire text corpus, such as 'What are the main themes in the dataset?', since this is inherently a query-focused summarization (QFS) task, rather than an explicit retrieval task." - "vector RAG approaches do not support sensemaking queries, meaning queries that require global understanding of the entire dataset" - "for questions of a global nature, which might otherwise be answered by samples of retrieved facts falsely presented as global summaries" ## 量化结果（vs vector RAG） - Comprehensiveness（全面性）胜率：Podcast 72–83% (p<.001)；News 72–80% (p<.001) - Diversity（多样性）胜率：Podcast 75–82% (p<.001)；News 62–71% (p<.01) - 根级（C0）vs vector RAG：comprehensiveness 72% win、diversity 62% win ## 成本（原文数字） - 构图：Podcast 数据集"took 281 minutes"，16GB RAM、Xeon Platinum 8171M CPU 虚拟机 - 查询成本：根级社区摘要（C0）只用最大令牌的 2.6%（Podcast）/ 2.3%（News）；"required over 97% fewer tokens"；C0 比源文本摘要每查询少 9x–43x 令牌 - 上下文窗口固定 8k tokens ## 数据集规模（关键：这是 1M token 量级） - Podcast transcripts（Behind the Tech with Kevin Scott）：1,669 × 600-token 块 ≈ 100 万 token；构图后 8,564 节点 / 20,691 边 - News（2013-09 至 2023-12）：3,197 × 600-token 块 ≈ 170 万 token；15,754 节点 / 19,520 边 ## 对 V6 的意义 - 原版 GraphRAG 的价值域是「全局感测（global sensemaking）问题」，在 1M+ token 语料上验证；本项目 L0 规模 522 节点/1433 边，比该论文的构图规模小三个数量级 - 原版 GraphRAG 是社区摘要（QFS）路线，不是图遍历检索；检索靠 LLM 抽取实体图 + 社区检测 + 摘要，不是「图上行走」 ## 等级 A（WebFetch 抓取 arxiv 摘要页 + HTML 全文）
