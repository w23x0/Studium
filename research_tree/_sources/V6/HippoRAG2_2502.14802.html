# HippoRAG 2 — Trade-offs Between Cost and Quality in LLM-based Knowledge Retrieval 来源：https://arxiv.org/abs/2502.14802 （摘要页）+ https://github.com/OSU-NLP-Group/HippoRAG （README） 作者：Bernal Jiménez Gutiérrez, Yiheng Shu, Weijian Qi, Sizhe Zhou, Yu Su 机构：Ohio State University (OSU-NLP-Group) 日期：2025-02-20 提交 v1；2025-06-19 v2；ICML 2025 抓取日期：2026-08-13（WebFetch，A 级原文） ## 摘要（原文） "Our ability to continuously acquire, organize, and leverage knowledge is a key feature of human intelligence that AI systems must approximate to unlock their full potential. ... Recent RAG approaches augment vector embeddings with various structures like knowledge graphs to address some of these gaps, namely sense-making and associativity. However, their performance on more basic factual memory tasks drops considerably below standard RAG. We address this unintended deterioration and propose HippoRAG 2, a framework that outperforms standard RAG comprehensively on factual, sense-making, and associative memory tasks. HippoRAG 2 builds upon the Personalized PageRank algorithm used in HippoRAG and enhances it with deeper passage integration and more effective online use of an LLM. This combination pushes this RAG system closer to the effectiveness of human long-term memory, achieving a 7% improvement in associative memory tasks over the state-of-the-art embedding model while also exhibiting superior factual knowledge and sense-making memory capabilities." ## 关键点 - 此前图增强 RAG（GraphRAG/LightRAG/RAPTOR）「their performance on more basic factual memory tasks drops considerably below standard RAG」——图方案在简单事实记忆上掉队；HippoRAG2 声称修复这一点 - 方法 = HippoRAG 的 Personalized PageRank（PPR）在图上的检索 + 更深的段落整合 + 在线 LLM 使用；OpenIE（开放信息抽取）建知识图 - 图+向量混合：向量存段落/实体 + 知识图 + PPR 图检索 - 索引成本：「significantly fewer resources for offline indexing compared to other graph-based solutions such as GraphRAG, RAPTOR, and LightRAG」（README 原文） - 基准：factual memory（NaturalQuestions, PopQA）、sense-making（NarrativeQA）、associativity（MuSiQue, 2Wiki, HotpotQA, LV-Eval） - README 结论「HippoRAG 2 surpasses other methods across all categories」；MIT 许可 ## 对 V6 的意义 - 图方案对「简单事实任务」掉队是反复出现的负面结果（2506.05690 与 HippoRAG2 摘要一致） - HippoRAG2 是「图+向量混合、且图只是检索路径之一、结论由 LLM 段落整合给出」的代表——图结构参与生成结论，这与 Studium 红线「向量只定向不结案」需要区分：GraphRAG 系把图检索结果直接喂给生成，图在结论路径上；Studium 的结论路径是锚点判等 ## 等级 A（WebFetch 抓取 arxiv 摘要页 + GitHub README）
