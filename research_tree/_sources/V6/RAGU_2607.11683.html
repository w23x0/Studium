# RAGU: A Multi-Step GraphRAG Engine with a Compact Domain-Adapted LLM 来源：https://arxiv.org/abs/2607.11683 作者：Mikhail Komarov 等 日期：2026-07-13 提交 抓取日期：2026-08-13（WebFetch，A 级原文） ## 摘要要点 - 开源模块化 GraphRAG 引擎；「two-stage typed extraction, DBSCAN-backed deduplication, LLM summarization, and Leiden community detection」 - 训练 Meno-Lite-0.1（7B），「optimized for language skills, which outperforms Qwen2.5-32B on knowledge-graph construction (+12.5% relative harmonic mean) and matches it on English GraphRAG tasks」 - 单 GPU 可跑，MIT，`pip install graph_ragu` ## 关键论断 - 「existing systems construct knowledge graphs in a single extraction pass, producing noisy entities and brittle retrieval」——单次抽取构图产生噪声实体与脆弱检索（图质量问题） - 图对什么有用：GraphRAG-Bench (Medical) 上「RAGU retrieves the most complete context at every factoid level (evidence recall up to 0.84 vs. ≤0.76)」「overtakes HippoRAG2 on synthesis tasks」 - 多跳事实 QA 上「the apparent HippoRAG2 advantage is shown to be largely an answer-format artifact」——部分所谓图优势是答案格式假象 ## 对 V6 的意义 - 2026 年最新系统仍在做「单次抽取构图噪声大 → 多阶段抽取 + DBSCAN 去重」——图的质量依赖实体抽取/去重，而这正是 Studium 红线用「锚点判等」替代 LLM 去重的动机 - 图的收益集中在上游证据召回（synthesis/context-complete），简单事实 QA 上优势部分是假象 ## 等级 A（WebFetch 抓取 arxiv 摘要页）
