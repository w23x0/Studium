Title: An Introduction to Probabilistic Programming
Authors: Jan-Willem van de Meent, Brooks Paige, Hongseok Yang, Frank Wood
Submitted: 27 Sep 2018 (v1); last revised 19 Oct 2021 (v2)

Abstract (verbatim, key sentences):
- "a graduate-level introduction to probabilistic programming"; covers using and designing PPS
- begins with "model-based reasoning and conditioning as a foundational computation"
- introduces "a first-order PPL corresponding to graphical models"
- proceeds to "higher-order PPLs with dynamic computation graphs, which may not instantiate the same set of random variables in each execution"
- "Inference requires methods that generate samples by repeatedly evaluating the program."
- addresses intersection of probabilistic and differentiable programming (AD, HMC, neural-network-parameterized models).

→ 模型=程序；推理=反复执行程序采样。表示(程序)与推断(采样算法)分层。
