# OWL 2 Web Ontology Language Document Overview (W3C)
抓取日期：2026-08-13 | URL: https://www.w3.org/TR/owl2-overview/ | A 级

Title: OWL 2 Web Ontology Language Document Overview (Second Edition)
Status: W3C Recommendation 11 December 2012

Key sentences (verbatim):
- The Direct Semantics "is compatible with the model theoretic semantics of the _SROIQ_ description logic—a fragment of first order logic."
- "the extensive description logic literature and implementation experience can be directly exploited by OWL 2 tools."
- Direct Semantics compatible with semantics of "the _SROIQ_ description logic—a fragment of first order logic with useful computational properties."
- "Three different profiles are defined: OWL 2 EL, OWL 2 QL, and OWL 2 RL" — "sub-languages (syntactic subsets) of OWL 2"
- each profile "trades off different aspects of OWL's expressive power in return for different computational and/or implementational benefits" — "each is more restrictive than OWL DL."
- "some conditions must be placed on ontology structures in order to ensure that they can be translated into a _SROIQ_ knowledge base", defining valid OWL 2 DL ontologies.

→ OWL 2 = DL fragment of FOL; profiles trade expressivity vs tractability. 类型论/一阶可表达的，不一定落入 DL 可判定片段。
