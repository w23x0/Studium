## 提取正文（关键句逐字）
- GQL = "an upcoming International Standard language for property graph querying that is currently being created."
- "April 17, 2024 – The GQL Standard is published!" 正式编号 "ISO/IEC 39075:2024 Information technology — Database languages — GQL"，"officially published and available for purchase on the ISO web store."
- 制定机构："the international standards committee ISO/IEC JTC1 SC32 WG3"
- "GQL supporters aim to develop a rock-solid next-generation declarative graph query language that builds on the foundations of SQL and integrates proven ideas from the existing openCypher, PGQL, GSQL, and G-CORE languages."
- GQL 纳入 "regular path queries, graph compositional queries (enabling views) and schema support"。
- LDBC 发起 "the LDBC Extended GQL Schema Working Group"。
