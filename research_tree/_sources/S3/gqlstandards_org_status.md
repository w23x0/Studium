# gqlstandards.org — GQL 标准站点（现状：无 2025/2026 新帖）

> 来源：https://www.gqlstandards.org/ 与 https://www.gqlstandards.org/home
> 抓取：2026-08-13（WebFetch）｜等级 A（原文到手）

## 原文要点

- 站点定位：追踪 ISO/IEC JTC1 SC32 WG3 内 GQL 标准化进度。
- 最新更新帖：**April 17, 2024 — "The GQL Standard is published!"**（ISO/IEC 39075:2024 正式发布）。
- 全部帖子为历史帖（2019-2024）：2019-09 项目启动；2022-02 CD ballot 结束（800+ 评论）；2022-06 Berlin 会议（532 评论已解决，计划 2022-09 第二次 CD2 咨询）；2023-05 DIS ballot（2023-05-23 至 2023-08-15）；2023-10 DIS 结果（12 批准/0 反对/8 弃权，493 评论）；2024-01 FDIS voting；2024-03 FDIS 关闭（14 批准/0 反对/6 弃权）；2024-04-17 发布。
- 页面明确："The LDBC initiated a new activity: the LDBC Extended GQL Schema Working Group"（2022-12，五子组：Use Cases、SHACL analysis、DDL representation、Visual representation、Graph representation）"input to SC32 WG3 for the next version of the GQL standard"。
- GQL 包含 "DML – Create, Read, Update, Delete"；"DDL – Create Graph Type, Create Graph, Create Graph from Graph Type"；"Support for schema-fixed and schema-flexible variants"。
- GPM（Graph Pattern Matching）与 SQL/PGQ 的 GPM "as identical as possible"。

## 关键判断（调研员）

- 站点自 2024-04 后无更新帖；无 2025/2026 帖子。=> 对"GQL v2 最新进展"的社区侧信号：无新公告（无变化）。GQL V2 进展证据需到 WG3 相关 deck（TUC）与 ISO 项目页。
