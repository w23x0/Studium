## Abstract（原文摘录）
"The abstract describes premise selection as 'essential when using automated reasoning as a tool for large-theory formal proof development.' ... First, they use 'a newly available minimal dependency analysis of existing high-level formal mathematical proofs' to build a knowledge base of proof dependencies. Second, they propose 'a new machine learning algorithm for premise selection based on kernel methods.' They evaluate both techniques using 'a benchmark consisting of 2078 large-theory mathematical problems.' The combined result is 'a 50% improvement on the benchmark over the Vampire/SInE state-of-the-art system.'"

## 关键摘录
- "premise selection" 定义：为大规模理论的形式化证明中选择相关前提。
- "a newly available minimal dependency analysis of existing high-level formal mathematical proofs" — 最小依赖分析作为前提选择的知识来源。
- 评估基准 2078 个大理论数学问题；相对 Vampire/SInE 提升 50%。
