# Snapshot: MathGloss (arXiv:2311.12649)

Source: https://arxiv.org/abs/2311.12649
Fetched: 2026-08-14

## Abstract (verbatim excerpts)

"create a knowledge graph (KG) for undergraduate mathematics from text, automatically"

"linked database of undergraduate concepts in mathematics"

"combines five resources: (i) Wikidata ... (ii) University of Chicago courses (iii) French undergraduate curriculum ... (iv) MuLiMa ... (v) the nLab"

"These links are not present between every pair of items that 'should' be linked because creating these links is a labor-intensive process."

"present the terms that get mapped to the same Wikidata ID as the same mathematical concept"
