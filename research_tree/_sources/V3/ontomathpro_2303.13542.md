# Snapshot: OntoMathPRO 2.0 (arXiv:2303.13542)

Source: https://arxiv.org/abs/2303.13542
Fetched: 2026-08-14

## Abstract (verbatim excerpts)

"formal model for the representation of mathematical statements in the Open Linked Data cloud"

"ontology is organized into three layers: a foundational ontology layer, a domain ontology layer and a linguistic layer"

"The domain ontology layer contains language-independent math concepts."

"concepts are organized in two main hierarchies: the hierarchy of objects and the hierarchy of reified relationships."

## OntoMathPRO 1.0 (same paper)

"defines five types of relationships between concepts"

"The existing version of the ontology contains a large number of general concepts, but a rather poor set of relationships between them."

"expressed by OWL DL (Web Ontology Language) formalism which is based on a description logic"

## Relevance note

Relationship vocabulary is **small fixed set in 1.0 (five types)** but architecture is **open LOD** with poor relationship coverage per authors' own admission — reference for concept/object modeling, not drop-in for M08 9+other.
