# Snapshot: OntoMath KESW2014 object properties (KESW 2014)

## Verbatim excerpts (§2.3 Relations)

"OntoMath PRO defines four types of object properties:"

1. "a directed relation between a mathematical knowledge object (E24) and a field of mathematics (E1) (P3 belongs to and its inverse P4 contains)"

2. "a directed relation of logical dependency between mathematical knowledge objects (P1 defines and its inverse P2 is defined by)" — "The P2 is defined by relation instance is established, if the definition of the first concept explicitly refers to the second concept"

3. "a symmetric transitive associative relation between mathematical knowledge objects (P5 see also)" — "semantics of this relation is equivalent to rdfs:seeAlso"

4. "a directed relation between a method and a task (P6 solves and its inverse P7 is solved by), these properties are defined on E449 Method and E339 Problem classes"

## Note on "five types"

2303.13542 abstract says OntoMathPRO 1.0 "defines five types of relationships" — KESW2014 lists **four types of object properties** (with inverses). Taxonomic ISA between concepts uses separate hierarchy (not listed as object property type in §2.3). 2.0 replaces flat properties with **reified relationship concepts** (A, ar5iv 2303.13542).
