## 文档规范

**docs/ 下所有 Markdown 文档面向 agent 阅读，不面向人类**：

- **单文件上限 400 行**。超出则拆分为多文件 + 索引 README。
- **优先结构化信息**：表格 > 列表 > 段落。避免长段落叙事。
- **目录索引必须明确**：每个子目录的 README 必须列出所有文件 + 一行描述。
- **删除冗余解释**：同一信息不在多处重复；一处定义，其他处引用。
- **明确待定/已决/已归档**：状态标注在文件头部。
- **偏的内容直接删，不做增量标记**：方向错误或已废弃的文档、段落、结论一律删除，不用改名、加括号、"已删除"占位或保留旧版本。错误内容留在文档里总会把后续的 agent/人带偏。文档保持与当前共识一致的最小集合。
