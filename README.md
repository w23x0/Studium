# Studium

学习这件事要跨几个月，而模型每次调用都从零开始。Studium 管好模型每一刻的输入和输出：知识交给模型，“这个人走到哪了”交给记录（学过的记录、方向目标、单子、守卫写下的理解）。

> **快速定位当前进度** → [`任务线路.md`](任务线路.md)（每次回到项目先读这一页）
