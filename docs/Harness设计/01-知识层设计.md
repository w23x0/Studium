## 6 M08 知识结构与概念关系

### 6.1 节点定位（`已确认`）

| 项 | 内容 |
| --- | --- |
| 拥有 | 不专属个人的**通用知识对象 + 关系 + 锚点 + 候选区** |
| 不拥有 | 个人掌握（M09）、资料本体（M07）、路线（M05）、策略（M10）、状态（M15） |
| 权威层 | **原文（M07 / L0） + 可核验引用**；抽象 / 对齐都是**派生**（引用形式待定，不采用实验的长度口径） |
| 输入 | M07 原文 / 结构 / 概念候选；M09、M14 去个人化候选；模型综合候选；人工更正 |
| 输出 | 对象、关系、阈值标记、来源与状态 |
| 明确不做 | 不保存个人掌握；不自由生成；不把模型记忆伪装成原文 |

### 6.2 存储结构（★核心）

**权威在原文（M07 / L0）+ 可核验引用；抽象与对齐都是派生。**

| 原则 | 内容 | 来源 |
| --- | --- | --- |
| **各表示独立存、不合并** | 每份资料保留自己的表示，各有稳定标识 | **D-03（用户）** |
| **不变性 = 链接，不是层** | “这两条说同一件事”是一条**带证据的判断（链接）**，不是被合并出来的节点 | 我方判断 |
| **链接可逆** | 链接只连接、不搬运内容；只追加，修订 = 新增一条 | 我方判断 |
| **默认候选** | 新建内容 / 链接默认候选；确认才生效 | 产品 |
| **可溯源** | 每条内容能回到原文：锚点 = W3C `TextQuoteSelector`（exact+prefix+suffix） | 产品 + K 线 + D-14 |
| **只追加** | 不物理删除；修订形成新版本 | 产品 + D-03 |

**粒度 = 遍历深度，不是存储层**：M05 看链接簇（粗）、M10 取单个表示（细）、M04 沿依赖边追（细）、M09 锚定到接地表示（细）。

**已定（2026-09-16，依据外部先例）**：

| 项 | 结论 |
| --- | --- |
| **最小单位** | **原子断言**（一条可独立引用、自带溯源的断言；= Nanopublication 的 Assertion 粒度）。链接两端 = 两条原子断言 |
| **锚点形式** | W3C **`TextQuoteSelector`**（exact + prefix + suffix），抗漂移；**不用行号 / 单 offset** |
| **链接起步词汇** | SKOS 映射 + PROV：`closeMatch`（**非传递**，防复合错误）/ `broadMatch` / `narrowMatch` / `relatedMatch` + `alternateOf` / `specializationOf` / `wasRevisionOf` / `wasQuotedFrom` |
| **等价降级** | 用 Wikidata **P460** 式“据说同一”的**可争议陈述**；**禁用 `owl:sameAs` 式合并**（会级联污染且不可撤销） |
| 仍待定 | 标识形态（自增 id / 内容寻址 / 其他）——只要**独立于路径与名字**即可 |

> 外部依据：[`_research/知识表示可借鉴方法-发现.md`](./_research/知识表示可借鉴方法-发现.md)（含 SKOS/PROV/Nanopublication/W3C Annotation/Datomic 一手来源）。

### 6.3 候选与晋升（环路闸门）

- 候选来源：M07 抽取、模型综合、M09 去个人化、M14 高阶、人工更正。
- **默认关闭**：候选不自动晋升；审计是唯一闸门。
- **审计对象 = M08 已有断言**：只做**纠错 / 补关系**，不做创造新抽象（D-01）。M08 是已有知识的模型，不是新知识的创造者（那是 M14 研究）。
- **无锚内容不进权威层**。

### 6.6 失败与降级

| --- | --- |

## 7 M09 动态学习者模型

### 7.1 节点定位（`已确认`）

| 项 | 内容 |
| --- | --- |
| 拥有 | 已结束闭环的**个人形成记录 + 证据边 + 时间版本 + 个人结构** |
| 不拥有 | 进行中诊断（M04）、高频状态（M15）、通用知识（M08）、策略（M10）、路线（M05） |
| 写入 | **只收已结束闭环**，闭环结束一次提交 |
| 输出 | 个人形成图、当前理解视图、未满足项、个人结构、时间版本、M08 候选材料 |

### 7.2 存储结构

| 原则 | 内容 |
| --- | --- |
| **权威 = 证据链** | 结论 + 证据边 + 条件 + 时间版本；不存完整对话，也不存标签 |
| **锚定 M08 对象** | 用 M08 的身份 / 锚点；未映射对象先暂存（仅个人有效） |
| **不覆盖旧结论** | 复检 / 遗忘 / 重新掌握 / 更正形成**新版本**（同 git 思路） |
| **派生视图可重建** | 当前掌握视图、四级标签、摘要、关键词——不权威 |
