## M05 学习导航与计划

### 定位（`已确认`）

| 项 | 内容 |
| --- | --- |
| 作用域 | **跨闭环（会话外）** |
| 职责 | 算下一闭环与路线；决定 继续 / 补前置 / 分叉 / 返回 / 搁置；定分叉范围与返回条件 |
| 明确不做 | 不做会话内策略（M10）；不判掌握（M04）；不写 M09；不建会话结构（M01 落实） |
| 触发 | 闭环边界（M04 关环后）；**也可在会话进行中由 M04 改线依据触发**（M05 审查单已确认第 3 条）；偏差判断在闭环外（D-05） |
| 链式 | 每次只设计**下一个**闭环，不是一次设计完（D-05） |

### 路线 = 图上算出来的路径（决策 3 A）

- 路线 = `实际面 → 目标面` 在 **M08 图**上的路径（D-07 梯子）。
- **读状态面三样**：**前方边界**（下一目标）/ **洞**（补前置）/ **孤岛**（跨域桥，D-02）。
- **是派生视图**：实时算，不持久化；算出的**决定**由 M01 存成路线事实（≠ 双写）。
- 二/三级子模块（复习、复检、补学、停车场、阶段复盘）沿用产品文档，建立在这条主干上。

### 失败与降级

| 情形 | 处理 |
| --- | --- |
| 目标面无（冷启动） | 用**粗目标**起步（决策 2）；配合目标畅谈（D-12） |
| 状态面空 | 用默认先验，路线标"临时" |
| M08 前置边缺失 | 路线标"未验证路段"（前沿段候选化，D-07） |
| M15 读数缺失 | 按无约束规划并标注 |

**输入清单与缺料 / 冲突规则（A-03 的 M05 落地；口径同 `01-节点设计.md` §2.9）**

| 输入 | 缺失时 |
| --- | --- |
| 目标面（M01） | 冷启动 → 用**粗目标**先验起步（D-16），路线标“临时” |
| M09 知识状态面 | 空 → 用主要靠 **M08 书本骨架**先验，路线标“临时” |
| M08 前置边 | 路线标“未验证路段”（前沿段候选化，D-07） |
| M15 承载读数 | 按无约束规划并标注（N-01 同一降级口径） |
| M04 改线依据 | 无则会话进行中不触发 M05，只在闭环边界规划下一闭环 |
| 期限 / 用户选择 | 继续，按无期限约束规划并标注 |

**冲突规则**：

1. 承载读数只读：不一致时 M05 调整计划，**不反向修改 M15**（严格单向）。
2. **习惯低谷不改道、不加量**（阶段读数）；阈值概念停滞走 M04 → M10，M05 不参与、不与状态侧合成压力量。
3. 目标面锚不到 M08 对象时允许**粗目标 + 逐步锚定**，不强行锚定（D-16）。
4. 期限 / 用户选择是**约束**而非路线结论；决定权在 M05，落脚点由 M01 记录。
5. **会话中改线不回传、不来回踢**（2026-09-23）：M04 先分流——闭环范围内的卡点交 M10，超出范围（缺前置 / 目标过大）才给 M05 改线依据；M05 的决定（含“维持原闭环”及理由）由 M01 存成路径事实，M04 下一轮在「位置与条件」里自然读到，不设回传步骤；M04 读到“已维持”后，**除非出现新证据**，不就同一事项再发改线依据。

## M01 项目、会话与容器

### 定位（`已确认`）

| 项 | 内容 |
| --- | --- |
| 拥有 | 项目 / 会话(闭环) / 分叉 / 轮次 的**容器树**；各模块产出的**归属**；**事实槽** |
| 只存事实，不存解释 | 存"各次会话启动间隔"，不存"启动困难"（解释由 M15/M04 子模块重导） |
| 唯一链接位置 | M09 与 M15 的关联经 M01（两者双向无引用） |
| 明确不做 | 不判掌握；不规划路线；不解释状态；不复制其他模块语义 |

### 容器树

```text
项目
└── 会话（= 一个学习闭环）
    ├── 主线（轮次序列）
    └── 分叉（= 新会话 / 新闭环）── 返回条件由 M05 定、M01 存
```

- 分叉会**打断缓存前缀**，视为独立会话。
- 一个闭环 = 一个对话；闭环内的交互都在同一上下文资产里。

### 事实槽（M01 存的事实）

| 槽 | 内容 |
| --- | --- |
| 目标面 | 粗目标 + 已锚定的 M08 对象（逐步补齐） |
| 路径事实 | 主线 / 分叉 / 当前位置 / 返回条件 |
| 状态关联事实 | M09 记录 ↔ M15 记录 的归属链接（只存位置，不存解释） |
| 产出归属 | 各模块产出资产的位置与产出者 |

### 交接与失败

| 情形 | 处理 |
| --- | --- |
| 某模块请求越权读 | 按权限表**拒绝**并记录 |

**输入清单与缺料 / 冲突规则（A-03 的 M01 落地）**

M01 是登记层：**不因缺料而不写**，规则是“缺什么只登记缺失，不推断”。

| 情形 | 处理 |
| --- | --- |
| 某模块尚无产出 | 登记“暂无产出”，**不推断**其结论或原因 |
| 只拿到解释型描述 | 退回收事实（存“各次会话启动间隔”，不存“启动困难”） |
| 归属 / 位置类跨区写入（R16 / R20 / R26 / R64 / R67） | 由 M01 **统一落账**，不逐个模块列 |
| 语义型内容（诊断 / 掌握 / 状态结论） | 不收（P02）；只保管归属与位置 |
