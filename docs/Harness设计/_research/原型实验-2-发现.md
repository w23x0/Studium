# 原型实验 2：会话中改线接入 M05（发现）

> 状态：待定（2026-09-23）。组合层证据，**不新增产品结论**；等产品负责人真人试用后再定是否改口径。
> 原型：`../../../proto/`。场景 `scenes/newton2.md`；模拟学习者 `learners/knows-newton2.md`（已会全部内容）；8 轮上限；运行 `runs/sim3-m05`。

## 1 接法

| 环节 | 做法 |
| --- | --- |
| 触发 | 教学调用的诊断记录 `[改线依据]` 段非“无”（缺前置 / 已超出范围） |
| M05 | 独立调用；只读当前场景、改线依据、自己的路线偏差记录（不读对话、不判掌握）；输出动作（补前置 / 转确认 / 加深 / 维持）+ 新场景 |
| 落实 | 新范围存 `turns/NNN/scene.md`；`route.md` 记路线偏差；对话本体加系统侧 `[路径]` 行；范围改了则本轮按新范围重做一次教学调用 |
| 防来回踢 | 每轮至多一次 M05；M05 读偏差记录，不做与已做调整相反的改动；教学调用对 `[路径]` 已处理的依据无新证据不再报 |

## 2 结果

| 项 | 结果 |
| --- | --- |
| 改线方向 | 第 3–8 轮：转确认 ×4、加深 ×2（新增主张 5、6）、维持 ×1；无来回改 |
| 维持 | M05 能据偏差记录判“无新依据 → 维持” |
| 有限视角 | 加深的主张主动限定“地面参考系、不借惯性力 / 功能 / 动量” |
| 闭环结束 | 8 轮未结束：范围一路加深，一直没有提议结束 |
| 代价 | 8 轮中 6 轮调用 M05（其中 1 次是解析误判“- 无”，已修），每次改范围多一次教学调用 |
