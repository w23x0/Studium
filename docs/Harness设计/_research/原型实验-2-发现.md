# 原型实验 2：会话中改线接入 M05（发现）

> 状态：现行（2026-09-23）。组合层证据；据此产品负责人确认的口径见 M05 审查单「验收范围的写法」（学习者已超出范围 → 转确认、尽快结束，不在会中加深）。
> 原型：`../../../proto/`。场景 `scenes/newton2.md`；模拟学习者 `learners/knows-newton2.md`（已会全部内容）；运行 `proto/runs/sim3-m05`、`sim4-m05-noextend`。

## 1 接法

| 环节 | 做法 |
| --- | --- |
| 触发 | 教学调用的诊断记录 `[改线依据]` 段非“无”（缺前置 / 已超出范围）；已有完整证据的主张不报 |
| M05 | 独立调用；只读当前场景、改线依据、自己的路线偏差记录（不读对话、不判掌握）；动作 = 补前置 / 转确认 / 维持，另写“下一闭环建议” |
| 落实 | 新范围存 `turns/NNN/scene.md`；`route.md` 记路线偏差；对话本体加系统侧 `[路径]` 行；范围改了则本轮按新范围重做一次教学调用 |
| 防来回踢 | 每轮至多一次 M05；M05 读偏差记录，不做与已做调整相反的改动；教学调用对 `[路径]` 已处理的依据无新证据不再报 |

## 2 结果

| 项 | sim3（允许会中加深） | sim4（不加深，尽快结束） |
| --- | --- | --- |
| 闭环结束 | 8 轮未结束：一路加深（新增主张 5、6） | 6 轮守卫通过 |
| M05 调用 | 8 轮中 6 次（含 1 次“- 无”解析误判，已修） | 1 次（主张 1 转确认） |
| 来回改 | 无 | 无 |
| 有限视角 | 加深的主张主动限定在已学范围内 | — |

## 3 据此改定

| 口径 | 位置 |
| --- | --- |
| 闭环是设计好的：学习者已超出范围 → 相关主张转确认、尽快结束、进入下一个闭环；更深内容记为下一闭环建议 | M05 / M04 审查单；Harness `01-容器与路线设计.md` §5 |
| 整个范围偏浅时剩余教学主张一次转确认，不逐条等；已有完整证据的主张不报改线依据 | 原型提示词（组合层） |
