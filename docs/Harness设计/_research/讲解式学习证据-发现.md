# 讲解式学习（费曼法）证据（发现）

> 状态：现行（2026-09-23）。外部调研，**不新增产品结论**；是 M05「验收范围的写法」与 M02「讲解式主线」（2026-09-23 改定）的依据。
> 问题：以学习者讲解为主线（费曼法）能否支撑“深入”；条件与局限是什么；有无以讲解为核心的辅导系统先例。
> 触发：原型真人试用 `proto/runs/me-3`——验收证据全写成“独立解基础题”，闭环变成问答 / 检验，不符合产品教学目标。

## 1 结论

| # | 结论 |
|---|---|
| 1 | 讲解式学习有稳定的中等效应；“费曼法”不是研究术语，其证据来自**自我解释**与**教中学**两条研究线，不是奇效 |
| 2 | **学习者事先知道要讲**是关键条件：带讲解预期学习再讲 g = 0.48，学完临时被要求讲 g ≈ 0 |
| 3 | **有人追问**优于对空讲（ICAP：互动 > 建构 > 主动 > 被动）；对空讲效果小且不稳，长期保持不占优 |
| 4 | 讲解质量决定收益：讲得多、跨部分整合的学习者才学得好 → 系统追问缺口是必需的 |
| 5 | 以讲解为核心的 ITS 有成熟先例（AutoTutor）：预存**期望要点 + 常见误解**，对照讲解的覆盖度追问 / 提示，约 0.8σ——结构与“验收主张 + 守卫核对”同构 |
| 6 | 大模型场景：开放式自我解释 + 大模型反馈，后测解题与刷题组持平、迁移题解释质量更好、做题量少得多 |

## 2 证据

| 发现 | 数据 | 来源 |
| --- | --- | --- |
| 自我解释效应 | 64 篇 / 69 个效应量，g = 0.55（随机效应） | Bisra et al. 2018 |
| 教中学与讲解预期 | 39 项研究：总体 g = 0.27；带讲解预期学习后讲 g = 0.48，无预期 g = −0.02 | Kobayashi 2024 |
| 对空讲（非互动教学） | 元分析小到中等且不稳；高中物理课堂 N = 1074：即时知识高于重学，长期保持不占优；先验知识不调节效果 | 2025 Educ Psychol Rev（见来源） |
| 书面 vs 口头讲解 | 书面更有组织、利于概念理解；口头更发散、利于迁移 | Lachner 等 2021 及相关研究 |
| 互动层级 | I > C > A > P：做题判对错多属“主动”，讲解属“建构”，被追问的讲解属“互动” | Chi & Wylie 2014 |
| 讲解暴露缺口 | 要求讲清机制后，自评理解显著下降（解释深度错觉） | Rozenblit & Keil 2002 |
| 讲解质量 | 高讲解者整合跨主题、形成正确心智模型；低讲解者与未提示者多未形成 | Chi et al. 1994 |
| 讲解式 ITS | 期望与误解驱动对话（EMT）；学习增益约 0.8σ | Graesser 2016（AutoTutor） |
| 大模型 + 自我解释 | 微积分 N = 92：后测无差异；迁移题解释质量 +11.9 个百分点（p = .030）；做题量明显少 | Chen et al. 2026（arXiv 2604.00142） |

## 3 对 Studium 的用法

| 用法 | 落点 |
| --- | --- |
| 教学主张的证据 = 学习者讲清楚；M05 为每条列要点与常见误解（≈ AutoTutor 期望 / 误解） | M05 审查单「验收范围的写法」 |
| 开场告知学习者本闭环要靠讲清楚收尾（讲解预期） | M02 审查单「讲解式主线」 |
| 教学主要动作：邀请讲解 → 对讲解追问缺口 → 需要时补讲一小段 | 同上 |
| 守卫按要点覆盖核对，讲得含糊判“无” | M04 闭环守卫 |
| 题目只留给迁移级主张，要综合、有深度，不堆基础题 | M05 审查单 |
