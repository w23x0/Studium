# 原型实验 5：先讲后追问真人试用 me-5（发现）

> 状态：现行（2026-09-26）。组合层证据；对应 `../00-技术方向确认.md` §实施顺序 第 3 步的前置（首个闭环）。
> 原型：`../../../proto/`。运行 `proto/runs/me-5`；学习者 = 产品负责人本人。场景由 M05 按“深入学习牛顿第二定律 / 学过高中物理、基础很好、学过微积分”设计（先讲后追问、冷启动不压深度等 2026-09-24 改定之后）。

## 1 结果

| 项 | 内容 |
| --- | --- |
| 轮数 / 结局 | 21 轮，跨三天（中途终端断开两次）；教学侧第 21 轮提议结束，守卫判主张 2、3 证据不足；学习者不再继续 |
| 主张 1【确认】分离变量 | 第 1 轮独立做对，守卫判有 |
| 主张 2【结构】F=ma 是 x(t) 的微分方程 | 开场即请学习者整段讲（先讲后追问生效），学习者“串不起来”→ 逐步搭台阶；各要点在引导下零散说出。第 20 轮不看前文的总结里，“力的形式”变回“加速度”（第 10 轮系统已讲过），“只含 t / 只含 v 的解法区别”仍未区分 |
| 主张 3【近迁移】阻力上抛综合题 | 第 10–19 轮约一半的轮次耗在拆项积分、洛必达等数学技巧和公式输入上；代数改写应学习者要求直接给出。收尾变式题（水平滑行、阻力 kv）独立做对，但未写上下限、未覆盖取极限 |
| 纵深 | 系统几乎没有主动引导往深处挖；“上抛为什么只能算到最高点（v(x) 不再是函数）”只在最后一轮顺带一句；学习者的“减半时间为什么与 v₀ 无关”记入下一闭环候选，未展开 |
| 教学侧误判 | 第 13 轮判“(a) 错在上下限”，第 14 轮自行更正（实为学习者正确） |
| 交互 | 终端断开后学习者三次要求重发；单轮最长约 3.5 分钟；打公式负担重 |

## 2 判断

| # | 判断 | 把握 |
| --- | --- | --- |
| 1 | **守卫独立核对有效**：首次在真人试用中拦下“自己给自己打分”。教学侧第 21 轮诊断写明“力的形式属于答案已暴露”，推断却改为“综合判断可以视为有证据”，把拆项积分、取极限划为“非核心”——自行改写验收标准以便结束；守卫按原文核对未放行 | 较高（逐行对照 `turns/021/diagnosis.md` 与 `guard.md`） |
| 2 | 诊断与守卫证据标准不一致：诊断把“系统讲过后学习者跟着说”算作会了；提示词中“权衡追问代价、推进势头”与收尾疲劳可能促成放宽 | 较高 / 原因不确定 |
| 3 | “系统讲过的内容，当场复述不算独立”使需要教的主张难以当场关闭；解法不是放宽，而是用**光靠复述做不到的方式**取证（换情境、预测、对比、找错、反例等，方法组合归 M10） | 方向经产品负责人确认 |
| 4 | **纵向设计缺失**：M05 给主张 2 标了【结构】，要点却只有“逻辑链怎么串”，缺大学结构级的动机 / 边界 / 依赖；教学侧只围着要点转，于是不主动挖深。“冷启动不压深度”因“深度”无刻度而落不了地 | 较高 |
| 5 | 综合题把数学技巧（拆项积分、ln(1+u) 取极限）捆进物理主张，时间耗在前置熟练度上 | 较高；本次未改，待下次场景观察 |
| 6 | 程序缺陷：守卫不通过时，教学侧“你已完成”的收尾话照样发给学习者 | 确定（已修） |
