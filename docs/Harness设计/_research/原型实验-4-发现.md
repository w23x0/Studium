# 原型实验 4：钻研氛围真人试用（发现）

> 状态：现行（2026-09-24）。组合层证据；对应 `../00-技术方向确认.md` §实施顺序 第 2 步“钻研氛围检验”。
> 原型：`../../../proto/`。运行 `proto/runs/me-3`（改前）、`me-4`（讲解式改后）；学习者 = 产品负责人本人。场景均为 M05 按“深入学习牛顿第二定律 / 学过高中物理、微积分”设计。

## 1 结果

| 项 | me-3（验收 = 独立解基础题） | me-4（验收 = 讲清要点 + 一道综合题） |
| --- | --- | --- |
| 轮数 / 结局 | 14 轮；学习者主动结束，守卫未过（主张 2、3） | 10 轮；学习者中止，仍在主张 2 第 ④ 点，综合题未到 |
| 对话形态 | 出题 → 作答 → 判对错 → 再出题；全程检验 | 每轮 2–4 个编号小问题 → 学习者短答 → 系统纠正 / 小段讲解 → 下一组小问题 |
| 讲解预期 | 无 | 开场告知“最后要讲清三件事 + 一道题” |
| 好奇被接住 | “高中公式怎么来的”被接住，随即回到题目 | “背后是什么原因”“还想继续了解”被接住，给了换自变量的解释；诊断记录写入下一闭环候选（`turns/010`） |
| 学习者自己的洞见 | 少 | 有：“初始 + 过程 → 结尾”“所需信息与阶数相关”“dF/dt = 0” |
| 学习者产出长度 | 短（公式片段） | 仍短（一两句 / 公式片段），**从未有过一段完整讲解** |
| 问题 | 闭环退化为问答检验 | 讲解被拆成小问答：系统带路、学习者答题；节奏慢（10 轮未完）；已做过的【确认】题重做（无 M09） |

## 2 判断

| # | 判断 | 把握 |
| --- | --- | --- |
| 1 | 讲解式验收让内容从“套公式”转到“为什么”，好奇与洞见被接住、被记录——方向有效 | 较高 |
| 2 | 但**教学动作仍是系统提问、学习者作答**：教学提示词里“一次推进一小步、给一个动作”与“请学习者讲”冲突，模型选了拆成小问题的苏格拉底式追问，学习者没有机会连贯地讲 | 较高（诊断记录的策略段每轮都是“给几个小问题”） |
| 3 | 学习者产出短，部分原因是打字 / 打公式成本高；讲解式学习对输入方式更敏感（口头讲解利于迁移，见 `讲解式学习证据-发现.md`） | 不确定 |
| 4 | 一个闭环装 3 条主张、其中一条含 4 个要点，按小问答推进需要 15 轮以上，节奏与“规模”问题相关 | 不确定 |

## 3 未决（待与产品负责人讨论）

- 学习者中止的主观原因（疲劳 / 被牵着走 / 输入负担 / 其他）——氛围以真人感受为准
- 讲解动作怎么改：先让学习者整段讲、再对缺口追问（真正的费曼顺序），还是保留小步引导
- 输入方式（语音 / 手写公式）是否提前
