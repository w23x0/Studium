### 5.6 结构环的可能形态（2026-10-02，agent 列出，讨论中）

前提：已站稳的部分本身连成一片。所以**新学的部分只要在已站稳的网上挂住两处，就合成了环**；挂一处是开口的链（现行定义）。

| 形态 | 在 M08 上的样子 | 需要的关系 | 例（K&K 第 4 章附近） |
| --- | --- | --- | --- |
| A 回到出发点 | 已知 a → 新点 n → 又回到 a（另一种关系） | 推导出去 + 特例 / 上下位 / 等价回来 | 牛二 → 动量定理；质量不变时动量定理就是牛二 |
| B 回到另一个已知点 | 已知 a → n，n 横着连到已知 b | 横向：对比 / 等价 / 应用 / 类比 | 动量守恒（新）与能量守恒（已知）对比：什么时候各自成立 |
| C 两条纵向路汇合 | 已知区两条推导路汇到 n | 只要纵向（现有四种即可） | K3 → K13 → K19 与 K3 → K17 → K19（产品负责人：太大） |
| D 新点之间自成环 | 几个新点互推 / 等价，只挂已知区一处 | 等价、互推 | 动量定理微分形式 ↔ 积分形式 |
| E 经应用情境回环 | 原理 → 用到一个情境 → 情境结果回验另一原理 | 应用 / 适用；情境要成为 M08 对象（M08 审查单待议第 1 条） | 用守恒算碰撞，再用冲量验证外力可忽略 |

变化的维度：回到哪（同一点 / 另一已知点 / 不回）· 靠什么边回（纵向 / 横向）· 新点几个 · 节点种类（概念原理方法 / 加应用情境）。

### 5.9 学习理论调研：回到旧点、跨阶段重述、单元随阶段增大（2026-10-02，子代理；多数只读摘要）

| 问题 | 发现 | 证据强度 / 边界 |
| --- | --- | --- |
| 新知识让旧知识被重新理解 | 没有理论直接证明这一机制。最贴、测量最扎实的是 Linn 知识整合（引出旧想法 → 加入新想法 → 区分 → 反思；Liu, Lee & Linn 2011 JRST 48:1079，18,729 名初高中生验证评估）；Ausubel 整合协调（1963/68）、Novak 交叉连接（1984）只作词汇 | 框架为主；概念图元分析（Nesbit & Adesope 2006 g=0.82 建图；Schroeder 2018 g=0.58）未单独检验交叉连接 |
| 回到的旧点分两类 | ① 旧知识成立、适用范围变了（质点 → 刚体；自然数 → 有理数，Vamvakoussi & Vosniadou 2010；Clement 1989 锚定概念）② 旧知识与新知识真冲突（Chi 1992/2008 三类先备知识）；靠“制造矛盾”触发重新理解效果不稳（Limón 2001） | 只读摘要 |
| 同一概念跨阶段重述 | 学习进阶（NRC 2007《Taking Science to School》第 8 章）最系统，自称假设性，主要覆盖 K-8；Bruner 螺旋课程（1960）效果证据混合；反方 Hammer & Sikorski 2015：阶梯是简化。质点 / 力从初中到大学：未检到研究 | 大学 → 研究生基本空白 |
| 单元随阶段增大 | 专家按原理组织知识（Chi, Feltovich & Glaser 1981，有复现；chunking：Chase & Simon 1973、Gobet & Simon 1998；HPL 2000）；expertise reversal（Kalyuga 2003） | 直接研究“学习单元随阶段增大”的文献未找到，属推论 |
| 仓库已有 | Posner、Vosniadou（`学术补充理论/维度5` §5.4）；APOS、阈值概念（`维度2` §2.2–2.3）；理解四级阶段适配（`理解理论.md`） | Ausubel、Linn、Novak、Bruner、学习进阶、Chi 1981 仓库里没有 |
