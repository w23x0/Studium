## 干跑主题

**主题 = 微积分「导数」的一个闭环**（学生：高中以上、非应试、正在自学微积分）。

## 要走的链（每步都要产出"实际资产文本"）

```
M01 目标面/容器
  → M09 实际状态面
  → M05 路线（算下一闭环）
  → M04 本轮诊断
  → M10 策略 + 四项强度
  → M02 教学回应（面向学习者）
  → M03 练习 + 学习者产出
  → M04 关环判断
  → M09 闭环记录
```

## 每一步都要写清四件事

| 项 | 说明 |
|---|---|
| 输入 | 这一步按设计该读什么（对照模块的"输入清单"） |
| 实际产出 | **把资产文本真的写出来**（用 `02` 的形态：文字 + `文件:行号` 引用；M08/M09 用原子断言 + 链接） |
| 是否可得 | 设计要求的输入，现实中这一步拿得到吗？拿不到就标出来 |
| 设计裁决 | 设计在这里**没说清 / 说不通 / 自相矛盾**的地方 |

## 重点观察（列出至少 8 条）

- 冷启动：M09 空、M08 薄时，目标面和状态面怎么起步？
- M04 的输入清单（§2.9）在真实一步里够不够用？
- M10 拿 M04 的输出能不能定出四项强度？
- M02 的"精准编排"（核心层/知识层/历史层）在真实对话里长什么样？

- M05 算路线的三读够不够？
- 权限表里有没有哪一步实际需要越权读？
