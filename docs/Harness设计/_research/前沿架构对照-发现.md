# 前沿架构对照（发现）

> 状态：现行（2026-09-23）。外部调研，**不新增产品结论**；是 `00-技术方向确认.md` 中 ITS 定位的依据。
> 问题：Studium 的「诊断 / 策略 / 表达拆分 + 上下文装配」在外部有无成熟做法与证据；该与谁对照、取什么、舍什么。

## 1 结论

| # | 结论 |
|---|---|
| 1 | 对照对象选**经典智能辅导系统（ITS）研究**，而非商业 AI 辅导产品：Studium 的模块划分几乎是 ITS 结构的重新推导 |
| 2 | 拆分成立，但理由是**隔离**（诊断不外露 + 长闭环上下文需隔离），不是“多模型更聪明” |
| 3 | 大模型作**隔离的判断函数**，由确定性程序控制流程；不做多身份 agent（交接丢信息，见 §3） |
| 4 | 模块间交接处丢信息是头号风险 → 上游输出完整度（`02` §3.6）是硬要求 |
| 5 | 原型对照组必须是“同信息单模型”，不能是裸模型 |

## 2 ITS 成熟结论 → Studium 对应

| ITS 结论 | 来源 | Studium 对应 | 用法 |
|---|---|---|---|
| 内外两层循环：外层每任务一次选下一任务；内层每步一次给反馈 / 提示并更新学习者模型 | VanLehn 2006 | 外层 = M05；内层 = M04 / M10 / M02 / M03 | 拆法有依据 |
| 按**步骤**交互的系统效果 d≈0.76，接近一对一人类辅导 d≈0.79 | VanLehn 2011 元分析 | M04「过程证据 > 仅最终答案」 | 过程证据是核心，不是点缀 |
| 知识空间理论「外沿」= 前置已具备、准备好学的点；ALEKS 从外沿选下一学习点，成功率约 .93 | Doignon & Falmagne；ALEKS 数据 | A-09 知识面（已学 / 未学交界面）；M05「前方边界」 | M05 选下一闭环可借外沿概念 |
| 以证据为中心的设计（ECD）：主张 → 证据模型（什么表现算证据）→ 任务模型（引出证据的任务） | Mislevy 2003 | M05 验收范围 → M04 闭环守卫 → M03 验证意图 | 验收范围写成「主张 + 证据」，供守卫逐条核对 |

**取**：结构、内外循环、外沿、ECD。**舍**：事先写好的完整领域模型、数值化掌握追踪（审查单已否数值评分）——大模型顶替领域建模与按证据的文字判断。

## 3 AI 辅导系统与多 agent 证据

| 对象 | 做法 | 证据强度 | 对 Studium |
|---|---|---|---|
| Khanmigo | 回复前后台单独做数学检查；先写出“学生可能怎么得到这个答案”再回复 | 1500 万次对话 A/B（强） | 支持“后台分析、诊断不外露”；纯文本对话记录使投入度约 +5%；重点防“作答前泄题”。**理念不同**：面向 K-12、以下一题正确率与投入度为指标 |
| LearnLM | 单模型，每轮以系统指令写明教学要求 | 专家评审 + 课堂试验 | 与 M10 → M02 强度条件同构；可作 M02 候选模型 |
| ITAS / IntelliCode | 多专职 agent 共享学习者状态 | 无单 agent 对照 / 仅模拟学生（弱） | 结构常见，不证明拆分有效 |
| DeepTutor | 多 agent + 独立验证 agent（减少自我确认错误） | 整套 vs 裸模型（混淆） | 独立验证思路与闭环守卫一致；**理念不同**：以解题问答为中心 |
| 单 agent vs 多 agent（2026） | 等算力下单 agent 在推理任务上持平或胜出；交接丢信息；上下文长 / 杂时多 agent 才占优 | 受控实验 | 拆分理由只能是隔离；交接完整度必须保证 |

## 4 模型选型相关（2.1）

| 发现 | 来源 |

## 5 “模型给不了的”部分：记忆 / 来源的最新进展（2026-09-23 补）

| 发现 | 来源 | 对 Studium |
| --- | --- | --- |
| 记忆系统评测大量混杂变量；控制后，逐字检索（RAG）≈ 全上下文，花哨记忆系统的优势多是特定题型、成本高数十倍 | MemDelta, arXiv 2606.29914 | **不采用现成记忆框架**（Mem0 / Zep / Letta 等）当方案；第一版纯文本 + 确定性装配 |
| 冲突时“按版本 / 时间戳确定性取最新”胜过让模型调解；瓶颈在检索后的**装配**，不在存储 | 2026 记忆综述引用的 MemoryAgentBench 结果 | 印证 `02` §3.7 读侧“取最新有效”、D-21 装配为核心 |
| 只追加的无损原始记录 + 带来源链的事实抽取 + “截至某时”过滤 + 矛盾事实标为失效而非删除；跨会话**精简检索的上下文比塞全历史准**（+10 分、token 少 8 倍）；但“只有事实会丢细节”，需配原文片段 | Engram, arXiv 2606.09900 | 与存储终稿（L0 原文单真源 + 版本历史）及 D-002“旧结论不删”同向；M04 读 M09 取“相关片”而非全量 |
| 把原始证据、检索线索、断言分成不同类型，避免“谁说的 / 是事实还是推断”混淆（provenance-role collapse） | MemIR, arXiv 2605.25869 | 与 M04 观测 / 推断 / 替代解释分段、M15 来源分层同向 |
| 记忆增强在长上下文任务上并不稳定胜过直接给基座模型上下文 | AgentLongBench, arXiv 2601.20730 | 闭环内 M04 读完整对话、不做检索，方向对 |

**结论**：护城河的技术底座（只追加原文 + 版本 + 来源 + 确定性装配）业界正在收敛，Studium 已在这条线上；**真正独有的是“存什么”**——带提示条件、独立程度、验收主张的学习证据，通用记忆系统不记录这些。
