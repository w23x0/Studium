## 9 M15 学习者状态与条件

### 9.1 节点定位（`已确认`）

| 项 | 内容 |
| --- | --- |
| 作用域 | 会话外、偏近期（跨轮、跨会话；频率低于 M04、高于 M09） |
| 拥有 | 带时间范围 / 来源 / 不确定性的**非知识类状态与现实条件**；对外输出分**承载读数**与**解释候选**两型 |
| 不拥有 | 知识掌握（M04）、个人知识形成（M09）、路线（M05）、策略（M10）、会话结构（M01） |
| 输入通道 | **对话通道**（主；与 M04 共享同一份 M01 过程记录，但**取不同字段**）+ **现实约束通道**（独立，预留） |
| 明确不做 | 状态记录撤回权、否认后失效传播、敏感状态屏蔽、人格 / 心理疾病判断；不与 M04 侧合成单一"压力量" |
| 严格单向 | M15 → M04（解释候选）；M04 只能回发"重新确认请求"；M15 不读 M04 任何知识结论、不读 M09 |

### 9.2 输入组合

| 通道 | 内容 | 进入方式 |
| --- | --- | --- |
| 对话通道（主） | M02/M03 的**状态相关可观察事实**（连续失误、长停顿、中断、无法启动、回答质量变化）；学习者状态自述；当前任务与上一任务之间的**跨度**（刺激强度前序事件） | 从 M01 过程记录**取字段**（与 M04 同源不同契约） |
| 现实约束通道（预留） | 可用时间上限、环境干扰 | 独立于对话；本轮不设计 |

**与 M04 的"同源不同契约"落在取哪些字段**（`已确认`）：M04 取作答 / 步骤 / 理由（判"会不会"）；M15 取时间间隔 / 中断点 / 求助频率 / 放弃点 / 任务跨度（判"什么状态"）。**不是同一份数据 + 不同 prompt。**

### 9.3 触发与频率（D-001 部分解决）

**触发源（`已确认`方向）**：

| 触发 | 说明 |
| --- | --- |
| 证据事件 | M02/M03 报"状态相关可观察事实"时才跑；无信号不跑 |
| 会话收尾 | 闭环结束时汇总 |
| M04 重新确认请求 | 唯一的反向边（只带请求，不带结论） |

**频率不是旋钮，是涌现的**：波动大 → 事件多 → 跑得勤；稳定 → 跑得少。产品只锁"M04 > M15 > M09"。

**自调频（`已确认`，2026-09-21）**：不新增控制模块，也不让 M05/M10 反向设频率（那会新增 M10→M15 边、且退化为被消费者轮询）。调频信号来自 M15 自身：

1. **状态阶段子模块**（§9.6）跨会话读 M01 会话事实（启动间隔、时长、中断），其"波动 / 恶化"读数即天然调频信号；
2. **自己的读数窗口即将过期** = 自触发刷新。

**窗口下界由消费者给**：M05/M10 的消费节奏决定读数窗口的下界；窗口 < 消费间隔 → 消费者只能看到"未知"（见 §9.4）。

### 9.4 输出分型与时效

**两型输出**（`已确认`），分界 = **是否与知识诊断竞争**：

| | 承载读数 | 解释候选 |
| --- | --- | --- |
| 是什么 | 近观察的事实（当前负荷、可挂任务数、可承载时长、环境限制） | 对本次表现下降的**假设** |
| 消费 | M05 / M10 **直连** | 经 **M04 裁决**后方可作行动依据 |
| 与知识诊断 | 正交，不竞争 | 与"他不会"竞争 |

> 两型是 M15 的**输出契约**（产品要求），经不同边分发（读数直连、候选经 M04）；不是跨模块检索用的语义标签。

**时效：归读侧（2026-09-19 更正）**：M15 只在每条输出上标**产出时间**；「这条读数什么时候还能被用」由**中心上下文分配机制（读侧新鲜度规则）**决定，见 [`02-上下文资产格式.md`](./02-上下文资产格式.md) §3.7。本节原「窗口分档 / 窗口外降为未知」是**产出侧自己管消费者**，已废。保留一条：数据不删，进日志层（见 §9.5）。

### 9.5 日志层 + 视图层（`已确认`方向）

| 层 | 内容 | 性质 |
| --- | --- | --- |
| 日志层 | 每条状态输出（含时间范围 / 来源 / 不确定性） | **只追加、权威** |
| 视图层 | "当前状态" | **派生、可重建**，可被覆盖 |

与 M09 同构（M09 用 git 式版本）。理由：状态必须保留时间范围 / 来源 / 不确定性，原地覆盖会丢失这些。

### 9.6 状态阶段判断子模块（跨会话，三锁）

输出**阶段类型**（习惯低谷 / 堆积型下滑 / 疲劳退化 / 阈值型动力低）+ **所依据的时间跨度**；各行自带回看窗口，输入是 M15 主体状态日志的整合（不新开跨模块通道）。

三锁（`已确认`）：① 只出类型与跨度，不出特质陈述；② 只给读数、不给动作；③ 不与 M04 侧阈值概念子模块合成单一"压力量"。它是"历史信息只用于概率参考"的**唯一例外**来源。

### 9.7 交接（含红线）

| 方向 | 内容 | 边界 |
| --- | --- | --- |
| M01 → M15 | 项目 / 会话、暂停恢复、时长、任务生命周期、节奏起点 | 只读事实 |
| M02/M03 → M15 | 状态相关可观察事实（只给事实） | 不给状态结论 |
| M15 → M05 | 承载读数（路线承载限制）+ 阶段读数 | 直连；不改路线 |
| M15 → M10 | 承载读数 + 已裁决候选 | 直连读数；候选用 M04 已裁决版 |
| M15 → M04 | 解释候选（含来源 / 时效 / 不确定性） | 单向；不得绕过 M04 行动 |
| M04 → M15 | **仅**"某状态需重新确认"的请求 | 不带结论 |
| M15 → M01 | 状态与项目 / 会话的关联事实 | M01 只存位置，不存解释 |
| M15 ✗ M09 | **双向无引用**（经 M01 链接） | 红线 |
| M15 ✗ M04 / M09 知识结论 | 不读 | 红线（保独立替代解释源） |

### 9.8 不建"显式请求"通道（2026-09-17 决议）

学习者显式请求 / 约束（"直接讲""今天只能 20 分钟"）**不建任何专用机制**：

- 它是**普通对话轮**，就在对话里；M04 读对话时顺带可见，M02 正常回应。**不新增输入、不新增边、不新增槽位。**
- 请求对**策略**的影响归 M10（策略所有者）：M10 拿它 + M04 诊断 + 策略模型一起决定是否照做，**不等于必须照做**。
- **习惯靠被动推断**：系统从 M01 会话事实发现"这人常只学 20 分钟"，M10 自动调小闭环——这是产品"被动考察为主"的正路，不需要学习者开口。
- 明确否定旧方案「快路径：显式自述 → M01 事实槽 → M10」：自述是状态侧来源（可靠性存疑），不能直达 M10 绕过 M15/M04；且 M10 每轮都跑，本无延迟问题，不需要快路径。
- 明确不做“不让学习者提请求”：自学者是主体，系统不剥夺其表达；只是**不把请求建成特权通道**。
- **与本模块边界不冲突**：产品给 M10 的「当前用户需求」照常读（M10 输入清单含它）；本节只是说**不为它新增通道 / 槽位**，也不让自述绕过 M15/M04。

### 9.9 失败与降级

| 情形 | 处理 |
| --- | --- |
| 无状态证据 | 不产出读数，标"未知"；不影响知识侧流程 |
| 读数过期 | 当前行动依据降为"未知"，数据留日志层 |
| M15 与 M04 解释冲突 | 并存、标注冲突，由 M04 裁决（不选边） |
| 自述与观察冲突 | 并存标注；自述不覆盖观察事实 |
| 声称超出学习范围（健康 / 心理疾病） | 不做诊断，不据以行动 |

### 9.10 输入清单与缺料 / 冲突规则（A-03 的 M15 落地）

**规则 1–4 同 `01-节点设计.md` §2.9**。M15 的缺料表现为**不产出**（无状态信号即无读数），而非降级猜测。

| 输入 | 缺失时 |
| --- | --- |
| 对话通道字段（间隔 / 中断点 / 求助频率 / 放弃点 / 任务跨度） | **不跑**：无状态信号即无产出，标“未知” |
| M02 / M03 状态相关可观察事实 | 同上（证据事件是主触发） |
| M01 会话事实（节奏起点、时长） | 降级：阶段子模块**不出“习惯低谷”**（其回看窗口依赖起始位置） |
| 现实约束通道（预留） | 不接入；只按对话通道出读数并标注“现实约束未知” |
| M04 重新确认请求 | 继续（请求非必需，只是唯一反向边） |
| 已有 M15 状态日志 | 继续；无历史则只出当前读数，**不出趋势** |
| 授权外部信息 | 继续；未授权则不接入 |
| M04 知识结论 / M09 | **红线：不读**（P10 / P24） |

**冲突规则**：

1. 自述 vs 观察 → **并存标注**，自述不覆盖可观察事实。
2. M15 候选 vs M04 诊断 → 并存、交 M04 裁决；M15 **不选边、不因 M04 结论收敛候选**。
3. 读数窗口过期 → 读侧判“缺槽”（`02` §3.7）；M15 只管产出与产出时间，不管消费者。
4. 阶段类型与 M04 侧读数**不得合成单一压力量**（三锁）。

### 9.12 状态使用规则（组合层定稿，2026-09-21）

> 这是**组合层自己该定的东西**，不是产品决策：M15 只负责产出资产，**谁用、怎么用由各模块自己的输入清单（A-03 各节）决定，不归 M15 设定**。

| 项 | 规则 |
| --- | --- |
| 谁用 | 由各模块输入清单决定：M05 / M10 直连读**承载读数**；M04 评估**解释候选**；M01 存状态与项目 / 会话的关联事实。M15 不维护消费者名单 |
| 怎么用 | 各消费方在自己作用域内决定（M05 调路线承载、M10 调本轮强度、M04 参与诊断裁决）；M15 不给动作、不排序优先级 |
| 解释候选 | **必须经 M04 评估**后才能作为行动依据；M05 / M10 读 M04 输出中"已评估的状态候选"一段，**不自判真假** |
| 时效 | 由**读侧新鲜度规则**（[`02-上下文资产格式.md`](./02-上下文资产格式.md) §3.7）判定"还有没有效"；M15 只管产出与产出时间，不管窗口、不管消费者 |
| 缺读数 | 消费方按"无状态约束"降级并标注（M05 / M10 各节失败降级） |
| 频率 | 由 M15 自身事件与窗口过期驱动（§9.3）；消费方不设频率、不请求刷新 |
| 红线 | M15 不读 M04 / M09 的知识结论；不与 M04 侧子模块合成单一压力量 |
