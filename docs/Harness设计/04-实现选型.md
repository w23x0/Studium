# 实现选型：原型用什么写、怎么保质量

> 状态：**已决（2026-10-08，#36；闭环内循环当日改为 Agent SDK）**。依据与比较见 [`_research/原型技术选型-发现.md`](./_research/原型技术选型-发现.md)（外部调研，不作结论）；本文件只写定下的选型。要装什么以 `00-技术方向确认.md`、`03-运行设计.md` 为准；本文件不新增产品结论。

## 选型

| 项 | 定了什么 | 一句话理由 |
| --- | --- | --- |
| 闭环内循环 | Claude Agent SDK（TypeScript），用产品负责人自己的 Claude 订阅登录；关掉内置工具（`tools` 只列我们的）、自定义系统提示、`settingSources: []` 不读 CLAUDE.md 与设置，我们的工具经进程内 MCP（`createSdkMcpServer`）挂上；第一版只接 Claude。以后要按 API 计费、公开给别人用或接其他厂商时，按四个接口（`03`「闭环对话」）换成 Anthropic 官方 SDK 的 Tool Runner 或别的框架 | 官方维护、不自写循环（`00` 原则 4）；个人自用可走订阅（官方：Pro / Max 额度按个人正常使用 Claude Code 与 Agent SDK 设定；禁止的是开发者让“他们的用户”用订阅登录）；上述选项官方文档都支持 |
| 语言 | 核心与界面都用 TypeScript；`书库处理/` 继续 Python，与核心只经文件交接 | 前后端共用类型；类型检查是代码全交 agent 写时最便宜的护栏 |
| 核心形态 | 常驻本地服务：HTTP 收命令、SSE 推事件，只绑本机地址 + 口令 | 界面关了后台会话照跑；以后换外壳核心不动 |
| 外壳 | 第一版在浏览器里打开本地页面，不打包；桌面外壳等打包时再选 | 改起来最快；换外壳不动核心与界面代码 |
| 界面 | React + Vite；shadcn/ui + assistant-ui，调颜色 / 字号 / 间距到接近 Claude 桌面版；不手搓、不 fork 整套开源聊天应用 | agent 最熟、界面一致 |
| 存储 | 每个会话一个 JSONL 正本，一个写者，只追加、**永不改写**（格式升级只产出新文件或派生层，不自动清理）；SQLite 作派生层（索引、列表、检索），坏了从 JSONL 重建；PDF 与转换结果只存路径 + 内容哈希 | `文件:行号` 稳定（`00` 原则 8、`03`「上下文资产」） |
| 代码位置 | Studium 仓库内新开一个目录，与 `书库处理/` 并列：`原型/`（10-08 实现时定） | 不另开仓库 |

## 实现时要守的

| 规矩 | 原因 |
| --- | --- |
| Agent SDK 存的记录不是模型原样消息：交回的对话原文由我们从它吐出的消息流里自己记（消息带原始 API 消息） | `03`「闭环对话」交回原文 |
| 实现期确认：中途追加事实走流式输入（`priority`），能否发中途 `role:"system"` 消息、压缩方式会不会让思考块失效 | Agent SDK 自己管上下文，下一行的规矩由它守多少未核实 |
| 一个闭环对话里只追加：不重渲染系统提示、不删改旧消息、不改工具数组；程序追加事实用中途 `role:"system"` 消息；工具 / skill 开场全部声明，隐藏的标 `defer_loading`、用 `tool_addition` 放出；太长用服务器端压缩 | 改前缀会让之前的思考块失效（报 400 或静默丢弃）；前缀不匹配时设为报错，不设静默丢弃 |
| 界面不靠工具调用之间的说明文字显示进度 | Sonnet / Opus 5.5 会把这段文字放进思考块，默认不返回 |
| 公式流式显示：没写完的公式先显示原文、写完再渲染；`\(\)` `\[\]` 归一成 `$` | 避免半截公式显示成错误 |

## 质量

产品负责人不读代码；界面由产品负责人自己看，不做截图检查。

| 优先 | 做什么 |
| --- | --- |
| P0（第一天） | 一条检查命令（`tsc` 严格 + lint + 格式 + 测试，几十秒跑完，报错一行一条）· 假模型，程序测试一律不调真模型 · 依赖方向测试（模型 SDK 只能在适配层被引用，报错写明怎么改）· Claude Code hooks 进 git（改后格式化 / lint，结束前跑检查，禁改验收测试目录）· CI 跑同一条检查 · 短 CLAUDE.md（约 100 行，当地图）· 功能清单 JSON（每条带怎么验证，初始全失败） |
| P1 | Playwright 只走功能主路径（开会话、发消息、关掉重开记录还在）· 真实运行录带、离线回放 · 独立审查子代理（新上下文、最好换模型、只报正确性与需求缺口）· 行为评测单独一个目录（模拟学生多轮、每个失败模式一个过 / 不过判定、看 k 次全过），不进每次提交的门禁 · 测试改动单独提交、CI 报告删改了哪些断言、lint 禁止宽泛吞异常 |
| P2 | 定期清理会话（去重、死代码、文档新鲜度）· 定期换模型做架构审查 · 核心模块变异测试 |

不做：覆盖率门槛、模型原文快照测试、大而全的 CLAUDE.md、第一天就多 agent 编排与自动合并、写代码的会话自评完成、审查意见条条照改。
