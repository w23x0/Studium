# 阶段0 · 概念热身：agent 生态地图

> 2026-08-15 · 零基础第一课
> 目标：建立「agent / framework / harness」三层坐标，看清 DSH 站在哪、它最特别的地方是什么。
> 依据：Anthropic《Building Effective Agents》、Cordis Primer、DSH 仓库 glossary / architecture。

## 1. 三个词，三层东西

先记住一句话，剩下都是展开：
**agent 是"人"，framework 是"积木"，harness 是"房子"。**

### Agent —— 能自己干活的程序单元

核心循环：观察 → 思考 → 行动 → 观察结果 → 再思考……

- LLM 负责"思考"（决定下一步）
- 工具负责"行动"（读写文件、跑命令、搜网页）
- 环境反馈驱动下一轮循环

### Agent Framework —— 搭 agent 的积木（库）

- 它是一堆你 import 的代码：编排逻辑、工具接口、记忆抽象
- 例子：LangChain、LlamaIndex、CrewAI、Microsoft AutoGen
- 你会"用 LangChain 搭一个 agent"，不会"运行 LangChain"

### Agent Harness —— agent 住的房子（运行时/宿主）

- 它替 agent 管"框架之外"的事：会话持久化、权限批准、沙箱、上下文管理、子 agent、日志、界面
- 例子：Claude Code、DeepSeek Harness、Cline
- 你会"跑在 Claude Code 里"、"用 DSH 启动一个 agent"

> 自测：LangChain 是 framework（积木），Claude Code 是 harness（房子），AutoGPT 是一个"自主 agent 应用"（成品）。

## 2. workflow vs agent —— Anthropic 的权威区分

- **Workflow**：路径由开发者写死，LLM 按预定步骤走（顺序、路由、并行）。可预测，适合定义清楚的任务。
- **Agent**：LLM 自己决定下一步做什么、用什么工具，根据环境反馈调整。适合开放性问题（路径无法预知），但更贵、错误会累积。
- 两者是同一光谱的两端，不是非黑即白。DSH 的 `agent-loop` 是"自主 agent"形态；`goal`/`turn`/`step` 就是它控制这种自主性的机制。

## 3. 底座：增强 LLM（Augmented LLM）

agent 的地基是"增强 LLM" = LLM + 三样东西：

- **Retrieval**：检索相关材料
- **Tools**：操作外部世界（文件、命令、API、网页）
- **Memory**：决定留什么、丢什么

**agent = 增强 LLM + 自主循环。** Studium 的自学系统本质也是这套：检索资料 + 调工具 + 决定哪些知识入册。

## 4. agent 的三类典型架构

1. **工具使用循环**：调工具 → 看结果 → 修正 → 再调。编程 agent 的日常：改文件、跑测试、看输出继续。
2. **规划与反思**：先规划，多轮执行，卡住暂停问人，完成或超限停止。evaluator-optimizer 模式：一个写、一个评。
3. **多 agent**：并行分派 / 编排者-工人。Studium 的调研流水线（research_tree）就是这种形态。

DSH 里的对应物（预告）：工具使用循环 → `packages/core` 的 agent-loop + tools；规划 → `plan` 包；多 agent → `subagent` 包。

## 5. DSH 站在哪 + 它最特别的地方

DSH 是 **harness**，不是 framework。它的特别之处有三：

1. **一切皆插件**：模型适配器、工具注册表、会话日志，连 agent 循环本身都是插件，全部可从配置替换，没有特权核心。
2. **有理论论文支撑**：大多数 agent 框架没有形式化基础；DSH 背靠北大 + DeepSeek 的《A Programming Paradigm for Spatiotemporal Composability》。
3. **底层是 Cordis**（自我定位"时空可组合性元框架"）——一个插件宿主。比喻：Cordis 是建材和图纸，DSH 是用它盖好的房子。

## 6. Cordis 五个核心概念（源码阶段的预告）

1. **Plugin** = 实现 Service 的对象。可以是一个带 `inject` / `apply(ctx)` 的函数，或一个 Service 子类。
2. **Context** = 服务的仓库。服务认领 `ctx.tools` / `ctx.llm` / `ctx.sessions` 这样的 key，别的插件靠 key 找服务，而不是 import 具体实现。
3. **inject** = 声明"我需要哪些服务"。加载顺序靠需求决定，不靠手动排 boot 顺序。
4. **Typed Events** = 类型化事件，四种分发模式：`emit`（观察）/ `waterfall`（中间件，包一层）/ `parallel`（并行）/ `serial`（按序、有返回值）。
5. **Registrations are reversible effects** = 一切注册都是可回滚副作用。这五个字直通论文的时间维组合性（temporal composability）。

## 7. 生态位置图（一句话版）

| 东西 | 类别 | 一句话 |
| --- | --- | --- |
| LangChain / LlamaIndex / CrewAI | framework | 搭 agent 的积木 |
| Claude Code / Cline | harness | agent 的宿主，有核心 |
| DeepSeek Harness | harness | 一切皆插件的宿主，有理论 |
| AutoGPT | 应用 | 一个自主 agent 成品 |
