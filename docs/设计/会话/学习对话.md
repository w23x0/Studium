## 1 是什么

| 项 | 内容 |
| --- | --- |
| 一句话 | 一次学习一个学习对话（主对话下的任务对话，`../01-流程.md`）；分析学习者、讲、练在这一个会话、一个主循环里完成 |
| 主任务 | 弄清学习者现在怎么理解这个点和它的出发点，并把新点接到这个理解上；这件事贯穿整场，不是开讲前的一步。讲、问、请学习者自己说或做、一起读原文、谈这个点拿来做什么，都是手段，一句话可同时做几件，由模型组合（§5 §6 是手段清单，不是先后两段）。提示词底层只写这个目标与定义；教学工具是按需取用的做法（§7） |
| 讲 / 练背后的原理 | §5“讲”§6“练”这样分只是为了好说；背后是两种方向：**模型教学**（模型把东西给学习者）与**模型索取**（模型想从学习者口中知道什么），这样分才完整，不按字面的“讲解 / 做题”理解 |
| 不是串行流水线 | 分析 → 讲 / 练 → 学习者的反应 → 再分析，可回流、可分支；不按职责排固定循环（`../00-定位与原则.md` §9） |
| 初始提示 | 只写清目标，怎么做交给模型；“讲授形态”（§5）的意思写进目标描述。程序只保证三项：何时停、记什么、什么算进展（`../00-定位与原则.md` §6 原则 7） |
| 提示词与上下文 | 位置、状态、策略、系统限制都以事实进入（开场、收件箱），不写成命令；提示词只留最小约定，不用角色、不用输出模板（B-03、B-05） |
| 用通用框架 | 一次学习之内不自写循环，用可整个替换的通用 agent 框架；Studium 做一次学习之外，两边只经 §2 四个接口 |

## 2 四个接口

| 接口 | 内容 |
| --- | --- |
| 开场 | 只给**目标 + 事实**：目标 = 靠单子里的出发点、沿选中的子句把新点合上；事实 = 单子（新点 + 选中的子句 + 路线动作，`../记录/单子与路线.md`）。程序不挑资料片，要什么模型自己到沙盒里取 |
| 沙盒 | 程序在执行环境里写死的边界，模型在里面用通用执行（脚本 / 命令），往云沙盒方向走。**只读**：本项目资料原文（`../记录/资料.md`；代码仓库可在学习者代码目录里跑、改）、学过的记录（`../记录/学过的记录.md`）、状态记录（`../记录/状态记录.md`）、教法记录与教法资料（`../记录/教法记录与教学工具.md`）；确切范围以 `../记录/读写权限.md` 为准。**可写**：模型工作区、学习者代码目录。联网另设 |
| 沙盒里的命令 | “申请收口”“结束这次学习（没合上）”只通知程序，写入与存盘由程序做。后者由学习者在界面上点，或在对话里说了由模型代为执行；之后程序走的清单见 `../01-流程.md` |
| 收件箱 | 程序中途推事实：守卫的收尾记录、离开多久、学习者动作等 |
| 事件记录 | 全程只追加；对话与沙盒动作**当场记**，每条标明学习者 / 模型 / 程序；Studium 用时再读，不必实时推（`../记录/对话与事件记录.md`） |
| 入选条件 | 换框架看：事件能当场取出、能接沙盒、能中途推消息、收口时程序能插手。Agent SDK 能否吐出沙盒动作事件：待查（实现期，`../实现选型.md`） |

## 3 怎么跑

| 项 | 设计 |
| --- | --- |
| 何时开 | 导航定下单子后，一次学习一个（`../01-流程.md`）；分叉 = 另开一个学习对话 |
| 何时跑一轮 | 学习者每发一次话；程序经收件箱推事实后（守卫交回收尾记录、学习者离开后回来）接着跑一轮 |
| 上下文 | **连续**：一次学习一份上下文，只追加；太长才压缩一次，用服务器端清理，学习者原话不删不改；压缩后要看原话，在沙盒里按行号读回；跨天原样重放（`../记录/对话与事件记录.md`） |
| 暂停与回来 | 不算事件：学习对话原样留着，回来时程序向收件箱推离开多久，模型据此接着教（`../01-流程.md`） |
| 模型 | 可单独配模型与思考强度，默认当下最强、高强度；不按职责分别选型；选模型看教学行为，不只看解题能力（MathTutorBench arXiv 2502.18940；arXiv 2505.15607） |
| 交回 | 给学习者的话 → 学习者；模型的分析留在它自己的连续上下文里，不作为记录交给别人读（§4）；工作区的写入由程序记进事件记录，守卫不读（`守卫.md`） |

**为什么连续**：

| 项 | 内容 |
| --- | --- |
| 冲突 | 前设计（从想象写出）：诊断记录不回灌下一轮，防止模型拿自己的分析喂自己。后验证（`../../agent框架学习/08-有状态与无状态.md` §4，含外部旁证 CCM：每轮重装使编程 agent 完成率明显下降）：宜连续。以后验证为准 |
| 收窄后的约束 | 只约束守卫：守卫不读模型的工作区与思考；学习对话的分析留在自己的连续上下文里 |
| 证据边界 | **未在本项目做过实验**；CCM 是终端任务、4.6 一代，属外部旁证 |
| 已知风险 | 错误推断留在上下文里，锚定后续判断（`08` §5：软推断没有报错那样的纠错信号） |
| 对照办法 | 同一组学习者输入下比较连续 vs 每轮重开 |

## 4 分析学习者（原进行中诊断）

**不另写诊断记录**：分析就是模型自己的思考，留在一次学习的连续上下文里；不要求每轮写下、不给学习者看、不作为记录交给别人读。工作区是模型自己的草稿，想记才记（写入照样由程序记进事件记录）。下表“诊断”指这种分析本身。

| 功能 | 内容 | 档 |
| --- | --- | --- |
| 基于整次学习的历史 | 读目标（单子）、路径位置、教学与练习条件、学习者表现、学过的记录，随新证据修正；不只看最近一轮；自己上一轮的诊断只作可推翻的工作判断，以现场证据为准 | 主干 |
| 信息分类 | 进入分析的信息不混成一段无类型文本，至少分：单子与路径位置（主线 / 分叉 / 迂回）；学习者原始表达和行为；已给过的讲解、提示、答案暴露和脚手架；练习任务、完成条件、独立程度；学过的记录（只作背景）；事件记录里的教法与强度；信息缺失、工具失败、模型降级等限制 | 主干 |
| 证据分级 | 区分学习者原始表现、自述、学过的记录、软推断和硬证据，保留来源、时点、提示条件和路径位置；守卫的证据标准只给守卫，不给学习对话（给了会照着尺子去造证据）；学习对话只按合上的定义（`../00-定位与原则.md` §2）判断什么时候学完；**不为凑证据驱动教学** | 主干 |
| 理解判断 | 对认出、复现、结构、迁移等表现分别取证，达标表现随目标和阶段变化；是判断维度，不是存下来的标签；不用数值评分、固定阈值、高维向量 | 主干 |
| 错误归因与替代解释 | 区分没学过、提取失败、概念混淆、步骤断裂、方法或条件问题；从可观察证据定位具体环节，保留替代假设，经后续教学或练习验证。**验证先预测**：先说出学习者在一道新题上预计会怎么做（会怎么错），再看实际表现，对上才算被支持；落空时先分清是归因推错、验证题测不出这个问题，还是状态原因，不默认回改依据资料。分类表不锁死 | 主干 |
| 替代解释的范围 | 只考虑知识与输入方面的可能（含“输入残缺 / 转写错误”，§5），**不猜测学习者的动机** | 主干 |
| 学过的记录可被怀疑 | 学过的记录（含外部导入）只作背景，不得覆盖本次证据；本次表现与之不符时以本次为准 | 主干 |
| 遗忘 | 发现“以前会的现在答不出”，作为一条替代解释（候选）考虑；可本轮直接补讲，或经导航另开复习；须排除疲劳退化等状态侧解释 | 主干 |
| 前置缺口与改线依据 | 受阻时结合单子里的出发点和本次表现验证前置缺口；出发点只来自自述 / 假定、对话表现说明它不牢时同样是前置缺口（自述与假定不是证据）。需要补前置、改目标、搁置或重规划时，在对话里跟学习者说清依据（是否补前置、分叉目标、返回前要满足什么；进事件记录），学习者到主对话要下一步时由导航读到并决定（`导航.md`「何时开」）；不自行建分叉。分叉里的表现保留路径关系，不直接判为主线缺口 | 主干 |
| 状态解释候选 | 读状态记录里的解释候选，和知识证据一起掂量：这就是裁决；不另写已评估的状态候选。不写状态记录，不给状态记录任何知识结论；只能发“某状态需要重新确认”的请求，请求不带结论（`../记录/状态记录.md`） | 主干 |
| 条件决定证据意义 | 同一个正确答案在独立完成、轻微提示、多次提示、答案已暴露下意义不同，不脱离条件只读最终结果 | 原则 |
| 缺料可见 | 上下文不完整或关键来源不可用时，对学习者明说限制，必要时说“证据不足”，不伪装完整 | 原则 |
| 分支不互相污染 | 主线、分叉、迂回的信息保留关系，不同任务、提示条件、无关旁支不互相污染 | 原则 |
| 分析不是结论性产物 | 分析不带出这次学习；这次学习唯一的结论性产物是守卫判定（`../会话/守卫.md`） | 原则 |

## 5 讲（原教学互动）

| 功能 | 内容 | 档 |
| --- | --- | --- |
| 本轮诉求与起点 | 回答前识别学习者是在求解释、澄清、例子、反馈还是验证，并先探查卡点 | 主干 |
| 理解 ↔ 训练 | 一次学习之内是理解与训练的来回：先理解（讲、推导），再让学习者用它自己推、自己用；用的时候暴露的缺口再回去讲。看懂 ≠ 理解，单靠输入不算合上。**学习者的输出是为了让理解完成，不是为了取证**：提问、给情境，是因为下一步取决于学习者会不会，也让学习者想清楚、用起来；问之前说清在问什么、为什么问；不按清单取证、不出谜题，不另设收尾复述——训练中的输出本身就能说明理解到了哪 | 主干 |
| 讲授形态 | 可以**成段讲授**，不拆成小问题；一轮讲到第一个“下一步要看学习者怎么回答”的地方就停，不一次讲完，不替学习者做完（学习者必须做事，稀缺的是学习者的注意力）。**质量下限是教材，兜底是直接引用资料原文**（给出处）；**上限不设**：知道学习者已站稳什么、这次从哪些出发点出发，可以讲得比写给一般读者的教材更贴合。与教材说法不一致之处要说明，不把模型自己的说法当原文。“作答前不给答案”只管题目；脚手架只在卡住时用。何时讲由分析定 | 主干 |
| 有限视角 | 只用学习者已知或当前可承接的内容组织最小推动，不从正确答案倒推学习者。“已知”以单子里的出发点（及学过的记录里已会的）为起点，**随这次学习里学习者实际表现出的知识更新**：学习者主动用出且用对了未列入的内容，可以接着用，不因“按设定未学”挡回 | 主干 |
| 追问与脚手架 | 卡住时用单步追问、提示、辨析和逐步撤除帮助学习者自己继续，不代替完成；不是默认教法。顺序参照 AutoTutor：开放式追问（“还有呢”）→ 提示 → 具体引导问题 → 最后才讲出 | 主干 |
| 解释、示例与多表征 | 例子、反例、图示 / 语言转换、类比、复述引导；辨析 / 对比用时由模型当场判断；不能被练习替代 | 主干 |
| 教学反馈 | 对学习者已有表达给出指向知识、逻辑或过程的反馈，不做人格 / 价值评判；必要时明说不确定 | 主干 |
| 原件与截图 | 需要时附原件页面 / 局部截图（位置来自资料）；转录未核实时以截图代文字（B8；放云端时给不给看见 `../待确认项.md` B18） | 主干 |
| 学习者表达的输入 | 要能连贯表达含公式的内容，纯文本框不够。语音、手写图片经外接转写工具转成文字进入对话，教学只读文字；原件保留，转写文本标来源；“输入残缺 / 转写错误”列为替代解释，不当作学习者的错误。摄像头、平板手写等多模态以后接 | 主干 |
| 好奇偏离 | 先接住；超出本次新点的记为下一次学习的候选（由导航定，`../会话/导航.md`） | 主干 |
| 离开与接续 | 待定（原依据 MVP 实验已撤下）；回来时的机制见 §3“暂停与回来” | 待定 |
| 教学风格口头调节 | 学习者在本轮口头调节严格度、简洁度、主动追问和反馈方式；可调维度、默认值、是否暴露待产品确认；长期配置见 `../记录/教法记录与教学工具.md` | 候选 |

## 6 练（原练习活动）

练习是一条活动链：目的匹配 → 独立产出 → 过程反馈 → 归纳 → 变式 / 迁移；不退化为出题判答案。

| 功能 | 内容 | 档 |
| --- | --- | --- |
| 讲与练的分界 | 看主要产出，不看消息方向：解释一道题、给例子和提示是讲；要求学习者完成题目 / 证明 / 实验 / 复述并记录过程是练。解释、复述、写作两边都可能，以谁产出、是否用于独立表现区分。重点一转为学习者独立产出就进入练习 | 定义性交界 |
| 资源组织 | 题目、证明、推导、实验、项目、解释和写作任务可按目标、内容、功能、阶段调用；题集属于资料，实际执行才是练习 | 主干 |
| 选择 / 生成 | 按缺口、目的、难度和当前阶段选或生成，不随机刷题；“知识 / 思路 / 技巧熟练层”与“概念澄清 / 计算 / 证明 / 应用功能”是两个分类维度，不各建一套 | 主干 |
| 任务说明与完成条件 | 每次练习说清练什么、交什么、能否提示、何时算完成 | 主干 |
| 答案与过程采集 | 同时记结果、关键步骤、理由、尝试和自我解释，不只最终答案 | 主干 |
| 错误反馈与重复模式 | 反馈定位知识、思路、技巧或过程问题；重复错误升级为模式，不作人格评价 | 主干 |
| 递进、变式与迁移 | 有提示 → 无提示，同形 → 变式 / 混合场景，检验独立提取和迁移；防止“原问法会答就算掌握” | 主干 |
| 题型 / 方法归纳 | 从同类任务提取关键条件、逻辑链、方法与易混点 | 第二梯队 |
| 阶段性练习体验 | 日常练习与阶段验收分开，降低每题的审判感 | 第二梯队 |
| 高阶活动 | 复现论文、实验、论证、写作等的任务过程与表现；长期可迭代的成品与版本归 `../记录/知识产出.md` | 第二梯队 |
| 生成的题 | 不默认进资料库，来源标“生成”（`../记录/资料.md`；D-008） | 主干 |

- 练习“做完” ≠ 合上；学习者把新点和出发点接起来用的表现，才说明接上了；守卫收尾时按学习者实际表现写记录（`../会话/守卫.md`）。固定阈值、字段枚举不进需求；自动推断、心理 / 负荷软信号不能单独让练习通过。

## 7 教法与强度（原教学策略的一次学习之内部分）

| 项 | 内容 |
| --- | --- |
| 强度自己定 | 学习对话据分析、状态记录的读数、现实条件和目标，自己选教法、定信息量、提示强度、挑战程度和节奏（本次会话内的强度坡度），可调外部数据来判断；信息量的高端是成段讲授（§5） |
| 缺输入还是缺练习 | 也由它据分析判断；输入与练习不可互替 |
| 合上标准不下调 | 慢慢施压要的是本轮坡度，不是拆掉门槛；什么时候学完由学习对话与学习者定 |
| 教学工具 | 不常驻提示词、不装进这次学习，作为沙盒里的可读资料，需要时自己查（以后模型可能内化教法，只需提醒激活）；每份是某个情形下可选的做法，不是流程，用不用、怎么组合由模型定；“听懂学习者现在怎么想”不是教学工具，在提示词底层（§1）。资料本身见 `../记录/教法记录与教学工具.md` |
| 程序照记 | 哪一轮读了哪份教学工具、用了什么强度，由程序从事件记录取，不靠模型自报；读了 ≠ 照着用了，不单独核对（B9） |
| 事后整理 | 教法对这个学习者管不管用，由后台整理事后读事件记录写进教法记录（`../会话/后台整理.md`），放进沙盒供下次学习查；学习对话不下发、也不收别人下发的策略 |
| 学习者请求 | “直接讲”“今天只能 20 分钟”是普通对话轮，影响归策略判断、不必照做，也不剥夺学习者表达（D-20） |
| 状态读数怎么用 | 承载读数（当前负荷、可挂核心任务数、可承载连续时长、环境限制）可直接用；解释候选按 §4 裁决后才用 |
| 先查自身教法 | 状态记录标注某状态出现在某反馈模式生效之后时，**必须先查自己的教法是否为成因**，不直接当作学习者固有条件（例：威胁感上升的成因是逐题评判，正确动作是改为阶段性验收，而不是降难度） |
| 阈值概念停滞 | 是不是阈值概念由模型现场判断；卡在阈值概念上是质变前兆、属预期内下降：会话内调强度（换切入角、降信息量、加小步验证、加密小反馈），**不改路线** |
| 与习惯低谷不合并 | 习惯低谷是状态侧、走状态记录 → 导航（不改道、不加任务）；阈值停滞是知识侧、在学习对话内处理；不合成单一“学习压力”量 |
| 状态阶段读数 | 读到状态阶段时可参照原教学策略侧的对应动作：疲劳退化降载、阈值型动力低改高频小反馈；习惯低谷与堆积型下滑主要由导航处理；不重新判断阶段类型 |
| 加压 / 减压 | 不设固定组合，由学习对话按现场的分析、状态记录等自己判断 |

## 8 跨一次学习带什么

一次学习之内不设单独的记忆，说过的就在连续上下文里。要带到下一次学习的，一律出这次学习、由有明确写入者的记录存住，下一次在开场给或在沙盒里查到。（本节框架未经定稿：待定；“学习者认识”“没合上”两行按 10-18 定稿）

| 要带的东西 | 存在哪 · 谁写 |
| --- | --- |
| 学习者认识 | 合上时守卫判定里写的“学习者实际表现出的理解”（`../会话/守卫.md`），连同单子、事件记录进学过的记录（`../记录/学过的记录.md`）；不另写形成记录 |
| 没合上就结束 | 单子 + 学习者为什么结束的原话 + 导航当时的路线决定和理由（`../记录/单子与路线.md`）；不另写总结 |
| 非知识状态 | 状态记录（`../记录/状态记录.md`） |
| 教法对这个学习者管不管用 | 教法记录：从事件记录（读了哪份、每轮强度）+ 守卫判定派生，后台整理写（`../记录/教法记录与教学工具.md`） |
| 学习对话的推断（未经守卫，如“怀疑混淆了 A 与 B”） | **不带出作结论**：留在它自己的上下文里（写进工作区的草稿随事件记录存，只作审计）；以后要知道学习者混了什么，读对话原文里学习者实际说的、做的（导航派检索子代理，`导航.md`）。带出去作结论就绕开守卫，等于往下一次学习塞自评 |

## 9 缺料与冲突

| 项 | 内容 |
| --- | --- |
| 缺了不开 | 单子；学习者输入（开会话前由程序查，A-03） |
| 缺了降级并标注 | 路径位置 → “位置未知”；学过的记录 → “缺历史背景”；资料 → “缺资料依据”；状态记录 → “缺状态信息”，按无状态约束 |
| 冲突 | 对话内现场证据优先于学过的记录；状态解释候选与知识解释竞争 → 按 §4 裁决；不把别的会话的结论当输入 |

## 10 边界

| 项 | 内容 |
| --- | --- |
| 不写结论性记录 | 不写学过的记录、状态记录、教法记录、单子；写入只经事件记录（程序记）与沙盒可写区 |
| 单子不由它改 | 新点与子句的调整须经导航决定（`../会话/导航.md`） |
| 不写收尾记录 | 学完了就申请收口；这次学到了什么由守卫独立写（`../会话/守卫.md`） |
| 给状态记录的是事实 | 反复卡在同一步、要求降难度、主动中断、连续放弃、要求提示、作答时长异常等只是可观察事实，在事件记录里；状态语义由状态记录形成 |
| 不贴标签 | 友好反馈不写成掌握结论；不形成固定学习风格、人格结论 |
