# 找资料

> 状态：已决（10-23）。来历查 `../../../定稿记录.md` 10-23。
> 参照：NotebookLM 的“发现来源”（按话题联网搜，推荐至多 10 份、各附为什么相关，用户导入后与自己加的资料一样用）；Claude 项目没有专门按钮，靠开线程去查、产出进 Library。

## 一句话

学习者要资料时，主对话开一个找资料对话：联网搜，列出候选、各写为什么选，学习者勾了才存进本项目资料。

## 何时开 · 开场给什么

| 项 | 内容 |
| --- | --- |
| 何时开 | 学习者在主对话说要找资料（“帮我找讲 SVD 的好资料”）；导航需要资料补全时不自己开，经主对话提议 |
| 开场给什么 | 学习者那句话、方向说明（`../记录/方向目标.md`）、项目说明（`../记录/项目说明.md`）、本项目已有资料清单 |
| 模型与强度 | 按会话类单独配（`../01-流程.md` §2） |

## 能读什么 / 工具

| 项 | 内容 |
| --- | --- |
| 联网 | 搜索与抓网页 |
| 读 | 上表开场给的；本项目资料的目录（判断已有、避免重复） |
| 交回 | 候选清单：每份 = 标题、网址或来源、为什么选（对着方向说明说）、是否已在本项目、至多 10 份 |

## 交回之后

| 步 | 谁 | 内容 |
| --- | --- | --- |
| 1 | 界面 | 候选清单给学习者勾；可全选、可一份不要 |
| 2 | 程序 | 勾中的按资料入口处理（抓快照转 md、记网址与抓取日期，标“联网查来”，`../记录/资料.md`「入口」）|
| 3 | 主对话 | 说一句存了几份 |

## 边界

| 不做 | 说明 |
| --- | --- |
| 不自动存 | 没勾的不进资料 |
| 不写总结冒充资料 | 模型写的调研说明留在这个对话里；进资料的只有原文快照 |
| 不定学什么 | 归导航 |
