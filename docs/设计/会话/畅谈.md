## 一句话

在主对话下开的任务对话：跟学习者谈出方向目标（终点：目标能力及理由），交回项目。它是会话的一种组合用法，不是另立的一块；产出有主（D-09）。

## 何时开 · 开场给什么

| 项 | 内容 |
| --- | --- |
| 何时开 | 主对话判为新方向时，在那条消息下开（`主对话.md`）；方向目标要再谈再改时同样经此 |
| 开场给什么 | 学习者那条消息；已有方向目标（有才放，`../记录/方向目标.md`） |
| 模型与强度 | 默认高强度；配置规则见 `../01-流程.md` §2 |

## 能读什么 · 工具

| 项 | 内容 |
| --- | --- |
| 学过的记录 | 看学习者已储备什么，据此定目标（`../记录/学过的记录.md`） |
| 外部搜索 | 模型辅助补目标细节与调研；搜索是 harness 工具（D-06、D-13） |
| 其余 | 按 `../记录/读写权限.md` |

## 交回什么

| 交回 | 去哪 |
| --- | --- |
| 方向目标（目标能力及理由） | 存为项目的方向目标；内容、谁读、怎么改以 `../记录/方向目标.md` 为准 |
| 谈话中得知的、学习者在系统之外学到的知识 | 学过的记录里的外部导入，标“未验证”（`../记录/学过的记录.md`） |

- 交回格式：待定（D-10 暂缓）；原 D-10 里“锚定通用知识结构”那半随通用知识结构取消作废。

## 冷启动

| 情形 | 做法 |
| --- | --- |
| 没有方向目标、学过的记录空 | 用默认先验（高中以上、脱离应试）出临时方向目标，标“临时”，随学习推进替换（D-12） |
| 目标一时说不细 | 允许粗目标，逐步补齐（D-16） |

## 边界

| 不做 | 归谁 |
| --- | --- |
| 定路线、排先后 | 导航；畅谈给的顺序只作参考，导航可按学过的记录调整（`导航.md`） |
| 开单子、开学习对话 | 导航出选择卡、学习者选定后由程序开 |
| 判学习者的水平、贴标签 | 不做（`../00-定位与原则.md` §9）；外部导入只作未验证的起点线索 |
