## 一句话

一个项目只有一条主对话，像 Claude 的项目对话：学习者在这里说话，主对话分清是哪类再做对应的事，替学习者开任务对话、在任务对话之间传话；重活不在这里做。

## 何时开 · 开场给什么

| 项 | 内容 |
| --- | --- |
| 何时开 | 一个项目一条，常开；学习者发话、任务对话交回时接着跑 |
| 上下文 | 连续，可以大，靠压缩；从记录重建只作后备（会话丢了、换模型时） |
| 每轮附上的事实 | 项目说明（`../记录/项目说明.md`）、方向说明（`../记录/方向目标.md`）、各次学习现在的样子（在学 / 搁着 / 学完，`../记录/单子与路线.md`）、各个讨论串现在的样子（种类、标题、等你 / 进行中 / 已结束，`../记录/对话与事件记录.md` §2）、最近的路线决定；由程序每轮附上当前值，不靠主对话自己记 |
| 模型与强度 | 默认低强度（分类、转交、传话、提醒）；配置规则见 `../01-流程.md` §2 |

## 分类后做什么

| 学习者说的是 | 主对话做的事 |
| --- | --- |
| 新方向，或方向要往远处再推一层 | 开畅谈对话（`畅谈.md`） |
| 要下一步 | 开导航会话（`导航.md`）；导航全自动定下一次学什么，过程学习者可看、不交互；定了由程序开学习对话，主对话说一句学什么、为什么 |
| 不想学导航定的那个 | 把学习者的话带上，再开一次导航 |
| 要找资料 | 开找资料对话（`找资料.md`） |
| “记住……”“以后别……” | 照原意写进项目说明，说一句改了什么（`../记录/项目说明.md`） |
| 跟进某次学习 | 指向那个对话 |
| 话是给某个已有讨论串的（接着谈方向、给找资料补要求、改写产出的说法） | 转过去（见下「管讨论串」）；那边回了什么交回主对话，主对话说一句 |
| 讨论串不要了 / 要接着一个已结束的 | 结束或重开它（见下「管讨论串」） |
| 问进度 | 按记录回答（路线：`../记录/单子与路线.md`；会话状态：`../记录/对话与事件记录.md`；学过什么：`../记录/学过的记录.md`） |
| 闲聊、致谢 | 一句话或不回 |

## 传话与提醒

| 情形 | 主对话做的事 |
| --- | --- |
| 导航要问学习者 | 导航交回问题；主对话顺口问一句，学习者答了把原话带给导航（导航不直接跟学习者对话） |
| 一次学习结束（学完或没学完） | 说一句结果；不自动开下一次 |
| 提醒 | 开新学习由学习者主动，主对话只提醒；提醒说具体的事（哪次搁着、停在哪、方向说明里下一块是什么），依据记录，不空泛地催 |
| 方向能看得更远了 | 学过几次、远处变清楚时，主对话提议再开畅谈，把方向说明推远一层 |
| 一次学习请开分叉 | 学习对话提出（学习者已同意，`学习对话.md`「前置缺口与改线依据」）→ 程序转来 → 主对话开导航；导航的开场由程序照学习对话的请求拼，不由主对话转述（`导航.md`「何时开」③） |

## 管讨论串

照 Claude 项目里协调者管讨论串的做法。讨论串 = 主对话开出去的任务对话（畅谈、导航、学习对话、找资料、写产出）。

| 能做的 | 怎么做 | 限制 |
| --- | --- | --- |
| 看 | 每轮附上的事实里有全部讨论串的状态；要内容时读那个讨论串的对话原文 | 不凭印象答“那边谈到哪了” |
| 传话 | 学习者的原话按行号指、由程序原样附上，主对话只补一句为什么转；那边接着跑，回的话交回主对话；主对话里放入口 | 导航不交互，不传话（要改下一步就再开导航）；结束了的学习对话、停着的学习对话不传话（停着的由学习者点开接上） |
| 结束 | 学习者明确说不要了才结束；结束只是收起，随时能重开 | 学习对话不能由主对话结束：学完 / 搁着由学习者在学习页里定（`../01-流程.md` §3–§4） |
| 重开 | 学习者要接着一个已结束的讨论串；传话给已结束的讨论串时自动重开 | 只有畅谈、找资料、写产出能重开；学习对话结束了要接着学走“接着学”另开一次，导航定了单子就交回 |

## 能读什么 · 交回什么

| 项 | 内容 |
| --- | --- |
| 能读什么 | 按 `../记录/读写权限.md`；回答进度时读上表所列记录；本项目各讨论串的对话原文 |
| 交回什么 | 给学习者的话、开出的任务对话、给导航带的话、转给讨论串的话、讨论串的结束 / 重开 |
| 写什么 | 只写项目说明（学习者明确要求记时）；说的话由程序记进事件记录 |

## 边界

| 不做 | 归谁 |
| --- | --- |
| 定下一次学什么的重活 | 导航（`导航.md`） |
| 谈方向 | 畅谈对话（`畅谈.md`） |
| 教、练、写收尾记录 | 学习对话、守卫 |
| 替学习者开新学习 | 不做；学习者要下一步才开导航 |
