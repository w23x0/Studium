# 页面编辑员

> 状态：已决（2026-10-26）。来历查 `../../../定稿记录.md`。活页面的定义与退回见 `学习对话.md` §11，本页不复述。

学习对话沙盒里一个专管活页面的子代理：主对话说改什么，它决定怎么写代码。目的是让写代码的细节不进学习对话的上下文，主对话只拿它判断要用的最少信息。

## 何时开、活多久

| 项 | 内容 |
| --- | --- |
| 何时开 | 学习对话第一次要改页面时开，一次学习一个 |
| 活多久 | 跟这次学习同在：做完一件不销毁，保留自己的上下文（记得页面的代码），下次叫它时接着做；学习结束随之结束 |
| 模型 | 单独配；主对话用 Opus 时，编辑员用 Opus 或 Sonnet，可选更快的模型 |

## 交接（主对话 → 编辑员）

| 项 | 内容 |
| --- | --- |
| 改什么 | 用教学的话说：展开哪块、折起哪块、标出什么、换一种画法，以及改完应该看到什么 |
| 留多大余地 | 每次写明这次的问题有多开放，例如“只把第 3 步展开”或“把这个概念换一种画法”，编辑员据此决定自己能动多少 |
| 页面版本 | 主对话依据的页面版本号；对不上的改动拒绝 |

## 交回（编辑员 → 主对话）

| 项 | 内容 |
| --- | --- |
| 交回什么 | 一句结果：成了，或哪里报错；以及改后学习者看得到哪几块。经收件箱以事实追加，不回头改主对话前面的内容 |
| 不交回 | 代码、调用日志、改动过程；这些由程序记进事件记录，留给界面与审计 |
| 改坏了 | 改动先在隔离区里做，框架检查通过才上页面；出错在编辑员这边改掉，学习者看不到半坏的页面 |

## 边界

| 项 | 内容 |
| --- | --- |
| 不做教学判断 | 露什么、露多少由主对话定；编辑员只决定怎么写 |
| 读写 | 只读写页面；范围以 `../记录/读写权限.md` 为准 |
| 代码跑在哪 | 模型写的代码在学习者浏览器的沙盒里跑，不联网，动作都经框架 |
| 退回 | 学习者退回时，编辑员的上下文与主对话一样从分叉点截掉、补一句教训（`学习对话.md` §11） |
