# 导航

> 状态：已决（标“待定”的条目除外）。
> 原来对应：原 M05（学习导航与计划）审查单；原 `03-运行设计.md`「M05」及路线规则、「闭环外：事件与清单」「缺料与冲突」M05 行；原 M08 审查单里仍成立的原则（先说后核、来源如实标、点按定义拆）；10-18 定稿第 2、3、4、7、8 条。原文在 `docs/撤下原文/模块时期/`；10-23 改为主对话开、全自动、不出选择卡，前写法见 `docs/撤下原文/主对话小与选择卡.md`。

导航负责一次学习（原称闭环）**之外**、多次学习之间的前方路线：下一次学什么、几次学习怎么衔接、沿哪条路走。它不管一次学习里怎么教（学习对话自己定，`../会话/学习对话.md`），不写收尾记录（`../会话/守卫.md`），不写学过的记录（`../记录/学过的记录.md`）。

## 何时开 · 会话形态

| 项 | 内容 |
| --- | --- |
| 何时开 | ① 学习者在主对话要下一步，主对话开（`主对话.md`）② 学习者不想学上次定的那个，主对话带上原话再开 ③ 学习中途要改线（要补前置、范围太大等）：学习对话在对话里跟学习者说清依据，学习者到主对话要下一步，同 ①；这次学习可先结束（没合上，导航会读完整对话），也可开着并行。程序不在学习进行中叫起导航；一次学习结束也不自动开：开新学习由学习者主动（10-23） |
| 不提前备好 | 用时才算，读当时最新的记录：多次学习并行、学习者在应用外也在学、会遗忘，每个时刻会的都不一样；学习者可以等（10-23） |
| 每次定几个 | 只定**下一次**；偏差判断在学习之外做（D-05） |
| 会话形态 | 主对话开的单独 agent 会话，全自动跑完：自己决定查什么、查几次，由 agent 定，不让学习者在选项里挑；过程学习者可看，不交互；只读沙盒，必要时联网调研 |
| 要问学习者 | 交回一个问题，由主对话顺口问、把原话带回，再接着定（`../会话/主对话.md`「传话与提醒」） |
| 模型 | 按会话类配置，默认高强度（10-08） |

| 期限 | 程序 |
| 触发原因与学习者的原话 | 程序 |

## 能读什么 · 工具

读写范围以读写权限（`../记录/读写权限.md`）为准。

| 项 | 内容 |
| --- | --- |
| 只读 | 学过的记录（上层与中层；底层经检索子代理）、本项目资料（`../记录/资料.md`）、状态记录（`../记录/状态记录.md`）、自己的路线决定与路线偏差记录、主对话原文；搁着的那几次的完整对话（10-18）；在学那几次里报出的改线依据（经检索子代理） |
| 外部搜索 | 可用（D-13） |
| 检索子代理 | 见下「检索子代理」 |
| 写 | 只交回单子、路线决定与理由（或一个要问学习者的问题），由程序存；不改别的记录 |

## 现场说出候选，当场对资料核

不存通用的点和子句；每次定下一步时现场推（10-18）。

| 步 | 做什么 |
| --- | --- |
| 1 读 | 方向目标、学过的记录（从上层读起）、资料（主资料定范围，`../记录/资料.md`） |
| 2 说出候选 | 模型凭自身知识现场说出候选：新点 + 子句（会了这几个出发点就能学会这个新点、预期学出什么理解） |
| 3 对资料核 | 当场对资料核：有支撑的指回原文位置；资料里没有的如实标“模型补的”，模型记忆不得伪装成原文；**找它漏掉的路线**：资料里有、候选没说到的补进来（审核到什么程度待看实际错误率再定，原 B6） |
| 4 现场判断 | 下列一律用时由模型判断、不存：知识边缘（已会与未会的交界）、簇、某点是不是阈值概念（用于优先级与路线安排；学习者跨没跨过不在这里判）、混淆 / 对比 / 同级类比 |
| 5 定下来 | 见「交回什么」；定下的写进单子（`../记录/单子与路线.md`） |

| 原则 | 内容 |
| --- | --- |
| 点按定义拆 | 同一对象的不同定义 / 刻画、学习者可能只会其一的，算不同的点（`../00-定位与原则.md`） |
| 资料给的是标准，不是个性化 | 教材给的路线是标准；给这位学习者选哪条子句，按学过的记录判断 |
| 没有现成路线的资料 | 代码仓库等不带路线：从它的结构推要先会什么（入口在哪、模块之间谁依赖谁、文档引用了哪些论文），再对照学过的记录定下一步；推出的前置对照仓库依赖与引用核一遍；每次现场推、不存（`../记录/资料.md`） |
| 选有分量的 | 选对这位学习者的水平与目标有分量的新点；已会的只作出发点，不再学一遍 |
| 顺序 | 参考主资料自带的顺序（教材有、仓库等没有）与畅谈给的顺序，可按学过的记录调整 |
| 出发点缺得多 | 先学出发点；不设考前置的环节（前置缺了在学习中发现） |
| 出发点来源 | 每个出发点注明来源：学过的记录 / 自述 / 假定 |
| 不另定深度 | 单个学习的目标 = 沿选中的子句把新点合上；要更深就另开一次走更抽象的子句（B11）；不写要点清单或证据条件 |
| 大小 | 一次坐下来能走完；上次拖长、没走完的，这次定得更小 |

## 检索子代理

导航需要上层答不了的细节时派出（10-18）。

| 项 | 内容 |
| --- | --- |
| 在哪跑 | 沙盒里，与导航隔离 |
| 怎么找 | 从上层（单子 + 守卫判定）出发、范围稍放宽，定位到底层的对话原文（`../记录/学过的记录.md` 分层） |
| 交回 | 只交回找到的几条，指回行号 |
| 隔离的用处 | 读的人可以多读，污染留在它自己的上下文里，导航只拿干净的结果 |
| 存不存 | 结果为这次决定服务，不另存成一层；要留就随路线决定的理由一起存（`../记录/单子与路线.md`） |

## 交回什么

不出选择卡、不让学习者在几个选项里挑：学习者挑的不一定对，下一步由导航定（10-23）。

| 项 | 内容 |
| --- | --- |
| 候选从哪来 | 学习对话里冒出的问题（事件记录）、搁着的那几次、导航现场说出的候选、现场判断的知识边缘上的点；比过之后定一个 |
| 几次学习的关系 | 不另立类型：相邻 = 经子句相连（一次的新点是另一次某条子句的出发点），无连接即独立；默认以相邻为主、同级类比少量 |
| 交回 | 一张单子 + 路线决定与理由（比过哪些、为什么是这个）→ 程序存单子与路线事实 → 开学习对话，单子进开场；主对话说一句学什么、为什么 |
| 或交回一个问题 | 缺一个只有学习者知道的事实时（如应用外最近学到哪），交回问题，经主对话问到再接着定 |
| 学习者不同意 | 学习者在主对话说不想学这个，主对话带上原话再开导航 |

## 路线规则

| 规则 | 内容 |
| --- | --- |
| 主干三项 | ① 核心任务与优先级：从方向目标反推当前注意力，区分核心目标、实现手段和非当前事项，在几个可选之间定先后 ② 下一次学习与路线动作：继续主线 / 补前置 / 开分叉 / 返回主线 / 搁置 ③ 分叉范围与返回条件：为补前置或旁支设定目标、范围、停止条件和返回主线条件 |
| 路线不存 | 路线 = 从起点（学过的记录）到终点（方向目标）的路径，导航现场推；只存决定与理由（10-18；D-17） |
| 理由必标行号 | 路线决定的理由必标 `文件:行号`，须可回查（`../记录/单子与路线.md`） |
| 按需激活 | 可带洞、可跳，不强制自下而上（D-02） |
| 中途改线 | 学习对话在对话里说明改线依据（缺前置、范围过大等），导航下次开时读到、决定是否改变几次学习之间的计划（「何时开」③）；导航选定新点与子句，学习对话与学习者定什么时候学完，两者不冲突 |
| 粗目标 | 允许粗目标，随学习推进逐步细化（D-16） |
| 资料缺段 | 路径不一定都在资料里：缺段可用外部搜索补（D-13），补来的经资料入库（`../记录/资料.md`）；没有资料支撑的路段标“未验证路段”（D-07、D-11） |
| 期限 | 期限是约束；下一次学什么由导航定，学习者不同意可在主对话说 |
| 跨学科 | 不设固定的项目或学科跨度；跨学科内容只要服务当前目标，也可进路线 |

## 冷启动

| 情形 | 做法 |
| --- | --- |
| 第一次学习 | 刻意选小：新点离已会的出发点近、内容量小，确保一次会话内完成，先让学习者拿到一次完整体验；之后按正常口径（代价：可能偏简单） |
| 学过的记录空 | 靠方向目标、畅谈导入与资料（主资料）起步，标“临时”，随学习推进替换 |
| 方向目标也没有 | 用默认先验（高中以上、脱离应试）出临时目标，标“临时”，随学习推进替换；方向在畅谈对话里谈（`../会话/畅谈.md`；D-12） |

## 跨领域：补习型 / 对比链接型

按学过的记录看学习者会不会对面的知识，分两种（P-02）：

| 型 | 何时 | 做法 |
| --- | --- | --- |
| 补习型 | 还没学过对面的知识 | 由原问题驱动的最小一次学习，只学到原学习需要的程度；最后一步回去解原问题，然后返回 |
| 对比链接型 | 已会 | 为加深理解对照两边结构，深度在结构 / 迁移级 |

两种都按学习者意愿开；动机取原问题，可按历史发生顺序讲（非灌输）；不限学科。

## 二级功能

建立在主干三项之上，可分别设计。

| 功能 | 内容 |
| --- | --- |
| 复习 | 按学过的记录、时间变化和当前目标，安排对已形成内容的巩固路线；固定复习天数不构成需求 |
| 复检 | 对过去作出的掌握结论安排重新验证，作为一次独立学习纳入路线；与复习目的不同；遗忘、降档不存成结论，用时比较带日期的判定，牵连不主动扩散、拿点当出发点前先看最新判定，均见 `../记录/学过的记录.md`「时间与版本」 |
| 补学 | 对尚未形成、当前缺失或被证明是前置缺口的内容安排补学，并处理它与原主线的返回关系 |
| 停车场与未完成负债 | 停车场里每条 = 没合上那次的上层（`../记录/单子与路线.md`）。可靠搁置 = 带具体恢复计划（何时、从哪接上），为未完成目标定下具体计划可消除它对注意的干扰（Masicampo & Baumeister 2011）；看缺在哪个出发点，决定接着学还是先补出发点；识别长期堆积并给出收束或降载建议。学习中学习者学不动时怎么处理：待定 |
| 状态输入、负荷与限流 | 只读状态记录，据此调整跨次路线、并行量和当前任务暴露；不形成、保存或反向改状态。理论依据（蔡格尼克、期末综合征、三系统疲劳）不包装成精确或医学化判断；四象限只作任务状态 / 弱先验，不把人固定分类或直接决定掌握；负荷分数与预算阈值不继承旧公式。状态读数在什么证据强度与时效下才改变行动：待定 |
| 阶段进展与复盘 | 综合阶段目标、已完成 / 未满足内容和关键连接，形成阶段回看及下一阶段路线建议，不用单一分数代替证据 |
| 计划、日程与提醒 | 把路线中的学习、复习、复检和长期任务映射为日程、提醒或计划安排 |

**读状态的规矩**：

| 读数 | 做法 |
| --- | --- |
| 承载读数（当前负荷、可挂核心任务数、可承载连续时长、环境限制） | 直接用；承载条件以核心任务数量表达（同时不超过两个），不以时间表 |
| 解释候选 | 学习对话的裁决不留记录；导航要用时自己读对话原文、和知识证据一起掂量（`../记录/状态记录.md`「两型输出」） |
| 习惯低谷 | 低谷期内的持续性下降属预期内波动：不改道、不加量（改道会重置计时，使学习者到不了正反馈形成点） |
| 堆积型下滑 / 疲劳退化 | 前者限流与主动搁置；后者留出恢复期 |
| 阈值概念停滞 | 知识侧、学习内，在学习对话里调强度、路线不动，导航不参与；与习惯低谷不合并、不合成一个“学习压力”量 |
| 缺读数 | 按无状态约束降级 |

## 边界

| 和谁 | 分工 |
| --- | --- |
| 学习对话 | 学习对话在学习内分析学习者、自己定教法与强度、报改线依据；导航不讲解、不出题、不判掌握 |
| 守卫 | 导航选新点与子句；守卫收尾时对照这条子句写下学习者实际表现出的理解，不把关；导航定路线主要靠它 |
| 学过的记录 | 导航只读，计划不写回 |
| 状态记录 | 只读，不形成、不保存、不反向改 |
| 教法记录 | 教法记录不负责改线依据、跨次路线或分叉 |
| 资料 | 可用资料适用性信息，不拥有资料质量本体；资料质量评分不是必做能力 |
| 知识产出 | 导航管当前注意力和阶段计划，含长周期研究本身的阶段推进路线；知识产出只管产出物及其版本链（`../记录/知识产出.md`） |
| 界面 | 旧系统的右栏、工作台和固定页面不属于导航的职责定义 |
