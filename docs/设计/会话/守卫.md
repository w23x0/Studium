## 1 是什么

| 项 | 内容 |
| --- | --- |
| 一句话 | 收尾时另开的一个会话，写下学习者在这次学习里实际表现出的理解；不把关、不打回（10-23：判断学到没有已内化在学习对话里，由它与学习者定） |
| 为什么独立 | 让这份记录只按学习者实际说的、做的来写，不掺教的一方“我觉得他懂了”的看法：守卫与学习对话隔离，不读模型的分析（`../00-定位与原则.md` §5 第 4 项、§6 原则 5）。学习对话的分析不留记录后，这是这次学习唯一写下的“学到了什么”，导航定路线主要靠它 |
| Studium 自有 | 换一次学习之内的框架不换守卫 |
| 实现方式 | 收口时另开一次调用，与教学隔离；以后可给守卫叠 skill 补它不会判的地方；依据是结构推理“自己教、自己判”，**未经实测**，有证据再改（B4） |
| 不管什么 | 不判合没合上、不管教法；教法管不管用由后台整理事后读记录（`../会话/后台整理.md`） |

## 2 何时开 · 读什么 · 工具

| 项 | 内容 |
| --- | --- |
| 何时开 | 每次申请收口：学习对话执行沙盒里的“申请收口”命令，或学习者手动申请（“我觉得懂了”）；程序开守卫。收口流程全貌见 `../01-流程.md` |
| 开场给 | 事件记录里两类（带行号）：① 学习者看得到的（双方对话、模型拿给学习者看的结果）② 学习者自己做的（话、改的代码、运行结果）；由程序按“谁做的”标签过滤（`../记录/对话与事件记录.md`）。+ 单子（新点 + 选中的子句 + 路线动作，`../记录/单子与路线.md`） |
| 不给 | 模型的工作区与思考 |
| 工具 | 只读查询资料原文（`../记录/资料.md`）；不给写工具，判定由程序存 |
| 缺了不开 | 单子；事件记录里上面两类 |
| 模型 | 可单独配模型与思考强度，默认当下最强、高强度 |

## 3 怎么写

| 项 | 内容 |
| --- | --- |
| 对照什么 | 单子里选中的子句（出发点 + 预期理解）：写下新点经所选出发点接进学习者已有认识的实际情形，可与预期不同（`../00-定位与原则.md` §2“合上”）；不另判深度（B11） |
| 怎么读 | 模型读事件记录整体判断；不设条目清单、固定刻度或数学公式 |
| 什么算证据 | 只认学习者自己说的、做的；判断指回行号，引用的行须落在学习者的行上，由程序核对，指到模型讲解的行不算证据（`../00-定位与原则.md` §4、§6 原则 7） |
| 独立程度 | 独立完成、轻微提示、答案暴露后的正确回答不是同一种证据 |
| 作答完整度 | 一两句短答、只给结论的作答只算“这一点答对了”，不据此推断整件事已懂 |
| 讲过的内容 | 学习者跟着复述不算独立证据；须用**光靠复述做不到的方式**重新表现（换情境讲、预测结果、对比两种情况、找错、举反例、解释为什么不行等，可组合）才算 |
| 自述与假定 | 不是证据（含“我学会了”、出发点只来自自述 / 假定） |
| 不往上写 | 模型自信、学习者自述、画像、高频状态、策略偏好、历史个人记录、单次表现都不能单独写成“学到了” |
| 证据不足 | 如实写薄；导航读到后自己决定要不要安排复检 |

本节的证据标准只给守卫；学习对话只按合上的定义判断什么时候学完（`../会话/学习对话.md` §4）。

## 4 交回什么

| 项 | 内容 |
| --- | --- |
| 总述 | 这次实际学到了什么、哪里还薄，指回行号 |
| 学习者实际表现出的理解 | 判定顺带写下学习者在这次学习里实际表现出的理解，每条指回学习者的行；不另开会话写形成记录或分析层 |
| 证据强度 | 每条理解注明是独立完成、提示后完成还是答案暴露后，以及仅当场 / 含变式 / 含延迟；让日后分得清“当时就学得模糊”还是“后来遗忘”（原 M09「证据边与条件」、旧 M04 总体记录契约，10-18 起由守卫判定承担） |
| 写法 | 带来源与证据关系的逐条文字，每条带行号引用（C-02）；不用 JSON / 固定字段模板；“自由文本 + 引用”更合适仍是假设，未验证（B-04） |
| 之后 | 收尾记录经收件箱推回学习对话 → 学习者确认结束 → 程序存收口快照（`../记录/对话与事件记录.md`）→ 后续按 `../01-流程.md` |
| 唯一结论性产物 | 每次学习只有一份结论性产物：守卫判定；不在同一粒度上再出第二份说法。它是学过的记录里这次学习的中层（几百 token，`../00-定位与原则.md` §4、`../记录/学过的记录.md`） |
| 可追溯 | 记实际执行的模型与版本（`../00-定位与原则.md` §7 横切 3） |

## 5 边界

| 项 | 内容 |
| --- | --- |
| 不读分析 | 学习对话的分析留在它自己的上下文里，守卫不读（只约束守卫） |
| 没合上就结束 | 学习者要结束、没合上时不开守卫，走“结束这次学习（没合上）”清单（`../01-流程.md`）；学习者觉得其实学会了，走手动申请收口 |
| 可见与更正 | 判定、依据与不确定性对学习者可见（`../00-定位与原则.md` §7 横切 5）；后续证据和学习者异议可更正，更正怎么记见 `../记录/学过的记录.md` |
