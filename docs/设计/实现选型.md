## 选型

| 项 | 定了什么 | 一句话理由 |
| --- | --- | --- |
| 闭环内循环 | Claude Agent SDK（TypeScript），用产品负责人自己的 Claude 订阅登录；打开通用执行能力（脚本 / 命令），在沙盒里跑，往云沙盒方向走（沙盒边界：能读写哪些数据、能否联网，由程序写死）；自定义系统提示、`settingSources: []` 不读 CLAUDE.md 与设置；其他会话（守卫、导航、后台整理）的查询工具暂仍经进程内 MCP（`createSdkMcpServer`）挂上；第一版只接 Claude；订阅方式与沙盒是否仍成立，实现期待查。以后要按 API 计费、公开给别人用或接其他厂商时，按四个接口（`会话/学习对话.md`）换成 Anthropic 官方 SDK 的 Tool Runner 或别的框架 | 官方维护、不自写循环（`00` 原则 4）；个人自用可走订阅（官方：Pro / Max 额度按个人正常使用 Claude Code 与 Agent SDK 设定；禁止的是开发者让“他们的用户”用订阅登录）；上述选项官方文档都支持 |
| 语言 | 核心与界面都用 TypeScript；`书库处理/` 继续 Python，与核心只经文件交接 | 前后端共用类型；类型检查是代码全交 agent 写时最便宜的护栏 |
| 核心形态 | 常驻本地服务：HTTP 收命令、SSE 推事件，只绑本机地址 + 口令 | 界面关了后台会话照跑；以后换外壳核心不动 |
| 外壳 | 第一版在浏览器里打开本地页面，不打包；桌面外壳等打包时再选 | 改起来最快；换外壳不动核心与界面代码 |
| 界面 | React + Vite；shadcn/ui + assistant-ui；仿 Claude 桌面版的布局与交互逻辑，不照抄视觉风格，越简单越好；不手搓、不 fork 整套开源聊天应用。分两层：布局按学习者版设计，开发信息（学过的记录详情、教法、守卫判定、依据等）收进开发者面板，在设置里开关、默认关；左栏“删除”只从列表藏起来，数据不删 | agent 最熟；简单好迭代；不在给开发者看的布局上迭代 |
| 存储 | 每个会话一个 JSONL 正本，一个写者（闭环对话的事件记录含对话与沙盒动作，多来源，仍由程序一个写者写入），只追加、**永不改写**（格式升级只产出新文件或派生层，不自动清理）；SQLite 作派生层（索引、列表、检索），坏了从 JSONL 重建；PDF 与转换结果只存路径 + 内容哈希 | `文件:行号` 稳定（`00` 原则 8、`03`「上下文资产」） |
| 活页面存储 | 每个结构块按内容指纹存一份（同样内容只存一份），一版 = 一张块清单（第 N 版由哪些块组成）；看旧版就是读旧清单，两张清单一比就是改了哪几块。事件记录只记版本号与清单的引用，不放页面内容；存页面的目录不落在任何会被快照或监视的范围里；定期清掉没有清单引用的块，第一版留着；服务里只常驻当前版，旧版要用时从磁盘读 | 编程 agent 与 agent 文件系统（opencode、Claude Code、oh-my-pi、layerfs）出过的大事故都来自快照了自己的存储目录、事件里塞大块内容、没有回收，不是“整份存”本身；按块存正好对上“按结构块局部替换”（10-26，`../../会话记录/2026-10-26-活页面技术架构/README.md`） |
| 代码位置 | Studium 仓库内新开一个目录，与 `书库处理/` 并列：`原型/`（10-08 实现时定） | 不另开仓库 |

## 实现时要守的

| 规矩 | 原因 |
| --- | --- |
| Agent SDK 存的记录不是模型原样消息：事件记录由我们从它吐出的消息流里自己当场记（消息带原始 API 消息）；沙盒动作事件能否吐出：待查 | `03`「闭环对话」事件记录 |
| 实现期确认：收件箱中途推事实走流式输入（`priority`），能否发中途 `role:"system"` 消息、压缩方式会不会让思考块失效 | Agent SDK 自己管上下文，下一行的规矩由它守多少未核实 |
| 一个闭环对话里只追加：不重渲染系统提示、不删改旧消息、不改工具数组，没有例外；程序经收件箱推事实用中途 `role:"system"` 消息；教学工具不进工具数组（是沙盒里的可读资料），工具配置开场定好不改；太长用服务器端压缩 | 改前缀会让之前的思考块失效（报 400 或静默丢弃）；前缀不匹配时设为报错，不设静默丢弃 |
| 界面不靠工具调用之间的说明文字显示进度 | Sonnet / Opus 5.5 会把这段文字放进思考块，默认不返回 |
| 公式流式显示：没写完的公式先显示原文、写完再渲染；`\(\)` `\[\]` 归一成 `$` | 避免半截公式显示成错误 |

## 质量

产品负责人不读代码；界面由产品负责人自己看，不做截图检查。

| 做什么 | 说明 |
| --- | --- |
| 一条检查命令 | `tsc` 严格 + lint + 格式；CI 跑同一条；Claude Code hooks 进 git（改后格式化 / lint，结束前跑检查） |
| 改完用真模型跑一遍 | 改到哪段就实际跑哪段、自己看结果再交；不写自动测试、不用假模型（假模型只证明程序按剧本走） |
| 真实运行录带、离线回放 | 留着，查问题时用 |
| 独立审查子代理 | 新上下文、最好换模型、只报正确性与需求缺口 |
| 短 CLAUDE.md | 当地图 |

不做：自动测试与假模型、覆盖率门槛、截图检查、大而全的 CLAUDE.md、写代码的会话自评完成、审查意见条条照改。
