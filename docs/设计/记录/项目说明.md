# 项目说明

> 状态：已决（10-23）。来历查 `../../../定稿记录.md` 10-23。
> 参照：Claude 项目的 project instructions（每个新线程与项目对话都收到的一段固定说明）；只取这一项，不取它的自由记忆（理由见「不做」）。

## 一句话

学习者写给这个项目的固定说明：每个对话开场都带上的长期要求和条件，比如“我用 Linux”“代码在某仓库”“周末才有空”“讲题先让我自己想”。

## 谁产生 · 何时

| 项 | 内容 |
| --- | --- |
| 谁写 | 学习者：在项目页「记着什么」直接改；或在主对话说“记住……”“以后别……”，由主对话代写 |
| 主对话代写 | 只写学习者明确要求记的；写前不问，写后在对话里说一句改了什么，学习者可撤；随口说的、主对话自己推断的不写 |
| 何时 | 随时；改了从下一个开场起生效，已开着的对话不追改 |

## 内容

| 项 | 内容 |
| --- | --- |
| 形态 | 一段纯文字，学习者的原话或主对话照原意整理的句子；不分栏、不打标签 |
| 版本 | 每次改动存一版（谁改、何时、改前改后），只追加；界面显示当前版，可看历史 |
| 长度 | 设上限（实现期定，参照 Claude 16000 字），超了提示学习者删 |

## 谁读

| 会话 | 怎么用 |
| --- | --- |
| 主对话、畅谈、导航、找资料、学习对话 | 开场作为学习者的长期要求给；与本次学习者当场说的冲突时以当场说的为准 |
| 守卫、后台整理 | 不读：守卫只看学习者实际表现，后台整理不吸收学习者的自述要求（`读写权限.md`） |

## 与教学偏好

10-06 定的“学习者在对话里表达的教学偏好目前不考虑”（`教法记录与教学工具.md`）仍管对话里随口说的；**写进项目说明的算学习者明确的长期要求**，学习对话照读、自己决定怎么照顾，不改成程序开关。

## 不做

| 不做 | 理由 |
| --- | --- |
| 模型自己写的自由记忆（Claude 的 project memory） | “这个人走到哪了”已存成几种确定的记录（方向目标、学过的记录、单子与路线、状态记录）；再加一份模型随手记的会与它们打架。项目页「记着什么」只把这些记录摊开给学习者看，不对的提异议 |
| 把项目说明当学过的证据 | “我会微积分”写在这里不算学过；要算，走学过的记录的外部导入（`学过的记录.md`） |
