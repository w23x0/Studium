## 执行方式

| 会话 | 怎么卡 |
| --- | --- |
| 学习对话 | **沙盒**（10-16）：能读写哪些数据、能否联网由程序在执行环境里写死，不靠模型自觉；沙盒里只读放下表允许读的，可写只有模型工作区与学习者代码目录；联网另设 |
| 导航派出的检索子代理 | 进沙盒（10-18 第 8 条） |
| 其他会话（主对话、畅谈、守卫、导航、后台整理） | 暂仍按**给什么工具**（10-07）：每个只拿到写自己产出的工具，表外的记录不给查询工具 |
| 对话与事件记录 | 由程序追加，不做成模型工具；归属 / 位置类跨记录写入由程序统一落账 |

## 权限表

| 会话 / 执行者 | 可写 | 可读 |
| --- | --- | --- |
| 程序（不调模型） | 对话与事件记录（每个事件当场追加：学习者每句话、沙盒里的学习者动作、各会话产出、状态变化、选择卡上的选择与导航的路线决定、收口快照）；归属 / 位置链接；资料选取关系 | 全部，但只按项目 / 会话 / 时间定归属，**不读语义** |
| 主对话 | 无自己的记录区（说的话、贴的选择卡由程序记） | 方向目标、最近几条消息、路线记录（`记录/单子与路线.md`） |
| 畅谈 | 方向目标（`记录/方向目标.md`） | 学习者那条消息、已有方向目标 |
| 学习对话 | 模型工作区、学习者代码目录；诊断与分析随事件记录由程序存 | 本次单子（开场给）、资料原文、教材路线、学过的记录、状态记录、教法记录、教学工具 |
| 守卫 | 不给写工具，判定由程序存 | 事件记录里学习者看得到的（双方对话、模型拿给学习者看的结果）和学习者自己做的（话、改的代码、运行结果），由程序按“谁做的”标签过滤；本次单子；资料原文 |
| 导航 | 选择卡与路线决定候选（学习者选定后程序存成路线事实）；单子与路线里归导航写的部分 | 方向目标、学过的记录、学习者的资料（10-18 第 3 条）；没合上就结束那次的完整事件记录；自己的路线偏差记录；状态记录（解释候选只用已裁决的）；资料；外部搜索（D-13） |
| 导航的检索子代理 | 不写；只把找到的几条（指回行号）交回导航，结果不另存（10-18 第 8 条） | 学过的记录各层：从单子 + 守卫判定出发、范围稍放宽，定位到事件记录里的原文或分析 |
| 状态整理 | 状态记录两层 | 事件记录里与诊断不同的字段、会话事实、自己的底层记录、授权外部信息、重新确认请求（仅请求）；**不读**诊断与模型分析、守卫判定、学过的记录 |
| 教法记录整理 | 教法记录 | 事件记录（用了哪份教学工具、什么强度、之后的表现与诊断）、守卫判定、单子、状态记录、已有教法记录 |
| 知识产出 | 产出物与版本链 | 资料、对话与事件记录、学习对话的判断、路线、教法记录（原读范围照搬）；由哪个会话执行：待定 |

阈值概念跨次判断不单独成会话：用时经检索子代理读学过的记录，见 `会话/后台整理.md`。

学过的记录本身由几样组成（单子、守卫判定、事件记录、外部导入），各由上表对应的写入者产生；外部导入谁写见 `记录/学过的记录.md`。

## 红线

| 红线 | 含义 |
| --- | --- |
| 学过的记录 ↔ 状态记录 | 互不可读；“一次学习（原称闭环）结束时处于什么状态”经程序存的归属链接关联 |
| 状态记录 ✗ 知识结论 | 状态整理不读诊断、守卫判定、学过的记录；学习对话只能发“需要重新确认”的请求，不带结论 |
| 学习对话 ✗ 写状态记录 | 诊断只评估状态候选，不写状态记录 |
| 守卫 ✗ 模型一侧 | 不读模型的工作区、分析记录与思考（防自我确认）；引用的行须落在学习者的行上，程序核对 |
| 思考块只给学习对话自己 | 含思考块的原始消息原样存，只学习对话自己读；其他会话的工具查不到 |
| 工作笔记不带出 | 学习对话里未经守卫的推断（如“怀疑混淆了 A 与 B”）不作为下一次的开场事实带出，留在本次事件记录；带出去就绕开守卫，等于往下一次塞自评（待定：未经定稿） |
| 知识产出 ✗ 学过的记录 | 原：不直读，个人知识经诊断进入；学过的记录改为原始记录后怎么对应：待定 |
| 资料正文不被改写 | 别的会话只能提可复用、非个人的标签；正文与原始结构的修正回到入库（`记录/资料.md`） |

## 缺料与冲突

**规则**（A-03）：

| # | 规则 |
| --- | --- |
| 1 | 必需 / 条件：只有必需项缺了不开工；其余缺失一律降级 + 标注，不中止 |
| 2 | 必需项由程序查：开会话前程序查开场交付里的必需项，缺了不开；其余由会话自己查，查不到按下表标注 |
| 3 | 冲突听谁的：对话内现场证据优先于学过的记录；状态解释候选与知识解释竞争 → 学习对话里的诊断裁决 |
| 4 | 学习对话自己上一轮的诊断只作可推翻的工作判断，以现场证据为准 |

| 会话 | 缺了不开 | 缺了降级并标注 |
| --- | --- | --- |
| 学习对话 | 本次单子；学习者输入 | 路径位置 → “位置未知”；学过的记录 → “缺历史背景”；资料 → “缺资料依据”；状态记录 → “缺状态信息”，按无状态约束 |
| 守卫 | 本次单子；事件记录里学习者一侧 | — |
| 导航 | — | 方向目标无 → 粗目标先验起步；学过的记录空 → 冷启动默认先验（高中以上、脱离应试）起步；两者都标“临时”（D-12、D-16）；资料缺段 → 外部搜索补、入库，路线标“未验证路段”（D-07、D-11）；状态记录 → 按无约束；期限 / 选择 → 按无期限 |
| 状态整理 | 状态信号（上列字段、可观察事实）→ 不跑，标“未知” | 会话事实 → 不出“习惯低谷”；无底层记录 → 只出当前读数、不出趋势；现实约束 → “现实约束未知”；未授权外部信息 → 不接入 |
| 程序 | 从不因缺料不写 | 只登记“暂无产出”，不推断；只收事实，诊断 / 掌握 / 状态结论不收 |

| 情形 | 处理 |
| --- | --- |
| 上下文不完整 / 关键来源不可用 | 把限制写进产出，必要时只给“证据不足”，不伪装完整 |
| 模型或服务降级 | 能力等价才可降级且留痕可见；不等价应失败（`00-定位与原则.md`） |
| 证据不足 | 一次学习保持进行中、复检或搁置；不因模型自信 / 自述 / 画像 / 单次表现判合上 |
| 分叉中的表现 | 保留路径关系，不直接判为主线缺口 |
| 自述 vs 观察 | 并存标注，自述不覆盖可观察事实 |
| 跨资料冲突 | 并存，不强合并（D-03） |
| 生成题 | 不默认入库，来源标“生成”（D-008） |
| 一次学习长期不结束 | 程序照常记事实，路线问题归导航 |
| 声称超出学习范围（健康 / 心理疾病） | 不诊断，不据以行动 |
