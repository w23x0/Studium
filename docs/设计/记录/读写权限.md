## 执行方式

| 会话 | 怎么卡 |
| --- | --- |
| 学习对话 | **沙盒**（10-16）：能读写哪些数据、能否联网由程序在执行环境里写死，不靠模型自觉；沙盒里只读放下表允许读的，可写只有模型工作区与学习者代码目录；联网另设 |
| 导航派出的检索子代理 | 进沙盒（10-18 第 8 条） |
| 页面子代理 | 进学习对话的沙盒，只能写它做的组件；资料只读（10-26；10-27 加读资料） |
| 主对话读本机 | **只读沙盒**（11-02）：学习者家目录只读（挡掉存密钥的位置），读文件、搜索、列目录与命令行都在沙盒里，不能写本机、不联网；读到要用的经导入存副本（`资料.md`「入口」）。其余仍按给什么工具 |
| 其他会话（畅谈、导航、找资料、后台整理） | 暂仍按**给什么工具**（10-07）：每个只拿到写自己产出的工具，表外的记录不给查询工具 |
| 读资料的范围 | 所有会话读资料与外部导入都按归属：学习者级的全部 + 本项目的，由程序算（`资料.md`「存在一处、按归属读」）；下表“本项目资料”都按这条读 |
| 对话与事件记录 | 由程序追加，不做成模型工具；归属 / 位置类跨记录写入由程序统一落账 |

## 权限表

| 会话 / 执行者 | 可写 | 可读 |
| --- | --- | --- |

| 主对话 | 项目说明（学习者明确要求记时，`../记录/项目说明.md`）；按学习者给的路径发起导入（副本由程序存）；其余无自己的记录区（说的话由程序记） | 自己的连续上下文；本机家目录（只读，见「执行方式」）；项目说明；方向说明、各次学习现在的样子、路线记录（`../记录/单子与路线.md`）；各讨论串的状态与对话原文（`../会话/主对话.md`「管讨论串」） |
| 畅谈 | 方向目标（`../记录/方向目标.md`） | 学习者那条消息、已有方向目标；项目说明；再开时学过的记录的上层；外部搜索（`../会话/畅谈.md`） |
| 学习对话 | 模型工作区（草稿，写入随事件记录由程序存）、学习者代码目录；收尾那一句（随“申请收口”交程序存，`../会话/学习对话.md` §8） | 本次单子（开场给）、本项目资料原文、学过的记录、状态记录、教法记录、教学工具 |
| 页面子代理 | 它做的组件（改动先在隔离区，框架检查通过才上页面；改动由程序记进事件记录） | 它做的组件当前版、学习对话交给它的交代、学习者对这些组件的操作；本项目资料原文（只读）；学习位置依据（单子与学过的记录里的点、此刻在哪、哪些已合上），只在交代要画位置图时给；不读学习对话的上下文与其他记录 |
| 导航 | 单子与路线决定候选（程序存成路线事实）；单子与路线里归导航写的部分 | 方向说明、学过的记录（含外部导入）；主对话原文；搁着那几次的完整事件记录；自己的路线偏差记录；状态记录（解释候选用时自己掂量）；资料；外部搜索（D-13）；在学那几次报出的改线依据（经检索子代理） |
| 找资料 | 不写；候选交回，学习者勾中的由程序按资料入口存（`../会话/找资料.md`） | 学习者那句话、方向说明、项目说明、本项目资料目录；外部搜索 |
| 导航的检索子代理 | 不写；只把找到的几条（指回行号）交回导航，结果不另存（10-18 第 8 条） | 学过的记录各层：从单子 + 收尾那一句出发、范围稍放宽，定位到事件记录里的原文 |
| 状态整理 | 状态记录两层 | 事件记录里与知识判断不同的字段、会话事实、自己的底层记录、授权外部信息、重新确认请求（仅请求）；**不读**学过的记录（含收尾那一句） |

## 红线

| 红线 | 含义 |
| --- | --- |
| 学过的记录 ↔ 状态记录 | 互不可读；“一次学习（原称闭环）结束时处于什么状态”经程序存的归属链接关联 |
| 状态记录 ✗ 知识结论 | 状态整理不读诊断、学过的记录（含收尾那一句）；学习对话只能发“需要重新确认”的请求，不带结论 |
| 学习对话 ✗ 写状态记录 | 诊断只评估状态候选，不写状态记录 |
| 读原文只认学习者的行 | 读以往学习的原文判断学习者会什么时，模型的讲解、工作区与思考都不算证据，引用的行由程序核对（`../记录/学过的记录.md`「读原文时什么算证据」） |
| 思考块只给学习对话自己 | 含思考块的原始消息原样存，只学习对话自己读；其他会话的工具查不到 |
| 工作笔记不带出 | 学习对话里的推断不作为下一次的开场事实带出（收尾那一句只作指针），留在本次事件记录（理由见 `../会话/学习对话.md` §8 末行）（待定：未经定稿） |
| 知识产出 ✗ 学过的记录 | 原：不直读，个人知识经诊断进入；学过的记录改为原始记录后怎么对应：待定 |
| 资料正文不被改写 | 别的会话只能提可复用、非个人的标签；正文与原始结构的修正回到入库（`../记录/资料.md`） |

## 缺料与冲突

**规则**（A-03）：

| # | 规则 |
| --- | --- |
| 1 | 必需 / 条件：只有必需项缺了不开工；其余缺失一律降级 + 标注，不中止 |
| 2 | 必需项由程序查：开会话前程序查开场交付里的必需项，缺了不开；其余由会话自己查，查不到按下表标注 |
| 3 | 冲突听谁的：对话内现场证据优先于学过的记录；状态解释候选与知识解释竞争 → 学习对话里的诊断裁决 |
| 4 | 学习对话自己先前的分析只作可推翻的工作判断，以现场证据为准 |

| 会话 | 缺了不开 | 缺了降级并标注 |
| --- | --- | --- |
| 学习对话 | 本次单子；学习者输入 | 路径位置 → “位置未知”；学过的记录 → “缺历史背景”；资料 → “缺资料依据”；状态记录 → “缺状态信息”，按无状态约束 |
| 导航 | — | 学过的记录空 → 靠方向目标、外部导入与资料起步；方向目标也没有 → 默认先验（高中以上、脱离应试）出临时目标；都标“临时”（`../会话/导航.md`「冷启动」；D-12、D-16）；资料缺段 → 外部搜索补、入库，路线标“未验证路段”（D-07、D-11）；状态记录 → 按无约束；期限 → 按无期限 |
| 状态整理 | 状态信号（上列字段、可观察事实）→ 不跑，标“未知” | 会话事实 → 不出“习惯低谷”；无底层记录 → 只出当前读数、不出趋势；现实约束 → “现实约束未知”；未授权外部信息 → 不接入 |
| 程序 | 从不因缺料不写 | 只登记“暂无产出”，不推断；只收事实，诊断 / 掌握 / 状态结论不收 |

| 情形 | 处理 |
| --- | --- |
| 上下文不完整 / 关键来源不可用 | 把限制写进产出，必要时只给“证据不足”，不伪装完整 |
| 模型或服务降级 | 能力等价才可降级且留痕可见；不等价应失败（`../00-定位与原则.md`） |
| 证据不足 | 一次学习保持进行中、复检或搁置；不因模型自信 / 自述 / 画像 / 单次表现判合上 |
| 分叉中的表现 | 保留路径关系，不直接判为主线缺口 |
| 自述 vs 观察 | 并存标注，自述不覆盖可观察事实 |
| 跨资料冲突 | 并存，不强合并（D-03） |
| 生成题 | 不默认入库，来源标“生成”（D-008） |
| 一次学习长期不结束 | 程序照常记事实，路线问题归导航 |
| 声称超出学习范围（健康 / 心理疾病） | 不诊断，不据以行动 |
