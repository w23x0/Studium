## 1 是什么

| 项 | 内容 |
| --- | --- |
| 一句话 | 程序维护的容器（项目 / 会话 / 轮次）和每个会话里只追加的事件记录；它就是会话日志，各会话的开场交付、查询都从这里取 |
| 谁写 | 程序，在每个事件后当场写；不调模型、不读语义，只按项目 / 会话 / 时间给事件定归属；对话记录由程序追加，不做成模型工具 |
| 在哪一层 | 分层里的下层（几千到几万 token，`../00-定位与原则.md` §4）：学习对话的对话原文在这里 |
| 不做什么 | 不决定路线、会话数量、一次学习的粒度、教学方式；不判断掌握、不关闭会话；不是模型上下文编排器 |

## 2 容器

| 项 | 内容 |
| --- | --- |
| 容器树 | 项目 → 主对话 + 任务对话（畅谈；学习对话 = 一次学习）→ 轮次（交互形状见 `../01-流程.md`） |
| 项目 | 一个项目 = 一个方向目标（`../记录/方向目标.md`）；存项目的资料清单（资料归项目，`../记录/资料.md`）、项目下的会话与各次学习。目标、期限、整体状态可以记，不强制学习者填 |
| 会话 | 一次学习一个学习对话，按一次学习划分、不按访问时长切；可跨天，可暂停、继续、搁置、结束；同时存在多少未完成会话不限，不要求只有一个当前焦点 |
| 会话关系 | 来源、父子、主从、返回等关系及其产生时的位置；分叉 = 另开一个学习对话，返回条件由导航定、这里存（`../会话/导航.md`）；分叉会打断缓存前缀。关系的产生条件与后续安排不由这里定 |
| 状态与时间 | 开始、进行、暂停、搁置、复检、完成等由外部决定的状态和时间；不解释“受阻”、不判断完成 |
| 一直没合上的 | 照常记事实（停在未完成）；“好几次学习都结束不了”属路线问题，归导航的并行量与限流 |

- 候选：项目模板与强制计划字段。考试、课程、研究等项目形态可作候选（长期研究项目形态也落在这里）；不把目标、期限、验收或固定阶段设为所有项目的必填。

## 3 事件记录：记什么、何时记

全程只追加，**当场记**；每条标明**学习者 / 模型 / 程序**，并标种类（对话、沙盒动作、推来的事实等）。

| 事件 | 谁 | 说明 |
| --- | --- | --- |
| 学习者每句话 | 学习者 | 含转写文本（标来源）与原件 |
| 沙盒里的学习者动作 | 学习者 | 改的代码、运行结果等；摄像头、平板手写等多模态以后接 |
| 学习者在页面上的真操作 | 学习者（程序记） | 填答案、拖滑块等观测得到的操作，带时间；与说的话同一身份（`../会话/学习对话.md` §11） |
| 给学习者的话、拿给学习者看的结果 | 模型 | 守卫读得到 |
| 模型工作区的写入 | 模型 | 守卫读不到；模型的分析不另记（留在它自己的上下文里） |
| 读了哪份教学工具、每轮强度 | 程序 | 当场记，不靠模型自报（`../会话/学习对话.md` §7） |
| 活页面的改动 | 子代理（程序记） | 每个版本的改动；守卫读得到改后学习者看到的页面（`../会话/学习对话.md` §11） |
| 收件箱推来的事实 | 程序 | 守卫判定等程序确知、不属于学习者的东西；也印行号（学习者的话与页面上的真操作标学习者） |
| 每个会话的产出 | 各会话 | 存产出的位置与产出者；内容归各自的记录页 |
| 状态变化 | 程序 | 开始 / 暂停 / 搁置 / 结束 |
| 导航定的单子 | 导航（程序存） | 导航的路线决定与理由存在 `../记录/单子与路线.md` |
| 收口快照 | 程序 | 见 §6 |

**谁做的标签有什么用**：守卫只拿“学习者看得到的”和“学习者自己做的”两类，由程序按标签过滤（`../会话/守卫.md`）；程序核对守卫引用的行是否落在学习者的行上。

## 4 原始消息与思考块

| 项 | 内容 |
| --- | --- |
| 存 | 学习对话的原始消息逐条原样另存，含思考块 |
| 谁读 | **只有学习对话自己**；守卫按标签过滤读不到；其他会话的工具查不到 |
| 别的会话的思考 | 不当记录；要不要借鉴另行调研（`../待确认项.md` A-07） |

## 5 行号即引用地址

| 项 | 内容 |
| --- | --- |
| 为什么稳定 | 只追加、永不改写，行号不变，可机械核对（A-06、B-01） |
| 怎么用 | 程序交给模型时每行前印行号（含中途推来的消息）；模型只抄行号 / 范围，原话由程序按行号取出，给守卫核对、给界面跳转高亮；截图单独占一行；规则全文见 `../00-定位与原则.md` §4 |
| 往下读 | 上层记录（单子、守卫判定、路线决定理由）指回这里的行号；读的人从上往下、按行号读到原文（导航的检索子代理见 `../会话/导航.md`） |
| 选取靠结构寻址 | 产出者 + 位置（会话 / 分叉 / 轮次 / 行号）+ 时间；不打语义标签（B-02） |
| 资料用锚点 | 资料会被修订，用锚点定位、不用行号，两者不混用（`../记录/资料.md`） |
| 存储形态 | 每个会话一个只追加的正本，派生索引可从它重建（`../实现选型.md`；物理载体与版本契约实现期定，`../待确认项.md` D-006） |

## 6 收口快照

一次学习结束时程序存盘，不调模型；**不另写总结**（B5）：下面几样就是全部材料，读的人各取所需，多一份总结就多一个二手版本。

| 怎么结束 | 快照组成 |
| --- | --- |
| 合上（守卫写好收尾记录、学习者确认） | 事件记录 + 单子 + 守卫判定 + 学习者确认 |
| 没合上就结束（“结束这次学习（没合上）”） | 事件记录 + 学习者要结束的话，状态记“没合上就结束”；不开守卫。导航之后的路线决定和理由存在 `../记录/单子与路线.md` |

这几样怎么组成这次学习在学过的记录里的那一份，见 `../记录/学过的记录.md`；结束之后的清单见 `../01-流程.md`。

## 7 跨天续接

| 项 | 内容 |
| --- | --- |
| 原样重放 | 跨天回来时学习对话的上下文原样重放；缓存过期只多付一次缓存写入 |
| 离开多久 | 不单独推；每条带时间，模型自己看得出并据此回应（`../会话/学习对话.md` §3） |

## 8 只存事实，不存解释

| 项 | 内容 |
| --- | --- |
| 规则 | 存“各次会话的启动间隔”“某次会话中断的时间点”，不存“启动困难”“注意力涣散” |
| 解释从哪来 | 每次由读的一方从记录重新导出（如状态记录的整理，`../记录/状态记录.md`），不在这里沉淀成长期结论；不建长期状态结论存储，那是人格标签的入口 |
| 代价 | 导出的解释不可复现；只承诺“依据可核对”（`../00-定位与原则.md` §7 横切 4） |
| 缺料 | 从不因缺料不写：缺什么只登记“暂无产出”，不推断；诊断、掌握、状态结论不收 |

## 9 归属链接

| 项 | 内容 |
| --- | --- |
| 产出归属 | 各会话产出的位置与产出者；归属 / 位置类跨记录的写入在这里统一落账 |
| 学过的记录 ↔ 状态记录 | 两者互不可读，“某次学习结束时学习者处于什么状态”只经这里的链接获得：这里知道这次学习属于哪些会话、对应哪些状态记录；只存位置 |
| 不混存 | 资料、状态记录、教法记录、路线决定各有自己的页，不混存进事件记录；格式、迁移、一致性由 Studium 自己定 |

## 10 边界

| 项 | 内容 |
| --- | --- |
| 与知识产出 | 只存产出物的项目归属和相关过程记录，不存产出物内容或版本（`../记录/知识产出.md`）；产出物能否脱离项目独立存在：待定 |
| 与过程审查 | 面向项目和会话的产品记录；跨会话技术日志、审查链、权限与数据治理不归这里，不扩展成通用日志基础设施（`../待确认项.md` D-005，暂缓） |
| 读权限 | 谁能读哪部分以 `../记录/读写权限.md` 为准 |
| 历史形态不构成约束 | 五层架构、固定三栏界面、固定会话数量、按访问时长切会话、thread / branch / turn 等旧命名 |
