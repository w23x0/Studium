# 状态记录

> 状态：已决（定义、边界、两层存放、两型输出、阶段类型）；标“待定”的除外。
> 原来对应：原 M15（`docs/撤下原文/模块时期/模块需求设计/模块审查单/M15-学习者状态与条件.md`）；`docs/撤下原文/模块时期/Harness设计/03-运行设计.md`「M15」；总览 M15 节。
> 本页管存什么、谁读、不能推什么；何时整理、怎么整理见后台整理（`../会话/后台整理.md`）；谁能读写见 `../记录/读写权限.md`。

“状态” = 学习过程中会变化、有时间范围、来源和不确定性的**非知识**状态与现实条件；不指心理疾病、人格或固定能力画像。

## 回答什么

| 项 | 内容 |
| --- | --- |
| 回答 | 学习者现在以什么状态学习、当前能承载哪些条件、哪些现实限制可能影响表现 |
| 不回答 | 学会了什么（学过的记录，`../记录/学过的记录.md`）· 接下来学什么（导航，`../会话/导航.md`）· 当前怎么教（学习对话，`../会话/学习对话.md`） |
| 用途 | 学习对话定本次强度、导航排路线承载读同一份有来源、带时效的信息；并为学习对话里的诊断提供可裁决的替代解释 |
| 一条状态判断至少说明 | 来自哪里 · 适用时间范围 · 事实还是推断 · 学习者是否确认 · 还有什么不确定 |
| 不是 | 包罗万象的“学习者画像”；不是原始日志库（原始事实在对话与事件记录，`../记录/对话与事件记录.md`） |

候选范围按四类理解，不锁死为字段或固定量表：

| 类别 | 可能内容 | 主要使用者 | 分级 |
| --- | --- | --- | --- |
| 认知与资源条件 | 当前负荷、疲劳、注意力波动、任务切换、未完成事项压力、近期正反馈稀缺度 | 导航、学习对话 | 主线：触发量全部来自事件记录里的过程事实，证据成本最低 |
| 情绪与评价条件 | 压力、焦虑、挫败、对考核或错误的威胁感 | 学习对话、导航 | 保留：降低获取标准而非降低优先级——只记可观察行为与紧邻前序事件，不记情绪名词 |
| 行动与持续条件 | 触发失效（难以开启）、行动失效（启动后维持不到正反馈）、奖励失效（完成了但无正反馈） | 导航、学习对话 | 部分可交付：触发失效看会话启动间隔与计划-实际差；行动失效需时长数据，等时间监控 |
| 现实约束 | 可用时间上限、环境干扰 | 导航、学习对话 | 预留：独立输入通道，本轮不设计形态；期限属项目属性，不归这里，导航使用 |

不放这里：教学偏好（对话里随口说的暂缓，`docs/暂缓设计/M10-学习者教学偏好.md`；写进项目说明的见 `项目说明.md`）、长期风格、模型配置、已形成的个人知识（学过的记录）。

**情绪与评价条件归这里，不并进诊断**：提取发生在对话上，与学习对话的诊断读同一份事件记录、输出契约各自独立；共用输入不构成所有权。提取只标“学习者出现了关于自身状态的表述”、原话行号与紧邻前序事件；情绪命名、来源分层、时效判断在整理时做。

**为什么单独一类记录**：对象（变化的状态与条件，而非知识形成）和生命周期（来源、时效、趋势、不确定性）都独立；导航、学习对话用它，诊断裁决它，三者的决定不同，放进任何一方都职责倒置，放进诊断还会消灭替代解释的独立来源；把高频状态并进学过的记录会恢复大画像的混合边界。独立不等于拥有全部学习者数据：项目、会话归属与过程事实仍在对话与事件记录。

## 两层存放

它是**存放处**：谁要谁查（当前的、近期的都查得到），后台自己整理；不按事件把结果推给谁（10-07）。

| 层 | 内容 | 改法 |
| --- | --- | --- |
| 底层：状态记录 | 每条一句话 + 来源（自述 / 观察 / 推断）+ 时间范围 + 指回事件记录行号；原话与时间戳在事件记录，不另抄 | 只追加；权威 |
| 上层：“当前状态”页 | 现在仍有效的几条 + 阶段判断及所依据的时间跨度；每条标承载读数还是解释候选 | 派生视图，可随时从底层整个重算，算错不丢东西 |

| 项 | 规则 |
| --- | --- |
| 时效归读侧 | 只标产出时间；还能不能用由读的一方判（原 03「横切：上下文资产」新鲜度规则） |
| 引用 | 输出必标来源分层 + 产出时间 + 行号（C-02） |
| 怎么整理 | 过期、阶段判断、并存标注、重算，只动上层；见 `../会话/后台整理.md` |

## 功能

| 功能 | 结论 | 级别 |
| --- | --- | --- |
| 状态与条件形成 | 从自述、可观察事实和授权信息形成有来源、带时效和不确定性的描述；不把缺证据的心理原因写成事实 | 主干 |
| 来源与证据分层 | 区分直接观察的事实、学习者自述、系统暂定判断、已确认状态、未确认替代解释；不把行为线索直接命名为心理状态 | 主干 |
| 时间有效性与变化 | 区分当前会话、近期阶段、相对稳定的现实约束；短时疲劳不默认成长期特征；保留改善、恶化、恢复、反复出现；区分**预期内波动**与**真实恶化**（新节奏必经低谷期，期间持续下降不构成改路线的理由）；同一下降可同时保留知识缺口、提取困难、疲劳、压力、环境干扰等解释，直到新证据区分。判据不交人工：隔离式判断，回看窗口内事实取全、多维分别判、留依据与反例，缺证据输出“不确定”、不选边（`../00-定位与原则.md` 判断的隔离） | 主干 |
| 状态阶段判断 | 见下「阶段类型」；怎么判见 `../会话/后台整理.md` | 主干方向 |
| 输出分型与裁决交接 | 每条对外输出标明承载读数还是解释候选，见下「两型输出」 | 主干 |
| 候选与趋势的隔离 | 趋势只由这里自己的多次独立可观察事实形成，不因诊断的存在而收敛；与诊断对同一表现的解释可以并存，各交各的使用者；用户确认不是趋势形成的前提 | 主干 |
| 承载能力与现实限制 | 描述当前可承受的任务量、持续时间、复杂度、切换压力和环境限制；不据此直接排路线、出计划或选教法。承载以核心任务数表达（同时不超过两个），不是时间表；现实约束不追求日程精度 | 主干方向 |
| 状态可见与异议记录 | 状态、来源、依据对学习者可见（产出可见原则）；异议按自述来源记录并标注，不覆盖可观察事实 | 主干 |
| 只读供给 | 向学习对话（解释条件、策略适配条件）、导航（路线承载限制）分别提供，不把同一信息的不同用途混成一个决策 | 主干 |
| 状态回看与学习者解释 | 以可读方式呈现变化、依据和限制，帮学习者理解系统为何提出暂停、降载或重新确认；界面形态不先定 | 第二梯队 |
| 外部条件接入 | 明确授权和用途说明后接入作息或设备信息；不默认自动采集；误读风险高，需单独审查 | 候选 |
| 自动长期趋势归纳 | 从多次状态信息提出可回看的近期趋势，保留时间范围和不确定性，不滑向固定画像或人格标签 | 候选 |
| 撤回、否认失效传播、敏感状态屏蔽 | 不做：自述不可信这一前提否掉了“由学习者裁定哪条状态成立”；屏蔽当前无必要 | 明确不做 |
| 心理疾病诊断与人格画像 | 不做，也不作隐藏候选 | 明确不做 |

## 两型输出

分界 = 是否与知识诊断竞争。这是输出契约，不是语义标签。

| 型 | 内容 | 谁怎么用 |
| --- | --- | --- |
| 承载读数 | 当前负荷、可挂核心任务数、可承载连续时长、环境限制 | 与知识诊断正交；导航、学习对话直接用 |
| 解释候选 | 当前表现下降的状态解释，及所属阶段类型 | 与“他不会”竞争，须经诊断裁决才能作行动依据 |

**裁决**：学习对话里诊断与教学同在一个会话，模型查到解释候选、和知识证据一起掂量，就是在裁决；裁决留在学习对话自己的上下文里，不另写，也不构成对状态记录的写入。导航用解释候选时自己读对话原文、和知识证据一起掂量。被裁为知识侧原因的候选不得沉淀为趋势。习惯低谷候选：诊断只需给出“知识侧解释不了本次下降”，节奏判断不在诊断视野内，候选存活后交导航用。

其余输出：当前状态 / 条件及适用时间；来源（自述、可观察事实、授权外部信息、暂定推断）；可见依据、不确定性、替代解释；需要重新确认的事项；与近期相比的变化（自然语言，不用不可解释的单一分数）；给学习者看的状态、来源与依据。

## 阶段类型

回答“这次下滑属于什么性质”。**盲发候选**：只依据可观察事实和自述，不知道诊断是否已判前置漏洞或台阶跳跃，排除由诊断裁决完成。判断要跨多次会话，输入是底层状态记录的整合，不新开通道。

| 阶段类型 | 依据 | 回看窗口 | 应对归属 |
| --- | --- | --- | --- |
| 习惯低谷 | 新节奏必经的低谷：即时奖励已撤、长期正反馈未形成，下降属预期内 | 该节奏起始至今（起始位置在事件记录） | 导航不改道、不加量 |
| 堆积型下滑 | 未完成事项累积，持续占用认知资源 | 近几次会话 | 导航限流、主动搁置 |
| 疲劳退化 | 明确可逆的分阶段退化 | 本次会话加近期对照 | 学习对话降载、导航留恢复期 |
| 阈值型动力低 | 即时刺激阈值抬高，慢反馈产生不了有效激励 | 跨阶段 | 学习对话高频小反馈 |

| 项 | 规则 |
| --- | --- |
| 输出三锁 | ① 只出阶段类型与所依据的时间跨度，不出特质陈述（多会话情绪涨幅积累够长就成人格断言，这是唯一的滑坡口）② 只给读数、不给动作，动作归导航 / 学习对话 ③ 不与阈值概念跨次判断合成单一“学习压力”量（合成需要一方同时持有知识侧与状态侧结论，正是单向所禁止的） |
| 窗口例外 | 本功能是“历史信息只作概率参考”的唯一例外：每类各自声明窗口，最长习惯低谷、最短疲劳退化；此外只用近期信息 |
| 知识侧原因 | 前置漏洞、台阶跳跃过早在这里**没有对应类型**，表现为无匹配特征，不产生候选 |
| 与阈值概念停滞 | 不合并，见 `../会话/后台整理.md`「阈值概念停滞与习惯低谷不合并」 |

## 可记录、临时参考与明确不推断

| 分类 | 内容 |
| --- | --- |
| 可记为状态或条件事实 | 学习者明确说出的当前疲劳、压力、挫败、焦虑、注意力、动力、启动困难、时间和环境限制；学习者对系统暂定状态的认同或异议（作自述来源记录：“学习者否认了这条”本身是事实，但不能裁掉观察结果，冲突时并存标注，由诊断裁决时处理）；学习过程的可观察事实及时间（学习时长、暂停、中断、任务堆积、连续错误、长时间无响应、反复切换）；学习者主动提供并明确授权的作息、设备等外部条件（用途和有效范围清楚）；多次有来源事实支持的近期趋势（保持时间范围和可推翻性） |
| 只能作临时参考或未确认候选 | 从回答质量、响应时间、任务中断推测的“可能疲劳”“可能过载”“注意力可能波动”；由当前条件派生的短期承载建议（不是稳定能力结论）；外部传感器或作息数据提示的变化（未经用户确认不提升为敏感心理或身体状态事实）；“当前表现可能受状态影响”的替代解释（只帮诊断保留假设，不证明掌握或不掌握） |
| 明确不推断 | 心理疾病、临床诊断、治疗需求、危机等级或任何医疗结论；人格、意志力、智力、稳定学习风格、长期动机或道德评价；“因为疲劳 / 焦虑所以不会”“因为没启动所以没动力”等未经验证的单一因果；知识掌握、理解深度、能力真值、一次学习（原称闭环）是否合上（归守卫与学过的记录）；下一步学什么、路线如何分叉、何时返回（归导航）；当前用哪种教法（归学习对话）；用户不知情时持续推断敏感心理状态，或把一次状态判断静默写成长期个人模型 |

## 输入

| 通道 | 内容 |
| --- | --- |
| 对话通道（主要来源） | 与诊断读同一份事件记录，靠取**不同字段**隔离：诊断取作答 / 步骤 / 理由判“会不会”；这里取时间间隔、中断点、求助频率、放弃点、状态自述、回复里的状态线索判“什么状态”；两次独立执行、不合并。可观察过程事实（连续失误、长时间无响应、任务无法启动、频繁中断、回答质量变化）是事实，不自动等于疲劳、焦虑或动机不足。当前任务与上一任务的跨度作刺激强度的前序事件（跨度大时挫败可能与难度相称，不是抗挫折能力低），从对话内容自取、不从诊断取；这里不当重点（N-02）。**不读任何知识结论** |
| 会话事实 | 项目、会话、暂停、恢复、时长、任务生命周期，含当前学习节奏的起始位置（程序记在事件记录） |
| 自己的历史 | 已有底层记录及其变化，用于时间对照，不用于造稳定人格结论 |
| 重新确认请求 | 学习对话里的诊断可发“某状态需要重新确认”：只带请求、不带判断、不压缩假设集，不能是状态结论；唯一反向边（D-19）；从学习对话怎么发出：待定 |
| 现实约束通道 | 独立、不经对话，来自用户设置与明确声明；只含可用时间上限与环境干扰；本轮只预留 |
| 授权外部信息 | 作息、设备信号等，只作学习条件参考；不能未经同意持续读取，不据此作健康诊断 |

| 规则 | 内容 |
| --- | --- |
| 采集路线 | 被动考察为主，持续优化被动判断的准确率；主动报告不是重点、不具权威（沉浸式形态下机会少，自述受可得性偏差影响，学习者还可能否认或掩盖）；自述与观察冲突时并存标注，由诊断裁决时处理，自述不单方面裁掉观察 |
| 不建显式请求通道（D-20） | 学习者请求（“直接讲”“今天只能 20 分钟”）是普通对话轮，不新增输入、边或槽位；对教法的影响由学习对话判断、不必照做；习惯靠从会话事实被动推断；自述不能绕过状态记录 / 诊断直达教法；也不剥夺学习者表达 |
| 状态独立入口 | 类似畅谈的独立状态自述入口：候选，暂不设计（N-03） |

## 谁读

| 读者 | 怎么读 | 用来 |
| --- | --- | --- |
| 学习对话 | 在沙盒里读：先看“当前状态”页，要细节按行号往下查 | 定本次强度、节奏；查解释候选并裁决 |
| 导航 | 经查询工具读，同上顺序 | 调路线承载、并行量、限流；用解释候选时自己读对话原文、和知识证据一起掂量（见「两型输出」裁决） |
| 教法记录整理 | 读（`../会话/后台整理.md`） | 对照状态条件整理教法反应，含“策略造成的状态”标注 |

| 规则 | 内容 |
| --- | --- |
| 不维护使用者名单 | 不给动作、不排优先级；用不用、怎么用由读的一方定 |
| 状态使用闸门 | 不设固定闸门：读数带证据强度与时间，读的人（导航 / 学习对话）当场决定要不要据此改行动 |
| 非主干（N-01） | 缺读数时导航、学习对话按“无状态约束”降级；关掉状态记录不影响一次学习跑通 |
| 守卫不读 | 状态不能让一次学习合上，不能代替守卫 |

## 边界

| 对象 | 规则 |
| --- | --- |
| 对话与事件记录 | 事件记录存项目、会话、生命周期和过程事实；这里形成状态语义。事件记录可存某状态出现在哪个会话、何时被确认，但不解释、不因状态自动暂停或结束会话；这里不建、不改会话结构。**只存事实不存解释**：事件记录存“各次会话启动间隔”，不存“启动困难”，解释每次整理时重新导出 |
| 学过的记录 | **双向都不引用**，是一对分开的学习者记录。同时要用知识与状态的是导航（直读两边）和学习对话（直读状态；知识侧经自己的诊断）。“一次学习结束时处于什么状态”经事件记录里程序存的归属链接获得。已知代价：导出的解释不可复现；每次导出带窗口与事实依据、可核对，不承诺两次相同。不为状态侧建长期结论存储（那是人格标签的入口） |
| 学习对话里的诊断 | **严格单向：状态 → 诊断。** 诊断不能写入或确认状态候选，不能向这里提供任何知识结论（前置漏洞、台阶跳跃、掌握判断都不进这里的上下文）。不许这里读诊断（已评估的代价：候选坍缩、回声、归因整体倒向知识侧、跨级别锚定）。已知代价：不掌握前置结构，难度读数粗；实为前置漏洞时仍会发疲劳或堆积候选——是候选不是结论，由诊断排除，且不得沉淀为趋势。诊断也不应把一次表现直接写成稳定状态 |
| 导航 | 这里提供可用时间、负荷、环境和持续条件；导航决定下一次学习、优先级、并行量、分叉、返回、复习和限流。这里不排路线；导航不反向创建或修改状态 |
| 学习对话的教法 | 这里描述状态和限制；学习对话据诊断、状态和目标自己定教法、提示强度、挑战程度、信息量和节奏；教法记录事后记反应（`../记录/教法记录与教学工具.md`）。这里不选方法、不存策略效果，不把一次策略效果写成长期开关或人格偏好 |
| 策略造成的状态 | **必须标来源**：当前教法本身会制造状态（逐题评判抬高威胁感，稀释审判频率降低它）。记录这类状态时标明它出现在某一反馈模式生效之后；这里不读学习对话的策略决定，标注来自事件记录里的可观察事实。学习对话读到带此标注的状态（教法记录整理同样），须先查自身教法是否为成因，不当作学习者固有条件（例：因威胁感上升而降难度，真正成因是逐题评判，正确动作是改为阶段性验收） |
| 会话内与会话外 | 诊断与教学是会话内级别（每轮生成、每轮用）；这里与导航偏会话外（跨轮、跨会话，关心节奏与承载）。所以整理频率低于诊断、不读诊断；让会话外的状态判断读入单轮证据，会把长时程状态锚在一次表现上 |
| 医疗 | 只提供学习相关的非医疗化支持；超出学习范围的健康问题不以这里的结论代替专业帮助，不作诊疗建议；外部信号接入需明确授权 |
