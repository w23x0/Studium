## 有哪几样

| 记录 | 谁产生 | 何时 | 在学过的记录里的层 |
| --- | --- | --- | --- |
| 选择卡 | 导航 | 每次出卡 | — （路线事实，不进分层） |
| 学习者的选择 | 程序记 | 学习者在卡上选定 | — |
| 单子 | 导航写进卡上每个选项；学习者选定后程序存 | 选定时 | 上层（一两百 token） |
| 路线决定与理由 | 导航 | 每次出卡；学习中途改线时 | 没合上那次的上层之一 |
| 没合上那次的结束原话 | 程序 | 学习者结束、没合上时 | 没合上那次的上层之一 |

分层与读法见学过的记录（`记录/学过的记录.md`）；容器归属（项目 / 对话 / 时间）见对话与事件记录（`记录/对话与事件记录.md`）；谁能读写以读写权限（`记录/读写权限.md`）为准。

## 单子

每次学习一张。单子说的是“这次打算学什么、从哪出发”，不是“学会了”；学会了什么看守卫判定（`会话/守卫.md`）。

| 栏 | 写什么 |
| --- | --- |
| 新点 | 写成知识本身，不写成题目；点按定义拆（`00-定位与原则.md`） |
| 选中的子句 | 出发点（一个或几个，**各注来源**：学过的记录 / 自述 / 假定）+ 一两句精简的话说清预期理解（从哪出发、学出什么理解、用到出发点的哪一面） |
| 对资料核的结果 | 导航当场对资料核过的：资料有支撑的指回原文位置；资料里没有的如实标“模型补的”，模型记忆不得伪装成原文（10-18；沿用旧“先生成、后回扫”原则）（待定：放在单子哪一栏、写多细） |
| 路线动作 | 继续主线 / 补前置 / 开分叉 / 返回主线 / 搁置；开分叉、补前置时带目标、范围、停止条件和返回主线的条件 |

| 规矩 | 内容 |
| --- | --- |
| 不写 | 要教会的要点清单、证据条件、深度 / 目标层次（单个学习的目标 = 沿选中的子句把新点合上，更深 = 另开一次走更抽象的子句；B11）；教材小节不单列（10-07）（待定：原理由“小节在点的派生层里”随通用知识结构取消失效，资料位置放哪随上行一起定） |
| 大小 | 一次坐下来能走完 |
| 谁用 | 学习对话（`会话/学习对话.md`）开场拿到的事实就是它；守卫对照的就是这条子句（出发点 + 预期理解）；导航以后读它当上层 |
| 可见可改 | 对学习者可见、可改（10-07）；学习者改单子 = 在事件记录里追加一条（改前、改后、时间），单子原行不改 |
| 自述 / 假定的出发点 | 只是来源标注，不是证据；学习中表现说明它不牢时按前置缺口处理（`会话/学习对话.md`） |

## 选择卡

卡的形状（几个选项、各带理由、推荐一个、学习者最后选）见 `01-流程.md`；怎么出卡见导航「选择卡」。本页只管存什么。

| 存什么 | 内容 |
| --- | --- |
| 选项 | 每个选项 = 一张单子草稿 + 理由 + 从哪来（学习对话里冒出的问题 / 导航现场说出的候选 / 现场判断的知识边缘上的点） |
| 推荐 | 推荐了哪一个 |
| 选择 | 学习者选了哪一个；由程序记 |

学习者选定 → 程序把那张单子存下、存路线事实 → 开学习对话，单子进开场（`01-流程.md`）。

## 路线决定与理由

| 项 | 内容 |
| --- | --- |
| 存什么 | 每次出卡、每次学习中途改线时导航作出的决定（含“维持”）及理由；分叉的返回条件随决定一起存；当前在主线还是分叉、从哪返回，都从这些决定读出（D-17） |
| 路线本身 | 不存：路线 = 从起点（学过的记录）到终点（方向目标）的路径，用时现场推（10-18） |
| 引用 | 理由**必标行号**（`文件:行号`），须可回查（C-02）；行号由程序印在事件记录上，模型只抄行号、不复述（`00-定位与原则.md`） |
| 检索结果 | 检索子代理交回的几条为这次决定服务，不另存成一层；要留就随这条理由一起存（10-18） |
| 不下结论 | 只记计划与决定的事实，不形成对学习者水平或能力的结论，不贴水平标签（D-08） |
| 谁写 | 导航只写路线决定（候选），由程序存；导航不改学过的记录、不改状态记录 |

## 路线偏差记录

供导航设计以后几次学习时参考（难度落点的个人化也读它，见导航「难度落点」）。与教法记录（`记录/教法记录与教学工具.md`）对称，是导航这一侧的记录，不写进守卫判定。

| 项 | 内容 |
| --- | --- |
| 由什么组成 | 每次学习的单子 + 学习对话中报出的改线依据（指回事件记录行号）+ 导航最终的调整（开分叉补前置 / 缩范围 / 维持）及理由 |
| 不另抄 | 这三样本来就存着（上两节、事件记录），偏差记录指回它们，不另写一份 |
| 只记偏差事实 | 不形成对学习者水平或能力的结论（D-08） |

## 没合上那次的上层

学习者没合上就结束（“结束这次学习（没合上）”命令，流程见 `01-流程.md`）时，不开守卫、没有判定，**不另写停车记录或总结**（10-18）。那次的上层是：

| 内容 | 谁写 |
| --- | --- |
| 单子 | 开始时已存 |
| 学习者为什么结束的原话 | 程序存盘时记（指回事件记录行号） |
| 导航当时的路线决定和理由 | 导航读那次的完整对话出下一张选择卡时写（本来就要读）；缺在哪个出发点、接着学还是先补出发点，写在这条理由里 |

- 这三样就是停车场里一条的内容；停车场怎么用见导航「二级功能」。
- 它说明打算学什么、停在哪、为什么停，**不是学会了的证据**（没有守卫判定）。

## 怎么改 / 不能改

| 规矩 | 内容 |
| --- | --- |
| 只追加 | 选择卡、选择、单子、路线决定都只追加；新决定取代旧决定时旧的留着、标“已被取代” |
| 谁能写 | 导航（选择卡、路线决定候选）、程序（存盘、学习者的选择）；学习者可改单子（见上） |
| 谁不能改 | 学习对话、守卫、后台整理（`会话/后台整理.md`）都不改单子与路线决定；学习对话只报改线依据，由导航决定 |
