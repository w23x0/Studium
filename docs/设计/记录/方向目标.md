## 一句话

一个项目对应一个方向目标：学习者要学成什么能力、为什么学，由畅谈谈出、存下来当确定的事实给。

## 谁产生 · 何时

| 项 | 内容 |
| --- | --- |
| 谁写 | 只有畅谈对话（`../会话/畅谈.md`） |
| 何时写 | 畅谈结束交回时；要改就再开畅谈，出新一版 |
| 冷启动 | 没有方向目标时，畅谈用默认先验出临时版，标“临时”，随学习推进替换（`../会话/畅谈.md`「冷启动」） |

## 内容

| 项 | 内容 |
| --- | --- |
| 目标能力 | 学成后能做什么；可以先粗、逐步补齐（D-16） |
| 每块为什么学 | 每块目标能力的理由 |
| 学习者确认时的理由 | 学习者认可这个方向时自己给的理由 |
| 路线顺序 | 畅谈顺带给的先后，只作参考；导航可按学过的记录调整 |
| 期限 | 可记，不强制填 |

| 粒度 | 规则 |
| --- | --- |
| 一个项目一个方向目标 | 粒度不限：一门学科、一本书、一个专题都可以 |
| 书不是目标 | 书是项目选用的资料（`资料.md`） |
| 原“目标面”里锚定通用结构的部分 | 随通用知识结构取消作废；只留方向目标本身 |

## 在哪一层

| 项 | 内容 |
| --- | --- |
| 性质 | 终点：确定的，存下来当事实给（`../00-定位与原则.md` §3） |
| 与分层的关系 | 不在“单子 → 守卫判定 → 对话原文”这条按密度排的线上（`../00-定位与原则.md` §4）；读的会话开场直接拿到 |

## 谁读

| 谁 | 怎么用 |
| --- | --- |
| 主对话 | 开场读（`../会话/主对话.md`） |
| 导航 | 出选择卡时读，和学过的记录、学习者资料一起现场推下一步（`../会话/导航.md`） |
| 畅谈对话 | 再谈时读已有的一版 |
| 学习者 | 可见（产出可见，`../00-定位与原则.md` §7） |
| 其余 | 按 `读写权限.md` |

## 怎么改 · 不能改

| 规则 | 内容 |
| --- | --- |
| 只经畅谈改 | 导航只读；导航能调的是路线顺序，不改方向目标本身 |
| 新版不覆盖旧版 | 改后旧版保留、标“已被取代”，不再作当前值 |
| 不当水平结论 | 方向目标说的是要去哪，不评学习者现在的水平（D-08） |
