# 学过的记录

> 状态：已决。
> 原来对应：原 M09 审查单（动态学习者模型）；原 M04 审查单「多源证据采集与分级」「闭环总体记录契约」「判断复核与更正」与遗忘次序约束；原 M04-02（只取写入部分）；原 `03-运行设计.md`「M08 / M09」M09 表、「闭环外：事件与清单」；10-18 定稿第 1、2、3、5、6、7、8 条。原文在 `docs/撤下原文/模块时期/`。

这个学习者学过什么、怎么学的、学成什么样。它是起点（学习者会什么）的事实来源，存下来、下次当事实给（`../00-定位与原则.md` 确定 / 不确定）。**不另开会话写分析层，不另造摘要 / 压缩层**（10-18）：各会话本来就产生的记录按信息密度排开，就是它的全部。

## 内容

| 内容 | 谁产生 | 何时 | 定义在 |
| --- | --- | --- | --- |
| 单子 | 导航定下后程序存 | 每次学习开始前 | `../记录/单子与路线.md` |
| 守卫判定 | 守卫（`../会话/守卫.md`） | 每次申请收口 | `../会话/守卫.md` 怎么判；本页「守卫判定」写记录要求 |
| 事件记录（对话原文） | 程序当场记 | 一次学习（原称闭环）全程 | `../记录/对话与事件记录.md` |
| 没合上那次的结束原话 + 导航当时的路线决定和理由 | 程序 / 导航 | 没合上就结束时 | `../记录/单子与路线.md`「没合上那次的上层」 |
| 外部导入（畅谈 / 笔记） | 见本页「外部导入」 | 导入时 | 本页 |

## 分层：按信息密度排开

| 层 | 合上的那次 | 没合上的那次 | 体量 |
| --- | --- | --- | --- |
| 上 | 单子 | 单子 + 学习者为什么结束的原话 + 导航当时的路线决定和理由（10-18） | 一两百 token |
| 中 | 守卫判定 | —（不开守卫，没有判定） | 几百 token |
| 下 | 事件记录：学习对话的对话原文 | 同左 | 几千到几万 token |

| 规矩 | 内容 |
| --- | --- |
| 读法 | 从上往下读：上层答得了就停，答不了再往下读一层 |
| 不压缩 | 每层都是某个会话本来就产生的东西，不是从下层压出来的摘要；不另造摘要 / 压缩层、当前视图或索引摘要 |
| 一份结论 | 每次学习只有一份结论性产物（守卫判定），不在同一粒度上出两份说法（10-18） |
| 单子 ≠ 学会了 | 单子只说打算学什么、从哪出发；学会了什么看守卫判定；没合上的那次不是学会了的证据 |
| 最小单位 | 一次学习 |

## 守卫判定（对本记录的要求）

合上之后**不另开会话写形成记录**；守卫判定顺带写下学习者实际表现出的理解（10-18）。怎么写见 `../会话/守卫.md`；本记录要求判定里有：

| 项 | 要求 |
| --- | --- |
| 总述 | 这次实际学到什么、哪里还薄，加依据，依据指回学习者的行（行号由程序印，模型只抄行号；程序核对引用落在学习者的行上）；守卫不判合没合上 |
| 学习者实际表现出的理解 | 写下来、指回学习者的行；可与子句的预期理解不同（出发点不同，理解不同：记出发点、新点、所走子句与实际理解，不只记“点亮了”） |
| 证据分得清 | 独立完成、提示后完成、答案暴露后的表现可区分；按新点及所用出发点分得出证据强度（仅当场 / 含变式 / 含延迟），由守卫判定写明（`../会话/守卫.md` §4） |
| 模型与版本 | **记实际执行的模型与版本，不记可变别名**：别名可被重新指向，会使整条证据失效（`../00-定位与原则.md` 横切原则） |
| 上层取哪份 | 一次学习可能申请几次收口：学习者确认结束前的最后一份是这次的中层；之前的几份经收件箱推回学习对话，留在事件记录里 |

## 谁从哪层读

读写范围以读写权限（`../记录/读写权限.md`）为准；下表只说从哪层开始读。

| 读的人 | 怎么读 |
| --- | --- |
| 导航（`../会话/导航.md`） | 读上层与中层；需要细节时派检索子代理，自己不往底层翻（10-18）；例外：搁着的那几次（没合上就结束）读完整对话（10-18） |
| 检索子代理 | 从上层（单子 + 判定）出发、范围稍放宽，定位到底层原文，只交回几条（指回行号）；跨很长时间把同一个点的多次学习找回来也走它 |
| 学习对话（`../会话/学习对话.md`） | 沙盒里只读，作背景；现场证据优先，学过的记录不得覆盖本次证据；可以怀疑它（含外部导入），本次表现不符时以本次为准；记录没有版本，只有带时间、只追加的条目，默认先看最新的，需要时往前看 |
| 守卫 | 只读本次的单子与本次事件记录里学习者那一侧，不读以往的学过的记录（`../会话/守卫.md`） |
| 畅谈（`../会话/畅谈.md`） | 看学习者已储备什么，帮着定目标 |
| 主对话（`../会话/主对话.md`） | 学习者问进度时据此回答学过什么 |
| 教法记录的整理（`../会话/后台整理.md`） | 读事件记录与守卫判定，整理教法管不管用；整理结果写进教法记录（`../记录/教法记录与教学工具.md`），不写进本记录 |
| 状态记录的整理 | 不读本记录的知识结论（见「边界」） |
| 知识产出（`../记录/知识产出.md`） | 不直读（原红线：知识产出不直读个人知识记录） |

## 外部导入

学习者在系统之外学到的东西，经外部导入进来，填补学过的记录的空白。

| 项 | 内容 |
| --- | --- |
| 渠道 | 畅谈导入（模型经对话获取）、笔记导入（模型处理学习者的笔记）、别处的 AI 对话记录导入（学习者在别的 AI 产品里学的对话导出，10-23）；以后可加其他渠道。笔记与对话记录从资料入口拖进来，模型分流判为“学过的”、学习者可改（`资料.md`「入口」）；分流只判归哪类，不分析内容 |
| 与学习记录分开 | 严格分开存，标“未验证”；可信度低于一次学习留下的证据 |
| 按来源分档 | 写明判读依据，例：有完整推导与自己解释的笔记 > 只抄定义 / 公式的笔记 > 自述 / 畅谈 |
| 可以怀疑 | 教学中可以怀疑它；学习留下的证据永远优先于导入，后来的守卫判定按来源排在导入之上、自然压过它，不另写降档（见「时间与版本」） |
| 过渡点 | “学习证据只来自守卫判定”只管学习记录，不管导入 |
| 何时写 | 导入时写入 |
| 怎么存、谁写 | 存原样：畅谈导入 = 畅谈里学习者说的那些行的指针（会话 id + 行号）；笔记导入 = 笔记文件本身（转 md 存在外部导入里，不进资料：笔记说的是学习者会什么，`资料.md`）+ 一条导入记录（来源、来源分档、时间、标“未验证”）；别处的 AI 对话记录同笔记：对话原文转 md 存在外部导入里，读的人只把学习者说的、做的当证据，AI 讲的不算学习者会。由程序在导入时写，不经模型分析、不写“点亮了什么”；用时由读的人（导航经检索子代理、学习对话）现场判断它说明学习者会什么 |

## 时间与版本

| 项 | 内容 |
| --- | --- |
| 两根轴 | 每条记录带可信度（来源分档：学习证据 / 各档导入）与时间；同一片知识不能只记会 / 不会 |
| 只追加、不覆盖 | 复检、重新掌握、更正、学习者异议都形成新记录，旧结论不静默覆盖、不删；遗忘、降档不单独成记录（见下两行） |
| 复检 | 由导航安排成一次独立的学习；它的守卫判定是新记录 |
| 重新掌握 | 后来某次学习合上同一个点，形成新判定；旧的留着 |
| 遗忘 / 提取失败 | 不存成结论，也没人写。学习中发现“以前会的现在答不出”只是**候选**（学习对话自己的分析），可据此本轮直接补讲，或由导航另开复习。复习 / 复检是一次独立的学习，留下新的带日期的守卫判定；新旧判定并存、只追加，用时由导航（经检索子代理）比较，判断是遗忘、当时就没学牢还是别的；排除疲劳等状态原因也在用时：检索子代理去查那天的状态记录。不用固定遗忘曲线 |
| 降档 | 不另写。后来学习中的表现与已有内容（含外部导入）不符时，新的守卫判定与旧内容并存、用时比较（见上行），以学习证据为准；外部导入按来源排在学习证据之下，后来的守卫判定自然压过它 |
| 学习者异议 | 按自述来源记下，不覆盖可观察事实；对判定的异议可触发复核，复核结果是新记录 |
| 时效 | 学习证据只在一次学习结束时形成，滞后一拍（进行中的不反映）；外部导入在导入时写入 |
| 牵连 | 不主动扩散，不顺着单子去找拿旧点当出发点的那些次。导航每次拿一个点当出发点前，经检索子代理看它最新的判定；后来的判定显示理解变了，由导航当场决定要不要先复检 |

## 不存，用时判断

| 东西 | 做法 |
| --- | --- |
| 知识边缘（已会与未会的交界） | 导航用时现场判断，不存（10-18） |
| 簇（学习者学会的一串细点按人合成一块，可作更抽象的出发点） | 用时由模型现场判断，跨多次学习也一样，不存 |
| 学习者实际混淆了什么 | 在事件记录里，用时读、用时判断；不另存结构 |
| 水平 | 不贴水平标签（D-08）；学习者会什么只由这些记录本身表达 |

## 边界

| 项 | 内容 |
| --- | --- |
| 范围 | 按人、按时间存，不按项目划界，每个项目都能看到 |
| 冷启动 | 记录为空时，导航靠方向目标、外部导入和资料起步，标“临时”（`../会话/导航.md`「冷启动」） |
| 只收结束的 | 学习进行中的诊断、教学回应、工具调用不当成结论写进来；进行中的东西只在事件记录里 |
| 与状态记录 | **双向不引用**，是分开的两份学习者记录（`../记录/状态记录.md`）；“学这次时处于什么状态”经事件记录里的时间与归属关联得到；关联只存事实不存解释，解释每次重新导出，只承诺依据可核对、不承诺结论可复现（`../00-定位与原则.md` 横切原则） |
| 与单子与路线 | 导航的计划不写进本记录；只有新的一次学习形成新记录 |
| 与教法记录 | 教法对这个学习者管不管用归教法记录，不写进本记录成为稳定人格或掌握结论 |
| 明确不做 | 人格类型、能力评级、跨学科自动泛化；固定复习天数、单一遗忘曲线、负荷分数、人格化策略偏好 |
