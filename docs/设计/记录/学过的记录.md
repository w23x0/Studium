## 读原文时什么算证据

本节是正本（10-31，原守卫的证据标准挪来；原文 `docs/撤下原文/会话-守卫.md` §3 §4）。谁守：凡是读以往学习的原文、据以判断学习者会什么的一方：导航、检索子代理、下一次学习的学习对话、后台整理（教法记录整理）。单子与收尾那一句只是指针，不是证据（`../00-定位与原则.md` §4）。读原文的模型同样可能被带偏，偏的问题在对话里解决，不另设独立会话（10-31）。

| 项 | 内容 |
| --- | --- |
| 对照什么 | 那次单子里选中的子句（出发点 + 预期理解）：看新点经所选出发点接进学习者已有认识的实际情形，可与预期不同（出发点不同，理解不同，`../00-定位与原则.md` §2）；不另判深度（B11） |
| 怎么读 | 读原文整体判断；不设条目清单、固定刻度或数学公式 |
| 只认学习者 | 只认学习者自己说的、做的（事件记录里标学习者的行，`../记录/对话与事件记录.md` §3）；判断指回行号，引用的行须落在学习者的行上，由程序核对，指到模型讲解的行不算证据；模型的工作区与思考也不算（行号规则见 `../00-定位与原则.md` §4） |
| 独立程度 | 独立完成、轻微提示、答案暴露后的正确回答不是同一种证据 |
| 时间条件 | 分清仅当场 / 含变式 / 含延迟，让日后分得清“当时就学得模糊”还是“后来遗忘”（原 M09「证据边与条件」、旧 M04 总体记录契约） |
| 作答完整度 | 一两句短答、只给结论的作答只算“这一点答对了”，不据此推断整件事已懂 |
| 讲过的内容 | 学习者跟着复述不算独立证据；须用**光靠复述做不到的方式**重新表现（换情境讲、预测结果、对比两种情况、找错、举反例、解释为什么不行等，可组合）才算 |
| 自述与假定 | 不是证据（含“我学会了”、出发点只来自自述 / 假定） |
| 不往上读 | 模型自信（含收尾那一句里学习对话的说法）、学习者自述、画像、高频状态、策略偏好、历史个人记录、单次表现都不能单独当成“学到了” |
| 证据不足 | 如实说薄；导航读到后自己决定要不要安排复检 |

## 谁从哪层读

读写范围以读写权限（`../记录/读写权限.md`）为准；下表只说从哪层开始读。

| 读的人 | 怎么读 |
| --- | --- |
| 导航（`../会话/导航.md`） | 读上层与中层作索引；要据以下判断时按指针读原文、按「读原文时什么算证据」读（自己读还是经检索子代理，待定：任务线路 #76；现行做法是派检索子代理，10-18）；例外：搁着的那几次（没合上就结束）读完整对话（10-18） |
| 检索子代理 | 怎么找、交回什么见 `../会话/导航.md`「检索子代理」；跨很长时间把同一个点的多次学习找回来也走它；读原文按「读原文时什么算证据」 |
| 学习对话（`../会话/学习对话.md`） | 沙盒里只读，作背景；现场证据优先，学过的记录不得覆盖本次证据；可以怀疑它（含外部导入），本次表现不符时以本次为准；记录没有版本，只有带时间、只追加的条目，默认先看最新的，需要时往前看；读以往学习的原文判断学习者会什么时按「读原文时什么算证据」 |
| 畅谈（`../会话/畅谈.md`） | 看学习者已储备什么，帮着定目标 |
| 主对话（`../会话/主对话.md`） | 学习者问进度时据此回答学过什么 |
| 教法记录的整理（`../会话/后台整理.md`） | 读事件记录与收尾那一句（作指针），按「读原文时什么算证据」看学习者之后的表现，整理教法管不管用；整理结果写进教法记录（`../记录/教法记录与教学工具.md`），不写进本记录 |
| 状态记录的整理 | 不读本记录的知识结论（见「边界」） |
| 知识产出（`../记录/知识产出.md`） | 不直读（原红线：知识产出不直读个人知识记录） |

## 外部导入

学习者在系统之外学到的东西，经外部导入进来，填补学过的记录的空白。

| 项 | 内容 |
| --- | --- |
| 渠道 | 畅谈导入（模型经对话获取）、笔记导入（模型处理学习者的笔记）、别处的 AI 对话记录导入（学习者在别的 AI 产品里学的对话导出，10-23）；以后可加其他渠道。笔记与对话记录从资料入口拖进来，或学习者给路径由主对话从本机读、存副本；模型分流判为“学过的”、顺带判归属（多为学习者级，所有项目都能读），学习者可改（`资料.md`「入口」「存在一处、按归属读」）；分流只判归哪类，不判学习者会什么 |
| 与学习记录分开 | 严格分开存，标“未验证”；可信度低于一次学习留下的证据 |
| 按来源分档 | 写明判读依据，例：有完整推导与自己解释的笔记 > 只抄定义 / 公式的笔记 > 自述 / 畅谈 |
| 可以怀疑 | 教学中可以怀疑它；学习留下的证据永远优先于导入，后来的学习记录按来源排在导入之上、自然压过它，不另写降档（见「时间与版本」） |
| 过渡点 | “学习证据只来自一次学习的原文里学习者的行”只管学习记录，不管导入 |
| 何时写 | 导入时写入 |
| 怎么存、谁写 | 存原样：畅谈导入 = 畅谈里学习者说的那些行的指针（会话 id + 行号）；笔记导入 = 笔记文件本身，与资料存在同一处，分原件层（原样、不改，保留原目录结构）与工作层（模型可整理，改动由程序记），见 `资料.md`「原件层与工作层」；另有一条导入记录（来源、来源分档、时间、标“未验证”）；别处的 AI 对话记录同笔记，读的人只把学习者说的、做的当证据，AI 讲的不算学习者会。导入记录由程序写，不写“点亮了什么”；判断学习者会什么以原件为准，工作层里模型整理过的文字不当学习者写的；用时由读的人（导航经检索子代理、学习对话）现场判断它说明学习者会什么 |

## 时间与版本

| 项 | 内容 |
| --- | --- |
| 两根轴 | 每条记录带可信度（来源分档：学习证据 / 各档导入）与时间；同一片知识不能只记会 / 不会 |
| 只追加、不覆盖 | 复检、重新掌握、更正、学习者异议都形成新记录，旧结论不静默覆盖、不删；遗忘、降档不单独成记录（见下两行） |
| 复检 | 由导航安排成一次独立的学习；它留下的单子、收尾那一句与原文是新记录 |
| 重新掌握 | 后来某次学习合上同一个点，形成新记录；旧的留着 |
| 遗忘 / 提取失败 | 不存成结论，也没人写。学习中发现“以前会的现在答不出”只是**候选**（学习对话自己的分析），可据此本轮直接补讲，或由导航另开复习。复习 / 复检是一次独立的学习，留下新的带日期的记录；新旧并存、只追加，用时由导航（经检索子代理）回看那几次学习的原文比较，判断是遗忘、当时就没学牢还是别的；排除疲劳等状态原因也在用时：检索子代理去查那天的状态记录。不用固定遗忘曲线 |
| 降档 | 不另写。后来学习中的表现与已有内容（含外部导入）不符时，新的学习记录与旧内容并存、用时比较（见上行），以学习证据为准；外部导入按来源排在学习证据之下，后来的学习记录自然压过它 |
| 学习者异议 | 按自述来源记下，不覆盖可观察事实 |
| 时效 | 学习证据只在一次学习结束时形成，滞后一拍（进行中的不反映）；外部导入在导入时写入 |
| 牵连 | 不主动扩散，不顺着单子去找拿旧点当出发点的那些次。导航每次拿一个点当出发点前，经检索子代理回看它最新那次学习的原文；后来的原文显示理解变了，由导航当场决定要不要先复检 |

## 不存，用时判断

| 东西 | 做法 |
| --- | --- |
| 知识边缘（已会与未会的交界） | 导航用时现场判断，不存（10-18） |
| 簇（学习者学会的一串细点按人合成一块，可作更抽象的出发点） | 用时由模型现场判断，跨多次学习也一样，不存 |
| 学习者实际混淆了什么 | 在事件记录里，用时读、用时判断；不另存结构 |
| 水平 | 不贴水平标签（D-08）；学习者会什么只由这些记录本身表达 |

## 边界

| 项 | 内容 |
| --- | --- |
| 范围 | 按人、按时间存，不按项目划界，每个项目都能看到 |
| 冷启动 | 记录为空时，导航靠方向目标、外部导入和资料起步，标“临时”（`../会话/导航.md`「冷启动」） |
| 只收结束的 | 学习进行中的诊断、教学回应、工具调用不当成结论写进来；进行中的东西只在事件记录里 |
| 与状态记录 | **双向不引用**，“学这次时处于什么状态”经事件记录里的归属链接关联（`../记录/读写权限.md`「红线」；代价与规矩见 `../记录/状态记录.md`「边界」学过的记录行、`../记录/对话与事件记录.md` §8–§9） |
| 与单子与路线 | 导航的计划不写进本记录；只有新的一次学习形成新记录 |
| 与教法记录 | 教法对这个学习者管不管用归教法记录，不写进本记录成为稳定人格或掌握结论 |
| 明确不做 | 人格类型、能力评级、跨学科自动泛化；固定复习天数、单一遗忘曲线、负荷分数、人格化策略偏好 |
