## 资料是干什么的

模型本来就懂一般知识；资料不是给模型补知识的。不懂的只有训练之后的新内容，那部分靠联网查来、作为资料进项目。

| 作用 | 内容 |
| --- | --- |
| 定范围 | 告诉模型这个人要学会的是什么（一个仓库、一本书、一组论文）；导航据此现场推出要先会哪些基础（`../会话/导航.md`） |
| 给具体 | 模型不知道的细节：这个仓库实际怎么写的、这本书用的记号与讲法、训练之后的新信息 |
| 给依据 | 讲的时候指回原文那一处，学习者能点过去核对 |
| 当练习场 | 代码仓库能跑、能改一行看结果；练习可以在资料上做，不只是读 |

不是资料的：学习者的笔记、在别处跟 AI 学的对话记录——它们说的是学习者会什么，进学过的记录的外部导入（`学过的记录.md`）。

## 资料归项目

| 项 | 内容 |
| --- | --- |
| 范围 | 资料的范围就是项目的范围：每个项目有自己的资料；项目之外的资料这个项目不读 |
| 跨项目重复 | 同一本书进两个项目各算一份，重复不管；实现上可共用转换产物 |
| 跨项目 | 跨项目时模型自己去看学习者在别的项目里学过什么（经学过的记录，`学过的记录.md`），不跨项目读资料 |
| 角色 | 主资料（目标所在，定范围）/ 参考资料（补讲法与细节）：由模型在检索时自己判断，判断结果作标注、前端可见；学习者不必手动分 |
| 冲突 | 几份资料说法不一致时并存、不强合并（D-03）；主资料为先，标明出处与日期；不打分 |

## 怎么存

不按资料种类各设计一套，只有一条规矩：**每份资料都处理成 md + 能指回原件的位置 + 固定版本 + 来源与日期**。原件保留。

| 种类 | 处理 | 定位 |
| --- | --- | --- |
| 书、讲义、论文（PDF） | MinerU 转 md | 原件页码 + 位置框（见下「原件、转录与修订」） |
| 网页 | 存当时的快照转 md，记抓取日期 | 段落引文 |
| 视频 | 字幕转 md | 时间点 |
| 代码仓库 | 固定在某次提交；**代码原样保留、不转 md**（要能跑；本身就是文本）；仓库里的文档本来多是 md | `文件:行号` |
| 联网查来的新内容 | 同网页；标“联网查来”与日期 | 段落引文 |

| 规则 | 内容 |
| --- | --- |
| 新种类 | 只加一个转换器，其余不变 |
| 不存派生 | 摘要、路线、知识点标签都不存；理解和路线每次现场推（10-18） |
| 版本 | 资料更新 = 新版本；旧引用仍指向旧版本，不悄悄改指 |
| 转换出错 | 在使用中发现、再修，有问题的块也先进来并标状态（B7；见下「入库」） |

## 怎么找

照主流编程 agent（Claude Code）的做法：最符合、最好用；以后随它变。

| 项 | 内容 |
| --- | --- |
| 谁找 | 模型自己在沙盒里找；程序不替模型挑资料片（`../会话/学习对话.md` §2） |
| 怎么找 | 先看地图（目录、README、文件树），再按关键词搜（grep / glob 一类），再读整段；不对就换词再找。一章、一个文件能整段读的就整段读 |
| 读得多时 | 派子代理在自己的上下文里读，只把找到的几处（带位置）交回；导航已有检索子代理（`../会话/导航.md`），资料同样做 |
| 索引 | 资料多到搜不动时才加；派生、可从原文整个重建，不当记录 |
| 不按什么找 | 不以点或子句作检索条件（10-18 第 3 条） |
| 谁用 | 学习对话、守卫在沙盒里读原文；导航读资料定范围、对候选核资料；知识产出取来源（读写见 `读写权限.md`） |

## 怎么保证准

| 项 | 内容 |
| --- | --- |
| 引用由程序核对 | 模型说“依据在某处”，程序按位置取出原文；取不到的不算依据。与守卫行号核对同一个思路（`../00-定位与原则.md` §6 原则 7） |
| 没有就说没有 | 资料里找不到就明说；模型自己补的标“模型补的”，模型记忆不得伪装成原文 |
| 新旧标清 | 资料带日期与版本；新旧说法冲突时明着标出（外部证据：上下文里混着过时信息时模型会更自信地答错，HoH arXiv 2503.04800，问答任务） |
| 是否真有用 | 事先保证不了，用真模型试：拿一个仓库和一本书各跑一次导航，看推出的“要先会什么”对不对；推出的前置对照仓库的依赖关系与文档引用的论文核一遍（外部证据：AI 生成的仓库导览会漏、人察觉不到，arXiv 2607.26987，只读到摘要） |

## 原件、转录与修订（待定：未经定稿）

适用于有原件、经转换的资料（现以 PDF 为主）。“原文” = **原件**；MinerU 输出降为可修订的转录（`方向记录.md` 10-06）。起因：Stewart 9e 的 PDF 字体编码坏（`=` → `−`、`<` → `,`、`/` → `y`、括号 → `s…d`），MinerU 照搬文字层，错误改变意思；PDF 文字层与转录错得一样，不能当第二来源（只查过一页，范围待量）。

| 项 | 内容 |
| --- | --- |
| 三层 | 原件（PDF 页面，不改）· 转录（MinerU v0 不改 + 修订记录只追加：位置、改前、改后、依据、提出者、核实状态）· 读取视图（v0 + 已核实修订，读时合成） |
| 定位 | 每块挂原件页码 + 位置框（MinerU `content_list.json` 已有）；锚点挂原件位置，转录修订或换转换器重转都不断锚；旧修订按位置重对，新版已改对的自动作废 |
| 锚点写法 | 原件位置（页 + 位置框）+ W3C `TextQuoteSelector`（exact + prefix + suffix，对读取视图），不用行号；修订后在同一位置内重新对引文。会话与事件记录用行号，资料用锚点，两者不混用（B-01）；代码仓库用固定提交下的 `文件:行号`，提交固定后不变 |
| 修什么 | 按危害：等价写法（`\to` / `\rightarrow`）不修，比对时归一；改变意思的符号、结构错（标题层级、并节、图注分离、页边注混入）、内容丢失必修 |
| 候选来源 | ① 程序：LaTeX 编译失败、已知坏编码模式、连字丢失（`Diferentiation`）② 使用中顺带：读原文的会话输出结构化“疑似转录错误”；学习者报告走入库修正 ③ 看图：按位置框截原件，能看图的模型对照提出改法，程序验 LaTeX |
| 按书归纳 | 坏编码整书一致：核实几处后成书级映射规则；`s` / `d` / `y` 本身是字母，规则须看上下文；规则产生的修订标来源、抽样核实 |
| 调度 | 机制通用；现阶段按需（被引用到、要给学习者看的块先核实），看图模型便宜后整本前置；预算只进调度，不进结构 |
| 块状态 = 由事件算出 | 每块只存事件：读到（哪个会话、何时）· 审查（谁、怎么审、结果）· 修订（改前、改后、依据、改没改意思）；状态读时算：有核实 = 已核实，无核实有疑点 = 疑似，都无 = 未核实 |
| 审查分量不同 | 只读文字的会话只能报疑点、不能证明对（看不到原件；试跑中三个模型都悄悄改对公式不报）——须明确要求它们报疑点，“读过没报”只算弱证据；只有对照原件（看图模型或人）才算核实 |
| 核实绑定版本 | 核实挂在某一版文字上；修订后旧核实作废 |
| 修订多是警报 | 反复修订或两个核实者改法不同 → 标“有争议”，停自动修订，转更强模型或人；给学习者看时用截图 |
| 核实优先级 | 被读次数 × 风险（程序算：公式密度、命中本书已知坏编码模式） |
| 实现期 | 阈值（核实几次算稳、改几次标争议）看实际错误率定；原文层物理载体与身份 / 版本 / 时间契约（D-006） |

## 入库

| 功能 | 结论 | 级别 |
| --- | --- | --- |
| 来源登记与资料类型 | 保存原始来源、作者 / 许可或可分享状态、资料类型、版本与日期；不同类型定位方式不同（见「怎么存」） | 主干 |
| 转成 md 与原文保真 | 正文、公式、图片 / 附件转成 md；md 不替换原件，保留 md 位置到原件位置的联动定位，使界面和会话能回到同一原文依据；代码原样保留 | 主干 |
| 资料结构 | 保留资料自己的结构（书的目录父子、仓库的目录树、网页的标题层级）供模型先看地图；深结构与浅结构资料不要求同一形态 | 主干 |
| 处理过程与状态查看 | 学习者能看到当前阶段、产物、待处理、成功和失败：可观察、可纠正、失败不伪装成功；不把处理步骤顺序写死 | 主干 |
| 异常、校核与人工修正 | 明确缺页、定位失败、结构异常、公式 / 图片损坏；允许修正后重新处理，不静默跳过。**按块记状态**：未核实或有疑问的块照常进来并标明状态，在使用中继续被发现、核实和修正（B7） | 主干 |
| 内容预览与定位检查 | 入库前后可抽查正文、结构和原文位置；生成性标注与原文分开呈现；不要求逐项人工确认 | 第二梯队 |
| 批量入口 | 批量不削弱逐份定位和失败可见性；入口与界面另页（导入入口在写） | 第二梯队 |
| 处理成本与产物复盘 | 保存处理的阶段结果，供错误复盘和质量检查 | 候选 |

## 浏览与题目

| 功能 | 结论 | 级别 |
| --- | --- | --- |
| 资料目录 | 项目页列出本项目的资料、各自角色标注、处理状态 | 主干 |
| 原结构浏览 | 按资料自己的结构查阅，看上下文和邻近内容；不重新识别或改写结构 | 主干 |
| 来源引用与原文跳转 | 每处引用保留资料与可理解的位置，可回到原件；生成性说明须可区分、可复核 | 主干 |
| 内容类型标签 | 按定义、证明、例题、练习等内容类型查找；标签可由入库或其他会话提出（可复用、非个人），不改写正文 | 第二梯队 |
| 题目 | 题目本体在资料里（题集、课后习题、仓库里的测试）；学习者实际做题的过程在学习对话的事件记录 | 主干 |
| 资料质量反馈 | 学习者可报告定位错误、正文问题、错误标注，回到入库修正，不直接改写来源 | 第二梯队 |
| 找资料 | 按目标发现其他来源，学习者勾选才存；入口另页（导入入口在写） | 候选 |

## 边界

| 对象 | 规则 |
| --- | --- |
| 不独立判断 | 覆盖、缺口、矛盾、来源质量不是资料的独立判断；学习者怎么理解归学过的记录；围绕研究问题的比较、论证归知识产出（`知识产出.md`） |
| 不做 | 自动综合质量分、固定权威阈值、“保留高分、删除低分”；不声称某种切片或检索已验证最优 |
| 资料不被学习改写 | 个人学习表现、一次性过程记录、未确认推断不得改变资料内容或写成标签 |
| 生成题 | 学习对话生成的练习不默认进资料，来源标“生成”（D-008） |
| 换模型 | 静默降级必须可见：处理状态与来源标记不因换模型而失真（`../00-定位与原则.md` §7） |
