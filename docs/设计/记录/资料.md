## 分两类：模型拿得到的 / 只有学习者手里有的

分界是**模型知不知道、拿不拿得到**，不是书还是笔记。

| 类 | 是什么 | 怎么进来 |
| --- | --- | --- |
| 模型自己拿得到的 | 模型本来就懂的（教材里的一般知识）+ 它能联网查到的（训练之后的新论文、仓库、网页） | 不由学习者导入。本来懂的直接讲；联网查来、要引用的，存一份当时的快照进项目（`../会话/找资料.md`） |
| 只有学习者手里有的 | **前置**：以前的笔记、在别处学的记录（含 AI 对话记录）、课程范围（老师讲哪几章、考什么）、学习者自己要配着学的书或教材<br>**进行时**：在 Studium 里学习时的产出（未设计，见 `../../../任务线路.md` #81） | 学习者导入：拖进来，或给路径由主对话从本机读、存副本（「入口」） |

| 规则 | 内容 |
| --- | --- |
| 书默认不导入 | 讲解靠模型自己的知识；模型知道的比一本书多，不为讲解去读书的原文。没导入的书不报页码、题号（看不到就不报） |
| 定范围 | 学习范围由方向目标（`方向目标.md`）与项目说明（`项目说明.md`）定；课程范围这类几行字的东西记进项目说明，不导入整本书。学习者导入了资料（一个仓库、一本自己要配着学的书）时，资料也定范围 |
| 学习者要配书 | 学习者自己导入，作这个项目的资料；模型不上网找书 |
| 题目 | 要做的题由学习者在对话里发来（拍照或贴文字）；题集、课后习题导入了的，题目本体在资料里；做题过程在学习对话的事件记录 |

## 资料是干什么的

模型本来就懂一般知识；导入的东西不是给模型补一般知识的。

| 作用 | 内容 |
| --- | --- |
| 给具体 | 模型不知道的细节：这个仓库实际怎么写的、学习者要配的那本书的记号与讲法、训练之后的新信息、学习者的笔记写到哪 |
| 给依据 | 讲的时候指回原文那一处，学习者能点过去核对；判断学习者以前会什么时，依据落到他笔记的原句（`学过的记录.md`） |
| 定范围 | 导入了才有（见上「定范围」）；导航据此现场推要先会哪些基础（`../会话/导航.md`） |
| 当练习场 | 代码仓库能跑、能改一行看结果；练习可以在资料上做，不只是读 |

## 存在一处、按归属读

资料与外部导入（笔记、别处的学习记录）不分两套存放：**所有导入存一处，格式与处理一样，每份带一个归属**。

| 项 | 内容 |
| --- | --- |
| 归属 | **学习者**：跟着学习者走，所有项目都能读（笔记、别处的学习记录多属这类）· **项目**：只给某个（或某几个）项目读（为某项目导入的书、仓库、课程材料） |
| 谁定 | 导入时模型分流顺带判归属并标出来，学习者可改（「入口」）；从哪个项目导入进来的照记，但不等于归那个项目 |
| 读范围 | 程序按归属给每个会话算能读什么：学习者级的全部 + 本项目的；别的项目的不在范围里，由程序挡，不靠模型自觉（`读写权限.md`） |
| 跨项目要用 | 另一个项目也要用：把归属改成学习者，或再加一个项目；改的是一个字段，文件不挪、不存两份 |
| 跨项目看学过什么 | 学习者在别的项目里学过什么经学过的记录直接读（`学过的记录.md`） |
| 角色 | 主资料（目标所在）/ 参考资料（补讲法与细节）：由模型在检索时自己判断，判断结果作标注、前端可见；学习者不必手动分 |
| 冲突 | 几份资料说法不一致时并存、不强合并（D-03）；主资料为先，标明出处与日期；不打分 |

## 原件层与工作层

借 agent 文件系统 layerfs 的一个想法（不变的底 + 叠在上面、能追溯的一层；它的多代理、分支、冲突不用）。

| 层 | 内容 |
| --- | --- |
| 原件层 | 导入时原样存下（文件夹保留原来的目录结构），谁都不改；记来源（路径或链接）、导入时间、指纹（以后能判断原件变没变）。溯源与判断学习者会什么都落到这一层 |
| 工作层 | 从原件来的可读副本，模型可以改：转成文字、切分、整理、给又大又乱的写一张说明（学科、主题、覆盖到哪、什么时候写的）、改文件名；不强求，看内容需不需要。每次改动由程序记（谁、何时、改了什么）；加工过的内容能指回原件哪个文件、哪几行 |

| 规则 | 内容 |
| --- | --- |
| 不分类、不打标签 | 导入的东西本来杂，硬分类反而分错；保留原样子，模型自己找。说明只是帮模型先挑读哪几份的指针，不作依据 |
| 以原件为准 | 工作层里模型整理过的文字不当学习者写的；要据以判断时读到原件（`../00-定位与原则.md` §4） |
| 版本 | 原件更新 = 再导入一版；旧引用仍指向旧版，不悄悄改指 |
| 不存派生结论 | 路线、知识点标签、“这份说明学习者会什么”都不存；理解和路线每次现场推（10-18） |

## 怎么处理

| 项 | 内容 |
| --- | --- |
| 不变的要求 | 每份最后都要：模型能读的文字（代码原样，要能跑）+ 能指回原件的位置 + 来源与日期；原件保留 |
| 怎么做到 | **试验中**（`../../../任务线路.md` #81）：原型里试由模型（Sonnet）自己处理，可用各种脚本工具，MinerU 作为它可调用的一个工具，图片存原件、直接给模型看；不写死按种类的转换流程。用出结果再写进这里 |
| 定位 | PDF 类：原件页码；网页：段落引文（记抓取日期）；代码仓库：固定提交下的 `文件:行号`；文字笔记：`文件:行号` |
| 处理出错 | 在使用中发现、再修；有问题的部分也先进来并标状态 |

## 怎么找

照主流编程 agent（Claude Code）的做法：最符合、最好用；以后随它变。

| 项 | 内容 |
| --- | --- |
| 谁找 | 模型自己在读范围内找；程序不替模型挑资料片（`../会话/学习对话.md` §2） |
| 先给清单 | 程序把本会话能读的资料列进开场（主对话每轮刷新）：每份一行，标题、种类、归属、大小；模型知道有什么，不靠它自己想到去查 |
| 整份读还是搜 | 跟眼下相关的整份读（导入多是学习者的笔记、记录，不大；书不导入，见「分两类」）；大的、或只找某一句时再搜。不按“能读的全部”整份放进上下文：归学习者的资料所有项目都能读，多半与眼下无关 |
| 怎么找 | 先看地图（目录、README、文件树、说明），再按关键词搜（grep / glob 一类），再读整段；不对就换词再找。一章、一个文件能整段读的就整段读 |
| 读得多时 | 派子代理在自己的上下文里读，只把找到的几处（带位置）交回；导航已有检索子代理（`../会话/导航.md`），资料同样做 |
| 索引 | 多到搜不动时才加；派生、可从原件整个重建，不当记录 |
| 不按什么找 | 不以点或子句作检索条件（10-18 第 3 条） |
| 谁用 | 学习对话在沙盒里读原文；导航读资料、对候选核资料；主对话找学习者给的文件；知识产出取来源（读写见 `读写权限.md`） |

## 怎么保证准

| 项 | 内容 |
| --- | --- |
| 引用由程序核对 | 模型说“依据在某处”，程序按位置取出原文；取不到的不算依据。与读原文时引用行号由程序核对同一个思路（`学过的记录.md`「读原文时什么算证据」） |
| 没有就说没有 | 资料里找不到就明说；模型自己补的标“模型补的”，模型记忆不得伪装成原文；没导入的书不报页码 |
| 新旧标清 | 资料带日期与版本；新旧说法冲突时明着标出（外部证据：上下文里混着过时信息时模型会更自信地答错，HoH arXiv 2503.04800，问答任务） |
| 是否真有用 | 事先保证不了，用真模型试：拿一个仓库跑一次导航，看推出的“要先会什么”对不对；推出的前置对照仓库的依赖关系与文档引用的论文核一遍（外部证据：AI 生成的仓库导览会漏、人察觉不到，arXiv 2607.26987，只读到摘要） |

## 入口

| 入口 | 内容 |
| --- | --- |
| 拖进来 | 文件（PDF、md、txt、Word、图片等）、整个文件夹；拖进主对话输入框 |
| 给路径 | 学习者说“我的笔记在某处”，主对话从本机读（只读，`读写权限.md`），要用就存副本进来；不把桌面当工作区 |
| 找资料 | 主对话说要找，开找资料对话联网搜、列候选，学习者勾了才进（`../会话/找资料.md`） |
| 以后 | 不在本机的来源（网盘等）只是多接一种“拿到原件”的方式，拿到之后的流程不变 |

| 进来之后 | 内容 |
| --- | --- |
| 先分流 | 模型判这份是讲知识的资料还是学过的（学习者的笔记、在别处学的记录），顺带判归属，并标出来，学习者可改；判为学过的进学过的记录的外部导入（`学过的记录.md`），存放仍在这一处 |
| 处理 | 见「怎么处理」 |
| 状态 | 每份显示 处理中 / 能用 / 有问题；有问题的写清哪一处、什么问题，可重试或删掉；失败不伪装成功 |
| 删除 | 学习者可删；已有引用标“资料已删”，不断成死链 |

## 边界

| 对象 | 规则 |
| --- | --- |
| 不独立判断 | 覆盖、缺口、矛盾、来源质量不是资料的独立判断；学习者怎么理解归学过的记录；围绕研究问题的比较、论证归知识产出（`知识产出.md`） |
| 不做 | 自动综合质量分、固定权威阈值、“保留高分、删除低分”；不声称某种切片或检索已验证最优 |
| 资料不被学习改写 | 个人学习表现、一次性过程记录、未确认推断不得改变资料内容或写成标签（工作层的整理是让文字好读，不写学习者会什么） |
| 生成题 | 学习对话生成的练习不默认进资料，来源标“生成”（D-008） |
| 换模型 | 静默降级必须可见：处理状态与来源标记不因换模型而失真（`../00-定位与原则.md` §7） |
