## 是什么

| 项 | 内容 |
| --- | --- |
| 保存什么 | 学习者自己的知识产出物：一篇研究、写作或内容编制成品从草稿到定稿的对象、版本链、修订比较、来源引用位置和编辑恢复位置 |
| 为什么单独一类 | 没有别的记录能承载“进行中的成品及其版本链”：资料不因学习表现而变；对话与事件记录的容器只到项目 / 会话 / 一次学习；学过的记录只收已结束的学习 |
| 不是 | 第二套教学、练习、诊断或规划；不保存通用知识；专属本人 |
| 依据 | 主干由产品负责人在第三次重构中直接确立；六份“学术补充理论”只是文献索引和理论方向，`DeepTutor 书籍功能.md` 属外部产品观察，都不是已验证依据 |

## 功能

| 功能 | 结论 | 级别 |
| --- | --- | --- |
| 产出物对象 | 围绕一个研究 / 写作 / 内容编制目标建立可继续编辑的成品对象，存材料引用、开放问题、草稿、反馈位置和恢复位置 | 主干（成立前提） |
| 版本链与修订比较 | 同一产出物的多个版本顺序、每版改动说明和可比较的差异，可回到任一历史版本 | 主干 |
| 来源引用位置 | 产出物每段内容可回到资料的原文位置（`../记录/资料.md`），引用关系随版本保留（C-02） | 主干 |
| 研究问题相关的文献关系 | 围绕特定研究问题组织引用、相互支持 / 矛盾、方法沿革和来源可靠性；关系必须回到资料来源 | 第二梯队 |
| 方法比较与适用边界 | 对多个方法的假设、适用条件、证据、限制和可迁移性作结构化比较，保存研究中尚未定论的暂时论证 | 第二梯队 |
| 研究问题形成 | 从资料缺口、矛盾、边界和跨域类比中外化候选问题，记录问题怎么变化，不替学习者宣称研究价值；是否属产品职责待定 | 候选 |
| 学习内容编制（书籍 / 课程 / 页面） | 不做，也不作隐藏候选（含 DeepTutor 式实时生成、自动评分、智能补弱、内容块） | 明确不做 |
| 多人协作、同行评审与知识交流 | 不做，也不作隐藏候选 | 明确不做 |

## 输入与输出

| 项 | 内容 |
| --- | --- |
| 输入 | 资料的多份原文、来源与出处位置；对话与事件记录里的项目归属、会话位置和过程记录；学习对话的理解与掌握判断（原规则：个人知识经诊断读、不直读学过的记录；学过的记录改为原始记录后怎么对应：待定）；学习者提出的研究问题、写作意图与已有成果 |
| 处理 | 建产出物对象；存草稿及版本链，记每版改了什么、支持比较；维护回到资料来源的引用位置；存编辑与恢复位置；围绕研究问题组织文献关系、方法比较和暂时论证 |
| 输出 | 可继续编辑的产出物及其版本链与修订差异、来源引用位置、围绕研究问题的文献与方法结构 |
| 不输出 | 教学表达、练习任务、诊断结论、掌握判断、跨次路线、学习者状态解释 |

## 边界

**已退回其他地方的功能**（这里只在产出物侧接收结果）：

| 功能 | 归哪 |
| --- | --- |
| 深度阅读路径 | 讲解 / 追问、复述 / 批注、理解判断在学习对话；阅读顺序与路线归导航；会话归属在对话与事件记录 |
| 长周期研究过程（计划、监控、调节、反思、子目标、暂存 / 重开） | 导航与对话与事件记录（任务状态、搁置 / 恢复）；长期项目的任务容器是项目 |
| 论证与批判性评估的反馈、解释与写作迭代的反馈 | 学习对话；这里只存论证对象本身及其版本，“修订与版本比较”留在这里 |
| 长期研究项目形态 | 项目形态的既有候选（考试、课程、研究等） |

| 对象 | 规则 |
| --- | --- |
| 理论 | 六份学术补充理论不是六类记录。抽象建构与多层概念理解：表征转换在学习对话，阈值概念用时由模型现场判断（10-18 第 3 条），都不在这里 |
| 学习对话 | 解释、写作、推导、实验既可能是学习对话里的学习活动，也可能形成这里的成品：用于检验能力的当次任务在学习对话，长期可迭代的成品与版本在这里，判断在学习对话 / 守卫；这里只接收可沉淀为成品的阅读、解释、实验和写作结果 |
| 一次学习 | 产出物跨多次学习存在，但本身不是一次学习，不产生合上判断 |
| 对话与事件记录 | 那边管项目、会话、一次学习的生命周期、归属和过程记录；这里只有产出物对象、版本链和引用位置，不管任务生命周期 |
| 导航 | 导航规划下一步、优先级、复检和长周期节奏；这里存产出物内部开放问题的演进，不做跨次路线决定 |
| 资料 | 引用必须回到资料位置；不改写资料，不把一次性产出物写进资料库 |
| 教法 | 高阶任务的教法与强度由学习对话定（`../记录/教法记录与教学工具.md`）；这里不拥有策略 |
| 状态 | 状态由状态记录存、由导航与学习对话用；这里不解释状态，也不因产出物进度推断状态 |
| 过程记录 | 运行过程和审查链在事件记录；这里存学习者真正要继续编辑和交付的成品 |
| 叫法 | 不用抽象层名（“高层网络 / 上升学习”）替代可审查功能 |

待定：产出物能否脱离项目独立存在；由哪个会话读写（原无对应会话，`../记录/读写权限.md`）。
