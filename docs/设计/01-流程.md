## 1 交互形状

学习者面对的是对话框：一个项目一条主对话，具体的事在主对话下面开任务对话做。参照 Claude 的项目模式（主对话 + 任务对话），只取形状，与云端无关。

| 项 | 含义 |
| --- | --- |
| 项目 | 一个项目对应一个方向目标，粒度不限（一门学科、一本书、一个专题都可以），由畅谈得出、可再谈再改（`记录/方向目标.md`）；学习者导入的书、仓库等是项目的资料（`记录/资料.md`；书默认不导入），不是目标 |
| 主对话 | 一个项目只有一条，连续、可以大；学习者在这里说话，主对话分清是哪类再做对应的事，开任务对话、在会话之间传话、提醒（`会话/主对话.md`） |
| 任务对话 | 畅谈对话：谈出方向说明，随学习一层层推远（`会话/畅谈.md`）；导航：主对话开，全自动定下一次学什么，过程可看、不交互（`会话/导航.md`）；学习对话：一次学习一个，开场拿单子，结束交回（`会话/学习对话.md`） |
| 并行 | 几次学习可以同时开着、以天计、不按顺序；开新学习由学习者主动，主对话只提醒 |
| 讨论串 | 任务对话在界面上叫讨论串，照 Claude 项目的讨论串：自己起总结标题；交回主对话的东西由讨论串自己写（学习对话同样，收尾那一句，§4）；交东西的交完就结束，讨论类的等学习者说完才结束；结束只是收起、能重开（学习对话除外）；主对话能看全部讨论串的状态、读、传话、结束 / 重开（`会话/主对话.md`「管讨论串」） |
| 项目页 | 三个页签加设置：**学习**（各次学习按 在学 / 搁着 / 学完 分组）· **资料**（本项目资料与学习者的产出，东西从这里拖进来，`记录/资料.md`「入口」）· **记着什么**（项目说明可改，`记录/项目说明.md`；方向说明、学过的记录、状态等摊开给看、可提异议；“内容送往哪里”也在这里，含各类对话用的模型，只看不改，`00-定位与原则.md` §7）；设置只有名字与期限，名字由学习者新建项目时自己起，谈方向不改它。Claude 项目的仓库、环境、插件、连接器、用量、建议线程不要 |
| 学到的东西 | 学过的记录按人、按时间存，不按项目划界，每个项目都能看到（`记录/学过的记录.md`） |

## 2 有哪些会话

每页回答：何时开 · 开场给什么 · 能读什么 / 工具 · 交回什么 · 边界。本表只列一句，以各页为准。

| 会话 | 做什么 | 何时开 | 页 |
| --- | --- | --- | --- |
| 主对话 | 接学习者的话，分类后做一件事 | 一个项目一条，常开 | `会话/主对话.md` |
| 畅谈对话 | 谈出方向说明，再开时推远一层 | 主对话判为新方向、或远处能看清一层时 | `会话/畅谈.md` |
| 学习对话 | 一次学习内的分析、讲、练 | 导航定下单子后，一次学习一个 | `会话/学习对话.md` |
| 页面子代理 | 主模型派出的 SDK 自带子代理，做要写代码的活（组件为主），让主上下文干净；主模型自己判断何时派 | 主模型自己判断（后台跑与活多久待定） | `会话/页面子代理.md` |
| 导航 | 定下一次学什么、开单子 | 学习者要下一步时主对话开（学习中途要改线也走这里，见导航页「何时开」） | `会话/导航.md` |
| 后台整理 | 整理状态记录、教法记录 | 会话结束后等，不挡别的 | `会话/后台整理.md` |
| 程序（不调模型） | 登记事件、开场交付、开会话前查必需项（缺了不开）、向收件箱推它自己确知、不属于学习者的东西（子代理交回、分叉结束的一句等）、收口时请学习对话写收尾那一句（§4）、存盘 | 每个事件 | 本页 |

| 要点 | 内容 |
| --- | --- |
| 会话不互相调用 | 都从记录里取、只写自己的产出；读谁、写谁以 `记录/读写权限.md` 为准（D-15） |
| 不是固定执行顺序 | 会话之间按事件接线（§3），不当成固定流水线或严格路由 |
| 模型与强度按会话类分开配 | 每类会话各有自己的模型与思考强度配置项，不写死、不全局一个；默认主对话低强度（分类、转交、传话、提醒），其余高强度；具体用哪个模型实现期按 `../模型基准/` 定 |

## 3 一次学习之外：按事件排

一次学习之外没有一条从头跑到尾的主循环，也没有程序记着的“当前阶段”（不写状态机）：程序只认刚发生了什么事，照这件事的清单做；清单里每步是一个会话或一个程序动作。加一种事件或改一张清单，别的清单不受影响。

| 事件 | 清单 |
| --- | --- |
| 学习者在主对话发话 | 主对话分类后做一件事（`会话/主对话.md`） |
| 一次学习合上（收口第 4 步，学习者确认） | 见下「合上之后」 |
| 学习者要结束、没合上 | 见下「没合上就结束」 |
| 暂停（学习者走开、过后回来） | 不算事件：任一对话（主对话、畅谈、学习对话等）原样留着，每条消息都带时间，回来后模型自己看得出离开多久，离开多久不设门槛，程序不单独推“离开多久”，接着该对话在做的事（学习对话即接着教）；隔很久回来时状态记录顺带整理（`会话/后台整理.md`） |

**合上之后**：

| 步 | 内容 |
| --- | --- |
| ① 程序存收口快照 | 快照组成见 `记录/对话与事件记录.md` §6，进 `记录/学过的记录.md`；不调模型 |
| ② 主对话说一句结果 | 学习对话的收尾那一句交回主对话，主对话照它说一句；不自动开导航、不自动开下一次：开新学习由学习者主动，主对话可按记录提醒（`会话/主对话.md`「传话与提醒」） |
| ③ 后台整理 | 状态记录整理、教法记录（这次教法管不管用）在后台跑（`会话/后台整理.md`）；只影响下一次学习怎么教；没跑完按“无状态读数”降级 |

- 合上后不另开会话写形成记录或分析层（`00-定位与原则.md` §9）；以原文为准、收尾那一句只作指针、不另写总结（`00-定位与原则.md` §4）。
- 什么时候学完由学习对话与学习者定（`00-定位与原则.md` §2）；“合上” = 学习对话写好收尾那一句 + 学习者确认“学完了”（§4）。

**没合上就结束**：

| 步 | 内容 |
| --- | --- |
| 触发 | 学习对话沙盒里的“结束这次学习（没合上）”命令（原名“结束闭环（没合上）”）：学习者在界面上点，或在对话里说了由模型代为执行（`会话/学习对话.md`） |
| ① 程序存盘 | 快照组成见 `记录/对话与事件记录.md` §6（状态记“没合上就结束”）；不写收尾那一句 |
| ② 主对话说一句结果 | 同「合上之后」②；这次学习算“搁着”，下次导航定下一步时读它的完整对话，缺在哪、接着学还是先补出发点写进那次的路线决定 |
| ③ 后台整理 | 同「合上之后」③ |

- 这次学习的上层见 `记录/单子与路线.md`「没合上那次的上层」；不另写停车记录或总结。
- 学习者觉得其实学会了，走手动申请收口（§4），不走这里。

## 4 收口

收口流程是 Studium 自有的，换一次学习内的框架不换它。10-31 起不另开会话：学习对话和其他讨论串一样，交回主对话的东西由它自己写（对齐 Claude 项目的讨论串）。

| 步 | 内容 |
| --- | --- |
| 1 申请 | 学习对话觉得学完了，写好收尾那一句、执行沙盒里的“申请收口”命令（只通知程序，那一句由程序存）；学习者也可手动申请（点“我觉得懂了”） |
| 2 收尾那一句 | 学习者手动申请时，程序请学习对话写这一句；学习对话觉得还差，也可以不写，直接跟学习者说差在哪、接着学。写什么见 `会话/学习对话.md` §8「收尾那一句」 |
| 3 确认 | 学习者看到那一句、确认“学完了”才算合上；不确认就接着学 |
| 4 出口 | 走 §3「合上之后」 |

- 学习者没合上仍要结束 → 走 §3「没合上就结束」，不写收尾那一句。
- 停车场 = 搁着的那几次（没合上就结束的），怎么接上由导航定（`会话/导航.md`「二级功能」）。
