# 设计资产（实验验证过的做法）

> 状态：现行（2026-09-28 建立）。
> 定位：**证据层，不是产品结论**。审查单采用某条资产时只引用、不抄正文。
> 来源：清理审查单 / 组合层时，**验证过的内容不删，移到这里**；没验证过（从想象写出）的内容照旧“偏了就删”（`CLAUDE.md`「文档规范」）。
> 分工：发现文件按实验记过程，`原型变更记录.md` 按时间记改动，本目录按主题只留**结论 + 验证条件 + 证据位置 + 现在用没用**，指回前两者、不复述。

## 每份的格式

| 列 | 写什么 |
| --- | --- |
| 结论 | 一两句 |
| 验证条件 | 当时的闭环定义、原型版本、哪次试用（真人 / 模拟） |
| 证据 | 指回发现文件 / 变更记录 / 运行记录的位置 |
| 现在 | 在用（写在哪）/ 暂不用（原因） |
