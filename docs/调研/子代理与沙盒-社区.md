## 2 同一个子代理跨次续上：有没有人做、取舍是什么

| 发现 | 依据（链接 + 原文关键句） | 对 Studium 的含义（一句） |
| --- | --- | --- |
| **opencode 用 `sessionID` 续**：不传就新开；工具说明把取舍写明 | [subagent.ts](https://github.com/anomalyco/opencode/blob/ed74ec82ce1fe3a36da6c0815a935473ef4bb0fb/packages/core/src/tool/plugin/subagent.ts)：`Continue a specific previous subagent conversation by passing its sessionID. Calls without a sessionID start a new conversation.`；`New child sessions start with fresh context, so include all relevant context and instructions when you don't pass a sessionID.`；完成通知也带 sessionID（[#36423](https://github.com/anomalyco/opencode/issues/36423)，2026-07-11） | 续 = 带全部旧上下文，不续 = 主模型重述；与我们“子代理保留上下文”同路 |
| **Cline 分两级**：子代理只在本次会话内，无共享状态；团队随会话恢复，task board / mailbox / mission log 落 `teams.db` | [multi-agent-teams.mdx](https://github.com/cline/cline/blob/a459f1d04dea030833b558be645011ab739c463b/docs/sdk/guides/multi-agent-teams.mdx)：`Persistence` 一行：`Within session only` / `Restored when the session resumes`；`Cline saves each team's task board, mailbox, mission log … in ~/.cline/data/db/teams.db` | 要跨次就升级成团队，状态面随之变大 |
| **Codex 用 fork 历史续**：`fork_turns` 省略 / `all` = 全历史 fork，继承父模型与 reasoning，不能改；要换模型得 `fork_turns:"none"`；`followup_task` / `send_message` 续子线程 | [multi_agent_instructions.rs](https://github.com/openai/codex/blob/970111f6cb62cc02fe36a82ea7d71b37a2889c97/codex-rs/prompts/src/multi_agent_instructions.rs)：`Full-history forks (fork_turns omitted or "all") inherit the parent model and reasoning effort and do not accept overrides.` | 全历史省重述但锁死模型；干净 fork 灵活但要重给上下文 |
| **pi 续的是对话存档**：会话可 fork，task 归会话所有；子代理结束后还能作为正常新任务再跑 | [spec.md](https://github.com/earendil-works/pi/blob/38ff99177fba21e9c57a670f4e95adcf407c99c7/packages/durable/docs/spec.md)：`A conversation is a transcript scope. It may fork another conversation.`；`a user interrogating a finished subagent, runs normally` | 进程可死，上下文要能重放 |
| **layerfs 把“跨次”放文件层**：每个代理挂一个可写 Workspace 在共享 committed history 上，做完提交、走人；不是续代理 | [README](https://github.com/Ephemeral-AI-Lab/layerfs/blob/ad78914e36b258b360daf13aec164b5655814689/README.md)：`Each one mounts a complete, writable Workspace over shared committed history, does its work, commits what it changed, and goes away.`（1.1.0，ad78914，2026-10-25） | 代理无状态、工作区有历史，和“子代理上下文”正交 |
