It often happens that Ax = b has no solution. The usual reason is: too many equations. The matrix A has more rows than columns. There are more equations than unknowns (mis greater than n). Then columns span a small part of m-dimensional space. Unless al measurements are perfect, b is outside that column space of A. Elimination reaches an impossible equation and stops. But we can't stop just because measurements include noise!

To repeat: We cannot always get the error $e = b - A$ x down to zero. When e is zero, x is an exact solution to $A x = b$ . When the length of e is as small as possible, $\widehat { \mathbf { x } }$ is a least squares solution. Our goal in this section is to compute $\widehat { \mathbf { x } }$ and use it. These are real problems and they need an answer.

The previous section emphasized p (the projection). This section emphasizes $\widehat { \mathbf { x } }$ (the least squares solution). They are connected by $\boldsymbol { p } = A \widehat { \boldsymbol { x } }$ . The fundamental equation is stil $A ^ { \mathrm { T } } A \widehat { \mathbf { x } } = A ^ { \mathrm { T } } b$ . Here is a short unofficial way to reach this "normal equation":

When Ax= b has no solution, multiply by $A ^ { \mathrm { T } }$ and solve $\boldsymbol { A } ^ { \mathrm { T } } \boldsymbol { A } \boldsymbol { \widehat { x } } = \boldsymbol { A } ^ { \mathrm { T } } \boldsymbol { b } .$

## Minimizing the Error

How do we make the error $e = b - A x$ as small as possible? This is an important question with a beautiful answer. The best x (called x) can be found by geometry (the error e meets the column space of A at $9 0 ^ { \circ } )$ and by algebra : $A ^ { \mathrm { T } } A \widehat { \pmb { x } } = A ^ { \mathrm { T } } \widehat { \pmb { b } }$ . Calculus gives the same $\widehat { \mathbfit { x } }$ : the derivative of the error $| | A x - b | | ^ { 2 }$ is zero at $\widehat { \mathbf { x } }$

By geometry Every Ax lies in the plane of the columns $( 1 , 1 , 1 )$ and $( 0 , 1 , 2 )$ . In that plane, we look for the point closest to b. The nearest point is the projection p.

The best choice for $A \widehat { \mathbfit { x } }$ is p. The smallest possible error is $e = b - p ,$ , perpendicular to the columns. The three points at heights $\left( p _ { 1 } , p _ { 2 } , p _ { 3 } \right)$ do lie on a line, because $_ p$ is in the column space of A. In fitting a straight line, xis the best choice for $( C , D )$

By algebra Every vector b splits into two parts. The part in the column space is $\mathbf { \nabla } p .$ The perpendicular part is e. There is an equation we cannot solve $( A x = b )$ . There is an equation $A { \widehat { \mathbf { x } } } = p$ we can and do solve (by removing e and solving $\widetilde { A } ^ { \mathrm { T } } A \widehat { \pmb { x } } = A ^ { \mathrm { T } } \pmb { b } )$

$A x = b = p + e$ is impossible

$A { \widehat { \mathbf { x } } } = p$ is solvable

$$
\widehat {\boldsymbol {x}} \quad \text { is } (A ^ {\mathrm{T}} A) ^ {- 1} A ^ {\mathrm{T}} \boldsymbol {b}.\tag{1}
$$

The solution to $A { \widehat { \mathbf { x } } } = p$ leaves the least possible error (which is e):

Squared length for any x

$$
\left\| A \boldsymbol {x} - \boldsymbol {b} \right\| ^ {2} = \left\| A \boldsymbol {x} - \boldsymbol {p} \right\| ^ {2} + \left\| \boldsymbol {e} \right\| ^ {2}.\tag{2}
$$

This is the law $c ^ { 2 } = a ^ { 2 } + b ^ { 2 }$ for a right triangle. The vector $A x - p$ in the column space is perpendicular to e in the left nullspace. We reduce $A x - p$ to zero by choosing ${ \boldsymbol { x } } = { \boldsymbol { \widehat { x } } }$ That leaves the smallest possible error $\boldsymbol { e } = ( e _ { 1 } , e _ { 2 } , e _ { 3 } )$ which we can't reduce.

Notice what "smallest" means. The squared length of $A x - b$ is minimized:

The least squares solution x makes $E = \| A x - b \| ^ { 2 }$ as small as possible.

Figure 4.6b shows the same problem in 3-dimensional space $( b p e { \mathrm { ~ s p a c e } } )$ . The vector b is not in the column space of A. That is why we could not solve $A x = b ,$ . No line goes through the three points. The smallest possible error is the perpendicular vector e. This is $e = \pmb { b } - A \widehat { \pmb { x } }$ , the vector of errors $( 1 , - 2 , 1 )$ ) in the three equations. Those are the distance from the best line. Behind both figures is the fundamental equation $A ^ { \mathrm { T } } A { \widehat { \mathbf { x } } } = A ^ { \mathrm { T } } b$

By calculus Most functions are minimized by calculus! The graph bottoms out and the derivative in every direction is zero. Here the error function E to be minimized is a sum of squares $e _ { 1 } ^ { 2 } + e _ { 2 } ^ { 2 } + e _ { 3 } ^ { 2 }$ (the square of the error in each equation):

$$
E = \left\| A \boldsymbol {x} - \boldsymbol {b} \right\| ^ {2} = (C + D \cdot 0 - 6) ^ {2} + (C + D \cdot 1) ^ {2} + (C + D \cdot 2) ^ {2}.\tag{3}
$$

The unknowns are C and D. With two unknowns there are two derivatives-both zero at the minimum. They are "partial derivatives" because $\partial E / \partial C$ treats D as constant and $\partial E / \partial D$ treats C as constant:

$$
\partial E / \partial C = 2 (C + D \cdot 0 - 6) \quad + 2 (C + D \cdot 1) \quad + 2 (C + D \cdot 2) \quad = 0
$$

$$
\partial E / \partial D = 2 (C + D \cdot 0 - 6) (\mathbf {0}) + 2 (C + D \cdot 1) (\mathbf {1}) + 2 (C + D \cdot 2) (\mathbf {2}) = 0.
$$

$\partial E / \partial D$ contains the extra factors O, 1, 2 from the chain rule. (The last derivative from $( C + 2 D ) ^ { 2 }$ was 2 times $C + 2 D$ times that extra 2.) Those factors are just 1, 1, 1 in $\partial E / \partial C$

It is no accident that those factors 1, 1, 1 and 0, 1, 2 in the derivatives of $\vert \vert A x - b \vert \vert ^ { 2 }$ are the columns of A. Now cancel 2 from every term and collect all $C ^ { \bullet } s$ and all $D ' _ { \mathrm { { S } ; \mathrm { ~ } } }$

$$

$$

These equations are identical with $A ^ { \mathrm { T } } A { \widehat { x } } = A ^ { \mathrm { T } } b$ . The best C and D are the components of x. The equations from calculus are the same as the "normal equations" from linea algebra. These are the key equations of least squares:

$$
\text { The   partial   derivatives   of } \| A x - b \| ^ {2} \text { are   zero   when } A ^ {\mathrm{T}} A \hat {x} = A ^ {\mathrm{T}} b.

## Fitting a Straight Line

Fitting a line is the clearest application of least squares. It starts with $m \ > \ 2$ points, hopefully near a straight line. At times $t _ { 1 } , \ldots , t _ { m }$ those m points are at heights $b _ { 1 } , \dots , b _ { m }$ . The best line $C + D t$ misses the points by vertical distances $e _ { 1 } , \ldots , e _ { m }$ No line is perfect, and the least squares line minimizes $E = e _ { 1 } ^ { 2 } + \cdots + e _ { m } ^ { 2 }$

The first example in this section had three points in Figure 4.6. Now we allow m points (and m can be large). The two components of x are still C and D.

A line goes through them points when we exactly solve $A x = b$ . Generally we can't do it. Two unknowns $C$ and $D$ determine a line, so $A$ has only $n = 2$ columns. To fit the m points, we are trying to solve m equations (and we only have two unknowns!).

$$
A \boldsymbol {x} = \boldsymbol {b} \quad \text { is } \quad \begin{array}{c} C + D t _ {1} = b _ {1} \\ C + D t _ {2} = b _ {2} \\ \vdots \\ C + D t _ {m} = b _ {m} \end{array} \quad \text { with } \quad A = \left[ \begin{array}{c c} 1 & t _ {1} \\ 1 & t _ {2} \\ \vdots & \vdots \\ 1 & t _ {m} \end{array} \right].\tag{5}
$$

The column space is so thin that almost certainly b is outside of it. When b happens to lie in the column space, the points happen to lie on a line. In that case $b = p$ . Then $A x = b$ is solvable and the errors are $e = ( 0 , \ldots , 0 )$

The closest line $C + D t$ has heights $p _ { 1 } , \ldots , p _ { m }$ with errors $e _ { 1 } , \ldots , e _ { m } .$

Solve $A ^ { \mathrm { T } } A { \widehat { x } } = A ^ { \mathrm { T } }$ b for x = (C, D). The erors are $e _ { i } = b _ { i } - C - D t _ { i }$

Fitting points by a straight line is so important that we give the two equations $A ^ { \mathrm { T } } A { \widehat { \mathbf { x } } } =$ $A ^ { \mathrm { T } } b ,$ once and for all. The two columns of A are independent (unless all times $t _ { i }$ are the same). So we turn to least squares and solve $A ^ { \mathrm { T } } A { \widehat { \mathbf { x } } } = { \widehat { A } } ^ { \mathrm { T } } b$ .

Dot-product matrix $A ^ { \mathbf { T } } A = { \left[ \begin{array} { l l l } { 1 } & { \cdots } & { 1 } \\ { t _ { 1 } } & { \cdots } & { t _ { m } } \end{array} \right] } { \left[ \begin{array} { l l } { 1 } & { t _ { 1 } } \\ { \vdots } & { \vdots } \\ { 1 } & { t _ { m } } \end{array} \right] } = { \left[ \begin{array} { l l } { m } & { \sum t _ { i } } \\ { \sum t _ { i } } & { \sum t _ { i } ^ { 2 } } \end{array} \right] } .$

(6)

On the right side of the normal equation is the 2 by 1 vector $A ^ { \mathrm { T } } b ;$

$$
A ^ {\mathrm{T}} \boldsymbol {b} = \left[ \begin{array}{c c c} 1 & \dots & 1 \\ t _ {1} & \dots & t _ {m} \end{array} \right] \left[ \begin{array}{c} b _ {1} \\ \vdots \\ b _ {m} \end{array} \right] = \left[ \begin{array}{c} \sum b _ {i} \\ \sum t _ {i} b _ {i} \end{array} \right].\tag{7}
$$

In a specific problem, these numbers are given. The best $\widehat { \pmb { x } } = ( C , D ) \mathrm { i s } ( A ^ { \mathrm { T } } A ) ^ { - 1 } A ^ { \mathrm { T } } \pmb { b }$

The line $C + D t$ minimizes $e _ { 1 } ^ { 2 } + \cdots + e _ { m } ^ { 2 } = \| A x - b \| ^ { 2 }$ when $A ^ { \mathrm { T } } A { \widehat { x } } = A ^ { \mathrm { T } } b$

$$
A ^ {\mathrm{T}} A \widehat {\boldsymbol {x}} = A ^ {\mathrm{T}} \boldsymbol {b} \qquad \left[ \begin{array}{c c} m & \sum t _ {i} \\ \sum t _ {i} & \sum t _ {i} ^ {2} \end{array} \right] \left[ \begin{array}{c} C \\ D \end{array} \right] = \left[ \begin{array}{c} \sum b _ {i} \\ \sum t _ {i} b _ {i} \end{array} \right].\tag{8}
$$

The vertical errors at the m points on the line are the components of $e = \pmb { b } - \pmb { p }$ <sub>.</sub> This error vector (the residual) $\textstyle \boldsymbol { b } - A { \widehat { \boldsymbol { x } } }$ is perpendicular to the columns of A (geometry). The error is in the nullspace of $A ^ { \mathrm { T } }$ (linear algebra). The best $\widehat { \pmb x } = ( C , D )$ minimizes the total error E, the sum of squares (calculus):

$$
E (\boldsymbol {x}) = \left\| A \boldsymbol {x} - \boldsymbol {b} \right\| ^ {2} = (C + D t _ {1} - b _ {1}) ^ {2} + \dots + (C + D t _ {m} - b _ {m}) ^ {2}.
$$

Calculus sets the derivatives $\partial E / \partial C$ and $\partial E / \partial D$ to zero, and produce $A ^ { \mathrm { T } } A { \widehat { \mathbf { x } } } = A ^ { \mathrm { T } } b .$

Other least squares problems have more than two unknowns. Fitting by the best parabola has $n \ = \ 3$ coefficients $C , D , E$ (see below). In general we are fitting m data points by n parameters $x _ { 1 } , \ldots , x _ { n }$ <sub>.</sub> The matrix A has n columns and $n < m$ . The derivatives of $\| A x - b \| ^ { 2 }$ give then equations $A ^ { \mathrm { T } } A { \widehat { \mathbf { x } } } = A ^ { \mathrm { T } } b$ . The derivative of a square is linear. This is why the method of least squares is so popular.

Example 2 A has orthogonal columns when the measurement times $t _ { i }$ add to zero.

Suppose $b = 1 , 2$ , 4 at times $t = - 2 , 0 , 2$ . Those times add to zero. The columns of A have zero dot product: $( 1 , 1 , 1 )$ is orthogonal to $( - 2 , 0 , 2 )$ ):

$$
\begin{array}{l} C + D (- 2) = 1 \\ C + \quad D (0) = 2 \\ C + \quad D (2) = 4 \end{array} \qquad \text {or} \qquad A x = \left[ \begin{array}{c c} 1 & - 2 \\ 1 & 0 \\ 1 & 2 \end{array} \right] \left[ \begin{array}{c} C \\ D \end{array} \right] = \left[ \begin{array}{c} 1 \\ 2 \\ 4 \end{array} \right].
$$

When the columns of A are orthogonal, $A ^ { \mathrm { T } } A$ will be a diagonal matrix:

$$
A ^ {\mathrm{T}} A \widehat {\boldsymbol {x}} = A ^ {\mathrm{T}} \boldsymbol {b} \qquad \text { is } \qquad \left[ \begin{array}{c c} 3 & \mathbf {0} \\ \mathbf {0} & 8 \end{array} \right] \left[ \begin{array}{c} C \\ D \end{array} \right] = \left[ \begin{array}{c} 7 \\ 6 \end{array} \right].\tag{9}
$$

Main point: Since $A ^ { \mathrm { T } } A$ is diagonal, we can solve separately for $\begin{array} { r } { C = \frac { 7 } { 3 } } \end{array}$ and $\begin{array} { r } { D = \frac { 6 } { 8 } } \end{array}$ . The zeros in $A ^ { \mathrm { T } } A$ are dot products of perpendicular columns in A. The diagonal matrix $A ^ { \mathrm { T } } A .$ with entries $m = 3$ and $t _ { 1 } ^ { 2 } + t _ { 2 } ^ { 2 } + t _ { 3 } ^ { 2 } = 8$ , is virtually as good as the identity matrix.

Orthogonal columns are so helpful that it is worth shifting the times by subtracting the average time $\widehat { t } = ( t _ { 1 } + \cdot \cdot \cdot + t _ { m } ) / m$ . If the original times were 1, 3, 5 then their average is $\widehat { t } = 3$ . The shifted times $T = t - { \widehat { t } } = t - 3$ add up to zero!

$$
\begin{array}{l} T _ {1} = 1 - 3 = - 2 \\ T _ {2} = 3 - 3 = \quad 0 \\ T _ {3} = 5 - 3 = \quad 2 \end{array} \qquad A _ {\text {new}} = \left[ \begin{array}{c c} 1 & T _ {1} \\ 1 & T _ {2} \\ 1 & T _ {3} \end{array} \right] \qquad A _ {\text {new}} ^ {\mathrm{T}} A _ {\text {new}} = \left[ \begin{array}{c c} 3 & \mathbf {0} \\ \mathbf {0} & 8 \end{array} \right].

## Dependent Columns in A: What is x?

From the start, this chapter has assumed independent columns in A. Then $A ^ { \mathrm { T } } A$ is invertible. Then $A ^ { \mathrm { T } } A \widehat { \pmb { x } } = A ^ { \hat { \mathrm { T } } } b$ produces the least squares solution to $A x = b$

Which x is best if A has dependent columns? Here is a specific example.

$$
\begin{array}{c c} \left[ \begin{array}{l l} 1 & 1 \\ 1 & 1 \end{array} \right] \left[ \begin{array}{l} x _ {1} \\ x _ {2} \end{array} \right] = \left[ \begin{array}{l} 3 \\ 1 \end{array} \right] = b & \left[ \begin{array}{l l} 1 & 1 \\ 1 & 1 \end{array} \right] \left[ \begin{array}{l} \widehat {x} _ {1} \\ \widehat {x} _ {2} \end{array} \right] = \left[ \begin{array}{l} 2 \\ 2 \end{array} \right] = p \\ A x = b & A \widehat {x} = p \end{array} \quad \begin{array}{c c} b _ {1} = 3 & \\ b _ {2} = 1 & \\ T = 1 & t \end{array}
$$

The measurements $b _ { 1 } = 3$ and $b _ { 2 } = 1$ are at the same time T ! A straight line $C + D t$ cannot go through both points. I think we are right to project $\boldsymbol { b } = ( 3 , 1 )$ to $p = ( 2 , 2 )$ in the column space of $A .$ . That changes the equation $A x = b$ to the equation $A { \widehat { \boldsymbol { x } } } = { \boldsymbol { p } } .$ An equation with no solution has become an equation with infinitely many solutions. The problem is that A has dependent columns and $( 1 , - 1 )$ is in its nulls pace.

Which solution $\widehat { \mathbfit { x } }$ should we choose? All the dashed lines in the figure have the same two errors 1 and -1 at time $T$ . Those errors $( 1 , - 1 ) = e = b - p$ are as small as possible. But this doesn't tell us which dashed line is best.

My instinct is to go for the horizontal line at height 2. If the equation for the best line is $b = C + D t$ , then my choice will have $\widehat { \pmb { x } } _ { 1 } = C = 2$ and $\widehat { \pmb { x } } _ { 2 } = D = 0$ . But what if the line had been written as $b = c t + d ?$ This is equally correct (just reversing $C$ and D). Now the horizontal line has $\widehat { \pmb { x } } _ { 1 } = { \pmb { c } } = 0$ and $\widehat { \pmb { x } } _ { 2 } = d = 2$ . I don't see any way out.

In Section 7.4, the "pseudoinverse" of A will choose the shortest solution to $A { \widehat { x } } = p$ Here, that shortest solution will be $x ^ { + } = \left( 1 , 1 \right)$ . We are arbitrarily choosing the nullspace component of the solution $x ^ { + }$ to be zero.

## Fitting by a Parabola

If we throw a ball, it would be crazy to fit the path by a straight line. A parabola $b =$ $C + D t + E t ^ { 2 }$ allows the ball to go up and come down again (bis the height at time t). The actual path is not a perfect parabola, but the whole theory of projectiles starts with that approximation.

When Galileo dropped a stone from the Leaning Tower of Pisa, it accelerated. The distance contains a quadratic term ${ \scriptstyle { \frac { 1 } { 2 } } } g t ^ { 2 }$ . (Galileo's point was that the stone's mass is not involved.) Without that $t ^ { 2 }$ term we could never send a satellite into its orbit. But even with a nonlinear function like $t ^ { 2 }$ the unknowns $C , D , E$ still appear linearly! Fitting points by the best parabola is still a problem in linear algebra.

Problem Fit heights $b _ { 1 } , \ldots , b _ { m }$ at times $t _ { 1 } , \ldots , t _ { m }$ by a parabola $C + D t + E t ^ { 2 }$

Solution With $m > 3$ points, the m equations for an exact fit are generally unsolvable:

$$
\begin{array}{c c} C + D t _ {1} + E t _ {1} ^ {2} = b _ {1} & \text {is A x = b with} \\ \vdots & \text {the m by 3 matrix} \\ C + D t _ {m} + E t _ {m} ^ {2} = b _ {m} & \end{array} \qquad \begin{array}{c c} A = \left[ \begin{array}{c c c} 1 & t _ {1} & t _ {1} ^ {2} \\ \vdots & \vdots & \vdots \\ 1 & t _ {m} & t _ {m} ^ {2} \end{array} \right]. \end{array}\tag{10}
$$

Least squares The closest parabola $C + D t + E t ^ { 2 }$ chooses $\widehat { \textbf { \textit { x } } } = \ ( C , D , E )$ to satisfy the three normal equations $A ^ { \mathrm { T } } A { \widehat { \mathbf { x } } } = A ^ { \mathrm { T } } b$

May I ask you to convert this to a problem of projection? The column space of A has dimension \_ . The projection of b is $\boldsymbol { p } = A \widehat { \boldsymbol { x } }$ , which combines the three columns using the coefficients $C , D , E$ . The error at the first data point is $e _ { 1 } = b _ { 1 } - C - D t _ { 1 } - E t _ { 1 } ^ { 2 }$ The total squared error is $e _ { 1 } ^ { 2 } + \_$ . If you prefer to minimize by calculus, take the partial derivatives of E with respect to $\_ , \_ ,$ . These three derivatives will be zero when $\widehat { \pmb { x } } = ( C , D , E )$ solves the 3 by 3 system of equations $A ^ { \mathrm { T } } A { \widehat { \mathbf { x } } } = A ^ { \mathrm { T } } b$

Section 10.5 has more least squares applications. The big one is Fourier seriesapproximating functions instead of vectors. The function to be minimized changes from a sum of squared errors $e _ { 1 } ^ { 2 } + \cdots + e _ { m } ^ { 2 }$ to an integral of the squared error.

Example 3 For a parabola $b = C + D t + E t ^ { 2 }$ to go through the three height $b = 6 , 0 , 0$ when $t = 0 , 1 , 2$ , the equations for $C , D , E$ are

$$
\begin{array}{l} C + D \cdot 0 + E \cdot 0 ^ {2} = 6 \\ C + D \cdot 1 + E \cdot 1 ^ {2} = 0 \\ C + D \cdot 2 + E \cdot 2 ^ {2} = 0. \end{array}\tag{11}
$$

This is $A x = b$ . We can solve it exactly. Three data points give three equations and a square matrix. The solution is ${ \pmb x } = ( C , D , E ) = ( { \bf 6 } , - { \bf 9 } , { \bf 3 } )$ . The parabola through the three points in Figure 4.8a is $\boldsymbol { b } = \mathbf { 6 } - \mathbf { 9 } t + \mathbf { 3 } t ^ { 2 }$

What does this mean for projection? The matrix has three columns, which span the whole space ${ \bf R } ^ { 3 }$ The projection matrix is the identity. The projection of b is b. The error is zero. We didn't need $\mathring { A } ^ { \mathrm { T } } A \widehat { \pmb { x } } = A ^ { \mathrm { T } } \pmb { b } ,$ , because we solved $A x = b$ . Of course we could multiply by $A ^ { \mathrm { T } }$ , but there is no reason to do it.

Will the least squares parabola stay the same, with all the error at the fourth point? Not likely!

## <sup>•</sup> REVIEW OF THE KEY IDEAS <sup>•</sup>

1. The least squares solution x minimizes $\| A \pmb { x } - \pmb { b } \| ^ { 2 } = \pmb { x } ^ { \mathrm { T } } A ^ { \mathrm { T } } A \pmb { x } - 2 \pmb { x } ^ { \mathrm { T } } A ^ { \mathrm { T } } \pmb { b } + \pmb { b } ^ { \mathrm { T } } \pmb { b } .$ This is E, the sum of squares of the errors in the m equation $( m > n )$

2. The best $\widehat { \mathbf { x } }$ comes from the normal equations $\boldsymbol { A } ^ { \mathrm { T } } \boldsymbol { A } \boldsymbol { \widehat { x } } = \boldsymbol { A } ^ { \mathrm { T } } \boldsymbol { b }$ . E is a minimum.

3. To fit m points by a line $b = C + D t .$ , the normal equations give C and D.

4. The heights of the best line are $\pmb { p } = ( p _ { 1 } , \dots , p _ { m } )$ . The vertical distances to the data points are the errors $\boldsymbol { e } = ( e _ { 1 } , \dots , e _ { m } )$ , A key equation is $A ^ { \mathrm { T } } e = \mathbf { 0 }$

5. If we try to fit m points by a combination of $n < m$ functions, the m equations $A x = b$ are generally unsolvable. Then equations $A ^ { \mathrm { T } } A { \widehat { \mathbf { x } } } = A ^ { \mathrm { T } } b$ give the least squares solution-the combination with smallest MSE (mean square error).
