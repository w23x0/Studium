## G5-P10-apostol-ext- 命名空间是否合法.md

*抽自小节：## 〇 裁定（进 SPEC / 不进 SPEC / 有条件进；一句话理由）；原文 14488 字符*

**有条件进 SPEC。** `apostol:ext-` 合法，但它表示的**不是**任务书猜测的「教材没有、为组织
图谱而加的扩展节点」，而是「**所指对象在第15章之外（第12章 / 第II卷），但第15章在正文里
点名征用了它**」——11 个节点的锚点全部落在第15章正文的引用句上，没有一条来自章外，
所以它们不是模型虚构，而是**章外依赖的记账位**；因此它与 `origin` **正交**，
「所有 ext- 必须标 origin:model」**是错的**（现有 9 个正确地标着 `source`），必须写成
反向规则：**ext- 节点的 origin 由「第15章有没有点名出处」决定，而不是由 ext- 前缀决定**。

一句话的判据差别：`ext-` 说的是**所指在哪里**，`origin` 说的是**statement 的内容从哪来**。

## G5-P11-需不需要「二次使用点复用」关系词.md

*抽自小节：## 〇 裁定（进 SPEC / 不进 SPEC / 有条件进；一句话理由）；原文 16007 字符*

**不新增关系词，但 S3 的决定性论证不成立，须换一条论证再进 SPEC。**
「复用」在数据里实际分裂成两个已有栏位分别承担的东西——前向引用由 `requires`（方向反写即可）承担，
论证模式的重复出现由 L2 的 `members` 承担（255 条成员引用、188 个不同下层 id 记的正是「同一模式在多节复现」）；
新增关系词会与 `members` 开第二套账，这才是不扩词的决定性理由。

S3 用的理由是「`sections` 是数组，57 个节点已靠它记多节出现」（`S3:66–68`）。
这条理由在 P09 裁定 `sections` = 语义 A（出处，**不是**被用到）之后失效：
语义 A 下 `sections` 恰恰**不**记第二使用点。裁决方向对，论证须替换。

## G5-P12-每个 statement 句子是否都必须被锚点管到.md

*抽自小节：## 〇 裁定（进 SPEC / 不进 SPEC / 有条件进；一句话理由）；原文 14955 字符*

**有条件进 SPEC，但条件是「不得要求每句都有锚」。**

一句话理由：抽样实测 10 节点 19 句，即使把 T1/T2/T3 三层证据池全算上仍有 4 句（21%）
完全无证据、6 句（32%）只有部分射程；这些句子多数是**模型的元评论与量词化概括**，
它们要么本来就不该由锚点承担，要么根本不可能在原文找到逐字依据 —— 强制「每句必有锚」
只会把这 10 句里的绝大多数逼成 D 型（硬凑一条邻近 quote，宣称覆盖而实际管不到），
把一个 grep 查不出但**人一眼能看出无锚**的缺陷，转译成一个**人也查不出**的假合规。
因此进 SPEC 的是它的对偶形式：**无锚句必须显式标记，而不是必须补锚。**
