## 逐个候选：为什么它是结构而不是话题

**`L2:closure-certificate-for-subspacehood`（封闭性证书）**
它是结构而非话题，因为它的内容不是「子空间」这个词，而是一份**有限待办清单及其为什么够**：十条公理里八条被两种机制处理掉（恒等式类自动继承、存在性类由非空见证元在 a=0 与 a=-1 处造出），只剩两条真算。话题式分组会把「所有子空间的例子」放在一起；本候选放进来的是判定动作在 15.03（多项式、解空间）、15.06（张成集）、15.14（S 垂直）三处的重复出现，其中 15.14 那次的价值恰在于它证明这套动作不依赖 S 本身是不是子空间。反例给的是 15.03 例 7 的「次数恰为 n 的多项式」——它跟「次数不超过 n」只差一个字，是全章最容易误判的对象。

**`L2:uniqueness-by-forcing-the-difference-to-zero`（唯一性定式）**
前两步（设两个、相减）在 15.04、15.08、15.13、15.14 四处逐字相同，第三步换零件（消去律 / 独立性 / 自正交）。它是结构的证据在反例侧：内积不唯一、张成集不唯一，恰恰因为第三步找不到「只有零元满足 P」的事实——同一套动作既解释了何时唯一性成立，也解释了何时它是假的。这是话题式分组做不到的：话题只能罗列成立的情形。

**`L2:read-off-a-coefficient-by-one-pairing`（配对读系数）**
15.11 的分量公式、Parseval、15.13 的 Gram-Schmidt 系数、15.14 的 s 垂直验算、15.15 的 Fourier 系数是同一份计算的五次出场。它不是「关于内积的一堆事」，因为它的内容是一个**替代策略**：n 次独立的一行配对取代解 n 元方程组，因而可以只求第 17 个系数不碰其余——这是话题不会告诉你的。反例用 15.07 例 7 划界：外形一样（打掉其余项读一个系数），机制不同（极限而非正交），而 15.07 全节没有内积可用。

**`L2:independence-by-killing-all-but-one-coefficient`（独立性骨架）**
骨架四步固定，只有「打项运算」需要现场发明；三次出场的打项手段分别是求导取值、归一化加极限、内积配对。它是结构而非话题，因为它给出的是**缺口的精确位置**：新家族的证明里哪一部分可以照抄、哪一部分必须自己想。反例是相依侧的全部论证——同一对概念，相反且严格更省力的结构（展示一条见证关系即可）。这个候选的 sections 只有两个（15.07、15.11），是全部 8 个里跨度最窄的，但两侧的打项机制截然不同（无内积 / 有内积），不是同一节的局部说法。

**`L2:proof-inheritance-by-auditing-what-the-old-proof-used`（证明继承）**
四处「证明见第12章」看起来是编辑省略，实际是同一个方法的四次执行：清点旧证明的实际依赖、对新场合的公理表做包含检查、宣布搬运有效。它是结构因为它的产物是一条**可预判的分界线**——清点结果显示 15.05–15.07 这条链完全不含度量概念，所以能预言哪些结论在无内积场合幸存。反例给的是本结构的失效模式（复情形 Cauchy-Schwarz 需补一步、复三角不等式需另证交叉项为实、指数函数独立性用到非公理输入），三种典型漏项形态。

**`L2:construct-the-orthogonal-part-by-subtracting-projections`（减投影造正交件）**
Gram-Schmidt 递推步、正交分解的 s 垂直 = x - s、逼近定理里 x - t 的拆分，是同一套「先减、再配对验证、再升级到张成」的三次出场；沿单个元素的投影是退化情形。它是结构因为它把**存在性证明变成算法**：定理 15.15 的存在性一半就是这套减法的显式公式，因此 15.15 的两个例子能真算。反例区分了「S 垂直存在（定义，对任意子集）」与「减投影能做（构造，需有限维）」，这两者被混同是常见误解。

**`L2:expand-the-squared-norm-and-classify-the-cross-terms`（平方展开定式）**
先平方、双线性展开、只处置交叉项；交叉项三种归宿（正交归零 / Cauchy-Schwarz 上界 / 复情形先证为实）。它是结构而非「所有和范数有关的」，判据就写在反例里：定理 15.9 的性质 (a)(b)(c) 与三角不等式并列在同一定理内，却被排除，因为它们里面没有两个不同元素相加、没有交叉项，本定式的核心判断在它们身上空转。分诊表是双向的——「想要等式就先安排正交性」这个反向用法，是 15.15 逼近定理的实际组织方式。

**`L2:testing-infinite-objects-through-finite-windows`（有限窗口定式）**
每个定义都在有限子族上下判断、再对全部有限子族取量词：相依的见证族有限、独立性是对全部有限子族全称、张成只许有限组合、正交集只管相异对、Gram-Schmidt 每步只碰有限个前项故不需有限维。它是结构因为它产出一份**哪些结论能过无限关的对照表**（相依/独立/张成/正交/Gram-Schmidt 能过；维数/基存在/正交分解/投影/最佳逼近不能过），从而能判断某处的有限维假设是不是可去的装饰——这正是 15.13 与 15.14 措辞差异的来源。反例是全体多项式空间：每个有限窗口都极好，整体却没有有限基、没有维数。

## 我最不确定的候选

**`L2:read-off-a-coefficient-by-one-pairing` 与 `L2:construct-the-orthogonal-part-by-subtracting-projections` 之间可能被判为层塌缩（死因 5）。** 两者共用同一条系数公式 `(x, y_j)/(y_j, y_j)`，成员上也有交叠（`d:coefficient-that-cancels-the-projection-component` 同时出现在两个候选里）。我最终保留两个，理由是动作方向相反：前者是**读出**——等式已给定，配对是为了把和式塌成一项、把未知量解出来；后者是**造出**——目标元素还不存在，减法是为了制造一个满足正交约束的新元素，而配对在这里只是事后验证。同一个公式在两处扮演的是解方程与构造解两种角色。但我承认这是我全部 8 个里最经得住反驳的一处，如果审计只留一个，我建议留 `construct-the-orthogonal-part`（它带算法与存在性证明，覆盖面更宽），并把 `read-off-a-coefficient` 的两条独有价值（只求单个系数不碰其余、出手前三项检查含「是否已规范化」）并入前者的 `abstraction_gain`。

次不确定的是 `L2:independence-by-killing-all-but-one-coefficient` 的 sections 只有两个（15.07、15.11），刚够门槛。若审计认为 15.11 那次出场（定理 15.10）已被配对定式覆盖，本候选会退化为 15.07 的局部说法。我的辩护是骨架的价值恰在于两处打项机制不同，但这个辩护依赖审计接受「机制不同、骨架相同」算作跨小节。

## 主动放弃的候选（4 个，含放弃理由）

**（1）「对生成元成立即对整个张成成立」的升级定式。** 出场至少三次：`d:orthogonality-to-generators-extends-to-their-span`（15.13）、`d:orthogonality-to-the-basis-extends-to-all-of-s`（15.14）、`d:orthogonality-to-a-set-equals-orthogonality-to-its-span`（15.14），成员和小节都够。放弃原因：它作为独立候选与 `L2:construct-the-orthogonal-part-by-subtracting-projections` 的第三步完全重合，而且它太短——整套动作只有一步，抽象增益基本只是「线性条件可以只在生成元上验」这一句。我把它并入减投影候选的 statement 与 members，并把它的边界价值（哪些条件不能这样升级）写进那个候选的反例。**给下游的提示：如果另有代理把它单独提出来并且写出了「哪些非线性条件不能升级」的完整反例族（范数为 1、Cauchy-Schwarz 取等条件、正交集只管相异对因此张成对自身不正交），那个版本可能比我的处理更好，值得优先于我的合并方案。**

**（2）「取特殊标量从公理榨出具体结论」的定式。** 素材扎实：15.06 里取 a=0 得零元、取 a=-1 得负元；15.10 里取 c=0 得 (O, y) = 0（`d:zero-element-has-zero-inner-product`）；15.04 定理 15.3(a)(b) 也是这一路。放弃原因是抽象增益写不硬：能写出来的最好版本是「公理里有自由标量就去代特殊值」，这更接近一条通用的做题习惯，而不是本章特有的结构；而且它的两处主要出场已经分别落在候选 1（零元与负元的获得）和候选 3（分母非零的保证）内部，单独立项会让审计合理地判为层塌缩。

**（3）「把待证结论化归为单个元素等于零」的定式。** 与候选 2（唯一性定式）的第二、三步是同一件事，只是把「差」换成「任意待证的差」。放弃原因：它是候选 2 的真子集，且比候选 2 更空洞——候选 2 至少给出了「去清单里选一条禁令 / 选不出就转去找反例」这个可操作的分叉，而这个版本只剩下「把目标改写成 = O」这一句改写动作。

**（4）「用一个反例点掉公理中某个假设不可省」的定式。** 出场处很多：`d:15-10-nonzero-hypothesis-is-essential`、`d:subspace-nonempty-requirement`、`d:weight-function-must-be-positive`、`d:parseval-requires-an-orthonormal-basis`、`d:projection-along-an-element-needs-a-nonzero-direction`、`d:angle-requires-nonzero-elements`。放弃原因：这是**教材的写作手法**，不是读者验证一个数学对象时执行的动作。收它会与 SPEC 要求每个候选自带 `boundary` 的机制撞车——那等于把审计机制本身抽象成一个被审计的候选。不过这些节点的信息没有浪费：它们被分散用作我 8 个候选的反例材料（其中 5 条直接出现在 `boundary` 里）。
