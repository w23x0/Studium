碰撞暴露出来。已把前者的 Apostol 锚点换成真正点名独立性的那 83 字符分句，后者保留原锚点

（`apostol:norm` / `apostol:norm-notation`，`apostol:linear-span` / `apostol:linear-span-notation-l-of-s`），
