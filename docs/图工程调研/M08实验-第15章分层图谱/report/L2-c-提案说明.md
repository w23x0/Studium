## 逐个候选

### C1 `L2:existence-costs-a-representation-uniqueness-is-free`
分解定理的两半不对称：唯一性免费，存在性要先付一个表示。

**为什么是结构而不是话题。** 「唯一分解」是话题；「每条唯一分解定理都由一半只用正定性、一半必须先造表示的两块拼成，且假设全挂在后一半上」是结构——它对定理的**内部构造**做了断言，可以在每一条上检验，而且能预测新定理的假设位置。它不是 `x:orthogonal-decomposition-of-the-ambient-space` 的换名：那个节点说的是「有唯一分解」，这个说的是「这条定理的两半从哪来、贵在哪」，并把 Strang 的法方程与 Apostol 的正交基放进同一个格子作为「存在性的两种付款方式」。

**反例。** C(-1,1) 上 S = 全体多项式：唯一性论证一字不改成立，存在性彻底失效（多项式在 L2 意义下稠密 ⇒ S 垂 = {0}，非多项式的 f 不存在分解）。这是「有限维」而非「是子空间」才是硬前提的直接证据。

### C2 `L2:orthogonality-as-a-certificate-of-optimality`
正交性是最优性的证书：把「求最小」换成「验垂直」。

**为什么是结构。** 这是本视角最核心的一条：它断言一个**判据**，而判据是可以被反向使用的。Apostol 正向用（先有投影，再证它最近），Strang 反向用（先要求垂直，解出系数得法方程）。同一条判据在两本书里承担相反的功能，这正是「同一个原理」的证据，而不是两处巧合。

**跨教材，也是最容易踩「同名异物」的一条。** 我刻意没有把 Apostol 的 `apostol:theorem-15-16-approximation-theorem` 与 Strang 的最小二乘直接对等，而是通过已有的 `x:least-squares-is-a-projection`、`x:orthogonality-of-the-residual` 转手——差异部分（Strang 的最小二乘主体在 4.3，不在 manifest 覆盖范围）由那两个 `x:` 节点自己承担，我不重复声明。

**反例。** 一致范数下的最佳多项式逼近：外形与 15.15 例 2 完全相同，但 sup 范数不由内积诱导，正交判据无主词，最优性刻画换成等振荡。标为 origin: model 性质的推断（书里没写这个反例），但 Apostol 侧「距离 = 范数 = 内积开方」这条链是逐字可查的。

### C3 `L2:orthogonalizing-first-decouples-the-coefficients`
先正交化让系数互不干扰。

**为什么是结构。** 「正交基算起来方便」是话题。这条给出机制并把它量化成一个可检查的特征：**系数公式里是否出现不同方向之间的交叉配对**。有交叉 ⇒ 耦合 ⇒ 必须联立；无交叉 ⇒ 逐个独立算。Strang 的 A^T A 非对角元素与 Apostol 的「与 e_j 配对后和式只剩一项」被认成同一件事的两个记法。

**反例。** e_1 = (1,0)、e_2 = (1,1)，x = (0,1)：套 c_j = (x,e_j)/(e_j,e_j) 得 (1/2,1/2) ≠ x，正确答案是 c_1 = -1、c_2 = 1。这个反例的作用是说明「分量 = 内积」在非正交基下**是错的**，不只是不方便。

### C4 `L2:peel-off-the-projection-to-manufacture-a-new-direction`
逐步剥离投影：用一个局部动作制造互不干扰的方向。

**为什么是结构。** 它认出 Strang 的 e = b - x-hat·a、Gram-Schmidt 的递推步、Apostol 的 s 垂 = x - s 是**同一个动作**在不同规模上的执行（一次 / 递推 / 对整个子空间一次），并指出系数不是任意的而是「恰好抵消该方向分量」的那一个。

**最有价值的一条边界。** 这个动作的正确性依赖它自己维护的不变量（已产出部分两两正交），而不是「减投影」这个形式。拿一族非正交方向逐个减投影，减完不正交。这一点在两本书里都没被单独说出来，但从 15.13 的 (y_{r+1},y_j) 展开只剩两项可以逐字看出来。

### C5 `L2:self-orthogonality-forces-zero-the-uniqueness-engine`
自正交迫零：这一层所有唯一性论证的同一台引擎。

**为什么是结构，且与 C1 不重复。** C1 说的是「唯一性那一半便宜」这个**格局**；C5 说的是驱动它的**引擎**，并指出这台引擎在别处也点火：Gram-Schmidt 的唯一性（`d:z-r-is-orthogonal-to-itself`）、Strang 的「行空间到列空间上 A 可逆」。C1 若单独存在，会漏掉「同一台引擎跨越三个看起来无关的定理」这件事；C5 若单独存在，会漏掉「存在性的代价」这半边。两条都保留，但我把 C1 的勾股记账部分删掉了，避免与 C7 塌缩。

**反例。** Strang 4.1 例 2 的两面墙（逐字可查）+ 不定配对下非零自正交元素存在（数学可查）。后者精确指出引擎挂在内积公理 4 上。

### C6 `L2:the-split-belongs-to-the-subspace-not-to-the-basis`
分解属于子空间，不属于用来算它的基。

**为什么是结构。** 三处不变性（Apostol 投影不依赖所选正交规范基、Strang 同一平面不同列基给同一个 P、Gram-Schmidt 输出在相差标量因子下由输入决定）被认成同一条，且给出一个可执行的分类动作：手上这个量只依赖对象与子空间，还是也依赖表示？

**反例是我认为这条候选最硬的部分。** 这条不变性**不能**延伸到分量：`d:components-depend-on-the-ordering-not-only-on-the-basis` 说得很清楚。我没有把那个 d 节点收进 `members`（它不是这条不变性的实例，是它的边界），只在 boundary 里引用。这一点请审计特别看：把边界证据误收成成员，正是死因 2 的软性版本。

### C7 `L2:orthogonal-splitting-makes-the-norm-additive`
正交分解使平方范数可加：交叉项消失既是结论也是判据。

**为什么是结构。** 四处勾股（15.14 的 (15.17)、Parseval 范数形式、逼近误差恒等式、Strang 的 ||p||^2+||e||^2=||b||^2）是同一次展开的四次落地，而且交叉项为零 ⟺ 两块正交，使这条记账反向可用作正交性检验。它还接上了严格最小性的来源：多出来的正是 ||s-t||^2，其严格正性来自范数正定性。

**反例。** (1,1) = (1,-1) + (0,2)：合法分解，但 2 ≠ 2+4，差额 -4 恰是被漏掉的交叉项 2·(-2)。附两条量词边界：Parseval 需要正交**规范**基（只正交时分母不能省）；(15.11) 的共轭来自 Hermite 对称而非齐次性。

### C8 `L2:orthonormal-systems-make-approximation-incremental`
正交系使逼近可增量推进。

**为什么是结构。** 这是 C3 的解耦机制在**时间维度**上的兑现：解耦 ⇒ 加一维不动旧系数 ⇒ 逼近从一次性求解变成可增量、可回滚的过程。Apostol 的两个逼近例子都在无声地用它（Legendre 计算里奇偶性使若干投影项为零；sin(pi t) 的最佳线性逼近同时是最佳二次逼近）。

**为什么它是唯一单侧的候选。** Strang 侧对应的东西是 4.3 结尾那句「事先把列正交化，A^T A 就是对角的，x-hat 就好算」以及 4.2 B 的 recursive least squares 更新公式——两处都在 manifest 覆盖之外，没有可用的 `strang:` id。按「编造成员 id 是最严重缺陷」，我宁可让这条只挂 Apostol 侧，把 Strang 侧的对应关系写在 boundary 的文字里（非正交基下加一列要重解整个法方程）。

**反例。** 单项式基下从 n=1 升到 n=2 全部系数重算（说明这条性质来自正交性，不是逼近问题自带的）+ 「若干系数为零」不等于「饱和」：sin(pi t) 例中 (f,phi_0) = (f,phi_2) = 0，但 (f,phi_3) ≠ 0，扩到次数 3 仍严格改进。

## 最不确定的候选

**C6（分解属于子空间，不属于基）**，两个理由。

一，它离「伪抽象」最近。三个成员实例里，Apostol 的「投影不依赖所选正交规范基」本身就是一个 `d:` 节点的原话，Strang 的 P_2 = P_3 是书里一句顺带的话。审计 B 完全可以判它是「把一个已有的 d 节点换个大点的名字」。我保留它的理由是它的**分类动作**是新的：它把「哪些量可以换基重算、哪些不能」变成一个先行判断，并给出一个廉价自检（两组基算同一投影不一致就是算错）。但这个理由是否够抵掉塌缩风险，我没有把握。

二，把 `apostol:orthogonal-sequence-unique-up-to-scalars` 收进 `members` 是我最不确定的一次归属。它讲的是「过程的输出由输入序列决定，不由过程中的选择决定」，我认为这与「投影由子空间决定，不由基决定」是同一条不变性的两个实例；但也可以论证它属于 C5（它的证明用的就是自正交迫零）。它同时出现在 C5 和 C6 的可能归属里——我最终只在 C6 收它、在 C5 收它证明里的 `d:z-r-is-orthogonal-to-itself` 与 `d:uniqueness-splits-the-competitor-into-span-plus-multiple`，用「结论 vs 证明步骤」来分。这个切法可能被判为牵强。

次不确定的是 **C2 的一致范数反例**：这个反例书里没有，是我加的（等振荡/Chebyshev 定理不在这两章材料内）。数学是对的，但它超出了本实验的文本范围，属于 origin: model 性质的断言。我在 boundary 里写明了 Apostol 侧可逐字核对的部分（距离 = 范数 = 内积开方）与不可核对的部分。

## 主动放弃的候选（5 个）

1. **「维数配平：分解两侧的维数加起来是全空间的维数」。** 看起来正是本视角要的东西（分解 ⇒ 计数），但 Apostol 侧**没有** dim S + dim S 垂 = dim V 这条结论——他的 S 垂 对任意子集都定义，可能无穷维，他只在 15.15 对有限维 S 拿到分解，从不配平维数。Strang 侧配平是核心（r + (n-r) = n）。强行合并会造出一条只有 Strang 一侧成立的「共同原理」，且直接撞上 `x:orthogonal-subspaces-versus-complements` 与 `x:dimension-versus-rank` 已经处理过的差异。这是我认为最诱人也最危险的一条，放弃。

2. **「约束下取极值 = 变分/拉格朗日条件」。** 本视角的任务书提到「在约束下取极值」。但这两章材料里**没有**任何变分论证、没有拉格朗日乘数、没有导数为零；Apostol 的最优性完全由勾股不等式给出，Strang 的最优性由垂直给出（4.2 B 那个例子里他确实用了 dE/dx = 0，但那是一维平均，不是一般框架）。把「正交条件」包装成「一阶必要条件」会引入两本书都没有的机器，成员只能靠编。放弃，其内容已由 C2 以「判据」而非「变分」的形式覆盖。

3. **「投影算子的幂等性 P^2 = P 与 I - P 给出互补分解的算子形式」。** 这是分解原理最漂亮的表达（分解 ⟺ 幂等算子对），但 Apostol 第 15 章**没有**算子、没有线性映射、更没有 P；`报告/横向-跨教材差异.md` 2.5 已经把这条判为「Apostol 不能讲」。做成 L2 会得到一个只有 Strang 一侧有成员的候选，成员数够但跨教材是假的。放弃。

4. **「Gram-Schmidt 作为一个独立结构」。** 它作为独立候选没有抽象增益——它就是一个具体算法。我把它拆进 C4（局部剥离动作）与 C3（解耦的代价来源），两处都从它身上取不同的东西。作为一个整体收录只会与 `apostol:gram-schmidt-process` 这个 L1 节点塌缩。

5. **「直和分解 vs 正交直和分解」的辨析。** 一个合法结构（非正交的直和也给唯一分解，但不给勾股记账、不给最优性），但它的内容已经被我拆成 C7 的反例（(1,-1)+(0,2)）与 C3 的反例（非正交基仍有唯一分量）。单列一条会与这两条重叠 70% 以上，且 Apostol 侧没有「直和」这个词，成员只能靠 `apostol:uniqueness-of-components` 硬撑。放弃。

## 没有覆盖到的（不静默截断）

- Strang 4.3（最小二乘主体）、4.4（Gram-Schmidt / QR）不在 manifest 覆盖范围内，因此本层所有涉及「Strang 怎么算最小二乘」「Strang 的 Gram-Schmidt」的对应关系都只以文字形式出现在 boundary / abstraction_gain 里，没有成员 id 支撑。C8 因此单侧。
- 复 Euclidean 空间下这些分解原理的形态（Hermite 对称使 (x,x) 为实、共轭出现在 Parseval 而非齐次性）我只在 C7 的边界里带了一句，没有做成独立候选——它属于「同一原理在复情形的形态」而非「同一原理跨场合」，更像 H-in 辨析的活。
