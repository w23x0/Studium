## §4 `:54` `d:infinite-dimensional-operational-criterion-arbitrarily-large-independent-sets`

### 4.1 逐条断言分解

| 编号 | 逐字断言 | 类型 |
| --- | --- | --- |
| C1 | **Equivalently**, V is infinite dimensional when for each n one can produce n independent elements of V. | 等价性断言(双向) |
| C2 | If V had a basis of k elements, Theorem 15.5 would make every k+1 elements dependent | 推理步 |
| C3 | contradicting the criterion at n = k+1 | 矛盾点 |

### 4.2 先报一处独立缺陷:C1 的「Equivalently」是过度断言(死因 1)

C2+C3 证明的是**一个方向**:判据成立 ⇒ V 无穷维。
(设判据成立;若 V 有 k 元基,Thm 15.5 给出「任 k+1 个元相依」,而判据在 n=k+1 处给出
k+1 个独立元,矛盾;另外 V={O} 时判据在 n=1 处即失效,因为 {O} 按 15.07 Example 3 相依,
所以判据也排除了定义里的 `or if V consists of O alone` 那一支。这一方向是完整的。)

**反方向「V 无穷维 ⇒ 对每个 n 都有 n 个独立元」在第 15 章内不可证。**
