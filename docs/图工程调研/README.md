## 这份资料夹的用途

这里集中保存与 Agent 图式工作流、上下文组织、状态图和持久化执行有关的研究资料。它用于帮助后续理解和讨论，不是 Studium 当前架构、技术选型或实施计划。

当前阶段只做三件事：

1. 说明“图工程”这一新术语与已有工程概念的关系。
2. 保存可信的入门资料、正式研究和框架文档入口。
3. 记录它可能与 Studium 哪些产品问题有关，但不提前把尚未确认的模块画成执行图。
4. 为模块审查后的“上下文工程 + 图工程”联合设计准备入口。

当前阶段明确不做：

- 不设计 Studium 的节点、边、状态或路由。
- 不决定使用 LangGraph、Microsoft Agent Framework、Temporal 或其他运行时。
- 不把产品模块直接等同于执行节点。
- 不以这份调研反向改变正在修正的模块边界。
- 不把 M11 或其他单一文件预设为全系统上下文/图运行模块。
