# Abel 分部求和引擎的双出口迁移:幂级数边界行为(Abel 极限定理/Abel 可和性)与 Fourier 级数点态收敛(定理10.19 = Dirichlet 核估计)

**类型**:迁移方向 · **层级**:L3 · **来源**:模型综合(候选,已过双审计)

## 共同机制

L2-S13 提炼的兑换原理(振荡×衰减 → 有界×可裂项,唯一兑换机制为恒等式 10.52)在后续分析中恰有两个主要买家,且第10章已为两者各预装了关键零件。出口一:幂级数边界理论。Abel 极限定理——若 Σa_n 收敛则 f(x)=Σa_n x^n 在 x→1⁻ 时趋于 Σa_n——的标准证明就是对 Σa_n·x^n 施行同一次分部求和(a_k 的部分和收敛充当有界因子,x^n 单调递减充当衰减因子,即 L2-S02 权衡曲线上 Abel 判别法一端的连续参数版);第10章用 Mercator 级数在 x=1 取值得 log 2(节点 logarithmic-series 与 alternating-harmonic-series 的衔接)正是该定理的胚芽实例,而把此过程反读即得 Abel 可和性——第一个能给发散级数(如 Σ(−1)^n ↦ 1/2)赋广义和的正规求和法。出口二:Fourier 级数。定理10.19 的估计 |Σ_{k=1}^n e^{2ikθ}| ≤ 1/|sin θ| 迁移后就是 Dirichlet 核部分和的一致有界性,与 Dirichlet 判别法(10.17)组合立即给出:系数 b_k 单调趋 0 时 Σb_k sin kθ、Σb_k cos kθ 在每个闭区间 [δ, 2π−δ] 上收敛——这是 Fourier 理论中三角级数点态收敛的第一批非平凡定理,其全部逻辑成分已在第10章到位。

## 抽象增益

各成员未陈述的内容:(1) 身份识别——定理10.19 在第10章内貌似一道孤立的复数练习(仅为 Dirichlet 判别法供例),迁移视角断言它就是 Dirichlet 核估计本身,是被提前放进第10章的 Fourier 零件,这个跨域身份无任何节点或 L2 结构陈述;(2) L2-S02 的权衡曲线两端在迁移后分道扬镳且各成一个领域:Dirichlet 端(有界部分和)长成 Fourier 点态收敛理论,Abel 端(收敛部分和)长成幂级数边界理论与可和性理论——『一条曲线、两个未来』的分岔结构只在迁移层可见;(3) 可和性反读:第10章只用引擎判收敛,迁移后同一恒等式反向用于给发散级数定义广义和,工具的语义从『判定』翻转为『定义』,这一翻转是任何成员都未包含的可能性。

## 适用条件

适用于一切『乘积型级数、一因子提供有界振荡、另一因子提供单调衰减』的目标场景:幂级数在收敛圆周上的取值与求和法理论、系数单调的三角级数、Dirichlet 级数 Σa_n n^{-s} 的收敛半平面理论(分部求和同样是其标准工具)。

## 边界与反例

目标域(Abel 定理属幂级数章、Fourier 级数属卷2/后续课程、可和性理论超出全书)均超出第10章,属模型知识外推。内在失效边界有三处:(1) 定理10.19 的界 1/|sin θ| 在 θ→0 时爆破,故迁移只买到内闭区间上的收敛,不给出含 0 邻域的一致收敛——Σ sin(nθ)/n 在 (0,π) 点态收敛但在 θ↓0 不一致,极限函数 (π−θ)/2 在 0 处跳跃为见证;(2) Abel 极限定理不可逆:Σ(−1)^n 发散但 Abel 可和于 1/2,逆命题需追加 Tauber 型条件(如 n·a_n → 0),这条单向性是迁移后才出现的新现象;(3) 引擎只处理『单调衰减』因子,系数非单调的 Fourier 级数(一般 L² 理论)完全超出此通道,需 Parseval/测度工具。

## 教学用途

两个直接用途:讲 Abel 定理时,让学生先复述 10.18 的证明再自行改写出 Abel 定理证明,体会『同一引擎换参数』;讲 Fourier 级数入门时,把定理10.19 重新命名为 Dirichlet 核估计并要求学生仅用第10章工具证明 Σ sin(nθ)/n 在 [δ, π] 收敛——这向学生证明 Fourier 收敛理论的第一步不需要任何新分析工具。
