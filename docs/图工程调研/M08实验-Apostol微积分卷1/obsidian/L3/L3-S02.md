# 标尺测量认知:判定 = 在“基准族 × 耦合精度”二维网格上给未知对象定位,“不可判”是分辨率读数而非失败

**类型**:思维框架 · **层级**:L3 · **来源**:模型综合(候选,已过双审计)

## 共同机制

把“这个复杂对象是否收敛”改写为测量问题:不直接分析对象,而是把它钉到一个单参数的、行为完全已知的参照对象族上,读出它相对族内临界参数的坐标。任何一个判别法的解剖结构都是两个正交选择的组合:选哪把标尺(几何族 x^n / zeta 族 n^{-s} / 一个具体积分 ∫f),以及耦合多紧(逐项优超 < 极限比 < 渐近展开)。L2-S01/S06 描述的是标尺轴:判别力偏序来自标尺分辨率递增(几何→zeta→n log n);L2-S19 描述的是耦合轴:同一根积分标尺在三档耦合精度下分别输出判敛、极限值、渐近展开。L2-S03 则表明测量仪器可整体搬运:字典把全套基准库运到瑕积分域,测量策略原样复用。在此视角下,“L=1 不可判”不是工具失灵而是一次成功的测量:它读出“对象落在本标尺两档刻度之间”,并据此规定下一步——换更细的标尺或收紧耦合。

## 抽象增益

L2-S06 只在正项级数内部说“判别力=基准分辨率”;L2-S19 只说一根标尺有三档读法。二者都没有说出的是二维分解本身:标尺轴与耦合精度轴正交,S01 的升级链是沿标尺轴的移动,S19 的三档读法是沿耦合轴的移动,全章判别法恰好填充这张网格(且预言 10.10 渐近比较、Gauss 判别法各自占据的格点)。另一条新断言是原则性的负面结论:相消型现象被证明地排除在测量范式之外——比较对变号级数不是“不够用”而是“不成立”(有上述反例)——这条范式边界在 S02、S06 中都只各持一半,从未合并陈述。

## 适用条件

适用于一切满足两个条件的分类问题:(a) 存在单参数已解实例族稠密地扫过各种行为(指数衰减、多项式衰减);(b) 存在保序耦合把未知对象与族成员挂钩——在本章即非负性或取绝对值保证的优超/极限比。超出级数:瑕积分(S03 已实现)、以及后续章节的收敛半径(仍是几何标尺)。

## 边界与反例

两条精确边界:(1) 耦合必需符号控制,否则测量原理整体失效而非精度下降——a_n = −1(对所有 n)满足 a_n ≤ 1/n² 且 Σ1/n² 收敛,但 Σa_n 发散:没有非负性时优超关系不传递任何信息。因此条件收敛现象(L2-S02/S13 的领域)在测量范式之外,Abel 机制不是更细的标尺而是完全不同的原理(相消,不是尺度);(2) 不存在完备的可数标尺族:Σ1/(n log n) 落在全部 zeta 刻度之间,加细到 Gauss 尺度后 Σ1/(n log n (log log n)²) 又落进新缝隙——已知不存在“收敛最慢的级数”,故升级链原则上不终止,任何有限标尺库的判定系统必有“未知”输出。

## 教学用途

消解“该用哪个判别法”的死记硬背:先目测通项的衰减类型(指数型/多项式型/带对数修正),直接选临界参数最近的标尺;把每次 L=1 当作数据记录下来,它就是下一步的路标。同时为幂级数章铺路:收敛半径 = 几何标尺测量的系统化。
