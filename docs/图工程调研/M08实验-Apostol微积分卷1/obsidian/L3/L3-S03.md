# 同构—字典—类比三级迁移:按保真度分级的跨域定理搬运策略,保真度等级决定认识义务(引用/查表/重证)

**类型**:思维框架 · **层级**:L3 · **来源**:模型综合(候选,已过双审计)

## 共同机制

本章靠三对跨域翻译运转,它们不是同一种东西,而是按保真度严格分级的三级:(a) 同构级——L2-S05 的数列↔级数翻译由显式互逆算子对(部分和 Σ / 差分)给出,无损且双向,任何定理自动过界(10.1 ↦ 10.7 即一次自动生成),使用义务仅为“引用”;(b) 字典级——L2-S03 的级数↔瑕积分翻译逐词条成立、证明骨架相同,但带有认证过的失效清单(第 n 项判别法不过界),使用义务为“先查失效清单再搬运”;(c) 类比级——L2-S13 的 Abel 分部求和↔连续分部积分、L2-S19 的矩形不等式桥,只搬运证明思路、零定理自动过界,10.17/10.18 虽“长得像”分部积分论证仍须从头证明,使用义务为“借骨架、重新证”。三对翻译还可复合成一张网:数列↔级数↔瑕积分,L2-S10 正利用了复合(10.23 = 连续化的 10.7 = 翻译两次的 10.1),而复合链的整体保真度由最弱一环决定。

## 抽象增益

每个 L2 成员只记录一对翻译各自的内容;没有任何一个陈述保真度分级本身,更没有陈述“等级 ⟹ 认识义务”的对应(同构=引用、字典=查表、类比=重证)与“三对翻译可复合、整链保真度取最弱一环”这两条系统级规则。此外把 L2-S03 的一条局部观察升格为通用策略:翻译的失效点不是缺陷而是探针——第一个不过界的命题精确定位两域的结构差异(离散强制采样 vs 连续测度容忍尖峰),因此检验任何新类比的正确起手式是主动寻找其失效点。这三条在 L2 各结构中均无承载。

## 适用条件

适用于任何面对两个平行理论(离散/连续、实/复、有限/无穷)的场合:动笔证明前先在迁移网上定位目标命题,按所在翻译对的保真度等级决定花多少力气。对本书尤其实用:幂级数、Fourier 级数、多元积分各章将重演这三个等级。

## 边界与反例

失效模式恰是等级误判,两个方向各有具体反例:(1) 把字典当同构会生产假定理——定理 10.6 的逐字翻译“∫₁^∞ f 收敛 ⟹ f(x)→0”为假(在 n+1/2 处放置宽度递缩、高度为 1 的尖峰,积分收敛而 f 不趋 0),这正是失效清单存在的意义;(2) 把类比当字典会凭空引用——连续分部积分有边界项与可微性假设,在离散侧无对应物,不能引用任何 ∫fg′ 的定理来对 Σa_k b_k 下结论。另一限制:同构级 S05 只对敛散问题无损,对求值几乎无增益(把“求 Σ1/n²”翻译成数列问题不产生任何新工具)。

## 教学用途

教会学生对一切“类比”提出标准质询:到底什么东西过界、失效清单在哪、我的使用义务是引用还是重证。这直接支持后续学习:遇到新的平行结构(如级数↔无穷乘积)时,第一件事是探测它的第一个不可翻译命题,以确定其等级。
