# 单调有界归结论证(Monotone–Bounded Reduction to Axiom 10)

**类型**:证明模式 · **层级**:L2 · **来源**:模型综合(候选,已过双审计)

## 共同机制

本章所有"极限存在性"证明共享同一骨架:把目标对象改写为(或分解出)一个单调序列,再证其有界,然后引用定理 10.1——它是最小上界公理(Axiom 10)在序列语言下的唯一出口——一次性获得极限存在。具体实例:定理 10.7 中非负项级数的部分和自动递增,收敛归结为有界;积分判别法(10.11)证明中 {s_n} 与 {t_n} 都单调递增,由夹逼不等式 Σ_{k=2}^n f(k) ≤ ∫_1^n f ≤ Σ_{k=1}^{n-1} f(k) 把两者的有界性互相传递;Leibniz 法则(10.14)对不单调的交错部分和,拆出偶子列 {s_2n}(递增)与奇子列 {s_{2n-1}}(递减),分别单调有界后再证两极限相等;定理 10.23 中 f≥0 使部分积分 I(b) 关于 b 单调,是同一论证的连续变量版本。论证义务总是精确分解为两个可独立验证的部分:(i) 单调性来源(非负性、递减假设、奇偶拆分),(ii) 一个界。

## 抽象增益

任何单个成员只陈述"某类对象在某条件下收敛";模式层说出的新事实是:本章全部三个充要型收敛准则(10.1、10.7、10.23)与两个存在性定理(10.11、10.14)的极限存在性都来自同一唯一来源——最小上界公理经定理 10.1 的一次封装——且五个证明的差异仅在于各自如何制造"单调性 + 有界性"这两个义务(非负性、夹逼不等式、奇偶拆分、非负被积函数)。这条"存在性只有一个出口"的断言在任何单个定理的文本里都不存在。

## 适用条件

对象本身或其可控子结构(奇偶子序列、部分积分函数)能证单调时适用:非负项级数、正项级数与其积分伴随、满足 Leibniz 条件的交错级数、非负被积函数的无穷积分。

## 边界与反例

部分和不单调且无单调子结构时失效:对一般复项级数(如 Σ e^{2ikθ}/k)既不能直接用也不能奇偶拆分,必须改用 Abel 分部求和模式。单调性假设不可删:{(-1)^n} 有界但不收敛。此外该模式只给出极限的存在性,不给出和的数值——交错调和级数经此法只知收敛,求出和为 log 2 还需另外的论证(Euler 常数)。

## 教学用途

教学生把"证收敛"任务标准化为两个检查项:哪里来的单调?哪里来的界?学生遇到新对象(如习题中的第二类瑕积分)可自行复制该骨架;也解释了为何 Leibniz 法则的证明要拆奇偶子列——这是对不单调对象强行制造单调性的标准补救。
