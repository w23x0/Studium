# 正项级数判别法 = 基准尺度族上的比较,判别力由基准分辨率决定

**类型**:结构模型 · **层级**:L2 · **来源**:模型综合(候选,已过双审计)

## 共同机制

所有正项级数判别法都是同一台机器的实例:定理 10.7(单调部分和的有界性准则)是唯一的动力源,其余判别法 = 选一个已知敛散的基准级数 + 一种耦合方式(逐项不等式 a_n ≤ c·b_n、极限比、渐近相等)把未知级数钉到基准上。判别法之间的差异不在逻辑而在基准尺度:根值/比值判别法以几何级数 ∑x^n 为基准(原文明言二者『实际上是比较判别法的特例』),测的是指数衰减率;zeta 函数 ∑1/n^s 基准测多项式衰减率;Raabe/Gauss 判别法把比值展开到 1 − A/n + O(1/n^s),测的是 1/n 尺度上的精细结构。

## 抽象增益

单个判别法节点只陈述自己的充分条件,root-test/ratio-test 节点甚至各自记录了 R=1 反例却未解释原因。本结构额外说出:(1) 全族共用唯一动力源定理 10.7,判别法个数是基准×耦合的组合数而非独立事实;(2) 『失效于 1』的统一解释——inconclusive 是基准分辨率不足的必然表现,且预言了修复方向(细化基准),这一因果陈述不存在于任何单个成员中。

## 适用条件

各项非负(比值族要求严格正)的级数;基准级数库中存在与目标同衰减尺度的成员时判别法有效。

## 边界与反例

两类失效:(1) 尺度失配——根值/比值在 R = L = 1 时失效不是偶然,而是因为几何基准分辨率太粗,区分不了任何多项式速率:∑1/n 与 ∑1/n² 都给 R = 1(节点 root-test 自带此反例),必须换更细的 zeta 或 Gauss 基准;(2) 符号失效——整个结构以部分和单调为前提,对变号级数完全沉默:交错调和级数 ∑(−1)^{n−1}/n 收敛,但比较机器对它无话可说(其绝对值级数发散),须交由 Leibniz/Dirichlet 一族处理。

## 教学用途

把 6 个判别法从『清单记忆』变为『两步选择』:先估计目标级数的衰减尺度,再选同尺度基准与耦合方式;并给出失效诊断程序——判别法给出 1 时不是『没办法了』,而是『该换更细的基准』,自然引出 Raabe/Gauss 作为分辨率升级而非孤立技巧。
