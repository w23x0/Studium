# 通项不趋零反证:发散的第 n 项论证(Divergence via Non-Vanishing Terms)

**类型**:证明模式 · **层级**:L2 · **来源**:模型综合(候选,已过双审计)

## 共同机制

定理 10.6 的逆否形式——a_n 不趋于 0 则 Σa_n 发散(其自身证明是一次极小的裂项:a_n = s_n − s_{n−1} → S − S = 0)——是本章所有判别法中发散分支 (b) 的真实引擎,而非比较论证:几何级数在 |x|≥1 发散因为 x^n 不趋于 0(10.8 节论证正是定理 10.6 的推理模式,虽然该定理要到 10.11 才正式陈述);根值判别法 (b) 的证明是 'R>1 implies a_n>1 for infinitely many n and hence a_n cannot tend to 0. Therefore, by Theorem 10.6, Σa_n diverges';比值判别法 (b) 同理由 L>1 推出 a_{n+1}>a_n 最终单调上升、不能趋 0。即这些判别法内部存在证明手法的不对称:收敛分支 (a) 走优超比较,发散分支 (b) 走通项反证。

## 抽象增益

单个成员只陈述自己的发散条款;模式层说出的新事实是一个不对称性定理:根值与比值判别法并非对称的双向工具,其收敛分支属于尺度比较模式(几何级数优超),发散分支却全部化归同一个必要条件(定理 10.6)的逆否——因此这些判别法的发散结论实际上不依赖比较尺度,也自动对更弱的假设(仅 a_n > 1 无穷多次,无需极限存在)成立。这条"发散分支同源且可减弱假设"的断言在任何单个定理文本中都不存在,且它精确划定了与比较模式的分工边界:比较模式负责 a_n→0 型发散,本模式负责通项不衰减型发散。

## 适用条件

任何能证明通项有无穷多项被正常数下界隔离(bounded away from 0)的级数:|x|≥1 的几何级数、R>1 或 L>1 的正项级数、以及一切通项振荡不衰减的级数(如 Σ(−1)^n)。

## 边界与反例

严格单向:只能证发散,且仅覆盖"通项不趋零"这一种发散方式。对 a_n→0 的发散级数完全失效——调和级数是书中特意给出的反例(a_n = 1/n → 0 但 Σ1/n 发散),说明该条件必要而不充分;此类发散必须回到比较/积分模式(Σ1/k ≥ log(n+1))。混淆充分与必要方向是学生的高频错误,书中为此专门加了 Warning(比值恒 <1 不保证 L<1)。

## 教学用途

作为判别流程的第零步教授:拿到任何级数先查通项是否趋零,不趋零立即终止;趋零则此工具作废、换比较类工具。同时用"收敛分支与发散分支证法不同源"训练学生读证明的结构而非只记结论。
