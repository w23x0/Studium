# 幂级数求和:对母恒等式施算子链(代换 / 乘 x / 逐项微分 / 逐项积分 / 线性组合)

**类型**:题型模式 · **层级**:L2 · **来源**:模型综合(候选,已过双审计)

## 共同机制

以极少数母恒等式为种子——1/(1−x) = Σx^n(定理 10.5)与 e^x = Σx^n/n!(10.9 第 22–23 题给定)——对恒等式两边同时施加保持相等的算子:变量代换 x↦−x, x², 2x;乘以 x;逐项微分;逐项积分;以及定理 10.2 的线性组合。算子的选取由目标和式的形状反推:系数含 n 的多项式 ⇒ 微分后乘 x(10.9 第 11–14 题 Σn^k x^n);分母含 n ⇒ 积分(第 15、16 题);分母含 n! ⇒ 换用指数种子(第 22、23 题);一般规律沿算子链用归纳法证明(第 20、21 题的 P_k(x)/(1−x)^{k+1} 与 Σ C(n+k,k) x^n = 1/(1−x)^{k+1})。10.8 节的 (10.26)–(10.33)(含对数级数、Gregory 级数)正是同一生成过程的教科书输出。

## 抽象增益

每个具体公式节点(10.26–10.33、对数级数、Gregory 级数)只是一个静态输出。该结构表达的是生成观:整个恒等式库 = 种子集在算子集下的闭包,并给出从目标形状到算子选择的可操作反推规则;同时指明该机制的合法性边界(形式性、端点失效)是全体输出共有的、而非逐条例外。『种子+算子闭包』这一层在任何单成员乃至 L1 任何边中都不存在。

## 适用条件

10.9 第 11–23 题;凡目标级数可由种子经有限次上述算子得到者;有效范围至少为 |x|<1(几何种子)或全体 x(指数种子)。

## 边界与反例

本章内全部操作是形式操作:逐项微分/积分的合法性明确推迟到 11.8 节,题目原文写明 'without attempting to justify the steps'。端点处恒等式可能失效或需独立论证:对数级数在 x=1 成立(得交错调和级数 = log 2)但这需要 10.17 的额外证明,在 x=−1 则发散;Gregory 级数在 x=±1 的成立同样超出算子机制本身。对非幂级数形态(如 Σ1/(n²+n))算子机制完全不适用。10.9 第 24–25 题(identical series 辨析)专门警示:代换生成的级数与原级数并非同一级数,算子输出的是新恒等式而非项级改写。

## 教学用途

是第 11 章幂级数理论(收敛半径内可逐项微积分、Taylor 展开)的操作性预演;训练『由目标形状反推算子序列』的启发式;归纳题(20、21)训练沿算子链做结构归纳。
