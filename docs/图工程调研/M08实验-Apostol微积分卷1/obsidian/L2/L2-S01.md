# 正项级数收敛判定决策链(以定理10.7为根、双基准标尺校准的升级式判别系统)

**类型**:方法体系 · **层级**:L2 · **来源**:模型综合(候选,已过双审计)

## 共同机制

全部判别法构成一棵以定理10.7(非负项级数收敛 ⟺ 部分和有界)为根的归约树:比较判别法(10.8)把待判级数的部分和有界性转移到一个已知基准级数上(优超关系);极限比较/渐近比较(10.9/10.10)自动补出比较常数;根值与比值判别法(10.12/10.13)是以几何级数 Σx^n 为基准的比较判别法特例(书中明言,边 e-G2-036/037),区别仅在从项数据 a_n^{1/n} 或 a_{n+1}/a_n 自动选出公比;积分判别法(10.11)以部分积分为基准转移有界性;Raabe/Gauss 判别法由比较判别法以更精细的基准(1/n^s 尺度、n log n 尺度,边 e-G2-048/049、e-G2-054)导出。整个系统由两个单参数基准族校准:几何标尺 x^n(指数衰减)与 zeta 标尺 1/n^s(多项式衰减);尾部不变性(10.5节)统一许可所有 'n ≥ N 起成立即可' 的假设形式。

## 抽象增益

任何单个成员都未陈述的三件事:(1) 判别力的严格偏序——比值可判 ⊂ 根值可判 ⊂ 比较可判(相对基准库),书中只说根值/比值是比较判别法特例,但'失败时沿此偏序向上升级'的策略无处陈述;(2) L=1 的诊断意义:它不是随机失效,而是'项衰减慢于任何几何级数'的信号,因此下一步必然改用多项式标尺(zeta/Raabe/Gauss)——这解释了 Raabe/Gauss 为何存在以及何时调用;(3) 整个系统是'一个引擎(定理10.7)+ 两把标尺(x^n 与 1/n^s)+ 一条许可(尾部不变性)'的闭合体系,各判别法只是引擎与标尺的不同接线方式。

## 适用条件

非负(比值判别法要求严格正)实项级数。决策顺序:第0步用第n项判别法筛除 a_n ↛ 0 的发散级数;第1步若 a_n 可渐近化简为 c/n^s 形式,用极限比较对 zeta 标尺(如 Σ(2n+1)/(n²+n)^{3/2});第2步含阶乘或连乘积用比值,含 n 次幂结构用根值;第3步项为单调递减初等函数且原函数易求时用积分判别法(如 Σ1/(n log n));第4步比值极限 L=1 时升级到 Raabe,Raabe 临界(A=1)再升级到 Gauss。

## 边界与反例

三个精确失效点:(1) 根值/比值在 R=1 或 L=1 时无结论,且 L=1 恰好发生在项以次几何速度(多项式尺度)衰减时——书中标准见证对是 Σ1/n(发散)与 Σ1/n²(收敛),二者都给出 R=L=1;这正是需要 zeta 标尺和 Raabe/Gauss 的原因。(2) 比值恒小于1不能代替 L<1:调和级数比值 n/(n+1)<1 恒成立却发散(定理10.13的 Warning)。(3) 整个系统只对非负项有效:对 Σ(-1)^{n-1}/n 它只能判定其不绝对收敛,不能判定其收敛——变号级数在本系统之外。极限比较当极限为0时退化为单向结论。

## 教学用途

把10.11–10.16六节的判别法从并列清单改造成可执行的决策程序:学生按'筛查→识形→升级'三段操作,每步失败都有明确的下一步;同时训练'为什么此题该用此法'的元认知(看衰减尺度选标尺)。它也是第11章幂级数收敛半径(根值/比值判定 |x|<R)的直接前置。
