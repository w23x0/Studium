# 个体化锚的基数与独立性分级:铸出物的地位是其独立个体化锚数目的函数——0 锚是空转命名,1 锚只得相对个体化(对象随唯一锚撤除而蒸发),至少 2 条相互独立的生产线交汇才获得跨语境实在性;该变量在三个成员的边界条款中各现一个取值而互不知晓

**类型**:元结构 · **层级**:L6 · **来源**:模型综合(候选,已过双审计)

## 共同机制

定义:铸出物 x 的一个个体化锚是一条能确定 x 的生产线(参照+包络+程序)。断言:三个 L5 结构的证书条款与边界条款分别使用了『锚数』这一变量的三个取值而未命名该变量。锚数=0:L5-S01 与 L5-S02 的边界共同案例(裂项级数式重命名)——铸出物完全可由赤字自身定义,无任何独立生产线,零成本亦零收益。锚数=1:L5-S05 的条件收敛案例——和值仅相对固定求和次序被个体化,重排(撤走唯一锚)则蒸发;同理任何单一求和法下的正规化值。锚数≥2 且独立:L5-S01 边界条款给 C 开出的非平凡性证书——C 独立出现于 Euler–Maclaurin 残差与 ζ 在 s→1 的展开这两条不同生产线;ζ 延拓的标尺/产物双重身份同属此级。独立性要求有章内反例支撑:root 与 ratio 判别法对同一级数族给出相同阈值 1,形似两线交汇,但 ratio 可算蕴含 root 可算且极限相同(root 强于 ratio),两线不独立,故公共阈值 1 不铸任何对象。推论:L5-S05 边界中自认『超出本结构』的求和法相容性公理(线性、稳定性)的功能在此获得解释——要求不同求和法交汇即是把 1 锚提升为多锚的制度化装置。

## 抽象增益

(1) 『锚数』作为显式变量在任何成员中不存在:L5-S01 只在边界条款里把『两条生产线交汇』用作 C 的一次性证书,L5-S05 只把『撤参照即蒸发』描述为一种负面现象,L5-S02 只把重命名列为退化——把证书、现象、退化证认为同一变量的取值 2、1、0,是三个互不引用的边界条款合并后才出现的命题。(2) 解释了成员自认无力解释之物:L5-S05 明言求和法相容性公理『超出本结构』,本层给出其功能定位(锚增殖装置),这是对成员遗留问题的正面回答而非重述。(3) 轴分离是新的区分:成员层把『撤锚蒸发』与『不许出生』读作一事,本结构证明出生许可(S05 的轴)与实在性等级(锚数的轴)独立——1 锚对象可合法出生、日后升级,该修正在任何单个成员中无法陈述。(4) 独立性要求连同 root/ratio 阈值反例给出了成员均无的具体审计步骤:交汇线须先证不可互导,否则多锚是假象。

## 适用条件

对任何拟议新对象或正规化值的审计程序:枚举其全部生产线,逐对检验独立性(一线是否可由另一线导出),按 0/1/≥2 分级;分级决定该对象可携带多远——0 级不入库,1 级只在其锚的语境内引用,≥2 级可跨语境引用。

## 边界与反例

两条限制,其一致命性须明说。(i) 独立性判据本身外在于本结构:『两线不可互导』的判定(如 root 强于 ratio 的支配关系)需要逐案的数学工作,本结构索要独立性却不提供其判据,故分级程序含一个不可自动化的步骤。(ii) 锚数分级是实在性等级而非出生许可,二者是不同的轴:章内 C 在残差收敛被证明的当下即已获得对象地位(当时仅一条生产线),ζ-锚是后来发现的——故 1 锚对象完全可以合法出生并在日后升级为多锚;若把本判据误用为存在性判据(『无二锚则不许出生』)则为假,出生许可归 L5-S05 管辖,本结构只管对象能被带出多远。

## 教学用途

把 L5-S05 的质询程序升级一档:学生遇到『Σn = −1/12』式断言时,除问『出生它的参照族是什么』(S05 层面)外再问『有几条相互独立的方法交汇于此值』——并给出可查证的作业:核对 ζ-正规化、Ramanujan 求和、带抵消项截断三条线是否独立地给出同一值,对比之下单一方法的值只能持保留态度。同时用 root/ratio 阈值 1 的反例训练独立性检查:交汇的线数要数,线的独立性更要证。
