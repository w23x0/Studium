# 收敛数列
*convergent sequence*

## 定义/陈述

If the sequence $\{f(n)\}$ has a limit L, we say the sequence converges to $L$. The phrase "convergent sequence" is used only for a sequence whose limit is finite.

> 适用语境:Real or complex sequences; a sequence with an infinite limit is not called convergent
