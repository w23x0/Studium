# 第 n 部分和
*nth partial sum*

## 定义/陈述

Given a sequence $a_{1}, a_{2}, \ldots, a_{n}, \ldots$, the partial sum $s_{n}$ of the first n terms is defined by $s _ {n} = a _ {1} + a _ {2} + \dots + a _ {n} = \sum_ {k = 1} ^ {n} a _ {k}$ (10.14).
