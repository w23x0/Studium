# 递增数列
*increasing sequence*

## 定义/陈述

A sequence $\{f(n)\}$ is said to be increasing if $f (n) \leq f (n + 1)$ for all $n \geq 1$; indicated briefly by writing $f(n)\nearrow$.

> 适用语境:Real-valued sequences (Section 10.3)
