# 斐波那契数
*Fibonacci numbers*

## 定义/陈述

The sequence defined by the recursion formula $a_{1} = a_{2} = 1$, $a_{n+1} = a_{n} + a_{n-1}$ for $n \geq 2$; its first few terms are 1, 1, 2, 3, 5, 8, 13, 21, 34.
