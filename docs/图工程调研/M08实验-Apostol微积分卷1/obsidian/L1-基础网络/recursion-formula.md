# 递推公式
*recursion formula*

## 定义/陈述

A way to define a sequence by a set of instructions which explains how to carry on after a given start, e.g. $a_{1} = a_{2} = 1$, $a_{n+1} = a_{n} + a_{n-1}$ for $n \geq 2$.
