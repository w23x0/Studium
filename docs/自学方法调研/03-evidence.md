## § 1 十种学习技巧效用评级

### 研究元数据
```
作者：Dunlosky et al.
年份：2013
期刊：Psychological Science in the Public Interest
证据等级：LEVEL_1
状态：[已读原文]（期刊页面含完整评级）
```

### 评级结果

#### 高效用（2种）
```
1. 练习测验 (practice testing)
2. 分散练习 (distributed practice)

理由：benefit learners of different ages and abilities
     boost performance across many criterion tasks
```

#### 中等效用（3种）
```
1. 精细化提问 (elaborative interrogation)
2. 自我解释 (self-explanation)
3. 交错练习 (interleaved practice)

限制：部分条件下有效
     真实课堂环境证据仍然稀薄
```

#### 低效用（5种）
```
1. 总结 (summarization)
2. 划线 (highlighting/underlining)
3. 关键词记忆法 (keyword mnemonic)
4. 意象法 (imagery for text learning)
5. 重读 (rereading)

原因：不一致地提升表现
     总结和意象只对部分学生的部分任务有效
     关键词法难以广泛应用且长期保持衰减
     建议用练习测验替换重读
```

### 使用注意
- 低效用≠无效
- 评级依据包含：可推广性 + 课堂证据强度
- 划线低评级部分因为：太容易执行成纯被动动作

## § 2 主动学习 vs 讲授（STEM 元分析）

### 研究元数据
```
作者：Freeman et al.
年份：2014
期刊：PNAS
URL：https://pmc.ncbi.nlm.nih.gov/articles/PMC4060654/
证据等级：LEVEL_1
状态：[已读原文]（PMC全文）
```

### 数据表

| 项目 | 数值 |
|------|------|
| 纳入研究总数 | 225 |
| 提供考试/评估数据 | 158 |
| 提供不及格率数据 | 67 |
| 考试成绩效应量 | 0.47 SD（~平均分高6%）|
| 不及格率-主动学习 | 21.8% |
| 不及格率-讲授 | 33.8% |
| 不及格几率比 | 1.95（讲授组1.5倍）|

### 对自学者的适用性限制
- 比较对象：两种**课堂教学设计**
- 对照组：会在传统讲授中走神的平均学生
- 约束范围：课程设计
- 不能推出：「自学者不该看讲座录像」
- 参见：02-methods.md § 5

## § 3 力学概念测验（FCI）

### 研究元数据
```
作者：Hestenes, Wells, Swackhamer
年份：1992
来源：Halloun & Hestenes 1985 Mechanics Diagnostic Test
证据等级：LEVEL_3
状态：[二手]（维基条目）
```

### 测验规格
- 题目数：30
- 题型：五选一
- 测量：conceptual understanding of fundamental conceptions of Newtonian mechanics

### 核心数据

```
完成大学入门物理课的学生中：
  能陈述牛顿第三定律：~80%
  FCI 显示真正理解：<15%

模式：在多个院校和多个学生群体中重复出现
```

### 影响
- 物理教育研究转向重视「active engagement」的直接推动力

### 取证限制
- 数字在维基条目中有明确表述
- 未回到 1992 年原文核对

## § 4 Hake 1998 归一化增益（数值待核）

### 研究元数据
```
作者：Hake
年份：1998
期刊：American Journal of Physics 66(1)
证据等级：LEVEL_3
状态：[未取到原文]
镜像尝试：udel/montana/physport/indiana 全部 404 或 403
```

### 已确定内容（来自 PhysPort）

归一化增益定义：
```
<g> = (<Post> - <Pre>) / (100 - <Pre>)

用途：rough measure of effectiveness in promoting conceptual understanding
理由：strongly differentiated between teaching methods in Hake's data
特性：在起点知识水平差异很大的群体间表现一致
     可用于跨院校类型比较
```

### 待核部分（常被转引但无一手出处）

```
传统课程：~0.23
互动参与课程：~0.48
样本规模：约6000名学生

状态：这两个数字在 PhysPort 页面正文中并未出现
     本次调研没有任何一手出处支持
     引用前必须回到 AJP 66(1) 原文核对
```

### 方法论提醒
- 一篇被引数千次的论文
- 其关键数值在整个可及网络上取不到一手出处
- 「人人引用但原文难取」在教育研究里不罕见

## § 5 Desirable Difficulties（可期望的困难）

### 研究元数据
```
来源：Bjork Learning and Forgetting Lab
URL：https://bjorklab.psych.ucla.edu/research/
术语出处：R. A. Bjork 1994
证据等级：LEVEL_1
状态：[已读原文]（实验室网页）
```

### 核心区分

```
学习 (learning) vs 表现 (performance)
  断言：训练期间的表现不一定代表长期学习
  原文：performance during training is not always representative of long-term learning
```

### 课堂示例

```
连续一小时只练一种题型：
  课上：看起来掌握了
  两周后测验：benefit may not be evident

交错不同题型：
  课上：感觉更难、表现更乱
  两周后测验：produces higher scores than easier version
```

### 已命名的可期望困难

```
1. 分散重复（spacing）
   vs 集中堆在一起

2. 测验/提取练习（retrieval practice）
   vs 被动重读

3. 生成信息（generation）
   vs 直接读到
   示例：从首字母提示补全

4. 变换练习条件（variation）
   vs 保持恒定

5. 知觉不流畅（perceptual disfluency）
   示例：较难读的字体
   效果：lead people to engage in deeper processing strategies
```

### 关键限制（容易被忽略）

```
困难不总是可叠加（次可加性）
  实验发现：间隔 × 变化存在 sub-additive interaction
  具体表现：variation beneficial only when spacing intervals are short
  
含义：组合多种可期望困难有时会相互抵消而非叠加
警告：对想同时上齐「间隔+交错+生成+变换」的系统设计
```

## § 6 测验效应（retrieval practice）

### 研究元数据
```
来源：维基条目整理的证据链
URL：https://en.wikipedia.org/wiki/Testing_effect
证据等级：LEVEL_3（二手）
交叉支持：Dunlosky § 1「练习测验=高效用」(LEVEL_1)
```

### 核心发现

```
主动从记忆中提取信息 > 重读或重学
  效果维度：长期保持、迁移、遗忘速率
```

### 证据链

```
历史观察：
  培根 1620：背诵 > 反复重读
  William James 1890：things impressed better by active than passive repetition

现代证据主体：
  Roediger, Karpicke, Pashler 等人对照研究
  发现：测验在保持、迁移、遗忘速率上均优于重学

调节因素：
  - 测验难度
  - 测验前延迟
  - 反馈
  - 题型（简答/论述型增益 > 选择题）

尚在争议：
  - pre-testing（学习前测验）
  - 复杂材料上的效应
```

### 取证状态
- 二手（维基条目）
- 但与 Dunlosky 元综述互相支持（后者是一手来源）

## § 7 fail-first 与 pre-testing 的关系

### Scott Young 的 fail-first 做法
```
来源：MIT Challenge
证据等级：LEVEL_4（个人经验）
流程：几乎不复习先考一次 → 用差成绩暴露缺口 → 用另一份卷子重考
理由来源：作者本人判断（自主学习里成本低）
         不是引用任何研究
```

### 与 pre-testing 的关系
```
形式上：接近 pre-testing
但：pre-testing 在 § 6 中被明确列为**尚在争议**的方向

结论：只能作为「一个有人用过的做法」
     不能作为有证据支持的技巧
```

## § 8 证据基础的结构性缺口

### 覆盖范围

```
所有硬数字关于：通用学习机制
  - 测验
  - 间隔
  - 交错
  - 主动参与

没有任何硬数字关于：
  - 数学物理该按什么顺序学
  - 哪本教材更好
```

### 原因
- 课程顺序和教材选择很难做随机对照实验
- 从业者判断在这些问题上仍是当前可得的最好证据

### 引用规范

```
机制层面结论：
  可按证据引用
  示例：「Dunlosky 2013 元综述评级练习测验为高效用」

路径层面结论：
  只能按「有经验者这样认为」引用
  示例：「Zhou（斯坦福物理博士、美国物理奥赛队教练）认为...」
  不能说：「证据表明顺序应该是...」
```

### 对 02-methods.md 的关系
- 02-methods.md 关于顺序、书籍选择、资料质量判断的内容
- 全部来自专家经验而非对照实验
- 这不是引用不足，而是这个问题的固有形态

### 读者应该调整的信任度
- 机制层面：按证据等级信任
- 路径层面：作为从业者见解参考，不作为已验证的最佳实践
