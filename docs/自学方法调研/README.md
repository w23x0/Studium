# 自学方法调研（偏数学物理）

## 这份调研是什么

网络上公开的、关于「怎样自学」的高质量内容，主要限定在数学与物理方向。目标是把散落的建议整理成可比较、可追溯的结构，而不是又一份书单。

## 调研边界

覆盖的是**公开且可核查**的内容：署名作者的建议文档、同行评议论文、大学课程材料。

没有覆盖的：

- 付费社群和课程内部材料
- 中文语区的自学社区内容（知乎、B站、豆瓣等），检索接口在本次调研期间不稳定，未能系统采样
- 非数理方向的自学方法（语言学习、编程、乐器等），除少数被数理来源引用者外

## 证据等级约定

沿用 [图工程调研](../图工程调研/02-资料索引.md) 的做法。

| 类型 | 主要用途 | 不能单独证明什么 |
| --- | --- | --- |
| 署名专家建议 | 理解从业者的实际做法和其理由 | 不能证明该做法对一般学习者有效 |
| 同行评议论文 | 理解已被检验的效应及其量级 | 不能直接迁移到具体个体或具体科目 |
| 大学课程材料 | 观察真实教学中的顺序和难度安排 | 不能证明自学者照搬可行 |
| 个人经验报告 | 发现可能的路径和时间尺度 | 样本量为一，不能作为普适依据 |

专家建议在本领域占比很高，这是这个主题的固有特征：「怎样自学数学物理」很难做随机对照实验，可引用的硬证据集中在认知科学的通用学习机制上，而不在具体学科路径上。读的时候要意识到这个不对称。

## 一处方法论提醒

本次调研中，Hake 1998（物理教育研究里被引用最多的一篇）的原文 PDF 在四个镜像上全部取不到，只能通过 PhysPort 的二手概述引用。相关数字在 [03-实证证据.md](03-实证证据.md) 里标注为待核。这类「人人引用但原文难取」的情况在教育研究里不罕见，转引时值得多一步确认。
