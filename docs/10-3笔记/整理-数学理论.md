## 总结论

| # | 结论 |
| --- | --- |
| 1 | 没有数学理论整句对应“差异小 → 局部顺应、差异大 → 忽略 / 同化”。最接近的是 **Gershman 2017 潜在原因模型**：误差小 → 并入旧结构但改动很小；误差很大 → 另立新结构、**旧的不动**；只有中间“甜点”才真正改旧结构（倒 U） |
| 2 | **精度加权**是连续加权，本身无阈值；“压低误差 vs 更新先验”靠给输入多少信任、更新落在快变量（状态）还是慢变量（参数 / 结构）。阈值式行为要引入“结构选择”（混合模型 / 新原因） |
| 3 | **换一套理论 = 贝叶斯模型选择**：数据积累到后验翻转就换；结构学习与参数学习是不同层次。证据只到儿童小任务的模型 + 行为拟合，无成人课程规模证据 |
| 4 | **最佳难度**三条线：学习进度 LP（成人有证据）、Goldilocks 惊奇（只有婴儿）、课程学习（只有机器）；ZPDES 结构上最像 M05 + M08（子代理判断） |
| 5 | **尖点突变**有形式、有儿童实证，但控制参数的认知含义没有定论；对 M09 最有用的是可检测的**标志**：双峰、滞后、转变前方差增大 |
| 6 | “预测加工 → 概念转变”最直接的经验工作：Theobald & Brod 2021、Colantonio 等 2023（同批儿童，N=94） |

## 方向 1：预测加工 / 精度加权

| 项 | 内容 |
| --- | --- |
| 数学核心 | 生成模型 p(s,ϑ)=p(s\|ϑ)p(ϑ)；自由能 F = KL[q(ϑ)‖p(ϑ\|s)] − ln p(s)，最小化 F 让 q 逼近后验；精度 Π = 逆方差，误差按精度加权 ξ = Π·ε；状态快、参数慢、精度更慢 |
| 一维高斯（教科书） | μ_post = μ0 + K(x−μ0)，K = Π_x/(Π_x+Π0)：K 大先验被拉走，K 小证据被打折、先验不动；Π_x 可由上层状态决定（状态依赖精度） |
| 文献 | Feldman & Friston 2010（Front. Hum. Neurosci.，读正文）：讲注意，学习留到以后，**没讨论何时改先验** |
| 教育证据 | Theobald & Brod 2021（Child Dev，N=94，6–9 岁，读摘要 / 引言 / 讨论）：先让儿童预测再看冲突结果，惊奇反应强、修正多（d=0.56）；先有信念的儿童只在冲突“无法解释掉”时才改。Colantonio 等 2023（Entropy）：惊奇分 Shannon 信息与 KL（信念变动量），只有主动预测时瞳孔反应与 KL 相关 |
| 能 / 不能回答 | 能：误差怎样按信任加权。不能：何时该改慢变量；成人自学者的 Π 怎么测 |

## 方向 2：图式 = 生成模型及先验（贝叶斯理论学习）

| 项 | 内容 |
| --- | --- |
| 数学核心 | 层级：框架理论 T → 具体理论 G → 数据 D，P(G,T\|D) ∝ P(D\|G)P(G\|T)P(T)；贝叶斯奥卡姆：数据少选简单理论，数据积累后验翻转换复杂理论；“抽象的福音”：高层可先于具体层学到 |
| 搜索视角 | Ullman 等 2012：理论空间外环、解释空间内环随机搜索（只读摘要）；Bonawitz 等 2014 win-stay, lose-sample：保持当前假设，数据不利才换（二手） |
| 文献 | Gopnik & Bonawitz 2015、Perfors 等 2011（读正文段）；Gopnik & Wellman 2012、Tenenbaum 等 2011、Bonawitz 等 2019（只读摘要） |
| 与“局部 vs 整体” | 参数学习 ≈ 不换结构只调权重；结构学习 ≈ 换图；换框架 T 一次改动多个具体理论 ≈ 整体重构。精确贝叶斯下是同一空间的后验权重，不是两种机制（子代理解读） |
| 能 / 不能回答 | 能：何时换理论；新旧理论可带权重并存。不能：局部与整体分界；成人先验怎么设 |

## 方向 3：最佳难度

| 理论 | 结构（白话） | 人类证据 |
| --- | --- | --- |
| 课程学习 Bengio 等 2009 | 先易后难 = 非凸优化的延续法 | 无（全为机器） |
| 学习进度 Oudeyer & Kaplan 2007 | 奖励 = 某区域内预测误差最近一段比前一段降了多少；已掌握和学不会两端奖励都为 0，自带倒 U | 计算模型，无人类实验 |
| Ten 等 2021（Nat. Commun.） | 自由选 4 类难度活动；正确率 + 学习进度两项进 softmax 选择 | **成人** N=400（19–71 岁）：靠正确率避开太易，含 LP 的模型拟合最好 |
| ZPDES（Clément 等 2015，JEDM） | 专家前置图划 ZPD；奖励 = 最近成功率增量；多臂赌博机选活动；成功率超阈值就向更难扩展；无进展临时撤出 | 7–8 岁 400 人有对照：达到的最高层级多于专家序列（学习增益未核） |
| Goldilocks（Kidd 等 2012） | 复杂度 = −log P(事件\|学习者当前信念)；移开视线概率对复杂度呈 U 形 | 7–8 月龄婴儿 |
| 85%（Wilson 等 2019） | 二分类 + 梯度下降 + 高斯噪声 | 无 |

子代理判断：概念定义上 Kidd 的“相对学习者当前模型的惊奇”与 Gershman 的“预测误差大小”最贴“新旧比例”；可观测控制信号最贴的是 LP。缺口：都没有“旧知识量”的显式变量；都不区分“差距太大”与“状态不佳”（M05 要求两个读数分开）。ZPDES 的信号是答题对错，对话闭环的对应信号要从 M04 日志里想。

## 方向 4：突变论与动力系统

| 项 | 内容 |
| --- | --- |
| 尖点模型（van der Maas & Molenaar 1992，Psych. Rev.，读正文） | 势函数 V(Z)=¼Z⁴−½YZ²−XZ，平衡面 Z³−YZ−X=0；X 非对称因子、Y 分裂因子；分叉集内两个稳定态 + 不稳定中层 |
| 8 个标志（Gilmore 1981） | 分叉集内：双峰、中层不可达、突跳、滞后、发散；分叉集外也可出现（可作预警）：线性响应发散、临界慢化、异常方差 |
| 控制参数含义（无定论） | 作者的“冲突尖点”：非守恒与守恒两股倾向都高 = 过渡期（原文：**尚未用于真实数据**）；测试条件优劣；工作记忆 / 场依赖（新皮亚杰派）；**Saari 1977 把同化 / 顺应作两个控制变量，无法独立测量，未经检验** |
| 实证 | Jansen & van der Maas 2001 天平任务 6–10 岁约 600 人，5 标志中 4 个观察到（只读摘要）；成人概念学习：没找到 |
| van Geert 1991（Psych. Rev.，读正文） | 受限增长 ΔL/Δt = r(K−L)；成长者之间有支持、竞争、条件关系；**竞争增长**：两个替代策略此消彼长，最终一方占优；“A 要等 B 过阈值才起步”，但结构模型该文没给 |
| 批评 | 作者自列：只能局部、不解释新策略怎么产生、不解释领域间先后、整体难验证；Zahler & Sussmann 1977 批突变论滥用（未读） |

标志在学习里的意思：双峰 = 同水平的人要么旧理解要么新理解、中间态少；滞后 = 走过去和退回来的翻转点不同；异常方差 / 临界慢化 = 翻转前表现波动变大，是唯一能提前看到的信号。

## 方向 5：“差异小 → 局部顺应、差异大 → 忽略 / 同化”

| 结果 | 内容 | 与笔记措辞 |
| --- | --- | --- |
| Gershman, Norman, Niv 2017（eLife，读正文） | 误差小归旧原因、改动小；误差很大另开新原因、旧的不动；中间甜点才真改旧结构；先验偏简单，误差持续累积才让新原因升高 | 大差异 = **新建结构、旧的保留**，不是“忽略”；证据主要是大鼠条件反射 |
| Körding 等 2007（PLoS ONE） | 两线索差距小整合、差距大分开（人类视听定位） | 有正式阈值行为，但是知觉 |
| Knill 2007（J. Vision，只读摘要） | 冲突大时线索权重平滑下降、不到零 | “忽略”不是硬阈值 |
| Nassar 等 2010；Faraji 等 2018 | 学习率随“环境变了”的概率调节；SMiLe：π_{n+1} ∝ p(x\|θ)^γ π_n^{1−γ}，γ 由惊奇定 | **方向相反**：大惊奇更采信新数据 |

子代理综合（待产品负责人判断）：大差异被忽略还是引发重构，取决于学习者模型里有没有“新原因 / 世界变了”这个备选及其先验权重。
