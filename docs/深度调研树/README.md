# 深度调研树（Deep Research Tree）— 使用说明

> 用途：用「树状多会话」做全网穷尽式深度调研。
> 一句话机制：**根会话找方向 → 输出子提示词 → 你拿提示词开子会话 → 子会话再细化 → 叶子执行调研 → 汇总仲裁 → 独立审计**。

## 核心文件
| 文件 | 作用 |
| --- | --- |
| `_中心控制\CONTEXT.md` | **总控宪法**：所有会话启动必读，统一范围/证据/产出规范 |
| `_中心控制\树状注册表.md` | 会话/方向/产出登记表：每层产出后登记，汇总和审计靠它收口 |
| `_提示词\P0-根方向探索.md` | 第一个会话用：拆方向 + 生成分支提示词 |
| `_提示词\P1-分支细化模板.md` | 中间层用：子主题 + 生成叶子提示词 |
| `_提示词\P2-叶子深挖模板.md` | 叶子层用：真正执行全网调研 |
| `_提示词\P3-汇总仲裁.md` | 收口用：横向对照 + 合成结论 |
| `_提示词\P4-审计复核.md` | 独立复核用：引文抽检 + 判死 + 宪法冲突检查 |

## 树状流程（照着走）
```
第 1 层  你编辑 CONTEXT.md 填入调研主题
第 2 层  开会话#1，粘贴 P0 → 产出《方向地图》+ 每分支的 P1 提示词
第 3 层  你为每个分支各开一个会话，粘贴对应 P1 提示词 → 每个产出子主题地图 + P2 提示词
第 4 层  再为每个子主题开叶子会话，粘贴对应 P2 → 叶子做全网调研，落盘 发现.md + _sources/
第 5 层  开汇总会话，粘贴 P3 → 合成报告
第 6 层  开审计会话，粘贴 P4 → 审计报告
```
> 每一层做完，把产出路径登记到 `树状注册表.md`（可由该会话代写，你确认即可）。

## 开会话的标准开场白（每次都用）
```
请先阅读并遵守 {CONTEXT.md 的完整路径} 和 {树状注册表.md 的完整路径}。
你的任务提示词如下（粘贴对应的 P 文件全文）。
全部产出落盘到 {指定目录}，落盘后把产出路径写进树状注册表。
```
## 会话命名建议
`T0-根` / `T1-{分支}` / `T1-1-{子主题}` / `L-{叶子}` / `M-汇总` / `A-审计`
## 纪律
- 只有叶子层做深度调研；中间层只拆方向、生成提示词。
- 任何会话不得替你做产品决策；推断必须标注。
- 任何会话不得捏造来源；抓不到原文就标「未核」。
