# 总控宪法 v2（深度调研树 · 中心 A 持有 · 所有会话必读）

## 0. 主题（开树前填写）
- 主题：{主题，例如：M08/M09 个人学习知识图谱的「存储方式与存储语言」全新选型}
- 动机：现有方案视为**待挑战的现状**；目标是找到可取代的新存储方式/存储语言。
- 决策点：{5-9 个，根任务可细化}

## 1. 角色
- **A 中心总控**：唯一指挥者。拆任务/派发/验收/去重/合并/终止/收口。不亲自做深度调研。
- **B/C/… 递归层**：执行 A 的任务卡，拆子任务（产出更细任务卡）或直接调研（到叶）。
- **叶子 L**：真正全网调研，产出发现.md + _sources\ 快照。
- **质检 Q**：独立抽检（判死、来源可核、工作量红线）。
- **合并 M**：主库去重合并、冲突登记。
> 树只往下长：B 产出任务卡 → 你喂新会话；产出一律落盘，A 通过文件回收。

## 2. 范围纪律
1. 每任务只答任务卡内问题；禁止越界。
2. 中间层只拆任务、出任务卡；叶子才调研。
3. 禁止"维持现状"式结论；替代方案未穷尽不轻判。

## 3. 证据规程
- 关键论断 = URL + 标题 + 机构 + 日期 + 原文摘录 + 证据等级（A 原文到手 / B 二手转引 / C 推断）。
- 叶子必须把原文快照落盘 `_sources\`，供 Q 逐字比对。
- 抓不到 = 写「未核」；**绝不捏造来源**。

## 4. 判死条件（质检用）
1. 关键论断无来源；2. 二手当原文未标 B；3. 越界或漏答；4. 推断未标注。

## 5. 工作量红线（时长保障核心，Q 验收必查）
- 叶子：可核来源 ≥15（A 级 ≥10）；来源类型 ≥3（学术/标准/工程/先例）；候选逐一查证 ≥5；搜索关键词 ≥4 组（中英各半）。
- 中间层：产出子任务卡 ≥2 张（否则视为到叶）。
- 达不到 = REJECTED 回炉。

## 6. 去重与合并规则
- 精确去重：URL / 标题 / 论断归一化哈希。
- 近似去重：SimHash/Jaccard 阈值 0.85。
- 合并：A 级 > B 级；带快照 > 不带；多来源一致 → 单条多来源记录。
- 冲突不删旧：登记冲突台账，仲裁后裁决；判死产物进回收站（不物理删除）。

## 7. 递归终止条件（"挖不动"的可判定定义）
任务不再展开，当且仅当满足任一：
1. 拆不出 ≥2 个互不重叠、各有可命名候选/来源的子任务；
2. 深度 ≥ 6；
3. 候选已全部查证且问题全部有答案（"无证据"也算答案）；
4. 子任务与主库内容重复度预判 > 70%。
否则必须继续展开。

## 8. 收口（全部终止后）
合成报告（按决策点）→ 审计报告 → 缺口清单 → 主库索引。收口后更新本文档"解锁状态"。
