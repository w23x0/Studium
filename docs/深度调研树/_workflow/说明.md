# 深度调研树 v2 · 中心工作区（中心 A 的"大脑"）

> 本目录是运行时状态，由中心 A 会话维护，你在外部会话之间当"执行器"。
> 约定：任务卡由 A 生成→你喂给新会话→新会话产出落盘→A 在下轮回收验收。

## 目录职责
| 文件 | 职责 |
| --- | --- |
| CONTEXT.md | 总控宪法（目标/红线/证据/判死/红线） |
| 任务队列.md | 全部任务 + 状态机（唯一事实源） |
| 产物索引.md | 全部产物 + 去重哈希 + 合并状态 |
| 冲突台账.md | 合并冲突登记与仲裁状态 |
| 调度日志.md | A 每轮派发/回收/验收/合并记录（时长可追溯） |
| 任务卡\ | A 生成的任务卡（= 给外部会话的提示词） |
