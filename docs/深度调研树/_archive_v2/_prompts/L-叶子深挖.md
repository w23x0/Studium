## 执行（穷尽原则）
分四路交叉搜索，中英文都搜，每组关键词换着搜，不只看第一页：
1. 学术：arXiv、ACL Anthology、Springer、IEEE、ISWC/ESWC、SIGMOD/VLDB/ICDE/PODS、综述论文
2. 标准：W3C、ISO、IETF、OASIS 规范原文（含草案与版本历史）
3. 工程：GitHub、官方文档、权威博客、系统架构说明
4. 先例领域：与本主题相关的成熟领域实现
对候选对象逐一查证：存在性、成熟度、活跃度、规模证据、真实采用案例。

## 工作量红线（不达标 = 回炉）
- 可核来源 ≥15（其中 A 级原文到手 ≥10）
- 来源类型 ≥3 类
- 候选逐一查证 ≥5 个
- 搜索关键词 ≥4 组（中英各半）
