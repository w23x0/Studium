# 厂商学习模式的后续（2025 → 2026）

> 状态：待定（2026-09-29，子代理调研，主 agent 未逐条复核）。**参考材料，不作产品结论**。厂商自述、研究、二手评论已分开标注；"推测"一节不是事实。

## 1 现状：都没下线，也都没换成"流程 / 闭环 / 学习者状态"式的新一代

| 厂商 | 现状 | 出处 |
| --- | --- | --- |
| OpenAI | Study Mode 还在，所有套餐可用，接入记忆功能；2026-04 前后菜单入口消失，没有公告，要输入 `@study` 才能调出（二手）。2026 年官方文章仍写"底层是定制系统指令"；2025 年说的"训练进主模型"没有兑现的证据。新动作是**测量**：学习成果测量套件（在爱沙尼亚对约 2 万名学生做验证）、Learning Lab 研究网络（2026-09-02）；青少年版里有"学习时段"（家长设定时段，新对话默认进学习模式） | [帮助中心](https://help.openai.com/en/articles/11780217-chatgpt-study-mode-faq) · [测量文章](https://openai.com/index/understanding-ai-and-learning-outcomes/) · [HN](https://news.ycombinator.com/item?id=47739305) |

## 2 遇到的问题（有证据的）

| 问题 | 证据 |
| --- | --- |
| 学生大量直接要答案 | [Anthropic 教育报告 2025-04](https://www.anthropic.com/news/anthropic-education-report-how-university-students-use-claude)：约 47% 的对话是"直接型" |
| 只加提示词护栏：只能做到"不伤害"，没有学习增益 | [Bastani 等，PNAS 2025](https://www.pnas.org/doi/10.1073/pnas.2422633122)：约千名高中生；普通 GPT 撤掉后成绩低 17%，护栏版抹平了负面影响，但没有增益 |
| 效果难证明；短期成绩不等于持久学习 | [斯坦福 SCALE 综述](https://scale.stanford.edu/research-in-action/understanding-evidence-base-ai-k12-education)；OpenAI 自己的实验里，一门课和传统资源分不出差别，另一门约 +15% |
| 提示词方案行为不稳定 | OpenAI 发布文与帮助中心都承认"有时仍直接给答案" |
| 提示词表达教学策略有上限 | [TeachLM arXiv 2510.05087](https://arxiv.org/abs/2510.05087)（有作者利益，预印本） |
| 泄露答案可以形式化地拦住，代价是有用性下降 | [arXiv 2608.00515](https://arxiv.org/abs/2608.00515)（预印本）：加严格放行检查后，泄露从 181 次降到 0 |
| 学生主动关掉学习模式 | **没找到一手数据** |

## 3 为什么没像编程那样深挖

没有厂商正面回答过。有来源的间接说法：证据"早期且混杂"、没有单一可优化的指标（OpenAI 自述）；对学生效果 mixed，所以先做教师端（Anthropic 自述）；最清楚的增益来自"AI 辅助教师"（SCALE 综述）。"成本高、学生不是好客户"只是网友猜测。

## 4 推测（子代理的看法，未经验证）

- 三家路径不同：Google 训练进模型并做严肃试验；OpenAI 先建测量再谈训练；Anthropic 先服务教师。
- 三家都卡在"先证明学习效果"上：谁先拿出可测的效果证据，谁就有空间。
- 纯自学场景的证据依然缺，现有试验里教师主导是关键变量。
