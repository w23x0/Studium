# 与 Studium 的关联

## META
- 用途：提问清单，不是设计结论
- 性质：调研得到的都是关于人类自学者的建议和研究
- 转换需求：需要额外论证，不在本次调研范围内
- 模块职责：以模块审查单为准，下面每条注明涉及模块及理由

## § 1 M08/M09 可能缺一个「理解方式」维度

### 依据
- 来源：Thurston 的导数七解
- 位置：02-methods.md § 1
- 断言：同一概念存在多种彼此不可互相替代的理解方式
- 特征：差异一旦被翻译成精确形式定义就开始蒸发

### 与现状的关系

M09 现状：
```
已明确拒绝：把个人形成记录压成「掌握/未掌握」或四级标签
功能清单中：「丰富个人形成记录」保存
  - 理解、应用、结构解释、心智模型
  - 可提取性、干扰、迁移、直觉
  - 缺口和适用条件
声明：维度可空、可扩展
```

### 未解决的问题

```
Thurston 说的不是深度维度
而是：同一深度上的不同侧面

示例：
  学习者可能牢固掌握：
    - 导数的符号理解
    - 导数的几何理解
  完全没有：
    - 微观镜头式的理解
  
  这两者都算「理解了导数」
```

在 M08 侧：
```
问题：一个概念对象是否需要挂多个理解侧面？
```

在 M09 侧：
```
问题：个人记录是否要区分侧面而非只区分深度？
```

### 为什么不能直接下结论

```
Thurston 自己没说：
  这些侧面应当被主动追求
  还是自然涌现

参见：04-conflicts.md § 终末未解答问题.2

如果是后者：
  把它做成显式维度 → 可能制造虚假的完备性要求
```

## § 2 M04 的诊断可能需要区分「阶段」与「覆盖」

### 依据
- 来源：Tao 的三阶段模型
- 位置：02-methods.md § 1
- 模型：pre-rigorous / rigorous / post-rigorous

### 与现状的关系

```
M04 负责：
  - 形成诊断事实
  - 替代解释
  - 证据限制
  - 验证需要

M10 依据这些选择策略
```

### 问题

```
两种不同的诊断结论：
  A. 这个学习者在这个概念上处于哪个阶段
  B. 这个学习者覆盖了哪些内容

导向不同策略：
  pre-rigorous 阶段的错误
    → 需要形式化训练
  
  post-rigorous 阶段的同一个表面错误
    → 可能只是笔误
```

### 已知的障碍

```
Tao 描述了阶段但没给自我诊断方法
  参见：04-conflicts.md § 终末未解答问题.1

Zhou 的 AP 模拟考判据：
  是覆盖度检验
  不是阶段检验

结论：
  即使承认这个区分有价值
  本次调研没有找到可用的判据
  这是真实的空白，不是文档遗漏
```

## § 3 M10 的策略选择可以对齐已有证据评级

### 依据
- 来源：03-evidence.md § 1 十种技巧三档评级
- 来源：03-evidence.md § 5 desirable difficulties

### 与现状的关系

M10 的「通用策略知识层」要求：
```
保存内容：
  - 策略
  - 其解决的问题
  - 机制
  - 适用条件
  - 限制
  - **理论来源**

明确写着：
  理论存在 ≠ 策略已经证实有效
```

### 这一条是本次调研中与现状契合度最高的

Dunlosky 三档评级 = 「适用条件与限制」栏可直接填入的内容

具体对应：
```
高效用 → 可作为默认倾向：
  - 练习测验
  - 分散练习

中等效用 → 注意课堂证据稀薄：
  - 精细化提问
  - 自我解释
  - 交错练习

低效用 → 尤其重读被明确建议用练习测验替换：
  - 总结
  - 划线
  - 重读
  - 关键词记忆法
  - 意象法
```

### 一处必须一起录入的限制

```
来源：03-evidence.md § 5

desirable difficulties 之间存在次可加性：
  间隔 × 变化的组合中
  「variation beneficial only when spacing intervals are short」

含义：
  如果 M10 的强度控制同时上齐多种困难
  可能相互抵消

这条限制比三档评级更容易被漏掉
```

## § 4 M15 的四类状态与 Zhou 的时间记录形成对照

### 依据
- 来源：Zhou 的 400h/1年记录
- 位置：02-methods.md § 6
- 归因：这些小时是「专注的」且「规律分布的」

Zhou 的原话：
```
I didn't need to cram, because I'd been immersed in physics the whole time
```

### 与现状的关系

M15 的「认知与资源条件」类：
```
定为主线
理由：触发量全部来自 M01 侧过程事实，证据成本最低
```

M15 的「行动与持续条件」中的行动失效：
```
需时长数据，等时间监控
```

### 可能的对照点

Zhou 归因的两个变量：
```
1. 专注度
   → 落在 M15 已定为主线的认知条件类

2. 分布规律性
   → 落在需要时长数据的持续条件类
```

Zhou 记录提供的参照量级：
```
每周约10小时
每周彻底理解一章
```

### 限制

```
参见：04-conflicts.md § 终末未解答问题.3

这个节奏的可迁移范围未知
不能当基准线用
```

## § 5 M06/M07 的资料质量判断有现成的元标准

### 依据
- 来源：Zhou 关于「好书是怎么产生的」那套倒推论证
- 位置：02-methods.md § 3

判据：
```
由一两位教授
+ 在好大学的固定课程上
+ 长期打磨
```

### 与现状的关系

```
M06 负责：静态资源入库
M07 负责：静态资料库
```

### 可能的用途

这套判据是**可核查的元数据**，不是主观评分：
```
可记录字段：
  - 是否由个别作者长期维护
  - 是否有对应的实际课程
  - 版次历史
```

Zhou 的反向判据：
```
超过10个版次的教材：
  新版收益不再成立
  倾向于被套公式习题和奇怪插图堆胀
```

### 要一并保留的否定判据

来源：02-methods.md § 3

| 类型 | 失效模式 |
|------|----------|
| 应试辅导书 | 为突击及格设计，最小努力通过最简单问题 |
| student-friendly 书 | 标榜友好实则降低标准 |
| 缺乏学生检验的书 | 错别字、平庸习题、难度断崖、关键遗漏 |

这些失效模式描述比单一质量分更有信息量

## § 6 社会性学习是自学的结构性缺口，Studium 未必能补

### 依据
- 来源：04-conflicts.md § 3 的结论
- 逻辑：Zhou 路线为课程提供的多数功能都给出了自学替代物

Zhou 提供的替代物：
```
课程功能 → 自学替代物
  节奏 → 每周一章
  反馈 → AP 模拟考 + 往年竞赛题
  专业判断 → 逐本书注明所需数学背景
```

Zhou 未覆盖的：
```
**社会性学习** → 没有替代物

证据：
  - Baez：找学习伙伴、去问答社区
  - Vakil：主要靠和人交谈来学习
  - Rusczyk：Calculus Trap 把同伴质量列为核心理由
```

### 为什么这条值得在产品文档里留痕

```
Studium 是单学习者系统

M02 的教学互动 + M03 的练习活动：
  可覆盖「有人给你反馈」
  
不能覆盖：
  「和同等水平的人争论同一个问题」

诚实的做法：
  把它记为已知边界
  不是假装 M02 能替代它
```

### 与 Vakil Three Things 的交叉

Vakil 的做法：
```
可执行部分（单人可做）：
  - 强制三件
  - 出现第四个时划掉一个

社交部分（不可单人）：
  - 与其他参与者比较各自记下的三件事
  - 他说这种比较「surprisingly enlightening」
```

## § 7 Zhou 对 LLM 的两种态度直接关系到 Studium 的定位

### 依据
- 来源：04-conflicts.md § 5
- 同一位作者的两种态度

Zhou 的区分：
```
不信任 LLM 作为：
  深入学习的媒介
  「about as good as Wikipedia for getting the gist」
  「not suitable for learning a subject deeply from scratch」

信任 LLM 作为：
  已有共识的汇总器
  把「中立询问 AI」的答案与自己和 Rigetti 的推荐并列
  作为共识证据
```

### 对 Studium 的含义

这个区分与 Studium 的现有架构方向意外一致：
```
Studium 不以「替学习者讲授答案」为目标
  M10 开头即如此声明

M07 保存的是：
  静态资料
  不是模型生成的解释

M02 的原则是：
  从学习者已经表现出的理解位置出发
  不过早给出完整答案
```

结论：
```
Studium 的定位更接近 Zhou 信任的那一侧
```

### 但这不构成背书

```
Zhou 的判断：
  一位从业者在特定时点的意见
  
本次调研：
  没有找到任何关于 LLM 辅助数理自学效果的对照研究

这一条只说明：
  现有架构方向与一位领域专家的判断不冲突
  
不说明：
  它有效
```

## § 8 一个尚未有模块归属的问题：流畅地谈论自己不懂的东西

### 依据
- 来源：02-methods.md § 9
- Vakil 描述的现象

现象：
```
真实且普遍：
  人会先学会正确使用一个词
  之后才知道它的精确定义

Vakil 术语：
  tendrils of knowledge + backfill

Vakil 评价：
  当作有用的捷径
  但附诚实性警告
```

Baez 的同一伦理的另一面：
```
1. 提问时明说置信度
2. 出错时公开承认
```

### 为什么它在 Studium 里没有明确归属

```
M04 判断诊断事实与证据限制：
  但这个现象的特征=学习者的表达看起来是对的
  证据层面不易触发

M09 保存个人形成记录并要求每层结构都有证据：
  但它接收的是已通过守卫的闭环结果

M15 处理非知识类状态：
  这个不属于状态
```

### 这可能是自学场景里最缺外部纠正机制的失效模式

```
特征：
  - 没有考试
  - 没有导师
  - 表现形式恰好=「看起来学会了」

是否要、以及在哪里处理它：
  值得单独讨论

但需要注意：
  Vakil 认为这条捷径本身**有价值**
  目标不是消除它
  而是确保 backfill 真的发生
```

## § 10 不要从这份调研里直接推出的东西

明确列出，避免误用：

### 1. 不要把书单当需求
```
各路线图的书目差异
  反映：作者偏好与目标差异
  不是：可以合并成一份权威列表的东西

参见：01-sources.md
```

### 2. 不要把 Freeman 2014 的主动学习效应量当作 Studium 有效性的依据
```
那是：课堂教学设计的对照结果
对照组：会在讲授中走神的平均学生

参见：03-evidence.md § 2
```

### 3. 不要引用 Hake 1998 的 0.23/0.48
```
本次调研未取到一手出处

参见：03-evidence.md § 4
```

### 4. 不要把 Zhou 的 400 小时当基准线
```
样本量为一
他本人的归因：投入的专注度与规律性，不是总时长
```

### 5. 不要把专家建议与实证结论混引
```
前者：可推广性未经检验
后者：只覆盖通用学习机制、不覆盖学科路径

参见：03-evidence.md § 8
```
