# 自学方法调研索引（数学物理）

## META

- 调研范围：数学、物理自学方法
- 证据类型：署名专家建议、同行评议论文、大学课程材料、个人经验报告
- 覆盖语区：英文
- 未覆盖：付费社群、中文社区、非数理领域
- 证据限制：专家建议不等于普适有效；实证研究聚焦通用学习机制而非学科路径

```
LEVEL_1: 同行评议论文，已读原文
LEVEL_2: 署名专家建议，已读原文
LEVEL_3: 二手引用，无原文核对
LEVEL_4: 个人经验报告（n=1）
```
