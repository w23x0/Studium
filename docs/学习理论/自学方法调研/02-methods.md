# 方法论主线

## META
- 用途：从来源归纳的方法论，按主题组织
- 格式：每条注明作者，「谁说的」决定推广范围

## § 1 理解的阶段性

### Tao 三阶段模型
- 作者：Terence Tao
- 证据等级：LEVEL_2

```
阶段1: pre-rigorous
  特征：靠直觉和计算
  表现：非形式、基于例子、模糊概念
  示例：微积分讲成斜率和变化率

阶段2: rigorous
  特征：学会形式精确
  动作：用严格逻辑重做熟悉材料
  重心：几乎全部转向理论与形式操作

阶段3: post-rigorous
  特征：形式基础牢固后回到直觉
  区别：此时直觉被严格性校准过
  能力：可随时按需转换成严格论证
```

关键断言：
- 「transition from second to third equally important, should not be forgotten」
- 严格性目的：不是摧毁直觉，而是筛掉坏直觉、加固好直觉

### Thurston 多重理解方式
- 作者：William Thurston
- 证据等级：LEVEL_2
- 示例：导数的七种理解方式

```
1. 无穷小
2. 符号
3. 逻辑
4. 几何
5. 变化率
6. 线性逼近
7. 显微镜
...
37. 纤维丛表述
```

关键发现：
- 理解方式原则上无终点
- 差异在「精确形式定义」中蒸发
- 个人过程：每种当作新东西吸收 → 消化 → 与其他调和 → 带新意义重访

对自学的含义：
- **「学过这个」≠「在哪个阶段学过」**
- 绝大多数自学计划只跟踪前者

## § 2 顺序依赖

### 三份路线图的顺序理由

#### Fowler
- 理由类型：知识依赖
- 表述：「each subject is built upon the previous subjects」
- 顺序：力学 → 静电学 → 波动 → 近代物理 → 经典力学 → 电动力学 → 量子力学 → 热统 → 选修

#### 't Hooft
- 理由类型：摩天楼比喻
- 警告：「Any omission will be punished: failure」
- 灵活性：「Not everything has to be done in this order」（近似顺序）

#### Kevin Zhou
- 理由类型：双线依赖（知识+数学工具）
- 处理：逐本书注明所需背景

```
Taylor 力学：
  数学需求：普通微积分
  引入时机：向量微积分逐步引入

Schroeder 热物理：
  数学需求：多变量微积分
  具体要求：多变量链式法则、多重积分

Griffiths 量子力学：
  数学需求：普通微积分
  引入时机：需要时引入一点线性代数
```

判断示例：
- 已掌握代数版力学 + 未开始代数版电磁学 → **先学微积分**
- 理由：没有微积分在电磁学和热力学里做不了什么

关键区分：
- 这类判断按**前置能力**排序
- 不是按学科名排序

## § 3 资料质量元标准

### Zhou 倒推论证
- 作者：Kevin Zhou
- 证据等级：LEVEL_2
- 方法：从「好书怎么产生」倒推判据

生产过程：
```
教师用教材上课
  ↓
形成自己路子写讲义
  ↓
学生年复一年找出错误
  ↓
教师修补 + 积累题库
  ↓
装订成书
```

两种活性成分：
```
成分1: 学生检验
  作用：充当试读者，逼迫逐年改进
  缺失后果：错别字、平庸习题、难度断崖、关键遗漏

成分2: 教师深厚专业能力
  要求：懂得远多于书中所含
  缺失后果：无原创性套公式习题、僵硬建议
```

可操作判据：
- **由一两位教授 + 好大学固定课程 + 长期打磨**

### 否定判据（带失效模式）

| 类型 | 失效模式 | Zhou 表述 |
|------|----------|-----------|
| 维基百科 | 遇矛盾时答案不在更多标签页里 | 只会放大困惑 |
| LLM (2025) | 与维基百科同级 | good for gist, not suitable for deep learning from scratch |
| YouTube 视频 | 作者前一天才学的基础 | 含糊、不准确、过长；想开3倍速=信息密度太低 |
| 应试辅导书 | 为突击及格设计 | 最小努力通过最简单问题，答不出更深问题 |
| student-friendly 书 | 标榜友好实则降低标准 | 自学时没理由用，because you have time to do it right |

Zhou 童年方法自我否定：
- 错误流程：Google → 开前十个链接 → 再开那些页面的所有链接
- 后果：五分钟问题耗掉一整天
- 比喻：书=光源，二手资料=投在各方向的影子

### Baez/Tao/Rusczyk 补充原则
- Baez：不要在知道已知什么之前扑向黑洞和弦论
- Tao：不要过早执着于单一大问题或大理论
- Rusczyk：Calculus Trap（进度≠变强）

## § 4 做题完整流程

### 所有来源的共识
- 做题=中心动作
- 分歧：做题之后干什么

### 各来源主张

```
Fowler:
  要求：必读书每一道都做
  重点：尤其 Griffiths 电动力学

Kevin Zhou:
  选书标准第三条：contain lots of good problems
  原因：这些书自洽、能预判误解、题目丰富

Tao:
  作业=诊断工具
  断言：homework 困难未解决 → 后续更多困难
  延伸动作：
    - 解出后继续搞这个问题（去假设、推向更强结论）
    - 理解判据：能否向同学讲清
    - 不能讲清 → 回去重做（cover up solution and try again）
  重要原则：部分进展=正当踏脚石，不是失败

Pólya 四步法:
  1. 理解问题
  2. 制定计划
  3. 执行计划
  4. Look back（最常被跳过）
```

Look back 内容：
- 检验结果合理性
- 确认所有已知条件都用上
- 复查推理
- 反思别的路子
- 这个方法还能用在哪里

### 完整动作序列

```
1. 独立尝试
2. 记录卡在哪
3. 得到解
4. 复述给别人 OR 盖住重做
5. 回顾方法适用边界
```

只完成步骤 1+3 = 退化版本

## § 5 听讲与读书的取舍

### Kevin Zhou 记录的因果链
- 现象：过去十年顶尖大学入门物理课改成 active learning
- 变化：讲授被小组解题取代，学生在家读背景材料
- 后果：好的入门物理录像变少

### 教育研究结论的适用边界
- 证据：active learning 对**平均**学生更有效
- 原因：传统讲授里那些人会走神
- 限制：如果你有动力到会自学，那条结论大概不适用于你

### Zhou 的实际推论
- **讲座不是必需的**
- 「You can do everything by just reading good books and thinking hard」
- 用讲座不必内疚

示范价值：
- 如何正确使用群体层面统计结论
- 它约束：默认教学设计
- 它不约束：个体的资料选择

## § 6 时间尺度

### Kevin Zhou 逐年记录
- 证据等级：LEVEL_4（n=1）
- 目标：IPhO 金牌

| 阶段 | 内容 | 投入 | 结果 |
|------|------|------|------|
| 9年级 | 学校预备微积分，不懂也没学物理 | — | — |
| 9年级暑假 | 「don't recall learning anything」，刷 RuneScape | — | — |
| 10年级 | 代数版入门物理+AP微积分，课上大量提问 | — | 勉强进 USAPhO，接近零分 |
| 10年级春/暑 | 自学微积分版物理，terrible 备考书+random google | ~150h | — |
| 11年级 | 读 Halliday/Resnick/Krane，**每周彻底理解一章**，穿插往年题 | 每周~10h，共~250h | IPhO 金牌 |

合计：~400h，分布在一年

### Zhou 的归因
- 「objectively, that isn't a lot of time」
- 差别不在总时长，在于：
  - **专注的**
  - **规律分布的**
- 「didn't need to cram, because immersed the whole time」

### 漏斗数字（Zhou 观察）
- 每 100 人问奥赛：
  - 75 人听说要通读书就走了
  - 剩 25 人说会读
    - 10 人真打开书
    - 5 人读过前几章
    - 1 人真正深入理解全书

### Scott Young MIT Challenge
- 证据等级：LEVEL_4（n=1）
- 时间尺度：12月、早期60h/周、后期35h/周
- 标准：通过期末考（≥50%分数）
- **不宜直接比较**：「通过考试」≠「深入理解」

## § 7 记忆不是理解的对立面

### Nielsen 立场
- 作者：Michael Nielsen
- 证据等级：LEVEL_2
- 核心主张：**基础事实和术语的流畅调用往往是理解高阶材料的最大障碍**
- 证据来源：国际象棋专长研究
- 机制：专家内化复杂心理组块，这种组块化而非原始智力解释专家表现

操作规则：
```
判断阈值：memorizing worth 10min future time → do it
问题要求：原子化、避免孤儿事实、避免是/否型
谁造卡：自己造 > 共享卡组（构造问题=精细编码）
何时有效：服务于具体个人项目
```

### Woźniak 20 条
- 作者：Piotr Woźniak（SuperMemo）
- 证据等级：LEVEL_2
- 前四条：
  1. 不理解不要记
  2. 先整体后拆分
  3. 先基础后复杂
  4. 最小信息原则
- 统一目的：「brain works in exactly same way at each repetition」

### Nielsen 具体用法
- 场景：读密集技术论文（AlphaGo）
- 流程：从基础术语问题开始造卡 → 逐步搭到高层概念问题
- 区别：不是「先读懂再记」，而是把造卡当作读论文的手段

## § 8 笔记组织方式

### Matuschak Evergreen Notes
- 作者：Andy Matuschak
- 证据等级：LEVEL_2

五条原则：
```
1. 原子化
2. 以概念为组织单位（不按来源/日期/项目）
3. 密集链接
4. 联想优于层级
5. 为自己写而非为想象读者写
```

底层目标：effectively developing insight（不是笔记技巧）

### Vakil Three Things
- 作者：Ravi Vakil
- 证据等级：LEVEL_2
- 成本：低于 Evergreen Notes

流程：
```
1. 听报告时带一张空白纸
2. 目标：结束时纸上恰好3样具体的东西
3. 候选类型：定义/定理/关键例子/动机问题/给讲者的问题
4. 不算：模糊印象
5. 出现第4个候选 → 回看已有3个 → 划掉1个
```

作者自评：
- 2007 前后试过
- 后来因厌倦形式而放弃
- 仍然推荐（尤其早期研究生或跨领域报告）

## § 9 学习伦理

### Vakil 的现象描述
- 作者：Ravi Vakil
- 证据等级：LEVEL_2
- 现象：会在真正知道精确定义之前，就已能正确使用该词、用它造句和提问
- 术语：tendrils of knowledge extending far from comfort zone
- 策略：之后 backfill 回填
- 评价：比严格按顺序 forwards 学要容易得多

警告：
- 反对：using fancy words in fancy sentences 而缺乏真实精确性
- 要求：如果这么做了却始终不回头补上，应该「feel a pang of guilt」

### Baez 社交建议
- 作者：John Baez
- 证据等级：LEVEL_2

两条原则：
```
1. 提问时明说置信度
2. 出错时公开承认
```

理由：
- 声称确定却出错 → make you look dumb
- 不承认错误 → 滑向 crackpot 式固执

### 为什么单列这一组
- 原因：处理**流畅地谈论自己不懂的东西**这一失效模式
- 特征：自学场景里几乎没有外部纠正机制
  - 没有考试
  - 没有导师
  - 表现形式=「看起来学会了」
- 注意：Vakil 认为这条捷径本身**有价值**
- 目标：不是消除它，而是确保 backfill 真的发生
