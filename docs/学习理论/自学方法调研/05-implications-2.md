## § 6 社会性学习是自学的结构性缺口，Studium 未必能补

### 依据
- 来源：04-conflicts.md § 3 的结论
- 逻辑：Zhou 路线为课程提供的多数功能都给出了自学替代物

Zhou 提供的替代物：
```
课程功能 → 自学替代物
  节奏 → 每周一章
  反馈 → AP 模拟考 + 往年竞赛题
  专业判断 → 逐本书注明所需数学背景
```

Zhou 未覆盖的：
```
**社会性学习** → 没有替代物

证据：
  - Baez：找学习伙伴、去问答社区
  - Vakil：主要靠和人交谈来学习
  - Rusczyk：Calculus Trap 把同伴质量列为核心理由
```

### 为什么这条值得在产品文档里留痕

```
Studium 是单学习者系统

M02 的教学互动 + M03 的练习活动：
  可覆盖「有人给你反馈」
  
不能覆盖：
  「和同等水平的人争论同一个问题」

诚实的做法：
  把它记为已知边界
  不是假装 M02 能替代它
```

### 与 Vakil Three Things 的交叉

Vakil 的做法：
```
可执行部分（单人可做）：
  - 强制三件
  - 出现第四个时划掉一个

社交部分（不可单人）：
  - 与其他参与者比较各自记下的三件事
  - 他说这种比较「surprisingly enlightening」
```

## § 7 Zhou 对 LLM 的两种态度直接关系到 Studium 的定位

### 依据
- 来源：04-conflicts.md § 5
- 同一位作者的两种态度

Zhou 的区分：
```
不信任 LLM 作为：
  深入学习的媒介
  「about as good as Wikipedia for getting the gist」
  「not suitable for learning a subject deeply from scratch」

信任 LLM 作为：
  已有共识的汇总器
  把「中立询问 AI」的答案与自己和 Rigetti 的推荐并列
  作为共识证据
```

### 对 Studium 的含义

这个区分与 Studium 的现有架构方向意外一致：
```
Studium 不以「替学习者讲授答案」为目标
  M10 开头即如此声明

M07 保存的是：
  静态资料
  不是模型生成的解释

M02 的原则是：
  从学习者已经表现出的理解位置出发
  不过早给出完整答案
```

结论：
```
Studium 的定位更接近 Zhou 信任的那一侧
```

### 但这不构成背书

```
Zhou 的判断：
  一位从业者在特定时点的意见
  
本次调研：
  没有找到任何关于 LLM 辅助数理自学效果的对照研究

这一条只说明：
  现有架构方向与一位领域专家的判断不冲突
  
不说明：
  它有效
```

## § 8 一个尚未有模块归属的问题：流畅地谈论自己不懂的东西

### 依据
- 来源：02-methods.md § 9
- Vakil 描述的现象

现象：
```
真实且普遍：
  人会先学会正确使用一个词
  之后才知道它的精确定义

Vakil 术语：
  tendrils of knowledge + backfill

Vakil 评价：
  当作有用的捷径
  但附诚实性警告
```

Baez 的同一伦理的另一面：
```
1. 提问时明说置信度
2. 出错时公开承认
```

### 为什么它在 Studium 里没有明确归属

```
M04 判断诊断事实与证据限制：
  但这个现象的特征=学习者的表达看起来是对的
  证据层面不易触发

M09 保存个人形成记录并要求每层结构都有证据：
  但它接收的是已通过守卫的闭环结果

M15 处理非知识类状态：
  这个不属于状态
```

### 这可能是自学场景里最缺外部纠正机制的失效模式

```
特征：
  - 没有考试
  - 没有导师
  - 表现形式恰好=「看起来学会了」

是否要、以及在哪里处理它：
  值得单独讨论

但需要注意：
  Vakil 认为这条捷径本身**有价值**
  目标不是消除它
  而是确保 backfill 真的发生
```

## § 10 不要从这份调研里直接推出的东西

明确列出，避免误用：

### 1. 不要把书单当需求
```
各路线图的书目差异
  反映：作者偏好与目标差异
  不是：可以合并成一份权威列表的东西

参见：01-sources.md
```

### 2. 不要把 Freeman 2014 的主动学习效应量当作 Studium 有效性的依据
```
那是：课堂教学设计的对照结果
对照组：会在讲授中走神的平均学生

参见：03-evidence.md § 2
```

### 3. 不要引用 Hake 1998 的 0.23/0.48
```
本次调研未取到一手出处

参见：03-evidence.md § 4
```

### 4. 不要把 Zhou 的 400 小时当基准线
```
样本量为一
他本人的归因：投入的专注度与规律性，不是总时长
```

### 5. 不要把专家建议与实证结论混引
```
前者：可推广性未经检验
后者：只覆盖通用学习机制、不覆盖学科路径

参见：03-evidence.md § 8
```
