## 二、B 类理论的阶段适配方案

### 设计思路：不是写两套理论，而是加"适配参数层"

B 类理论的核心机制不变，变的是三个东西：
1. 操作对象（从"题"变为"证明/论文/实验"）
2. 判据标准（从"正确率"变为"能否产出/解释/迁移"）
3. 时间尺度（从"一次作业"变为"一个研究周期"）

系统架构中的处理：每个 B 类理论增加 `stage_profile` 字段，Agent 策略层根据学习者当前阶段读取对应 profile 做决策。

### 举例：三个核心理论的适配

#### 最小学习单元理论 — 闭环粒度适配

初高中闭环：
- 对象 = 单知识点
- 完成判据 = 基础题正确率稳定
- 典型周期 = 30min ~ 3天
- 嵌套 = 无或一层

大学闭环：
- 对象 = 概念体系（如"线性变换的完整理解"）
- 完成判据 = 能独立推导核心定理 + 能识别应用场景 + 能解释给他人
- 典型周期 = 3天 ~ 2周
- 嵌套 = 2-3层（子概念闭环 → 体系闭环 → 跨域连接闭环）

研究生闭环：
- 对象 = 方法/理论框架（如"有限元方法的完整掌握"）
- 完成判据 = 能复现经典结果 + 能在新问题上应用 + 能判断适用边界
- 典型周期 = 2周 ~ 2月
- 嵌套 = 3-4层（概念→方法→应用→创新）

#### 有效练习理论 — 练习形式适配

初高中"练习"：
- 形式 = 做题
- 有效标准 = 思考→反馈→内化 完整路径
- "练够"判据 = 不费脑力 + 高正确率
- 限时训练 = 考前最后阶段

大学"练习"：
- 形式 = 推导证明 / 编程实现 / 实验设计 / 文献复现
- 有效标准 = 能独立完成完整推导 + 能变换条件重新推
- "练够"判据 = 能脱离参考独立完成 + 能处理变式
- "限时"对应 = 考试周集中训练（日常不限时）

研究生"练习"：
- 形式 = 复现论文结果 / 推广已有定理 / 设计实验验证假设
- 有效标准 = 能发现原文未言明的假设 + 能找到改进空间
- "练够"判据 = 能向他人讲清方法的适用条件和局限
- 注意 = 不存在"标准答案"，练习终点是产出而非正确

#### 任务管理理论 — 核心任务识别适配

初高中：
- 核心任务来源 = 外部（考试/作业/老师要求）
- 识别难度 = 低（考哪门就学哪门）
- 标准 = 由考试定义（分数）

大学：
- 核心任务来源 = 半外部（课程框架+自选方向）
- 识别难度 = 中（需判断哪些课的哪些部分是真正核心）
- 标准 = 部分外部（考试）+ 部分自定义（理解深度）

研究生：
- 核心任务来源 = 内部（自己的研究问题）
- 识别难度 = 高（"什么值得研究"本身就是核心能力）
- 标准 = 几乎完全自定义（能否产出有意义的结果）
- 特殊问题 = 核心任务可能在进行中才逐渐清晰，需容忍模糊期

#### 理解理论 — 四级模型重心适配

初高中：
- 重心 = 1→2→3 级递进
- 3级含义 = 能解释公式推导、知道使用条件
- 4级含义 = 综合题中灵活组合多个知识点
- 被动学习天花板 = 好老师带到接近3级

大学：
- 重心 = 3→4 级，且3级深度天花板大幅提高
- 3级含义 = 能解释"为什么这样定义"、定理证明思路、概念间逻辑依赖、体系整体结构
- 4级含义 = 在全新问题中识别并调用该概念，跨课程/跨领域迁移
- 被动学习天花板 = 好教材只能接近3级，4级必须靠独立思考+跨域联想

研究生：
- 重心 = 4级内部分化（4a近迁移→4b远迁移→4c创造性迁移）
- 3级含义 = 理解方法设计动机、适用条件、与其他方法的关系、历史演化
- 4a = 同领域新问题上应用已知方法
- 4b = 跨领域映射（A领域方法用在B领域）
- 4c = 迁移过程中产出新方法/新理论（博士核心能力）
- 被动学习天花板 = 读论文只到2级（复现），带问题批判性读才到3级

#### 信息加工理论 — 加工策略适配

初高中：
- 主输入通道 = 课堂视听（教师驱动组织）
- 加工方式 = 被动接收已组织好的信息
- 双重编码 = 教师同时提供语言讲解+板书图示，自然发生
- 费曼法定位 = 可选的加速器（有作业和提问强制输出）

大学：
- 主输入通道 = 教材/讲义文本（学习者自己驱动）
- 加工方式 = 必须主动从原始文本提取并组织信息、自己构造心理模型
- 双重编码 = 需要刻意切换（抽象推导→画图/几何直觉；直觉内容→精确语言）
- 费曼法定位 = 核心必需（缺外部强制输出，不做则停留在"读了≈懂了"幻觉）

研究生：
- 主输入通道 = 论文（高度压缩，省略大量中间步骤）
- 加工方式 = 补全省略步骤 + 批判性评估 + 跨文本综合建模
- 双重编码 = 需要多模态切换（代码/实验数据/公式/图示之间）
- 费曼法定位 = 组会报告和论文写作就是制度化的费曼法

#### 输入与练习的不可替代性 — 两侧形态适配

初高中：
- 输入 = 听课、看教材、看视频
- 练习 = 做习题、写作业
- 错位典型 = 不断补课但不做题 / 疯狂刷题概念不清

大学：
- 输入 = 精读教材、读讲义、读参考书（课堂降级为索引）
- 练习 = 推导证明 / 编程实现 / 开放式习题 / 课程项目
- 错位典型 = 反复看教材不动手推（缺练习）/ 直接刷题概念体系未建（缺输入）
- 特殊点 = 大学教材中"证明过程"本身就是核心输入，不可跳过

研究生：
- 输入 = 前沿论文、学术专著、学术报告、导师指导
- 练习 = 复现论文 / 在新问题上应用方法 / 设计实验 / 论文写作
- 错位典型 = 无止境读论文不动手（缺练习）/ 一头扎进实验不看文献（缺输入）
- 特殊点 = 输入和练习边界模糊（带问题读论文=同时做两件事；写作暴露理解漏洞）

#### 有效练习理论 — 练习质量标准适配

初高中：
- 反馈来源 = 答案对不对
- 题目利用度 = 每个选项精细化思考 + 脱离题目分析所有关系
- 无效信号 = 用排除法/蒙答案

大学：
- 反馈来源 = 推导是否严谨？逻辑链是否完整？是否抓住关键步骤？
- 题目利用度 → 证明利用度 = 理解每步动机 + 能变换条件重推
- 无效信号 = 抄参考答案步骤不理解为什么这样走

研究生：
- 反馈来源 = 实验是否符合预期？推广是否自洽？同行评审意见
- 题目利用度 → 论文利用度 = 识别隐含假设 + 找可改进点 + 想可推广方向
- 无效信号 = 机械重复已会实验 / 照搬方法不理解原理

#### 题目的功能分类与深度学习 — 分类对象适配

初高中：
- 分类对象 = 习题册里的题
- 四象限 = 高/低功能性 × 高/低难度
- 深度方法 = "备课心态"（为什么这么做→提炼分析章法）
- 有效提问 = "为什么想到这样做""什么情况下用类似思路"

大学：
- 分类对象 = 证明题 / 计算题 / 设计题 / 开放题
- 四象限适配 = 高功能性=能训练核心思维方式；低功能性=机械计算/已熟练套路
- 深度方法 = "定理精读心态"（为什么定义要这样设？证明关键跳跃在哪步？）
- 有效提问 = "这个证明策略还能用在哪类问题上？""去掉某个条件会怎样？"

研究生：
- 分类对象 = 研究问题 / 论文选题 / 方法比较
- 四象限适配 = 高功能性=能推进自己研究；低功能性=与研究方向无关的技术细节
- 深度方法 = "审稿人心态"（假设合理吗？结论是否过度推广？有无更好方案？）
- 有效提问 = "这个方法的本质限制是什么？""如果换一种建模方式会怎样？"

#### 直觉形成理论 — 直觉对象适配

初高中：
- 直觉对象 = 题型模式识别（条件特征→对应解法）
- 养成方式 = 对同类题归类分析，积累逻辑链类型
- 两种直觉 = 找核心条件 + 识别情境

大学：
- 直觉对象 = 方法选择直觉（问题结构→合适工具）
- 养成方式 = 对同类问题尝试不同方法，比较各自适用条件
- 大学独有 = "数学品味"——哪个定义更自然、哪种推广更有意义

研究生：
- 直觉对象 = 问题嗅觉（什么值得研究）+ 理论连接直觉（跨领域结构类比）
- 养成方式 = 大量阅读 + 主动寻找不同领域间的结构相似性
- 研究生独有 = 品味——哪些问题有深度、哪些方向有前景、哪些结果trivial

#### 信息处理能力 — 五步载体适配

| 步骤 | 初高中载体 | 大学载体 | 研究生载体 |
|------|-----------|---------|-----------|
| 摄入 | 听课/看书 | 精读教材/讲义 | 读论文（需补全省略步骤） |
| 甄别 | 判断重要程度 | 判断主次/参考资料质量 | 判断方法可靠性和结论有效性 |
| 分类 | 按知识点/章节归类 | 建立概念层次/方法分类体系 | 建立领域知识地图/方法论谱系 |
| 连接 | 知识点间关联 | 跨课程关联（线代与微方程） | 跨领域结构类比/方法迁移 |
| 调取 | 做题时调用 | 面对新问题选择工具 | 面对研究问题调用方法论直觉 |

#### 三阶段瓶颈与模式递进 — 阶段锚点适配

初高中：
- 锚点 = 考试分数（~40%/~65%/~80%）
- 第一阶段 = 不及格，缺基本听课和练习
- 第二阶段 = 中游，题刷了但利用度低
- 第三阶段 = 高分段，需系统分析能力

大学：
- 锚点 = 不再以分数为唯一标准
- 第一阶段 = 不看教材不做作业/跟不上课程 → 补行为
- 第二阶段 = 能过考试但无法独立解决新问题 → 补训练质量
- 第三阶段 = 能解题但缺体系感和跨域视角 → 补思维连接
- 替代判据 = 能否独立完成课程项目/能否解释核心概念体系

研究生：
- 锚点 = 研究产出能力
- 第一阶段 = 不读文献不做实验 → 补行为习惯
- 第二阶段 = 能复现但不能创新 → 补在新问题上的应用尝试
- 第三阶段 = 能做出结果但不能判断意义 → 补问题品味和取舍能力
- 替代判据 = 能否独立完成从问题到论文的全流程

#### 学习者效能理论 — 四象限判据适配

初高中：
- 行为主导性 = 能否坐下来学习（对抗手机/娱乐）
- 价值判断 = 能否选对方法和重点（应试框架内）
- Q2 = 想法多但不执行，Q4 = 猛学但方法错

大学：
- 行为主导性 = 在高自由度环境中能否自主启动（无人监督/无固定作业）
- 价值判断 = 能否判断哪些课程/内容真正核心（选课/深度/广度取舍）
- Q2 = 有清晰规划但执行力差，Q4 = 很努力但选错方向（只做模板题/考前突击背诵）

研究生：
- 行为主导性 = 在极高不确定性中能否持续推进（无明确任务/无人催促/反馈周期长）
- 价值判断 = 研究方向选择、问题识别、方法判断（"什么值得做"）
- Q2 = 有想法有品味但不动手（论文焦虑/完美主义），Q4 = 疯狂做实验但方向偏/只做trivial工作
- 特殊点 = 错误代价从数周扩大到数月甚至数年

#### 信息差与外部资源利用 — 信息差来源适配

初高中：
- 提供者 = 老师
- 三类信息差 = 知识系统性 / 学习规划经验 / 前沿政策
- 弥补 = 找好老师/好网课

大学：
- 提供者 = 教授/助教/学长/学术论坛/教材作者
- 知识系统性 = 教授课程设计体现知识结构（但不再手把手教）
- 规划经验 = 学长的选课/考研/学习路径建议
- 前沿信息 = 各方向趋势/就业/保研政策
- 功利化陷阱 = 只看考试重点跳过概念理解

研究生：
- 提供者 = 导师/组会/同行评审/学术会议/论文引用网络
- 知识系统性 = 导师对领域全景把握（"哪些工作重要哪些灌水"）
- 规划经验 = 导师对研究路径的指导（"该读什么/做什么实验"）
- 前沿信息 = 最新动态/审稿趋势/基金方向
- 功利化陷阱 = 只看能直接用在论文里的内容 → 知识面狭窄

#### 完美主义错配理论 — "够了"标准适配

初高中：
- 应避免 = 听课理解/笔记格式/作业（七八成即推进）
- 应施展 = 能力边缘的题目/知识点闭环

大学：
- 应避免 = 文献初筛/课堂笔记/非核心课作业/教材首遍阅读
- 应施展 = 核心概念推导/课程项目/重要考试/毕业设计
- 典型错配 = 排版/笔记美观花大量时间 / 低优先级课投入同核心课一样

研究生：
- 应避免 = 文献调研阶段/实验初期探索/草稿初版/组会报告
- 应施展 = 论文终稿/核心实验严谨性/方法的数学证明
- 典型错配 = 文献调研无止境 / 初期实验追求完美导致进展极慢
- 特殊判据 = 当前处于探索期还是收敛期？探索期避免，收敛期施展

#### 学习与备考的区分 — 模式切换适配

初高中：
- 两种模式 = 学习（探索）vs 备考（工程）
- 切换时机 = 考前若干周固定切换
- 粒度 = 以学期为单位，阶段分明

大学：
- 模式 = 探索 vs 工程，切换更频繁
- 切换时机 = 课程=主要工程模式；选修/兴趣=探索；课程项目=混合
- 粒度 = 以周或任务为单位
- 新增难点 = 整学期探索模式→考试周才切工程→来不及

研究生：
- 模式 = 探索（文献/方向/idea发散）vs 工程（写作/实验/deadline）
- 切换时机 = 早期=探索为主；确定方向=工程为主；卡住=重回探索
- 粒度 = 以天甚至小时为单位
- 新增难点 = 长期探索不收敛 / 过早进入工程导致方向错误
- 判断标准 = 目标/范围/方法三者明确→工程模式；任一不明确→保持探索

### 系统实现原则

1. 理论的核心机制写死在系统底层（不随阶段变）
2. 阶段参数作为配置层覆盖在上面（随学习者状态切换）
3. Agent 策略层读取当前阶段参数做具体决策
4. 同一个学习者可能在不同科目处于不同阶段
