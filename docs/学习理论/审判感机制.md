# 审判感机制（Judgment Pressure）

> 状态：**参考材料**（2026-09-21 从 Deep 档案转入，仅重排语言与结构，未改内容）

> 原文定位：心理干扰模块 —— 解释练习过程中自我评价压力如何消耗认知资源

## 1 核心论述

审判感 = 对学习活动附加的**自我评价压力**：把每次练习都当成能力检测。它是学习过程中最隐蔽的认知资源耗散源之一。

问题在于：练习本应是训练工具，审判感把它变成了**检测场景**，于是每道题都在额外消耗情绪能量。

## 2 机制

### 2.1 危害是怎么发生的

| # | 危害 | 怎么发生 |
| --- | --- | --- |
| 1 | 认知资源持续耗散 | 每道题都分配精力去做自我评价 |
| 2 | 直接触发三系统疲劳 | 高压力 + 低反馈 |
| 3 | 产生大量「未完成感」 | 每道错题都变成一个「我不行」的未关闭循环 |

### 2.2 审判感从哪来

- 从小被训练出「每次练习 = 能力检测」的认知模式
- 缺乏外部反馈时，学习者会**自动补偿性地做自我检测**
- 完美主义倾向：把结果与自我价值直接挂钩

### 2.3 消解策略（原文给的）

| 策略 | 做法 |
| --- | --- |
| 稀释审判频率 | 把逐题的隐性检测换成**阶段性的显性验收**，让审判感几十道题才出现一次 |
| 功能性拆解 | 对检验结果做**功能性拆解（漏洞筛查）**，而不是价值判断 |
| 练习与测试分离 | 主动区分「练习模式」与「检测模式」；练习时不评判对错的意义 |

## 3 与其它模型的关系

| 关联模型 | 关系 |
| --- | --- |
| 三系统疲劳模型 | 审判感带来的「高压力 + 低反馈 + 未完成感」是三系统疲劳的直接触发条件 |
| 蔡格尼克效应与认知资源耗散 | 每道错题在审判感下都变成未关闭的后台任务 |
| 学习者效能理论（Q2 关注区） | 与 Q2 的「关注区膨胀」是同一现象的不同切面：都把精力从问题本身转移到自我评价上 |
| 行为优先干预 CBT | 审判感导致认知卡死时，行为优先干预是直接对策 |

## 4 原文自带的协助设想

> 原文列的清单（前 LLM 时代设想），**不是本仓库的设计结论**，仅作参考。

- **替代逐题评判**：由 AI 承担评判与反馈，学习者只需专注思考过程，不需要自我评分
- **阶段性验收设计**：设置合理的验收节点（原文举例：每 30 题一次检验），自动稀释审判频率
- **功能性反馈**：对错误只做「漏洞定位」式分析，不做价值判断——把「你不行」转成「这个点需要补」
- **情绪隔离**：AI 作为中间层隔离学习者与原始对错数据，只在验收节点呈现整体分析
