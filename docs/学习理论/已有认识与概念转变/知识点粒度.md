# 知识点粒度：一个点切多大

> 状态：**参考材料，不作产品结论**（2026-10-05，线索 #22 / B2）。问题：按闭环定义（从一组出发点学一个新点、一次坐下来理解到目标层次），M08 的点切多大。
> 来源：researcher 子代理 10-05 调研；主会话抽查 Sweller 1994 p.305–306、KLI 草稿 L713–719、Roa-Fuentes & Oktaç 2010（GD 不唯一句），属实。

## 取舍

| 内容 | 判定 | 去向 |
| --- | --- | --- |
| 单元大小相对学习者：什么算一个元素取决于学习者已有图式，离开学习者无法给出（Sweller 1994） | 采纳（产品负责人 10-05 认可） | 点的大小相对一组出发点；M05 圈点簇时按学习者 |
| 只拆到“刚好高于目标人群已熟练的那一层”，更低层当原子（KLI，Koedinger 等 2012） | 采纳（同上） | 出发点已熟练 = 下限；与闭环定义同构 |
| 一个概念的构造路径（genetic decomposition，GD）不唯一，取决于构造路径与个体已有结构；GD 是研究者假设、可被数据修订（APOS） | 采纳（同上） | 一个新点可有几组出发点（B2） |
| 两类任务难度差 = 多出一块前置，应拆开（Learning Factors Analysis / Difficulty Factors Assessment） | 只借逻辑 | “太粗”信号：同一簇的不同部分要不同出发点；统计方法依赖重复练习日志，不可用 |
| 导数四种表示 × 三层（Zandieh 2000，二手）；三个世界 / 局部直线（Tall & Katz 2014） | 只作线索 | 出发点分类提示；不是点内粒度判据 |
| 学习进阶 grain size、Sfard 过程-对象、Tall & Vinner 概念意象、Simon 假设性学习轨迹、Pardos 技能模型粒度 | 不采用 / 只作词汇 | 量级不对（年级跨度、秒级）或与仓库已有重复，不给粒度判据 |

没有文献用“一次坐下来”（小时级）定粒度；没找到“ln 先积分定义 vs 先反函数定义”对理解影响的实证。

## 产品负责人判断（2026-10-05）

| 项 | 内容 |
| --- | --- |
| 最小单位 | M08 现在的细点（一条定义 / 定理 / 方法）作最小单位没问题；M08 作通用框架要大容量（后续多用户数据、更多 token） |
| 点簇 | 闭环的“新点”对应 M08 上一簇点，合理；出发点符合闭环定义 |
| 储存层不需要粒度 | “一个学习单位多大”是消费层概念（M05 等）；储存层只要最小单位：能锚到原文一段、能用一个名字说清（定义 / 定理 / 方法 / 例子），更细的留在原文；现抽取基本已到这一下限 |
| 信息量从哪来 | 不靠切细，靠子句与连线多（一个点挂几个子句，跨书、跨学习者累加）+ 原文保留（点是原文索引，细节经工具读）；“出发点组”统一叫子句（`../../同类项目对照/05-ALEKS-知识空间理论.md`） |
| 要看的 | 信息量：存的是给模型看的文字，按模型真正需要什么来定存储的结构、内容、怎么给模型；这些还不清楚，暂不能做实验 |

## 发现

| 理论 · 出处 | 怎么定粒度 | 对我们的用处 | 强度与边界 |
| --- | --- | --- | --- |
| 元素交互性（Sweller 1994, Learning and Instruction 4:293–312） | 元素 = 需要学的任何信息；能串行学 = 低交互，必须同时学 = 高交互；“精确度量独立于学习者不可得，什么构成一个元素受个人知识影响” | 点无绝对大小；不需要出发点组合、一句话讲完 = 太细；一簇里同时处理的交互元素过多 = 太粗 | 一手。负荷是工作记忆瞬时量，不是“一次坐下来”，只借“交互 + 相对图式” |
| Knowledge component（Koedinger, Corbett & Perfetti 2012, Cognitive Science 36(5)） | KC = 从一组相关任务表现推断出的习得单元；分析层取刚好高于已熟练的一层，“前提是目标人群已掌握” | 出发点已熟练 = 下限 | 一手，读的是作者工作稿 v5.00（未对定稿）；KC 约 10 秒一步，比我们的点小；美国课程 |
| Genetic decomposition（Roa-Fuentes & Oktaç 2010, RELIME 13(1)；Oktaç, Trigueros & Romo 2019, FLM 39(1)；Borji 等 2018, EJMSTE 14(7)） | GD = 构造一个概念所需心理结构与机制的假设模型，“假设 → 教学 → 数据 → 修订”；“不存在唯一的 GD，因为依赖构造路径与个体已有结构”；例：导数从割线斜率（动作）→ b→a 过程 → 切线对象 | 每组出发点 = 已有的动作 / 过程 / 对象；一个 GD 含 3–7 步构造，比 M08 一个点大，接近一个闭环 | 一手。样本：线性代数（RELIME）、伊朗大一 50 人（Borji）；GD 是假设不是实测 |
| Learning Factors Analysis（Cen, Koedinger & Junker 2006；Liu & Koedinger 2017, JEDM 9(1)） | 学习曲线出 blip = 技能太笼统；例：圆面积正向 / 反向，反向多要开平方 → 拆成两个 | “太粗”信号的外部证据 | 一手。课堂复验 N=91（美国一所高中 10 年级），d=0.47，但同时改了提示与练习分配，效应不只属于拆分 |
| 本机 M08 抽取（`studium-m08-data`） | 现在一点 = 一条定义 / 定理 / 方法；Spivak 2410 点、Stewart 中文本 4463 点 | Spivak K508–K515（ln 积分定义 → 导数 → 性质 → exp 为反函数）共用一组出发点，一次坐下来可连着走完 → 闭环新点 ≈ 一簇点；同一点（ln）在别的书里是 e^x 的反函数，现关系表存不下“另一组出发点” | 一手（本机数据），子代理读取 |
