## 【属于什么理论模块】

生理基础模块 — 将学习状态拆解为四个环节×九种神经物质，提供生理层面的诊断和调节框架

## 【核心论述】

学习状态不是玄学，是九种神经物质共同作用的结果。状态问题要先定位是哪个环节出了问题（愿不愿意→能不能开始→效率如何→能不能持续），再对应调节相关物质。所有优化都是长线过程，没有立竿见影的技巧。

## 【机制/模型】

### 四部门架构

| 部门 | 对应环节 | 负责物质 |
|------|---------|---------|
| 动力部门 | 愿不愿意学 | 多巴胺 |
| 行动力部门 | 能不能开始学 | 血清素、睾酮、内啡肽 |
| 质量部门 | 学的过程效率 | 去甲肾上腺素、乙酰胆碱、BDNF |
| 持续性部门 | 能不能持续学 | 皮质醇、褪黑素 |

### 行动力部门（启动行为）

| 物质 | 作用 | 提升方式 |
|------|------|---------|
| 血清素 | 稳定情绪、对抗挫败感 | 中强度有氧运动（短期提升数小时，长期提升基础水平） |
| 睾酮 | 冒险精神、行动意愿 | 力量型运动 + 保持低体脂 |
| 内啡肽 | 坚持后的奖励感 | 只在做合适挑战并坚持到一定程度时出现，无长期效应 |

诊断：任务制定合理但每次开启行动都困难 → 行动力部门问题

### 质量部门（学习效率）

| 物质 | 作用 | 提升方式 |
|------|------|---------|
| 去甲肾上腺素 | 短期聚焦注意力、提升反应速度 | 选择合适任务训练，逐步拓展难度，维持正常阈值 |
| 乙酰胆碱 | 神经元间信号传递（思考和记忆的核心） | 短期：饮食+睡眠；长期：运动+好的思考习惯 |
| BDNF | 升级神经传输带宽 | 中强度运动后2-3小时峰值；长期：运动+Omega-3+类黄酮+控制热量 |

### 持续性部门（长期可持续）

| 物质 | 作用 | 调节方式 |
|------|------|---------|
| 皮质醇 | 压力源（短期正面，长期破坏） | 精神压力导致的高皮质醇无捷径，靠长期行为慢慢降 |
| 褪黑素 | 负责睡眠 | 规律生物钟，避免干扰因素 |

**睡眠的三个不可替代作用：**
1. 重置多巴胺、去甲肾上腺素、皮质醇至正常水平
2. 自动强化白天新建立的神经连接
3. 清除β-淀粉样蛋白（代谢废物，长期积累不可逆地损害神经元）

### 多巴胺（动力系统，最特殊）

**产生方式：**
- 方式一：有预期就会产生（包括幻想）
- 方式二：预期→行动→结果，根据结果与预期的关系给波动

**两个不可利用的"bug"：**
- 只预期不行动 → 预期通货膨胀 → 奖励系统崩坏 → 对一切丧失兴趣
- 刻意降低预期 → 大脑判定无效目标 → 达到了也不给奖励

**良性动力系统：**
预期（差不多准确）→ 行动 → 反馈 → 修正预期 → 循环

健康节奏 = 一个个小任务小循环构成，不靠宏伟目标直接驱动

## 【与哪些模型有关系】

- → [[三系统疲劳模型]]：多巴胺系统疲劳是三系统之一，本模型提供了更完整的生理全景
- → [[蔡格尼克效应与认知资源耗散]]：未完成任务堆积→皮质醇升高→持续性部门受损
- → [[最小学习单元理论]]：良性多巴胺循环 = 小闭环完成后获得反馈奖励
- → [[行为优先干预CBT]]：内啡肽只在行动后出现，验证了"先行动后感受"的原则
- → [[有效练习理论]]：去甲肾上腺素的保养需要"选择合适任务逐步拓展"，与渐进练习一致

## 【AI可以在这个模型有什么帮助】

- **状态环节诊断**：AI通过提问定位问题在哪个部门（不想学？启动难？效率低？无法持续？）
- **多巴胺循环维护**：AI设计"预期准确"的小任务循环，避免目标过高或过低
- **睡眠/运动提醒**：AI在检测到持续性下降时，提醒生理基础维护
- **BDNF窗口利用**：AI建议在运动后2-3小时内安排高质量学习任务
- **皮质醇预警**：当学习计划过密或任务堆积时，AI预警长期压力风险
