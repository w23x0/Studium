## 【属于什么理论模块】

学习资源模块 — 识别自学中缺失的结构性信息优势，以及如何弥补

## 【核心论述】

老师（或高质量外部指导）提供三类信息差。自学者缺乏这些信息差时，需要自觉识别缺口并主动弥补，否则容易陷入"功利化听课+选择化理解+低效刷题"的恶性循环。

## 【机制/模型】

### 三类信息差

| 类别 | 内容 | 价值 | 自学如何弥补 |
|------|------|------|-------------|
| 知识系统性 | 老师把零散知识提炼为层次清晰、主次分明的框架，可从不同角度重组输出 | 纯自学中最难弥补的一点 | 找多个高质量信息源交叉验证；用AI辅助构建知识结构 |
| 学习规划经验 | 对不同阶段、不同问题如何高效解决的经验（不是会做题=好老师） | 避免走弯路 | 学习理论框架+AI动态规划+实践中验证迭代 |
| 前沿/政策信息 | 命题变化、考试信息、领域动态 | 方向不跑偏 | 关注官方信息源，避免未经确认的二手信息 |

### "功利化听课"的恶性循环（自学者同样适用）

自学版本：只看"能直接解题"的内容 → 跳过概念理解 → 底层积木打歪 → 上层理解崩塌 → 归纳无法进行 → 只能低效刷题 → 自我怀疑"理解力差"

```
功利化输入 → 概念漏洞 → 底层积木歪 → 上层理解崩塌
                                         ↓
                          归纳进行不下去 → 只能低效刷题
                                         ↓
                                    自我怀疑（假性理解力差）
```

**真相：** 绝大部分"理解力差"不是天生的，而是底层概念理解被跳过后的连锁反应。

### 自学者的信息差弥补原则

1. 概念型知识不能跳过——这是知识系统性信息差中最容易被自学者忽略的部分
2. 不以"能否直接解题"判断输入的价值——很多概念理解是间接支撑上层能力的
3. 每个概念都要用自己的语言准确复述——如果做不到，说明理解有漏洞
4. 连贯性强的学科（数学、物理）漏洞会累积放大——越早补越好

## 【与哪些模型有关系】

- → [[输入与练习的不可替代性]]：信息差的第一类（知识系统性）对应输入的不可替代功能
- → [[理解理论]]（四级模型）：功利化输入只到认出级，跳过了结构级的构建
- → [[认知精准度与上限理论]]（流程vs方法）：信息差认知是流程层面的问题，不是方法问题
- → [[三阶段瓶颈与模式递进]]：第一阶段瓶颈常因概念积木打歪而无法突破
- → [[精准归因能力]]："理解力差"往往是错误归因，真实原因是底层概念漏洞

## 【AI可以在这个模型有什么帮助】

- **弥补第一类信息差**：AI帮助构建知识的层次结构，从不同角度重组解释概念
- **概念漏洞检测**：AI要求学习者用自己的语言复述概念，检测是否存在偏差
- **弥补第二类信息差**：AI根据学习理论框架提供阶段性学习规划建议
- **防止功利化**：AI在输入阶段确保概念型内容被充分理解后再进入练习
- **连贯性漏洞追溯**：当上层学习出现困难时，AI向下追溯定位底层概念漏洞
