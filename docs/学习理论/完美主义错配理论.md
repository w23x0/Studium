## 【属于什么理论模块】

策略分配模块 — 识别完美主义应该施展和应该避免的位置，防止精力错配

## 【核心论述】

完美主义本身不是问题，问题在于错配。完美主义就是对行为结果的高预期，高预期反过来影响行为方式。在不当的地方完美主义→事情始终达不到预期→未完成感堆积→认知资源耗散。要避免的不是完美主义本身，而是完美主义的错配。

## 【机制/模型】

### 完美主义导致拖延的机理

1. 人切换任务有阻力（蔡格尼克效应 + 需要清除工作记忆 + 评估新任务消耗）
2. 对新任务有过高预期 → 评估所需能量投入过高
3. 启动新行动的阻力极大 → 拖延

本质：完美主义 = 人节约能量的天性 + 对任务要求和自己能力的认知偏差

### 判断标准（两个前提）

1. **短期内是否能完成一个小闭环，打上"已完成"标记？**
   - 能 → 完美主义有意义
   - 不能 → 避免完美主义，先推进再多次覆盖

2. **该学习环节本身的客观要求是什么？**
   - 环节要求精确 → 完美主义
   - 环节只需大体过关不影响后续 → 先往下推进

### 应避免完美主义的地方

| 环节 | 为什么避免 | 正确标准 |
|------|-----------|---------|
| 听课/阅读理解 | 知识客观上不是一次性能完全理解的线性过程，死磕→未完成堆积 | 重要概念懂了、无结构性空白→直接做基础题 |
| 作业 | 标准化产品，面向班级最大公约数，约30%与你不适配 | 工具为你服务，低价值题不需要投入 |
| 笔记/错题本 | 过度追求格式美观 = 精力错配 | 功能性优先，不追求形式 |

### 应施展完美主义的地方

| 环节 | 为什么需要 | 具体要求 |
|------|-----------|---------|
| 能力边缘的题目 | 能力提升的最佳素材 | 每一步不猜测、每个选项分析确切对错、分析工具和技巧的使用逻辑 |
| 单一知识点的闭环练习 | 不是对一道题，而是对"这个知识点完全理解"的目的 | 没达到就继续练继续思考，目的不打折扣 |
| 类型题的精细化链条 | 在一个类型上完成完整递进链 | 更容易完成小闭环 |

### 对自学的启示

- 阅读新材料：理解到七八成就开始做应用，不要死磕到100%再动手
- 练习闭环：对"掌握这个知识点"的目标要完美主义，不能打折
- 工具性任务（整理笔记、排版、找资料）：够用就行，不追求完美

## 【与哪些模型有关系】

- → [[蔡格尼克效应与认知资源耗散]]：完美主义在错误环节→事情达不到预期→未完成感堆积→后台资源耗散
- → [[最小学习单元理论]]：完美主义该施展的核心判据就是"能否完成一个小闭环"
- → [[输入与练习的不可替代性]]：输入环节避免完美主义（七八成即可），练习环节施展完美主义（闭环不打折）
- → [[认知精准度与上限理论]]：完美主义错配本质上是认知偏差——对各环节客观要求的判断不准确
- → [[任务管理理论]]：工具和手段不等于目标，对工具完美主义=精力错配

## 【AI可以在这个模型有什么帮助】

- **环节标准设定**：AI明确告知当前环节"够了"的标准，防止在输入环节过度死磕
- **闭环完成度追踪**：AI判断知识点是否达到闭环标准，没达到时督促继续，达到时提示推进
- **精力错配预警**：当学习者在低价值任务上投入过多时间时，AI提醒切换
- **完美主义位置引导**：AI在能力边缘的题目上要求精细化分析，在常规任务上不要求
