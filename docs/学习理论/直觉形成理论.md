## 【属于什么理论模块】

能力形成模块 — 解释"直觉"的本质是什么、如何后天养成，消除"直觉=天赋"的误解

## 【核心论述】

直觉 = 经验的显化 = 用正确方式积累足够经验之后的快速反应。它不是天赋，而是对每种情况的逻辑链充分分析后形成的快速判断能力——跳过推理的一种反射。直觉差不是脑子差，是积累经验的方式不对。

## 【机制/模型】

### 直觉的本质

```
大量正确方式的经验积累 → 对逻辑链的充分分析 → 模式识别自动化 → 跳过推理的条件反射 = 直觉
```

### 两种可后天养成的直觉

**1. 找到核心条件的直觉**

- 定义：面对陌生问题时，能快速定位"需要创造什么条件"来打通逻辑链
- 养成方式：对每类问题的逻辑链做主动归类分析
- 过程：做若干道同类题 → 仔细分析发现共有几类逻辑链 → 每类有各自的特征和确定的核心条件 → 积累够了之后形成条件反射

**2. 识别题目考点/情境的直觉**

- 定义：能识别复杂情境是由什么基础情境组合或变化而来的
- 不是"题目问什么" → 而是"这个情境的构成是什么"
- 养成方式：对所有基础情境充分熟悉 → 熟悉每个进阶模型 → 对复杂综合情境有拆解能力
- 顺序不可跳过：基础模型 → 进阶模型 → 复杂组合识别

### 没有直觉时的表现

- 面对陌生难题需要枚举所有可能性逐个尝试
- 被复杂情境或选项吓住，无法快速定位本质
- 同样的题量，别人能形成模式识别而自己不能

### 养成直觉的关键：主动归类意识

不是做完一道题就结束，而是：
1. 分析这道题属于哪类逻辑链
2. 这类逻辑链的特征是什么
3. 核心条件/关键步骤是什么
4. 和其他类型的区别在哪里

积累足够后，哪怕题目被包装得面目全非，只要本质特征存在 → 条件反射式反应

## 【与哪些模型有关系】

- → [[有效练习理论]]（三层递进/题目利用度）：直觉建立在第二层（思路）充分熟练的基础上；高利用度的精细化分析是直觉积累的方式
- → [[题目的功能分类与深度学习]]（备课心态）："为什么这么做"的深度分析就是直觉积累的过程
- → [[学习效率理论]]（神经连接）：直觉 = 相关神经网络高度活跃后的自动化反应
- → [[三阶段瓶颈与模式递进]]（第三阶段思维模式）：直觉的形成就是从训练模式进入思维模式的标志

## 【AI可以在这个模型有什么帮助】

- **归类引导**：每道题做完后，AI引导学习者分析"这属于哪类逻辑链""核心条件是什么"
- **模式库构建**：AI帮助学习者积累和整理各类问题的逻辑链分类
- **识别训练**：AI出不分类的混合题目，训练学习者的情境识别能力
- **基础情境覆盖度追踪**：AI确保基础模型全部覆盖，再推进进阶模型
- **变形展示**：AI对同一逻辑链展示多种包装形式，帮助学习者看穿表面识别本质
