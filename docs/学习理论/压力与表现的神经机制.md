## 【属于什么理论模块】

神经机制模块 — 解释压力场景下表现下降的脑科学路径，以及如何从杏仁核路径切换到前额叶路径

## 【核心论述】

紧张和压力是结果，不是根本原因。根本原因是"我正在被考核"这个信息被杏仁核（警报器）而非前额叶（理性中枢）处理了。杏仁核接管→皮质醇升高→前额叶和海马体被抑制→表现下降→负反馈加深焦虑→死循环。

对自学者的意义：任何"被评估"的场景（自测、阶段验收、向他人展示成果）都可能触发同一机制。

## 【机制/模型】

### 两条信息处理路径

| 路径 | 处理方式 | 生理效应 | 表现结果 |
|------|---------|---------|---------|
| 杏仁核路径（恶性） | 将"被考核"视为威胁信号 | 皮质醇↑，抑制前额叶+海马体 | 迷糊、紧张、发挥失常 |
| 前额叶路径（良性） | 将"被考核"视为调动思维的场景 | 血清素↑、BDNF↑ | 冷静清醒、正常/超常发挥 |

### 恶性循环

杏仁核接管 → 皮质醇升高 → 前额叶/海马体被抑制 → 表现差 → 负反馈 → 强化"考核=威胁" → 下次更容易被杏仁核接管

### 良性循环

前额叶处理 → 血清素+BDNF提升 → 清醒+易于提取记忆 → 表现符合预期 → 正反馈 → 强化前额叶路径

### 自我诊断

考核时比平时更冷静清醒 → 前额叶主导（良性）
考核时比平时更迷糊 → 杏仁核主导（恶性）

### 干预方案（三个角度）

**1. 生理基础（长线，不可跳过）**
- 有氧运动：增加血清素、降低皮质醇（每天≥20分钟中强度）
- 低GI饮食：避免血糖波动引起注意力涣散和情绪低落
- 稳定睡眠：重塑神经系统、控制皮质醇

临时措施：考核前1小时做中强度间歇运动15-20分钟 → BDNF峰值维持2-3小时

**2. 降低不确定性（行为层面）**
- 增加自测机会（不限时，完整做）→ 熟悉结构和重难点分布
- 人对越熟悉的东西恐惧越少 → 越容易进入前额叶路径
- 对自己能力范围的判断越准确 → 预期越合理 → 焦虑越少

**3. 心理层面**
- 关注失误内容本身（重新做、重新思考），不给它打"本该会"的标签
- 关注知识点和题目，而非自己的感受和别人的评价
- 将考核视为工具（定位漏洞），而非目的（证明自己）

- → [[学习状态的生理基础]]：本模型是九物质模型在压力场景下的具体应用（皮质醇、血清素、BDNF的对抗关系）
- → [[三系统疲劳模型]]：前额叶与杏仁核此消彼长 = 三系统中前额叶疲劳的机制
- → [[审判感机制]]：将考核视为威胁 = 审判感的极端表现
- → [[学习者效能理论]]（Q2关注区）：杏仁核路径 = 精力投入在关注区（别人评价、自我感受），前额叶路径 = 精力在问题区
- → [[认知精准度与上限理论]]：对自己能力的准确判断能降低不确定性，减少杏仁核激活

## 【AI可以在这个模型有什么帮助】

- **验收场景的情绪隔离**：AI设计低威胁感的验收方式，避免触发杏仁核
- **渐进暴露**：AI逐步增加验收的正式程度，让学习者适应"被评估"而不产生威胁感
- **运动提醒**：AI在重要学习任务前提醒运动，利用BDNF窗口
- **能力范围校准**：AI帮助学习者准确判断当前水平，降低预期与现实的落差
- **功能性反馈**：AI对验收结果只做漏洞定位，不做价值评判，引导前额叶路径
