## 【属于什么理论模块】

执行框架模块 — 从任务本质出发反推精力和时间分配的管理范式

## 【核心论述】

时间管理的本质是精力管理，精力管理的本质是任务管理。正确路径不是"安排时间→分配精力→完成任务"，而是反过来："明确核心任务→反推精力分配→时间自然到位"。

核心一句话：时间不够用的本质 = 在重要的事情上投入的精力不够。

## 【机制/模型】

### 三层递进关系

```
时间管理（表层）← 精力管理（中层）← 任务管理（本质）
```

### 时间管理 vs 任务管理（逻辑完全相反）

| 维度 | 时间管理模式 | 任务管理模式 |
|------|-------------|-------------|
| 起点 | 凭感觉做时间计划表 | 从任务本身的特点和重要性出发 |
| 逻辑 | 时间分配→精力分配→任务完成度 | 核心任务→精力分配→时间自然到位 |
| 结果 | 静态死板，哪项没做都不踏实 | 动态可调整的工作流 |
| 长期效果 | 目标远高于现实，错位焦虑 | 对目标和自我能力认知越来越准确 |

### 任务管理的两个核心要素

**1. 找准核心任务**
- 任何阶段的核心任务不会超过两个
- 区分"核心目标"和"实现手段"：预习、错题、刷题等都是手段，不是目标本身
- 把手段当目标 → 任务管理混乱 → 优先级不清 → 容易被碎片建议带跑

**2. 确定任务标准**
- 每个核心任务必须有确切清晰的标准，没有模糊地带
- 三个必答问题：什么叫"学过的内容"？"熟练掌握"的最低标准是什么？执行过程中的最小步骤是什么？
- 核心任务不是标准化模板，对不同程度、不同阶段完全不同

### 为什么时间管理模式失败

- 精力是有限资源，但可消耗精力的事相对无限
- 靠时间表分配 → 精力被稀释到所有事上 → 无法专注
- 计划表本身没有依据（不是从任务需求推导的）→ 完不成 → 焦虑

## 【与哪些模型有关系】

- → [[蔡格尼克效应与认知资源耗散]]：任务管理通过明确"什么是当前核心任务"来减少后台未完成任务数量
- → [[最小学习单元理论]]：任务管理中的"最小步骤"对应闭环模型的最小循环单位
- → [[学习者效能理论]]（价值判断能力）：任务管理能力本质上就是价值判断能力的具体运用——能区分核心目标和手段
- → [[行为优先干预CBT]]：任务管理提供明确的行为指令，让"下一步做什么"不需要额外决策

## 【AI可以在这个模型有什么帮助】

- **核心任务提炼**：AI根据学习者当前阶段和水平，识别不超过两个核心任务，过滤掉手段层噪音
- **标准明确化**：AI将模糊目标转化为可验收的具体标准（如"熟练掌握=基础题正确率95%+不需要调用明显脑力"）
- **动态工作流管理**：AI根据任务完成情况动态调整优先级，替代静态时间表
- **手段推荐**：核心任务确定后，AI根据当前情况推荐合适的实现手段，而非让学习者自己在手段间纠结
- **精力聚焦**：AI一次只呈现当前核心任务，屏蔽其他干扰项
