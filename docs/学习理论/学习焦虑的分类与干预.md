## 【属于什么理论模块】

心理诊断模块 — 区分两类学习焦虑的本质机制，提供对应的干预路径

## 【核心论述】

学习焦虑分两大类：付出不足型（心力消耗在非行动环节）和回报失衡型（付出了但回报不成比例）。两类的干预方式完全不同，误诊会加重问题。共同的底层解法：让行为的激活优先于认知的改变。

## 【机制/模型】

### 第一类：付出不足型焦虑（心力守恒失衡）

核心原理：人的心力在一个阶段内大体守恒，心力被非行动环节消耗 → 支撑实际行动的能量不足。

**亚型A："虚假希望型"**
- 表现：精细化计划做得美观整齐、收集大量方法和资料、做大量"学习前准备"
- 机理：潜意识把"计划"和"成功"直接关联，弱化了"行动"的比重
- 多巴胺机制：做计划时的幻想 → 多巴胺高位 → 实际行动反馈慢 → 落回低位 → 被打断
- 本质：虚假的路径依赖

**亚型B："认知冻结型"**
- 表现：止于焦虑不行动、爆发式学习+急刹车、排斥回顾错题、在舒适区打转
- 机理：心力耗费在预言恐惧上，遇到困难或错误率高就停止
- 多巴胺机制：阈值被拉高（短视频/游戏），学习的慢反馈无法产生有效刺激
- 触发：每次停止学习的直接原因 = 遇到困难或错误率高

**第一类的干预（三条核心）：**
1. 直接开始做，不需要精细化计划，不需要自我审视和定性
2. 接受知识的叠加特性：不是听了→懂→会做→考高分的线性过程
3. 把练习和测试分开，不把练习当检测

### 第二类：回报失衡型焦虑

**可能性一：客观问题**
- 学习流程存在缺陷
- 教学质量问题导致的回报失衡
- 诊断：用流程检查，不用情绪判断

**可能性二：主观问题（潜意识自我保护）**
- 来源：低年级靠勤奋得到好成绩 → 对结果的关注远大于过程
- 机理：成绩和付出不成比例后，潜意识保护自尊 → 下意识避开核心步骤 → 陷入低效努力 → 永远有台阶下
- 典型特征：时刻和别人对比结果和过程、潜意识认为自己有天赋、避开见效慢的学习步骤、急功近利
- 表现：跳过基础练习刷难题、跳过积累只刷题

**第二类的干预：**
- 核心 = "破壁"：真诚面对自己的心理根源
- 看清行为变形来自于保护自尊的潜意识
- 补上之前潜意识刻意回避的必要学习步骤

## 【与哪些模型有关系】

- → [[行为优先干预CBT]]：两类焦虑的共同底层解法就是行为优先——不要想先改变认知再行动
- → [[学习状态的生理基础]]（多巴胺）：虚假希望型=计划时多巴胺虚高；认知冻结型=多巴胺阈值被拉高
- → [[审判感机制]]：认知冻结型的"遇到错误就停止"=审判感发作
- → [[完美主义错配理论]]：虚假希望型对计划完美主义、认知冻结型对结果完美主义，都是错配
- → [[认知精准度与上限理论]]（可得性偏差）：回报失衡型的"觉得自己很努力"往往是可得性偏差
- → [[任务管理理论]]：第一类焦虑的根源之一是把手段（做计划、收集方法）当成了目标

## 【AI可以在这个模型有什么帮助】

- **类型诊断**：AI通过提问判断属于哪种焦虑类型，避免误诊
- **行为直接启动**：对第一类，AI不做认知说服，直接给出最小行动指令
- **计划极简化**：AI替代精细化计划，只给"下一步做什么"，消除计划幻想消耗
- **客观记录对抗偏差**：对第二类，AI记录实际行为数据，帮助学习者看清"回避核心步骤"的模式
- **正反馈节奏设计**：对认知冻结型，AI在任务中插入高频小反馈点，降低多巴胺阈值依赖
