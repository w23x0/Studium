## 【属于什么理论模块】

干预策略模块 — 当认知和情绪层面卡死时，从行为层面破局的原则

## 【核心论述】

行为改变是最快的切入点，行为可以反向影响情绪和认知。当认知层面无法切换时，直接从行为层面介入仍然有效。这与认知行为疗法（CBT）的行为激活（Behavioral Activation）原理一致。

核心论断：不要等"想通了"再行动，行动本身就是想通的途径。

## 【机制/模型】

### 三层干预模型

人有三个可干预层：
1. **认知层**（想法）— 最难直接控制
2. **情绪层**（感受）— 无法被意志直接操控
3. **行为层**（动作）— 最容易被意志直接控制

### 常规路径 vs 行为优先路径

- 常规路径：先想通 → 心情好 → 再行动（经常卡死在第一步）
- 行为优先：直接行动 → 情绪自然改善 → 认知随之更新

### 为什么行为层最有效

- 行为是三者中唯一可以在不理解、不情愿的状态下强制启动的
- 行动一旦启动，会反向改写情绪和认知
- 做了5分钟题 → 焦虑自然降低 → "我不行"的念头自动弱化

### 实际应用

- 不想学 → 不等"调整好状态"，直接翻开书读第一句
- 觉得太难 → 不分析为什么难，先抄一遍定义
- 拖延 → 不反思拖延原因，先坐到桌前打开文件

## 【与哪些模型有关系】

- → [[审判感机制]]：行为优先干预是审判感的直接对策——认知卡在自我评判里时，从行为绕过
- → [[三系统疲劳模型]]：三系统疲劳导致前额叶宕机时，行为优先是唯一可行的破局点
- → [[学习者效能理论]]（Q2关注区）：Q2学习者精力困在关注区（情绪/评价），行为优先可以强制将精力拉回问题区
- → [[蔡格尼克效应与认知资源耗散]]：通过行为直接完成小闭环，消除后台运行的未完成任务

## 【AI可以在这个模型有什么帮助】

- **直接安排行动**：当学习者陷入犹豫/纠结时，AI不做解释说服，直接给出下一步具体动作指令
- **最小行动设计**：AI将任务拆解到"不需要决策就能启动"的粒度（如"打开第3章第2节，读第一个定义"）
- **绕过认知层**：AI不问"你准备好了吗"，而是直接说"现在做这道题"
- **行为链启动**：AI设计连续的小动作序列，利用惯性让学习者自然进入状态
