## 阅读方式（先看这段）

本项目 **不实现任何 KT 概率/深度模型**（v0.2 已明确拒绝 BKT/DKT，理由：输出数字而非诊断）。
所以这 6 个模型对我的价值是**"思想供体"**——把它们解决问题的*思路*，翻译成 LLM + prompt + SQLite 能落地的启发式。

每个模型分三块写：
1. **它是什么**（一句话技术概念）
2. **它解决的真问题**（这才是可迁移的内核）
3. **🎯 翻译到本项目**（具体落点：哪张表 / 哪个 prompt / 哪个环节）

## 1. DKVMN — Dynamic Key-Value Memory Networks ✅已核实
> Zhang et al., WWW 2017。arXiv:1611.08108

**它是什么**：两块记忆矩阵，一静一动。
- **Key 矩阵（静态）**：存"有哪些知识概念"，固定不变，起"寻址/定位"作用——把每道题映射到相关概念。
- **Value 矩阵（动态）**：存"学生对每个概念的掌握度"，每做一题就读取+更新。

**它解决的真问题**：
- DKT 的隐藏层是**一个不透明的整体状态**，没法说出"对哪个概念好、哪个不熟"。
- DKVMN 把记忆**按概念分格**，能**直接输出每个概念的掌握度**，还能自动发现题目背后的潜在概念（免人工标注）。

**🎯 翻译到本项目**：
- 这就是本项目"学习者状态模型 → 知识掌握状态 per concept"维度的**理论靠山**。我早就在做"按 concept 分格存掌握度"，DKVMN 证明这条路对。
- **关键差异 = 我的升级点**：DKVMN 的 Value 格子里存的是**数字向量**（不可读）；本项目存的是 **LLM 写的自然语言掌握描述 + 证据引用**（v0.3 文本主导）。
  → **我的 Value 矩阵是"可解释版的 DKVMN"**。DKVMN 想可解释但只能给数字，我用 LLM 直接给人话。
- **可借鉴的机制**："读 Key 定位 → 读 Value 预测 → 只写相关格子"这套"局部更新"思路 → 一次学习交互后，**只更新本次涉及的 concept 的状态文字，不动其它**（省 token、状态稳定）。

## 2. SAKT — Self-Attentive Knowledge Tracing ✅已核实
> Pandey & Karypis, EDM 2019。arXiv:1907.06837

**它是什么**：第一个用 Transformer **自注意力**做 KT。预测某知识点时，自动找出历史上**与它最相关的少数几次互动**，只基于这几次预测，而非整段历史。

**它解决的真问题**：
- RN（DKT/DKVMN）处理**稀疏数据泛化差**——学生其实只碰过很少的知识点。
- SAKT "只看最相关的少数历史"，**更好地应对数据稀疏**，AUC 平均提升 4.43%。

**🎯 翻译到本项目**：
- **这是"上下文构造"的黄金启发式**。本项目资料层用 RAG 检索切片、闭环层要回看历史——别把全部历史塞进 prompt。
  → **学某个知识点 / 做闭环判定时，只挑"与当前知识点最相关的少数几条历史交互"喂给 LLM**（靠向量相似度 + 证据图关系挑选）。这正是 SAKT 的"selective attention"，且天然契合我"切片少、单人数据稀疏"的场景。
- 副产物：注意力权重本身可解释——"为什么判你卡在这"可以回溯到"因为你在这几道相关历史上表现如何"。本项目的"证据引用"就是这个思想的落地。

## 3. AKT — Context-Aware Attentive Knowledge Tracing ✅已核实
> Ghosh, Heffernan & Lan, KDD 2020。arXiv:2007.12324

**它是什么**：在注意力里**显式建模"遗忘"**，并用心理测量学正则化题目嵌入。
- **单调注意力衰减**：注意力权重 = 题目相似度 × **指数衰减 × 上下文相对距离**。历史上越久远的互动，权重越低 → 用数学把"知识随时间淡忘"刻进模型。
- **Rasch 模型嵌入**：用经典心理测量的 Rasch 模型正则化嵌入，**用极少参数就能区分"同一概念下不同难度的题"**。

**它解决的真问题**：之前的深度 KT 可解释性差、不适合个性化；AKT 把注意力网络和**认知/心理测量模型**结合，兼顾精度与可解释，AUC 最高提升 6%。

**🎯 翻译到本项目**（⭐ 这是我说"想用但不知道怎么用"的那个）：
- **遗忘衰减 → 复习调度启发式**：学习者状态里给每个 concept 记 **`last_touched`（上次接触的 loop 时间戳）**。判定是否需要复习时，把"距今多久"作为 prompt 的输入信号——**越久没碰，LLM 越倾向判"可能遗忘，需复检"**。
  - 不用写指数公式，用 prompt 启发式即可："概念 X 上次接触在 12 个 loop 前，期间未复现，按遗忘规律评估当前掌握度并决定是否插入复检"。
  - 这就是 AKT "exponential decay" 的 LLM 版——**把算法换成语言推理，把数值换成时间戳 + 自然语言判断**。
- **Rasch 思想 → 题目/资料难度分层**：同一知识点下的资料/自测题有难易之分。可让 LLM 给资料切片标个**粗粒度难度**，深度控制时按"由易到难"推进（呼应综述里 RBT 布鲁姆分类法那条）。

## 4. GKT / 图神经网络 🔶思想有把握，联网未核实
> Nakagawa, Iwasawa, Matsuo, 2019（GKT）。注：IEEE 页面 418 未抓到原文，以下据知识库。

**它是什么**：把知识点建成**图**（节点=知识点，边=知识点关系）。学生掌握某知识点后，掌握状态**沿着图的边传播**到相邻知识点（消息传递 message passing）。知识点关系未知时，可做"图结构学习"自动推断。

**它解决的真问题**：DKT 等假设知识点相互独立；GKT 显式利用**知识点之间的结构关系**，且因为按图节点组织，**可解释**（能看每个知识点的状态）。

**🎯 翻译到本项目**（⭐ 我说"太需要、完美的学习者知识点模型"的就是它）：
- **这就是本项目"生长式证据图"的算法亲戚**。`relation_inferences` 表 + 7 种关系（prerequisite/derives_from/...）= GKT 的图；本项目的边是 **LLM 推理生成 + 学习者验证**的，比 GKT 的"学出来的隐式图"更可解释。
- **可直接借鉴：消息传递 → 闭环后的"状态扩散"**：
  → **一个 concept 闭环完成时，沿证据图的边（尤其 `prerequisite`/`derives_from`），让 LLM 重新评估相邻 concept 的掌握度**。
  例：刚闭环"特征值"，它 `derives_from`"行列式"→ 提示 LLM"行列式作为前置应已巩固，可调高其掌握判断"；它是"对角化"的 prerequisite → 提示"对角化现在具备学习条件，可推进"。
- **图结构学习 → 边的自动生成**：GKT 在关系未知时自动推断图，正对应本项目"LLM 动态推理关系并落盘"的设计。GKT 验证了"关系可以学出来"这件事可行。

## 5. 对比学习 KT 🔶思想有把握，联网未核实
> 代表如 CL4KT (Lee et al., 2022) 等。注：arXiv ID 未命中，以下据知识库。

**它是什么**：用**对比学习 + 数据增强**对抗数据稀疏。把一个学生的作答序列做扰动（删几道题、换顺序、替换相似题）生成"正样本对"，训练模型对同一学生学到**鲁棒、一致**的表示。

**它解决的真问题**：KT 数据稀疏、单个学生序列短，模型易过拟合。增强 + 对比让表示更稳。

**🎯 翻译到本项目**（我是**单人系统**，数据极稀疏，这条尤其相关）：
	- **直接搬算法不现实（我没有大规模训练），但内核可借**：核心思想是"**同一个理解，换种问法/换个顺序，应得到一致的诊断**"。
  → **诊断鲁棒性自检**：判定"是否真掌握"时，让 LLM **换一个角度/换一道等价题再问一次**，若两次诊断不一致 → 说明掌握不牢（是"伪闭环"）。这是对比学习"扰动后应一致"思想的 prompt 版。
	- 呼应本项目根基（ACT-R 的"动态可提取性"）：区分"真懂"和"刚好这么问能答上来"——**换个问法还能答 = 真可提取**。对比学习给了这件事一个理论名分。

## 6. LLM + KT ✅已核实（2026-06 联网回填，绕开 WebSearch 502 用 arXiv API 取得）
> 2023 起兴起。本轮通过 arXiv API 核实了 40+ 篇 2024–2026 代表作，结论：**我笔记里"主流是特征提取器、本项目是诊断引擎"的判断成立，但"独此一家"需修正——2026 年已有 3-4 篇同路工作。**

**它是什么**：用大语言模型**读懂题目的文本语义**，而不只把题当成一个匿名 ID。进一步用 LLM 直接做学生建模/诊断（理解错因、生成反馈）。

**它解决的真问题**：传统 KT 把题目当 ID，丢了题面里的全部语义信息；冷启动（新题没历史数据）也无解。LLM 能直接理解题目内容，缓解这两点。

### 6.1 学界已分化成两条路线（核实后命名）

| 路线 | 代表作（arXiv ID） | 说明 |
|---|---|---|
| **A. LLM 当特征提取器**（主流、最拥挤） | LMCD `2505.21239`、LM4CD `2505.13492`、KCD `2502.05556`、DFCD `2410.15054`、SINKT `2407.01245`、KCQRL `2410.01727`、LKT `2406.02893`、NTKT `2511.02599` | LM 把题目语义/概念关系编码成 embedding，喂给传统 CDM/KT 数值模型。即我笔记说的"慢半拍把新技术搬下来用在做题上"。 |
| **B. LM 直接做诊断引擎，training-free**（新兴、与本项目同路） | **MERIT `2603.22289`、Thinking-KT `2601.01708`、CIKT `2505.17705`、SLOW `2603.28062`、MathCog `2504.00843`** | 冻结 LLM，靠 prompt + 外部记忆/检索直接出诊断，不训练下游模型。**这条线 2026 年才爆发——本项目 v0.2/v0.3 设计踩在了点上。** |

### 6.2 🎯 翻译到本项目（核实后更新）

- **定位校准**：本项目仍是 LLM+KT 中较激进的一支，但**不再是孤例**。MERIT/Thinking-KT/CIKT 已在做"冻结 LLM + 不训练下游模型"。**本项目真正的独特性**：它们大多仍以"预测下一题对错的 AUC"为最终目标，而本项目**彻底放弃数值预测、只做文字诊断 + 证据图**。→ 价值锚点必须是"可解释诊断 + 学习决策"，**绝不能锚在预测精度**（见 6.4 反调论文）。
- **MERIT（`2603.22289`）≈ 本项目的学术孪生，最该精读**：
  - training-free 冻结 LLM，把交互日志转成"可解释记忆库"，让 LLM 基于**检索到的证据**做诊断而非学权重 → 正是本项目的"证据引用"机制。
  - **paradigm bank（错误范式库）**：离线分析典型错误模式，每个配一段 CoT 解释，推理时当可解释样例 → 本项目可建一张"常见误解库"表。
  - **logic-augmented module**：施加语义约束**校准预测、防幻觉** → 这是本项目目前缺的"防过度积极"护栏。
  - 支持记忆**动态局部更新** → 印证从 DKVMN 学的"只更新相关格子"。

### 6.3 ⭐ 防 LLM"过度积极判掌握"——MathCog（`2504.00843`）给了实证（最该警惕）

- 测了 **18 个 LLM，全部 F1 < 0.5**，无论模型多强；证据模糊时性能断崖式下跌。
- 三种系统性失败模式，**全部指向"过度积极"**：
  1. **误判证据强度**：把"模糊证据(Vague)"当成"确凿证据(Evident)"——最致命。
  2. **过度解读**：从稀疏线索脑补出学生没做的推理步骤。
  3. **幻觉证据**：直接编造学生答案里根本没有的认知证据。
- **直接处方（可抄进 prompt 工程）**：① **证据分级**——诊断时强制 LLM 给每条证据标 `Evident / Vague` 两档，别合并；② **teacher-in-the-loop**——低证据情况必须人裁决。对本项目单人系统 = "Wang 自己当 teacher，LM 标注证据强度，凡 Vague 的必须触发复检"。**这就是对比学习那条"伪闭环自检"的实证靠山。**

### 6.4 ⚠️ 必须正视的两篇"唱反调"论文（挑战本项目根本假设）

- **《Specialised KT Models Outperform LLMs》(`2603.02830`)**：直接对比，传统 KT 模型在**准确率、速度（快几个数量级）、成本（低几个数量级）全面碾压 LLM**；结论"闭源 LLM 不该当万能解"。
- **《Why LLMs Alone Fall Short for Responsible Tutoring in K-12》(`2512.23036`)**：DKT 达 AUC 0.83 持续优于 LLM，微调后 LLM 仍不及且**时间连贯性更差**，主张混合框架。
- **对本项目的意义**：这些批判都用"预测下一题对错的 AUC"当裁判——而本项目**根本不玩这个指标**。它们恰好证明：若去比 AUC 必输，所以本项目价值**只能锚在"可解释诊断 + 个性化决策"**。这反而强化了 v0.2 放弃数值预测的决定。

### 6.5 两个笔记里原本没有、但高价值的新点子

- **RPKT（`2508.11892`）**：LLM **递归往前追溯前置知识**，直到触到学习者"知识边界"，无需预建知识图谱，用 binary 评估降认知负荷 → 直接呼应本项目"生长式证据图"的动态建边 + GKT 的"图结构学习"。
- **Thinking-KT（`2601.01708`）**：用 **Test-Time Scaling**（推理时多想、不训练）让小模型同时做诊断+反馈+推荐 → 对本项目省成本有参考。
- **TASA（`2511.15163`）**：把**遗忘曲线 + persona + event memory** 组合进 LLM 出题 → 正是 §3 AKT 那条"遗忘衰减想用但不知怎么用"的现成落地参照。
