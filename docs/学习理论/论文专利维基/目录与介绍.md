## 关键结论速查

**本文件夹回答了什么：**
- 认知跟踪（KT）模型是什么、解决什么问题（综述 §1.3）
- 为何本项目不用 BKT/DKT（输出数字不可读、假设不符真实学习，详见 v0.2 架构设计总结）

- 哪些前沿思想能翻译进 LLM 架构（六大模型灵感表）

**核心洞察：**
> 认知跟踪的历史是"精度 vs 可解释性"的拉锯。深度学习派冲精度丢可解释（DKT→DKVMN），Transformer 派既要又要（SAKT/AKT），图神经网络派补知识结构（GKT）。**本项目走极端路线：用 LLM 把可解释推满、用证据图补结构、用文字取代数字，学术上属 LLM+KT 的 training-free 新兴派。**
