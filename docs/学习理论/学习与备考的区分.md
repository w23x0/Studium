## 【属于什么理论模块】

元认知模块 — 区分两种根本不同的学习活动模式，防止范式混淆

## 【核心论述】

学习和备考是两种本质不同的活动模式。学习是创造性且发散的，备考是工程性且收敛的。用学习的思维做备考（或反过来）会导致资源错配。

对自学者的意义：自学中同样存在"探索模式"和"工程模式"的区分。当目标明确、范围有限、有验收标准时，应切换为工程模式。

## 【机制/模型】

### 两种模式的本质区别

| 维度 | 学习（探索模式） | 备考/工程模式 |
|------|-----------------|--------------|
| 性质 | 创造性、发散的 | 工程性、收敛的 |
| 边界 | 不限定 | 严格限定范围和形式 |
| 路径 | 自由度高，点亮顺序随意 | 有成熟主流流程 |
| 评估 | 难以靠单一标准衡量 | 明确的得分标准 |
| 核心策略 | 探索、好奇心驱动 | 冷静分配精力资源、追求可靠性 |

### 工程模式的六条原则

1. **资源分配靠理性，不靠喜好**：按价值权重和效率分配精力，激活前额叶做行为决策
2. **追求可靠性**：练习目的是提升得分可靠性，排除法和猜答案不增加可靠性
3. **工具服务于目标**：听课、作业等是工具，不是枷锁，工具不合适时要调整
4. **关注自己的流程和执行**：不是智商测试，少关注别人，不在意"努力的姿势"
5. **懂取舍**：目的是产出最大化，不需要学会所有东西
6. **尊重规则**：在成为高手之前少找捷径，捷径会反噬

### 对自学的启示

- 当你有明确的学习目标（如掌握某门课程、通过某个考核）→ 切换为工程模式
- 工程模式下的行为准则：范围收敛、路径确定、按效率分配、追求可靠性
- 当你在纯粹探索新领域、构建兴趣 → 保持探索模式，自由度优先

## 【与哪些模型有关系】

- → [[任务管理理论]]：工程模式本质上就是任务管理——从目标反推资源分配
- → [[有效练习理论]]：工程模式下的练习必须追求可靠性，与"有效练习"原则一致
- → [[学习者效能理论]]（价值判断能力）：区分两种模式并在正确时机切换，本身就是价值判断能力的体现
- → [[输入与练习的不可替代性]]：工程模式下更需要精准诊断缺输入还是缺练习，不允许错位

## 【AI可以在这个模型有什么帮助】

- **模式识别与提醒**：AI判断当前学习目标适合探索模式还是工程模式，防止范式混淆
- **工程模式下的资源分配**：AI按价值权重排列任务优先级，避免学习者凭喜好分配精力
- **取舍建议**：AI根据目标和时间约束，明确告知哪些内容可以放弃
- **可靠性追踪**：AI追踪各知识模块的掌握可靠性（而非仅正确率），定位薄弱环节
