## 【属于什么理论模块】

学习方法论模块 — 按功能性×难度对题目分类，以及在缺乏外部指导时如何自主完成深度学习

## 【核心论述】

题目按功能性和难度可分为四类，不同类别需要不同处理策略。当外部指导不足时，学习者需要自己完成"为什么这么做"的思考——这不是额外负担，而是能力提升的核心路径。解决问题的前提是提出问题。

对自学者的核心意义：自学本身就没有"老师讲题"，必须自己完成从"看懂解析"到"知道为什么"的跨越。

## 【机制/模型】

### 题目的四象限分类

| | 低难度 | 高难度 |
|---|--------|--------|
| **高功能性** | 例题/基础应用题：加深概念理解，不需要额外讲解 | **核心弥补区**：必会题型、模型题、综合应用 |
| **低功能性** | 已完全熟练的重复题：跳过 | 偏题怪题：搁置到最后阶段拓展覆盖面 |

重点投入区 = 高难度×高功能性

### 演示式学习 vs 分析归纳式学习

| 维度 | 演示式（低效） | 分析归纳式（高效） |
|------|---------------|-------------------|
| 关注点 | 第一步做什么，第二步做什么 | 为什么想到第一步该这么做 |
| 收获 | 知道这一道题怎么解 | 知道这一类问题如何思考 |
| 等价于 | 看解析 | 以备课心态分析题目 |

### 自主深度学习的方法（"备课心态"）

**步骤：**
1. 第一遍做出来或对照解析勉强做出来
2. 对每一步提问"为什么这么做"
3. 精细化思考每个决策点：为什么选这个分析角度而不是另一个？
4. 积累若干问题后，寻找共性 → 提炼分析章法
5. 发现持续无法解决的问题 → 定向搜索资料/课程 → 集中练同类题

**核心原则：**
- 提出的问题是有解的（分析角度的组合是有限的）
- 主动思考和尝试的次数多了，就会找到章法
- 一直顺着别人思路做题 → 很难提升
- 始终解决不了的问题 = 精准的漏洞定位 → 定向补

### 各类题的处理策略

- **低难度高功能（例题/基础题）**：看不懂 → 问题在概念理解或前置漏洞，不是题目本身
- **低难度低功能（已熟练）**：跳过
- **高难度低功能（偏题怪题）**：遵循递进原则自然识别，非冲满分则搁置
- **高难度高功能（必会题型）**：重头在练熟而非看懂；用"备课心态"深度分析

## 【与哪些模型有关系】

- → [[有效练习理论]]："为什么这么做"的思考 = 有效练习的核心（思考→反馈→内化）
- → [[输入与练习的不可替代性]]：深度分析题目 = 练习侧的高质量执行；看不懂例题 = 输入侧有漏洞
- → [[学习效率理论]]：自主提问和思考的过程 = 高质量思考积累 = 神经连接的建立和强化
- → [[完美主义错配理论]]：高难度高功能题值得完美主义（精细化分析每一步）；低功能题不值得
- → [[认知精准度与上限理论]]（流程vs方法）：深度分析是流程层面的能力，不是某个方法

## 【AI可以在这个模型有什么帮助】

- **替代"好老师"的分析归纳**：AI对题目做"为什么这么做"的分析，而非仅展示步骤
- **提问引导**：AI在学习者看完解析后，主动提出"为什么"类问题，引导深度思考
- **题目分类**：AI判断一道题属于哪个象限，帮助学习者决定投入程度
- **共性提炼**：AI在学习者做完一组同类题后，帮助归纳分析章法和思维模式
- **漏洞聚焦**：AI识别学习者持续无法解决的问题类型，推荐定向补充资源

### 向AI有效提问的原则

无效提问 = 试图用提问跳过思考环节。一切试图替代主动思考的行为都不能带来进步。

| 提问类型 | 示例 | 效果 |
|----------|------|------|
| 无效（信息不对等） | "这题怎么做？" | 等于重看一遍解析，收获的是错觉 |
| 有效（聚焦性提问） | "我试了A和B思路都走不通，解析我看懂了，但怎样能第一时间想到在这里画辅助线？下次什么情况可以用类似思路？" | 解决一类题的共性问题 |

**有效提问的标准：**
1. 先充分思考，把能自己解决的部分解决掉
2. 基本信息对等：除了聚焦的问题点外，其他部分自己已经清楚
3. 问的是"为什么这么想"和"什么情况下用"，不是"怎么做"
4. 解决的不仅是这一道题，而是一种思路/一类题的共性
