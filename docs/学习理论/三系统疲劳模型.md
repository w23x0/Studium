## 【属于什么理论模块】

生理机制模块 — 解释学习状态下降的三条神经系统退化路径

## 【核心论述】

学习疲劳不是单一现象，而是前额叶、海马体、多巴胺系统三条线同时退化的综合结果。三系统互相影响，形成退化循环。任何一条线的疲劳都会加速其他两条的恶化。

## 【机制/模型】

### 1. 前额叶疲劳

- **成因**：持续高耗能（后台任务累积）
- **后果**：理性决策能力下降、抗干扰能力减弱
- **连锁反应**：前额叶与杏仁核此消彼长，前额叶弱化 → 杏仁核敏感化 → 情绪更易被激活

### 2. 海马体疲劳

- **成因**：多任务并行状态下信息繁杂 + 高皮质醇
- **后果**：记忆编码效率降低，遗忘加速
- **类比**：同时听多个声音源，辨别能力快速下降

### 3. 多巴胺系统疲劳

- **成因**：高压力 + 低正反馈 + 未完成感积累
- **两阶段退化**：
  - 阶段一：寻求高刺激替代 → 阈值不断抬高
  - 阶段二：对大部分事物丧失兴趣（可逆）

### 退化循环

前额叶疲劳 → 决策力下降 → 任务管理失控 → 海马体负担加重 → 记忆力下降 → 正反馈减少 → 多巴胺系统退化 → 动力丧失 → 更多任务堆积 → 前额叶进一步疲劳

## 【与哪些模型有关系】

- → [[蔡格尼克效应与认知资源耗散]]：蔡格尼克效应是本模型的触发源头，未完成任务堆积直接启动三系统疲劳
- → [[学习者效能理论]]：三系统疲劳为"行为主导性"下降提供了生理机制解释
- → [[审判感机制]]：审判感产生的高压力+低反馈+未完成感，直接触发三系统疲劳
- → [[行为优先干预CBT]]：三系统疲劳时认知层卡死，行为优先干预是破局手段

## 【AI可以在这个模型有什么帮助】

- **疲劳状态监测**：AI通过记录的学习时长、错误率变化、响应速度等信息判断当前疲劳状态
- **预防性干预**：当检测到疲劳信号时，AI主动建议休息或切换低耗能任务
- **正反馈维护**：AI定期呈现进步数据，防止多巴胺系统因低反馈而退化
- **任务负载控制**：AI控制同时暴露的任务数量，避免海马体过载
