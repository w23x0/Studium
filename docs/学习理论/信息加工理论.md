## 【属于什么理论模块】

学习原理模块 — 解释从输入到内化的加工过程，以及不同表征方式对学习效果的影响

## 【核心论述】

学习中的信息加工 = 从输入到输出的表征转化过程。关键不在于输入通道（看/听），而在于内部表征方式：语言表征（命题/逻辑链）vs 视觉表征（空间结构/图像模型）。两者独立但可协同，对应 Paivio 的双重编码理论。加工通道的选择应根据认知负荷动态切换。

## 【机制/模型】

### 双重编码理论（Dual Coding Theory）

信息可以被编码为两套独立系统：
- **语言系统**：形成命题/逻辑链（语言表征）
- **意象系统**：形成空间结构/图像模型（视觉表征）

两者独立存储但可协同工作，双通道同时编码时记忆效果最强。

### 文字学习的加工路径

文字输入的神经路径：视觉输入（枕叶识别字形）→ 语言加工（颞叶/额叶处理语义）

真正区分学习效果的不是输入通道，而是内部表征方式——同样读一段文字，有人形成逻辑链，有人形成空间模型。

### 加工通道的动态选择

| 认知负荷 | 策略 | 典型行为 |
|---------|------|---------|
| 高负荷 | 使用偏好表征方式 | 写笔记叙述（语言偏好者） |
| 低负荷 | 刻意切换到非偏好表征方式 | 口头讲述（语言偏好者切换到输出模式） |

### 辅助加工方法

- **仿真训练**：在脑内模拟操作过程，激活意象系统
- **实际操演**：动手操作，形成程序性记忆
- **费曼方法**：用语言讲解阐述已学会的内容，即对[[理解理论]]第三层理解的检验

### 与费曼方法的关联

费曼方法的本质 = 强制将内部表征外化为语言输出。如果讲不清楚，说明内部表征还停留在碎片状态，未形成完整逻辑链。这是对理解第3级（结构级）的直接检验。

## 【阶段适配：从课堂视听到文本自学的加工策略演变】

双重编码机制本身不变，但输入通道权重和加工策略随阶段有本质转换。

### 初高中阶段（视听输入为主）

- 主输入通道：课堂讲授（听觉+板书），辅以教材阅读
- 加工主要由教师驱动：教师负责组织信息为易理解的序列
- 学习者加工任务：跟上节奏、记录关键点、课后练习巩固
- 双重编码自然发生：教师同时使用语言讲解+板书图示

### 大学阶段（文本自学为主）

主输入通道：教材/讲义（纯文字+公式），课堂只是辅助索引。加工必须由学习者自己主动驱动。

**核心转变：从"接收已组织好的信息" → "自己从原始文本中提取并组织信息"**

三个关键策略变化：

**1. 主动建模成为必需**
- 初高中：教师给出模型，学生理解和记忆
- 大学：文本只给定义和定理，学生必须自己构造心理模型
- 例：读到"线性变换将一个向量空间映射到另一个"时，需要自己构造空间变形的视觉意象
- 不主动建模 → 阅读只停留在字面（认出级），无法到达结构级

**2. 加工通道选择变得关键**
- 抽象代数推导 → 需要刻意切换到视觉表征（画图、构造几何直觉）
- 几何/物理直觉强的内容 → 需要补充精确语言表征（避免模糊理解）
- 大学高效学习者的共同特征：频繁在两种表征之间主动切换

**3. 费曼方法的重要性急剧上升**
- 初高中有教师提问和作业强制输出，费曼法是可选加速器
- 大学缺乏外部强制输出机制，不主动做费曼法 → 容易停留在"读了≈懂了"的幻觉
- 大学版费曼法 = 合上书复述核心逻辑链 + 画概念关系图 + 向假想听众解释

### 研究生/博士阶段（论文阅读+跨文本综合）

主输入通道：研究论文（高度压缩的文本，省略大量中间步骤）。加工任务进一步升级为跨多篇文本综合建模。

**1. 补全省略步骤（reconstruction）**
- 论文为节省篇幅省略推导细节和动机
- 读者必须自己补全中间步骤——这本身就是深加工
- 不补全 → 只能达到"复现"级理解（能照着做但不知为什么）

**2. 批判性加工（critical processing）**
- 不只理解作者说了什么，还要判断：推导严谨性？假设合理性？结论是否过度推广？
- 初高中/大学本科不需要的加工层次
- 需要同时调用语言表征（逻辑链检验）和空间表征（构造反例/边界条件）

**3. 跨文本整合（synthesis）**
- 一个研究问题的理解需要整合5-20篇论文
- 需要构建"方法地图"：各方法关系、适用范围、历史演化
- 超出单文本加工的范畴，是元级别的信息组织能力

**4. 表征方式多样化**
- 代码实现 = 精确的程序性表征
- 实验数据模式 = 经验性表征
- 数学公式 = 形式化符号表征
- 研究生需要在这些表征间自由转换来深化理解

### AI辅助的阶段性差异

- 初高中：AI辅助 = 用多种方式（语言+图示）重新解释知识点
- 大学：AI辅助 = 引导自己构造模型（"你能画出来吗""用自己的话说"）
- 研究生：AI辅助 = 帮助补全论文省略步骤、组织多论文关系图、检验推导严谨性

## 【与哪些模型有关系】

- → [[理解理论]]：费曼方法检验第3级理解；双重编码支撑从认出到结构的跨越
- → [[有效练习理论]]：高利用度练习 = 主动切换表征方式加工同一内容
- → [[输入与练习的不可替代性]]：输入侧的质量取决于加工深度（表征转化次数），不是输入时长
- → [[学习效率理论]]：信息加工的完整路径（输入→表征→内化）是学习效率的底层机制

## 【AI可以在这个模型有什么帮助】

- **表征方式诊断**：AI通过学习者的笔记和回答判断其偏好表征方式，引导切换到非偏好通道加深理解
- **费曼检验**：AI要求学习者用自己的话解释概念，检测语言表征是否完整
- **多模态辅助**：AI为纯文字内容提供图示/空间结构描述，激活意象系统协同编码
- **加工深度监控**：AI判断学习者是否停留在浅层语义加工（只记住文字），引导向逻辑建模推进
- **负荷适配**：AI根据当前任务复杂度建议使用偏好通道（高负荷）还是切换通道（低负荷巩固）
