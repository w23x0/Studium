## 【属于什么理论模块】

能力底层模块 — 将学习能力拆解为五步信息处理流程，作为诊断学习问题的统一框架

## 【核心论述】

学习能力的母能力 = 信息处理能力。所有学习过程都可以拆解为五个步骤：摄入→甄别→分类→建立连接→调取熟练。任何学习困难都可以通过检查这五步定位到具体环节。所谓"天赋高"很多时候只是信息处理的某几步特别强。

## 【机制/模型】

### 信息处理五步流程

| 步骤      | 对应学习行为         | 出问题的表现                 |
| ------- | -------------- | ---------------------- |
| 1. 摄入   | 听课、看书、看视频等一切输入 | 走神/低质量接收/信息源差          |
| 2. 甄别   | 判断信息质量和价值      | 全盘接收、被错误信息干扰、被碎片方法左右拉扯 |
| 3. 分类   | 对信息按结构分层存储     | 知识负担重、找不到、混淆           |
| 4. 建立连接 | 找到知识间的关联，形成网络  | "理解力差"、无法处理综合问题        |
| 5. 调取熟练 | 练习过程中反复调用      | 知道但用不出来、速度慢            |

### 各步骤的问题诊断与对策

**步骤1（摄入）出问题：**
- 走神/低质量接收 → 自律和习惯问题，靠行为改变
- 信息源差 → 更换或补充信息源

**步骤2（甄别）出问题：**
- 本质是对学习的认知不足
- 不知道学科标准 → 容易全盘接收相互干扰
- 不清楚学习原理 → 被各种方法经验拉扯

**步骤3（分类）出问题：**
- 没有统一标准，大多不可言传
- 从实践中逐渐找到感觉
- 没有分类 → 知识负担重，后续步骤无法完成

**步骤4（建立连接）出问题：**
- 所谓"理解力差"往往是这步有问题
- 随着信息量增加和深入，知识间连接必然增多
- 不建立连接 → 无法处理综合性、灵活性强的问题

**步骤5（调取熟练）出问题：**
- 只要前四步没问题，这步靠练习一定会出结果
- 调取越多，路径越通畅（神经可塑性）

### 核心洞察

- 记忆力好 = 已有信息已系统化，新信息更容易被接纳
- 理解力差 = 通常是步骤3和4有问题
- 前三步没问题 + 勤奋 → 初中可以拿高分
- 高中还需要步骤4（建立连接）才能突破

## 【与哪些模型有关系】

- → [[输入与练习的不可替代性]]：步骤1=输入，步骤5=练习，两者对应不同步骤
- → [[认知精准度与上限理论]]：步骤2（甄别）= 学习认知的精准度
- → [[有效练习理论]]（点状→网状）：步骤4（建立连接）= 把点状知识变成网状结构
- → [[直觉形成理论]]：直觉 = 步骤3+4充分完成后，步骤5高度熟练的自动化反应
- → [[信息差与外部资源利用]]：老师的第一类信息差帮助完成步骤3和4
- → [[学习效率理论]]（神经连接）：整个五步流程的生理基础是神经连接的建立和强化
- → [[精准归因能力]]：五步框架提供了精准归因的诊断工具

## 【AI可以在这个模型有什么帮助】

- **步骤诊断**：AI通过测试和提问定位学习者卡在哪个步骤
- **步骤1辅助**：AI提供高质量结构化输入，替代低质量信息源
- **步骤2辅助**：AI帮助甄别信息质量，过滤无效/错误内容
- **步骤3辅助**：AI辅助知识分类，提供结构化的存储框架
- **步骤4辅助**：AI引导学习者发现知识间的关联，帮助构建连接网络
- **步骤5辅助**：AI设计递进练习，提升调取路径的通畅度
