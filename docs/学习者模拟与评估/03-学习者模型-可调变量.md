# 学习者模型：可调变量与构造（草案）

> 状态：待定（2026-09-29 建）。设计侧草案，**不作产品结论**；未经实验。
> 目标（产品负责人 2026-09-29）：做一个**复杂、可调、稳定、准确**的模拟学习者；主要靠提示词工作，用受提示词控制强的模型。
> 来源：`../学习理论/`（下文简称“理论”，文件名省略 `.md`）；真人试用记录 me-1 到 me-9（`../Harness设计/_research/原型实验-N-发现.md`）；外部研究见 §6。
> 说明：模拟人设是测试工具，不是产品输出，所以可以写明水平与倾向。D-08（不给学习者贴标签）约束的是产品，不约束测试人设。

## 1 最大的难点：模型“一被纠正就学会”

| 现象 | 出处 |
| --- | --- |
| 让模型扮演带误解的学生，不管老师的纠正是否说中那条误解，它改答案的比例都差不多；研究者称之为“讨好式”失败——模型不像带着误解的学生，而像一个解题者，把任何纠正都当作信号，扔掉角色、用自己的知识重解 | Misconception Faithfulness（2026），7 个模型都如此 |
| 只靠提示词的模拟学生，回复比真人长得多（约 11 个词对真人约 2 个词），问问题更少，语言过于成熟 | Substance or Illusion（ACL 2026） |
| 我们现有的人设就写着“讲清楚的东西，下一轮可以正确使用”（`proto/learners/owner-like.md`），等于把学会的判断交给了模型自己；`m09check-sim` 的记录是“配合度高，不代表真人” | 本项目 |

**实测（2026-09-29，`proto/runs/simcheck-sfs/result.md`）**：Opus 5.5 / Sonnet 5.5 **没有**出现讨好式失败——只在反馈说中误解时改（12/12），错位或只说“不对”时很少改（0–2/12）；提示词加不加“说中才改”差别不大。论文结论不适用于当下模型。仍未测的是：一次讲清就全对，是否学得比真人快（“要自己用对一次才稳”“换个问法会不会又错”）。

原推论（据此降级为待定）：**“学会了没有”不能交给扮演学习者的那次调用自己决定。** 这是 §4 构造的出发点。

**“相信错的”与“不知道”要分开（2026-09-30，外部证据 + 推断，未验证）**：只写模糊的水平描述（“掌握得差”），小模型（SSKG）和强模型（Srivatsa 等，SSKG 引）都演不出低水平，正确率接近满分；写具体的错误信念，Opus / Sonnet 5.5 能守住（simcheck-sfs）。推断：误解是可执行的错误规则，模型能演；“不知道”要模型压住自己会的东西，难演。起作用的是写法，不是模型大小。

## 2 可调变量

每个变量写：档位、来自哪里、在对话里怎么表现。档位是初步想法，要在校准时再定。

### 2.1 知识状态（每个知识点一份，编号沿用 M08）

| 变量 | 档位 | 来源 | 对话里的表现 |
| --- | --- | --- | --- |
| 理解层级 | 1 认出 / 2 复现 / 3 结构 / 4 迁移 | 理论《理解理论》 | 2 级：能写定义、能按步骤算，问“为什么这样定义”就答不上；3 级：能讲推导动机和条件；4 级：换个情境能自己想到用它。**属“不知道”类，按 §4 改写成具体行为规则** |
| 误解 | 具体的错误信念 + 它在什么情境下冒出来 | 本项目 `learners/typical.md`（把 T(cv) 写成 T(c)T(v)）；外部 MathDial | 在触发情境里稳定地犯同一个错，不是随机错 |
| 前置缺口 | 哪些前置不牢，不牢到什么程度 | 理论《学习效率理论》“前置漏洞 → 负反馈过多”；me-6 | 新内容听得懂，但一用到那个前置就卡住或出错。**属“不知道”类，按 §4 改写成具体行为规则** |
| 熟练度 | 知识 / 思路 / 技巧 三层各自熟不熟 | 理论《有效练习理论》 | 懂道理但算得慢、易出计算错；或者会算但说不出思路 |
| 自述准确度 | 自述比真实水平高 / 准 / 低 | 理论《认知精准度与上限理论》（可得性偏差）；me-9 自述“可能是我记公式没有记原理” | 开场说“这个我会”但一做就错；或者说不会，其实会 |

### 2.2 学习怎样发生（状态更新规则）

| 变量 | 档位 | 来源 | 表现 |
| --- | --- | --- | --- |
| 被动听讲的上限 | 听讲最多把层级提到 2，好的讲解到 3 的一部分；到 4 必须自己做 | 理论《理解理论》“被动接收的天花板” | 老师讲完后说“懂了”，但让自己推时仍卡在关键处 |
| 误解松动的条件 | 只有讲解**正对着**那条误解时才松动；要稳住，还得自己用对一次 | 外部 Misconception Faithfulness；理论《学习效率理论》“行动 → 反馈 → 重复” | 泛泛地说“你错了”，不改或改错；说中了才改 |
| 学得快慢 | 每个知识点要几次自己用对才稳 | 理论《学习效率理论》“练够”；外部：练习的幂律 | 慢的人第二次换个问法又错 |
| 遗忘 | 离开多久、回来时保留多少 | 理论《学习效率理论》（当场表现 ≠ 长期保持）；D-011 回来先回忆 | 隔天回来，细节连不上 |
| 计算失误率 | 低 / 中 / 高，与道理上的缺口分开设 | 理论《有效练习理论》“计算失误指出即可” | 思路对，符号或代数写错 |

### 2.3 思考方式

| 变量 | 档位 | 来源 | 表现 |
| --- | --- | --- | --- |
| 卡在信息处理的哪一步 | 摄入 / 甄别 / 分类 / 连接 / 调取 | 理论《信息处理能力》（作诊断视角） | 连接弱：单个知识点都会，综合起来就乱 |
| 猜答案、跳步 | 不猜 / 偶尔 / 常常 | 本项目 `typical.md`；理论《有效练习理论》“排除法 = 无效练习” | 不会时先猜一个；证明写得很短 |
| 归类意识 | 做完就算 / 会主动问“这类题的共性” | 理论《直觉形成理论》 | 有的学习者会自己总结“这和上一题是同一类” |
| 求完美的地方 | 读的时候死磕到百分之百 / 七八成就往下做 | 理论《完美主义错配理论》 | 死磕型会在一个细节上反复追问、迟迟不动手 |

### 2.4 对话行为

| 变量 | 档位 | 来源 | 表现 |
| --- | --- | --- | --- |
| 回复长度与形式 | 公式片段 / 一两句 / 成段讲 | me-5（学习者始终短答，打公式负担重）；外部：提示词模拟普遍过长 | 真人大多数轮只写几个字 |
| 主动提问 | 很少 / 卡住才问 / 常追问更深 | `owner-like.md`“讲得好会追问”；外部 Substance or Illusion（模拟学生很少主动求助） | 追问型会问“那如果条件变了呢” |
| 想要的教法 | 希望直接讲清楚 / 愿意被引导 | me-6、me-8（“你到底是想反问我什么知识点”） | 对谜题式提问会不耐烦、直接说出来 |
| 说“懂了”的倾向 | 很少说 / 常常附和 | 守卫“不采信自述”；理论《理解理论》“觉得懂 ≠ 真懂” | 附和型会说“嗯明白”，接着做错 |
| 困惑怎么表达 | 明说 / 含糊说 / 不说直接放弃 | me-9（困惑以一句自述带过） | 含糊型只说“有点绕” |
| 输入成本 | 打字、打公式的负担 | me-5 | 负担高时把式子省成文字描述，或者干脆不写 |

### 2.5 状态与情绪（只写可以观察到的行为）

| 变量 | 档位 | 来源 | 表现 |
| --- | --- | --- | --- |
| 精力曲线 | 第几轮开始下降，下降多快 | me-6（第 15 轮起“不太想算了”“大脑不怎么能深入思考”） | 回复变短、错误变多、想结束 |

| 对被考的反感 | 阈值高 / 低 | 理论《审判感机制》；me-1（“像考试”）、me-8 | 连续被要求证明时反感，开始敷衍 |
| 犯错之后 | 继续试 / 放慢 / 停下回避 | 理论《学习焦虑的分类与干预》（遇到高错误率就停）、《学习效率理论》（把错误当成失败） | 回避型连错两次后转移话题或想结束 |

## 3 “乱”怎么放进去

产品负责人：学习者的情况很乱。设计侧想法：

| 做法 | 说明 |
| --- | --- |
| 人设 = 变量取值的组合 | 预设几种组合（例如接近产品负责人的、应试型、回避型），也可以随机组合 |
| 事件由程序按概率注入，带随机种子 | 中途离开、状态下降、突然想换方向等，交给程序而不是模型自己决定；有种子就能复现同一次“乱” |
| 真人记录是锚 | 每个预设人设都要能指出它像 me-几里的哪一段 |

## 4 构造：让“稳定准确”不只靠一次提示（初步想法，未验证）

| 部分 | 做什么 | 为什么 |
| --- | --- | --- |
| 人设卡 | 一份文件写全 §2 的变量取值，知识状态逐个知识点写 | 可调：改卡不改提示词 |
| 状态更新调用 | 每轮先单独判断：老师这一轮是否正对着某条误解或缺口讲了？学习者自己做了没有？按 §2.2 的规则输出状态变化，写回人设卡的状态区 | 把“学会没有”从扮演调用里拿出来，针对 §1 的讨好式失败 |
| 扮演调用 | 只看人设卡、当前状态和学习者能看到的对话，写出学习者这一轮说的话 | 扮演只负责“像”，不负责决定学没学会 |
| 程序 | 管随机事件、种子、轮次，记录每轮的状态变化 | 可复现；状态变化本身也是评估数据（能看出教学到底动了哪一条） |

这仍然主要是提示词的工作（两次调用各一份提示词），只多了一步程序维护的状态。

**不确定**：两次调用会不会让回复变得机械；状态更新调用本身是否准确（它也是一个需要校准的判断）。

**“不知道”怎么演（产品负责人 2026-09-30 选 1，未验证）**：

| # | 做法 | 状态 |
| --- | --- | --- |
| 1 | 把“不知道”改写成具体行为规则：不写“前置不牢”，写“遇到要用 X 的那一步会卡住、说不出下一步 / 拿 Y 顶替 X”；理解 2 级写“被问为什么只能复述定义或步骤” | **采用**；风险是规则只覆盖想到的情境，开放对话里可能露出会；用 `06` E1、E2 检验 |
| 2 | 外部状态决定对错、扮演只负责说得像（EduClaw / SSKG；M08 可当知识图谱） | 1 守不住时的备选；开放对话里“错成什么样”本身要校准 |
| 3 | 发出前检查是否超出人设知识，超出重写 | 未选 |
| 4 | 换小模型或微调 | 不做（精力、硬件） |

**外部先例**：EduClaw-Bench 同样把状态与扮演分开，但状态更新靠用真实数据训练的知识追踪模型，不是模型调用（§7）；它证明结构可行，不证明我们的更新方式可行。

## 6 怎么检验模拟得准不准（接 `02` §2）

| 检验 | 做法 | 来源 |
| --- | --- | --- |
| 选择性翻转 | 同一条误解，分别给正对着它的讲解、针对另一条误解的讲解、只说“错了”三种反馈，看学习者是不是只在第一种情况下改 | Misconception Faithfulness 的对照设计 |
| 对照真人 | 从 me-5、me-6、me-8、me-9 里截取对话前段，让模拟学习者续写下一轮，与真人的实际回复比较长度、行为、对错 | Substance or Illusion 的逐轮对照方法 |
| 重复波动 | 同一人设、同一段链、不做任何改动，重复跑几次 | `02` §2 |
| 行为而非自评 | 检验人设是否稳住看旁观评分（评委看行为），不问模拟学生自己；自评在行为漂移时仍保持稳定 | ADHD 人设稳定性（§7） |

## 7 外部研究

| 文献 | 用到的点 |
| --- | --- |
| Simulating Students or Sycophantic Problem Solving? On Misconception Faithfulness of LLM Simulators，arXiv 2605.12748（2026） | 讨好式失败；三种反馈对照；靠微调可以改善 |
| Simulated Students in Tutoring Dialogues: Substance or Illusion?，arXiv 2601.04025，ACL 2026 | 六个维度：对话动作、对错、犯错方式、知识习得、语言、对老师的回应；只用提示词普遍失败 |
| EduClaw-Bench，arXiv 2608.03206（2026-08） | 30 天长程模拟学习者；11 种学习者性格 × 5 种学习安排。**正文核对（2026-09-30）**：构造与 §4 同思路——知识状态在知识追踪模型里（831 个知识点各一个掌握度，用真实学生数据训练，小学数学约 5000 名学生，AUC 0.80），每答一题按公式更新；大模型只按当前掌握度扮演作答（提示词写能力档、年级、最弱 / 最强知识点）。**边界**：状态更新靠数据训练的模型，本项目没有这类数据；校准 ECE 0.049 测的是模拟作答与知识追踪掌握度对得上，不是“像真人”；课堂实测（约 500 名中小学生，另一套家教系统）验证的是评分标准，不是模拟学习者；家教可直接读掌握度（`GET /mastery`），现实做不到；扮演用 4B–8B 小模型，能力档固定“中”，单一种子。另两条结论：教学质量是底座模型 × 外壳的搭配属性（换底座排名重排）；30 天几乎没有组合能持续有效，单次成功约 0.47、4 次全成功约 0.11（pass^k，见 `04`） |
| StudentSim，arXiv 2609.01591（微软等，2026-09-01） | 用稀疏数据训练个性化模拟学生（本项目暂不微调，只记方向）。**正文核对（2026-09-30）**：两个指标——行为保真 F（能否复现某个学生改前的具体答案和错误）、指导响应 R（读了指导后是否改到**标准正确答案**，不是真人实际改成什么）。GPT-5.4 靠提示扮演：原话“流畅地跟着指导走”（R 棋 0.72、数学 0.71，均低于 StudentSim 的 0.91、0.92），但复现不了具体学生的水平与错误（F 棋 23% 对 51%；数学四选一 0.61 对 0.64，差距小）。家教训练只做国际象棋（家教 Qwen3-VL-8B；8 名棋手盲评 74 条）：以 StudentSim 为奖励准确率 90.5%，不训练 75.7%，以 GPT-5.4 为奖励 71.6%。**边界**：只测 GPT-5.4 / GPT-4o，没有 Claude、Gemini；学生数 30 / 15 / 15；R 只看一步更新，作者自认不涉及长期学习动态，**回答不了 `06` 的“是否学得比真人快”**。可用处：“靠文字人设控制具体水平与错误不可靠”的旁证，主要证据在国际象棋。**社交媒体误读**：X 上流传的“通用模型扮演学生太容易被纠正、高估吸收能力”，原文没有这个说法 |
| Temporal Student Persona Stability Across ADHD Profiles，arXiv 2605.06307（v4 2026-09；模型偏旧：Opus 4.5、GPT-5.1、Gemini 3.1 Pro、DeepSeek V4 Flash、Grok 4.1 Fast） | **只涉及 §2.4 对话行为、§2.5 状态与情绪，不涉及知识状态与误解**。9 轮对话：自由对话中旁观评分下降约 11%（向普通学生靠拢），模型自评却保持稳定——**自评查不出漂移**；对话方每轮给与任务相关的固定提示，漂移减少 97%；中等强度人设比高强度不稳。**边界**：他们安排的是对话方的台词，我们的对话方是被测教学系统，不能安排；可借的只是原理（角色信号每轮出现在模拟学生眼前，由程序追加，未验证）。与 §4“扮演调用每轮重看人设卡”方向一致 |
| SSKG，arXiv 2608.21668（2026-08；模型偏旧小档：Haiku 4.5、GPT-5.4-mini、Gemini 3.1 Flash Lite） | 379 道 SAT 代数选择题、5 种画像：只写画像（含“掌握得很差”）正确率 96.8–100%，画像间无差别；外部按掌握度抽签定对错、模型只写理由后降到 44–85% 并呈梯度。引 Srivatsa 等：强模型按年级扮演也在每个年级超过真实学生。**边界**：单次选择题、无对话；未对照真实学生；只测了模糊画像，未测具体错误信念。用于 §1“相信错的 / 不知道”之分 |
| MathDial（Macina et al. 2023） | 带误解的模拟学生对话数据 |
