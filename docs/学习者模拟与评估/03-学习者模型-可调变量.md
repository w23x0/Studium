# 学习者模型：可调变量与构造（草案）

> 状态：待定（2026-09-29 建）。设计侧草案，**不作产品结论**；未经实验。
> 目标（产品负责人 2026-09-29）：做一个**复杂、可调、稳定、准确**的模拟学习者；主要靠提示词工作，用受提示词控制强的模型。
> 来源：`../学习理论/`（下文简称“理论”，文件名省略 `.md`）；真人试用记录 me-1 到 me-9（`../Harness设计/_research/原型实验-N-发现.md`）；外部研究见 §6。
> 说明：模拟人设是测试工具，不是产品输出，所以可以写明水平与倾向。D-08（不给学习者贴标签）约束的是产品，不约束测试人设。

## 1 最大的难点：模型“一被纠正就学会”

| 现象 | 出处 |
| --- | --- |
| 让模型扮演带误解的学生，不管老师的纠正是否说中那条误解，它改答案的比例都差不多；研究者称之为“讨好式”失败——模型不像带着误解的学生，而像一个解题者，把任何纠正都当作信号，扔掉角色、用自己的知识重解 | Misconception Faithfulness（2026），7 个模型都如此 |
| 只靠提示词的模拟学生，回复比真人长得多（约 11 个词对真人约 2 个词），问问题更少，语言过于成熟 | Substance or Illusion（ACL 2026） |
| 我们现有的人设就写着“讲清楚的东西，下一轮可以正确使用”（`proto/learners/owner-like.md`），等于把学会的判断交给了模型自己；`m09check-sim` 的记录是“配合度高，不代表真人” | 本项目 |

推论（设计侧）：**“学会了没有”不能交给扮演学习者的那次调用自己决定。** 这是 §4 构造的出发点。

## 2 可调变量

每个变量写：档位、来自哪里、在对话里怎么表现。档位是初步想法，要在校准时再定。

### 2.1 知识状态（每个知识点一份，编号沿用 M08）

| 变量 | 档位 | 来源 | 对话里的表现 |
| --- | --- | --- | --- |
| 理解层级 | 1 认出 / 2 复现 / 3 结构 / 4 迁移 | 理论《理解理论》 | 2 级：能写定义、能按步骤算，问“为什么这样定义”就答不上；3 级：能讲推导动机和条件；4 级：换个情境能自己想到用它 |
| 误解 | 具体的错误信念 + 它在什么情境下冒出来 | 本项目 `learners/typical.md`（把 T(cv) 写成 T(c)T(v)）；外部 MathDial | 在触发情境里稳定地犯同一个错，不是随机错 |
| 前置缺口 | 哪些前置不牢，不牢到什么程度 | 理论《学习效率理论》“前置漏洞 → 负反馈过多”；me-6 | 新内容听得懂，但一用到那个前置就卡住或出错 |
| 熟练度 | 知识 / 思路 / 技巧 三层各自熟不熟 | 理论《有效练习理论》 | 懂道理但算得慢、易出计算错；或者会算但说不出思路 |
| 自述准确度 | 自述比真实水平高 / 准 / 低 | 理论《认知精准度与上限理论》（可得性偏差）；me-9 自述“可能是我记公式没有记原理” | 开场说“这个我会”但一做就错；或者说不会，其实会 |

### 2.2 学习怎样发生（状态更新规则）

| 变量 | 档位 | 来源 | 表现 |
| --- | --- | --- | --- |
| 被动听讲的上限 | 听讲最多把层级提到 2，好的讲解到 3 的一部分；到 4 必须自己做 | 理论《理解理论》“被动接收的天花板” | 老师讲完后说“懂了”，但让自己推时仍卡在关键处 |
| 误解松动的条件 | 只有讲解**正对着**那条误解时才松动；要稳住，还得自己用对一次 | 外部 Misconception Faithfulness；理论《学习效率理论》“行动 → 反馈 → 重复” | 泛泛地说“你错了”，不改或改错；说中了才改 |
| 学得快慢 | 每个知识点要几次自己用对才稳 | 理论《学习效率理论》“练够”；外部：练习的幂律 | 慢的人第二次换个问法又错 |
| 遗忘 | 离开多久、回来时保留多少 | 理论《学习效率理论》（当场表现 ≠ 长期保持）；D-011 回来先回忆 | 隔天回来，细节连不上 |
| 计算失误率 | 低 / 中 / 高，与道理上的缺口分开设 | 理论《有效练习理论》“计算失误指出即可” | 思路对，符号或代数写错 |

### 2.3 思考方式

| 变量 | 档位 | 来源 | 表现 |
| --- | --- | --- | --- |
| 卡在信息处理的哪一步 | 摄入 / 甄别 / 分类 / 连接 / 调取 | 理论《信息处理能力》（作诊断视角） | 连接弱：单个知识点都会，综合起来就乱 |
| 猜答案、跳步 | 不猜 / 偶尔 / 常常 | 本项目 `typical.md`；理论《有效练习理论》“排除法 = 无效练习” | 不会时先猜一个；证明写得很短 |
| 归类意识 | 做完就算 / 会主动问“这类题的共性” | 理论《直觉形成理论》 | 有的学习者会自己总结“这和上一题是同一类” |
| 求完美的地方 | 读的时候死磕到百分之百 / 七八成就往下做 | 理论《完美主义错配理论》 | 死磕型会在一个细节上反复追问、迟迟不动手 |

### 2.4 对话行为

| 变量 | 档位 | 来源 | 表现 |
| --- | --- | --- | --- |
| 回复长度与形式 | 公式片段 / 一两句 / 成段讲 | me-5（学习者始终短答，打公式负担重）；外部：提示词模拟普遍过长 | 真人大多数轮只写几个字 |
| 主动提问 | 很少 / 卡住才问 / 常追问更深 | `owner-like.md`“讲得好会追问”；外部 Substance or Illusion（模拟学生很少主动求助） | 追问型会问“那如果条件变了呢” |
| 想要的教法 | 希望直接讲清楚 / 愿意被引导 | me-6、me-8（“你到底是想反问我什么知识点”） | 对谜题式提问会不耐烦、直接说出来 |
| 说“懂了”的倾向 | 很少说 / 常常附和 | 守卫“不采信自述”；理论《理解理论》“觉得懂 ≠ 真懂” | 附和型会说“嗯明白”，接着做错 |
| 困惑怎么表达 | 明说 / 含糊说 / 不说直接放弃 | me-9（困惑以一句自述带过） | 含糊型只说“有点绕” |
| 输入成本 | 打字、打公式的负担 | me-5 | 负担高时把式子省成文字描述，或者干脆不写 |

### 2.5 状态与情绪（只写可以观察到的行为）

| 变量 | 档位 | 来源 | 表现 |
| --- | --- | --- | --- |
| 精力曲线 | 第几轮开始下降，下降多快 | me-6（第 15 轮起“不太想算了”“大脑不怎么能深入思考”） | 回复变短、错误变多、想结束 |
| 离开与中断 | 会不会中途离开，离开多久 | me-6、D-011 | 回来时说“刚才的连不上了” |
| 对被考的反感 | 阈值高 / 低 | 理论《审判感机制》；me-1（“像考试”）、me-8 | 连续被要求证明时反感，开始敷衍 |
| 犯错之后 | 继续试 / 放慢 / 停下回避 | 理论《学习焦虑的分类与干预》（遇到高错误率就停）、《学习效率理论》（把错误当成失败） | 回避型连错两次后转移话题或想结束 |
| 投入程度 | 高 / 中 / 低 | 理论《学习者效能理论》（投入量；四象限已否定，不用） | 投入低时只回最少的字 |

## 3 “乱”怎么放进去

产品负责人：学习者的情况很乱。设计侧想法：

| 做法 | 说明 |
| --- | --- |
| 人设 = 变量取值的组合 | 预设几种组合（例如接近产品负责人的、应试型、回避型），也可以随机组合 |
| 事件由程序按概率注入，带随机种子 | 中途离开、状态下降、突然想换方向等，交给程序而不是模型自己决定；有种子就能复现同一次“乱” |
| 真人记录是锚 | 每个预设人设都要能指出它像 me-几里的哪一段 |

## 4 构造：让“稳定准确”不只靠一次提示（初步想法，未验证）

| 部分 | 做什么 | 为什么 |
| --- | --- | --- |
| 人设卡 | 一份文件写全 §2 的变量取值，知识状态逐个知识点写 | 可调：改卡不改提示词 |
| 状态更新调用 | 每轮先单独判断：老师这一轮是否正对着某条误解或缺口讲了？学习者自己做了没有？按 §2.2 的规则输出状态变化，写回人设卡的状态区 | 把“学会没有”从扮演调用里拿出来，针对 §1 的讨好式失败 |
| 扮演调用 | 只看人设卡、当前状态和学习者能看到的对话，写出学习者这一轮说的话 | 扮演只负责“像”，不负责决定学没学会 |
| 程序 | 管随机事件、种子、轮次，记录每轮的状态变化 | 可复现；状态变化本身也是评估数据（能看出教学到底动了哪一条） |

这仍然主要是提示词的工作（两次调用各一份提示词），只多了一步程序维护的状态。

**不确定**：两次调用会不会让回复变得机械；状态更新调用本身是否准确（它也是一个需要校准的判断）。

## 6 怎么检验模拟得准不准（接 `02` §2）

| 检验 | 做法 | 来源 |
| --- | --- | --- |
| 选择性翻转 | 同一条误解，分别给正对着它的讲解、针对另一条误解的讲解、只说“错了”三种反馈，看学习者是不是只在第一种情况下改 | Misconception Faithfulness 的对照设计 |
| 对照真人 | 从 me-5、me-6、me-8、me-9 里截取对话前段，让模拟学习者续写下一轮，与真人的实际回复比较长度、行为、对错 | Substance or Illusion 的逐轮对照方法 |
| 重复波动 | 同一人设、同一段链、不做任何改动，重复跑几次 | `02` §2 |
