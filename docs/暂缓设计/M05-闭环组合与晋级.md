| --- | --- |
| 原结论 | 小闭环组合成父闭环、向上晋级（对应最小学习单元的闭环嵌套：子概念 → 体系 → 跨域）。**默认规则**：子闭环都达到“结构”级才开父闭环；父闭环的验收主张写**子对象之间的结构与跨子迁移**，不重复子闭环的主张；跨域闭环对应远迁移。**允许跳跃**（不必一步步来，D-02）：M05 可带着未完成的子闭环先开父闭环，此时须做三件事——① 在父闭环的验收范围里标出**哪些主张依赖哪个未完成子闭环**，守卫核对这些主张时同时列出依赖缺口；② 父闭环进行中若卡点追到该子闭环，M04 按“已知缺口”给改线依据（回补），不当新问题重诊；③ 跳跃及其后果（是否回补、回补几次）记入路线偏差记录，供以后判断跳跃是否划算。未完成子闭环按“未完成负债”计入停车场。（2026-09-23） |
| 依据 | `最小学习单元理论.md` §阶段适配（闭环嵌套）、§三条关键推论（负债）；`理解理论.md`；产品负责人 2026-09-23 讨论 |
| 原建议 | 主干方向 |
| 理由 | 没有组合规则，闭环只能平铺，无法向上形成体系；跳跃不留痕，未完成负债会在后续闭环里以“莫名卡住”的形式出现。 |
