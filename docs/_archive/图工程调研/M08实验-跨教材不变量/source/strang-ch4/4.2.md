## $A ^ { \mathrm { T } }$ A is invertible if and only if A has linearly independent columns.

Proof $A ^ { \mathrm { T } } A$ is a square matrix $( n \ \mathsf { b y } \ n )$ . For every matrix $A ,$ we will now show that $A ^ { \mathrm { T } } A$ has the same nulspace as A.
