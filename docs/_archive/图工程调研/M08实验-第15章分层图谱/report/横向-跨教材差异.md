## 3. 同名异物陷阱

六个。每个都给两边的逐字引用。

### 3.1 "orthogonal set" —— 零元素能不能进去

Apostol(15.11):

```
A subset S of V is called an orthogonal set if $(x, y) = 0$ for every pair of distinct elements x and y in S.
```

条件只约束**互异**的一对。零元素与任何元素内积为零,也与自己内积为零,所以 $\{O, e_1, e_2\}$ 按 Apostol 的定义**是**一个正交集。他必须把"非零"另外写进定理里:

```
THEOREM 15.10. In a Euclidean space V, every orthogonal set of nonzero elements is independent.
```
(15.11)

Strang(3.4):

```
We can never allow the zero vector into a basis, because then linear independence is lost.
```

差异与代价:Apostol 的"正交集"是一个比"正交基"弱得多的对象,弱到不保证独立,所以 15.11 需要一条单独的定理去补;Strang 从一开始就把零向量排除在他关心的对象之外,省掉这条定理,但也就没法讨论"含零的正交集"这种中间物。读者若把两本书的"orthogonal set"当同一个词,会以为 Apostol 定理 15.10 是废话。

### 3.2 "orthogonal subspaces" ≠ "orthogonal complement"

Strang(4.1)明确把两者拆开,并给出反例:

```
Example 2 Two walls look perpendicular but those two subspaces are not orthogonal! The meeting line is in both $V$ and W -and this line is not perpendicular to itself.
```

Apostol(15.14)只定义了 $S^{\perp}$,从不定义"两个子空间正交",也从不提这个反例:

```
The set of all elements orthogonal to S is denoted by $S^{\perp}$ and is called “S perpendicular.”
```

差异与代价:Apostol 的路线上不需要"两个子空间正交"这个概念——他只需要 $S$ 和 $S^{\perp}$ 这一对,而这一对天然满足正交且交为 $\{O\}$。代价是读者从 Apostol 出来后,很容易把"看起来垂直的两个平面"误认为正交子空间;Strang 花一整个例子堵这个洞,因为他要靠"行空间 ⊥ 零空间"这种具体子空间对做计算,必须先说清什么不算。

### 3.3 $S^{\perp}$ 的适用范围 —— 任意子集 vs 只对子空间

Apostol(15.14):

```
It is a simple exercise to verify that $S^{\perp}$ is a subspace of V, whether or not S itself is one. In case S is a subspace, then $S^{\perp}$ is called the orthogonal complement of S.
```

Strang(4.1):

```
DEFINITION The orthogonal complement of a subspace V contains every vector that is perpendicular to V. This orthogonal subspace is denoted by $V ^ { \perp }$ (pronounced "V perp").
```

差异与代价:Apostol 对**任意子集**取 $\perp$,并把"orthogonal complement"这个**名字**保留给子空间的情形——即记号的适用范围比名字宽。Strang 只对子空间定义,而且立刻把它嵌进一个维数配对里($\dim V + \dim V^{\perp} = n$)。代价:Apostol 的 $S^{\perp}$ 没有维数公式($S$ 可能是无穷维,可能不是子空间),他只在 15.15 定理里对**有限维子空间** $S$ 才拿到分解;Strang 的 $V^{\perp}$ 总是配平的,但代价是他不能对一个随手给的向量集合直接取 $\perp$,得先取张成。

### 3.4 "projection" —— 沿一个元素 vs 投到一条直线

Apostol(15.13),这是 Gram-Schmidt 的中间步骤,只是一个被减掉的量:

```
is called the projection of x along y. In the Gram-Schmidt process (15.15), we construct the element $y_{r+1}$ by subtracting from $x_{r+1}$ the projection of $x_{r+1}$ along each of the earlier elements $y_{1},\ldots,y_{r}$ .
```

Strang(4.2),这是整章的地基,而且立刻产出一个矩阵:

```
The projection of b onto the line through a is the vector $p = { \widehat { x } } a = { \frac { a ^ { \mathrm { T } } b } { a ^ { \mathrm { T } } a } } a$
```

差异与代价:同一个公式在两本书里的**地位**相反。Apostol 的"projection along $y$"是一个辅助量,他真正的目标对象是"投到子空间 $S$";Strang 的"projection onto a line"是范式,子空间投影是把它推广($a \to A$,$a^{\mathrm{T}}a \to A^{\mathrm{T}}A$)。代价:Apostol 因此不给一维投影单独命名成矩阵,失去 $P = aa^{\mathrm{T}}/a^{\mathrm{T}}a$ 这个"秩一"观察;Strang 因此必须先讲一维再讲子空间,顺序被锁死。

### 3.5 "dimension" / "rank" —— 一个空间的数 vs 一个矩阵的数

Strang(3.4)把语言禁令写在明面上:

```
Note about the language of linear algebra We never say "the rank of a space" or "the dimension of a basis" or "the basis of a matrix". Those terms have no meaning. It is the dimension of the column space that equals the rank of the matrix.
```

Apostol(15.08):

```
DEFINITION. If a linear space V has a basis of n elements, the integer n is called the dimension of V. We write $n = \dim V$ . If $V = \{O\}$ , we say V has dimension 0.
```

差异与代价:Apostol 只有 dimension,附着在空间上;Strang 有 dimension 和 rank 两个数,分别附着在空间和矩阵上,靠 Rank Theorem 把它们焊起来。代价:Apostol 没有任何"数出维数"的手段——`x:all-bases-are-equinumerous` 保证维数良定义,但要知道 $\dim S$ 是几,得手工找一组基;Strang 一消元就读出来。反过来,Strang 的 rank 一旦离开矩阵就没有主词。

### 3.6 "basis" —— 集合 vs 序列

Apostol(15.08):

```
DEFINITION. A finite set S of elements in a linear space V is called a finite basis for V if S is independent and spans V.
```

Strang(3.4):

```
DEFINITION A basis for a vector space is a sequence of vectors with two properties:
```
```
Correct language: "The sequence of vectors is linearly independent." Acceptable shortcut: "The vectors are independent." Unacceptable: "The matrix is independent."
```

差异与代价:Strang 要序列,因为基向量要当矩阵的列排进去,顺序决定了 $A$ 是哪个矩阵、$\widehat{x}$ 的分量对应谁;Apostol 要集合,因为他不排矩阵,顺序无意义——但这让他的 Gram-Schmidt 必须另外声明输入是**序列**(15.13 用的是 "a finite or infinite sequence of elements"),即他在需要顺序的地方偷偷换回了序列。这一处是"表示需求反向渗透进抽象叙述"的最清楚证据。

## 4. 表示依赖

问题:哪些结论一旦离开矩阵表示,就**不成立**、或者**还成立但不再可计算**?

### 4.1 离开矩阵表示后不再成立(陈述本身失去主词)

- **秩、主元、消元**。三者都是"对一张数表做行操作"的产物。没有数表,没有主元。
- **Rank Theorem(行秩 = 列秩)**。需要同一个对象有"行"和"列"两种切法。抽象线性空间里没有这种双重性;要恢复它得先引入对偶空间,而那比矩阵贵。
- **四个基本子空间**。它们是从 $A$ 和 $A^{\mathrm{T}}$ 派生的。$A^{\mathrm{T}}$ 在抽象层的对应物是伴随算子,而伴随算子的存在本身需要内积——即 Strang 在第 3 章就免费用上的 $A^{\mathrm{T}}$,抽象层要等到有内积(Apostol 15.10)才买得到。
- **投影矩阵 $P$、$P^2=P$、$I-P$**。见 2.5。
- **$A^{\mathrm{T}}A$ 可逆 ⟺ $A$ 列独立**。左边完全是矩阵陈述。抽象对应物是 Gram 矩阵非奇异,仍然要把内积排成表。
- **"$A$ 里藏着 $r \times r$ 可逆矩阵"**。见 2.6。

### 4.2 离开矩阵表示仍然成立,但不再可计算

这一类是本实验里最值得记的:**Apostol 的定理更普适,但它的证明不给算法**。

- **所有基等势 / 维数良定义**。抽象层成立(Apostol 定理 15.5、15.6),但"这个空间的维数是几"没有过程。Strang 用消元读主元个数,直接给出数。
- **正交分解 $x = s + s^{\perp}$**。Apostol 对任意 Euclidean 空间的任意有限维子空间 $S$ 成立,包括函数空间。但他的构造是

```
s = \sum_ {i = 1} ^ {n} (x, e _ {i}) e _ {i}, \quad s ^ {\perp} = x - s.
```
(15.14)

  **必须先有正交规范基**。所以在函数空间里,分解仍然存在,但要算出来必须先跑一遍 Gram-Schmidt(可能是无穷序列),这不是有限步算法。Strang 的 $p = A(A^{\mathrm{T}}A)^{-1}A^{\mathrm{T}}b$ 只要求列独立,一次求解就完事。
- **最佳逼近**。Apostol 的逼近定理对任意 Euclidean 空间成立(15.15),这就是为什么三角逼近和多项式逼近能合并;但"求出这个最佳逼近"落回上一条,仍需正交基。Strang 的最小二乘是解一个 $n \times n$ 方程组。
- **Pythagorean 恒等式 $\|x\|^2 = \|s\|^2 + \|s^{\perp}\|^2$**。纯粹从内积公理推出,与表示无关;Strang 侧的对应物是"误差向量在左零空间里"这种具体定位,更强但更窄。

### 4.3 结论:抽象买到了什么、Strang 补上了什么

Apostol 用"先有正交基"换来了**定理的适用面**(实/复、有限/无限维、任意内积、函数空间),代价是把 Gram-Schmidt 变成投影的**硬前置**:15.13 必须排在 15.14 前面,否则 15.14 的定义写不出来。

Strang 用"锁定矩阵表示"换来了**不需要正交基**:他的投影只要求 $A$ 列独立,代价是必须解法方程 $A^{\mathrm{T}}A\widehat{x} = A^{\mathrm{T}}b$,并且必须单独证明 $A^{\mathrm{T}}A$ 可逆(4.2 用了一整段带证明的标题句)。Gram-Schmidt 在他那里降级成一个**优化**——把 $A^{\mathrm{T}}A$ 变成对角:

```
That was a perfect example of the "Gram-Schmidt idea" coming in the next section: Make the columns orthogonal in advance. Then $A _ { \mathrm { n e w } } ^ { \mathrm { T } } A _ { \mathrm { n e w } }$ is diagonal and $\widehat { \boldsymbol { x } } _ { \mathrm { n e w } }$ is easy.
```
(4.3)

同一个工具,在 Apostol 那里是**必需品**(没有它投影无定义),在 Strang 那里是**加速器**(没有它照样能投影,只是要解方程)。这是本次跨教材对齐里最干净的一处"抽象的代价"。

## 5. 放弃对齐的内容(不静默截断)

以下内容存在明显的跨教材对应,但**没有**写成 `x:` 节点,原因如下:

1. **Gram-Schmidt 本身**。Strang 的 Gram-Schmidt 在 4.4,不在 manifest 覆盖的 3.3–3.5 / 4.1–4.2 范围内,**manifest 里没有任何 `strang:gram-schmidt` 类 id**。造 id 是本实验最严重的缺陷,所以宁可不建这个节点。它的对齐结论以文字形式留在本文 4.3。同理 $Q^{\mathrm{T}}Q=I$、正交矩阵、$A=QR$ 全部放弃。
2. **最小二乘的完整对齐**。Strang 的最小二乘主体在 4.3,同样在 manifest 之外。`x:least-squares-is-a-projection` 与 `x:best-approximation-by-the-projection` 只能挂到 4.1/4.2 里的 `strang:normal-equation`、`strang:error-vector`、`strang:solvability-condition`、`strang:projection-onto-a-subspace`,anchor 取自 4.1/4.2。拟合直线、$C+Dt$、误差平方和这些具体内容没有节点。
3. **Cauchy–Schwarz、三角不等式、范数公理、夹角**。Apostol 单边,Strang 第 3–4 章无对应(他的 $\|\cdot\|$ 是既有工具,不作公理化处理)。没有 Strang 侧 anchor,按"每边至少一条 anchor"的规则不能建 `x:` 节点,只在本文 1.4 记录。
4. **Parseval / 正交规范基下的分量公式**。Strang 侧材料在 4.4,同 1。
5. **Fourier 级数、Legendre 多项式、三角逼近**。Apostol 单边应用层,Strang 明确推给第 10.5 节。只在本文 1.3、1.5 记录。
6. **复数域**。Apostol 单边,见 1.1。
7. **D 层原子节点的细粒度对齐**。230 个 D 层节点里只有与上述不变量直接相关的少数被引用进 `apostol_ids`;Apostol 公理逐条(闭合性、结合律等)与 Strang 的向量空间要求没有做逐条配对,因为 Strang 第 3–4 章不重述公理表。
