## `apostol:cx-absolute-value-of-the-dot-product-breaks-homogeneity`

- 文件：`data/nodes-A2-x2.jsonl`
- 无锚点数值：`0`
- statement：The formula (x, y) = |sum x_i y_i| is symmetric and strictly positive on nonzero elements, so it passes axioms 1 and 4, but it is not an inner product: homogeneity fails for negative scalars, because (cx, y) = |c| |sum x_i y_i|, and additivity fails because |a + b| is not |a| + |b| in general: for n = 1 with x = 1, y = 1, z = -1 one gets (x, y + z) = 0 while (x, y) + (x, z) = 2.
