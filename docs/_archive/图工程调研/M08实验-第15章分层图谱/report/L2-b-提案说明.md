## 逐个候选：为什么它是结构而不是话题

### C1 `L2:dimension-as-a-two-sided-count-barrier` 维数是一道双向计数壁垒

不是「维数这一节」，而是 Apostol 证 15.6 时的那一次操作：把 15.5 分别用在两个基上，各得一条不等式（m ≤ k 与 k ≤ m），再由反对称性夹出相等。抽出来的结构是「同一个数从两侧夹」——上限管无关集（n+1 个必相关），下限管张成集（不少于 n 个）。之所以是一个结构，是因为这两侧不是并列的两条性质，而是同一次挤压的两半，去掉任一半 15.6 就证不出来。边界里我特意放了容易被误读的那一个：下限只说张成集「不少于」n 个，`{O, i, -i, j, -j, i+j}` 张成 V_2 却有 6 个元素，所以不能反过来说张成集有 n 个元素。增益是一个不需要计算的反驳动作，而这在 Apostol 一侧是唯一可用的工具——他全章没有消元算法。

### C2 `L2:count-saturation-upgrades-a-necessary-condition-to-a-sufficient-one` 计数饱和把必要条件升级为充分条件

这个候选最需要辩护它不是在重述 `x:right-count-upgrades-one-basis-property-to-both`。区别在于：X 节点说的是基的两个子句之间的升级；我提的是「某个量顶到已知上限」这个更一般的机制，并且给出了三个不同族的实例——15.7b（n 个无关元素成基）、15.10 的那一条（n 个非零正交元素成基，走的是完全不同的假设：正交＋非零，而不是无关）、以及 Strang 4.1 的正交对在维数加对时升级成正交补。第三个实例里被升级的甚至不是基的性质，而是子空间对的关系，所以它不可能是 X 节点的换皮。边界写的是「饱和有时反而让另一条变成不可能」：R³ 里两个 2 维平面各自不超上限，但 2+2 > 3，于是根本不可能正交，两面墙的相交线同时在两个子空间里而它不垂直于自己。

### C3 `L2:one-independent-constraint-costs-exactly-one-dimension` 一条独立约束恰好花掉一个自由度

结构是「汇率」本身：约束与自由度之间有一个固定的兑换比，兑换完两侧的数必须重新加回环境的那个数。Strang 把它写成定律并当推理工具用——他证 N(A) 的垂空间就是行空间时，靠的正是「再添一条独立行就会破坏 r+(n−r)=n」。Apostol 从不写这条式子，但同一套账目就是二阶齐次方程解空间为 2 维、次数 ≤ n 的多项式为 n+1 维的原因，所以这个结构横跨两侧而两侧的表达完全不同，这是它有内容的证据。

出处边界我写得比较硬，因为这里最容易张冠李戴：**Apostol 15.14 只给了唯一正交分解，全章没有 dim S + dim S^⊥ = dim V 这条式子**，这条计数定律的文本只在 Strang 3.5/4.1 一侧。本候选是把 Strang 的账目方式搬到 Apostol 的例子上，不能反过来说 Apostol 陈述了它。另两条边界是汇率的适用条件：相关的行不花钱（秩数的是主元不是行）；非齐次时根本没有维数可付，`y''=2` 的解集不是子空间，完全解是平移而不是丢一个自由度。

### C4 `L2:a-basis-locks-the-coordinate-count-not-the-geometry` 基锁定坐标个数，不锁定几何

这一个是「守恒量的边界」而不是守恒量的应用：固定基之后被锁死的量**只有**坐标个数，长度、角度、正交性全都不在其中。之所以是结构，因为它同时解释了两件本来不相干的事——为什么唯一性证明只用无关性（两个表示相减、对差用无关性，两本书是同一步），以及为什么维数理论可以完全不提度量（`d:dimension-theory-uses-no-metric-notions`）。边界给的是同一个空间上换加权内积：坐标个数一个不变，而范数、角度、谁跟谁正交全变。增益是一条分诊动作：结论只依赖坐标个数的，固定基就够；涉及长度或正交的，必须先声明用哪个内积。

### C5 `L2:orthogonalization-as-a-dimension-counter` 正交化过程是一台维数计数器

Gram-Schmidt 通常被当成「造正交基的方法」，这里提炼的是它的第二重身份：读数装置。前缀张成不变，而输出在哪一步变成零就暴露输入在哪一步开始相关，非零输出的个数就是张成的维数——Apostol 的 V₄ 例子里 y₃ = O，直接读出 L(x₁,x₂,x₃) 是 2 维。它是结构而不是话题，因为让计数器能工作的是一条更底层的东西：内积的正定公理保证只有零元与自己正交，所以除数非零、零输出必定意味着相关；换一个退化的配对，这台计数器立刻失灵。

三条边界都是真会踩的：数的必须是**非零**输出（相关输入照样给 n 个输出，照个数读会把 V₄ 那例读成 3 而正确答案是 2）；正交不蕴含无关，所以不能反着用（零元与每个元素正交，`{O, x}` 是正交集却相关，这正是 15.10 必须写「非零」假设的原因）；无限维时计数器仍运转但读出的可能不是全空间的维数（Legendre 序列取前 n+1 个读出的是 n+1 维的多项式子空间，不是 C(−1,1)）。

**这是 8 个里唯一成员全在 Apostol 一侧的候选。** 不是遗漏：Strang 第 3–4 章没有 Gram-Schmidt（在他书里属第 4.4 节之后/更靠后的正交化内容，本实验的继承 L1 里没有对应节点），把 `strang:basis-by-elimination` 硬拉进来会变成另一个结构（那是 C8 的内容）。我选择让它保持单侧，而不是为了凑跨教材去编一个成员归属。

### C6 `L2:checking-against-a-set-compresses-to-checking-against-a-count` 对整个集合的检验压缩成有限条数的检验

结构是一次「条数替换」：从 |S| 条（可能无穷多条）换成 dim L(S) 条。Apostol 一侧是「与 S 正交等价于与 L(S) 正交」再落到基上；Strang 一侧同一压缩有两个矩阵形态——x 垂直于 A 的每一行等价于 x ∈ N(A)（真正被检验的是 r 条而不是 m 条），以及法方程把「与列空间正交」压成 n 个内积。两侧的表达没有共同符号，压缩比却是同一个数，所以这是结构不是术语统一。边界里区分了三层容易混的东西：压缩只压条数不改变 S^⊥ 这个对象，而「正交补」这个名字只对子空间成立；互相正交不等于凑成补（行空间与零空间之所以是补，是因为 r+(n−r)=n 加对了，不只因为正交）；L(S) 无限维时压不到有限条（整个三角正交系由正交＋非零得无关，其张成不是有限维）。

### C7 `L2:the-size-of-the-best-approximation-is-fixed-by-the-subspace-dimension` 最佳逼近的规模由 dim S 一个数定死

一个数同时定死三件事：展开式项数、要算的内积个数、矩阵形态下投影矩阵的秩。Apostol 的两个例子把它读得很直白（2n+1 个三角函数 → 2n+1 维 → 2n+1 项；n+1 个规范 Legendre → n+1 维 → n+1 项），Strang 一侧同一个数是秩（投影到直线是秩一矩阵，到平面是秩二）。是结构而不是「投影这个话题」，因为它还附带一条独立的事实：投影不依赖所选的那个正交基，只依赖子空间——所以「个数」这个量是子空间的属性，不是计算路径的属性。

边界一是我最喜欢的一条，因为它是 Apostol 原文里的现成反例：sin(πt) 在 [−1,1] 上的最佳一次逼近是 (3/π)t，而下一个系数为零，于是它**同时就是最佳二次逼近**——维数加一、项数加一、误差一点没降。这直接封住「项数定死 ⇒ 每项都有贡献」的过度解读。边界二说定死的是项数不是误差，Parseval 那种等式要的是全空间的正交规范基而不是子空间的。边界三是量词边界：整条陈述以 S 有限维为前提，15.15 与 15.16 都是这么写的。

### C8 `L2:counts-survive-the-procedures-that-destroy-the-objects` 计数量能活过摧毁对象本身的手续

消元、正交化、乘可逆矩阵这几道手续都把原来的元素换掉，各自保下一个数。可迁移的判断力不在任何单个手续里，而在「先认准这道手续守的是哪个量」这个动作上——这是为什么它是结构：它是关于「守恒量」这个概念本身怎么用的，不是关于某一个守恒量。

边界一直接引用了 Strang 自己标出的错误理由：「A 与 R 有相同列空间」是**假的**，消元守住的是行空间与零空间本身、以及列空间的维数与主元列的位置，不是列空间。边界二指出并非所有守恒都是原样保留（正交化保前缀张成，输出元素全换了，「输出个数」不是守恒量、「非零输出个数」才是——这一条与 C5 的读数规则是同一件事的两面）。边界三：秩在相乘下不守恒，只有单侧不等式，只有乘可逆矩阵才守。增益是使用任何化简手续之前的一次检查：写下这道手续保的是哪个量，再确认结论只用到那个量。

## 最不确定的候选

**C2 `L2:count-saturation-upgrades-a-necessary-condition-to-a-sufficient-one`。**

理由是它离 `x:right-count-upgrades-one-basis-property-to-both` 最近，有实打实的层塌缩风险（死因 5）。我第一版草稿几乎就是把那个 X 节点的 statement 换成中文重写，发现后改成了现在这版：把主张从「基的一个子句推出另一个」放宽到「某个量顶到已知上限时，两个待验条件塌成一个」，并且要求它至少覆盖三个假设互不相同的实例——15.7b（无关 → 基）、15.10 的推论（正交且非零 → 基，走的完全不是无关性这条路）、4.1 的正交对在维数加对时升级为正交补（被升级的对象不是基而是子空间对）。第三个实例是我判断它站得住的主要依据。

但我仍然不确定审计 B 会不会认为「上限饱和」这个说法太薄，等于把三个定理放进一个袋子而没有给出新的判断力。如果它被判死，我认为最合理的死因是层塌缩而不是数学错误或成员编造——它的成员和数学内容我核对过，问题只可能出在抽象增益是否真的超出了 X 层。若必须砍一个，砍它。

第二不确定的是 C8，风险类型不同：它的守恒量不是单一的数（秩、前缀张成、非零输出个数是三个不同的量），可能被认为视角不聚焦。我保留它是因为它的边界（Strang 亲自标出的列空间错误理由）提供了本轮最硬的一条反例，而这条反例不属于其他任何候选。

## 主动放弃的候选及理由

**放弃 1：维数为零与退化端点的约定簇。**（dim{O} = 0 而 |{O}| = 1、空集无关、L(∅) = {O}、零空间「由规定」算有限维）这些是同一个记账习惯的四个断面，成员现成、边界现成，但它们不是「某个数在若干现象背后起作用」——它们是为了让别处的计数公式在端点不崩掉而事先付的账。抽象增益只能写成「知道约定就不会在端点算错」，这是一条注意事项而不是一个可迁移的判断动作。放弃。它的材料我改成了其他候选的边界（C1 的无限维那半、C5 的零元那半）。

**放弃 2：Apostol 维数章节（15.08）整体。** 任务里明确禁止，但我记下放弃理由以示区分：15.08 里同时住着至少三个不同的结构（双向夹逼、饱和升级、坐标锁定），把它们打包成一个候选会让每一条边界都只能对其中一部分负责，`boundary` 必然写空。这正是「话题不是结构」的定义。它被拆进了 C1 / C2 / C4。

**放弃 3：dim S + dim S^⊥ = dim V 作为独立候选。** 数学上正确、也确实是我这个视角最漂亮的一条守恒式，但 **Apostol 第 15 章不陈述它**（15.14 只给唯一正交分解），文本只在 Strang 一侧。单独立候选会让 `members` 的 Apostol 侧全靠我的推断来撑，逼近死因 2/3 的边缘。改为并入 C3，并在 C3 的边界里把这条出处限制写成明文。

**放弃 4：rank(AB) ≤ min(rank A, rank B) 及秩在乘法下的行为。** 是真的计数结构，但只在 Strang 3.5 一侧有文本，Apostol 第 15 章没有任何对应物（他全章不出现矩阵乘法）。它无法满足跨教材要求，而单侧候选我已经有 C5 了；C5 的补偿是它在 Apostol 一侧极深（正定公理层面），这一条则只是一条不等式。放弃，只把「乘可逆矩阵才守秩」这半句留在 C8 的边界里。
