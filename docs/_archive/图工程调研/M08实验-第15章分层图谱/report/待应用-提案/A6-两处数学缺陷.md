## 一 缺陷 1：`d:exponential-independence-select-the-largest-exponent`

### 1.1 定位

- 目标文件：`data/nodes-D2.jsonl`
- 目标行号：**36**
- 完整 id（回显）：`d:exponential-independence-select-the-largest-exponent`
- 教材出处：`source/apostol-ch15/15.07.md`，Example 7，L39（前提）、L45（归纳）、L51（选最大）、L57（负性与极限）

### 1.2 现 statement 逐字

> The step picks a_M to be the largest of the n exponents. This uses the total ordering of the reals and the finiteness of the index set, so a maximum exists; the choice is what makes all the other exponents smaller by a strictly negative amount.

### 1.3 缺陷在哪一句、数学上错在什么地方

缺陷在**末句分号之后**：`the choice is what makes all the other exponents smaller by a strictly negative amount`。
两个独立的错：

**(a) 严格性误归因（主错）。** 「取最大」这一动作只能产出**非严格**不等式：由 a_M = max{a_1,…,a_n}
按定义只得 `a_k - a_M <= 0`，对一切 k 成立。严格负性 `a_k - a_M < 0`（k ≠ M）需要额外一个前提：
指数**互不相同**，即 Example 7 的假设（15.07.md L39 `are distinct real numbers`）。
把严格性记在「选最大」名下，等于宣称这一步自带一个它无权产出的结论。

后果不是纸面瑕疵。若允许并列最大（a_1 = a_2 = a_M），则 k = 1 项的平移指数为 0，
该项在 x → +∞ 时不衰减，极限只给出 `c_1 + c_2 = 0` 而非 `c_M = 0`——整条论证断在这里；
而且此时两个函数本身相等，按「一元素是另一元素的标量倍」判据集合**确实相依**，
所以失效的不只是证明，结论本身也假。即：距离性由 `<=` 升到 `<` 是这条证明的全部要害，
现 statement 把这个要害安在了不承载它的一步上。

**(b) 符号词误用（次错，同一句）。** `smaller by a strictly negative amount` 字面读是
「比 a_M 小了一个负量」，即 a_k = a_M + (负数的相反数) → 反而更大。正确表述是
「差 a_k - a_M 严格为负」或「小了一个严格正的量」。这句无论归因对不对，字面都自相矛盾。

**归因应落到哪一步：** 落到 `d:exponential-independence-hypothesis-distinct-exponents`
（`nodes-D2.jsonl:33`，Example 7 的互异前提），由 `d:exponential-independence-negativity-of-the-shifted-exponents`
（`:39`）消耗。**图里这两处本来就写对了**：`:39` 的 statement 明写
`This is where the distinctness hypothesis is consumed`，`:34`（证明架构）明写
`Only the elimination step uses the hypothesis that the exponents are distinct -- it is what makes a_k - a_M strictly negative for k not M`。
`:39 --requires--> :33` 这条依赖边也已存在（`edges-D2.jsonl:39`）。
所以 :36 不只是数学错，还与同族三个节点的表述**互相矛盾**——改 :36 即可自洽，无需动其他节点。

### 1.4 改写定稿

**主方案（推荐，2 条锚点）——逐字最终 statement：**

```
The step picks a_M to be the largest of the n exponents; a largest one exists because the index set is finite and the reals are totally ordered. Maximality by itself gives only a_k - a_M <= 0 for every k, so it is not the source of the strictness the proof needs: the strict negativity for k not equal to M comes from the distinctness hypothesis of Example 7, which forbids any other exponent from tying with a_M.
```

- 目标行号：**51**

  与内容相符，**不必改**。Parseval 一侧的 `d:parseval-norm-form`（`nodes-D3.jsonl:69`）已单独核过，
  它自始写的是 `||x||^2 = sum |(x, e_i)|^2`，**没有本缺陷**。

### 2.2 现 statement 逐字

> Applying the Pythagorean formula to the decomposition of x - t gives ||x - t||^2 = ||x - s||^2 + ||s - t||^2. This identity, not an inequality, is the substantive content of the approximation theorem: the error of any competitor exceeds the error at s by exactly ||s - t||^2.

### 2.3 缺陷在哪一句、数学上错在什么地方

缺陷在**末句冒号之后**：`the error of any competitor exceeds the error at s by exactly ||s - t||^2`。

**(a) 范数与范数平方混同（主错）。** 首句给出的恒等式两端全是**平方**范数，重排得

```
||x - t||^2 - ||x - s||^2 = ||s - t||^2      （真）
```

末句丢掉了平方，字面读作 `||x - t|| - ||x - s|| = ||s - t||^2`（"the error" 在本节点上下文里
只能指距离 `||x - t||`，因为首句刚用 `||x - t||^2` 与之对照）。这个式子一般为假。
**数值见证（已跑）：** 取 V_2 配普通点积，S = span{(1,0)}，x = (4,3)，则投影 s = (4,0)，
取竞争者 t = (0,0) ∈ S。此时 x - s = (0,3)、s - t = (4,0)，内积 0（确为正交分解），
||x - s|| = 3、||s - t|| = 4、||x - t|| = 5。恒等式核对：25 = 9 + 16 ✓。
而末句所断言的量：`||x - t|| - ||x - s||` = 5 − 3 = **2**，`||s - t||^2` = **16**。2 ≠ 16。
量纲上也接不上：左端是范数之差（一次），右端是平方范数（二次），
所以这不是一个「差一点」的偏差，而是两个不同次数的量被写成相等。

顺带一处**语义副作用**：`exceeds ... by exactly` 隐含「严格超出」，但 t = s 时超出量为 0，
恰是取等情形——这正是 `d:equality-holds-exactly-when-t-equals-s`（`:52`）承载的内容。
改写用「exceeds ... by exactly ||s - t||^2」搭配显式的平方口径后此歧义消解（超出量允许为 0）。

**(b) 过度断言（次错，同一句前半）。** `is the substantive content of the approximation theorem`：
按 Apostol，定理的**内容**是 15.15.md L3 + L9 的不等式加 iff 从句
（`Then the projection of x on S is nearer to x than any other element of S.` /
`for all $t$ in $S$ ; the equality sign holds if and only if $t = s$ .`），
恒等式是**证明的机制**而非定理的陈述。父节点 `:48` 已把这层关系写对
（`two steps that discharge the two halves of the claim from a single identity`）。
故改写把这句降级为对恒等式性质的描述（「是等式而非不等式」），不再宣称它就是定理的内容。

### 2.4 改写定稿

**主方案（推荐，3 条锚点）——逐字最终 statement：**

```
Applying the Pythagorean formula to the orthogonal decomposition of x - t gives ||x - t||^2 = ||x - s||^2 + ||s - t||^2. The relation is an exact identity between squared norms, not an inequality: for any t in S the squared distance from x to t exceeds the squared distance from x to s by exactly ||s - t||^2. What the identity evaluates is therefore ||x - t||^2 - ||x - s||^2, not ||x - t|| - ||x - s||.
```

（3 句，SPEC 上限；纯 ASCII，无双引号无反斜杠，可直接嵌入 JSONL。）

**备选方案（2 条锚点，锚点数组完全不动）——逐字最终 statement：**

```
Applying the Pythagorean formula to the orthogonal decomposition of x - t gives ||x - t||^2 = ||x - s||^2 + ||s - t||^2. The relation is an exact identity between squared norms, not an inequality: the excess of ||x - t||^2 over ||x - s||^2 is exactly ||s - t||^2, so what it evaluates is the difference of the squares and not the difference ||x - t|| - ||x - s|| of the norms themselves.
```

备选去掉了「for any t in S」这个全称量词，因此不需要新增 15.15.md L11 的锚点
