## 6. 其它维度问题登记（不裁定，只登记）

### R-1 #68 见证的普适性缺陷（**本片段最重的非 D/E 问题**，建议死因 4 或 1）

statement：`"a witness is p(t) = t^n and q(t) = -t^n + t, both of degree n, whose sum is t, of degree 1."`

- **n = 1**：`q(t) = -t + t = 0`，是零多项式，**无次数**，不在"次数恰为 1"的集合中；且和 `t` 恰为 1 次，根本不构成反例。
- **n = 0**：`q(t) = -1 + t` 是 1 次，不是 0 次。
- statement 对 n 无任何限制，Apostol 也只说 "n is fixed"（`15.03.md:25`），未排除 n = 0, 1。故 `"both of degree n"` 在 n ∈ {0, 1} 上**为假**。
- **同一缺陷在边级 `rel_note` 中原样复制**：`other → d:axiom-1-closure-under-addition` 的 `rel_note` 写 "t^n and -t^n + t both have degree n but their sum t does not"。两处而非一处。
- 结论本身不错：n = 0, 1 时 Axiom 1 仍失效（n=1 取 `t` 与 `-t+1`，和为常数 1；n=0 取 `1` 与 `-1`，和为零多项式）。错的只是见证的普适性。
- **建议改法**：改为 `p(t) = t^n`、`q(t) = -t^n + 1`（和为常数 1，对一切 n ≥ 1 有效），或直接注明 n ≥ 2。
