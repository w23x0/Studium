# 边证据索引(只读派生物,非缺陷清单)

来源:`data/*.jsonl` + `data/inherited/*.jsonl`。生成脚本为一次性 `tmp_*.py`,用后即删。

## 为什么有这个文件

D1 片 57–81 发现:节点的一个断言可能由**边上的 `evidence`** 支撑,而不在节点自己的 `anchors` 里。
该分片因此推翻了自己 3 个初判。其余分片的简报都只要求查 `anchors`,
所以它们自报的形式 E/D 计数**可能偏高**。此表把每个节点可达的全部证据摊平,
供汇总时逐条回查,不必重读全图。

**注意 `evidence` 的形状是 dict(`{"file","quote"}`),不是 list。**按 list 解析会全部读空。

### 更正(2026-08-03)

本节此前只有"自身 anchors 为空的节点 = 0"一行,并据此写过一句
"最坏情况不存在,过报风险只限于形式 D"。**那句话错了,已删。**

"anchors 为空"的节点其实有 **4** 个,全在 `nodes-D2.jsonl`(:42 / :54 / :72 / :73),
而且触及它们的 3–4 条边**也都没有 evidence**——所以它们不属于"靠边兜住"那一格,
属于更坏的一格:**任何形式的引文支撑都为零**。四个节点均 `origin: 'model'`,
即生产者如实标注了模型供给,不是伪造归属。详见 `进度报告.md` 第九节。

需要分清的是:**"过报风险只限于形式 D"这个结论仍然成立**,
它的依据是 931/1433 条带证据的边和 324/522 个证据池扩大的节点,与这 4 个节点无关。
被删掉的只是我给它加的那句"因为最坏情况不存在"的加强理由——**结论对,理由错**。
