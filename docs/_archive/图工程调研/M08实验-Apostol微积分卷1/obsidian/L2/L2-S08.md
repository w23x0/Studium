# Abel 求和结构:振荡有界性兑换单调衰减的收敛制造机

**类型**:结构模型 · **层级**:L2 · **来源**:模型综合(候选,已过双审计)

## 共同机制

Abel 分部求和公式 ∑a_k b_k = A_n b_{n+1} + ∑A_k(b_k − b_{k+1}) 把乘积级数的收敛问题分解为两种可分别验证的资源:因子 {a_n} 提供振荡抵消(只需部分和 A_n 有界,不需 ∑a_n 收敛),因子 {b_n} 提供单调衰减(∑(b_k − b_{k+1}) 是收敛裂项级数,定理 10.4 在证明内部充当引擎)。Dirichlet 判别法 = 有界 A_n × 单调趋 0 的 b_n;Abel 判别法 = 收敛 ∑a_n × 单调收敛 b_n;Leibniz 法则 = Dirichlet 取 a_n = (−1)^{n−1}(A_n ∈ {0,1} 有界)的特例,原文在 10.19 节亲自指认这一点;定理 10.19(复指数部分和估计 |∑e^{2ikθ}| ≤ 1/|sinθ|)则是为 Dirichlet 判别法生产『有界振荡因子』的标准供货源。

## 抽象增益

各判别法节点只陈述各自前提结论,leibniz-rule 节点甚至未提 Abel 公式。本结构额外说出:(1) 三个判别法是一个恒等式的三次消费,存在明确的『资源兑换』守恒式——A_n 的界越松,对 b_n 衰减方式的要求越严(Abel 判别法用 ∑a_n 收敛这一更强资源,换来 b_n 不必趋 0);(2) 这台机器恰好接管比较法族的失效区(条件收敛),两族判别法按『绝对收敛区/条件收敛区』互补分工——这个分工地图在任何单个节点中都不存在。

## 适用条件

变号或复项级数,尤其绝对值级数发散、比较法族整体失效的条件收敛区;凡能把通项分解为『振荡部分 × 衰减部分』的级数(三角级数 ∑sin(nθ)/n、交错级数、幂级数在收敛圆周上的行为)。

## 边界与反例

衰减因子的单调性不可去:存在 b_n → 0 但非单调、A_n 有界而 ∑a_n b_n 发散的反例(如把 b_n 在 a_n 同号的下标上放大),因为非单调时 ∑|b_k − b_{k+1}| 可发散,裂项引擎失灵。此外该结构只判收敛、原则上不给和的值(与几何级数、裂项级数不同);对正项级数它退化——正项时 A_n 有界已等价于 ∑a_n 收敛,结构不提供新信息。

## 教学用途

统一讲授 10.17 与 10.19 两节:先教 Abel 公式作为『离散分部积分』,再把 Leibniz、Dirichlet、Abel 三个判别法呈现为同一公式在三组资源配置下的输出,学生只需记一个恒等式;解题时训练『分解 a_n b_n』的眼光,直接迁移到 Fourier 级数逐点收敛的 Dirichlet 核论证。
