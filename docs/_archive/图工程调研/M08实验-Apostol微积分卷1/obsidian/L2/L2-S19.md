# 部分和-积分双向夹逼:同一矩形不等式的三种读法(判敛 / Riemann 和极限 / 渐近展开与常数相消)

**类型**:题型模式 · **层级**:L2 · **来源**:模型综合(候选,已过双审计)

## 共同机制

核心是单一不等式:f 单调(递减)时 Σ_{k=2}^n f(k) ≤ ∫_1^n f(x)dx ≤ Σ_{k=1}^{n-1} f(k)(递增时反向,10.14 第 19 题要求自行推出)。它有三种强度递增的读法:(i) 定性——两侧同有界/同无界,即积分判别法(定理 10.11);(ii) 极限——当两侧差趋于 0 时,和的极限等于积分,用于 Riemann 和求极限(10.4 第 34–35 题:Σ1/(n+k) → log 2 等六个极限);(iii) 定量渐近——保留差项得『和 = 积分 + 常数 + o(1)』型展开:Euler 常数公式 Σ_{k≤n}1/k = log n + C + o(1)(10.50)与 n! 的估计 e·n^n e^{-n} < n! < e·n^{n+1}e^{-n}(10.41,推出 (n!)^{1/n} ~ n/e)。读法 (iii) 的杀手应用是常数相消:对同一问题中多个成比例自变量的部分和(4m、2m、m)各写一次展开再相减,C 与 log 的公共部分相消,只剩纯对数差——由此算出重排交错调和级数的和 3/2·log 2(10.21 节)及一般 p 正 q 负重排的 log 2 + ½log(p/q)(10.22 第 18 题),以及 lim Σ_{k=qn}^{pn} 1/k = log(p/q)。

## 抽象增益

各成员节点分别只陈述一个孤立结果(积分判别法是定性的;Euler 常数是一个极限;重排例子是一次具体计算)。该结构额外陈述:(a) 这些结果是同一个矩形夹逼不等式在三个精度档位上的输出,档位间严格递强(iii ⇒ ii ⇒ i);(b) 常数相消机制的精确条件——C 的数值(0.5772…,是否有理未知)完全不参与,所需的仅是展开式的存在性与自变量的比例结构——这解释了为何 log 2 + ½log(p/q) 是 p、q 的显式函数而 C 不出现。这一跨节点的机制性陈述在 L1 中无任何单点或单边承载。

## 适用条件

通项/被积函数单调(或分段单调)的和;凡问题要求增长速率、误差量级或重排后的精确和,而不只是敛散二值结论时。

## 边界与反例

单调性是夹逼成立的全部前提:10.24 第 18(b) 题专门要求构造非单调反例——尖峰型 f 使 Σf(n) 收敛而 ∫_1^∞ f 发散,两侧界彻底失效。方法输出的是 o(1) 级渐近而非闭式和:对 Σ1/n² 它给出部分和 ~ 常数,但给不出 π²/6。常数相消技巧要求各部分和的自变量保持固定比例(块状重排的 4m:2m:m 结构);对无块结构的任意重排失效——Riemann 重排定理(定理 10.22)表明此时和可为任意预定值,不存在公式。

## 教学用途

把散落在 10.1、10.4、10.13、10.14、10.17、10.21、10.22 六处的技巧统一为一个不等式的三档使用,便于迁移;读法 (iii) 是学生首次接触『渐近展开中未知常数因相减而无关紧要』这一分析学核心手法,直通 Stirling 公式与 Euler–Maclaurin 求和。
