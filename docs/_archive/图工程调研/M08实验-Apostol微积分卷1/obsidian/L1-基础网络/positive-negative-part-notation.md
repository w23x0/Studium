# 级数项的正部与负部记号
*Positive and negative parts $a_n^+$, $a_n^-$*

## 定义/陈述

$a_n^+ = \frac{a_n + |a_n|}{2}$, $a_n^- = \frac{a_n - |a_n|}{2}$ (10.59). If $a_n$ is positive, then $a_n^+ = a_n$ and $a_n^- = 0$; if $a_n$ is negative, then $a_n^- = a_n$ and $a_n^+ = 0$.
