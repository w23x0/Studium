# 数列基本极限公式 (10.9)–(10.13)
*basic limit formulas for sequences (10.9)-(10.13)*

## 定义/陈述

$\lim_{n\to\infty} 1/n^{\alpha} = 0$ if $\alpha > 0$; $\lim_{n\to\infty} x^{n} = 0$ if $|x| < 1$; $\lim_{n\to\infty} (\log n)^{a}/n^{b} = 0$ for all $a > 0, b > 0$; $\lim_{n\to\infty} n^{1/n} = 1$; $\lim_{n\to\infty} (1 + a/n)^{n} = e^{a}$ for all real $a$.
