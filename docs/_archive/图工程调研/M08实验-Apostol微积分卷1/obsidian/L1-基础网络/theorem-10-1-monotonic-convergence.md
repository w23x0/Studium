# 定理 10.1(单调数列收敛判别准则)
*Theorem 10.1 (monotonic convergence criterion)*

## 定义/陈述

THEOREM 10.1. A monotonic sequence converges if and only if it is bounded. A bounded increasing sequence converges to the least upper bound of its set of function values; a bounded decreasing sequence converges to the greatest lower bound.

> 适用语境:Monotonic sequences of real numbers; proof uses Axiom 10 (least-upper-bound axiom) of the real-number system
