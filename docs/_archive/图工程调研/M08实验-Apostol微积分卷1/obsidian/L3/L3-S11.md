# 矩形夹逼精度阶梯的向上延伸:Euler–Maclaurin 展开、Stirling 公式与 ζ 的正规化(『和 − 积分 → 常数』现象的一般化)

**类型**:迁移方向 · **层级**:L3 · **来源**:模型综合(候选,已过双审计)

## 共同机制

L2-S19 识别出矩形不等式的三档读法(定性判敛 / 极限 / 渐近展开加常数相消),迁移方向断言这架阶梯向上无限延伸且有统一机器:每档的升级都是给『Σ_{k≤n} f(k) − ∫_1^n f』补一个更高阶修正项,极限形态是 Euler–Maclaurin 公式——Σf(k) = ∫f + (f(1)+f(n))/2 + Σ(B_{2j}/(2j)!)(f^{(2j-1)}(n)−f^{(2j-1)}(1)) + 余项,其中矩形档(第10章的全部内容)是零阶截断,单调性假设只买到零阶,每升一阶需 f 多一阶导数。第10章的两个孤立结果在此机器下是同一现象的两次采样:Euler 常数 C = lim(Σ1/k − log n)(10.50)是『和−积分收敛到常数』现象在 f=1/x 的实例;习题10.41 的 n! 估计 e·n^n e^{-n} < n! < e·n^{n+1} e^{-n} 是 Stirling 公式 n! ~ √(2πn)·n^n e^{-n} 的零阶前身,升阶后常数 √(2π) 被机器算出而非仅夹住。更远的出口:对 f = x^{-s} 作同一构造,极限常数作为 s 的函数给出 ζ(s) − 1/(s−1) 在 s > 0 的解析延拓,且 C = lim_{s→1}(ζ(s) − 1/(s−1))——第10章中互不相干的两个节点 euler-constant 与 riemann-zeta-function 在迁移层被一条恒等式焊接。L2-S19 的常数相消技术(重排求和时 C 不参与)在一般化后成为原理:凡只依赖展开式存在性与自变量比例结构的结论,对常数的数值免疫——这正是正规化方法(把发散和的『有限部分』定义为那个常数)合法性的雏形。

## 抽象增益

各成员未陈述的内容:(1) 阶梯的开放性——L2-S19 只断言三档且档间递强,本结构断言阶梯向上无限延伸、每档的价格(一阶光滑性)与产出(一阶精度)有明确汇率,且第10章恰好停在『单调性买得起』的零阶,这个停止位置的原因无任何成员说明;(2) 跨节点焊接:C 与 ζ(s) 在第10章分属求和系统与判敛标尺、互无边相连,迁移层给出显式恒等式 C = lim_{s→1}(ζ(s)−1/(s−1)) 把两者接通,并揭示『C 是否有理未知』与『ζ 的特殊值』同属一个问题家族;(3) 状态三分:第10章的世界只有收敛/发散两态,迁移后出现第三态——发散但渐近有效(最优截断)、发散但可正规化(有限部分),常数相消技术被识别为正规化合法性的胚芽,这一本体论扩张是零阶世界内不可陈述的。

## 适用条件

适用于任何『离散和 vs 连续积分』的定量比较问题:渐近计数(调和数、n!、素数定理的 Chebyshev 初等估计)、数值积分误差分析(梯形法则误差 = Euler–Maclaurin 一阶项)、解析数论中部分求和的标准起手式。升阶的前提是被加函数具有相应阶的光滑性。

## 边界与反例

目标域(Euler–Maclaurin、Stirling 精确形、ζ 解析延拓)全部超出本书第10章;Apostol 卷1 未定义 Bernoulli 数与复变量 ζ,本结构属模型知识外推。内在失效边界有二:(1) 光滑性台阶——第10章的单调性假设只支撑零阶档,f 仅单调不可微时(如取整函数叠加的阶梯扰动)高阶修正项无定义,阶梯在零阶戛然而止;(2) 阶梯的极限本身通常发散——Euler–Maclaurin 级数对固定 n 取 j→∞ 一般不收敛(Stirling 级数是标准反例:各阶截断误差先减后增),故『渐近展开』不可当作收敛级数使用,这一『最优截断』现象在第10章的收敛/发散二分法中完全没有位置,是迁移后才出现的第三种状态。

## 教学用途

支撑三类后续学习:数值分析中梯形/Simpson 误差公式可作为『第10章矩形估计的高阶亲戚』引入;渐近分析入门时用 C 和 10.41 作为学生已会的零阶实例,再展示机器如何吐出 √(2π);解析数论起步时把 Abel/Euler 部分求和作为标准工具时,学生可将其认作 L2-S19 阶梯的正式化。解题上,常数相消技术(多尺度展开相减)可直接教为独立技巧,用于一切 lim Σ_{k=an}^{bn} f(k) 型极限。
