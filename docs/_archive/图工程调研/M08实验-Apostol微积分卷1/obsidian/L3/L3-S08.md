# sup-范数提升:正项判别系统整体迁移为一致收敛判定(Weierstrass M-判别法与 Cauchy–Hadamard 半径公式)

**类型**:迁移方向 · **层级**:L3 · **来源**:模型综合(候选,已过双审计)

## 共同机制

存在一个统一的提升算子:把函数项级数 Σf_n(x) 的每一项换成数 M_n = sup_{x∈S}|f_n(x)|,则 L2-S01 的整个正项判定决策链(引擎 10.7 + 两把标尺 + 比较耦合)逐字变成一致收敛判别系统:比较判别法提升后恰是 Weierstrass M-判别法(Σf_n 被数值级数 ΣM_n 优超 ⟹ 绝对且一致收敛),提升所需的唯一新原料是 sup-范数下的完备性(Cauchy 一致准则),对应 L2-S10 已识别的『存在性唯一出口』在函数空间的版本。对幂级数 Σc_n x^n,这一提升与 L2-S06 的几何标尺结合直接产出 Cauchy–Hadamard 公式:R = 1/limsup|c_n|^{1/n},收敛圆盘 |x| ≤ r < R 正是几何基准 (r/R')^n 一致优超的区域;L2-S01 陈述的判别力偏序(比值 ⊂ 根值)在迁移后成为『半径公式必须用根值的 limsup 而非比值』的原因——比值极限可以不存在而半径始终存在。同时,L2-S04 在第10章『赊账使用』的四个组合子中最强的一个(逐项微分/积分,生成 Mercator 与 Gregory 级数时未加证明)在目标域获得清偿:一致收敛正是允许极限与积分/微分交换的许可证。

## 抽象增益

各成员均未陈述的内容:(1) 迁移是成批的而非逐条的——存在单一提升算子 a_n ↦ sup|f_n|,使 L2-S01 整个决策链一次性变成一致收敛判定系统,M-判别法不是孤立新定理而是比较判别法的像;(2) 提升的精确损耗有刻画:像只覆盖『绝对一致』类,条件收敛函数级数是系统性盲区而非偶然遗漏(Σsin(nx)/n 为见证);(3) L2-S01 内部的判别力偏序在迁移后获得新的解释力——它预言半径公式的正确形态(limsup 根值)并解释比值版半径公式为何只是便宜的特例;(4) L2-S04 的逐项微积分组合子与本迁移的关系是『先赊账后清偿』,这个跨章的债务结构在两章文本中都无一处成文。

## 适用条件

适用于能取到有限上确界控制 M_n 且 ΣM_n 收敛的函数项级数;对幂级数在任何严格内闭圆盘上自动满足。凡第10章正项系统可判定 ΣM_n 的场合,提升后的系统即可判定一致收敛。

## 边界与反例

目标域(函数级数、一致收敛、幂级数理论,对应 Apostol 卷1第11章及以后)完全超出本书第10章,本结构属模型知识外推。内在失效边界:sup-提升只能产出『绝对且一致』的收敛,凡靠符号相消的条件收敛函数级数必然漏网——具体反例:Σ sin(nx)/n 在 (0,π) 上点态收敛(由 Dirichlet 判别法),但 M_n = sup|sin(nx)/n| = 1/n 给出发散的调和级数,M-判别法无结论;事实上该级数在含 0 的区间上确实不一致收敛,处理它需要另一条迁移通道(见 Abel 引擎迁移结构)。此外一致收敛只是交换极限的充分条件而非必要条件,提升系统对『不一致但极限仍可交换』的情形(Arzelà 型定理)无话可说。

## 教学用途

学幂级数时,学生不必把 M-判别法和半径公式当新知识:M-判别法 = 比较判别法 + 一次 sup 提升,Cauchy–Hadamard = 根值判别法对 |c_n x^n| 的直接应用。教师可布置『把第10章每条正项判别法手动提升一遍,标出哪条提升失败、为何失败』作为衔接练习;并用『第10章第10.9节逐项操作是赊账、第11章还账』组织两章的叙事线。
