# 单调累积泛函的双模型理论:级数与瑕积分是同一公理化收敛理论的两个模型,可移植性由『证明是否使用增量的原子性』先验判定

**类型**:跨对象统一 · **层级**:L3 · **来源**:模型综合(候选,已过双审计)

## 共同机制

抽象出一个公共结构:『累积过程』= 定向指标集 I 上由非负增量生成的单调不减函数 S:I→ℝ(级数取 I=ℕ、S=部分和 s_n;瑕积分取 I=[a,∞)、S=部分积分 I(b)),收敛 ⟺ S 有上界,其唯一存在性来源是最小上界公理经定理10.1 的封装(L2-S10 已证明该出口在两侧均唯一)。关键观察:L2-S03 字典中可移植的三条定理(有界性准则 10.7↦10.23、比较 10.8↦10.24、极限比较 10.9↦10.25)的证明只使用了『序 + 单调累积 + 上界』这三种抽象资源,从不使用 ℕ 的后继结构;而唯一不可移植的第n项判别法(10.6)的证明恰恰依赖原子差分 a_n = s_n − s_{n−1}——即从累积函数中恢复单个增量,这个操作在连续模型中不存在(I(b) 的『增量』是无穷小,恢复它需要微分与正则性)。因此 Apostol 所说的『证明相似』(similar to the corresponding results for series)可升级为『同一个证明在两个模型中各读一遍』:字典不是两段平行文本的巧合,而是一个模型无关定理集的双重实例化。积分判别法(10.11)在此框架下是两个模型间的忠实桥:单调递减插值使同一数据(f 与其整点采样)在两个模型中的累积函数互相夹逼(L2-S19 的矩形不等式),从而基准库(ζ 标尺 ⟷ ∫x^{-s})整体双向流通。

## 抽象增益

L2-S03 记录了字典的词条表与失效机理(离散强制采样 vs 连续容忍尖峰),L2-S10 证明了存在性出口唯一;两者都没有说出本结构的核心断言:存在一个先验的、语法层面的可移植性判据——一条定理可过字典 ⟺ 其证明不使用增量的原子恢复操作(a_n = s_n − s_{n−1})。这个判据把 S03 的『事后清单』(哪些移植了、哪些没有)升级为『事前预言』(给出任一新定理,读其证明即可判定是否可移植),并且解释了 S03 的两个限制(第n项判别法失效、桥需单调性)为何是同一件事:两者都在试图从累积函数恢复点态增量信息,这正是抽象结构中不存在的资源。此外它把适用范围延伸到 S03 未提及的第三、第四个模型(第二类瑕积分、双重级数)——『一部理论、多个模型、桥是模型等价』这一陈述在任何 L2 结构或 L1 节点中都不存在。

## 适用条件

任何『非负增量在定向指标上累积』的收敛问题:正项级数、非负被积函数的无穷积分、第二类瑕积分(改变指标方向后同构)、以及本章之外的双重级数/含参积分——凡证明只调用序与单调累积资源的定理,均自动在所有模型中成立,无需逐一重证。

## 边界与反例

(1) 增量变号即失效:累积函数不再单调,唯一出口(定理10.1)不可用,两个模型真正分道——条件收敛级数与振荡型瑕积分各需专门工具(见 L2-S02/S13)。(2) 桥(10.11)必须假设 f 单调递减,否则两模型在同一数据上可给出相反判决:取 f≥0 在每个整数 n 附近为高 1、宽 2^{-n} 的尖峰、其余处为 0,则 ∫₁^∞f 收敛(面积 ≤ Σ2^{-n})而 f(n)=1 不趋于 0,采样级数 Σf(n) 发散;反向地令尖峰错开整点则 Σf(n)=0 收敛而可使积分发散。(3) 该理论只回答敛散,不产出和/积分值——精确求值属于另一套系统(L2-S04、U『离散-连续微积分对偶』)。

## 教学用途

教学生在学习任何新的『无穷累积』对象(二重级数、含参瑕积分、测度论中的单调收敛)时,先问两个问题:增量是否非负?证明是否只用序与有界性?若是,则正项级数的整套判定系统(比较、极限比较、基准标尺)可零成本迁移,无需重学;同时训练学生用『证明用了哪些结构资源』来预判定理的推广范围——这是从做题到做数学的关键一步。做题层面:遇到瑕积分敛散题直接调用级数直觉(标尺、比较),遇到非单调被积函数则知道必须先处理尖峰反例风险。
