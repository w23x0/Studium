# 总控宪法（深度调研树 · 所有会话共享 · 先读本文）

> 本文件是方向控制中枢。任何会话启动后第一件事：完整读本文 + 树状注册表。
> 修改本文 = 修改全局调研方向，只在汇总仲裁后由你确认更新。

## 0. 调研主题（每次开树前填写）
- 主题：{主题，例如：M08/M09 个人学习知识图谱的「存储方式与存储语言」全新选型}
- 动机：现有方案（JSONL+脚本）视为**待挑战的现状**，不是结论；本次目标是找到**可取代的新存储方式/存储语言**（底层格式、表达语言、语义模型、版本化、查询、校验、互操作），不做厂商/引擎浅层对比。
- 决策点（汇总层要回答的问题）：{列出 5-9 个决策问题，根会话可以细化}

## 1. 范围纪律
1. 每个会话只答**父会话明确指定**的问题；禁止越界裁决。
2. 中间层（根/分支）只做「方向划分 + 生成子提示词」；只有叶子层做深度调研。
3. 禁止提前下「维持现状」类结论；替代方案未穷尽前不轻判。

## 2. 证据规程（引文是命脉）
- 关键论断必须可核：**URL + 标题 + 作者/机构 + 日期 + 原文摘录/要点**。
- 证据等级：**A=原文到手**（抓取并核对原文）/ **B=二手转引**（显式标注）/ **C=推断**（基于证据的工程判断，显式标注）。
- 叶子层把抓到的原文快照存到本节点 `_sources\` 目录（html/txt/md/pdf 均可），供审计逐字比对。
- 搜不全、抓不到 = 如实写「未核/未取到」，**绝不捏造来源、绝不把不存在页面当已抓取**。

## 3. 判死条件（产出不合格，汇总/审计可判死）
1. 任何关键论断没有来源；
2. 把二手转引当成原文结论（未标证据等级）；
3. 越界回答了范围外问题、或漏答了范围内问题；
4. 推断未标注、被写成结论。

## 4. 发现.md 统一结构（叶子层必须遵守）
```
# 叶子 <主题> 调研发现
> 日期 / 执行会话 / 关键前提
## 0. 一句话结论
## 1. 父会话问题逐条回答
## 2. 关键发现（每条：论断 + 来源 + 原文摘录 + 证据等级）
## 3. 对决策点的输入
## 4. 与范围/红线的冲突张力（无则明说无）
## 5. 未决与风险
## 6. 建议的下一步
## 7. 来源清单（全部 URL，标注 A/B/C）
## 8. 判死自查结果
```

## 5. 树规则
- 父会话产出「子提示词」，子会话只执行自己那份提示词；互不覆盖、互不等待。
- 每层落盘后登记到 `树状注册表.md`；汇总/审计以注册表为准收口。
