- 子主题：{子主题名}

## 第一步（开工前必读）
1. 完整读 `{CONTEXT.md 路径}`（总控宪法：证据规程 A/B/C、判死条件、发现.md 结构）。
2. 只回答父会话给你的问题。

## 第二步：全网穷尽调研（关键词：穷尽）
分四路交叉搜索，中英文都搜，多组关键词换着搜，不要只看第一页结果：
1. **学术**：arXiv、ACL Anthology、Springer、IEEE Xplore、ISWC/ESWC（语义网）、SIGMOD/VLDB/ICDE/PODS（数据库）、相关综述（survey/position paper）。
2. **标准与规范**：W3C、ISO、IETF、OASIS；相关规范原文（含工作草案/版本历史）。
3. **工程实践**：GitHub（按格式/语言名搜仓库与 star 量级）、官方文档、权威博客、知名系统架构说明。
4. **先例领域**：数学知识库、教育系统、知识图谱、间隔重复、健康档案、审计日志等与本主题相关的领域实现。
> 对本子主题下**所有可命名的候选**逐一查证：存在与否、成熟度、活跃度、规模证据、真实采用案例。

## 第三步：产出
1. `发现.md`：严格按 CONTEXT 第六节结构（0 一句话结论 … 7 来源清单 8 判死自查）。
2. 每条关键论断带来源 + 原文摘录 + 证据等级；抓取原文快照存到 `{输出目录\_sources\}`（html/txt/md/pdf）。
3. 覆盖不到的如实写「未核」，绝不捏造。

## 第四步：判死自查
对照 CONTEXT 四条判死条件逐条自查，结果写进发现.md 第 8 节，并登记树状注册表。

## 禁止
- 不答范围外问题、不替决策；
- 不引用旧调研结论作为前提（可提「现状」但必须标注为待挑战对象）；
- 不捏造来源；二手转引必须标 B。

## 交付
最终回复用中文：一句话结论、发现数、来源数、未核项清单、判死自查结果。
