# Q-质量检验规范（v2 · 中心 A 验收时执行，或独立审计子代理执行）

对每份 SUBMITTED 产物执行三道检验：

## 一、判死四条件（任一触发 = REJECTED）
1. 关键论断无来源
2. 二手转引当原文（未标 B）
3. 越界回答了范围外问题 / 漏答范围内问题
4. 推断未标注、被写成结论

## 二、来源可核性（抽检）
- URL 存在性抽检 ≥20%：打不开/404 → 该论断降级为"未核"
- 快照与摘录逐字比对 ≥10%：`_sources\` 中的原文必须包含发现.md 引用的句子
- 无快照目录的叶子 → 整体验收降级，优先回炉补快照

## 三、工作量红线核对（不达 = 回炉）
- 来源数 ≥15（A 级 ≥10）✓/✗
- 来源类型 ≥3 ✓/✗
- 候选查证数 ≥5 ✓/✗
- 关键词组数 ≥4（中英各半）✓/✗

## 输出
验收结论表：PASS（ACCEPTED）/ FAIL（REJECTED + 整改意见 + 重新 QUEUED）。
回炉 ≥2 次 → 中心 A 降级处理（缩范围或亲自兜底），禁止无限回炉。
