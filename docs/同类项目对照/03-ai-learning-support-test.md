## 2. 技术

| 项 | 事实 | 出处 |
| --- | --- | --- |
| 首要判别 | **通用 harness + 学习工具**：Vercel AI SDK 的 `streamText` + 4 个工具，最多 5 步；无状态机、无路由，流程全由模型决定 | `app/api/chat/route.ts:153-159`；`docs/adr/0004-*` |
| 系统提示词 | 只约束：用工具检索、依据资料、按 [资料, 页] 引用、资料里没有就明说、不编造；教学风格一句“简洁、主动学习”。**没有**不代做题 / 苏格拉底约束 | `lib/ai/prompts.ts:1-22` |
| 工具 | 资料检索（向量，总量 ≤8000 字符，原文全返回模型）、概念邻居、前置链、取练习题 | `lib/ai/tools.ts`、`lib/ai/tools/graph.ts`、`lib/materials/retrieval.ts:4,68` |
| 资料处理 | 上传 → 视觉模型转 Markdown → 切块 → gemini embedding → pgvector；概念图抽取手动触发 | `lib/materials/vision.ts:39`、`chunker.ts`、`concept-extraction.ts:412,445` |
| 前置关系 | LLM（默认 gemini-3.7-flash）一次抽取概念、依赖边、练习题；只做结构校验（去自环 / 悬空、查询防环） | `concept-extraction.ts:605,732`；`prompts.ts:54-84`；#117 |
| 前置链工具 | 递归查祖先（默认深 10）；**何时调由模型自选**，提示词只说“评估先修知识时可调”，没有“卡住”检测；给模型的结果只是计数 `[OK: 3 prerequisite ancestors]`（无概念名）；学习者界面不显示（只发状态事件，前端无消费者） | `graph.ts:42-45,196-260`；`prompts.ts:8`；`components/chat/data-stream-handler.tsx:33-38` |
| 学习者状态 | **无**。表只有对话、资料 / 切块、知识点、依赖、练习题；“学习者知识状态”只在术语表 | `lib/db/schema/*`；`CONTEXT.md:134-136` |
| “学会了”怎么判 | **无**。有“可学前沿”算法接收已掌握集合，但生产代码无调用方，只有测试 | `lib/learning/knowledge-graph.ts:84`；`lib/db/queries/knowledge.ts:513` |
| 上下文 / 记忆 | 每轮 = 系统提示词 + 本会话全部历史；检索由模型调工具；无跨会话记忆；名为 GraphRAG，检索不用图 | `route.ts:98-100,139` |
| 模型 | 默认 gemini-3.5-flash-lite，可选 3.7-flash、Ollama、OpenRouter / OpenAI；用户自带密钥 | `lib/ai/providers.ts:30-58` |
