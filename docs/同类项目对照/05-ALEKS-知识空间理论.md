## 2. 技术

### 2.1 理论对象

| 对象 | 人话 | 原文 / 出处 |
| --- | --- | --- |
| 知识状态 | 一个学习者已会的题项（item）集合；只是集合，不记怎么学会、理解多深 | `综述` Def.1 |
| 知识空间 | 状态族对并封闭（两人会的合起来也是一个合法状态） | `综述` Def.5 |
| 学习空间 | 两条公理：[L1] 从小状态能一次学一个点走到大状态；[L2] “Knowing more does not prevent learning something new.” 等价于 well-graded 知识空间（= antimatroid） | `综述` Def.3、Thm 7 |
| 准序空间 | 对交也封闭；与 item 上的一个前置偏序一一对应（每个点只有一组前置）。综述评价：“the closure under intersection does not make good pedagogical sense.” | `综述` Def.9、Thm 10、p.10 |
| 内沿 / 外沿 | 内沿：去掉后仍是合法状态的已会点（最近学会的“顶”）；外沿：加上后仍是合法状态的未会点 = “exactly what the student is ready to learn”。学习空间里一个状态由内外沿唯一确定 | `综述` Def.20、Thm 21 |
| 多组前置（surmise function） | 给每个点一族子句（clause），每个子句是一组可选前置：“to master item b, one must first master either item d, or items a and c, or items c and e.” 状态合法 ⇔ 其中每个点至少有一个子句被包含。与知识空间一一对应（Doignon–Falmagne 1985，Thm 18），是 Birkhoff 定理的推广；只有一组前置是特例（agent 由 Thm 10/18 推出，原文未单句写明） | `综述` Def.17、式 9、Example 16、Thm 18 |
| 学习空间里的子句 | 有限知识空间是学习空间 ⇔ “any clause is a clause for only one item” | `综述` Thm 19 |
| 技能层（CbKST） | 题项背后再挂技能；一道题可由几组不同技能解出：“alternative sets of prerequisites for solving the item, especially for different possible solution paths” | `CbKST包`；`JUCS2003` p.1430–1431 |

### 2.2 ALEKS 产品

| 项 | 内容 | 出处 |
| --- | --- | --- |
| 流程谁控制 | 程序：评估 → 外沿作为学习入口 → 学 → 进度评估，循环；“学习与评估循环 not intrinsically a KST concept”，学习环节靠“evolving heuristics” | `Cosyn2020` p.4、§4 |
| 状态评估 | 状态上放概率分布，每题有粗心 / 猜中参数；选答对概率最接近 .5 的题，乘法更新；初评上限 30 题（含 1 道不计分），item 似然 >80% 算会、<20% 算不会 | `综述` §9–10；`Cosyn2020` §1.3（约 2020 版，现行未核） |
| 学会了怎么判 | 只看做题：答对 +1、连对再 +2、答错 −1，看讲解打断连对；目标分多为 5（“provisionally learned”）；连错 5 次算失败；进度评估把遗忘的点移出状态，重学目标分 3 | `Cosyn2020` p.8 |
| 外沿准不准 | 外沿内的点实际学会概率中位数 .93（1,940,473 次学习） | `综述` §12.3 |
| 结构怎么建 | QUERY：问专家“答错 A 中全部题的学生，几乎肯定也答错 q 吗”；先得偏序（含大量假状态），再用评估数据删掉 99% 假状态；更高阶段“still at the project stage” | `综述` §11 |
| 规模 | 一门课 300–600 个 item；College Placement 314 个 item ≈ 10^23 个状态；状态太多时分块投影并行评估 | `综述` §1；`Cosyn2020` p.3 |
| 与 Math Academy | Skycak 自述重实现过 ALEKS 诊断：二叉分叉每翻倍状态数平方，约 100 个节点后算不动；Math Academy 要覆盖上千节点并加间隔复习，改为“量沿图流动、构造出状态”，不从全部可能状态里筛 | 《The Math Academy Way》p.503–504 |
| 自认局限 | 数据质疑 BLIM（答题只由粗心 / 猜中两参数决定）：答对率随该点在状态里的“层”变化；遗忘随层变化（第 1 层约 .6、≥5 层约 .8） | `Cosyn2020` §3–4 |

### 2.3 粒度与结构形态

补充材料：`Cosyn2013` = Cosyn 等《Knowledge Spaces: Applications in Education》第 2 章（Springer 2013）；`课程表` = ALEKS 官方课程 topic 列表 PDF（aleks.com/about_aleks/course_products，2026 版）；`KLI` = Koedinger, Corbett, Perfetti 知识-学习-教学框架（Cognitive Science 36(5)，读的是接收前草稿）；`LFA` = Cen, Koedinger, Junker 2005；DataShop 帮助页 learningCurve。已抽查：item 例子、`Cosyn2013` 三类信号原句、KLI “10 秒”。

| 项 | 内容 | 出处 |
| --- | --- | --- |
| item 多大 | 一类题型，不是概念：“a collection of examples, called instances, each focused on the same, narrow topic, and designed to be equal in difficulty”。同一操作按变体拆成几个 item，如 Multiplying binomials with leading coefficients of 1 / greater than 1 / in two variables | `Cosyn2020` §1.1；`课程表` Beginning Algebra |
| 一门课多少 | 核心 + 附加：Beginning Algebra 375 + 443，College Algebra 538 + 424，Calculus 180 + 330，Gen Chem I 233 + 600 | `课程表` |
| 学一个 item 多久 | 无一手数据；按总时长 ÷ 学会数粗估约 7–13 分钟（含测评，偏高） | `Cosyn2020` Table 1（子代理推算） |
| 怎么切 | 只见“领域与课程重合”、参考多本教材；无“切多大”的显式原则 | `Cosyn2013` §2.4.2 脚注 13；`综述` §12 |
| 切错怎么发现 | 三类信号：粗心率高 → “The instances of an item are not homogeneous”，改题；相关低 / 学会率低 → “a misplacement of an item in the structure”，删掉重放；学会率 <0.8 的约 6% → 可能“the domain lacks ‘granularity’”，加 step item（只是假设，未验证）。未见实际拆 / 合 item 的案例 | `Cosyn2013` pp.46–48；`Cosyn2020` §3.1 |
| 换粒度工具 | 投影：把结构限制到 item 子集上，仍是学习空间；用途是分块并行评估、教师选课程范围。只取子集，不把几个点合成粗点。atom / granular 是形式性质，与“粒度”无关 | `综述` Def 31、Thm 33；`Cosyn2020` p.5 |
| 更细一层 | CbKST：item 背后挂技能，技能组合 = 可选前置；JUCS2003 分“教的 / 要求的 / 测的”能力 | `CbKST包`；`JUCS2003` |
| 结构形态数据 | 不公开 Hasse 图、深度、宽度；College Placement 314 item ≈ 10^23 状态；Beginning Algebra 10 item 子结构 34 个状态、37 item 子结构 4,615 个；“层”按相对某状态定义，外层 / 内层各约十几层（读图估计） | `Cosyn2020` §1、§2、Fig 3；`综述` §8 |
| 多组前置实际多不多 | 无占比数据；构建是先偏序、再用数据删假状态，倾向“偏序骨架 + 少量多子句”（推断） | `综述` §11 |
| 关系种类 | 只有一种：蕴含（会 q 才能会 r）；等价的 item 直接合并，不当边；作者未论述取舍，CbKST 说明称 KST “is a behavioral model … does not look into the skills” | `综述` Def 1、§11；`CbKST包` |
| 点 / 边上存什么 | 点：粗心 / 猜中率、难度、学会率、按层的遗忘曲线、按位置的答对率曲线；边上不存任何东西 | `Cosyn2020` §2–3 |
| 外部光谱 | 由细到粗：KLI 知识成分（KC，步骤级，单个任务约 10 秒）→ ALEKS item（题型）≈ Math Academy 知识点（一例题 + 2–5 题，3–4 个组成一节课）→ Math Academy topic（一节课）。LFA / DataShop 用学习曲线发现切得不对：曲线不降 → “Explore whether the KC can be split”，数据太少 → 合并；拆分后的改进经课堂验证（Liu & Koedinger 2017 JEDM，只读摘要） | `KLI`；书 p.217、p.449；`LFA`；DataShop 帮助页 |

| 条 | 产品负责人 | agent 分析 | 归类 |

| 1.1 外沿与出发点 | 理解了子句；算法重构（评估、状态筛选）大概率用不到；它至今不用 AI 主要是转向成本太高，而且对理解的处理也不太对；要看的是粒度和知识结构到底什么样 | 外沿 = 现在能学的未会点，对应我们的新点候选，不是出发点；对应出发点的是子句（clause，一个点的一组可选前置），一个点可有几组，只有一组前置（Math Academy）是特例（`综述` Thm 18）。差别：子句只决定“能不能学”，状态是集合、不记从哪组学会，表达不了“出发点不同、理解不同”（agent 由定义推出）。“不用 AI 是转向成本”：官方没说原因，只有 2026 预印本研究了 AI 对学习的影响，未核实 | 同（多组出发点的形式写法）；方向不同（理解） |
| 2.1 粒度（讨论中） | 原子断言离现在太远，先看对不对得上；我们可能确实太粗；题型粒度不适合作 M08 的单位；我们没有题目绑定。续：粒度由 M08 的消费者定义；闭环没有外部依据和实验，现在难定。失去题目带来的细粒度，就转向学习路径：对闭环的把控 = 对子句的选取，控制学习方向在时间上的走向，这种细微差距实现“准确学习”——不考虑应试，目标是理解和应用（学习理论的高层级）；消费模块需要区分学习的细微差距，相当于他们“解一道题的细微差距”这一层；反馈出现在学习者实际学习过程中，比做题慢、准确度低，但价值高，能表示复杂繁多的学习路径 | 同意题型不能直接搬：它的单位由“同一类题能判”定义，我们没有题、判的是理解。“太粗”拿不准：切法该从闭环定义推——一个点 = 一组出发点、一次坐下来能理解到目标层次的东西；太粗的信号是同一个点的不同部分要不同出发点（其实是几个闭环），或守卫说不清学会的是哪部分；太细的信号是不需要出发点组合、一句话就讲完。ALEKS 的“靠数据事后发现切错”可借：闭环拖长、某部分反复卡住 = 该拆。可在 #22 实验里加一列量一下。续（agent 对“转向路径”的分析，待回应）：成立——分辨率从“点切多细”挪到“选哪组出发点、按什么顺序”，与闭环定义一致，也正好落在 KST 不记的地方（状态不记从哪个子句学会）；他们的细在“一个概念拆成多个题型”，我们的细在“一个点有多组子句”。由此推出 M08 要显式存“点的几组出发点、各组导向哪种理解”，现在只存单条连线；M09 记用了哪组。要分开两件事：表示多条路径容易，评价哪条路径好难——单个学习者没有对照，理解薄是出发点选错还是别的原因分不开，跨学习者比较要规模（同 `04` §6）。题目没有完全失去：闭环里有应用训练，题是现场出的、不绑在 M08 上，能给比守卫更快的信号；瓶颈在守卫判断的准确度，未实验 | 待定 |
| 2.1b 路径好坏与反馈 | 书本路径就是最好的路径（人类知识沉淀的捷径）；不同路径不会完全不同，只是不同知识面下每人有差异，差异随阶段变大，分界在 K12 与以上；题目有书本例题保底（没有出题系统，要专门设计才好，否则像别的产品的卡片 / 简单问答）；检验性与准确性相反（讨论过底层原因）：题目好检验、信息量少、不能准确指出问题所在；模型检验难、信息量最大 | 书本路径作基准，解掉了“哪条路径好”的评价难题：个人路径 = 书本路径附近的局部偏离（按知识面换某个点的子句），只需判断偏离是否由知识面支撑。补一点：多本书 = 同一 M08 上多条路线（产品总览），“最好”是对各书设定的读者而言，书本路径是一组高质量候选。K12 分界大体同意（K12 课程统一、知识面相近；ALEKS / Math Academy 都在 K12 到大学初段、用固定路径，与此相符），但变量是学习者的知识面而非内容所处阶段：成人自学 K12 内容时差异也大（推断，无数据）。产品负责人澄清：说的是知识密度——K12 知识少、考深度，很少卡住要补别处；K12 以上知识面广、不集中，学一本书会在很多地方卡住、要补别的知识。agent：据此 K12 以上的出发点常在本书之外，跨书合并（#15 无设计）会直接影响能选的子句。检验性与准确性：心理测量里叫“带宽–保真度两难”（bandwidth–fidelity dilemma：测得广则信息多而不精，测得窄则精而信息少；Cronbach & Gleser 1957，agent 记忆，未核原文；产品负责人要求记下） | 同（书本路径作基准）；待核（K12 分界） |
