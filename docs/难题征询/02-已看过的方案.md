# 已看过的方案

> 免得重复提。“采纳”= 已用进已定方案；“只借”= 只取思路；“不采用”附原因。

## 1. 理论与技术

| 来源 | 要点 | 判定 |
| --- | --- | --- |
| 知识空间理论 / ALEKS | 一个点可有几组可选前置（子句）；外沿 = 现在能学的点 | 采纳“子句”“边缘”；它不记从哪组学会、等价点直接合并、只有一种关系——这几处不合我们 |
| Math Academy | 约 2500 topic，粒度靠多年手工拆；按例题通过率改讲解 | 只借“路线问题与内容问题分开处理” |
| 认知负荷理论（Sweller 1994） | 什么算一个元素取决于学习者已有图式，不能离开学习者给出 | 采纳：点无绝对大小 |
| KLI 知识成分（Koedinger 等 2012） | 只拆到刚好高于学习者已熟练的一层 | 采纳：出发点已熟练 = 下限 |
| APOS 发生分解 | 一个概念的构造路径不唯一，取决于个体已有结构 | 采纳：一个点可有几组子句 |
| Learning Factors Analysis | 两类任务难度差 = 多一块前置，该拆 | 只借逻辑；统计要大量练习日志，不可用 |
| SKOS / SSSOM 映射记录 | 链接单独成记录（谓词、理由、置信度、工具版本、审核者、可记“否”）；closeMatch 不传递以防复合错误 | 采纳记录形态 |
| 大模型本体对齐（LogMapLLM、Agent-OM、LLMs4OM，2024–2026） | 便宜检索出候选，大模型只判少量不确定的 | 采纳“候选检索 + 隔离调用判”；作者自承模型远非完美裁判，且只在生物医学本体上验证 |
| 后果签名（Gauthier & Kaliszyk 2019） | 不比定义比后果，认出不同定义的同一对象 | 只借思路，未在教材上验证 |
| 外部中枢（Wikidata / MathGloss / mathlib） | 映射到共享 ID | 不采用为主结构：只到概念名一层，覆盖不到电路、C++ |
| 名字融合、边并集（BUPT 2023、Graphusion 2024） | 相似实体合并，一对点只许一种关系 | 不采用：与“不合并”冲突，打散子句 |
| 自动形式化到 Lean 判等价 | 精度 82–90%（200 对数学） | 不采用为主线：只覆盖数学、成本高 |
| 知识追踪、强化学习、多臂老虎机 | 估掌握、选下一步 | 不采用：都要大量学习者数据 |
| 学习进阶、螺旋课程 | 跨年级重讲 | 量级不对（年级跨度） |

## 2. 真实例子：ln / exp（本机抽取，免费模型抽的，未审）

| 陈述 | Spivak《Calculus》 | Stewart《Calculus》9e（晚讲版） | 其他书 |
| --- | --- | --- | --- |
| ln x = ∫₁ˣ 1/t dt | 定义（出发点） | 6.2* 节路线的定义；6.2 节路线里是推出的结果 | — |
| ln 是 eˣ 的反函数 | 推出的结果（再定义 exp 为 ln 的反函数） | 6.2 节路线的定义 | Thomas、普林斯顿读本、Larson 都走这条 |
| (ln x)′ = 1/x | 由微积分基本定理推出 | 由反函数 / 隐函数求导推出 | 普林斯顿给 (log_b x)′ = 1/(x ln b)，取 b = e 得到 |
| e 的定义 | e = exp(1) | 使 aˣ 在 0 处斜率为 1 的底 | — |
| 书自己写出另一条路 | — | p.415：“另一种做法是先用积分定义对数，再把指数定义为它的反函数”，较不直观但更严谨 | — |

这一主题至少有两个子句：从积分进去（ln 是面积累积，exp 是推出的）与从指数进去（exp 先有，ln 是反函数）。旧抽取（已作废）每点只挂单条前置，两条路存不进同一张关系表，还漏掉了 Stewart 6.2–6.4 与带星号的几节；新做法下这是 ln 的两个点（按定义拆）加各自的子句。
