# 背景与已定

## 1. 项目一句话

Studium：给成年自学者（高中以上、不为应试，偏研究型理科，如微积分、物理、电路）用的学习系统。闭环内的教学交给大模型；系统把力气放在大模型做不好的部分：跨时间记得学到哪、会了什么、下一步学什么、知识怎么连起来。现阶段只有一个学习者（产品负责人本人），模型只用 Claude Opus 5.5 / Sonnet 5.5。

## 2. 闭环（学习的基本单位）

| 项 | 含义 |
| --- | --- |
| 定义 | 从学习者**已会的几个出发点**出发，学知识网上的一个**新点**，靠这些出发点把它理解到目标层次 |
| 出发点不同，理解不同 | 同一个点从不同出发点学（如同一物理定律从代数或从微积分出发），学到的理解不一样，所以要记“从哪学会的”，不只记“会了” |
| 合上 | 新点经出发点接进学习者已有的认识（同化或顺应），而不是学成孤立的一块；由模型读对话原文判断，不用打分公式 |
| 大小 | 一次坐下来能走完；阶段越高，出发点越抽象、目标层次越高 |

## 3. 相关的三个部分

| 部分 | 做什么 | 关键约束 |
| --- | --- | --- |
| 知识网（下称 M08） | 通用知识结构，由书本抽取而来：点、连线、原文 | 不读任何个人信息；原文是权威，其余都是派生；多份资料**各存各的、不合并**，“两条说同一件事”是一条带证据的链接；只追加、可撤回；新内容默认是候选，经审核才算数 |
| 学习者模型（下称 M09） | 记这个人合上过的闭环：从哪组出发点、学会了什么、到什么层次，底层是闭环对话原文 | 只在闭环合上时写入 |
| 导航（下称 M05） | 每次只设计下一个闭环：选新点、选出发点、定目标层次 | 读 M08 + M09 + 学习者状态（精力、时间）；决定要能回查到原文 |

## 4. 约束

| 约束 | 说明 |
| --- | --- |
| 存的都是文字，给模型读 | 不是给人看的数据库；也要能被审核者（模型或人）读懂 |
| 没有统计数据 | 一个学习者，学习方式是对话，没有题库、没有大量答题记录；知识追踪、强化学习这类靠大数据的方法用不上 |
| 输入干净 | 没有统计去纠错，只能靠给模型的输入准确、可回查 |
| 规模 | 本机已抽 33 本书（微积分、线代、概率、电路、电磁学、C++ 等），一本 2000–4500 个点 |
| 抽取现状 | 免费模型逐节抽取：点表（编号、名称、类型、一句话、原文引文、页码）+ 关系表（前置 / 推导 / 组成 / 混淆）；每点只挂单条前置，存不下“几组出发点” |

## 5. 本轮暂定（产品负责人暂时接受，未验证）

| 项 | 暂定 |
| --- | --- |
| 储存层不需要“粒度” | “一个学习单位多大”是消费时的概念；储存层只要**最小单位**：能锚到原文一段、能用一个名字说清（一个定义 / 定理 / 方法 / 例子）。现有抽取已到这个下限 |
| 信息量从哪来 | 不靠把点切细，靠**子句**和连线多 + 原文保留 |
| 子句 | 一个点可以从哪几组出发点学会，每组 = 一个子句（借自知识空间理论）。**子句按点存**：一个子句指向一个点 |
| 三层 | 原文（按书 → 章 → 节排，保留作者顺序）· 点（名字 + 一句话 + 锚点）· 子句 / 连线（挂在点之间成网，不属于某本书）。子句标来源：书给的 / 模型补的 / 学习过程来的 |
| 簇属于学习者 | 闭环的“新点”实际是 M08 上一簇点；簇不存 M08，由 M05 现场算：从选定子句出发一个个推下去，到一次坐下来的量为止。合上后 M09 记下这一簇，以后可整簇当出发点 |
| 知识边缘 | 未会、但至少有一个子句的出发点全已会的点；每合上一个闭环重算，纯图计算，不用模型 |
| 子句标“用到出发点的哪一面”，不标层次 | 例：用积分路线定义 exp，要用到 ln 的“面积累积”那一面；从指数那边学会 ln 的人可能缺这一面。M05 读文字比对；判错由闭环内“缺前置就当场补”兜底 |
| 派生不随个人改 | 个人化留在 M09，M05 用时合；学习过程来的只作候选、追加证据 |
| 书本子句 = 标准 | 但标准不代表个性化；个性化靠在子句间选、补桥接 |
| 派生写精简句子 | 点一句、子句一两句（从哪出发、学出什么、用到哪一面）；关键词只给程序粗筛用 |
| 子句怎么来：先生成、后审核 | 模型先凭自身知识说出某主题有哪些点、哪些子句；再拿书审核：书里找得到支撑原文 = 书给的，找不到 = 模型补的（候选）；书里有、清单没有的路线反过来补进清单。审核由模型做 |
