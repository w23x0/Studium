# M05 验收范围的写法（撤下原文）

> 状态：**已撤下**（2026-09-28），**不作依据**；保留原文只为回溯方向、找回原想法。
> 撤下原因：闭环重定为“知识链上的一段”（产品总览「闭环定义」）；真人试用 me-8 显示“主张 + 证据”把闭环变成取证过程（`../../Harness设计/_research/原型实验-9-发现.md`）。
> 去向：现行写法见 M05 审查单「这段链的写法」；其中验证过的五条移入 `../../设计资产/`（教学深度 / 已会与取证 / 闭环尺寸与范围）；其余未经实验。

| 原结论 | 验收范围写成**一组可逐条核对的“主张 + 证据”**（借以证据为中心的设计）：主张 = 学习者应会什么，按理解四级标明层级（闭环至少含一条“结构”级主张）、判据按学习阶段取（如大学：能独立推导核心定理 / 识别应用场景 / 讲清逻辑链）。**闭环边界有横纵两向**：横向 = 包含哪些知识点（内容量），纵向 = 每个知识点理解到哪一级、多深；两向超出都记为下一闭环候选，纵向往上走由「闭环组合与晋级」承接。**纵向深度按学段写足**：某级主张的要点须覆盖该学段该级的全部内涵，不能只写步骤——如大学“结构”级须含**动机**（为什么这样定义 / 构造）、**边界**（什么条件下成立，去掉某个条件会怎样）、**依赖**（与相邻概念怎样相连）（产品负责人 2026-09-26 确认，依据真人试用 me-5：“结构”级主张只写了逻辑链，纵向只到步骤层，系统从不引导往深处挖，见 `../../Harness设计/_research/原型实验-5-发现.md`；刻度见 `../../学习理论/理解理论.md` §阶段适配）；证据 = 什么表现算数，带条件（独立 / 无提示 / 过程可见 / 变式）。**教学主张的证据以学习者讲清楚为主（费曼式）**：M05 为每条列出讲解须覆盖的**要点**与**常见误解**，学习者无提示讲到要点、未落入误解即算数；**题目只用于迁移级主张**，要综合、有深度，不堆基础题——基础题会让闭环退化为问答检验，本产品不做熟练度练习（产品负责人 2026-09-23 确认，依据 `../../Harness设计/_research/讲解式学习证据-发现.md` 与原型真人试用 me-3）。引出证据的任务归 M03（验证意图），**只用在收尾的验证阶段**；学习阶段的任务为理解而设，不以取证为目的（M02「讲解式主线」学与验分开，2026-09-27）。逐条核对归 M04 闭环守卫。“结构”级主张的要点写成**一般原理**（对象、前提、边界、方法），具体情境只出现在证据的检验方式里，不让讲解停在某道题上（2026-09-27，依据 me-7：要点落在“船和人”上，学习者指出总结不该停在特定场景）。是否要求变式或延迟证据，由 M05 按该闭环目标需要的深度决定，**不设全局要求**（闭环 = 一个会话，当场可结束）。**读 M09 的来源档次**：外部导入（畅谈 / 笔记，未验证）的内容，本闭环离不开时先放一条【确认】再当前置（2026-09-27）。**读 M09 的证据强度**：M09 里证据只有“仅当场”、而新闭环离不开的内容，放一条【确认】主张隔时再验（延迟证据），每个闭环至多一条、优先新闭环依赖的前置；新闭环用不到的“仅当场”内容归复习子模块，不在此处理（2026-09-27，采纳 `../../F5.1的建议/03` 后该建议删除）。主张分两类：**教学主张**（本闭环要教会的）与**确认主张**（前置或可能已会的；有行为证据即可，不要求“用自己的话讲一遍”，防止对已会内容变成考试）。会话中收到“学习者已超出范围”的改线依据时，M05 把相关主张转为确认，让闭环**尽快结束、进入下一个闭环**；**不在会话中往深处扩**——闭环是设计好的东西，更深的内容由下一个闭环承接，偏浅的事实记入路线偏差记录供设计下一个闭环时参考（产品负责人 2026-09-23 确认，依据原型实验 2：会中加深导致闭环一直不结束）。由 M01 落实。主张过多说明闭环过大，应拆成嵌套闭环。**尺寸以一次坐下来能完成为准**，重度依赖的前置若来源只是自述 / 假定，宁可先确认或拆出去；验收范围后标 2–3 个**停靠点**（完成某条主张或要点之后，学习者可安心离开的位置）。**学到一半发现过大**（待实验，2026-09-27 第一次实践于 me-6）：守卫核对后记入停车场，由 M05 按原闭环剩余部分写**拆分计划**——原主张与要点一条不删、全部分配到若干最小闭环，按依赖排先后、前置不牢的先补——再逐个设计；拆分计划是 M05 自有记录。为补前置拆出的小闭环，**深度只做到后续闭环用得上的程度**，不强行配满动机 / 边界 / 依赖，学习者凭直觉已会的点不单独做成结构级主张；要点写成要表达的意思，不写成标准句（依据 me-7：一个小前置被写成四要点的结构级主张，教学变成追问措辞）。默认对学习者可见、可改，但闭环进行中不反复提起（防审判感）。（2026-09-23） |
