## 边界结论

### M02 与 M03

- 保留两个模块。理论资料明确区分“教学输入形成表征”和“学习者练习形成独立调用能力”：M02 输出讲解、表征、追问、示例和教学推动；M03 输出学习者完成题目、推导、证明、实验或解释后形成的表现与练习证据。
- 不把两者割裂，也不把它们排成固定流水线。M02、M03、M04、M10 在当前学习闭环中构成可分支、反馈和回返的运行图：M02/M03 执行教学和练习，M04 持续诊断，M10 依据诊断和学习者状态给出学习策略与强度条件；M05 位于闭环之外，负责前方路线，M01 保存会话与路线事实。

### M07、M08 与 M09

- M07 保存相对稳定、可追溯的资料及题目，交付目录、原文位置、检索结果和引用上下文。
- M08 保存不专属于某个学习者的概念、方法及前置、推导、对比、混淆和迁移关系。资料章节、父子切片和内容类型仍属于 M06/M07，不能自动当作概念关系。
- M09 只保存已结束学习闭环形成的丰富个人知识、理解、能力条件、高层个人结构、证据边和时间版本。负荷、情绪、注意力和策略偏好等高频状态不属于 M09 核心，也不能写回通用 M08。
- M08 可从 M07 提取通用知识结构，也可接收 M09 基于多个已结束闭环整理出的去个人化候选。只有经过通用性、来源、冲突、隐私和适用范围审查的候选才能晋升；M04 不直接写入 M08。

### M04 与 M09

- M04 贯穿整个进行中的学习闭环，在主线、分支和迂回路径上持续维护诊断、替代解释、证据限制与未满足项；从 M04 自身视角看是围绕闭环目标反复判断的内循环，但系统整体仍是图。
- M04 的中间诊断只服务当轮教学、验证和路线决策，保存在运行期上下文与日志中。闭环守卫通过后，M04 才按 M09 契约一次性编译总体个人形成记录，并通知 M01 结束闭环。
- M09 保存异步的已结束闭环记录，不合并每轮临时判断。界面若展示“当前掌握”，必须区分 M04 的进行中诊断与 M09 的既有闭环记录，不能把两者压成一个同步更新字段。

### M10 教学策略系统

- M10 拥有通用策略知识、个人策略过程记录、适用条件、本轮选择和强度条件；M02/M03 执行教学与练习，M04 提供当前诊断，M05 决定闭环之外的路线、分支范围和返回条件，M01 保存并显示路线变化。
- “某策略在什么条件下有效”及其跨情境效果记录归 M10。正在变化的学习状态留在运行期上下文；不能因一次策略效果就在 M09 固化为偏好，也不能用策略历史覆盖 M04 的当前证据或证明掌握。
