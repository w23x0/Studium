# M15 学习者状态与条件

> 状态：已精简（2026-10-05，#24）；10-07 #35 “读取频率”改为存放处 + 按需查 + 内部整理（旧句见 `../撤下原文/M15-读取频率.md`）。原文见 `../撤下原文/审查单精简前/`。技术实现（触发、频率、读什么）见 `../../Harness设计/03-运行设计.md`「M15」。
> 这里的“状态”指学习过程中会变化、具有时间范围、来源和不确定性的非知识类状态与现实条件，不指心理疾病、人格或固定能力画像。

## 核心问题

保存并更新会影响学习过程、但不等于知识掌握的当前状态、近期趋势和现实条件，使 M10 的会话内策略和 M05 的跨会话路线可以读取同一份有来源、带时效的信息，并为 M04 的诊断提供可裁决的替代解释。

> 学习者现在以什么状态学习，当前能承载哪些学习条件，哪些现实限制可能影响表现？

它不回答“学会了什么”“接下来学什么”或“当前怎么教”。

**核心对象**是动态学习状态与现实条件。一个状态判断至少要能说明它来自哪里、适用于什么时间范围、是事实还是推断、是否得到学习者确认，以及目前还存在什么不确定性；它是一组可随会话和阶段变化的状态信息，而不是包罗万象的“学习者画像”。候选范围先按四类理解，不预先锁死为字段或固定量表：

| 类别 | 可能内容 | 主要使用者 | 分级 |
| --- | --- | --- | --- |
| 认知与资源条件 | 当前负荷、疲劳、注意力波动、任务切换、未完成事项压力、近期正反馈稀缺度 | M05、M10 | 主线。触发量全部来自 M01 侧过程事实，证据成本最低 |
| 情绪与评价条件 | 压力、焦虑、挫败、对考核或错误的威胁感 | M10、M05 | 保留。降低获取标准而非降低优先级：只记可观察行为与紧邻前序事件，不记情绪名词 |
| 行动与持续条件 | 触发失效（难以开启）、行动失效（启动后维持不到正反馈）、奖励失效（完成了但无正反馈） | M05、M10 | 部分可交付。触发失效看会话启动间隔与计划-实际差即可；行动失效需时长数据，等时间监控 |
| 现实约束 | 可用时间上限、环境干扰 | M05、M10 | 预留。独立输入通道，本轮不设计具体形态；期限属项目属性，归 M01 持有、M05 使用 |

主要使用者是 M05 和 M10；M04 是解释候选的裁决方，不是状态信息的常规消费者。这些类别描述学习条件，不形成长期人格、智力或医学结论；教学偏好、长期风格、模型配置和已形成的个人知识不放入 M15，分别更接近用户设置、M10 策略条件或 M09。

情绪与评价条件的记录归属在 M15，不迁往 M04：提取动作发生在对话通道上，与 M04 的诊断提取共用同一份输入、使用各自独立的输出契约，共用输入不构成所有权。M15 侧的提取只标注学习者出现了关于自身状态的表述、原话片段和紧邻前序事件，情绪命名、来源分层和时效判断在 M15 内部完成。

**作为与 M09 并列的独立一级模块**：它有独立对象（变化的状态与现实条件，而非知识形成结果）和独立生命周期（来源区分、时间有效性、趋势和不确定性）；M05、M10 读取它、M04 裁决它的解释候选，三者的决定不同，放入任何一个消费者都会职责倒置，放入 M04 还会消灭替代解释的独立来源；把高频状态放回 M09 会恢复旧版大画像的混合边界。M15 的独立不等于拥有所有学习者数据：M01 仍拥有项目/会话归属和过程事实，日志、审查链和数据治理归 M13 或后续跨模块记录设计。

## 功能

| 功能 | 产品结论 | 级别 |
| --- | --- | --- |
| 状态与条件形成 | 从自述、可观察事实和授权信息形成有来源、带时效和不确定性的状态描述；不把缺少证据的心理原因写成事实。 | 主干 |
| 来源与证据分层 | 区分直接观察到的事实、学习者自述、系统暂定判断、已确认的状态和未确认的替代解释，不把行为线索直接命名为心理状态。 | 主干 |
| 时间有效性与变化 | 区分当前会话、近期阶段和相对稳定的现实约束；短时疲劳不能默认成为长期特征；保留改善、恶化、恢复和反复出现的条件；区分**预期内波动**与**真实恶化**——新建立的学习节奏存在必然的低谷期，此期间持续性下降不构成改变路线的理由。同一表现下降可同时保留知识缺口、提取困难、疲劳、压力或环境干扰等解释，直到有新证据区分。判据不交给人工裁定（横切原则 4）：准备好所需证据后做隔离式判断——回看窗口内的事实取全、多维分别判、留下依据与反例；缺证据时输出“不确定”，不选边；各功能之间保持细粒度隔离，使出错时能定位到哪一段判断。 | 主干 |
| 状态阶段判断（跨会话子模块） | 见下「状态阶段判断子模块」。 | 主干方向 |
| 输出分型与裁决交接 | 所有对外输出标明属于**承载读数**还是**解释候选**。承载读数（当前负荷、可挂核心任务数、可承载连续时长、环境限制）与 M04 的知识诊断正交，M05/M10 可直接使用；解释候选（对当前表现下降的状态解释）与 M04 的诊断竞争，须经 M04 裁决后才能被 M05/M10 用作行动依据。 | 主干 |
| 候选与趋势的隔离 | 趋势只能由 M15 自己的多次独立可观察事实形成，不因另一模块的存在而收敛；M15 与 M04 对同一表现的解释可以并存，各自交付给各自的消费者（M15 给 M05/M10，M04 给 M10）。用户确认不构成趋势形成的前提。 | 主干 |
| 承载能力与现实限制 | 描述当前可能承受的任务量、持续时间、复杂度、切换压力和环境限制，不据此直接排出路线、生成计划或选择教学法。承载条件以核心任务数量表达（同时不超过两个），而非时间表；现实约束不必追求日程精度。 | 主干方向 |
| 状态可见与异议记录 | 状态记录、来源和依据对学习者可见（横切原则 5）；学习者异议按自述来源记录并标注，不覆盖可观察事实。 | 主干 |
| 面向模块的只读供给 | 向 M04/M05/M10 分别提供解释条件、路线承载限制和策略适配条件，不把同一信息的不同用途混成一个决策模块。 | 主干 |
| 状态回看与学习者解释 | 以可读方式呈现状态变化、依据和限制，支持学习者理解系统为何提出暂停、降载或重新确认；不先锁定界面形态。 | 第二梯队 |
| 外部条件接入 | 在明确授权和用途说明后接入作息或设备信息；不把自动采集当默认；误读风险高，需单独审查。 | 候选 |
| 自动长期趋势归纳 | 从多次状态信息提出可回看的近期趋势，始终保留时间范围和不确定性，不滑向固定画像或人格标签。 | 候选 |
| 状态记录撤回、否认失效传播、敏感状态屏蔽 | 不做：自述不可信这一前提本身否掉了“由学习者裁定哪条状态记录成立”的机制；屏蔽功能当前无必要。 | 明确不做 |
| 心理疾病诊断与人格画像 | 不做，也不作为隐藏候选功能。 | 明确不做 |

### 状态阶段判断子模块（跨会话）

回答“这次下滑属于什么性质”。它**盲发候选**：只依据可观察事实和自述，不知道 M04 是否已判定前置漏洞或台阶跳跃；排除由 M04 的裁决完成。它是 M15 内部独立的跨会话子模块：判断情绪与承载的涨幅需要跨多次会话，输入是 M15 主体已产出的状态日志的整合，不新开跨模块通道。M04 侧有一个对称的跨闭环子模块，两者互不读取。

**输出契约上锁三条**：① 只输出**阶段类型**与**所依据的时间跨度**，不输出特质陈述（多会话情绪涨幅积累到足够长度就构成人格断言，这是唯一的滑坡口）；② 只给读数，不给动作，动作归 M05/M10；③ 不与 M04 侧子模块的结论合并为单一「学习压力」量（合成需要一方同时持有知识侧与状态侧结论，正是严格单向所禁止的）。M05 与 M10 各读两个读数、在各自作用域内行动。

| 阶段类型 | 依据 | 需要的回看窗口 | 应对归属 |
| --- | --- | --- | --- |
| 习惯低谷 | 新节奏必然经过的低谷期：即时奖励已撤、长期正反馈尚未形成，此时下降属预期内 | 该节奏起始至今（起始位置由 M01 持有） | M05 不改道 |
| 堆积型下滑 | 未完成事项累积持续占用认知资源 | 近几次会话 | M05 限流、主动搁置 |
| 疲劳退化 | 明确可逆的分阶段退化 | 本次会话加近期对照 | M10 降载、M05 留恢复期 |
| 阈值型动力低 | 即时刺激阈值抬高，慢反馈无法产生有效激励 | 跨阶段 | M10 高频小反馈 |

本功能区是“历史信息只用于概率参考”的唯一例外：每类阶段各自声明所需回看窗口，最长为习惯低谷，最短为疲劳退化；功能区之外仍只用近期信息。知识侧原因（前置漏洞、台阶跳跃过早）在本功能区**没有对应类型**，在 M15 侧表现为无匹配特征，不产生候选。

### 可记录、临时参考与明确不推断

| 分类 | 内容 |
| --- | --- |
| 可以记录为状态或条件事实 | 学习者明确说出的当前疲劳、压力、挫败、焦虑、注意力、动力、启动困难、时间和环境限制；学习者对系统暂定状态的认同或异议（作为自述来源记录，“学习者否认了这条”本身是事实，但不能裁掉观察结果，冲突时并存并标注，由 M04 裁决时处理）；学习过程的可观察事实及其发生时间（学习时长、暂停、中断、任务堆积、连续错误、长时间无响应、反复切换）；学习者主动提供并明确授权的作息、设备等外部条件（用途和有效范围清楚）；在多次有来源事实支持下形成的近期趋势（保持时间范围和可推翻性） |
| 只能作为临时参考或未确认候选 | 从回答质量、响应时间或任务中断推测的“可能疲劳”“可能过载”“注意力可能波动”；由当前条件派生的短期承载建议（不是稳定能力结论）；外部传感器或作息数据提示的变化（没有用户确认时不能提升为敏感心理或身体状态事实）；“当前表现可能受状态影响”的替代解释（只帮助 M04 保留假设，不能证明掌握或不掌握） |
| 明确不能由 M15 推断 | 心理疾病、临床诊断、治疗需求、危机等级或任何医疗结论；人格、意志力、智力、稳定学习风格、长期动机或道德评价；“因为疲劳/焦虑所以不会”“因为没有启动所以没有动力”等未经验证的单一因果结论；知识掌握、理解深度、能力真值或闭环是否完成（归 M04/M09）；下一步学什么、路线如何分叉、何时返回（归 M05）；当前采用哪种策略（归 M10，由 M02/M03 执行）；在用户不知情的情况下持续推断敏感心理状态，或把一次状态判断静默写成长期个人模型 |

## 输入输出

**输入分两条互不相通的通道。**

- **对话通道**（主要来源，与 M04 共享同一份 M01 过程记录，以不同的提取指令和输出契约隔离）：M02/M03 产生的可观察学习过程事实（连续失误、长时间无响应、任务无法启动、频繁中断、回答质量变化——是事实，不自动等同于疲劳、焦虑或动机不足）；学习者关于自身状态的表述；**当前任务与上一任务之间的跨度**，作为刺激强度的前序事件（跨度大时，挫败反应可能与难度相称，而不是抗挫折能力低），跨度从对话内容本身自取，不从 M04 的判断中取。M15 **不读取 M04 的任何知识结论**。
- **怎么被用**：M15 是存放处，不按事件把结果推给各模块。底层是只追加的状态记录，上层是可从底层重算的“当前状态”页；闭环对话、M05 按需查（实时的、近期的都能查到）；M15 自己在会话结束后、学习者隔很久回来时整理（过期、阶段判断、自述与观察并存标注），整理不把多次记录合并成长期特征。技术实现见 `../../Harness设计/03-运行设计.md`「M15」。
- **现实约束通道**（独立输入，本轮只预留位置）：不经过对话，来自用户设置与明确声明；范围只含可用时间上限与环境干扰。
- **其他输入**：M01 的项目、会话、暂停、恢复、时长和任务生命周期事实，含当前学习节奏的起始位置；已有 M15 状态记录及其变化历史（用于时间对照，不用于制造稳定人格结论）；M04 的**重新确认请求**（不携带判断、不压缩假设集，不能是状态结论）；学习者明确授权的外部信息（作息、设备信号等，只作学习条件参考，不能未经同意持续读取，也不能据此作健康诊断）。
- **采集路线是被动考察为主**，持续优化被动判断的准确率；主动报告不是采集重点、也不具备权威（沉浸式形态下机会稀少，自述受可得性偏差影响，学习者还可能否认或掩盖）。自述与观察冲突时并存并标注，由 M04 在裁决解释候选时处理，不由自述单方面裁掉观察结果。

**输出**（每条标明属于承载读数还是解释候选）：

- 当前状态或现实条件及适用时间范围；状态来源（用户自述、可观察事实、授权外部信息或暂定推断）；可见依据、不确定性和可能的替代解释。
- 当前承载限制、环境约束和需要重新确认的事项（承载读数，直连 M05/M10）。
- 当前表现下降的状态解释候选，以及所属状态阶段类型（解释候选，经 M04 裁决后生效）。
- 与近期状态相比的变化，用自然语言描述，不以不可解释的单一分数代表真实状态。
- 供 M10 使用的策略适配条件；供 M05 使用的路线承载限制；供 M04 裁决用的解释候选；供 M01 记录的状态与项目/会话关联事实（不把状态语义转移给 M01）；面向学习者的状态、来源和依据的可见呈现。

M15 不直接创建、暂停、恢复或结束 M01 会话；不直接关闭 M04 闭环；不直接修改 M05 路线；不直接调用 M10 的教学策略；不替任何模块输出诊断结论、路线决定或教学策略。

## 边界

- **M15 与 M01**：M01 保存项目、会话、闭环、生命周期和路线事实；M15 形成动态状态与现实条件。M01 可以记录某状态发生于哪个项目或会话、何时被确认以及相关过程事实，但不解释该状态，也不因为状态自动暂停或结束会话。M15 不能创建或修改 M01 的会话结构。
- **M15 与 M04**：M15 提供“当前可能有哪些状态和现实条件，以及证据有多强、何时有效”；M04 判断“这些条件是否可能解释当前表现、还需要什么知识证据”。M15 不判断会不会、是否掌握或闭环是否完成；M04 也不应把一次表现直接写成稳定状态。
  - **信息流严格单向 M15 → M04。** M04 不能写入或确认 M15 状态候选，也不能向 M15 提供任何知识结论；M15 的输出不受知识判断影响，正是它作为独立替代解释源的价值。不允许 M15 读 M04（已评估的代价：候选坍缩、与 M10 自循环同类的回声、归因整体倒向知识侧、跨级别锚定）。
  - 已知代价：M15 不掌握前置结构，难度读数是粗的；实际为前置漏洞时 M15 仍会发出疲劳或堆积候选——它是候选不是结论，由 M04 排除，且不得沉淀为趋势。
  - M04 可以向 M15 发出**请求**：某状态需要重新确认，请求不携带结论。M04 的输出中包含对状态候选的裁决（检查过哪些 M15 解释候选、知识证据支持还是排除），属于诊断的一部分，不构成对 M15 的写入；M05/M10 因此拿到已裁决的解释。习惯低谷候选同样经 M04 裁决，但 M04 只需给出“知识侧解释不了本次下降”，节奏判断本身不在 M04 视野内，该候选存活后交 M05 使用。
- **M15 与 M05**：M15 提供可用时间、负荷、环境和持续条件等路线输入；M05 决定下一闭环、优先级、并行量、分叉、返回、复习和限流。M15 不安排学习路线，M05 不反向创建或修改 M15 状态。
- **M15 与 M10**：M15 描述当前状态和限制；M10 根据 M04 诊断、M15 条件和目标选择策略、提示强度、挑战程度、信息量和节奏；M02/M03 执行。M15 不选择方法，不保存策略效果，也不把一次策略效果写成长期开关或人格偏好。**策略造成的状态必须标注来源**：当前策略本身会制造状态（逐题评判抬高威胁感，稀释审判频率降低它），M15 记录这类状态并标明它出现在某一反馈模式生效之后；M15 不读取 M10 的策略决定，该标注来自 M02/M03 的可观察事实。M10 读到带此标注的状态时，应先检查自身策略是否为成因。
- **M15 与 M09**：两者是一对分开的学习者模型，**双向都没有引用关系**。需要同时用到知识与状态的是 M05 和 M10：M05 直读两边；M10 直读 M15，知识侧经 M04 的诊断进入。“闭环完成时学习者处于什么状态”经 **M01 链接**获得；M01 只存事实（各次会话的启动间隔），不存解释（“启动困难”），解释每次由子模块重新导出。已知代价：导出的解释不可复现；按横切原则 4，每次导出带窗口与事实依据、可被核对，不承诺两次导出结果相同。不为状态侧建长期结论存储，因为那是人格标签的入口。
- **会话内与会话外级别**：M04 与 M10 是会话内级别（每轮生成、每轮消费，M04 是 M10 的主要输入来源）；M15 与 M05 偏会话外级别（跨轮、跨会话，关心节奏与承载而非单轮表现）。这解释了 M15 读取频率低于 M04、消费者主要是 M05 和 M10、以及 M15 不该读 M04。
- **阈值概念停滞与习惯低谷不合并**，各自独立护栏：阈值概念停滞在知识侧（M08 标记、M04 判断是否跨过），走 M04 → M10，M10 在会话内调策略强度，不动路线；习惯低谷在节奏侧（M15 状态阶段子模块），走 M15 → M05，M05 不改道、不加任务。不抽象成共同概念，避免会话内的判断影响会话外的改道决定。
- **M15 与 M02/M03**：M02/M03 产生可观察的互动和练习事实，供 M15 作为状态线索、供 M04 作为学习证据。M15 不直接控制教学和练习，也不把“长时间未答”“连续错误”等事实单独解释成心理状态。
- **M15 与 M13**：M13 或后续跨模块记录设计保存过程事件、审查链、版本和数据治理；M15 保存经过整理、可供学习过程使用的状态语义。M15 不是原始日志库，M13 也不替 M15 判断状态含义。
- **医疗边界**：系统只能提供学习相关的非医疗化支持；出现超出学习产品范围的健康问题时，不以 M15 结论代替专业帮助，也不作诊疗建议。外部信号接入需明确授权。
- **不进入产品输出的理论内容**（只作词汇和机制参考）：神经物质模型的具体物质名称（医疗化）；学习焦虑的亚型命名（距人格标签仅一步）；学习者效能理论的四象限命名、动态定位与迁移追踪。可保留的降级形式：四部门提问阶梯（愿不愿意学 / 能不能开始 / 效率如何 / 能不能持续）、可观察行为及其前序事件、单一“投入量”条件词汇。价值判断能力归 M04，不进 M15。
- 状态解释回到可观察事实，支持低负担的下一动作；审判密度和反馈措辞是可调条件、部分由产品自身设计造成，“考核时比平时更冷静还是更迷糊”是不依赖自述的可观察对比量。
