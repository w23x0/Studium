# M09 动态学习者模型（个人知识形成与掌握）

> 状态：已精简（2026-10-05，#24），原文见 `../撤下原文/审查单精简前/`。技术实现见 `../../Harness设计/03-运行设计.md`「M08 / M09」。闭环怎么定义见产品总览「闭环定义」，本单只用“本闭环的新点 / 出发点 / 目标层次”“合上”这些词。

### 核心问题

保存某个学习者在已经结束的学习闭环中真正形成了什么知识、理解、能力条件和高层个人结构，以及这些结论由哪些证据支持、怎样随时间变化。M09 是“个人知识形成与掌握模型”，锚定 M08 的通用知识对象，但不是 M08 的简单映射或个人覆盖图，也不是包含情绪、负荷、注意力等全部即时状态的“人物画像”（这些归 M15，不进入 M09）。

M09 只接收已经结束闭环的异步结果。进行中对话产生的同步信息、中间诊断和高频状态保存在当前闭环上下文与过程记录中；闭环结束后，M04 才把经过证据守卫的个人形成记录整理进 M09。摘要、认出/复现/结构/迁移等标签只是诊断与索引轴，不能替代底层形成记录、证据边、条件和时间版本。

### 功能

**核心机制**：M09 的底层是**闭环的原始对话文本**；模型对它的分析（结论、证据链、关键理解、关系）是派生层，用于检索、总结和跨闭环比较，可以换模型、换分析框架重做。（产品负责人 2026-10-05：原始对话文本是最好的记录，分析结果用于检索、总结——同一段话可有几种读法，分析会过时，原文不会。**待验证**：旧写法“存证据链而不是完整对话”原文见 `../撤下原文/M09-证据链存储原则.md`，两种写法在实验中对照。）

| 层 | 内容 | 地位 |
| --- | --- | --- |
| 原文层 | 闭环全过程的原始对话（学习者原话、系统讲解、题与作答），按闭环归档、带时间 | 权威；只追加，不改写 |
| 分析层 | 结论 + 证据链 + 关键理解 + 关系，含出发点、新点、目标层次；每条指回原文位置，记分析所用模型与版本 | 派生；可重做、多个分析版本可并存；检索、总结、当前视图从这里取 |

- **提交方式**：闭环守卫通过后**一次提交**（该闭环原文 + 当次分析）；学习过程与学习结果严格分离，分析层结构化保留有意义的形成事实和证据引用，不压缩成一句总结。
- **待定**：原文存放位置与体量控制；哪些模块能读原文（暂沿用 `../../Harness设计/03-运行设计.md`「M08 / M09」历史可见性）；跨很长时间后怎样把同一知识点的多条原文找回来；“后续闭环带来重新理解”的版本与并列记录，以及旧点理解改动后的牵连：改的是 M08 上的中心点（被很多点 / 出发点组用到）时，顺着记录找出拿它当出发点合上的闭环交 M05 复检（`../../../会话记录/2026-10-05-补理论-已有认识怎么变.md` 1.3、2.3，改后必须设计）。

| 功能 | 产品结论 | 级别 |
|---|---|---|
| 已结束闭环形成记录 | 只接收 M04 对整个闭环作出的总体诊断，保存出发点、新点、目标层次、路线、关键形成过程、结果、未满足项、时间和证据引用；M09 不接管进行中的诊断图。 | 主干 |
| 外部导入记录（畅谈 / 笔记导入） | 学习者在系统之外学到的知识，经**外部导入通道**点亮 M09 的知识区域：畅谈 = 模型通过对话获取，笔记导入 = 模型处理学习者的笔记；以后可加其他渠道。与闭环记录**严格分开**：标“未验证”，可信度低于闭环记录，按来源分档并写明判读依据（如有完整推导与自己解释的笔记 > 只抄定义 / 公式的笔记 > 自述 / 畅谈），用于填补 M09 的空白区域。教学中可以怀疑它：后续闭环的证据说明不牢时降档，闭环证据永远优先于导入。“守卫通过是唯一过渡点”只管闭环记录。（产品负责人 2026-09-27 确认） | 主干 |
| M08 锚点与未映射个人对象 | 闭环记录优先引用 M08 对象及版本；如果闭环结束时出现 M08 尚未表达的细节、理解路径或对象，可先作为有来源、仅个人有效的未映射对象/连接保存，之后再尝试锚定或提交候选（方向已定：先在 M09 暂存，经审核确认为普遍后晋升 M08；形态随 M08 设计定）。不能因通用库尚未表达某项个人形成事实而丢失闭环结果。 | 主干方向 |
| 丰富个人形成记录 | 对每个对象保存开放但结构化的理解、陈述/程序应用、结构解释、心智模型、可提取性、干扰、迁移、直觉、缺口和适用条件。维度可空、可扩展，不强制压成四级或一个总结；不用数值评分、固定公式、阈值或七维统一画像。 | 主干 |
| 证据边与条件 | 每项个人结论引用相关闭环、学习者表现、教学/提示条件、时间和必要原始过程位置；独立完成、提示后完成和答案暴露后的表现必须可区分。**证据引用还必须记录该结论由哪个模型、哪个版本得出，且必须是实际执行模型而不是可变别名**（别名可被重新指向，会使整条证据链失效）。 | 主干 |
| 当前视图与索引摘要 | 可从底层记录派生当前理解视图、四级理解标签、一句话摘要和检索关键词；这些派生结果可重建，不得替代底层形成记录和证据，不拥有权威性。 | 主干 |
| 闭环网络与高层个人结构 | 组织同一闭环和不同 closed 记录之间的组成、前后、复用和关联；从多个记录归纳方法、结构模型或思维框架在该学习者身上的形成情况。高层结构必须有范围、内容和证据，不能只是关系边或人格标签；不自动成为 M08 通用知识。 | 主干方向，实验能力未定型 |
| 时间、版本与重新掌握 | 记录闭环完成、复检、遗忘/提取失败、重新掌握和更正的时间版本，不静默覆盖旧结论。未来遗忘研究还需区分是否独立提取、提示条件、间隔和任务变式。**遗忘/提取失败只能来自闭环结束的那次提交，且提交时须已排除状态侧解释**；M04 进行中发现的“以前会的现在答不出”是候选，可用于给 M10 补讲或给 M05 另开复习，但不构成 M09 记录。**遗忘与降档的来源**：后续闭环里，M04 发现学习者对 M09 已有内容（含外部导入）的表现不符，记下并随该闭环提交；M09 据此记“提取失败 / 降档”，不静默覆盖旧结论；不使用固定遗忘曲线（2026-09-27）。 | 主干 |
| M09 反向增益 M08 | 从一个或多个已结束闭环中整理 M08 未表达的知识细节、理解路径、边界、反例、个人结构和迁移尝试；去个人化后提交候选。M09 不直接写入正式 M08。 | 主干方向 |
| 跨项目/跨学科个人结构 | 在项目或学科间记录可复用的个人形成结构、边界和来源；默认不因同一学习者而自动泛化。共享与权限规则尚未确认。 | 候选 |
| 人格类型、能力评级、跨学科自动泛化 | 不做，也不作为隐藏候选功能。M09 只保存有证据、有范围、可推翻的个人形成事实。 | 明确不做 |

#### 知识面（派生视图，2026-09-18）

**知识面 = M09 的一个派生视图，不是 M09 的存储。** 面从个人形成记录派生。

| 项 | 内容 |
| --- | --- |
| 骨架 | **M08 图**（对象 + 关系）——面寄生在 M08 上 |
| 取值 | **覆盖 / 部分 / 未知**（不是 0/1；遗忘、分析系统等后续按真实自学问题再加） |
| 来源 | **闭环证据**（精确·点，已验证） + **外部导入**（畅谈、笔记导入；未验证，按来源分档）；**书本 = M08，不是面的来源**；面上标明每块的来源档次 |
| 分辨率 | **多分辨率**：目标面**粗** / M05 算路线**中** / M10 闭环内**细** |
| 时效 | 闭环证据只由已结束闭环写入 → **滞后一拍**（进行中不反映）；外部导入在导入时写入 |
| 权威性 | **派生、可重建**；不得替代底层形成记录和证据 |
| 消费者 | **M05（主）**：实际面 → 目标面算路线；**畅谈**：看已储备、定目标；M04：读相关一片当背景 |

**冷启动**：M09 空时，面主要靠 **M08（书本骨架）** 给 M05 起步，**畅谈**补一层粗的个人面；随闭环推进，闭环证据逐步细化它。**记录仍需两根轴**：每条个人记录带**可信度（来源分层）**与**时间变量**——同一片知识，证据可信度不同，所以面不能是 0/1。

### 输入输出

- 输入：M08 当前的概念、方法、结构模型、思维框架及关系；M04 在整个学习闭环结束后形成并通过闭环守卫的总体诊断；M01 的会话目标、主线/分叉来源和完成时间；被 M04 采用的教学/练习表现和证据引用；闭环内参与过的所有上下文资产（经 M04 的闭环记录汇总）；学习者更正。**M09 不读取 M15**。
- 主要处理：把闭环结果锚定到一个或多个 M08 对象；保存学习者对对象形成的理解、应用、结构解释、提取、干扰、迁移、直觉、缺口和条件；连接相关已结束闭环；保留时间、版本和证据边；从多个 closed 记录中形成有范围、可推翻的高层个人结构；必要时保存尚未映射到 M08 的个人对象或连接，并向独立候选/审计通道提供反向增益材料。
- 输出：已结束闭环构成的个人知识形成图、当前可读取的个人理解与能力条件、未满足项、个人结构对象、时间版本和证据引用；以及面向 M08 的去个人化候选材料。M09 不保存进行中诊断图，不拥有通用知识、学习计划、教学策略或高频即时状态。

### 边界

- M08 的抽象轴属于通用知识；M09 不复制这条抽象轴，而是在任何 M08 对象上保存“这个学习者形成了什么”。理解深度、应用条件和个人形成过程是 M09 的内容。
- 证据不是 M09 的一个层级，而是连接个人结论与已结束闭环、具体表现和原始过程的支撑边；每一层个人结构都必须有自己的证据。关系边不能单独承载高层思维：高层个人结构应允许成为有适用条件、识别线索、内部步骤、边界、失败案例和证据的复合对象或个人子图。固定四层树塔和固定理解枚举不作为 M09 数据结构；图可递归增长，层只表达抽象或理解视角。
- M04 → M09：M04 贯穿进行中闭环并维护同步诊断；闭环守卫通过后，才提交一次符合 M09 结构的总体个人形成记录。M09 不读取每轮临时判断作为正式状态，不做每轮同步 upsert。
- M08 ↔ M09：M08 通常领先于当前规划范围，提供通用知识锚点和当前可学习边界；M09 保存个人在这些对象上的形成记录，并把 M08 未表达的内容整理成候选。正式通用内容仍由 M08 审计和晋升，M09 只能提供反向增益材料；M08 扩展后，M05 基于扩展后的 M08/M09 规划下一轮学习。
- M09 → M05：M05 比较 M08 的可学习结构与 M09 已结束闭环记录，制定下一目标、复习/复检和路线。M05 的计划不写回 M09；只有新闭环完成后才形成新记录。
- M09 → M04 → M10：M04 读取与当前目标有关的已结束个人知识，并结合当前表现形成诊断；M10 消费该诊断制定策略，不重复把 M09 的个人知识作为教学判断。M10 的个人策略过程与效果记录独立保存，不能写入 M09 成为稳定人格或掌握结论。
- M01 → M09：M01 提供闭环目标、主线/分叉来源、完成位置和时间事实；分叉会话独立完成后可立即形成 M09 记录，再由路线返回原主线。
- M09 与 M15：**双向都无引用关系**，是一对分开的学习者模型。需要同时用到知识与状态的是 M05 和 M10：M05 直读两边；M10 直读 M15，知识侧经 M04 的诊断进入。“闭环完成时学习者处于什么状态”经 **M01 链接**获得。M01 只存事实、不存解释；解释每次由 M04/M15 各自的跨会话子模块从事实重新导出，只承诺依据可核对、不承诺结论可复现（横切原则 4），不靠人工校准兜底。
- 未完成闭环不进入 M09：闭环记录只接收已结束闭环（外部导入另走通道）。会话未结束期间的事实由 M01 记录，当时的状态由 M15 记录。闭环长期无法结束属路线问题，归 M05（并行量与限流）。
- 进行中上下文与日志：M02/M03 的同步互动、M04 中间诊断、M10 当前控制和工具调用不直接写入 M09；不能靠逐轮聊天摘要直接写库。
- 固定复习天数、单一遗忘曲线、负荷分数、人格化策略偏好和跨项目自动共享均未得到验证，不作为需求。

#### 待产品负责人回答

第 1–3 问依赖 M08 的对象结构（接地表示 + 链接 + 粒度 = 遍历深度），属 M08/M09 设计的下游项。

1. 丰富个人形成记录的最小必需内容是什么；哪些维度只在出现相关证据时保存，避免强制填满固定模板？
2. 未映射对象 / 连接的可行形态（方向已定，见上表「M08 锚点与未映射个人对象」）。
3. 高层个人结构应满足哪些最低条件才可从多个 closed 记录派生；是否必须包含适用范围、内部机制、失败案例和多条证据？（属更深层功能设计）
4. M09 的时间版本最低保留到什么粒度；复检、遗忘/提取失败和重新掌握是否都形成新版本而不覆盖旧记录？
5. M09 → M08 候选在什么条件下自动生成；自动审查、人工审核、晋升和退回分别有什么权限？

**规模问题（由第 4 问引出，未决）**：不覆盖旧结论意味着 M09 体积单调增长。三个方向，在 M08/M09 设计中一并决定：① 重新规划 M09 自身结构，让历史版本在内部有独立位置；② 历史版本移交别的模块保管（例如 M01）；③ M09 分历史区与现有边缘区——“动态”体现在边缘网状节点上，历史沉到另一区（与「当前视图与索引摘要」一致，但把区划写进了数据结构，同样受选型约束）。
