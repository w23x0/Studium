# M03 练习活动

### 核心问题

把“听懂/看懂”转化为可独立调用、推导、应用和迁移的能力，并通过学习者真实产出暴露错误、思路和熟练度证据；练习不能退化为单纯出题和判答案。

### 输入、主要处理与输出

- 输入：M01 当前闭环目标、M05 的路线和分叉约束、M10 当前策略与练习所需的信息量、提示强度、挑战程度和节奏条件、M04 当前诊断、M08 的前置、辨析点、逻辑链和可迁移结构、M07 的题目与任务资源及出处、M02 交接过来的练习/验证动作。已结束闭环形成的个人理解经 M04 读取后进入本模块，M03 不直读 M09。
- 主要处理：按目的、能力层和当前教学条件选择/生成练习；明确任务要求和提示条件；采集答案与思考过程；提供功能性反馈；识别重复错误；组织递进、辨析、变式和迁移。
- 输出：练习任务、学习者产出和过程、练习反馈、错误模式、交给 M04 的表现证据，以及供 M15 使用的可观察练习过程事实。M03 是单向输出：只提供练习活动与可观察事实，不写回知识层（M08/M09），也不形成诊断、掌握、路线或状态结论。

### 重复合并后的结论

- “有效练习、学习效率、题目功能、直觉形成”高度重叠，合并为“目的匹配→独立产出→过程反馈→归纳→变式/迁移”的活动链。
- 知识/思路/技巧熟练层与概念澄清/计算/证明/应用功能是两种分类维度，不应各建一套练习模块。
- 解释、复述、写作既可能是 M02 的教学方法，也可能是 M03 的学习者任务；以谁产出、是否用于独立表现取证区分。

### 被后续资料覆盖的旧结论

- 旧系统将练习作为聊天回合中的“出题”动作，v0.5 和理论资料已覆盖为包含目的、过程、反馈、重复模式、变式和迁移的完整活动链。
- 旧三项掌握检查被 v0.4 四项证据覆盖；固定阈值和字段枚举不进入需求。
- 自动推断、心理/负荷软信号不能单独让练习通过闭环；v0.5 的软硬证据隔离覆盖乐观自动判断。

### 边界和信息流（专门检查 M02/M03/M04）

- M02 形成表征和教学推动；M03 要求学习者独立调用并产生可观察表现。二者不可替代，但可交错编排。
- M03 拥有练习任务生命周期、产出采集和练习反馈；M04 对产出作错误归因、理解层级和掌握判断。练习“做完”不等于“掌握”。
- M07 保存题目/资料资源，M03 选择并执行；题库内容不会因被调用而变成个人状态。**M03 生成的练习是否入库 M07 尚未决定**：M07 明确禁止一次性过程记录改变资料库，所以生成题不能默认入库；见本单产品负责人问题第 2 条。
- M05 决定当前目标、是否转入补前置分叉及何时返回；M10 决定当前学习策略及练习所需的**信息量、提示强度、挑战程度和节奏**四项条件；M03 组织独立产出活动并回传结果，不自定这四项。
- M08 -> M03：提供前置、辨析点、逻辑链和可迁移结构，供选择/生成练习、组织辨析与变式时使用。M03 的同步练习活动不能写回 M08。
- M09 -> M04 -> M03：已结束闭环形成的个人理解经 M04 读取后作为诊断上下文进入本单；M03 不直读 M09。
- M02 <-> M03：M02 在教学回合中发起练习/验证动作，M03 接住并接管练习生命周期；题目前后的教学措辞与对话衔接仍归 M02。
- M03 -> M15：提供可观察的练习过程事实（如连续放弃、要求提示、作答时长异常）。这些是事实，不等于疲劳、焦虑或负荷结论；状态语义由 M15 形成。
- 高阶写作/研究：作为能力检验的任务过程与表现证据归 M03；作为长期可迭代成品、版本链和来源引用归 M14。
