# M03 练习活动

> 状态：已精简（2026-10-05，#24），原文见 `../撤下原文/审查单精简前/`。技术实现见 `../../Harness设计/03-运行设计.md`。闭环怎么定义见产品总览「闭环定义」。

### 核心问题

把“听懂/看懂”转化为可独立调用、推导、应用和迁移的能力，并通过学习者真实产出暴露错误、思路和熟练度证据；练习不能退化为单纯出题和判答案。练习是一条完整活动链：目的匹配 → 独立产出 → 过程反馈 → 归纳 → 变式/迁移。

### 功能

| 功能 | 产品结论 | 级别 |
|---|---|---|
| 练习资源组织 | 题目、证明、推导、实验、项目、解释和写作任务可按目标、内容、功能和阶段被调用；题集属于资料，实际执行才是练习。 | 主干 |
| 练习选择/生成 | 根据缺口、目的、难度和当前阶段选择或生成活动，而非随机刷题。知识/思路/技巧熟练层与概念澄清/计算/证明/应用功能是两种分类维度，不各建一套练习模块。 | 主干 |
| 任务说明与完成条件 | 每次练习明确练什么、需提交什么、是否允许提示及何时算完成。 | 主干 |
| 答案与思考过程采集 | 同时记录结果、关键步骤、理由、尝试和自我解释，不只保存最终答案。 | 主干 |
| 错误反馈与重复模式 | 反馈定位知识、思路、技巧或过程问题；重复错误升级为模式，但不作人格评价。 | 主干 |
| 题型/方法归纳 | 从同类任务提取关键条件、逻辑链、方法与易混点，支持从点到网。 | 第二梯队 |
| 递进、变式与迁移 | 从有提示到无提示，从同形到变式/混合场景，检验独立提取和迁移；防止“原问法会答就算掌握”。 | 主干 |
| 阶段性练习体验 | 将日常练习与阶段验收区分，降低每题的审判感。挑战程度本身归 M10 的强度参数，本单不自定其升降。 | 第二梯队 |
| 接收 M02 交接的练习动作 | 接住 M02 在教学回合中提出的复述、辨析、例题等动作，转为正式练习任务并接管其生命周期；与 M02 侧的“发起练习/验证动作”成对存在。 | 主干（定义性交界） |
| 高阶活动形态 | 支持复现论文、实验、论证和写作等大学/研究阶段活动的**任务过程与表现取证**；其长期可迭代成品与版本归 M14。 | 第二梯队 |

### 输入输出

- 输入：M01 当前闭环目标、M05 的路线和分叉约束、M10 当前策略与练习所需的信息量、提示强度、挑战程度和节奏条件、M04 当前诊断、M08 的前置、辨析点、逻辑链和可迁移结构（待定：随 B2 改）、M07 的题目与任务资源及出处、M02 交接过来的练习/验证动作。已结束闭环形成的个人理解经 M04 读取后进入本模块，M03 不直读 M09。
- 主要处理：按目的、能力层和当前教学条件选择/生成练习；明确任务要求和提示条件；采集答案与思考过程；提供功能性反馈；识别重复错误；组织递进、辨析、变式和迁移。
- 输出：练习任务、学习者产出和过程、练习反馈、错误模式、交给 M04 的表现证据，以及供 M15 使用的可观察练习过程事实。M03 是单向输出：只提供练习活动与可观察事实，不写回知识层（M08/M09），也不形成诊断、掌握、路线或状态结论。

### 边界

- M02 形成表征和教学推动；M03 要求学习者独立调用并产生可观察表现。二者不可替代，但可交错编排。解释、复述、写作既可能是 M02 的教学方法，也可能是 M03 的学习者任务：以谁产出、是否用于独立表现取证区分。
- M03 拥有练习任务生命周期、产出采集和练习反馈；M04 对产出作错误归因、理解层级和掌握判断。练习“做完”不等于“掌握”。练习形式类教学工具（题型、练习生成方法，供教学侧按情形选用）由 M03 维护；引出学习者输出的方法与策略类教学工具归 M10（见 M10「通用策略知识层」）。
- 练习中学习者把新点和出发点接起来用的表现，是判断合上的依据（怎么判见 M04「闭环判定与证据守卫」）。固定阈值和字段枚举不进入需求；自动推断、心理/负荷软信号不能单独让练习通过闭环。
- M07 保存题目/资料资源，M03 选择并执行；题库内容不会因被调用而变成个人状态。**M03 生成的练习是否入库 M07 尚未决定**：M07 禁止一次性过程记录改变资料库，所以生成题不能默认入库。
- M05 决定当前目标、是否转入补前置分叉及何时返回；M10 决定当前学习策略及练习所需的**信息量、提示强度、挑战程度和节奏**四项条件；M03 组织独立产出活动并回传结果，不自定这四项。
- M08 → M03：提供前置、辨析点、逻辑链和可迁移结构，供选择/生成练习、组织辨析与变式时使用（待定：随 B2 改）。M03 的同步练习活动不能写回 M08。
- M09 → M04 → M03：已结束闭环形成的个人理解经 M04 读取后作为诊断上下文进入本单；M03 不直读 M09。
- M02 ↔ M03：M02 在教学回合中发起练习/验证动作，M03 接住并接管练习生命周期；题目前后的教学措辞与对话衔接仍归 M02。
- M03 → M15：提供可观察的练习过程事实（如连续放弃、要求提示、作答时长异常）。这些是事实，不等于疲劳、焦虑或负荷结论；状态语义由 M15 形成。
- 高阶写作/研究：作为能力检验的任务过程与表现证据归 M03；作为长期可迭代成品、版本链和来源引用归 M14。
