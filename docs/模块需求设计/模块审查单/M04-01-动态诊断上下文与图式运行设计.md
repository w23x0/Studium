# M04-01 动态诊断上下文

> 定位：M04 的诊断上下文备忘，不是新的产品模块，也不改变 M04 的产品职责。
> 状态：已精简（2026-10-05，#24），原文见 `../撤下原文/审查单精简前/`。技术实现（几个会话、开场交付什么、给哪些工具）见 `../../Harness设计/03-运行设计.md`「闭环对话」「收口与闭环守卫」。闭环怎么定义见产品总览「闭环定义」。

### 核心问题

M04 贯穿一个进行中的学习闭环、随 M02/M03 的教学互动和学习者表现持续更新判断。它需要拿到哪些来源的信息、这些信息要怎样区分，诊断才可复核、不被污染。

### 功能

| 功能 | 产品结论 | 级别 |
| --- | --- | --- |
| 诊断判断过程不直接展示 | M04 的判断过程默认不直接展示给学习者；面向学习者的表达由 M02/M03 生成；需要复盘或审查的过程由 M13 提供分级视图。 | 原则 |
| 上下文分类 | 进入 M04 的信息不合并成一段无类型聊天文本，至少区分：当前目标（M05 的单子（新点 + 选中的子句 + 路线动作）与本闭环目标）和闭环边界；当前路径位置及其与主线、分叉、迂回路径的关系；学习者原始表达和行为表现；教学系统已提供的讲解、提示、答案暴露和脚手架；练习任务、完成条件、独立程度；M08 通用知识依据及来源；M09 已结束个人知识记录、时间版本及适用范围；M10 的策略上下文；信息缺失、工具失败、模型降级等影响判断质量的限制。 | 原则 |
| 条件决定证据意义 | 同一个正确答案在独立完成、轻微提示、多次提示或答案已经暴露等条件下证据意义不同，诊断不能脱离教学和练习条件只读最终结果。 | 原则 |
| 基于完整闭环历史 | M04 基于完整闭环历史持续修正诊断，不只看最近一轮；教学侧保留自己上一轮的诊断，后续证据可以支持、修改或推翻它；闭环守卫不读这些诊断（2026-10-05）。 | 原则 |
| 中间诊断不沉淀 | 中间诊断在闭环结束前不得写成 M09 的稳定个人状态，也不得晋升为 M08 的正式通用知识。 | 原则 |
| 压缩可回查 | 摘要或压缩结果必须能回到原始证据核实，不能让压缩后的模型描述替代原始事实；信息保留类型、来源模块、原始位置、时间、适用范围和是否仍有效。 | 原则 |
| 分支不互相污染 | 主线、分叉和迂回路径的信息保留关系，避免不同任务、不同提示条件或无关旁支相互污染。 | 原则 |
| 缺料可见 | 上下文不完整或关键来源不可用时，M04 必须把限制纳入判断，必要时输出证据不足，不能伪装成完整诊断。 | 原则 |

### 输入输出

M04 可在一个进行中闭环内维护上下文，但不改变原始信息的模块归属。来源与所有权：

| 来源 | 提供给 M04 的主要信息 | 所有权边界 |
|---|---|---|
| M01 | 当前闭环目标、任务状态、主线/分支关系和当前位置 | M01 保存项目、闭环和路径结构 |
| M05 | 单子（新点 + 选中的子句 + 路线动作）与本闭环目标；主线/分叉决定、分叉范围、返回条件和下一目标 | M05 拥有前方路线规划，不拥有诊断或会话结构 |
| M02 | 已实施的讲解、追问、提示、反馈及学习者对话表达 | M02 拥有教学互动，不拥有诊断结论 |
| M03 | 练习条件、提示条件、学习者答案、步骤、理由和其他可观察表现 | M03 拥有练习活动，不拥有掌握判断 |
| M08 | 点与子句及来源（混淆 / 对比不存，用时当场判断） | M08 拥有通用知识结构 |
| M09 | 以前已结束闭环形成的个人知识、丰富理解、个人结构、时间版本和证据引用 | M09 只提供异步跨闭环背景，不能覆盖本次证据 |
| M10 | 当前采用的学习策略、提示强度、挑战程度、节奏和活动条件 | M10 拥有策略模型与活动条件，M04 根据后续表现判断结果 |
| 跨模块过程记录 | 必要的历史过程位置、原始证据引用、异常和降级信息 | M13 暂作技术设计参考，不作为独立业务模块 |

输出见 M04 审查单「输入输出」。

### 边界

- M02、M03、M04、M10 是不同职责，不构成固定线性步骤或一个封闭的大循环。
- M04 判断当前理解、困难、证据是否充分以及是否合上；M10 接收诊断与学习者状态，形成学习策略和活动强度条件；M02/M03 形成面向学习者的教学内容和活动；M05 在闭环之外规划前方路线。
- 一个 M01 学习会话承载一个学习闭环目标。M04 判断合上后，通知 M01 结束并保存该会话；M01 管理生命周期和路线位置，不替代 M04 作掌握判断。
- 主线、分叉和迂回路径都可能产生有效诊断信息。M04 读取并综合与当前闭环有关的信息，需要时向 M05 提供改线依据；M05 决定是否转向、分叉范围和返回条件，M01 保存并显示路线结构。M10 不拥有路线守卫。
