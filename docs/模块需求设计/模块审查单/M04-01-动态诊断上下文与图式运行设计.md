# M04-01 动态诊断上下文与图式运行设计

> 定位：M04 的“上下文工程 + 图工程”后续技术设计备忘，不是新的产品模块，也不改变已确认的产品职责。
>
> 状态：暂记。当前只记录已经讨论清楚的设计方向和下一轮必须研究的问题，不提前确定 Agent 数量、图节点、缓存结构、模型提示词或具体框架。

## 已确认的运行边界

- M04 贯穿一个进行中的学习闭环，不是一次回合结束后才运行的旁路判断。
- M04 随 M02/M03 的教学互动和学习者表现持续更新判断。M02、M03、M04、M10 是图中的不同职责，不构成固定线性步骤或一个封闭的大循环。
- M04 负责判断当前理解、困难、证据是否充分以及闭环目标是否完成；M10 接收诊断与学习者状态，形成学习策略和活动强度条件；M02/M03 负责形成真正面向学习者的教学内容和活动；M05 在闭环之外规划前方路线。
- M04 的判断过程默认不直接展示给学习者。面向学习者的表达由 M02/M03 生成；需要复盘或审查的过程由 M13 提供分级视图。
- 一个 M01 学习会话承载一个学习闭环目标。M04 判断完成后，通知 M01 结束并保存该会话；M01 管理生命周期和路线位置，不替代 M04 作掌握判断。
- 主线、分叉和迂回路径都可能产生有效诊断信息。M04 读取并综合与当前闭环有关的信息，并在需要时向 M05 提供改线依据；M05 决定是否转向、分叉范围和返回条件，M01 保存并显示路线结构。M10 不拥有路线守卫，只在当前闭环中输出策略和活动条件。

## M04 所需上下文的来源

M04 可以在一个进行中闭环内维护上下文缓存，但缓存不改变原始信息的模块归属。至少需要区分以下来源：

| 来源 | 提供给 M04 的主要信息 | 所有权边界 |
|---|---|---|
| M01 | 当前闭环目标、验收范围、任务状态、主线/分支关系和当前位置 | M01 保存项目、闭环和路径结构 |
| M05 | 当前主线/分叉决定、分叉范围、返回条件和下一目标 | M05 拥有前方路线规划，不拥有诊断或会话结构 |
| M02 | 已实施的讲解、追问、提示、反馈及学习者对话表达 | M02 拥有教学互动，不拥有诊断结论 |
| M03 | 练习条件、提示条件、学习者答案、步骤、理由和其他可观察表现 | M03 拥有练习活动，不拥有掌握判断 |
| M08 | 概念、方法、前置、组成、混淆和其他通用知识关系及来源 | M08 拥有通用知识结构 |
| M09 | 以前已结束闭环形成的个人知识、丰富理解、个人结构、时间版本和证据引用 | M09 只提供异步跨闭环背景，不能覆盖本次证据 |
| M10 | 当前采用的学习策略、提示强度、挑战程度、节奏和活动条件 | M10 拥有策略模型与活动条件，M04 根据后续表现判断结果 |
| 跨模块过程记录 | 必要的历史过程位置、原始证据引用、异常和降级信息 | M13 暂作为后续技术设计参考，不作为独立业务模块 |

## 上下文分类要求

下一轮设计不能把全部信息合并成一段无类型聊天文本。进入 M04 的信息至少需要区分：

- 当前目标、验收范围和闭环边界；
- 当前路径位置及其与主线、分叉、迂回路径的关系；
- 学习者原始表达和行为表现；
- 教学系统已经提供的讲解、提示、答案暴露和脚手架；
- 练习任务、完成条件及独立程度；
- M04 已形成但仍可推翻的中间判断和替代解释；
- M08 提供的通用知识依据及来源；
- M09 提供的已结束个人知识记录、时间版本及适用范围；
- M10 的策略上下文；
- 信息缺失、工具失败、模型降级和其他会影响判断质量的限制。

同一个正确答案在独立完成、轻微提示、多次提示或答案已经暴露等条件下具有不同证据意义，因此诊断不能脱离教学和练习条件只读取最终结果。

## 上下文缓存的基本要求

- 缓存服务于当前进行中的学习闭环，使 M04 能跨多轮持续修正诊断，而不是每轮从零判断。
- 缓存需要保留信息类型、来源模块、原始位置、时间、适用范围和是否仍有效。
- 中间诊断可以进入当前闭环的工作缓存，并被后续证据支持、修改或推翻，但在闭环结束前不得写成 M09 的稳定个人状态，也不得晋升为 M08 的正式通用知识。
- 摘要或压缩结果必须能够回到原始证据核实，不能让压缩后的模型描述替代原始事实。
- 主线、分叉和迂回路径的信息需要保留关系，避免不同任务、不同提示条件或无关旁支相互污染。
- 上下文不完整或关键来源不可用时，M04 必须把限制纳入判断，必要时输出证据不足，不能伪装成完整诊断。

## 后续图式运行设计问题

以下内容留到产品模块边界确认后再设计：

1. M04 是一个诊断子图、多个判断节点，还是由多个受限 Agent 协作。
2. M02、M03、M04、M10 之间如何以图关系路由、回流、分叉、暂停、恢复和等待学习者输入，而不预设固定循环顺序。
3. 哪些上下文常驻当前闭环缓存，哪些按需从原模块读取，哪些只保留引用。
4. 上下文类型、优先级、完整度和冲突如何表达与校验。
5. 如何区分原始观测、模块事实、中间推断、替代解释和最终结论。
6. M04 的改线依据、M05 的分叉决定、M01 的新会话，以及 M10 的策略和活动条件如何通过类型化交接协作。
7. 闭环结束时如何冻结本轮工作状态，并按 M01、M08、M09、M13 各自契约生成不同输出。
8. 使用何种图运行框架、检查点、缓存、存储、提示词、模型和失败恢复机制。
