# M14 高阶学习与知识产出

### 模块解决的核心问题

保存并迭代学习者自己的知识产出物：一篇研究、写作或内容编制成品从草稿到定稿的对象、版本链、修订比较、来源引用位置和编辑恢复位置。M14 不是第二套教学、练习、诊断或规划模块，也不保存通用知识；它是专属于本人的产出物容器，与 M08 的去个人化通用知识、M09 的已结束闭环个人知识形成记录并列而不重叠。

重要证据限制：六份“学术补充理论”是文献索引和理论方向，不是已确认的产品需求。`DeepTutor 书籍功能.md` 本轮重新定性为**外部产品观察**（`项目定位与资产地图.md` 将 `docs/DeepTutor/` 与 `docs/实际使用/` 归为同一档：“是需求来源，不是实现说明”），不能作为本项目的历史能力依据。因此本单主干由产品负责人在第三次重构中直接确立，不再挂靠历史构想。

### 输入、主要处理和输出

- 输入：M07 的多份资料、来源与出处位置；M08 的通用概念/方法对象与关系；M01 的项目归属、会话位置和已保存过程记录；M04 的理解与掌握判断（已结束闭环形成的相关个人知识经 M04 读取，M14 不直读 M09）；学习者提出的研究问题、写作意图与已有成果。
- 主要处理：建立产出物对象；保存草稿及其版本链，记录每版改了什么并支持版本比较；维护回到 M07 来源和 M08 对象的引用位置；保存编辑与恢复位置；围绕特定研究问题组织文献关系、方法比较和暂时论证；把可去个人化的结果整理为 M08 候选。
- 输出：可继续编辑的知识产出物及其版本链与修订差异、来源/对象引用位置、围绕研究问题的文献与方法结构、面向 M08 候选审计通道的高阶候选材料。M14 不输出教学表达、练习任务、诊断结论、掌握判断、跨闭环路线或学习者状态解释。

### 已退回已确认模块的功能（本单不再拥有）

上一版 M14 列过的下列能力，经与已确认模块比对后全部退回，M14 只在产出物侧接收其结果：

- 深度阅读路径 → 讲解/追问归 M02，复述/批注等学习者表现归 M03，理解判断归 M04，阅读顺序与路线归 M05，会话归属归 M01。
- 长周期研究过程（计划、监控、调节、反思、子目标、暂存/重开）→ 归 M05（三项主干与阶段复盘、停车场）与 M01（任务状态与搁置/恢复）。`M05` 已明确“长期项目的任务容器仍归 M01”。
- 论证与批判性评估的**反馈输出** → 归 M02 教学反馈（主干，指向知识、逻辑或过程）。M14 只保存论证对象本身及其版本。
- 解释与写作迭代中的**反馈** → 归 M02；其中“修订与版本比较”留在 M14，即本单“版本链与修订比较”。
- 长期研究项目形态 → 归 M01 项目模板的既有候选（考试、课程、研究等项目形态）。

### 重复内容合并后的结论

- 六份学术补充理论不是六个模块，也不能合并成 M14 的五类内部能力。上一版“合并为五类”的说法与事实不符：维度2（抽象建构与多层概念理解）在那次合并中被漏掉，而它在旧资料中是优先级第 1。维度2 的归属本轮已确定：表征转换归 M02，阶段性表述与“哪些概念是阈值概念”的标记归 M08，均不在 M14。
- 解释、写作、推导、实验既可能是 M03 的学习活动，也可能形成 M14 的成品。以主要产出区分：用于验证能力的当次任务归 M03，其长期可迭代的成品与版本归 M14，判断归 M04。
- M14 的知识结果不直接进入 M08，与 M09 共用同一条候选审计通道（M08 输入清单已包含“M14 的高阶候选”）。
- 产出物跨多个学习闭环存在，但它本身不是闭环，也不产生闭环判断；闭环的开始与结束仍由 M04 判断、M01 保存。

### 被后续资料覆盖的旧结论

- 早期“高层网络/上升学习”等抽象愿景被后续理论拆解；不能继续用抽象层名替代可审查功能。
- `DeepTutor 书籍功能.md` 中实时生成、自动评分、智能补弱、具体内容块和接口不是当前需求；本轮进一步把该资料整体降为外部产品观察。
- 六份学术补充文件自述为“文献索引”，只能证明理论来源，不证明产品功能已验证。
- 上一版输入清单中的“M09 状态”和“M04 的论证诊断”都是过期表述：状态已归 M15，M09 只保存已结束闭环形成的个人知识；M04 的产物是理解与掌握判断、错误归因，没有“论证诊断”这一项。
- 上一版“M14 是否独立需产品负责人确认”已确认：M14 作为知识产出物模块保留；长期研究项目的任务容器仍归 M01。

### 与其他模块的边界和信息流

- M01 <-> M14：M01 管项目/会话/闭环的生命周期、归属和过程记录，长期研究项目属于 M01 项目模板的形态之一；M14 只拥有产出物对象、版本链和引用位置，不管理任务生命周期。
- M05 -> M14：M05 规划下一步、优先级、复检和长周期节奏调节；M14 保存产出物内部的开放问题演进，不做跨闭环路线决定。
- M07 -> M14：M07 提供原文、出处和静态互补/矛盾；M14 的引用必须回到 M07 位置，不改写 M07 内容，也不把一次性产出物写进 M07。
- M08 <-> M14：M08 提供通用概念/方法对象与关系；M14 的高阶结果去个人化后经 M08 候选审计通道提交，不直接写入 M08。研究中的暂时论证按 M08 已确认分工留在 M14。
- M02/M03/M04 -> M14：M02/M03 组织讲解与独立产出、M04 形成理解判断；M14 只接收其中可沉淀为成品的阅读、解释、实验和写作结果，不承担教学表达、练习生命周期或判断。
- M10 -> M14：M10 为高阶任务选择策略与强度条件；M14 不拥有策略。
- M15 -> M04/M05/M10：学习者负荷、情绪、疲劳和现实限制由 M15 拥有并由 M04/M05/M10 消费；M14 不解释状态，也不因产出物进度推断状态。
- 跨模块过程记录保存运行过程和审查链（M13 暂作设计参考）；M14 保存用户真正要继续编辑和交付的知识产物。

## 产品负责人审查问题

1. 产品是否要帮助“形成研究问题并判断研究价值”，还是只负责外化材料、比较与反馈，把价值判断完全留给学习者？（对应上表“研究问题形成”候选档）
2. 围绕研究问题的暂时论证在什么时机从 M14 移交 M08 候选通道：学习者手动提交，还是产出物定稿时？
3. 版本链是否需要向学习者呈现“每版改了什么”的差异视图，还是只保留可回退的版本顺序？
4. 产出物能否独立于任何 M01 项目存在，还是必须挂在一个项目之下？
