# M05 学习导航与计划

> 状态：已精简（2026-10-05，#24），原文见 `../撤下原文/审查单精简前/`。技术实现见 `../../Harness设计/03-运行设计.md`「M05」。闭环怎么定义见产品总览「闭环定义」，本单只用“本闭环的新点 / 出发点 / 目标层次”“合上”这些词。

### 核心问题

M05 位于单个学习会话和学习闭环之外，负责多个会话/闭环之间的前方路线。每个学习会话承载一个独立学习闭环；M05 把项目目标、已经结束的个人知识形成结果、M08 的通用结构，以及 M04 在进行中闭环形成的路线相关判断，转成下一学习目标、会话之间的先后关系、主线/分叉选择和返回条件。系统核心是学习导航，诊断是输入，不是最终产品交付。

M05 规划“接下来进入哪个学习闭环、多个闭环怎样衔接、沿哪条路线走”。M04 和 M10 在一个进行中的学习会话内分别负责诊断判断与学习策略；M05 不负责当前一轮具体怎样教，也不替代 M04 作闭环判断或写入 M09。

### 功能

路线主干是三项：核心任务与优先级、下一学习闭环与路线动作、分叉范围与返回条件；复习、复检、补学、停车场、状态与负荷、阶段复盘、日程提醒均建立在这三项之上，作为可分别设计的二级子模块。

| 功能 | 产品结论 | 级别 |
|---|---|---|
| 核心任务与优先级 | 从项目目标和标准反推当前注意力，区分核心目标、实现手段和非当前事项，并在多个可选闭环之间确定先后。 | 主干 |
| 下一学习闭环与路线动作 | 根据项目目标、通用知识结构、已结束个人记录和当前改线依据，选择下一闭环，并决定继续主线、补前置、开分叉、返回主线或搁置。具体教学动作由 M10/M02/M03 决定。**闭环之间的关系不另立类型**：闭环锚定在 M08 对象上，相邻 = 前置 / 推导 / 组成边，同级类比 = 跨领域结构映射，无连接即独立；M05 在 M08 结构上结合 M09 知识面选。**学习者统一拍板**：诊断记录里冒出的问题、M05 设计时的候选、知识面上的相邻格汇总成一张候选单，每条注明从哪来，闭环结束或学习者要分支时给学习者看、由学习者选；默认以相邻为主、同级类比少量。**跨领域闭环按 M09 分两种**：学习者还没学过对面的知识 → 补习型（由原问题驱动的最小闭环，只学到原闭环需要的程度，最后一步是回去解原问题，然后返回）；已会 → 对比链接型（为加深理解对照两边结构，深度在结构 / 迁移级）。两种都按学习者意愿开，动机取原问题、可按历史发生顺序讲（非灌输），不限学科（产品负责人 2026-09-27 确认，P-02）。 | 主干 |
| 分叉范围与返回条件 | 为补前置或旁支闭环设定目标、范围、允许深度、停止条件和返回主线条件。M04 在会话内提供改线依据，M05 决定会话之间的路线变化，M01 负责落实和保存。 | 主干 |
| 冷启动的首个闭环 | 项目刚开始（M09 空、目标面粗）时，**第一个闭环刻意选小的：新点离已会的出发点近、内容量小，确保一次会话内能完成**，先让学习者拿到一次完整闭环体验；之后按正常口径设计。**收窄只管内容量，不压低深度**：学习者自述基础好、要深入时，深度按自述定（2026-09-24，依据 me-3）。（产品负责人 2026-09-23 确认；代价是首个闭环可能偏简单） | 第二梯队 |
| 出发点与新点的写法 | 闭环目标写成**本闭环的新点与出发点**（定义见产品总览「闭环定义」）：新点（锚在 M08 上，写成知识本身，不写成题目）＋这次用的几个出发点（已会的点，注明来源 M09 / 自述 / 假定）＋目标层次（怎么写待定，见 `../../Harness设计/待确认项.md` B1）＋对应的教材小节。出发点按什么从 M08 选、彼此先后以什么为准：待定（见 `../../Harness设计/待确认项.md` B2）。**怎么选**：选对这位学习者的水平与目标有分量的新点；已会的只作出发点，不再学一遍；顺序参考教材路线；出发点缺得多就先学出发点，不设考前置的环节；停车场里未合上的闭环，看它缺在哪个出发点，决定接着学还是先补出发点。**大小**：一次坐下来能走完。M05 只选出发点与新点，不写要教会的要点清单或证据条件：闭环内怎么讲、怎么练由 M02 / M03 / M10 决定，是否合上由 M04 闭环守卫判断。选定的出发点与新点对学习者可见、可改。（2026-09-28 产品负责人确认的选段写法，10-05 按 10-02 闭环定义改写；依据 me-8：按“主张 + 证据”写的验收范围把闭环变成取证过程；me-9：按链选段（09-28 定义）选到了重点，见 `../../Harness设计/_research/原型实验-9-发现.md`；旧写法下验证过的做法见 `../../设计资产/`） | 主干 |
| 路线偏差记录 | 记录每个闭环选定的出发点与新点、M04 在会话中报出的改线依据、M05 最终的调整（开分叉补前置 / 缩范围 / 维持），供设计后续闭环时参考；与 M10 的个人策略过程层对称，是 M05 自有记录，不写 M09。**只记计划偏差的事实，不形成对学习者的水平或能力结论**（D-08）；偏差若源于 M08 缺前置边等通用结构问题，经 M04 闭环总结进 M09、再按候选通道修正 M08，M05 不直接改 M08。（2026-09-23） | 主干 |
| 复习子模块 | 根据已结束闭环的形成记录、时间变化和当前目标，安排对已经形成内容的巩固路线；固定复习天数不构成需求。 | 第二梯队 |
| 复检子模块 | 对过去已经作出的掌握结论安排重新验证，并把复检作为独立闭环纳入路线；复检与复习目的不同。 | 第二梯队 |
| 补学子模块 | 对尚未形成、当前缺失或被证明为前置缺口的内容安排补学闭环，并处理它与原主线的返回关系。 | 第二梯队 |
| 停车场与未完成负债 | 将非当前闭环可靠搁置并保留后续安排，识别长期堆积并给出收束或降载建议。**可靠搁置 = 带具体恢复计划**（何时、从哪接上）：为未完成目标定下具体计划可消除它对注意的干扰（Masicampo & Baumeister 2011）。实际生命周期和恢复位置由 M01 保存。**会话内学习者学不动时，按闭环大小处理，不临时缩小闭环（不换更小的新点、不降目标层次）**：最小闭环没有可动空间 → 就地停下，即可靠搁置（记离开时间与接续点，回来后先回忆再接上，见 M02「离开与接续」）；父闭环（暂缓设计，见 `../暂缓设计/M05-闭环组合与晋级.md`）有可动空间 → M05 可切到其中另一个更轻的子闭环。轻度疲劳由 M10 在闭环内处理（降强度 / 改讲授）。切换前须经 M04 区分“学习者累了”与“内容太难 / 讲得不清”，后者走补前置或换讲法（产品负责人 2026-09-27 确认，依据 me-6，D-011）。 | 第二梯队 |
| 状态输入、认知负荷预算与任务限流 | M05 只读使用 M15 输出的状态与现实条件信息，据此调整跨会话路线、并行量和当前任务暴露；M05 不负责形成、保存或反向修改这些状态。理论依据（蔡格尼克、期末综合征、三系统疲劳）不能被包装成精确或医学化判断；四象限只作任务状态 / 弱先验，不把人固定分类或直接决定掌握；负荷分数和预算阈值不继承旧公式，保留读取状态结果、可解释调度和任务限流的需求。 | 第二梯队 |
| 阶段进展与复盘 | 综合阶段目标、已完成/未满足内容和关键连接，形成阶段回看及下一阶段路线建议，不用单一分数代替证据。 | 第二梯队 |
| 计划、日程与提醒 | 将路线中的学习闭环、复习、复检和长期任务映射为日程、提醒或计划安排。 | 第二梯队 |

### 输入输出

- 输入：M01 的项目目标、已有会话/闭环和路线状态；M08 的可学习对象与关系；M09 的已结束闭环、个人知识形成记录及时间历史；M04 在进行中闭环形成的诊断、未满足项及其他路线相关判断；期限、用户选择；以及 M15 学习者状态与条件输出的状态与现实条件信息（负荷、情绪、行动条件、现实约束）。
- 主要处理：从多个可能的学习闭环中选择当前和下一目标；确定闭环之间的主线、先后、依赖和分叉关系；决定继续、补前置、开分叉、搁置或返回主线；为目标与分叉设定范围和返回条件。
- 输出：当前/下一学习闭环目标、多个闭环之间的路线决定、主线或分叉关系、分叉边界与返回条件，以及本闭环的出发点与新点（含目标层次，见「出发点与新点的写法」），交 M01 建立、保存或调整相应会话结构。复习、复检、补学、停车场、限流、阶段复盘和日程计划是建立在该主干之上的二级输出。

### 边界

- M05 通常围绕同一学习项目规划相邻知识和多个独立闭环会话，但不设置固定的项目或学科跨度；跨学科内容只要服务当前目标，也可进入路线。
- M01 保存项目、会话、闭环之间的路线事实、生命周期和恢复位置；M05 在单个会话之外提出创建或调整会话的路线请求，经过后续统一安全审查后，由 M01 落实相应会话结构。安全审查可自动完成，不要求每次人工确认；它不是 M05 的产品职责。
- M05 可在会话进行中被触发（待拍板撤回，见 `../../Harness设计/待确认项.md` 1.4）。M04 向 M05 提供诊断、未满足项及其他路线相关判断，不按“小分叉”或某一种具体事件重新划分 M05 与 M10 的边界。
- 每个学习会话都是独立学习闭环。M05 负责多个闭环之间的计划；M04/M10 负责单个进行中闭环内的诊断与学习策略。M04 向 M05 提供路线规划所需的判断结果；M10 不负责形成 M05 的路线输入。
- M04 在进行中的会话内提供当前诊断、未满足项及其他路线相关判断；M05 决定这些判断是否改变多个闭环之间的计划。M05 选定出发点与新点，M04 在会话内判断是否合上，二者不冲突。
- M10 接收当前闭环的目标范围和必要条件，在会话内依据 M04 诊断及学习者状态选择学习策略，并向 M02/M03 输出活动倾向和强度要求；M10 不负责改线依据、跨会话路线或分叉会话。
- M02/M03 在 M10 当前策略下执行教学或练习活动，结果可触发 M04 更新诊断；M05 不直接讲解、出题或判掌握。
- 与 M07：M05 可使用资料适用性信息，但不拥有资料质量本体；资料质量评分不是必做能力。
- 与 M14：M05 管当前注意力和阶段计划，包括长周期研究本身的阶段推进路线；M14 只管产出物对象及其版本链。长期项目的任务容器仍归 M01。
- M08 → M05：阈值概念标记作为通用对象属性提供给 M05，用于优先级与路线安排；是否已跨过由 M04 判断。
- 与 M15：M05 只读使用 M15 的状态、认知负荷及现实条件信息服务跨会话规划，不负责形成、保存或反向修改状态。**承载读数**（当前负荷、可挂核心任务数、可承载连续时长、环境限制）可直接使用；**解释候选**（本次下降的状态解释）须以 M04 已裁决的版本为准，M05 不自行判断候选真假。
- 与 M15 的状态阶段：状态阶段判断跨会话子模块给出下降所属的阶段类型（习惯低谷、堆积型下滑、疲劳退化、阈值型动力低）及其判断跨度，只给读数、不给动作。**习惯低谷期内的持续性下降属预期内波动，不构成改道理由，也不因此加量**——改道会重置计时，使学习者永远到不了正反馈形成点。堆积型下滑对应限流与主动搁置，疲劳退化对应留出恢复期。承载条件以核心任务数量表达（同时不超过两个），而非时间表。
- **习惯低谷与阈值概念停滞不合并**：阈值概念停滞是知识侧、会话内，走 M04 → M10（本轮加强度，路线不动），M05 不参与；习惯低谷是状态侧、会话外，走 M15 → M05（不改道、不加量）。刻意不抽象成共用概念，避免会话内的判断影响会话外的路线决定。
- 与 M04 的阈值概念跨闭环子模块：M05 两个读数各读、在自己作用域内行动，不要求两侧合成单一「学习压力」量。M05 不改道而 M10 降载并非不一致——路线不动、本轮减压，正是预期结果。
- 旧系统中的右栏、工作台和固定页面不属于 M05 的职责定义，也不约束后续产品形态。
