# M05 学习导航与计划

### 核心问题

M05 位于单个学习会话和学习闭环之外，负责多个会话/闭环之间的前方路线。每个学习会话承载一个独立学习闭环；M05 把项目目标、已经结束的个人知识形成结果、M08 的通用结构，以及 M04 在进行中闭环形成的路线相关判断，转成下一学习目标、会话之间的先后关系、主线/分叉选择和返回条件。

M05 规划“接下来进入哪个学习闭环、多个闭环怎样衔接、沿哪条路线走”。M04 和 M10 在一个进行中的学习会话内分别负责诊断判断与学习策略；M05 不负责当前一轮具体怎样教，也不替代 M04 作闭环判断或写入 M09。

### 输入、主要处理与输出

- 输入：M01 的项目目标、已有会话/闭环和路线状态；M08 的可学习对象与关系；M09 的已结束闭环、个人知识形成记录及时间历史；M04 在进行中闭环形成的诊断、未满足项及其他路线相关判断；期限、用户选择；以及 M15 学习者状态与条件输出的心理、生理、负荷和现实条件信息。
- 主要处理：从多个可能的学习闭环中选择当前和下一目标；确定闭环之间的主线、先后、依赖和分叉关系；决定继续、补前置、开分叉、搁置或返回主线；为目标与分叉设定范围和返回条件。
- 输出：当前/下一学习闭环目标、多个闭环之间的路线决定、主线或分叉关系、分叉边界与返回条件，以及目标的计划范围和验收范围，交 M01 建立、保存或调整相应会话结构。复习、复检、补学、停车场、限流、阶段复盘和日程计划是建立在该主干之上的二级输出。

### 重复合并后的结论

- M05 的主干只有三部分：跨闭环的核心目标与优先级、下一学习闭环与路线动作、分叉范围与返回条件。复习、复检、补学、停车场、状态与负荷、阶段复盘、日程提醒均建立在这三项能力之上，作为可分别设计的二级子模块。
- M05 位于单个会话之外，负责多个独立闭环会话之间的路线；M04 和 M10 位于进行中的会话内，分别负责诊断判断和当前学习策略。M04 向 M05 提供路线规划所需的判断结果；M10 不负责形成 M05 的路线输入。
- 蔡格尼克、期末综合征和三系统疲劳描述同一因果链的不同部分。完整产品需要利用心理、生理、负荷和任务状态调整计划，但理论依据不能被包装成精确或医学化判断。
- 旧系统中的右栏、工作台和固定页面只证明曾存在一种呈现方式，不属于 M05 的模块职责定义，也不约束后续产品形态。

### 被后续资料覆盖的旧结论

- 系统核心已从“孤立诊断”修正为“学习导航”；诊断是输入，不是最终产品交付。
- v0.3 将四象限明确限定为任务状态/弱先验，不能把人固定分类或直接决定掌握；这不否定 M05 为路线规划读取和使用心理、生理及负荷状态的必要性。
- 固定复习天数、负荷分数和预算阈值只是历史实现；保留读取状态结果、可解释调度和任务限流的需求，不继承旧公式。
- 早期资料质量评分被取消为必做能力；M05 可使用资料适用性信息，但不拥有资料质量本体。

### 边界和信息流

- M01 保存项目、会话、闭环之间的路线事实、生命周期和恢复位置；M05 在单个会话之外提出创建或调整会话的路线请求，经过后续统一安全审查后，由 M01 落实相应会话结构。安全审查不是 M05 的产品职责。
- M04 在进行中的会话内提供当前诊断、未满足项及其他路线相关判断；M05 决定这些判断是否改变多个闭环之间的计划。M05 设定目标及其验收范围，M04 在会话内判断证据是否满足该范围，二者不冲突。
- M10 接收当前闭环的目标范围和必要条件，在会话内依据 M04 诊断及学习者状态选择学习策略，并向 M02/M03 输出活动倾向和强度要求；M10 不负责改线依据、跨会话路线或分叉会话。
- M02/M03 在 M10 当前策略下执行教学或练习活动，结果可触发 M04 更新诊断；M05 不直接讲解、出题或判掌握。
- 与 M14：M05 管当前注意力和阶段计划，包括长周期研究本身的阶段推进路线（M14 本轮已把这一项退回 M05 + M01）；M14 只管产出物对象及其版本链。长期项目的任务容器仍归 M01。
- M08 -> M05：阈值概念标记作为通用对象属性提供给 M05，用于优先级与路线安排；是否已跨过由 M04 判断。
- 与 M15：M15 向 M05 输出心理、生理、认知负荷及现实条件信息。M05 只读使用这些结果服务跨会话规划，不负责形成、保存或反向修改状态。M15 的输出分两型，M05 的用法不同：**承载读数**（当前负荷、可挂核心任务数、可承载连续时长、环境限制）可直接使用；**解释候选**（本次下降的状态解释）须以 M04 已裁决的版本为准，M05 不自行判断候选真假。
- 与 M15 的状态阶段：M15 的**状态阶段判断跨会话子模块**会给出下降所属的阶段类型（习惯低谷、堆积型下滑、疲劳退化、阈值型动力低）及其判断跨度，只给读数、不给动作。**习惯低谷期内的持续性下降属预期内波动，不构成改道理由，也不因此加量**——新节奏必然经过即时奖励已撤、长期正反馈尚未形成的窗口，此时改道会重置计时，使学习者永远到不了正反馈形成点。堆积型下滑对应限流与主动搁置，疲劳退化对应留出恢复期。承载条件以核心任务数量表达（同时不超过两个），而非时间表。
- **习惯低谷与阈值概念停滞不合并。** 两者都是“预期内下降、不该改道”，但级别不同、消费者不同：阈值概念停滞是知识侧、会话内，走 M04 → M10（本轮加强度，路线不动），M05 不参与；习惯低谷是状态侧、会话外，走 M15 → M05（不改道、不加量）。刻意不抽象成一个共用概念，避免会话内的判断经共用概念影响会话外的路线决定。
- 与 M04 的阈值概念跨闭环子模块：M04 侧另有一个与 M15 状态阶段对称的子模块，输出“某阈值概念跨了多少闭环仍未过”的读数。M05 两个读数各读、在自己作用域内行动，不要求两侧合成单一「学习压力」量。出现 M05 不改道而 M10 降载并非不一致——路线不动、本轮减压，正是预期结果。

## 本轮审查已确认

1. M05 通常围绕同一学习项目规划相邻知识和多个独立闭环会话，但不设置固定的项目或学科跨度；跨学科内容只要服务当前目标，也可进入路线。
2. M05 提出创建或调整会话的路线请求；请求经过后续统一安全审查后交给 M01，M01 负责真正建立和保存会话。安全审查可自动完成，不要求每次人工确认。
3. M05 可在会话进行中被触发。M04 向 M05 提供诊断、未满足项及其他路线相关判断，不按“小分叉”或某一种具体事件重新划分 M05 与 M10 的边界。
4. 每个学习会话都是独立学习闭环。M05 负责多个闭环之间的计划；M04/M10 负责单个进行中闭环内的诊断与学习策略。
5. M15 学习者状态与条件向 M05 输出心理、生理、负荷和现实条件信息；M05 只读使用，不负责形成、保存或反向修改状态。
