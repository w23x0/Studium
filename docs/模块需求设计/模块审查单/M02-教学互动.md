# M02 教学互动

### 核心问题

让系统在每一教学回合从学习者当前已知和当前卡点出发，以合适的信息量、深度、节奏和表达方式推动理解，而不是进行全知灌输或一次性倾倒答案。

### 输入、主要处理与输出

- 输入：M01 当前闭环目标和会话位置、M05 的路线约束、M10 当前策略和活动强度条件、M04 当前诊断、M08 的定义/前置/辨析点/逻辑链/可迁移结构、M07 的原文与出处位置、学习者表达。已结束闭环形成的个人理解经 M04 读取后进入本模块，M02 不直读 M09。
- 主要处理：理解本轮诉求与起点；从学习者当前理解位置组织讲解、追问、例子、表征转换、反馈和最小推动；在 M10 给出的策略目标和强度条件下推进当前目标；必要时发起练习活动。
- 输出：本轮教学回应、需要学习者回答/执行的下一动作、供 M04 观察的教学过程，以及供 M15 使用的可观察教学过程事实。M02 是单向输出：只提供教学表达与可观察事实，不写回知识层（M08/M09），也不形成诊断、掌握、路线或状态结论。

### 重复合并后的结论

- “回答、反问、推进、拦截、补资料、有限视角、多表征”合并为教学回合中的不同动作，不升级为平级模块。
- “先探起点、精准归因、理解诊断”有重叠：M02 负责以追问收集信息并据已给诊断组织表达，M04 负责形成可复核归因和理解结论。
- 多套理论均支持一步推进和功能性反馈，但它们是交互原则，不等于已确认的固定提示词、固定语气或自动策略。

### 被后续资料覆盖的旧结论

- 早期把所有回答、反问、出题、推进都放在单一 executor 中是历史实现，不应据此合并 M02/M03/M04。
- “LLM 是唯一诊断途径”、内部三层推理链、提示词重复加权、模型温度等不属于产品结论。
- 旧普通聊天/白纸前端形态已被“资料能力 + 学习监控”的后续方向覆盖；教学互动仍须围绕项目与闭环。

### 边界和信息流（专门检查 M02/M03）

- 判断主准则是主要产出，不是消息发送方向：解释一道题、给例子和提示属于 M02；要求学习者完成题目/证明/实验/复述并记录过程属于 M03。
- “系统出题”是交界：题目选择/生成及练习状态归 M03；题目前后的教学措辞、提示和对话衔接归 M02。
- M02/M03/M04/M10 是可回流、可分支的运行图中的不同职责，不构成固定串行步骤；M02/M03 的活动与产物均可触发 M04 更新诊断。
- M01/M05 决定活动服务哪个闭环目标和路线位置；M10 决定本轮学习策略及活动强度条件；M02 从学习者当前理解位置形成具体教学表达。
- M04 可给 M02 “当前卡点/替代解释”依据，但 M02 不应把友好反馈直接写成掌握结论。“补什么”属于 M10 的输入/练习倾向选择，不在本单：链条是 M04 诊断 -> M10 决定推什么 -> M02 负责表达。
- M10 拥有策略适用条件和选择理由；M02 只执行本轮表达。
- M08 -> M02：提供定义、别名与阶段性表述、资料定位、前置、辨析点、逻辑链和可迁移结构。M02 的讲解、辨析和多表征依赖这些内容，不自行认定通用知识；M02 的同步教学活动不能写回 M08。
- M07 -> M02：提供原文与出处位置，供讲解时定位与引用。
- M09 -> M04 -> M02：已结束闭环形成的个人理解经 M04 读取后作为诊断上下文进入本单；M02 不直读 M09，也不把 M09 结论当作本轮教学判断重用。
- M02 -> M15：提供可观察的教学过程事实（如反复卡在同一步、要求降低难度、主动中断）。这些是事实，不等于疲劳、焦虑或负荷结论；状态语义由 M15 形成。
- M02 -> M04：提供供观察的教学过程；诊断与掌握结论归 M04。
