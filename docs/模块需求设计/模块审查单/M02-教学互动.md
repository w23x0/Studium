# M02 教学互动

> 状态：已精简（2026-10-05，#24），原文见 `../撤下原文/审查单精简前/`。技术实现见 `../../Harness设计/03-运行设计.md`。闭环怎么定义见产品总览「闭环定义」，本单只用“本闭环的新点 / 出发点 / 目标层次”“合上”这些词。

### 核心问题

让系统在每一教学回合从学习者当前已知和当前卡点出发，以合适的信息量、深度、节奏和表达方式推动理解，而不是进行全知灌输或一次性倾倒答案。

### 功能

**职责分工**：诊断归 M04、策略归 M10、表达归 M02、练习归 M03；四者各有归属，不因运行上怎么调用而合并职责。每轮先形成诊断记录（观测 / 推断 / 替代解释 / 未满足项 / 本轮策略与强度 / 练习的验证意图），再形成给学习者的话；诊断记录单独保存，不放进给学习者的回复，但学习者可以查阅（横切原则 5）。闭环守卫独立核对，不读教学侧的诊断记录（见 M04）。

| 功能 | 产品结论 | 级别 |
|---|---|---|
| 本轮诉求与起点确认 | 回答前识别用户是在求解释、澄清、例子、反馈还是验证，并先探查卡点。 | 主干 |
| 理解 ↔ 训练 | 闭环内是**理解与训练的来回**（产品总览「闭环定义」“合上”行）：先理解（讲、推导），再让学习者用它自己推、自己用；用的时候暴露出的缺口，再回去讲。看懂 ≠ 理解，单靠输入不算合上。**学习者的输出是为了让理解完成，不是为了取证**：提问、给情境，是因为下一步怎么做取决于学习者会不会，也让学习者想清楚、用起来；问之前说清在问什么、为什么问；不按清单取证、不出谜题，也不另设收尾复述——训练中的输出本身就能说明理解到了什么程度（是否合上由 M04 守卫判断）。不把讲解拆成一连串编号小问题（2026-09-24，me-4）。训练的形态与出题归 M03。学习者好奇偏离时先接住，超出本闭环新点的记为下一闭环候选（产品总览「闭环定义」闭环间）。（2026-09-28，依据真人试用 me-5 ~ me-9，见 `../../Harness设计/_research/原型实验-9-发现.md`；纵深与题目深度见 `../../设计资产/`） | 主干 |
| 讲授形态 | 教学可以**成段讲授**，不拆成小问题；但一轮讲到第一个“下一步要看学习者怎么回答”的地方就停，不一次讲完，也不替学习者做完（学习者必须做事，稀缺的是学习者的注意力）。**质量下限是教材，兜底是直接引用教材原文**（给 M07 出处）；**上限不设**：系统知道学习者已站稳什么、这次从哪些出发点出发、它们和哪些已会的点相连，可以讲得比写给一般读者的教材更贴合（有限视角）。与教材说法不一致之处要说明，不把模型自己的说法当原文。讲清楚后接训练（「理解 ↔ 训练」）。“作答前不给答案”只管题目；脚手架只在卡住时用。何时讲授由 M10 定（信息量条件）。（产品负责人 2026-09-29 确认；依据 me-8 / me-9，均为单人单章，只支持“教材作下限与兜底”；“上限不设”来自产品总览「设计取向」） | 主干 |
| 离开与接续 | 学习者学不动时，尽量停在告一段落的地方、不停在推导中间，说清下次从哪接上，不再追加新问题（说停就停）。学习者离开一段时间后回来（离开时间由 M01 照实记）：离开较久时系统先用两三行说清**位置**（学到哪、停在哪一问），不说内容；再请其用一两句说出上次的关键结论，不先替其回顾；再补上没接上的部分后继续。这次回忆讲对了，是隔了一段时间的证据（M04 证据强度“含延迟”）。（产品负责人 2026-09-27 确认，依据 me-6；10-05 去掉“停靠点”，见清点 A15） | 主干 |
| 板书 | 系统维护一块板书，只记“是什么”：符号约定（每个符号指什么、正方向 / 参考系）、已推出的式子与结论（注明在哪一轮、谁推出的）、还悬着的问题；不记推理过程。有变化时才更新；学习者随时可看，回来续学时一起给出（原写“与位置图一起”，位置图暂缓，见 `../暂缓设计/组合层-学习位置图.md`）。符号约定写在一处，前后不改口。给学习者的话尽量短：一次只做一件事。（产品负责人 2026-09-27 同意试，依据 me-6） | 待实验 |
| 学习者表达的输入 | 学习者需要能连贯表达含公式的内容，纯文本框不够（me-3 / me-4）。语音、手写图片经**外接转写工具**转成文字后进入对话，教学只读文字；原件保留，转写文本标来源；诊断把“输入残缺 / 转写错误”列为替代解释，不当作学习者的错误。（产品负责人 2026-09-24 确认，工具后续接入） | 主干 |
| 有限视角讲解 | 只使用学习者已知或当前可承接的内容组织最小推动，避免从正确答案倒推学习者。“已知”以 M05 选定的出发点（及 M09 里已会的点）为起点，**并随闭环内学习者实际表现出的知识更新**：学习者主动用出且用对了未列入的内容，可以接着用，不因“按设定未学”把学习者挡回（2026-09-23）。 | 主干 |
| 追问与脚手架 | 学习者**卡住时**，通过单步追问、提示、辨析和逐步撤除帮助其自己继续，而非代替其完成；脚手架是卡住时的工具，不是默认教法（默认见「理解 ↔ 训练」，2026-09-24）。顺序参照 AutoTutor：先开放式追问（“还有呢”）→ 提示 → 具体引导问题 → 最后才由系统讲出。 | 主干 |
| 解释、示例与多表征 | 可用例子、反例、图示/语言转换、类比和复述引导形成表征；不能被练习替代。表征转换在本单，阶段性表述与阈值概念标记归 M08。 | 主干 |
| 教学反馈 | 对学习者已有表达给出指向知识、逻辑或过程的反馈，避免人格/价值评判；必要时明确不确定。 | 主干 |
| 信息量、深度与节奏执行 | 按 M10 当前策略及其信息量、提示强度、挑战程度和节奏条件，引导时一次只推进足够小的教学动作，讲授时成段讲一块（见「讲授形态」），并把学习者的新反应交回继续判断。四项强度参数归 M10，本单只执行。 | 主干 |
| 发起练习/验证动作 | 教学回合可提出复述、辨析、例题等下一动作，并把活动正式交接给 M03：一旦重点转为学习者独立产出，练习生命周期归 M03。M03 侧有对应的接收交接能力。 | 主干（定义性交界） |
| 教学风格可调 | 允许用户调节严格度、简洁度、主动追问和反馈方式；可调维度、默认值和是否暴露待产品确认。用户长期策略配置归 M10；本单只处理单回合口头调节。 | 候选 |

### 输入输出

- 输入：M01 当前闭环目标和会话位置、M05 的路线约束、M10 当前策略和活动强度条件、M04 当前诊断、M08 的定义/前置/辨析点/逻辑链/可迁移结构、M07 的原文与出处位置、学习者表达。已结束闭环形成的个人理解经 M04 读取后进入本模块，M02 不直读 M09。上下文怎么编排见 `../../Harness设计/03-运行设计.md`「教学调用」。
- 主要处理：理解本轮诉求与起点；从学习者当前理解位置组织讲解、追问、例子、表征转换、反馈和最小推动；在 M10 给出的策略目标和强度条件下推进当前目标；必要时发起练习活动。
- 输出：本轮教学回应、需要学习者回答/执行的下一动作、供 M04 观察的教学过程，以及供 M15 使用的可观察教学过程事实。M02 是单向输出：只提供教学表达与可观察事实，不写回知识层（M08/M09），也不形成诊断、掌握、路线或状态结论。

### 边界

- “回答、反问、推进、拦截、补资料、有限视角、多表征”是教学回合中的不同动作，不升级为平级模块；教学互动始终围绕项目与闭环。
- 一步推进、功能性反馈是交互原则，不等于已确认的固定提示词、固定语气或自动策略。
- 判断主准则是主要产出，不是消息发送方向：解释一道题、给例子和提示属于 M02；要求学习者完成题目/证明/实验/复述并记录过程属于 M03。
- “系统出题”是交界：题目选择/生成及练习状态归 M03；题目前后的教学措辞、提示和对话衔接归 M02。
- M02/M03/M04/M10 是可回流、可分支的不同职责，不构成固定串行步骤；M02/M03 的活动与产物均可触发 M04 更新诊断。
- M01/M05 决定活动服务哪个闭环目标和路线位置；M10 决定本轮学习策略及活动强度条件；M02 从学习者当前理解位置形成具体教学表达。
- M04 可给 M02 “当前卡点/替代解释”依据，但 M02 不应把友好反馈直接写成掌握结论。“先探起点”时 M02 以追问收集信息并据已给诊断组织表达，可复核的归因与理解结论归 M04。“补什么”属于 M10 的输入/练习倾向选择：M04 诊断 → M10 决定推什么 → M02 负责表达。
- M10 拥有策略适用条件和选择理由；M02 只执行本轮表达。
- M08 → M02：提供定义、别名与阶段性表述、资料定位、前置、辨析点、逻辑链和可迁移结构。M02 不自行认定通用知识；同步教学活动不能写回 M08。
- M07 → M02：提供原文与出处位置，供讲解时定位与引用。
- M09 → M04 → M02：已结束闭环形成的个人理解经 M04 读取后作为诊断上下文进入本单；M02 不直读 M09，也不把 M09 结论当作本轮教学判断重用。
- M02 → M15：提供可观察的教学过程事实（如反复卡在同一步、要求降低难度、主动中断）。这些是事实，不等于疲劳、焦虑或负荷结论；状态语义由 M15 形成。
- M02 → M04：提供供观察的教学过程；诊断与掌握结论归 M04。
