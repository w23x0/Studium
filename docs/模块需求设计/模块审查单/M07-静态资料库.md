# M07 静态资料库

### 核心问题

让已由 M06 入库、不会因某次学习表现而改变的资料和题目被长期组织、浏览、查找和引用，并向学习过程交付带来源与上下文的内容。M07 可以接收其他模块提供的、不会改写资料内容的通用检索标签与关联条件。

### 输入、主要处理与输出

- 输入：M06 交付的资源、项目对资料的选取关系、查找条件和学习问题；M08 及其他模块提供的、可复用且不属于个人的检索标签或关联条件；资料标签修正。
- 主要处理：组织全局唯一资料及项目选取视图；按 M06 已确认的原书/资料结构浏览；保存资料来源、原文位置、内容类型和通用标签；在整份与局部内容中按结构、文本、标签或问题查找，并保留必要上下文。
- 输出：可浏览资料目录、相关原文与上下文、引用位置、题目/证明/例子等资料项及其检索标签。它不输出个人掌握状态，不改写资料内容，也不直接决定如何教学。

### 重复内容合并后的结论

- “目录、书籍结构、内容分类、检索、引用”是多份 PRD/归档反复出现的同一主链，合并为“从全局唯一资料目录或项目选取视图进入资料，按结构、问题或标签找到内容，并回到原文”。
- 内容类型与概念/方法/前置/推导等都是检索条件，但来源不同：M06 产生资料结构和类型，M08 产生通用概念关系；M07 接收、保存并用于查找，且不改写资料正文。
- “覆盖、缺口、重复、互补、递进、矛盾、来源质量”不能合并为 M07 的独立判断能力。M07 可保存检索标签和比较线索；通用概念关系归 M08，个人学习变化归 M09，围绕特定研究问题的比较、解释和论证归 M14。
- “正文、检索文本和增强标注分离”的产品含义仅保留为：用户看到的依据必须是可追溯原文，任何生成性说明须可区分、可复核。

### 被后续资料覆盖的旧结论

- 早期不做检索的范围决定已被 2026-07-01 文档推翻。
- v0.2 资料层的自动综合质量分、固定权威阈值和“保留高分、删除低分”不再是确认需求；v0.3 只保留资料管理与检索。资料可靠性可作为说明和审查依据，但不得伪装成客观分数。
- 后期知识库 PRD 选择“切片级跳转、相似度分数、父块展开”是当时界面决定；第三次重构应确认“可理解且精确的原文定位”，不继承具体分数、结果布局或分块形态。
- 线性代数实验只证明处理与检索链曾运行；EXP-001 至 EXP-005 均未开始，不能声称某种切片、检索或公式处理质量已验证最优。

### 与其他模块的信息流

- M06 -> M07：交付需要从外部文件/材料提取并已通过校核的资源。个人或人工编写、已经是可保存正文的笔记可直接进入 M07；若笔记仍需文件解析、结构识别或原文定位，则再走 M06。M07 -> M06：返回需重提取、重定位或重分类的问题。
- M01 <-> M07：M01 保存项目对全局资料的选取及项目关系；M07 提供全局资料目录和项目内选取视图。项目目标、关系和会话不归 M07。
- M07 -> M02/M03：提供讲解依据和练习素材；如何讲归 M02，练习活动和学习者表现归 M03。
- M07 -> M08：提供原文、资料结构、类型和来源，供形成概念/关系候选；M08 -> M07：提供概念、方法、前置、推导等通用检索标签或关联条件，用于结构化查找，但不改变原资料结构或正文。
- M07 -> M04/M05/M14：提供诊断核查、补资料、深度阅读和论证所需来源。
- M07 与 M09：M07 保存稳定资料及不属于个人掌握判断的检索标签；“该学习者如何理解/掌握它”只能在闭环结束后进入 M09，不能作为 M07 标签写回。个人或人工编写笔记可直接进入 M07，但必须标明作者/来源范围，不能默认作为通用权威知识。
- M02/M03/M04/M14 可提出可复用、非个人的资料标签或关联条件；个人学习表现、一次性过程记录和未确认推断不得改变 M07 的资料内容或写成静态标签。
- 后续上下文工程负责把 M07 结果按当前图节点需要组织给 Agent；M07 本身拥有资料、查找结果、出处和浏览体验。

## 产品负责人审查问题


1. 是否确认资料本体全局唯一、项目仅选取和重复调用资料；项目之间的关系由 M01 管理而非 M07？
2. 资料库是否需要同时面向用户浏览和 Agent 调取；两者的来源上下文最低要求是否相同？
3. 哪些模块可以向 M07 提交可复用的静态检索标签；标签是否都需显示来源、适用范围和确认状态？
4. 项目目标下的资料覆盖/缺口、跨资料的支持/矛盾比较，是否按“资料事实查询归 M07、通用关系归 M08、研究问题比较归 M14”的分工确认？
5. 是否保留任何面向用户的资料质量表达；若保留，应只展示分项依据还是允许人工结论？
6. 外部资料发现/推荐是否属于 M07 的完整产品边界，还是只管理用户已导入的资料？
