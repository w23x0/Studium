# M07 静态资料库

> 状态：已精简（2026-10-05，#24），原文见 `../撤下原文/审查单精简前/`。技术实现见 `../../Harness设计/03-运行设计.md`。

### 核心问题

让已由 M06 入库、不会因某次学习表现而改变的资料和题目被长期组织、浏览、查找和引用，并向学习过程交付带来源与上下文的内容。M07 可以接收其他模块提供的、不会改写资料内容的通用检索标签与关联条件。主链是：从全局唯一资料目录或项目选取视图进入资料，按结构、问题或标签找到内容，并回到原文。

### 功能

| 功能 | 产品结论 | 级别 |
| --- | --- | --- |
| 项目/资料目录 | 资料本体全局唯一；项目可选取并重复调用资料。M07 提供全局目录和项目选取视图，项目之间的关系、目标和生命周期归 M01。 | 主干 |
| 原资料结构浏览 | 按 M06 已确认的书/章/节/段落或相应媒体结构查阅资料，并查看上下文和邻近内容；M07 不重新识别或改写结构。学习资料不是无结构切片集合。 | 主干 |
| 搜索与学习过程调取 | 根据问题或条件找到相关资料内容，并保留足够上下文；供学习者浏览，也供 M02/M03/M14 取用。 | 主干 |
| 来源引用与原文跳转 | 每个结果保留资料、章节/页/段落等可理解位置，并可回到原文；引用粒度与实际可定位粒度一致；原文定位要“可理解且精确”，不继承具体分数、结果布局或分块形态。用户看到的依据必须是可追溯原文，任何生成性说明须可区分、可复核。 | 主干 |
| 内容类型、概念与练习资源标签浏览 | 可按定义、证明、动机、例题、练习、综述等内容类型，以及概念、方法、前置、推导等通用标签查找（待定：随 B2 改）。标签可由 M06 处理产生（资料结构和类型），也可由 M08（通用概念关系）或其他模块补充；M07 保存标签而不改写资料正文。题目本体归 M07，学习者实际完成题目及反馈链归 M03。不要求所有资料在入库时完成统一标准化分类。 | 主干 |
| 跨资料检索标签与重复线索 | 保存带来源和适用范围的通用标签/关联条件，支持找出同标签、同来源或高度相关的资料，作为重复、互补或进一步比较的检索线索；不在 M07 独立断言资料覆盖、缺口、矛盾或价值高低。 | 第二梯队 |
| 来源可靠性与适用性说明 | 展示作者/机构、时点、权利、适用阶段及已知限制；避免用一个综合分数替代判断，资料可靠性不得伪装成客观分数。 | 第二梯队 |
| 资料质量反馈与修正 | 用户可报告定位错误、正文问题、重复或错误标注，并触发回到 M06 修正，不直接改写来源。 | 第二梯队 |
| 跨来源探索与资料推荐 | 根据目标或当前资料缺口发现其他来源；推荐必须展示理由、来源和是否已入库。外部发现、推荐范围和可信度尚未形成稳定产品决定。 | 候选 |

### 输入输出

- 输入：M06 交付的资源、项目对资料的选取关系、查找条件和学习问题；M08 及其他模块提供的、可复用且不属于个人的检索标签或关联条件；资料标签修正。
- 主要处理：组织全局唯一资料及项目选取视图；按 M06 已确认的原书/资料结构浏览；保存资料来源、原文位置、内容类型和通用标签；在整份与局部内容中按结构、文本、标签或问题查找，并保留必要上下文。
- 输出：可浏览资料目录、相关原文与上下文、引用位置、题目/证明/例子等资料项及其检索标签。它不输出个人掌握状态，不改写资料内容，也不直接决定如何教学。

### 边界

- “覆盖、缺口、重复、互补、递进、矛盾、来源质量”不是 M07 的独立判断能力：M07 可保存检索标签和比较线索；通用概念关系归 M08，个人学习变化归 M09，围绕特定研究问题的比较、解释和论证归 M14。
- 不做自动综合质量分、固定权威阈值和“保留高分、删除低分”；不能声称某种切片、检索或公式处理质量已验证最优。
- M06 → M07：交付需要从外部文件/材料提取并已通过校核的资源。个人或人工编写、已经是可保存正文的笔记可直接进入 M07；若笔记仍需文件解析、结构识别或原文定位，则再走 M06。M07 → M06：返回需重提取、重定位或重分类的问题。
- M01 ↔ M07：M01 保存项目对全局资料的选取及项目关系；M07 提供全局资料目录和项目内选取视图。项目目标、关系和会话不归 M07。
- M07 → M02/M03：提供讲解依据和练习素材；如何讲归 M02，练习活动和学习者表现归 M03。
- M07 → M08：提供原文、资料结构、类型和来源，供形成概念/关系候选；M08 → M07：提供概念、方法、前置、推导等通用检索标签或关联条件，用于结构化查找，但不改变原资料结构或正文（待定：随 B2 改）。
- M07 → M04/M05/M14：提供诊断核查、补资料、深度阅读和论证所需来源。
- M07 与 M09：M07 保存稳定资料及不属于个人掌握判断的检索标签；“该学习者如何理解/掌握它”只能在闭环结束后进入 M09，不能作为 M07 标签写回。个人或人工编写笔记可直接进入 M07，但必须标明作者/来源范围，不能默认作为通用权威知识。
- M02/M03/M04/M14 可提出可复用、非个人的资料标签或关联条件；个人学习表现、一次性过程记录和未确认推断不得改变 M07 的资料内容或写成静态标签。
- M07 拥有资料、查找结果、出处和浏览体验；怎么把结果组织给调用见 `../../Harness设计/03-运行设计.md`。
