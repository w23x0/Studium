# M08 知识结构与概念关系

> 状态：已精简（2026-10-05，#24），原文见 `../撤下原文/审查单精简前/`。技术实现见 `../../Harness设计/03-运行设计.md`「M08 / M09」。闭环怎么定义见产品总览「闭环定义」。

### 核心问题

把 M07 中的资料、概念、方法和原文位置，整理成不属于某个学习者的通用知识模型。它先从资料形成可查找、可定位的基础概念、方法和关系；随后接收由多个已结束个人学习闭环、高阶研究或模型综合形成的候选，经隔离、审计和更正后增长出结构模型、思维框架和跨域迁移对象。M08 为学习规划、教学、诊断和高阶学习提供“知识本身是什么、怎样连接、可以怎样继续向上抽象”的依据，但不保存某个人的掌握过程。

这里的“通用”不等于永不变化：M08 可以被 M09 已结束闭环中产生的新细节、理解路径和高层结构反向补充，但只能经过候选与审查通道。M09 锚定 M08，却不是 M08 的个人覆盖图；M08 只保留去个人化、可复用的知识对象和结构。

**来源与增长（2026-09-18）**：M08 的**基础段复用书本结构**——书本是 M08 的**早期骨架**（“跟着书本的教学路线学”）；书本覆盖不到的**前沿段**（如工程目标），由**外部工具**（网络搜索 / 教材论坛 / 更强模型）补，经 **M06 → M07** 入库、**只到候选**（带锚点、不结案）。因此 M05 从知识边缘到目标的路径**不一定在 M08 里**，缺段靠外部补候选。不预建完整知识图谱：从选定的 M07 资料形成足够使用的基础网络，按学习需要、候选审计和更正持续增长，不追求一次穷尽全学科。

**M08/M09 交替递增**：M08 通常领先于当前学习范围，为 M05 提供可规划对象；M09 记录学习者在已结束闭环中真正形成的个人知识，再把 M08 尚未表达的细节或更高结构送入候选通道：

```text
M07 资料 → M08 当前通用对象与结构 → M05 制定学习路线 → 教学与诊断，M04 关闭闭环
→ M09 保存个人形成记录、证据边和时间版本 → 出现 M08 未表达的细节、路径或高层个人结构
→ 去个人化候选 → 审计/晋升 → M08 扩展后的通用结构 → 再进入下一轮规划与学习
```

### 功能

| 功能 | 产品结论 | 级别 |
| --- | --- | --- |
| 概念/方法目录与原文索引 | 形成可查找的通用概念、方法对象，并以主干标签连接 M07 正文位置和片段。对象不等同于章节或切片，是基础网络的节点和跨资料索引；既承载关系，也承担快速定位资料的作用。 | 主干 |
| 定义、别名与阶段性表述 | 保存人类可读定义、同名/异名和来源；同一对象可有不同阶段、表征或语境下的说明，并标注适用范围；定义不同、学习者可能只会其一的，拆成不同的点（产品总览「点按定义拆」）。M10 选择本轮教学表达，不另建一套概念。 | 主干 |
| 阈值概念标记 | 在通用对象上标记“该概念是否为阈值概念”，与难度一样属于对象属性，而不是学习者个人状态。判据取自阈值概念的四个性质：难以跨越（troublesome）、跨过后理解方式改变（transformative）、跨过后不易退回（irreversible）、跨过后多个零散内容被整合（integrative）。M08 只标记“它是”，不判断“某学习者是否跨过了”——后者由 M04 判断、M09 保存。标记后，M05 可优先安排、M10 可提高投入强度、M04 可预期此处的卡点是质变前兆而非普通错误。（产品负责人第三次重构直接决定；理论只提供概念与判据词汇） | 第二梯队 |
| 点与子句 | M08 的基本结构是**点 + 子句**。子句 = 会了这几个出发点，就能学会这个新点，预期学出什么理解；一条子句指向一个新点，一个新点可有多条子句；子句不属于某本书，标来源（书给的 / 模型补的）。子句是条件，对谁都成立；会不会、经哪条子句学会、实际学出的理解、书里没有的个人路线都在 M09，不进 M08。书给的子句是标准，但标准不代表个性化：给谁选哪条由 M05 依据 M09 判断。给模型读的派生写精简句子（点一句，子句一两句），关键词 / 公式只作程序粗筛索引，细节经锚点回原文。子句格式待定（`../../Harness设计/待确认项.md` B14）；混淆 / 对比 / 同级类比怎么表示待定（B13）。旧的关系种类写法见 `../撤下原文/M08-关系种类与旧粒度.md`。 | 主干 |
| 点与子句的生成 | 先生成、后回扫：模型先凭自身知识说出某主题有哪些点与子句，再对原文审核——找到原文支撑的标“书给的”，找不到的标“模型补的”（候选）；书有、清单没有的路线在回扫时补进来。来源性质必须如实标记，模型记忆不得伪装成原文。审核到什么程度见 B6；多本书怎么关联待定（B15）。 | 主干 |
| 高层结构候选 | 从多个基础概念、方法和 M09 已结束闭环中形成的个人结构材料里，提出可表达为方法、结构模型、思维框架、适用边界或迁移方向的候选。候选应说明它连接了什么、共同机制是什么、可支持何种后续学习。 | 核心方向，实验能力未定型 |
| 候选隔离、审计与晋升 | M09 已结束闭环、M14 高阶工作或模型综合产生的内容先进入独立候选区；记录来源闭环/资料、理由、适用条件、去个人化情况和更正历史。只有经过通用性、逻辑/资料依据和人工或自动审查，才晋升为 M08 正式结构。 | 主干 |
| 通用结构的更正与版本 | 学习者、教学活动和高阶研究可提出增补、连接或纠错；M08 保留依据和历史，不静默覆盖。M08 是可演化的通用模型，不是一次生成后冻结的图。 | 主干 |
| 结构浏览与关系解释 | 用户可查看点、子句、来源、状态和理由；基础实验可采用类似 Obsidian 的关系图，但图形界面只是查看方式，具体可视化不在需求阶段锁定。 | 第二梯队 |
| 跨来源/跨领域连接 | 提出并保存资料间、领域间的结构映射、推广、适用/实现和迁移关系（怎么表示待定，`../../Harness设计/待确认项.md` B13）；研究中的暂时论证先留在 M14。 | 候选 |

### 输入输出

- 输入：以 M07 的原文、资料结构、内容类型、概念/方法候选和来源位置为基础输入；同时接收从 M09 一个或多个已结束闭环中去个人化后形成的细节、理解路径、连接和高层结构候选，M14 的高阶候选以及学习者/人工更正。M02/M03 的同步活动和 M04 的中间诊断不能直接进入 M08；模型已有领域知识可以参与提出候选，但不能伪装成可定位的资料原文。
- 主要处理：建立概念/方法对象并连接 M07 原文；合并别名和不同表述；先生成后回扫，形成点与子句；在对象上标记阈值概念等通用属性；从多个基础对象中提出方法、结构模型、思维方式和迁移关系等更高抽象候选；保存其来源、适用条件、反例/争议、状态和更正历史。
- 输出：基础概念/方法网络及其原文索引，已进入通用库的结构模型和高层关系，对象的通用属性（含阈值概念标记），关系依据、适用范围与状态。候选区的内容与正式通用结构分离；个人掌握、个人混淆、个人偏好和个人工作模型不属于 M08 输出。

### 边界

- **粒度**：点按定义拆（产品总览「点按定义拆」）；信息量靠子句与指向原文的锚点；学习者会的细点按人合成簇，簇属于学习者，不存 M08（M09「知识边缘」）。旧写法（接地表示 + 链接、粒度 = 遍历深度）见 `../撤下原文/M08-关系种类与旧粒度.md`。
- 基础网络中的点与子句是基础层内容；基础层不等于高层网络。子句描述点怎样相连，方法、结构模型、思维框架和迁移方向描述这些连接被压缩后形成的更高抽象对象，两者不混为一类。
- M08 是可演化的通用知识模型（“知识网络、知识图谱、概念关联、概念依赖、结构感”统一于此）：包括基础概念/方法节点、原文索引、基础关系，以及经审计后进入库的高层结构；图形只是可能的表达方式。
- 高层网络不是预先规定的第二、第三层固定目录，而是把多个已形成连接压缩为可教学、可复用的结构（例如多个概念逐步组织成一个方法、一条逻辑链、一个解释模型、一个思维框架或一个迁移方向）；实际数据更接近可多分支、多复用的图，“层”只描述抽象深度和学习推进。高层结构再次成为可学习对象后，学习者可以再在 M09 中学习它，形成递归；当前只确认该方向，不承诺固定层数、自动生成质量或完整上升算法。
- “从资料抽取”“模型综合推理”“M09 已结束闭环反向增益”和“学习者/人工更正”都是候选来源，不是四套知识库；每一条内容必须标明来源性质，不能把模型记忆或个人经验伪装成原文引用。
- M08 与 M09 可以共同呈现为一张学习图（同一界面叠加查看），但数据归属必须分离：通用结构归 M08，个人掌握/困难归 M09，最新诊断证据归 M04；候选区是从个人/模型发现通往通用结构的独立审计通道。
- 产品只确认来源、适用范围、状态、可更正性和候选隔离需要可见；数值置信度、向量相似、固定关系表等属历史技术方案。
- 同步学习事件和 M04 中间诊断不能直接触发 M08 写入；M04 完成一个闭环判断后，M09 保存个人形成记录，它可以成为 M08 候选的材料，不能自动把个人结论写入 M08；只有闭环结束后由 M09 整理出的材料才可进入候选通道（单次学习事件确认关系会把个人错误过度泛化）。
- 高层结构生成、候选晋升和模块协同不能仅靠把固定工作流串接起来，也不能让模型无边界地决定目标、权限或正式写入。
- M07 → M08：交付原文、章节、内容类型、概念/方法候选和来源位置；M08 → M07：交付点与子句作为查找条件。M08 不改写原资料目录或正文。
- M08 → M04：提供点与子句（子句的出发点即前置）；混淆 / 对比待定（B13）；M04 仍须根据本次表现判断闭环、缺口和是否达到下一学习目标。
- M04 → M09：仅在闭环结束后提交符合 M09 结构的个人形成记录；M04 不直接向 M08 输出。M09 可把已结束闭环中 M08 未表达的细节、理解路径或高层个人结构整理成去个人化候选。
- M08/M09 → M05：M05 比较通用可学习结构与个人已形成知识，决定下一目标和路线；M10 在当前目标内依据 M04 诊断选择学习策略和活动条件。M08 不替代 M05 的规划、M04 的诊断或 M10 的策略选择。
- M08 → M02/M03：提供定义、资料定位、子句（出发点与预期理解）；辨析 / 对比待定（B13）；M02 负责教学互动，M03 负责练习活动与学习者产出。
- 独立候选/审计通道读取 M09 已结束闭环和必要证据引用，并向 M08 提交去个人化候选；它不是教学策略层，也不能绕过 M08 的状态和更正规则。
- M08 → M04/M05/M10：阈值概念标记作为通用对象属性提供给三方——M05 用于优先级与路线安排，M10 用于强度参数取值，M04 用于把该处的卡点理解为质变前兆。M08 不判断任何学习者是否已跨过该概念。
- M08 ↔ M14：M08 为知识产出物提供通用概念、方法和结构对象；M14 可就其研究问题提出跨资料/跨领域候选，走与 M09 相同的候选审计通道，不能直写 M08。围绕特定研究问题的暂时论证和个人工作模型作为产出物内容留在 M14；对论证的教学反馈归 M02。
