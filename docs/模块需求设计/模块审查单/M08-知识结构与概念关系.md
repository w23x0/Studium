# M08 知识结构与概念关系

### 核心问题

把 M07 中的资料、概念、方法和原文位置，整理成不属于某个学习者的通用知识模型。它先从资料形成可查找、可定位的基础概念、方法和关系；随后接收由多个已结束个人学习闭环、高阶研究或模型综合形成的候选，经隔离、审计和更正后增长出结构模型、思维框架和跨域迁移对象。M08 为学习规划、教学、诊断和高阶学习提供“知识本身是什么、怎样连接、可以怎样继续向上抽象”的依据，但不保存某个人的掌握过程。

这里的“通用”不等于永不变化：M08 可以被 M09 已结束闭环中产生的新细节、理解路径和高层结构反向补充，但只能经过候选与审查通道。M09 锚定 M08，却不是 M08 的个人覆盖图；M08 只保留去个人化、可复用的知识对象和结构。

### 输入、主要处理与输出

- 输入：以 M07 的原文、资料结构、内容类型、概念/方法候选和来源位置为基础输入；同时接收从 M09 一个或多个已结束闭环中去个人化后形成的细节、理解路径、连接和高层结构候选，M14 的高阶候选以及学习者/人工更正。M02/M03 的同步活动和 M04 的中间诊断不能直接进入 M08；模型已有领域知识可以参与提出候选，但不能伪装成可定位的资料原文。
- 主要处理：建立概念/方法对象并连接 M07 原文；合并别名和不同表述；组织上位/下位、组成、前置、推导、等价、对比/混淆等基础关系；在对象上标记阈值概念等通用属性；从多个基础对象中提出方法、结构模型、思维方式和迁移关系等更高抽象候选；保存其来源、适用条件、反例/争议、状态和更正历史。
- 输出：基础概念/方法网络及其原文索引，已进入通用库的结构模型和高层关系，对象的通用属性（含阈值概念标记），关系依据、适用范围与状态。候选区的内容与正式通用结构分离；个人掌握、个人混淆、个人偏好和个人工作模型不属于 M08 输出。

### M08/M09 的交替递增关系

M08 与 M09 不是两张互相替代的图。M08 通常领先于当前学习范围，为 M05 提供可规划对象；M09 记录学习者在已结束闭环中真正形成的个人知识，再把 M08 尚未表达的细节或更高结构送入候选通道：

```text
M07 资料 ──→ M08 当前通用对象与结构
                    ↓
             M05 制定学习路线
                    ↓
         图式教学与诊断运行，M04 关闭闭环
                    ↓
     M09 保存个人形成记录、证据边和时间版本
                    ↓
  M09 中出现 M08 未表达的细节、路径或高层个人结构
                    ↓
     去个人化候选 ──→ 审计/晋升 ──→ M08 扩展后的通用结构
                                             ↓
                                      再进入下一轮规划与学习
```

- 基础网络中的概念节点、节点间的上位/下位、组成、前置、推导等，都是基础层内容；“概念层级与组成”不等于高层网络。
- 高层网络不是预先规定的第二、第三层固定目录，而是把多个已形成连接压缩为可教学、可复用的结构。例如多个概念可逐步组织成一个方法、一条逻辑链、一个解释模型、一个思维框架或一个迁移方向。
- M04 完成一个概念或结构的学习闭环判断后，M09 保存该学习者的个人形成记录；它可以成为 M08 候选的材料，不能自动把个人结论写入 M08。
- 高层结构再次成为 M08 中可学习的对象后，学习者可以再在 M09 中学习它，形成继续向上抽象的递归过程。当前产品只确认该方向，不承诺固定层数、自动生成质量或完整上升算法。

### 重复内容合并后的结论

- “知识网络、知识图谱、概念关联、概念依赖、结构感”统一为可演化的通用知识模型：它包括基础概念/方法节点、原文索引、基础关系，以及经审计后进入库的高层结构。图形只是可能的表达方式。
- 基础关系和高层结构不能混为一类。前置、推导、组成、等价、混淆等主要描述基础节点怎样相连；方法、结构模型、思维框架和迁移方向描述这些连接被压缩后形成的更高抽象对象。
- “从资料抽取”“模型综合推理”“M09 已结束闭环反向增益”和“学习者/人工更正”都是候选来源，不是四套知识库。每一条内容必须标明来源性质，不能把模型记忆或个人经验伪装成原文引用。
- M08 与 M09 可以共同呈现为一张学习图，但数据归属必须分离：M08 是通用对象抽象图；M09 是锚定这些对象的个人形成记录、个人结构和证据边；候选区是从个人/模型发现通往通用结构的独立审计通道。
- 高层网络是递归增长方向，不是当前就承诺的三层或四层树塔。实际数据更接近可多分支、多复用的图；“层”只描述抽象深度和学习推进，不应写死为固定结构。

### 被后续资料覆盖或需降格的旧结论

- 完整预建知识图谱被 `知识网络层.md` 明确否定；当前结论不是“不建基础网络”，而是从选定的 M07 资料形成足够使用的基础网络，并按学习需要、候选审计和更正持续增长，不追求一次穷尽全学科。
- 同一文档文首的 v0.3 修正曾把最基础版缩为只做 RAG、不建概念/关系表。这是当时范围收缩，不足以否定第三次重构已经重新提出的 M08 产品问题；也证明高层网络未被实现或验证。
- 旧“学习监控图谱”把闭环、掌握度和概念关联混在一张图中。第三次重构必须拆分：通用结构归 M08，个人掌握/困难归 M09，最新诊断证据归 M04；需要时可在同一界面叠加查看。
- 旧设计中的数值置信度、向量相似、固定关系表、动态推理步骤和图数据库选型都只属历史技术方案。产品只确认来源、适用范围、状态、可更正性和候选隔离需要可见。
- “单次学习事件确认前置关系”可能把个人错误过度泛化。同步学习事件和 M04 中间诊断不能直接触发 M08 写入；只有闭环结束后由 M09 整理出的材料才可进入候选通道。

### 与其他模块的信息流及专项边界

- M07 -> M08：交付原文、章节、内容类型、概念/方法候选和来源位置；M08 -> M07：交付通用概念、方法和关系作为查找条件。M08 不改写原资料目录或正文。
- M08 -> M04：提供通用前置、组成、混淆、方法和结构关系；M04 仍须根据本次表现判断闭环、缺口和是否达到下一学习目标。
- M04 -> M09：仅在闭环结束后提交符合 M09 结构的个人形成记录；M04 不直接向 M08 输出。M09 可把已结束闭环中 M08 未表达的细节、理解路径或高层个人结构整理成去个人化候选。
- M08/M09 -> M05：M05 比较通用可学习结构与个人已形成知识，决定下一目标和路线；M10 在当前目标内依据 M04 诊断选择学习策略和活动条件。M08 不替代 M05 的规划、M04 的诊断或 M10 的策略选择。
- M08 -> M02/M03：提供定义、资料定位、前置、辨析点、逻辑链和可迁移结构；M02 负责教学互动，M03 负责练习活动与学习者产出。
- 独立候选/审计通道读取 M09 已结束闭环和必要证据引用，并向 M08 提交去个人化候选；它不是教学策略层，也不能绕过 M08 的状态和更正规则。候选是否可在探索教学中使用，另行确定。
- M08 为后续“上下文工程 + 图工程”提供按对象、关系、来源和状态读取的通用上下文。候选生成、审计、晋升和更正的运行记录由跨模块技术设计保存。M08 所需的模型能力（多资料综合、高层结构候选生成）在本单“以后转技术方案”中一并转出：本轮已取消 M12，不再有单独的模型与服务模块承接。
- M08 -> M04/M05/M10：阈值概念标记作为通用对象属性提供给三方使用——M05 用于优先级与路线安排，M10 用于强度参数取值，M04 用于把该处的卡点理解为质变前兆。M08 不判断任何学习者是否已跨过该概念，该判断归 M04，结果由 M09 保存。
- M08 <-> M14：M08 为知识产出物提供通用概念、方法和结构对象；M14 可就其研究问题提出跨资料/跨领域候选，走与 M09 相同的候选审计通道，不能直写 M08。围绕特定研究问题的暂时论证和个人工作模型作为产出物内容留在 M14；对论证的教学反馈归 M02，不归 M08 也不归 M14。

## 产品负责人审查问题

1. M08 的正式对象范围是否确认包含概念、方法，以及经过审计的结构模型/思维框架；定理、题型模式、应用情境和研究问题分别是独立对象、关系，还是资料属性？
2. 高层候选的最小表达应包含哪些内容：组成对象、共同机制、适用条件、边界/反例、教学用途、迁移方向中哪些为必需？
3. 候选晋升为正式 M08 结构时，哪些审计条件必需；人工、学习者、规则和模型各有什么确认/否决权？
4. 候选区中的内容能否在教学探索中使用；若可以，怎样与 M08 正式内容及 M09 个人形成记录清楚区分？
5. M08 的“层”是否只作为图上的抽象深度/学习视图，而不设固定层数；若需展示，应如何避免把多分支图误读为单一路径的树？
6. 用户编辑通用结构时，默认生成个人候选、可提交的通用候选，还是允许直接修改正式结构？
7. M08 与 M09 是否允许在同一界面叠加展示；若允许，怎样稳定标识通用结构、候选内容和“我的掌握状态”？
