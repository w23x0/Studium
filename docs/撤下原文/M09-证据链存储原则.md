## 原文（M09 审查单，2026-09-23 措辞统一版）

**核心机制**：M09 存储**证据链**而不是完整对话，也不是简单标签。

**证据链存储原则**：
- **内容**：总结对话历史的学习过程原始信息
  - 结论 + 证据链 + 关键理解 + 关系
  - 可追溯（能回到原始对话核实）
  - 可压缩（不会爆炸）
- **提交方式**：闭环守卫通过后**一次提交**，但提交的是**含过程证据的丰富记录**，不是只交最后结论（2026-09-23 措辞统一，与本单“写入一次闭环级个人形成记录”一致）
  - 要保留过程信息
  - 不是把完整对话塞进来，是结构化的证据链

**证据链示例结构**：
```
闭环：掌握导数定义
结论：已掌握（2026-09-09）
证据链：
  - [独立完成] 题目 A：求 f(x)=x^2 在 x=1 的导数（正确）
  - [轻微提示] 题目 B：求 f(x)=sin(x) 在 x=0 的导数（正确，需提示极限定义）
  - [独立完成] 题目 C：导数的几何意义（正确）
关键理解：
  - 导数定义：掌握
  - 极限定义：理解但不熟练
  - 几何意义：清楚
前置关系：
  - 依赖：极限定义（来自 M08）
  - 支撑：微分（后续学习）
```
