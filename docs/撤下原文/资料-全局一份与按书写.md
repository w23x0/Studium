## 管什么

| 部分 | 回答 |
| --- | --- |
| 入库 | 把书籍、讲义、论文、题集、网页、字幕等外部材料，变成有来源、有结构、可定位、可检查、处理状态明确的资源；失败或不完整的不伪装成可用 |
| 资料库 | 已入库、**不因某次学习表现而改变**的资料与题目：长期组织、浏览、查找、引用，向学习过程交付带来源与上下文的内容 |
| 主链 | 从全局唯一资料目录或项目选取视图进入 → 按结构、问题或标签找到内容 → 回到原件 |

## 原件、转录与修订（待定：未经定稿）

“原文” = **PDF 原件**；MinerU 输出降为可修订的转录（`方向记录.md` 10-06）。起因：Stewart 9e 的 PDF 字体编码坏（`=` → `−`、`<` → `,`、`/` → `y`、括号 → `s…d`），MinerU 照搬文字层，错误改变意思；PDF 文字层与转录错得一样，不能当第二来源（只查过一页，范围待量）。

| 项 | 内容 |
| --- | --- |
| 三层 | 原件（PDF 页面，不改）· 转录（MinerU v0 不改 + 修订记录只追加：位置、改前、改后、依据、提出者、核实状态）· 读取视图（v0 + 已核实修订，读时合成） |
| 定位 | 每块挂原件页码 + 位置框（MinerU `content_list.json` 已有）；锚点挂原件位置，转录修订或换转换器重转都不断锚；旧修订按位置重对，新版已改对的自动作废 |
| 锚点写法 | 原件位置（页 + 位置框）+ W3C `TextQuoteSelector`（exact + prefix + suffix，对读取视图），不用行号；修订后在同一位置内重新对引文（原为知识结构锚点所定，D-14）。会话与事件记录用行号，资料用锚点，两者不混用（B-01） |
| 修什么 | 按危害：等价写法（`\to` / `\rightarrow`）不修，比对时归一；改变意思的符号、结构错（标题层级、并节、图注分离、页边注混入）、内容丢失必修 |
| 候选来源 | ① 程序：LaTeX 编译失败、已知坏编码模式、连字丢失（`Diferentiation`）② 使用中顺带：读原文的会话（导航对资料核、教学）输出结构化“疑似转录错误”；学习者报告走资料库 → 入库修正 ③ 看图：按位置框截原件，能看图的模型对照提出改法，程序验 LaTeX |
| 按书归纳 | 坏编码整书一致：核实几处后成书级映射规则；`s` / `d` / `y` 本身是字母，规则须看上下文；规则产生的修订标来源、抽样核实 |
| 调度 | 机制通用；现阶段按需（被引用到、要给学习者看的块先核实），看图模型便宜后整本前置；预算只进调度，不进结构 |
| 块状态 = 由事件算出 | 每块只存事件：读到（哪个会话、何时）· 审查（谁、怎么审、结果：没问题 / 疑似 / 提出改法）· 修订（改前、改后、依据、改没改意思）；状态读时算：有核实 = 已核实，无核实有疑点 = 疑似，都无 = 未核实 |
| 审查分量不同 | 只读文字的会话只能报疑点、不能证明对（看不到原件；试跑中三个模型都悄悄改对公式不报）——须明确要求它们报疑点，“读过没报”只算弱证据；只有对照原件（看图模型或人）才算核实 |
| 核实绑定版本 | 核实挂在某一版文字上；修订后旧核实作废 |
| 修订多是警报 | 反复修订或两个核实者改法不同 → 标“有争议”，停自动修订，转更强模型或人；给学习者看时用截图 |
| 核实优先级 | 被读次数 × 风险（程序算：公式密度、命中本书已知坏编码模式） |
| 实现期 | 阈值（核实几次算稳、改几次标争议）看实际错误率定；原文层物理载体与身份 / 版本 / 时间契约（D-006） |

## 入库

| 功能 | 结论 | 级别 |
| --- | --- | --- |
| 来源登记与资料类型 | 保存原始来源、作者 / 许可或可分享状态、资料类型及目标归属；不同类型可有不同结构和定位方式 | 主干 |
| 内容提取与原文保真 | 提取正文、公式、图片 / 附件等可学习内容；处理后的正文不替换原件，须保留转换内容位置到原件位置的联动定位，使界面和会话能回到同一原文依据 | 主干 |
| 资料结构识别 | 识别章、节、段落及定义、动机、证明、例题、练习、综述等内容单元；书籍保留目录父子结构及章节关联，形成可调取的最小内容单元；深结构与浅结构资料不要求同一形态 | 主干 |
| 处理过程与状态查看 | 用户能看到当前阶段、产物、待处理、成功和失败：可观察、可纠正、失败不伪装成功；只保留可见阶段、状态和重做能力，不把历史“五步”顺序写死 | 主干 |
| 异常、校核与人工修正 | 明确缺页、定位失败、结构异常、公式 / 图片损坏、待确认类型；允许用户修正后重新处理，不静默跳过。**按块记状态**：未核实或有疑问的块照常进资料库并标明状态，在使用中继续被发现、核实和修正（B7） | 主干 |
| 内容预览与定位检查 | 入库前后可抽查正文、结构、内容类型和原文位置；生成性标注与原文分开呈现；不要求逐项人工确认 | 第二梯队 |
| 多类型与批量入口 | 更多文件、网页、字幕及批量资料；批量不削弱逐份定位和失败可见性 | 第二梯队 |
| 内容类型 / 扩展标注治理 | 系统可提出新内容类型或扩展标注，须显示来源、待确认状态并允许接受 / 拒绝，不静默改变正式分类；原文不被改写；不确认任何自动标注准确率 | 第二梯队 |
| 处理成本与产物复盘 | 保存处理的阶段结果，供错误复盘和质量检查；详细成本和技术产物是否产品化另审 | 候选 |

交付：带块级处理状态的资源、结构、来源 / 权利信息、转换内容与原件的联动定位；未核实块不冒充已核实。

## 资料库

| 功能 | 结论 | 级别 |
| --- | --- | --- |
| 资料目录与项目选取 | 资料本体全局唯一；项目可选取、重复调用；提供全局目录和项目选取视图；选取关系由程序存（`记录/对话与事件记录.md`），项目目标、关系和会话不归这里 | 主干 |
| 原资料结构浏览 | 按入库确认的书 / 章 / 节 / 段落或相应媒体结构查阅，看上下文和邻近内容；不重新识别或改写结构；学习资料不是无结构切片集合 | 主干 |
| 检索与调取 | 见下「检索」 | 主干 |
| 来源引用与原文跳转 | 每个结果保留资料、章节 / 页 / 段落等可理解位置，可回到原件；引用粒度与实际可定位粒度一致；“可理解且精确”，不继承具体分数、结果布局或分块形态；学习者看到的依据须可追溯原文，生成性说明须可区分、可复核 | 主干 |
| 内容类型与练习资源标签 | 按定义、证明、动机、例题、练习、综述等内容类型查找；标签由入库产生（结构与类型），也可由其他会话提出可复用、非个人的标签；保存标签不改写正文；不要求入库时统一标准化分类 | 主干 |
| 题目 | 题目本体在资料库；学习者实际做题、反馈链在学习对话的事件记录 | 主干 |
| 跨资料检索标签与重复线索 | 保存带来源和适用范围的标签 / 关联条件，找出同标签、同来源或高度相关的资料，作为重复、互补或进一步比较的检索线索；不独立断言覆盖、缺口、矛盾或价值高低 | 第二梯队 |
| 来源可靠性与适用性说明 | 展示作者 / 机构、时点、权利、适用阶段及已知限制；不用一个综合分数替代判断 | 第二梯队 |
| 资料质量反馈与修正 | 用户可报告定位错误、正文问题、重复或错误标注，回到入库修正，不直接改写来源 | 第二梯队 |
| 跨来源探索与资料推荐 | 按目标或资料缺口发现其他来源；推荐须展示理由、来源和是否已入库；外部发现、推荐范围和可信度未定 | 候选 |

## 检索

| 项 | 内容 |
| --- | --- |
| 按什么找 | 结构（书 / 章 / 节 / 段）、文本、内容类型标签、问题；整份与局部都能找，保留必要上下文；可用目录定位、全文索引、语义 / 向量检索或组合 |
| 不按什么找 | 不以点或子句作检索条件，不存点标签（10-18 第 3 条） |
| 谁用 | 学习者浏览；学习对话、守卫在沙盒里或经工具读原文；导航补资料、对候选核资料；知识产出取来源（读写见 `记录/读写权限.md`） |
| 范围 | 检索与引用在产品范围内（早期“不做 RAG、整段放入上下文”已推翻） |
| 引用 | 出处与原文位置必标（C-02） |

## 边界

| 对象 | 规则 |
| --- | --- |
| 不独立判断 | 覆盖、缺口、重复、互补、递进、矛盾、来源质量不是资料库的独立判断；可存检索标签和比较线索。学习者怎么理解归学过的记录；围绕研究问题的比较、解释、论证归知识产出（`记录/知识产出.md`） |
| 不做 | 自动综合质量分、固定权威阈值、“保留高分、删除低分”；不声称某种切片、检索或公式处理已验证最优 |
| 资料不被学习改写 | 个人学习表现、一次性过程记录、未确认推断不得改变资料内容或写成标签；学习者怎么理解 / 掌握只进学过的记录，不作资料标签写回 |
| 生成题 | 学习对话生成的练习不默认入库，来源标“生成”；标签命名空间与回流实现期定（D-008） |
| 入库 ↔ 资料库 | 入库交付已校核的资源；资料库把需重提取、重定位或重分类的问题退回入库 |
| 换模型 | 静默降级必须可见：处理状态与来源标记不因换模型而失真（`00-定位与原则.md`） |
| 旧提案 | 后期 PRD 中的 Project、父子分块、多资料类型等是设计提案、旧后端未实现，可作需求证据，不写成已验证事实 |
| 开发日志 | 面向开发的详细处理日志不在本页（原交跨模块过程记录，该设计暂缓） |
