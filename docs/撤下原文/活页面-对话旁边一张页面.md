## 11 活页面

一次学习里，对话旁边有一张一直在的页面。定义与边界在这里，页面怎么被改见 `页面子代理.md`。

| 项 | 内容 |
| --- | --- |
| 为什么有 | 学习者的注意力几乎只在当前这一轮，对话流越长越乱、位置越难找；页面用平面、非线性的排布压缩信息，控制信息的边界和速度，让学习者一直处在学习状态。作用是压缩，不是多装 |
| 是什么 | 一个持续对象，由模型写代码构成（含用代码做的动画），随对话一点点改；页面上的文字（含分析）由主模型写，位置、样子、交互由子代理管；不是插在对话流里的卡片，不是一次性做成的书或课程（`../记录/知识产出.md`「学习内容编制」不做照旧） |
| 我们做什么 | 只做底层框架和挂在学习对话外面的工具与接口；不做技能、不定样式规则，页面长什么样由模型决定。提示词只写页面是什么、为什么有、学习者在和它一起交互；其余靠框架每轮给事实 |
| 怎么改 | 按结构块（HTML 元素）局部替换，不按行、不整页重写；检查由框架做：内容过期拒绝、没看过的地方不许改、按元素定位。替换的写法跟着接入的模型换（做薄，给以后的模型留余地） |
| 主对话看什么 | 自己写的页面文字自己知道；子代理做出的东西（函数图、代码等）交回时只说一句做了什么，要细节主模型自己调工具查。主模型上下文里不出现块编号、版本号；页面过没过时由程序核对 |
| 谁写代码 | 页面上的文字由主模型写；位置、样子、交互交给主模型派出的子代理（`页面子代理.md`）。主对话用教学的话说要什么（露哪块、折哪块、标什么）以及留给子代理多大余地。露什么、露多少是教学判断，留在主对话 |
| 版本 | 程序内部给页面存版本号与块编号（存档、核对改动是否过期、看旧版用），不进主模型上下文；模型改一次、学习者动一次都产生新版本；同时动页面时过期的改动由程序拒绝 |
| 看旧版 | 学习者可以看以前的版本，只看：页面与上下文都不变；不做退回（不满意就直接说，主对话接着改） |
| 学习者在页面上的动作 | 学习者在页面上真动手的操作（填答案、拖滑块、展开 / 折起等）与说的话是同一种身份：学习者；只记观测得到的（真操作、打字、说话），不记“看得到哪几块、在哪块停了多久”。页面自己定义的动作由子代理写页面时接上框架给的发送口递出（页面不能联网，只经这个口），带时间进上下文，不交子代理：平时攒到学习者下次说话时一起带上，等回应的动作（如提交答案）立刻跑一轮；连续的动作合成一条、算一版。页面不放选择题、“我懂了”这类低信息量按钮（收口时学习者手动申请“我觉得懂了”另算，`../01-流程.md` §4） |
| 学习位置图 | 不是固定部件，是模型可以在页面上画的一种东西（例如点 = 知识点、线 = 关系、亮度 = 扎实程度、此刻所在最亮）；画不画、怎么画由模型定。框架给依据：哪些点、此刻在哪、哪些被守卫确认过（来自单子与学过的记录）；只有守卫确认过的才算扎实，学习对话自己的看法不算；线从哪来不预先限定 |
| 进外层 | 页面改动由程序记进事件记录（`../记录/对话与事件记录.md`） |
| 技术架构 | 页面怎么存见 `实现选型.md`「选型」活页面一行；子代理怎么改见 `页面子代理.md`「怎么改」；拿不准的细节不预先限定，交给模型 |
```

# 页面子代理

> 状态：已决（2026-10-26）。来历查 `../../../定稿记录.md`。活页面的定义见 `学习对话.md` §11，本页不复述。

主模型（学习对话）派出的子代理，用 Agent SDK 自带的子代理，统称“子代理”，不另起名字。分工：页面上的文字（含分析）由主模型写；子代理管位置、样子、交互。目的是让写代码的细节不进学习对话的上下文，主对话只拿它判断要用的最少信息。Studium 只做外围：子代理能写哪些文件、交时检查、浏览器隐藏小窗试跑（见「怎么改」）。

## 何时开、活多久

| 项 | 内容 |
| --- | --- |
| 何时开 | 主模型第一次要改页面时派 |
| 后台跑、活多久 | 待定：SDK 子代理能否后台跑、跨次叫它时是否保留自己的上下文，等查（`../../../任务线路.md` #62） |
| 模型 | 单独配；主对话用 Opus 时，子代理用 Opus 或 Sonnet，可选更快的模型 |

## 交接（主对话 → 子代理）

| 项 | 内容 |
| --- | --- |
| 文字 | 页面上要出现的文字（含分析、公式）由主模型写好交给子代理，子代理照原样放，不改写 |
| 要什么 | 用教学的话说：展开哪块、折起哪块、标出什么、换一种画法、做一个什么图，以及改完应该看到什么 |
| 留多大余地 | 每次写明这次的问题有多开放，例如“只把第 3 步展开”或“把这个概念换一种画法”，子代理据此决定自己能动多少 |

## 交回（子代理 → 主对话）

| 项 | 内容 |
| --- | --- |
| 交回什么 | 一句话：做成了什么（如“画了函数图”“加了一段可拖动的代码”），或哪里报错；写明是子代理交回的结果，进主对话的时间线（`学习对话.md` §3），不回头改前面的内容 |
| 细节 | 子代理做出的东西不在交回里展开；主模型要细节自己调工具查 |
| 不交回 | 代码、调用日志、改动过程、块编号、版本号；改动由程序记进事件记录，留给界面与审计 |
| 改坏了 | 改动先在隔离区里做，框架检查通过才上页面；出错在子代理这边改掉，学习者看不到半坏的页面 |

## 怎么改

| 项 | 内容 |
| --- | --- |
| 用什么改 | 不发明新工具：框架把页面按块摊成文件放进子代理的沙盒（每块一个文件，加一份目录），子代理用模型自带的读和替换去改 |
| 没看过不许改 | 子代理读过哪些块，框架从沙盒动作里知道；改了没读过的块，退回 |
| 交 | 子代理改完交一次；框架查版本号对不对、有没有动没读过的块，新块的编号由框架发；过了才生成新版本（版本号与块编号只在程序内部用，不进主模型上下文） |
| 试跑再换上 | 新版本先在学习者浏览器里一个看不见的小窗里跑，没报错才换到前台；报错交回子代理改，学习者看到的一直是上一版。加载后点了才出的错，等学习者碰到时报回再修 |

## 边界

| 项 | 内容 |
| --- | --- |
| 不做教学判断 | 露什么、露多少由主对话定；子代理只决定怎么做 |
| 不写页面文字 | 页面上的文字（含分析）由主模型写 |
| 读写 | 只读写页面；范围以 `../记录/读写权限.md` 为准 |
| 代码跑在哪 | 模型写的代码在学习者浏览器的沙盒里跑，不联网，动作都经框架 |
```
