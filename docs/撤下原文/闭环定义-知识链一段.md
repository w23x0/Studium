## 闭环定义（2026-09-28）

**一个闭环是知识链上的一段**：从学习者已经站稳的知识点出发，走到一个新的知识点，并让它在学习者这里**闭合、连上**（产品负责人 2026-09-28 确认，依据真人试用 me-8 / me-9：me-8 闭环被做成“主张 + 证据”的取证过程；me-9 改后只剩快速讲授、没有训练，走完即关，效果不好）。“环”有三层：

| 层 | 含义 | 依据 |
| --- | --- | --- |
| ① 闭环内：理解 ↔ 训练 | 先理解（讲、推导，质量不低于教材），再用它做应用训练（M03：契合学习者知识面的综合题），训练中的思考反过来让理解真正完成；看懂 ≠ 理解，单靠输入不算闭合 | `学习理论/最小学习单元理论.md`（采纳） |
| ② 闭环收口：判定 + 连上 | 学习者认为学完、或系统判断可收束时提议结束，**由学习者确认**；判定看能否自己从头把这段链走一遍、换问法或新情境下仍能用（缺口就补）；关闭时记下这一段**连上了哪些已关闭的知识点** | 前代 Deep「学习会话闭环」、四项闭环证据 |
| ③ 闭环之间：串联上升 | 多个已关闭的闭环连成网，从中长出更高层的个人结构（方法、模型、思维框架），经候选通道丰富 M08，再供下一轮规划——**本产品的特别之处；属未来，不在当前基础范围** | M09「闭环网络与高层个人结构」、M08「M08/M09 交替递增」 |

| 范围 | 做法 |
| --- | --- |
| 闭环内 | 教学对话发生在这段链上：该讲就成段讲，该练就练，学习者已经会的就往前走；前置缺了在过程中发现、记下，不开场考前置；提问和出题是为了让学习者想清楚、用起来，不为取证 |
| 闭环间 | 系统管这条链往哪走：这一段选得对不对（是重点、合学习者的水平），前置缺得多就先走前置那一段；学习者钻研出的新方向记为下一闭环候选，由 M05 在项目目标与学习者兴趣之间控制方向（主线 / 分叉 / 搁置） |

教材 = M08 里选出的一块子结构 + 作者排定的线性学习路线；多本教材是同一 M08 上的多条路线。

检验：单次闭环的教学不明显差于“通用对话模型 + 同一份教材”；跨闭环（记得学到哪、会了什么、下一段走哪、连上了什么）明显更好。最终以产品负责人真人试用为准。
