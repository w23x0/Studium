# M14 高阶学习与知识产出

> 状态：已精简（2026-10-05，#24），原文见 `../撤下原文/审查单精简前/`。技术实现见 `../../Harness设计/03-运行设计.md`。

### 核心问题

保存并迭代学习者自己的知识产出物：一篇研究、写作或内容编制成品从草稿到定稿的对象、版本链、修订比较、来源引用位置和编辑恢复位置。M14 不是第二套教学、练习、诊断或规划模块，也不保存通用知识；它是专属于本人的产出物容器，与 M08 的去个人化通用知识、M09 的已结束闭环个人知识形成记录并列而不重叠。

M14 的主干由产品负责人在第三次重构中直接确立；六份“学术补充理论”只是文献索引和理论方向，`DeepTutor 书籍功能.md` 属外部产品观察，都不是本单功能的已验证依据。

### 功能

| 功能 | 产品结论 | 级别 |
|---|---|---|
| 知识产出物对象 | 围绕一个研究/写作/内容编制目标建立可继续编辑的成品对象，保存其材料引用、开放问题、草稿、反馈位置和恢复位置。全项目没有其他模块能承载“进行中的成品”。 | 主干（模块成立前提） |
| 版本链与修订比较 | 保存同一产出物的多个版本顺序、每版改动说明和可比较的差异，支持回到任一历史版本。 | 主干 |
| 来源与对象引用位置 | 产出物中的每段内容可回到 M07 的原文位置和 M08 的通用对象，引用关系随版本保留。 | 主干 |
| 研究问题相关的文献关系 | 围绕特定研究问题组织引用、相互支持/矛盾、方法沿革和来源可靠性；关系必须回到 M07 来源，不写回 M08 通用关系。 | 第二梯队 |
| 方法比较与适用边界 | 对多个方法的假设、适用条件、证据、限制和可迁移性形成结构化比较，并保存研究中尚未定论的暂时论证；与 M08 候选通道的移交时机待定。 | 第二梯队 |
| 研究问题形成 | 从资料缺口、矛盾、边界和跨域类比中外化候选问题，记录问题如何变化，不替学习者宣称研究价值；是否属于产品职责待产品负责人确认。 | 候选 |
| 学习内容编制（书籍/课程/页面） | 不做，也不作为隐藏候选功能（含 DeepTutor 式实时生成、自动评分、智能补弱、内容块）。 | 明确不做 |
| 多人协作、同行评审与知识交流 | 不做，也不作为隐藏候选功能。 | 明确不做 |

### 输入输出

- 输入：M07 的多份资料、来源与出处位置；M08 的通用概念/方法对象与关系；M01 的项目归属、会话位置和已保存过程记录；M04 的理解与掌握判断（已结束闭环形成的相关个人知识经 M04 读取，M14 不直读 M09）；学习者提出的研究问题、写作意图与已有成果。
- 主要处理：建立产出物对象；保存草稿及其版本链，记录每版改了什么并支持版本比较；维护回到 M07 来源和 M08 对象的引用位置；保存编辑与恢复位置；围绕特定研究问题组织文献关系、方法比较和暂时论证；把可去个人化的结果整理为 M08 候选。
- 输出：可继续编辑的知识产出物及其版本链与修订差异、来源/对象引用位置、围绕研究问题的文献与方法结构、面向 M08 候选审计通道的高阶候选材料。M14 不输出教学表达、练习任务、诊断结论、掌握判断、跨闭环路线或学习者状态解释。

### 边界

**已退回其他模块的功能**（M14 只在产出物侧接收其结果）：

- 深度阅读路径 → 讲解/追问归 M02，复述/批注等学习者表现归 M03，理解判断归 M04，阅读顺序与路线归 M05，会话归属归 M01。
- 长周期研究过程（计划、监控、调节、反思、子目标、暂存/重开）→ 归 M05（三项主干与阶段复盘、停车场）与 M01（任务状态与搁置/恢复）；长期项目的任务容器归 M01。
- 论证与批判性评估的**反馈输出** → 归 M02 教学反馈；M14 只保存论证对象本身及其版本。
- 解释与写作迭代中的**反馈** → 归 M02；“修订与版本比较”留在 M14。
- 长期研究项目形态 → 归 M01 项目模板的既有候选（考试、课程、研究等项目形态）。

**分工**：

- 六份学术补充理论不是六个模块。维度2（抽象建构与多层概念理解）的归属：表征转换归 M02，阶段性表述与“哪些概念是阈值概念”的标记归 M08，均不在 M14。
- 解释、写作、推导、实验既可能是 M03 的学习活动，也可能形成 M14 的成品：用于验证能力的当次任务归 M03，其长期可迭代的成品与版本归 M14，判断归 M04。
- 产出物跨多个学习闭环存在，但它本身不是闭环，也不产生闭环判断；闭环的开始与结束仍由 M04 判断、M01 保存。
- 不用抽象层名（“高层网络 / 上升学习”）替代可审查功能。
- M01 ↔ M14：M01 管项目/会话/闭环的生命周期、归属和过程记录；M14 只拥有产出物对象、版本链和引用位置，不管理任务生命周期。
- M05 → M14：M05 规划下一步、优先级、复检和长周期节奏调节；M14 保存产出物内部的开放问题演进，不做跨闭环路线决定。
- M07 → M14：M07 提供原文、出处和静态互补/矛盾；M14 的引用必须回到 M07 位置，不改写 M07 内容，也不把一次性产出物写进 M07。
- M08 ↔ M14：M08 提供通用概念/方法对象与关系；M14 的高阶结果去个人化后经 M08 候选审计通道提交（与 M09 共用），不直接写入 M08。研究中的暂时论证留在 M14。
- M02/M03/M04 → M14：M02/M03 组织讲解与独立产出、M04 形成理解判断；M14 只接收其中可沉淀为成品的阅读、解释、实验和写作结果，不承担教学表达、练习生命周期或判断。
- M10 → M14：M10 为高阶任务选择策略与强度条件；M14 不拥有策略。
- M15 → M04/M05/M10：学习者状态由 M15 拥有并由 M04/M05/M10 消费；M14 不解释状态，也不因产出物进度推断状态。
- 跨模块过程记录保存运行过程和审查链（M13 暂作设计参考）；M14 保存用户真正要继续编辑和交付的知识产物。
- 待定：产出物能否脱离项目独立存在。
