# M10 教学策略系统

> 状态：已精简（2026-10-05，#24），原文见 `../撤下原文/审查单精简前/`。技术实现见 `../../Harness设计/03-运行设计.md`「闭环对话」。闭环怎么定义见产品总览「闭环定义」，本单只用“本闭环的新点 / 出发点 / 选中的子句”“合上”这些词。
> 更新：2026-10-16（#47 闭环内只限不增：教学工具进沙盒、强度由闭环对话自己定，M10 从“提供教法”转为“了解 / 定制到这个学习者”；被取代的原句见 `../撤下原文/M10-教学工具与强度下发.md`）。

### 核心问题

Studium 的目标不是把系统做成替学习者讲授答案的“老师”，而是从学习者已经形成的理解和当前条件出发，帮助其通过合适的学习活动走向更高阶的理解、独立调用和思考。

M10 服务一个个学习闭环，但不在闭环内下发策略：闭环对话据 M04 的诊断和学习者状态自己选教法、定强度，M02/M03 的教学互动和练习活动都在这个主循环里形成。M10 事后读事件记录，了解这个学习者、把教法定制到他身上。

M10 回答的是：**这个学习者在什么教法、什么强度下有反应。** 它不判断学习者是否掌握，不拥有闭环守卫，不决定学习目标、分叉、收束、返回或跨会话路线。

M04 只形成诊断事实、替代解释、证据限制和验证需要，不给教学建议；M10 不重新诊断，事后读记录和 M04 的后续判断，整理教法对这个学习者管不管用。

### 功能

**职责分工**：教学工具不常驻提示词、不装进闭环，作为沙盒里的可读资料，模型需要时自己查（以后模型可能内化教法，只需提醒激活），不写成诊断记录的栏目（见 M02「职责分工」）。哪一轮读了哪份教学工具、用了什么强度，由程序当场记进事件记录，须可识别、可比较：可识别靠每份教学工具有名字，可比较靠使用记录与之后是否判合上的对照；M10 事后读这些记录更新个人策略过程记录，放进沙盒供下个闭环查。教学强度由闭环对话自己定，不由 M10 下发。

**学习者导向的策略原则**：

- M10 的策略服务学习者自己形成理解、结构、逻辑链、独立调用和迁移，而不以更快给出答案或更像教师讲授为目标；M10 不能因为拥有策略而变成教师式讲授模块。
- “从学习者已经表现出的理解位置出发、不过早给出完整答案”是 M02 的有限视角教学原则，不由 M10 单独占有；闭环对话定强度和提示条件时遵守它。有限视角材料中的“诊断路径”和“最小推动”拆开：M04 形成诊断，闭环对话选择推动策略，M02 以学习者视角形成表达。
- “学习者完成关键思考、独立产出并暴露过程”是 M03 的活动原则。
- “当前缺输入还是缺练习”是闭环对话基于 M04 诊断作出的策略结论。M04 只说明当前缺口和证据，不直接指定应该讲解还是练习。
- 用户可在会话中主动提出现实需求；用户级配置和自定义策略暂不作为默认功能，只保留为第二梯队候选。

| 策略理由与可见记录 | 保留每轮的教法、强度、依据、状态条件和主要取舍（事件记录），供后续教学界面解释、学习复盘和产品审查使用；默认展示方式以后决定。 | 第二梯队 |
| 用户级策略配置与自定义 | 允许用户长期选择、调整或提供策略。当前不作为默认功能，待基本策略模型稳定后再审查。 | 第二梯队候选 |

### 输入输出

- 输入：
  - 事件记录（每轮用了什么教法 / 强度、读了哪份教法资料）与教法资料，以及该学习者过去的个人策略过程记录和 M04 后续判断；
  - M01 当前会话承载的闭环目标和位置，以及 M05 给该闭环的单子（新点 + 选中的子句 + 路线动作）和必要路线条件；
  - M04 的当前诊断、替代解释、证据限制、未满足项和需要验证的内容；
  - M15 学习者状态与条件提供的非知识类信息（M04 用于解释当前表现，闭环对话用于选择教法和强度，M05 用于跨会话路线）；
  - 学习者在当前会话主动提出的现实需求和限制。
- 主要处理：事后读事件记录，了解这个学习者在什么教法、什么强度下有反应；接收 M04 在后续活动中形成的新判断，更新个人策略过程记录。
- 输出：个人策略过程与效果记录（放进沙盒供下个闭环查）。M10 不下发策略与强度，不直接拥有最终面向学习者的讲解、追问或练习正文。

### 边界

- 旧资料中的回答、反问、出题、推进、拦截、补资料（含六种动作、八组动作空间）只是历史动作空间，不限制 M10 策略模型或 M02/M03 的活动类型。M04 → M10 表示产品职责上的判断与策略关系，不预设固定调用顺序。
- 压力、疲劳、负荷、注意力、现实时间和其他非知识类条件不是 M10 自己诊断或保存的对象；它们属于 M15，M10 只消费其信息。
- 固定学历阶段、固定分数阈值、固定策略顺序和“策略一定直接产生某效果”的表达不进入需求。
- **M04 → M10**：M04 提供当前理解、卡点、替代解释、证据限制和验证需要；闭环对话依据这些事实选择教法，M10 事后读记录整理。M04 不提供教学建议，M10 不重复诊断或闭环判断。闭环守卫不转给 M10：守卫需要闭环级证据链（M04 持有跨轮诊断与证据），M10 只拿到诊断摘要。
- **M15 → M10/M05（主要消费者）与 M15 → M04（裁决）**：同一状态信息可分别用于调整会话内策略、规划跨会话路线和解释表现，不等于职责重复；M15 拥有状态对象、范围和时间有效性，三个消费者不反向拥有状态语义。**承载读数**（当前负荷、可挂核心任务数、可承载连续时长、环境限制）闭环对话可直接使用；**解释候选**（本次下降的状态解释）须以 M04 输出中“已评估的状态候选”为准，不自行判断候选真假。
- **对状态成因的自查义务**：当前教法本身会制造状态——逐题评判会抬高威胁感，稀释审判频率会降低它。M15 记录这类状态时会标注它出现在某一反馈模式生效之后。闭环对话读到带此标注的状态时（M10 事后整理记录时同样），**必须先检查自身教法是否为成因**，不得直接当作学习者固有条件（例如因威胁感上升而降低难度，而真正成因是逐题评判，正确动作是改为阶段性验收）。M10 不向 M15 写入策略决定，该标注由 M02/M03 的可观察事实产生。
- **M15 的状态阶段类型**：状态阶段判断跨会话子模块给出下降所属阶段（习惯低谷、堆积型下滑、疲劳退化、阈值型动力低）及判断跨度，只给读数、不给动作。M10 侧的对应动作是疲劳退化降载、阈值型动力低改高频小反馈；习惯低谷与堆积型下滑主要由 M05 处理。M10 不重新判断阶段类型。
- **阈值概念停滞：调强度不改道。** 卡在阈值概念上是质变前兆，属预期内下降，闭环对话在会话内提高投入、加密小反馈，**不改路线**（改道归 M05）。它与习惯低谷刻意**不合并**：阈值停滞是知识侧、会话内，在闭环对话内处理；习惯低谷是状态侧、会话外，走 M15 → M05。
- **M04 的阈值概念跨闭环子模块 → M10**：输出“某阈值概念跨了多少闭环仍未过”的类型与时间跨度读数，只给读数不给动作、不与状态侧合成单一「学习压力」量。M10 与 M05 各读两个读数、在各自作用域内行动；M05 不改道而 M10 降载并非不一致：路线不动，本轮减压。
- **强度由闭环对话自己定**（10-16）：闭环对话参考 M04 的分析与 M15 的状态读数后，自己定**本次会话内的强度坡度**（本轮节奏、信息量、分解粒度、挑战程度），可调外部数据来判断；程序照记每轮用了什么强度，M10 事后读记录整理。**合上标准不可下调**——是否合上由 M04 闭环守卫判断（产品总览「闭环定义」“合上”行）。本闭环新点与子句的调整必须经 M05 决定、M01 落实。加压/减压的切换是多输入策略判断（M04 诊断、阈值概念跨闭环读数、M15 状态阶段读数），具体组合待定。
- **M10 与 M02/M03**：M10 不向 M02/M03 下发策略与强度；强度（信息量、提示强度、挑战程度、节奏）由闭环对话自己定，M02/M03 的教学互动和练习活动都在这个主循环里形成。
- **M08 → M10**：向闭环对话与 M10 提供**阈值概念标记**（强度取值）。M10 用到的是与本闭环相关的 M08 内容（点与子句；辨析用时当场判断）；这些内容缺失时 M10 的模型能力足以完成当下一步。M10 不判断学习者是否已跨过阈值概念，该判断归 M04。
- **M04 → M05 → M01**：若 M04 判断当前闭环需要改变目标、补前置、搁置或重规划，M04 向 M05 提供依据；M05 作跨闭环路线决定，M01 落实会话结构。M10 不拥有这条链路，不包含方向守卫、分叉深度、收束、返回或重新规划。
- **M09 与 M10**：知识相关历史通常先由 M04 与当前证据合成为诊断，再交给 M10；M10 的个人策略过程与效果记录独立保存，不写入 M09。
- **M05 与 M10**：分别位于闭环之外和闭环事后，存在必要的信息交流，具体交换内容在后续实际设计中再确认，当前不作为 M10 功能或输出。
- **M13**：策略理由、使用记录和 M04 后续判断需要可追溯；日志与复盘的实现不归 M10。
