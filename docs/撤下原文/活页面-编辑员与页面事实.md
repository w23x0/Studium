## 一、`会话/页面编辑员.md` 整页（原样）

# 页面编辑员

> 状态：已决（2026-10-26）。来历查 `../../../定稿记录.md`。活页面的定义与退回见 `学习对话.md` §11，本页不复述。

学习对话沙盒里一个专管活页面的子代理：主对话说改什么，它决定怎么写代码。目的是让写代码的细节不进学习对话的上下文，主对话只拿它判断要用的最少信息。

## 何时开、活多久

| 项 | 内容 |
| --- | --- |
| 何时开 | 学习对话第一次要改页面时开，一次学习一个 |
| 活多久 | 跟这次学习同在：做完一件不销毁，保留自己的上下文（记得页面的代码），下次叫它时接着做；学习结束随之结束 |
| 模型 | 单独配；主对话用 Opus 时，编辑员用 Opus 或 Sonnet，可选更快的模型 |

## 交接（主对话 → 编辑员）

| 项 | 内容 |
| --- | --- |
| 改什么 | 用教学的话说：展开哪块、折起哪块、标出什么、换一种画法，以及改完应该看到什么 |
| 留多大余地 | 每次写明这次的问题有多开放，例如“只把第 3 步展开”或“把这个概念换一种画法”，编辑员据此决定自己能动多少 |
| 页面版本 | 主对话依据的页面版本号；对不上的改动拒绝 |

## 交回（编辑员 → 主对话）

| 项 | 内容 |
| --- | --- |
| 交回什么 | 一句结果：成了，或哪里报错；以及改后学习者看得到哪几块。经收件箱以事实追加，不回头改主对话前面的内容 |
| 不交回 | 代码、调用日志、改动过程；这些由程序记进事件记录，留给界面与审计 |
| 改坏了 | 改动先在隔离区里做，框架检查通过才上页面；出错在编辑员这边改掉，学习者看不到半坏的页面 |

## 怎么改

| 项 | 内容 |
| --- | --- |
| 用什么改 | 不发明新工具：框架把页面按块摊成文件放进编辑员的沙盒（每块一个文件，加一份目录），编辑员用模型自带的读和替换去改 |
| 没看过不许改 | 编辑员读过哪些块，框架从沙盒动作里知道；改了没读过的块，退回 |
| 交 | 编辑员改完交一次；框架查版本号对不对、有没有动没读过的块，新块的编号由框架发；过了才生成新版本 |
| 试跑再换上 | 新版本先在学习者浏览器里一个看不见的小窗里跑，没报错才换到前台；报错交回编辑员改，学习者看到的一直是上一版。加载后点了才出的错，等学习者碰到时报回再修 |

## 边界

| 项 | 内容 |
| --- | --- |
| 不做教学判断 | 露什么、露多少由主对话定；编辑员只决定怎么写 |
| 读写 | 只读写页面；范围以 `../记录/读写权限.md` 为准 |
| 代码跑在哪 | 模型写的代码在学习者浏览器的沙盒里跑，不联网，动作都经框架 |
| 退回 | 学习者退回时，编辑员的上下文与主对话一样从分叉点截掉、补一句教训（`学习对话.md` §11） |

## 二、`会话/学习对话.md` 被改的行（原样）

### §1 提示词与上下文

| 项 | 内容 |
| --- | --- |
| 提示词与上下文 | 位置、状态、策略、系统限制都以事实进入（开场、收件箱），不写成命令；提示词只留最小约定，不用角色、不用输出模板（B-03、B-05） |

### §2 收件箱

| 项 | 内容 |
| --- | --- |
| 收件箱 | 程序中途推事实：守卫的收尾记录、离开多久、学习者动作等 |

### §3 何时跑一轮、暂停与回来

| 项 | 内容 |
| --- | --- |
| 何时跑一轮 | 学习者每发一次话；程序经收件箱推事实后（守卫交回收尾记录、学习者离开后回来）接着跑一轮 |
| 暂停与回来 | 不算事件：学习对话原样留着，回来时程序向收件箱推离开多久，模型据此接着教（`../01-流程.md`） |

### §11 活页面

| 项 | 内容 |
| --- | --- |
| 项 | 内容 |
| 主对话看什么 | 页面的目录（每块的编号与一句话）+ 学习者此刻看得到哪几块，不看整页代码 |
| 谁写代码 | 主对话用教学的话说改什么（露哪块、折哪块、标什么）以及留给编辑员多大余地；怎么写代码交给沙盒里的页面编辑员（`页面编辑员.md`）。露什么、露多少是教学判断，留在主对话 |
| 版本 | 主对话、页面编辑员、学习者看到的页面共用一个版本号；模型改一次、学习者动一次、退回一次都产生新版本；同时动页面时过期的改动一律拒绝 |
| 学习者在页面上的动作 | 两种：框架自己看得到的（学习者看得到哪几块、展开 / 折起、在哪块停了多久），框架自动记，用来更新主对话的“学习者此刻看得到哪几块”；页面自己定义的（填答案、拖滑块、点“我懂了”等），由编辑员写页面时接上框架给的发送口递出（页面不能联网，只经这个口）。都作为事实经收件箱交给主对话（§2），不交编辑员：平时攒到学习者下次说话时一起附上，等回应的动作（如提交答案）立刻推；连续的动作合成一条、算一版 |
| 技术架构 | 页面怎么存见 `实现选型.md`「选型」活页面一行；编辑员怎么改见 `页面编辑员.md`「怎么改」；拿不准的细节不预先限定，交给模型 |
