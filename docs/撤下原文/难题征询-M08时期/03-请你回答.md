# 请你回答

前面三份是背景、难题和已看过的方案。想听的是**创造性的意见**：换个角度看问题、我们没想到的做法、或者指出我们问题本身问错了。

## 想要的

| 要 | 说明 |
| --- | --- |
| 挑问题 | 六个难题里，你认为哪些其实是同一个问题、哪些是问错了、哪个最该先解决 |
| 新角度 | 尤其难题 1、2、5：子句怎么来、怎么挂到多本书上、“学出什么理解”怎么写得具体 |
| 方向检查 | “M08 = 点 + 子句”“先生成后回扫”已定，但只在一本书的一章上试过；你看有没有根本性的问题 |
| 能落地 | 每个建议说清：落在哪一层（原文 / 点 / 子句 / M05 判断 / M09），谁来做（程序 / 模型 / 人），先用一个主题（如 ln / exp）怎么试 |

## 不要的

| 不要 | 原因 |
| --- | --- |
| 靠大量学习者数据或训练模型的方法 | 只有一个学习者，没有题库 |
| 把多本书的点合并成一个点 | 违反“各存各的、只追加”；会抹掉书和书的差别 |
| 已在 `02-已看过的方案.md` 里判过的，除非你有新理由 | 免得重复 |
| 打分公式、固定刻度判“会不会”“合没合上” | 已定由模型读对话原文判断 |

## 格式

1. 先用三五句话说你最重要的看法。
2. 再按难题编号逐条给意见，每条标：**把握程度**（有依据 / 推测）；有外部依据的给出处。
3. 最后列出你认为我们没问、但应该问的问题。
