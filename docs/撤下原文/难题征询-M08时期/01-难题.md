# 难题

> 每条：问题 · 已知的 · 为什么不满意。顺序大致按卡得多紧。

## 1. 多本书的结构怎么关联

| 项 | 内容 |
| --- | --- |
| 问题 | 不同书的子句几乎不可能一样，这正是书和书的差距。多本书怎么挂到同一张点 + 子句网上，让下游拿到“一个点的几条子句”？难点有两层：两本书里的两个点是不是同一个点；两本书走的两条路线是不是同一条子句 |
| 已知 | 逐点两两对齐在领域内仍未解决（本体对齐评测 OAEI 2025 报告自述“复杂对齐、非等价关系”未解决）。定义不同的已定拆成不同的点（ln 的积分定义与反函数定义是两个点），所以“同一点”只在定义相同时成立；但两本书讲同一条定理、讲法也相同时应该能对上，两者在文字上很像，模型容易混。形式数学库里“比后果、不比定义”认出同一对象有效（Gauthier & Kaliszyk 2019），没在自然语言教材上验证。书有时自己写出另一条路（Stewart：“另一种做法是先用积分定义对数”） |
| 现在的想法 | 未讨论：先生成的那份清单当中心，各书逐本对它审核、回扫（不两两比）。只试过一本书的一章 |
| 不满意 | 难点挪到“清单上的点落到哪本书的哪个点上”；抽出的点概念与陈述混在一起，“后果”不一定抽得出来；没有验证过 |

## 2. 先生成后回扫：怎么高效发现“书里有、清单没有”

| 项 | 内容 |
| --- | --- |
| 问题 | 模型凭自身知识说出的子句，可能集中在最常见的一两条路线，漏掉书里少见但有价值的讲法（这正是 M08 的本质：清单要被不断补——书补、学习过程也补） |
| 已知 | 试跑里回扫确实有用：书里有、清单没有的路线找出 8 条（背景 §7）；审核时让模型写出“书自己那条”才找得全（试跑里只部分写了） |
| 不满意 | 回扫等于又要读懂每本书的路线，书一多成本按书线性涨；不知道漏掉的比例，只试过一章 |

## 3. 审核审到什么程度

| 项 | 内容 |
| --- | --- |
| 问题 | 子句与跨书链接都由模型审核。审多严？没有标准答案、没有多个学习者、没有题目对错，拿什么判一个子句“对” |
| 已知 | 书给的有原文作证；模型补的只是候选；学习者真走通了是单人证据 |
| 不满意 | 错误率未知；审核者也是模型，可能和生成者犯同样的错 |

## 4. 一个闭环多大

| 项 | 内容 |
| --- | --- |
| 问题 | 导航从一条子句出发往下排新点，排到“一次坐下来能走完的量”就停。这个量怎么定 |
| 已知 | 文献里没有用“一次坐下来”（小时级）定学习单位的；认知负荷理论说单元大小相对学习者已有图式；学习者状态（精力、时间）由另一模块给读数；由模型判断，不用公式 |
| 不满意 | 没有数据校准；估错的代价是闭环拖长或太碎 |

## 5. “学出什么理解”能不能写具体

| 项 | 内容 |
| --- | --- |
| 问题 | 子句的价值在“从这里进去，学出来是什么样的理解”。这句话写得出具体内容（如“从积分进去，把 ln 理解为面积的累积”），导航才能按目标挑；只能写“理解更深”就没用 |
| 已知 | 书里很少直接写这句话；试跑显示书走了这条路线就能从证明步骤读出（每步用到出发点的哪个性质，背景 §7）；书没走的路线只能靠模型自己写 |
| 不满意 | 不知道能写到多具体；子句用固定格式（“从 X 出发，把 Y 理解为…；用到 X 的…”）还是自由句子没定，固定格式可能僵硬 |

## 6. 没有逐条数据回路

| 项 | 内容 |
| --- | --- |
| 问题 | 做题驱动的系统（Math Academy）能按每道例题的通过率改讲解、发现某处切得太粗；我们的讲解是模型现场生成的对话，没有这种回路。路线好不好、子句准不准，拿什么反馈 |
| 已知 | 闭环内有现场出的练习；闭环原始对话全部保存；学习者走出的新路线可作候选回流 |
| 不满意 | 单个学习者没有对照，理解薄是出发点选错还是别的原因分不开 |
