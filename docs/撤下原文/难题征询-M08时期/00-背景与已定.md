# 背景与已定

## 1. 项目一句话

Studium：给成年自学者（高中以上、不为应试，偏研究型理科，如微积分、物理、电路）用的学习系统。闭环内的教学交给大模型；系统把力气放在大模型做不好的部分：跨时间记得学到哪、会了什么、下一步学什么、知识怎么连起来。现阶段只有一个学习者（产品负责人本人），模型只用 Claude Opus 5.5 / Sonnet 5.5。

## 2. 闭环（学习的基本单位）

| 项 | 含义 |
| --- | --- |
| 定义 | 从学习者**已会的几个出发点**出发，学知识网上的一个**新点**，靠这些出发点把它理解到位 |
| 出发点不同，理解不同 | 同一个点从不同出发点学（如同一物理定律从代数或从微积分出发），学到的理解不一样，所以要记“从哪学会的”，不只记“会了” |
| 合上 | 新点经出发点接进学习者已有的认识（同化或顺应），而不是学成孤立的一块；由模型读对话原文判断，不用打分公式 |
| 目标分三层 | 方向目标（和学习者对话确认）· 闭环之间（导航决定方向、节奏、开几个新点）· 单个闭环的目标（比较固定，导航不另定深度；由什么决定还没定） |
| 大小 | 一次坐下来能走完；阶段越高，出发点越抽象 |

## 3. 相关的三个部分

| 部分 | 做什么 | 关键约束 |
| --- | --- | --- |
| 知识网（下称 M08） | 通用知识结构：点 + 子句 + 原文 | 不读任何个人信息；原文（书的 PDF 原件）是权威，其余都是派生；只追加、可撤回；新内容默认是候选，经审核才算数 |
| 学习者模型（下称 M09） | 记这个人合上过的闭环：经哪条子句学会了哪些点、实际学出什么理解，底层是闭环对话原文 | 只在闭环合上时写入；分析层可从原文重做 |
| 导航（下称 M05） | 每次只设计下一个闭环，开一张单子：新点 + 选中的子句 + 路线动作（继续 / 补前置 / 分叉 / 搁置） | 读 M08 + M09 + 学习者状态（精力、时间）；最后由学习者从几个选项里选 |

闭环内外都按 agent 操作设计：模型带查询工具，自己决定查什么、查几次，不是“装配一次材料、调用一次模型”。

## 4. 约束

| 约束 | 说明 |
| --- | --- |
| 存的都是文字，给模型读 | 不是给人看的数据库；也要能被审核者（模型或人）读懂 |
| 没有统计数据 | 一个学习者，学习方式是对话，没有题库、没有大量答题记录；知识追踪、强化学习这类靠大数据的方法用不上 |
| 输入干净 | 没有统计去纠错，只能靠给模型的输入准确、可回查 |
| 规模 | 本机书库 30 多本（微积分、线代、概率、电路、电磁学、C++ 等），已转成文字（PDF 原件仍是权威） |
| 抽取现状 | 旧做法（免费模型逐节抽点表 + 两两关系表）分不出几个出发点是否合走一条路，还丢了整条路线，结果已全部作废；新做法只在 Stewart 第 6 章试过一次（见 §7） |

## 5. 已定

| 项 | 内容 |
| --- | --- |
| 点 + 子句 | M08 的基本结构是点 + 子句。子句 = “会了这几个出发点，就能学会这个新点，预期学出什么理解”；一条子句指向一个新点，一个新点可有多条子句（借自知识空间理论）。子句不属于某本书，标来源：书给的 / 模型补的。不再用两两连线的关系种类（前置 / 推导 / 组成 / 混淆）作基本结构 |
| 点按定义拆 | 同一对象的不同定义（如 ln 的积分定义与“eˣ 的反函数”定义），学习者可能只会其一的，拆成不同的点，靠子句连接 |
| 子句是条件 | 子句对谁都成立；会不会、经哪条子句学会、实际学出的理解、书里没有的个人路线都在 M09，不进 M08 |
| 书给的子句是标准 | 但标准不代表个性化：给谁选哪条，由导航按学习者模型判断 |
| 先生成、后回扫 | 模型先凭自身知识说出某主题有哪些点、哪些子句；再拿书审核：找得到支撑原文 = 书给的，找不到 = 模型补的（候选）；书里有、清单没有的路线回扫补进来。审核由模型做 |
| 派生写精简句子 | 点一句、子句一两句；关键词 / 公式只给程序粗筛用；细节经锚点回原文 |
| 知识边缘与簇由模型判断 | 知识边缘 = 未会、但至少一条子句的出发点全已会的点；簇 = 学习者会的一串细点按人合并、可整体当出发点。都不用图计算，由模型配查询工具判断；簇不作为状态存储，要用时现场判断 |

## 6. 未定

| 项 | 说明 |
| --- | --- |
| 子句格式 | 固定 / 半结构字段，还是自由的精简句子 |
| 混淆 / 对比 / 同级类比 | 子句是学习路线，装不下它们；怎么表示没谈 |
| 多本书怎么关联 | 见难题 1 |
| 审核审到什么程度 | 见难题 3 |
| 单个闭环的目标由什么决定 | 候选：选定的子句 + “合上”；还模糊 |

## 7. 试跑（新做法只试过这一次）

| 项 | 结果 |
| --- | --- |
| Stewart 9e 第 6 章，6 个目标点 | Opus 生成 34 点 / 42 子句，再对全章审核：点大多能落到书上（18 一致、6 处书的定义不同）；子句 11 条书给的、20 条“部分”、11 条模型补的；书里有而清单没有的路线 8 条。只试过一本书的一章 |
| 原文读得出“学出什么理解”吗 | 书走了某条路线就读得出：证明每一步要用出发点的某个性质（如 ln 的积分定义正合微积分基本定理第一部分）；书没走的路线读不出 |
