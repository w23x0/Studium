### 一句话

一个项目只有一条主对话。学习者在这里说话，主对话先分清是哪类，再做对应的一件事；重活不在这里做。

### 何时开 · 开场给什么

| 项 | 内容 |
| --- | --- |
| 何时开 | 一个项目一条，常开；学习者发话、任务对话交回时接着跑 |
| 开场给什么 | 方向目标（`../记录/方向目标.md`）、最近几条消息、路线记录（`../记录/单子与路线.md`） |
| 上下文 | 小；可随时换掉、从记录重建 |
| 模型与强度 | 默认低强度（只分类、转交、贴卡）；配置规则见 `../01-流程.md` §2 |

### 分类后做什么

| 学习者说的是 | 主对话做的事 |
| --- | --- |
| 新方向 | 在这条消息下开畅谈对话（`畅谈.md`） |
| 要下一步，或一次学习刚结束 | 请导航出选择卡（`导航.md`），贴给学习者；学习者选定后开这次学习的学习对话（`学习对话.md`） |
| 跟进某次学习 | 指向那个对话 |
| 问进度 | 按记录回答（路线：`../记录/单子与路线.md`；会话状态：`../记录/对话与事件记录.md`；学过什么：`../记录/学过的记录.md`） |
| 闲聊、致谢 | 一句话或不回 |

学习对话结束交回时，主对话说一句结果，接着贴出下一张选择卡（顺序见 `../01-流程.md` §3）。

## 01-流程.md §1–§3

## 1 交互形状

学习者面对的是对话框：一个项目一条主对话，具体的事在主对话下面开任务对话做。参照 Claude 的项目模式（主对话 + 任务对话），只取形状，与云端无关。

| 项 | 含义 |
| --- | --- |
| 项目 | 一个项目对应一个方向目标，粒度不限（一门学科、一本书、一个专题都可以），由畅谈得出、可再谈再改（`记录/方向目标.md`）；书是项目选用的资料（`记录/资料.md`），不是目标 |
| 主对话 | 一个项目只有一条；学习者在这里说话，主对话分清是哪类再做对应的一件事（`会话/主对话.md`） |
| 任务对话 | 畅谈对话：谈出方向目标，交回项目（`会话/畅谈.md`）；学习对话：一次学习一个，开场拿单子，结束交回（`会话/学习对话.md`） |
| 选择卡 | 导航给几个选项、各带理由、推荐其中一个，学习者最后选（`会话/导航.md`） |
| 学到的东西 | 学过的记录按人、按时间存，不按项目划界，每个项目都能看到（`记录/学过的记录.md`） |

## 2 有哪些会话

每页回答：何时开 · 开场给什么 · 能读什么 / 工具 · 交回什么 · 边界。本表只列一句，以各页为准。

| 会话 | 做什么 | 何时开 | 页 |
| --- | --- | --- | --- |
| 主对话 | 接学习者的话，分类后做一件事 | 一个项目一条，常开 | `会话/主对话.md` |
| 畅谈对话 | 谈出方向目标 | 主对话判为新方向时 | `会话/畅谈.md` |
| 学习对话 | 一次学习内的分析、讲、练 | 学习者在选择卡上选定后，一次学习一个 | `会话/学习对话.md` |
| 守卫 | 写这次学习的收尾记录（学习者实际表现出的理解），不把关 | 收口流程中，每次申请收口 | `会话/守卫.md` |
| 导航 | 开单子、出选择卡 | 一次学习的边界；学习者要下一步；会中出现改线需求；在主对话背后单独开 | `会话/导航.md` |
| 后台整理 | 整理状态记录、教法记录 | 会话结束后等，不挡选择卡 | `会话/后台整理.md` |
| 程序（不调模型） | 登记事件、开场交付、开会话前查必需项（缺了不开）、向收件箱推事实、收口时调守卫、存盘 | 每个事件 | 本页 |

| 要点 | 内容 |
| --- | --- |
| 会话不互相调用 | 都从记录里取、只写自己的产出；读谁、写谁以 `记录/读写权限.md` 为准（D-15） |
| 不是固定执行顺序 | 会话之间按事件接线（§3），不当成固定流水线或严格路由 |
| 模型与强度按会话类分开配 | 每类会话各有自己的模型与思考强度配置项，不写死、不全局一个；默认主对话低强度（只分类、转交、贴卡），其余高强度；具体用哪个模型实现期按 `../模型基准/` 定 |

## 3 一次学习之外：按事件排

一次学习之外没有一条从头跑到尾的主循环，也没有程序记着的“当前阶段”（不写状态机）：程序只认刚发生了什么事，照这件事的清单做；清单里每步是一个会话或一个程序动作。加一种事件或改一张清单，别的清单不受影响。

| 事件 | 清单 |
| --- | --- |
| 学习者在主对话发话 | 主对话分类后做一件事（`会话/主对话.md`） |
| 一次学习合上（收口第 4 步，学习者确认） | 见下「合上之后」 |
| 学习者要结束、没合上 | 见下「没合上就结束」 |
| 暂停（学习者走开、过后回来） | 不算事件：学习对话原样留着，回来时程序向收件箱推离开多久（对话保留时间，模型知道每条消息的时间），接着教；隔很久回来时状态记录顺带整理（`会话/后台整理.md`） |

**合上之后**：

| 步 | 内容 |
| --- | --- |
| ① 程序存收口快照 | 事件记录、单子、守卫判定、学习者确认，作为收口快照存下（`记录/学过的记录.md`）；不调模型 |
| ② 导航出选择卡 | 紧接 ① 开：导航读方向目标、学过的记录等出卡（`会话/导航.md`）；主对话说一句结果，接着贴出选择卡 |
| ③ 后台整理不挡卡 | 状态记录整理、教法记录（这次教法管不管用）在后台跑（`会话/后台整理.md`）；只影响下一次学习怎么教，不挡选择卡；没跑完按“无状态读数”降级 |

- 合上后不另开会话写形成记录或分析层：守卫判定顺带写下“学习者实际表现出的理解”，指回学习者的行（`会话/守卫.md`）。
- 每次学习只有一份结论性产物（守卫判定），不在同一粒度上出两份说法；也不另写总结（B5）：多一份总结就多一个二手版本，漏了或偏了会一路传下去。什么时候学完由学习对话与学习者定；“合上” = 守卫写好收尾记录 + 学习者确认。

**没合上就结束**：

| 步 | 内容 |
| --- | --- |
| 触发 | 学习对话沙盒里的“结束这次学习（没合上）”命令（原名“结束闭环（没合上）”）：学习者在界面上点，或在对话里说了由模型代为执行（`会话/学习对话.md`） |
| ① 程序存盘 | 事件记录、学习者要结束的原话，状态记“没合上就结束”；不开守卫，没有守卫判定 |
| ② 导航出选择卡 | 导航读这次学习事件记录里的完整对话出下一张选择卡；当时的路线决定和理由随之存下 |
| ③ 后台整理 | 同「合上之后」③ |

- 这次学习的上层 = 单子 + 学习者为什么结束的原话 + 导航当时的路线决定和理由（`记录/单子与路线.md`）；不另写停车记录或总结。
- 学习者觉得其实学会了，走手动申请收口（§4），不走这里。

## 单子与路线.md「选择卡」「没合上那次的上层」

## 选择卡

卡的形状（几个选项、各带理由、推荐一个、学习者最后选）见 `01-流程.md`；怎么出卡见导航「选择卡」。本页只管存什么。

| 存什么 | 内容 |
| --- | --- |
| 选项 | 每个选项 = 一张单子草稿 + 理由 + 从哪来（学习对话里冒出的问题 / 导航现场说出的候选 / 现场判断的知识边缘上的点） |
| 推荐 | 推荐了哪一个 |

学习者选定 → 程序把那张单子存下、存路线事实 → 开学习对话，单子进开场（`01-流程.md`）。

## 没合上那次的上层

学习者没合上就结束（“结束这次学习（没合上）”命令，流程见 `01-流程.md`）时，不开守卫、没有判定，**不另写停车记录或总结**（10-18）。那次的上层是：

| 内容 | 谁写 |
| --- | --- |
| 单子 | 开始时已存 |
| 学习者为什么结束的原话 | 程序存盘时记（指回事件记录行号） |
| 导航当时的路线决定和理由 | 导航读那次的完整对话出下一张选择卡时写（本来就要读）；缺在哪个出发点、接着学还是先补出发点，写在这条理由里 |

- 这三样就是停车场里一条的内容；停车场怎么用见导航「二级功能」。
- 它说明打算学什么、停在哪、为什么停，**不是学会了的证据**（没有守卫判定）。
