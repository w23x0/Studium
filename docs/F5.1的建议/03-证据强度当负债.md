# 1.3 证据强度当负债：M05 用"仅当场"安排延迟复述

> 状态：建议（记录待用；最贴近实施顺序第 3 步）。不作产品结论。

## 问题根据

| 观察 | 出处 |
| --- | --- |
| 守卫已为每条主张输出证据强度：仅当场 / 含变式 / 含延迟；目前只用于当次结论 | `../../proto/studium/prompts/guard.md` |
| 固定复习天数、单一遗忘曲线、数值追踪已被否定 | M09 审查单"被覆盖的旧结论" |
| 第 3 步要验证"闭环记录能否支撑下一次 M05 / M04"，但还没定 M05 读记录后**做什么** | `00` §实施顺序 第 3 步 |

## 做法

| 步骤 | 内容 |
| --- | --- |
| M09 提交 | 每条主张带证据强度列（守卫原样给出），进闭环记录 |
| M05 设计下一闭环 | 读上次记录；凡"仅当场"的教学主张，在新闭环开头安排**一次**延迟复述：不看旧稿重讲一节（配合 `01-讲解稿与版本差异.md` 即重写 + diff） |
| 通过 | 该主张升为"含延迟"，作为新闭环的一条确认类主张写进验收范围，守卫照常核对 |
| 不通过 | 只算候选（M04 次序约束）：给 M10 补讲，或由 M05 记为复习负债；不写 M09 遗忘记录 |
| 限流 | 每个闭环开头至多复述一条，优先选新闭环要依赖的前置 |

## 为什么值得

| 点 | 说明 |
| --- | --- |
| 间隔提取的效果 | 有了延迟提取，却不需要遗忘曲线或数值；触发依据是证据本身的等级，可核对、可回溯 |
| 与现有设计零冲突 | M04 次序约束、M09 只在闭环结束写、M05 管路线，全部沿用 |
| 第 3 步的通过标准 | "诊断能引用上次证据、不把已会内容重考"：复述只针对"仅当场"，已"含延迟"的不再碰 |

## 风险与不确定

| 项 | 说明 |
| --- | --- |
| 节奏 | 每闭环开头多一轮；me-4 已暴露节奏慢，限流一条是底线 |
| 强度判断本身 | 守卫给的强度是模型判断，回放（`02-冻结回放.md`）可查其稳定性 |
| 状态侧解释 | 复述失败可能是疲劳等状态原因；沿用 M04"候选 ≠ 记录"，不新增机制 |
| 待定 | "含变式"是否也算负债、多久算"延迟"（跨会话即可，还是要隔天）属实现细节，登记到实现期 |
